## 연결·미확인·확인 범위

- 기존 Main friends stable ID→open/always→modal-friends, Close→close/always. Escape는 presentation 정책이며 가짜 클릭 transition을 만들지 않습니다. 외부탭닫기는 미확인입니다.
- Send/Reject는 action/target 빈칸·condition unknown. 실제 요청/전송/거절 API·게임수치변화는 미확인입니다. 표시 피드백만으로 성공을 주장하지 않습니다.
- 원본6행은 일부만 보입니다. 제안한84px root는 통일된 공간일 뿐 그 안의 미관찰 본문·금액·아이콘을 창작하지 않습니다.
- 이 하위는 source/UI/설계/공용수신·STATUS·보고/서버/빌드/패키지/외부발송을 변경하지 않았습니다. actual UI·native입력·저장/재열기·키보드·모바일/데스크톱·404·스크롤은 실행하지 않았습니다.
- 생성은 이MD/JSON2개뿐이며 새 파일이라 기존 파일 백업 대상이 없습니다. 메모리 확대 관찰 이미지는 파일로 저장하지 않았습니다.
