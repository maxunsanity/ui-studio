# 모노폴리 GO 영상 UI 목록

[화면·상태·연결 문서 열기](/ui-studio/source/guide/reference/monopoly-go-video-20261117/index.html)

기존 툴 조립 10화면 r277/902부품/20연결과 지정 MOV 9개(합계 230.868초)를 대조했습니다. 영상별 화면 기록44개/상태84개(연출·로딩 포함)를 UI 가족 후보31개(게임25/외부6)로 묶었습니다. 신규 게임 가족21개와 쇼룸 토큰 보완1가족은 제작 대기이며, 기록 수/정적 검사 수를 완성률로 쓰지 않습니다.

## 읽는 방법

1. 현재 제작 10화면의 실제 캡처와 최초 제공 참고를 비교합니다.
2. 영상 목차에서 화면ID·시각·원본 전체 프레임·게임 영역 크롭을 엽니다.
3. 관찰 연결은 문서 이동일 뿐, 제품 동작 연결이 아닙니다. 클릭·뒤로·닫기 결과가 불명확하면 runtimeTarget=null로 남깁니다.
4. 누락 목록에서 공통 규격/부품 분리/새 그림·투명 자원/native text·입력·9slice/엔진 그림자를 계획한 후 native 툴로 조립합니다.
5. 기존ID·연결·원본 보존, 저장/재열기·기기·마우스/키보드/초점/차단·스크롤을 검수하고 실제 저장판으로 목록을 갱신합니다.

## 영상 추출에서 확인한 경험

- 메타데이터 읽기와 프레임 디코드 성공은 별도입니다. AVFoundation은 MGV04/05/09에서 325/325프레임 성공했고, 다른 영상에서 실패한 결과를 전체 실패로 일반화하지 않습니다. 검증된 앱 번들 ffmpeg는 바이너리만 재사용하며 앱을 실행/조작하거나 새 패키지를 설치하지 않습니다.
- fps=2 JPEG의 0.5초 표시는 샘플 예정 시각입니다. 원본 입력 PTS와 다를 수 있습니다. 실제로 MGV07의 명목0.5초JPEG와 원본0.5초PNG의 팝업 유무가 달랐습니다. 최종 대표는 원본 PNG와 실제 PTS(showinfo/AVFoundation actual)를 기록합니다.
- MGV05 18.0초는 어두운 전환 프레임이어서 같은 잠김 상태의18.5초 원본 PNG를 대표로 바꾸고 이전 프레임을 진단 자료로 보존했습니다.
- JPEG를 PNG로 저장한 크롭은 원본 직접 PNG가 아닙니다. 현재 상태68개는 원본 PNG,16개는 JPEG 리뷰 크롭으로 명시했습니다. 크롭은 참고 자료이며 정식 그림 자원에 등록하지 않습니다.
- 정본은 docs/reference/monopoly-go/video-analysis-20261117입니다. 브라우저용 공개본은 기존 도구 source/guide 공개 경로에 필요한 문서/캡처만 복사하고 public-manifest.json에 정본·SHA를 기록합니다. 원본 MOV는 복사하지 않습니다. 서버 allow-list 수정/재시작은 없습니다.
- 이번 브라우저 캡처에서 스크롤 후 기본 screenshot이 빈 화면을 반환했습니다. 실제 DOM y·devicePixelRatio를 기록하고 SDK clip을 실측 배율로 지정해 내용이 보이는 캡처를 다시 확인했습니다. 빈 파일은 최종 증거에서 제외하며 모든 환경에 이 보정이 필요하다고 일반화하지 않습니다.

## 현재 경계

외부 스토어·GO!CHAT은 영상 참고만 기록하며 설치·계정·동의·메시지·구매를 실행하거나 외부 URI를 추측하지 않습니다. 7018만 진행/7007 제외, 프로젝트 guide.4와 2차 카피바라고 전용 설계·자원·탭·규격은 보존합니다. W/P/U/S0/4·원본 최종 동등 승인0/10·게임 API/폰트/사용자 승인 미완료입니다.

## 감옥 신규 조립 진행 · r283

영상 목록 완성 뒤 native18부품을 추가해 현재11화면920부품20연결입니다. 기존10화면/20연결은 r277과 deep equality입니다. 카드 fill9/frame9·인물·제목/보상/×10·주사위·하단 바탕/고정 그림/버튼/남은 횟수는 분리했습니다. 새 인물은 내장 imagegen, 고정 녹색 버튼/보라 3slice는 기존 SVG/Pillow 제작 방식을 재사용했습니다. source screenshot 재사용0입니다. 인물의 극소 alpha fringe 때문에 raw bbox가 넓어지는 것을 확인해 alpha>4 bbox로 여백을 계산하되 master/내부alpha를 보존하고 v002로 남겼습니다. 빈 배수/부모 상속·복사된 source region·형제순서도 재확인했습니다.

공통 연출 draft의 딤 체크는 저장 설정과 다릅니다. 해당 모달 안 버튼에서 연결 저장은 제품 규칙상 거절됩니다. 이때 native 페이지 임시 버튼으로 같은 연출 설정을 저장하고 즉시 임시 버튼/edge를 지운 뒤 기존10화면/20연결 불변을 확인했습니다. 외부JSON수정이나 최종 가짜 연결을 만든 것이 아닙니다. 인물 그림은 frame보다 앞에 놓아 테두리가 몸 위를 가르지 않게 했습니다.

감옥 입구·결과는 미확인이라 연결을 비웠습니다. 남은 횟수는 현재 static native text이며 게임 감소/판정 구현이 아닙니다. 기존 Main HUD 숨김, 감옥 3D 문맥, 3→2→1→0·보석금 상태, 원본 삽화 유사도·장식·폰 기기 최종검수는 남아 있습니다. 단위 조립을 전체 완성으로 세지 않습니다.

### 기기 비례 보완 · r284

430×932 기기 보기에서 legacy % 카드의 높이가280.35px로 늘어난 것을 실제 확인했습니다. 화면 논리 폭551을 유지하는 CanvasScaler 보기에서는 높이만 여유 공간으로 늘어나므로, 새 카드/하단 바탕/왕관2개/버튼/남은 횟수의6화면직속요소를 native 고정 RectTransform 앵커로 바꿨습니다. Card는왼쪽위 [109.5,-195]/332×296, Bar는왼쪽아래 [0,0]/551×120, Crown2는[145.5,0]/260×280, Roll은[160.5,60]/230×220, Remaining은[95.5,12]/360×36입니다. 아래앵커의 양수Y는 위쪽으로 올라갑니다. 내부자식은 고정 부모에 상대 배치합니다.

실제430에서Card259.086×230.995·Roll179.492×171.688,390에서Card234.985×209.507·Roll162.795×155.717로 논리크기×폭비율과0.08px이내6/6쌍이 일치했습니다. 두기기보기이미지실패0/loading0,Escape닫기·기준551복귀·최종r284파일재열기를확인했습니다. 이것은 상세편집기 기기보기이며 브라우저 CSS430 독립 runtime 전체검수를대신하지않습니다. 기존10화면/20연결은불변입니다.


## 최신 .24 · 배후 UI 숨김 / 감옥·보석금 r289

독립 정본의 native 공통 연출은 '배후 화면에서 숨길 레이어'에서 기준 페이지의 화면직속 레이어를 선택합니다. '공통 설정에 적용'은 설계 변경이며 파일 저장은 별도입니다. 동작 연결이 없는 모달도 설정만 저장할 수 있어 임시 버튼/임시 edge를 만들 필요가 없습니다. 선택/연출 draft와 저장을 구분합니다.

presentation.hideBaseElements는 stable ID 배열(중복 없음/최대400)입니다. 활성 모달들의 합집합만 배후 페이지에 visibility:hidden으로 적용하며 DOM·컨트롤·스크롤은 보존합니다. 닫히면 남은 모달의 숨김만 유지하고 전부 닫히면 복원합니다. 다른 기준 페이지에 없는 ID는 효과가 없습니다. Main/특정 게임 이름을 엔진에 하드코딩하지 않습니다. Grapes 단독 모달 보드는 배후 페이지가 없으므로 이 옵션을 표현하지 않고 저장 계약을 보존합니다.

이번 실제 r289는12화면936부품20연결. 감옥18/보석금16의6화면직속 앵커를 고정하고,14개 기존 Main HUD/이벤트 루트만 선택했으며 Slot_3D는 유지했습니다. 상세 동작 시험 기기390×844/430×932의6루트 크기·높이·닫기 복원/이미지 오류를 확인합니다. 독립 runtime의 새 감옥 입구/게임 판정·횟수 감소·보석금 연결·원본 동등은 미완료입니다.

복사·붙여넣기는 선택 번들 최상위를 현재 좌표의 legacy %로 평탄화하고2% 오프셋을 줍니다(commands.mjs). 따라서 고정 앵커가 보존됐다고 가정하면 안 됩니다. 보석금 r286은 이 때문에 세로가 늘어났고, native6앵커 재입력 후r289에서 고쳤습니다. 내부 자식/부모/TargetGraphic 재매핑 보존과 최상위 반응형 계약을 별도 확인하세요. 가로폭만 맞아도 높이·모서리·하단 위치가 맞는 것은 아닙니다.

이번 기능 RED→관련29/29→새 전체509/509 통과. 기존 VM의 새 의존 주입/문서 immutable 교체 후 오래된 객체 참조, 새 fixture logicalSize 누락을 수정한 실패 기록도 보존했습니다. 자동시험은 시각 완성률이 아닙니다. 원본10화면/20연결 deep equality, 다른 프로젝트 guide.4·2차 설계/자원 무수정입니다.

현중이 추가로 버튼/그림자 정확성을 요청했습니다. 실제3초 마우스 누름에서 normal→hover→pressed 및 tint1→.949→.741을 확인했지만 앞면/글자 이동·상태별 그림자는 아직 없습니다. 감옥 버튼 부모와 이미지의 이중 그림자도 확인했습니다. 고정 입력 wrapper/림 + 앞면 그룹(이미지/글자/비용 동반 이동)의 선택적 계약을 2차 세션과 공유했으며 연구/구현/실검수 전 지원 완료라 쓰지 않습니다.
