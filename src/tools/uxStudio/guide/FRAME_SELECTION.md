## 추가 기록 · 복제 부품과 화면 복구의 경계 (2026-11-18, .32 보충)

선별한 프레임의 재사용에서도 복사 결과를 원본과 동일한 화면으로 간주하지 않습니다. 복사는 선택 루트의 앵커·안전 영역을 평탄화하고 위치를 2% 옮기며 새 ID와 ‘복사’ 이름을 만듭니다. 함께 복사되지 않은 버튼 그림/눌림 대상/탭 패널과 외부 화면 연결을 별도로 대조합니다. 같은 역할의 규격과 그 게임의 논리 크기를 기준으로 native 속성을 다시 맞춥니다.

논리 크기·연출·딤/차단/닫기 정책, 시작점과 들어오는 입구는 별도로 설정합니다. Clipboard는 현재 탭의 메모리이므로 미저장 원본의 백업으로 쓰지 않습니다. 원본 탭 전환 전 정식 내보내기 보존과 깨끗한 탭의 저장·재열기 시험을 구분합니다. 새 문서에 v4 부품을 붙이기 전에 논리 크기를 설정해야 합니다.

세부 보존 범위와 절차는 [사용 설명서의 복사·부분 복구](USER_GUIDE.md#native-copy-recovery)를 따릅니다. 이번 보충은 소스/파일 검토이며 실제 문서 간 UI 복구 성공이나 새 프레임 완성으로 세지 않습니다.
