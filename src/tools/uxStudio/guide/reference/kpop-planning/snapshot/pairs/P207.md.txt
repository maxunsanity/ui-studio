# P207 · 음악 앱·차트·페스티벌 · 대표 개발 기획서

**이 문서는** 한 시즌 63일 가운데 1~8주 주간 페스티벌(동레벨 100명 구역)과 9주차 월드 페스티벌(실력별 리그 · 동시 차트 인 · 파이널 1,000 · 5탭)에 발매곡으로 출전하고, 같은 음악 앱에서 발견·감상·투표하는 화면 계약을 설명합니다.

**보는 법** 1장 흐름 → 3장 신청 화면 → 4장 음악·평가 → 7장 미확인 범위 순서입니다. 세부 규칙은 [P191 4-6](../../기획서/산출_기획서_음원×페스티벌_v1_클로드.html#festival-current-contract), 실행은 기존 공통 버튼 구역과 오른쪽 시험 도구를 사용합니다.

**지금 상태** 현재 개발되지 않음, 진행 중. 주간 달력 63일 · 7일째 바퀴 보상 · 인기 기획 시뮬, 주간 개인 신청(현중 직접 확인) · 월드 개인/크루 신청과 활동 로비의 로컬 시험은 개발됨입니다. 100명 구역 · 100명 그룹 · 파이널 정확히 1,000명 나누기는 표(`festival_runtime.json` `weeklyZoneSize` · `worldGroupSize` · `worldFinalSize`)와 계산(`festival-brackets.mjs`)까지 개발됨(11/16)이고, 그룹당 차트 인 비율 · 리그 크기 · 5탭 스냅샷 · 화면 연결은 현재 개발되지 않음, 진행 중입니다. 2차 기획(기간 투표 · 게임 인기 · 곡 배틀 · 외부 연동)은 기획만 있고 구현하지 않았습니다.

### 음악 앱 메인·내 음원·투표·인기 응원

**2026-11-10 16:33 KST · 현중 직접 지시 반영 · 제안**

| 위치 | 현재 화면 계약 |
|---|---|
| 음악 앱 메인 | 음원·공연·숏츠 카드 3개. 일반 앱 입장은 메인으로 열고 하위 시험 메뉴는 유지합니다. |
| 내 음원 | 실제 내 팀의 발매곡을 강조 박스와 ‘내 발매곡’ 표시로 구분합니다. 음원·차트·보관함에 같은 표시를 사용합니다. |

| 주간·월드 | 현재 기간과 연결된 순위가 있을 때만 표시합니다. 단독 시험은 선택한 주간/월드 범위를 따릅니다. 개인 순위와 크루 순위를 합산하지 않고 크루 순위는 별도 입구로 엽니다. |
| 음원 목록 | 내 발매곡·다른 출전자 곡·시험 음원을 구분합니다. 이 목록 순서를 추천순 또는 인기 급상승순이라고 부르지 않습니다. 추천·급등은 차트의 별도 지표입니다. |
| 관객 투표 | 감상 → 찜 → 보관함 → 출전곡·대회 확인 → ‘이 곡에 투표하시겠습니까?’ → 확정. 음원 목록의 직접 투표를 없앱니다. 취소/닫기는 쓰지 않고, 확정 시 최신 내 팀·회차·찜·자격·한도·투표 상태를 다시 확인합니다. 확정한 투표는 취소할 수 없습니다. 공식 인정 감상 초수는 새로 만들지 않습니다. |
| 월드 인기 응원 | 월드 차트 → 인기 → 출전곡 ‘인기 응원’ → 사용할 수량 확인 → 인기 사용하기 → 해당 곡 기여 인기·인기 기여 차트 갱신. 투표·추천·찜·레이싱 연료와 별도입니다. |

**2026-11-10 17:01 KST** 찜 선택·출전곡 상세 투표 보정: 찜한 곡은 채운 하트와 ‘찜 완료’로 표시합니다. 감상용 시험곡의 찜은 점수 원장과 분리한 개인 보관함에 실행·세션·시즌·내 팀 범위로 보관합니다. 데이터 갱신·화면 이동·새로고침으로 사라지지 않으며 전체 초기화는 새 범위를 엽니다. 찜한 출전곡은 보관함과 곡 상세/재생 화면 모두에서 투표 확인창을 열 수 있습니다. 음원 목록에서 바로 투표를 쓰지는 않습니다. 감상용 곡에는 ‘감상용·투표 대상 아님’을 표시하고 주간·월드 출전곡 입구를 제공합니다. 출전곡이 아닌 곡을 실제 대회 후보로 만들지 않습니다.

**구현과 정책의 구분:** 자유 시험에서는 가져온 데이터도 인기 재화를 무제한으로 사용하며, 사용 영수증·곡별 기여를 공통 실행/세션/시즌/내 팀 범위로 보관합니다. 화면 재진입·새로고침으로 재사용하지 않고 기존 전체 초기화가 새 범위를 엽니다. 인기 기여 차트는 사용한 인기의 누적량을 비교하는 시험 순위입니다. 실제 활동의 인기 획득 공급·유한 지갑·지급량·상한·최종 우승 점수 비중은 발란스/운영 연결 대기입니다. 인기 기여 순위와 기존 월드 종합 시험 순위를 같은 점수라고 표시하지 않습니다.

### 세 차트 보상·앨범 누적·월드 보드 전환

**2026-11-10 15:16 KST - 현중 직접 지시 반영 · 제안**

| 차트 | 보상 종류 | 용도 |
|---|---|---|
| 일반 랭킹 | 한 바퀴 보상 | START 통과 정산·일반 성장 |
| 주간 페스티벌 | 레이싱 연료 | 레이싱 사용 |
| 월드 페스티벌 | 인기 재화 | 월드 출전곡 인기 기여 |

**현중 직접 정정:** 일반 차트·주간 차트·월드 차트의 세 개로 구분합니다. 주간과 월드는 개최 기간이 겹치지 않습니다. 일반은 한 바퀴 보상, 주간은 레이싱 연료, 월드는 인기 재화로 획득 내역과 표시를 분리합니다. 지급 수량·상한·정확한 획득 사건은 비앙카 장부 산정 항목이며 인기 재화를 연료로 대체하지 않습니다.

**앨범 누적 기여:** 대표곡 한 곡을 우대하고 지난 발매곡들도 낮은 가중치로 기여하는 기존 기획을 일반 한 바퀴 보상에 명확히 연결하는 제안입니다. 1개와 8개의 차이를 보유곡 기여·직전 성적 계승·출전곡 선택 폭으로 구분합니다. 앨범 수만으로 활성 버프를 8중 적용하지 않습니다. 대표곡/구작/시간 감쇠 계수는 정본 비어 있는 값을 보존합니다.

**월드 신청과 보드 복귀:** 성공한 월드 신청의 출전곡·현재 팀을 확인한 뒤 게임으로 돌아오면 같은 보드의 연습실·녹음실 등에 공연용 간판과 월드 표시를 적용합니다. 표시가 준비된 뒤 폰 내부 모달 「월드 공연 보드로 전환됐어요」와 「공연 보드 확인」 버튼을 보여 줍니다. 신청 실패·취소·보기만 한 경우·주간에는 표시하지 않습니다. 확인한 같은 시즌/팀의 전환 알림은 재진입·새로고침·개인/크루 중복 출전으로 반복하지 않습니다. 표시가 준비되기 전에 알림을 소비하지 않습니다.

**기간·보존:** 일반 연결은 실제 월드 기간의 유효 신청을 확인합니다. 단독 테스트는 명시적으로 선택한 월드 시험만 전환하며 주간 시험으로 바꾸면 일반 보드로 복원합니다. 개인/크루 성공 기록은 보존합니다. 다음 시즌·새 공통 시험 데이터는 별도 범위로 처리합니다. 월드 종료 시 원래 시설 간판을 복원합니다.

**현재 구현 범위:** 월드 간판·표시 프로필과 1회 복귀 모달은 이번 로컬 연결 대상입니다. 건물 위치·레벨·기존 경제 writer를 바꾸거나 공연 결과·인기 재화·상금을 이 표시만으로 새 지급하지 않습니다. 실제 공연 조작/정산·월드 일반 성장 효과의 유지/대체·세 보상의 최종 지급표·누적 기여 계수는 후속 연결/비앙카 장부 산정 항목입니다.


**현재 단독 테스트 · 2026-11-10 13:58 KST · 제안**

게임 시뮬레이터 단독 테스트는 상위 메뉴를 주간 페스티벌과 월드 페스티벌로 나눕니다. 폰 하단도 주간·월드로 바로 엽니다. 일반 월드 입구는 개인 출전이며, 크루 출전은 응원 크루의 고정된 크루장 전용 신청 버튼에서만 시작합니다. 크루 화면에는 앨범의 데뷔 준비·앨범 활동·차트·파이널 단계표를 표시하지 않습니다. 주간 신청 뒤에는 레이싱 입장과 주간 진행·레이싱 기록을 바로 볼 수 있습니다. 레이싱 입장은 같은 발매 앨범의 기존 시티 투어 자동차 레이싱으로 연결합니다. 기록은 기본 펼침으로 표시합니다.

단독 테스트에서 월드 메뉴(개인·크루)에 진입하면 현재 주간 신청·버프·자동 연료/레이싱 진행을 새 시험 상태로 초기화합니다. 원본 신청 영수증은 이력으로 보존하고 현재 유효한 신청에서 제외합니다. 다시 주간에 들어오면 앨범 선택·신청부터 시작합니다. 앨범·공통 팀·이미 지급된 공통 재화·월드 신청·크루 투표는 지우지 않습니다. 이전 자동 진행 기록은 다음 실제 보드 저장에서 보관하며 활성 기록과 분리합니다. 이 초기화는 단독 테스트만의 조작이며 실제 운영 일정·게임 일차·일반 연결 플레이의 버프 정책을 바꾸지 않습니다.

자유 테스트에서는 이전 앨범의24시간 차트가 진행 중이어도 새 앨범을 먼저 발매할 수 있습니다. 기존 차트·실적·제작비 결제·발매곡을 보존하고 새 곡의 이벤트 참가는 순서대로 대기합니다. 기존 순차 차트 진입 경로를 사용하며 일반 연결 플레이의 차트 잠금과 운영 수치는 변경하지 않습니다.

주간·월드의 일반 입구는 모두 개인 신청입니다. 내 발매 앨범을 선택하고 같은 화면에서 신청하며, 월드는 성공 뒤 내 출전곡 참여 로비를 엽니다. 개인/크루 선택·선택되지 않은 곡 확인·별도 준비 단계를 두지 않습니다. 크루 소속·직책과 관계없이 크루장과 멤버도 개인 월드에 출전할 수 있습니다.

크루 월드 신청은 크루 페이지에서 크루장에게만 켭니다. 현재 멤버가 공유된 발매곡 한 곡에 내부 투표합니다. 한 번 투표하면 바꾸거나 취소할 수 없습니다. 투표 결과는 참고용이며, 크루장이 득표와 무관하게 최종 공유곡·원소유자 사용 동의를 확인해 신청합니다. 원소유자는 일반 크루원이어도 크루 페이지에서 자기 곡의 회차 사용 동의·철회를 할 수 있습니다. 내부 곡 투표는 관객의 공식 페스티벌 투표·점수·재화와 별개입니다. 개인 출전과 크루 출전을 서로 잠그지 않습니다.

주간 버프는 신청한 경우에만 해당 주의7일째부터 공통 주간 마감까지 적용합니다. 7일째 중간에 신청하면 신청 이후 남은 기간만 받습니다. 신청일부터24시간을 새로 주지 않으며, 신청 전 활동을 소급하지 않습니다. 미신청·다음 주·월드 기간에는 주간 버프가 없습니다. 다음 주에는 새로 신청합니다. 게임 시뮬레이터의 표시는 현재 게임 일차·실제 굴림 시계를 사용하며 실제 서버 시계와 구분합니다.

## UI 기획 · 개별 화면 시험과 연동 제작 계획

앨범·공연·음악 앱·페스티벌은 각각 열어 시험할 수 있는 모듈로 만듭니다. 연동에서는 같은 팀·곡·공연·대회 정보를 사용하고 각 모듈의 진행 결과를 공유합니다. 감상 입구는 음악 앱에 모으며, 제작·활동·신청 UI를 하나의 거대한 화면으로 합치지 않습니다.

### 주간·월드의 별도 UI

주간·월드 신청 UI는 별도로 제작합니다. 실제 플레이는 현재 주간 기간이면 주간만, 월드 기간이면 월드만 신청할 수 있게 표시합니다. 시뮬레이터의 개별 시험 입구에서는 두 화면을 각각 열어 해당 기간·미개막 상태를 시험합니다. 월드는 시즌 피날레용 무대·포스터·색/빛 연출과 출전 방법·참여 경험·시즌 기록 안내를 강화합니다. 내 출전곡 소개·시즌 순위 경쟁은 기존 흐름을 사용하고, 베스트 컷·발견 노출·시즌 회고 혜택은 기존 후속 기획으로 구분합니다. 추가 보상 종류·수량·인기 경제는 결정/비앙카 장부 산정 항목입니다.

### 메뉴별 시험 시작점

앨범 발매 상위 메뉴의 기본 진입은 음원 제작입니다. 새 공통 테스트에서는 음원 제작 전 음악 선택 화면으로 시작하고 자동 시험 발매를 실행하지 않습니다. 작성 중인 초안은 이어가고 기존 발매곡은 보존합니다. 시티 투어는 제작·발매된 곡과 필요한 리그를 준비한 뒤 차량 선택·급유로 바로 시험합니다. 곡이 필요한 하위 콘텐츠의 준비와 제작 메뉴의 미제작 출발을 구분합니다.

| 페스티벌 모듈 | 주간:앨범 선택/개인 신청/상단 버프 · 월드:대회/신청/활동 로비 | 주간 개인·내 앨범/버프, 월드 개인/크루·권한·기간·성공/실패 단독 확인 | 현재 발매곡·권한·동의·성공 entry를 기존 명령으로 재검증 |

| 곡 | 같은 albumId/trackRef·발매 상태·고정 참여자·재킷/매체 출처 |
| 공연 | performanceId·활동 원인·장소/채널·공연 상태·시작/종료·매체/권한 공급. 신규 필드명/저장 형식은 U1에서 기존 계약과 대조 |

| 복귀·재생 | 진입 출처·선택 곡/공연·목록 위치·플레이어/큐. 감상 이동과 게임 진행/지급을 분리 |

### UI 흐름에 따른 제작 순서

| 단계 | 제작 범위 | 완료를 판단할 기준 |
| --- | --- | --- |
| U0 · 이번 UI 기획 | 7개 화면·개별/연동 시안·상태표·핵심제안 정리 | 이 단계는 화면 검토용. 실제 발매/공연/공식 표 완료와 구분 |
| U1 · 공통 연결 준비 | 팀/곡/공연/회차·출처·복귀 계약과 화면별 시험 입력 adapter | 모든 화면에 직접 진입 가능. 같은 데이터와 결과 공유, 새 원장/메뉴별 저장 복제 없음 |
| U2 · 앨범 UI 정리 | 기존 제작·재킷·발매·앨범 차트/활동 입구 재사용 | 초안 복귀·중복 결제/발매 방지·시험곡 준비·발란스 수신 보존 확인 |
| U3 · 공연 UI와 공급 연결 | 장소 도착 활동→공연 상태/PIP→음악 앱의 같은 공연 | 처음은 시험 공급자로 단독 확인, 실제 사건 공급자는 별도 연결. 공연 ID별 한 번, 인터뷰 자동 환산 없음 |
| U4 · 음악 앱 관람 정리 | 같은 곡 상세·공연 목록/관람·숏츠·공통 재생기 | 실제 공연 없음/연결 중/종료/권한 없음 구분. 같은 곡·위치·큐·원래 화면 복귀 |
| U5 · 페스티벌 연결 | 기존 대회/신청/로비 UI→같은 회차 음악 앱 | 권한·동의·중복·미개막·집계 전·같은 출전곡 복귀. 인기/공식 투표 공급은 정책 준비 후 |
| U6 · 개별·연동 검수 | 각 모듈 직접 진입 검수 후 전체 선택 흐름·재접속·초기화 | 화면/정산/서버를 분리 보고. 미연결은 시안/대기, 시험 원본을 공식 결과로 승격하지 않음 |

### 개별·연동 검수 계획

| 시험 | 진입 순서 | 확인할 결과 |
| --- | --- | --- |
| 개별 진입 | 앨범·공연·음악 앱·페스티벌 어디든 바로 열기 | 이전 메뉴 완료 요구 없음. 누락된 시험 준비만 1회 수행, 초안 보존 |
| 앨범↔보드 | 발매곡의 활동 입구→보드→곡 차트 | 같은 팀·곡·기존 활동/START 영수증. 왕복으로 새 발매/지급 없음 |
| 보드↔공연 | 해당 장소의 실제 공연 시작→PIP→확인→관람→복귀 | 같은 공연 ID·채널·곡·종료 상태. 취소는 이동만 취소, PIP 닫기는 공연 취소 아님 |
| 대회↔음악 앱 | 신청 성공→활동 로비→확인→같은 회차 차트→복귀 | 같은 round/entry·개인/크루·곡. 조회/재생이 투표 제출이 아님 |
| 누락·오류 | 곡 없음·사용자 초안·공연 없음·미개막·동의 없음·원본 연결 대기 | 없는 원본은 대기/빈 화면. 다른 공연·곡·회차로 대신 채우지 않음 |
| 공유·복원 | 발란스 가져오기→여러 메뉴 조작→재접속→전체 초기화 | 가져온 데이터/결과 공통 유지·시험 재화 무제한. 초기화 전 새 수신/메뉴 진입이 덮어쓰지 않음 |

시험 조작·상태 선택은 오른쪽/외부 검수 패널에 둡니다. 모바일 본문에는 현재 행동·대상·비용/실패 사유를 먼저 보입니다. 다른 콘텐츠 이동은 모바일 내부 확인을 거치며, 같은 음악 앱의 곡/공연 상세 이동은 직접 처리합니다. 페스티벌 점수 설정·투표 시험·월드 인기·우승은 기존의 접힌 보조 도구 안에 함께 둡니다. 음악 앱의 하위 메뉴는 음원·공연·숏츠이며 같은 음악 앱 안에서 각각 시험합니다.

### 화면마다 무엇을 누르나요

| 화면 | 보여 줄 흐름 | 주동작·다음/복귀 |
| --- | --- | --- |
| 앨범 준비 | 현재 팀·음악·참여 옵션 → 재킷·제작 조건 | 제작 완료 → 앨범 발매 · 이전으로 가면 같은 초안 유지 |

| 페스티벌 활동 로비 | 내 등록곡·현재 회차·순위 또는 집계 전 | 순위·다른 곡 듣기 → 같은 회차 음악 앱 / 대회 보기 → 대회 선택 |

### 같은 곡으로 연결할 기준

| 기준 | UI·데이터 관계 |
| --- | --- |
| 같은 곡 | 앨범 ID·곡 참조·고정 참여자를 유지합니다. 실제 곡에 공연이 없으면 연결 없음으로 표시하고 다른 시안 공연으로 채우지 않습니다. |
| 같은 공연 | 장소/채널·공연 ID·시작/종료·매체/공연 상태를 함께 연결하는 기획입니다. 인터뷰만 한 사건은 노래 공연으로 자동 환산하지 않습니다. |
| 같은 대회 | 대회 유형·회차·개인/크루·출전곡 ID를 보존합니다. 일반 곡 감상에 임의 대회/투표 대상을 붙이지 않습니다. |
| 세 차트 | 일반 차트·주간 차트·월드 차트를 각각 표시합니다. 일반은 앨범 활동·팬 중심이고 주간/월드는 해당 대회에 접수된 곡의 평가입니다. 주간과 월드의 기간·기록·재화는 구분하며 앨범 등수나 이전 주간 점수를 월드 점수로 옮기지 않습니다. |
| 시험 도구 | 페스티벌 점수 설정·투표 시험·월드 인기·우승은 기존 보조 도구 안에 함께 둡니다. 이용자의 감상·허용 반응/투표는 음악 앱에 연결합니다. 음원·공연·숏츠는 음악 앱의 하위 메뉴이며 별도 검수 그룹을 만들지 않습니다. |
| 시뮬레이터 이동 | 모든 메뉴는 같은 팀·수신 데이터·결과를 공유합니다. 자동 콘텐츠 이동을 멈추고 다른 콘텐츠로 가야 할 때는 모바일 내부 이동 확인을 거칩니다. 음악 앱 안의 곡·공연 전환은 같은 앱의 상세 이동입니다. |
| 시험 시작·초기화 | 발란스 수신 데이터는 전체 초기화 전까지 보존하며 재화 무제한은 시험 환경에 적용합니다. 발매곡이 없으면 기존 시험곡을 준비하고 작성 중인 앨범·기존 발매곡은 보존합니다. 본게임의 제작·발매 조건을 폐지하는 정책이 아닙니다. |

### 공연은 어디까지 만들어졌나요

| 범위 | 현재 구분 |
| --- | --- |
| 앨범 제작·발매 / 음악 앱 연결 | 로컬 구현. 실제 AI 제작·외부 음원 유통과 구분 |

| 실제 장소 도착 → 공연 생성 → 내 PIP·공연 목록 공급 | 현재 개발되지 않음, 진행 중. 시안 연결만으로 구현 완료로 표시하지 않음 |

## 먼저 보기 · 인기 재화로 출전곡을 키워 월드 우승에 도전

**개인이나 크루가 인기 재화를 모아 출전곡에 기여하고, 그 곡의 인기 등급과 우승 점수를 올립니다.**

개발됨(로컬 통합 화면). 음악 앱 메인의 음원·공연·숏츠 카드 3개와 연결된 차트 입구에서 시작합니다. 음원 안에서 같은 곡의 공연과 별도 숏츠 발견으로 이어집니다. 실제 발매곡·재생·BGM·허용 반응/투표는 기존 음악 원장과 컨트롤러를 사용합니다. 스테이지·숏츠·관계·접속 규모는 로컬 시안이며 실제 게시·추천·방송 서버는 현재 개발되지 않음, 진행 중입니다. 인기 사용 영수증과 기여 차트는 음악 앱의 별도 범위 자유 시험에 연결했습니다. 실제 획득 공급·유한 지갑·등급/우승 비중은 운영/비앙카 장부 산정 항목이며 별도 비교 도구의 예시값을 운영 정책으로 쓰지 않습니다.

```mermaid
flowchart LR
 A["개인·크루의 활동"] --> B["인기 재화 모으기"]
 B --> C["응원할 월드 출전곡에 사용"]
 C --> D["곡에 인정된 인기 기여"]
 D --> E["곡의 인기 등급·우승 점수"]
 F["다른 사람의 추천·찜"] --> G["보조 평가"]
 G --> E
 E --> H["같은 회차 순위 → 마감 결과"]
 D -. "별도 정보" .-> I["급등·발견 차트"]
```

| 왜 지금 | 이게 핵심 | 이게 아닌 것 |
|---|---|---|
| 듣는 화면과 실제 음악 앱의 기능·점수 설명이 달랐습니다 | 인기 재화 획득 → 곡에 사용 → 인기 등급과 점수 → 우승 경쟁 | 재화 보유량만으로 우승, 급등 등수를 보너스로 재가산, 시안 순위의 공식 집계 사용 |

| 사용자가 할 일 | 화면에서 바로 볼 것 |
|---|---|
| 인기 재화를 모읍니다 | 보유 인기 재화, 획득할 수 있는 활동과 조건 |
| 개인 또는 크루의 출전곡에 기여합니다 | 대상 곡·회차, 사용할 양과 인정되는 기여, 사용 확인 |
| 출전곡의 등급을 올립니다 | 곡의 현재 인기 등급, 다음 등급까지 남은 조건, 누적 인정 인기 |
| 다른 사람이 곡을 추천·찜합니다 | 보조 평가 수치와 인정 상태. 개인 보관과 평가용 반응 구별 |
| 월드 우승을 노립니다 | 종합 점수·현재 순위·마감 상태, 인기/추천/찜별 반영 근거 |

### 음악 앱 메인과 공연·숏츠 탐색

| 입구 | 보여 주는 내용 | 지킬 관계 |
|---|---|---|
| 음원 홈 · 지금 공연 중 | 공연 중인 무대와 최근 공연 목록 | 보드 공연의 출처 채널을 작은 필터로 구분. 별도 콘텐츠 카드 여섯 개로 나누지 않음 |
| 곡 상세 · 이 곡의 스테이지 | 같은 곡에 연결된 공연 목록 → 선택한 공연 | 다른 곡·샘플로 빈 공연을 채우지 않음. 곡 연결 없는 인터뷰를 특정 곡 공연으로 합치지 않음 |
| 상단 · 숏츠 발견 | 곡 선택과 독립된 공개 후보 | 무작위 발견에 관심사·관계·구독·미시청·반복 제약 적용. 고정 스테이지 명단으로 후보를 제한하지 않음 |
| 관련 숏츠 | 사용자가 고른 곡/공연의 하이라이트 | 독립 추천과 구분하고 원본 ID·권한·뒤로 복귀 유지 |

현재 로컬 시안은 한 번 정한 후보 순서를 유지하고, 새 발견 입장 때 세션에서 재생한 항목을 제외해 섞습니다. 선택 관심사의 창작자 첫 후보·창작자/원공연 연속 회피는 시안 비교용 규칙입니다. 공개 서버 검사·실제 시청 유효 기준·개인화 가중치·혼합 비율은 제작/비앙카 장부 산정 항목이며 이 시안의 순서를 운영 추천 공식으로 사용하지 않습니다. 구독 변경·화면 갱신은 보고 있던 숏츠를 바꾸지 않습니다.

### 현재 통합 음악 앱 · 제안

| 한 입구 | 현재 동작 |
|---|---|
| [음악 앱 실행](/docs/planning/game-simulator.html?module=simulator_module_music_app) | 메인 카드 3개와 내 순위·일반/주간/월드 차트 입구. 음원 안에서 음악/차트/보관함과 같은 플레이어·세션 사용 |
| 음원 | 기존 음악/차트/보관함·전체 플레이어·재생 큐·내 발매곡 강조·BGM. 찜한 출전곡은 보관함에서 투표 확인 후 접수(투표 취소 없음) |
| 차트 구성 | 일반·주간·월드의 현재 자료를 구분. 월드는 종합·인기 기여를 별도 표시하고 추천·찜·급등은 각각의 지표로 유지 |
| 스테이지·숏츠 | 기존 미디어 UI·관련 곡/공연 왕복·관심사/관계 조건 비교. 시안 게시물·인원·순위는 시험 데이터 |
| 실제 기능 보존 | 같은 음악 controller·재생기·source·기존 투표 원장·권한 검사 사용. 인기는 별도 자유 시험 사용 영수증에 기록하며 실제 회원/유한 지갑을 만들지 않음 |
| 오른쪽 입력 | 기존 운영·조건·발란스 시험 설정은 접힌 칸에 보존, 미디어 관계/관람 조건은 별도 시안 조작 |
| [인기·우승 시험](월드인기우승_기획시뮬레이터.html) | 보조 도구에서 별도 실행. 모바일 결과와 오른쪽 입력·현재 연결/단독 시험을 분리 |

실제 발매곡과 라이선스 시험 음원·시안곡은 목록의 출처로 구분합니다. 미공급 인기 집계를 팬·능력·앨범 이벤트 재화로 대체하지 않습니다. 통합 화면 제작은 운영 인기 원장·최종 비중·유효 추천·공개 공유·실제 방송/게시 서버의 완성을 뜻하지 않습니다.

### 통합 앱의 읽는 길

찬스 칸 옆의 음악 앱은 음원·공연·숏츠 카드 3개가 있는 메인에서 시작합니다. [스테이지](공연스테이지_핵심제안서.html)·[숏츠](숏츠_핵심제안서.html)는 음원에서 공연을 관람하거나 새로운 아이돌을 발견하는 이동입니다. 음원에서는 곡 목록·차트·보관함과 기존 공통 플레이어를 사용합니다. 곡 목록은 추천순·인기 급상승순으로 오인시키지 않습니다. 내 실제 발매곡·BGM·페스티벌 이동을 유지합니다.

```mermaid
flowchart TD
 H["음악 앱 메인 · 음원/공연/숏츠 · 현재 차트"] --> A["음원 · 음악/차트/보관함"] --> B["곡 상세"] --> C["이 곡의 스테이지"]
 A --> D["지금 공연 중"] --> E["보드 출처별 공연 목록"]
 A -. "별도 발견 입구" .-> F["숏츠 발견"] --> G["공개·관심사·관계·미시청·반복 조건의 무작위 후보"]
```

차트·필터·화면 이동은 현재 재생곡·큐·재생 위치를 바꾸지 않습니다. 실제 발매곡과 시안/라이선스 샘플은 출처를 구분합니다. 시안곡은 실제 출전곡이나 유효 기여로 바뀌지 않습니다.

### 앨범 판매부터 월드 순위 경쟁까지 · 전체 시퀀스

[제안서 카드의 첫 장](/docs/planning/proposal-concept/fest.html#slide-1)에서 한눈에 봅니다. 앨범 발매·판매 활동은 기존1차 경로이며, 투표/인기/배틀의 새 운영 구조는2차 기획입니다. 앨범 활동의 매출·팬·리그 순위를 월드 유효표나 승점으로 그대로 옮기지 않습니다.

**현재 규칙 한눈에** 한 시즌 63일(9주) 가운데 1~8주는 주간 페스티벌, 9주차는 월드 페스티벌이며 둘은 같이 열리지 않습니다. 세부 규칙은 [전체기획서 08장](../../전체기획서/08_월드페스티벌전투오리지널16_클로드.html) 3장입니다.

| 구분 | 현재 규칙 (전체기획서 08장, 11/13 확정) |
|---|---|
| 1~8주 주간 · 구역 | 친구 먼저 → 빈자리는 비슷한 엔터파워 등급으로 100명 구역(R-08-1) |
| 주간 · 출품 | 음원 단독 출품 불가, 영상이 없으면 아이돌 이미지 자동 컷씬(R-08-2). 창작곡도 출전하며 내부곡과 같은 순위표(R-08-3). 출전 단위는 팀 칸 멤버 전원(R-08-4) |
| 주간 · 보상 | 매주 7일째 START 통과 때 5명 무리 순위대로 돈 500~100 · 팬 20~4 · 능력 0.25~0.05(R-08-6). 100명 구역 등수의 1~8주 합이 월드 순번이며 등수별 가산점은 비어 있음(0으로 동작)(R-08-8) |

| 9주차 월드 · 리그 | 전원 참가, 1~8주 성적 · 가산점 순번대로 1위 리그 · 2위 리그 …, 리그마다 100명 그룹(R-08-14 · 15) |

## 3. 구동 방법·시뮬레이션

### 월드 신청 화면 계약 · 주간은 개인 앨범 신청

| 화면 | 본문 | 기존 공통 버튼 구역 |
|---|---|---|
| 대회 메인 · competition | 월드 개인 전용 앨범 선택·신청, 성공한 내 참여 음악행·접힌 안내 | 선택한 앨범 신청 주동작, 신청 성공 뒤 같은 곡 음악 앱 |
| 참가 신청 · entry | 같은 실행의 적격 released 앨범 1곡 선택·고정 참여자·소유/동의 상태·신청 내용 확인 체크를 **한 화면**에 표시 | 「신청 확인」으로 실제 제출·이전 |
| 활동 로비 · participation | 선택한 대회/주체/entryId의 등록곡·아티스트·크루·포스터, 참여 중·회차 순위·공통 음악행·작은 득표율 | 「순위·다른 곡 듣기」 주동작 + 「대회 보기」 |

월드 개인 입구는 **내 앨범 선택·신청 → 활동 로비**입니다. 선택·신청은 한 화면에서 하고 성공 영수증 뒤 내 곡으로 참여 중인 무대를 보여 줍니다. 크루 신청은 별도의 크루 페이지에서 크루장만 시작합니다.

**화면 우선순위:** 월드 메뉴는 내 앨범 선택 → 개인 신청, 크루 페이지는 공유곡·사용 동의 확인 → 크루장 신청입니다. 주간 메뉴는 내 앨범 선택 → 개인 신청 → 레이싱 입장/진행 기록 순서이며, 기록은 기본 펼침으로 표시합니다. 명시 단독 테스트는 기존 시험곡 준비 경로를 한 번 자동 실행하며 실제 연계 게임의 발매 조건과 크루장 권한은 유지합니다.

크루 신청은 현재 크루장만 선택·확인·제출합니다. 로비에는 재신청·개인/크루 전환·신청 확인 폼을 두지 않습니다. 현재 크루에 공유된 자기 곡의 회차 사용 동의/철회는 기존 권한 검사를 거치는 **기본 접힘 곡 권한 상세**에 남깁니다. 추천·찜·투표 기록도 기본 접힘입니다. 본문 큰 이동 버튼·별도 fixed 앱 바·독립 투표 UI를 중복하지 않습니다.

시작 화면이 지정되지 않았고 현재 실행에 실제 World 참여가 있으면 그 `roundType/roundId/entryMode/entryId`의 로비를 기본으로 엽니다. 명시적인 「대회 보기」 복귀는 유지하며 다른 대회 유형을 신청할 수 있습니다. 메인의 내 참여도 같은 로비로 열고 같은 명의의 중복 신청은 막고 개인·크루 출전은 별도로 유지합니다. 선택한 entry가 유효하지 않으면 다른 참여곡으로 대체하지 않습니다.

순위는 **해당 회차 `round.rankings.overall`에서 같은 entryId의 실제 행**만 표시합니다. 점수·순위가 없으면 `집계 전`이며 앨범 활동 100위·다른 회차 순위·임의 공식 참가자 수를 가져오지 않습니다. 현재 로컬 순위와 득표율은 시험 집계임을 작게 구분합니다. 공통 음악행의 재생 조작은 기존 컨트롤러를 쓰고, 「순위·다른 곡 듣기」는 같은 대회/회차/entry 문맥의 음악 앱을 열며 자동 재생하지 않습니다.

```mermaid
sequenceDiagram
 participant U as 사용자
 participant V as 페스티벌 화면
 participant S as 현재 원본·scope
 participant W as 기존 접수 명령
 U->>V: 대회·개인 또는 크루 선택
 V->>S: 실제 발매곡·권한·참여 잠금 조회
 S-->>V: 적격곡 또는 불가 사유
 U->>V: 공통 신청 버튼·신청(entry) 열기
 opt 명시적 로컬 시험에 필요한 회차 준비
  V->>W: 기존 시험 준비 경로
  W-->>V: 준비 결과
  V->>S: scope·session·run·season·owner·team 재검증
 end

```

회차 준비 전에도 실제 발매곡을 조회할 수 있어야 합니다. 준비 후 범위나 팀이 바뀌면 이전 선택·확인을 무효화합니다. 준비·내용 확인 체크는 접수 성공이 아니며, 실제 영수증의 entryId가 있어야 참여로 표시합니다. 초안·실제 발매 앨범을 자동 생성하지 않습니다.

### 현재 실행을 유지하는 이동

같은 창의 기존 공통 버튼과 오른쪽 시험 도구는 현재 run/session/testPage를 유지합니다. 별도 단독 링크는 다른 시험 범위일 수 있습니다. 내 크루에서 왔다면 crewId·선택 앨범·목록 위치를 보존해 복귀하며, referrer만으로 권한을 인정하지 않습니다.

| 무엇을 하나 | 쉬운 동작 | 어디에 반영되나 |
|---|---|---|
| 팬 투표 | 감상 → 찜 → 보관함에서 출전곡 선택 → 투표 확인 | 팬 평가 A. 앱·웹·SNS 유입은 같은 표 한도 |
| 인기 응원 | 게임으로 인기 재화 모으기 → 응원할 출전곡에 사용 | **게임 인기 C**. SNS 인기도·실제 팬 수와 별개 |
| 곡 선호 배틀 | 배정된 두 곡 듣기 → 하나 선택/건너뛰기 | 승무패·배틀점수 → A의 배틀 항목 |
| 내 무대 | 타이밍·라이브·전략·공연게임 대결 | 검증한 공연 성과 G. 기존 아이돌 실력은 B |
| 외부 음악 성적 | 멜론 등 허용된 자료의 같은 곡·기간 확인 | 제휴·권한·전 후보 공급을 갖춘 경우만 A의 별도 항목 |

flowchart LR

**단이 의견:** 특정 시각에만 몰아서 투표하기보다 월드 기간의 상시 투표와 비동기 곡 대결을 기본으로 두고, 집중 시간은 함께 듣는 연출로 쓰는 안입니다. 정확한 표수·배점·시각은 확정하지 않았습니다. MAMA는 부문·연도별 공식 구조를 참고하고 서로 다른 부문의 배점/조회 방식을 섞지 않습니다.

#### 개인·크루를 나눠 볼 수 있는 차트

```mermaid
flowchart TD
 W["월드 음악 차트"] --> F["전체 | 개인 출전자 | 크루 출전자"]
 F --> T["종합 | 팬 투표 | 인기 | 곡 배틀 | 콘텐츠 | 더보기"]
 T --> L["한 줄 곡 목록·순위 변동·재생"]
 L --> P["공통 영상 플레이어·미니플레이어"]
 L --> D["펼치기: 내 기여·점수 근거·갱신 시각"]
```

개인 출전자는 **개인 유저 명의의 출전**이며 팀·유닛곡도 가능합니다. 가입한 크루가 있어도 개인으로 신청한 곡은 개인 차트에 나옵니다. 각 차트의 인정 점수가 최종에 연결되며 등수를 보너스로 다시 더하지 않습니다. 필터·자동 순위 갱신은 재생곡·큐·위치를 바꾸지 않습니다.

#### 개인에게도 할 일과 혜택

| 콘텐츠 묶음 · 전부 기획안 | 고를 수 있는 재미 | 반영·혜택 |
|---|---|---|
| 공통 4종 | 공연게임 대결·스테이지 타이밍·관객 호응 리듬·콘셉트 카드 | G 성과 또는 인기 획득→지정곡 사용→C |
| 개인 특화 6종 | 내 팀 원테이크·댄스 브레이크·팬콜/인터뷰·팬캠 디렉팅·세트리스트·시티 앙코르 | 혼자 고르는 무대/인기 경로, 내 팀 기록·베스트 컷·개인 발견 슬롯 |
| 크루 특화 2종 | 파트 응원 릴레이·현장 응원 큐 퍼즐 | 협동 방식의 재미. 개인보다 높은 점수 상한·추가 표는 없음 |

모든 종목을 매일 다 해야 하는 구조보다, 같은 공식 점수 슬롯에서 취향에 맞는 대안을 고르는 안입니다. 개인도 같은 최고점에 접근할 수 있게 설계하고 실제 시간·무료 기회·매칭 대기를 함께 검수합니다. 크루 미션의 보상은 계속 **크루 재화 한 종류**입니다. 새 인기 재화는 별도 경제 제안이고 원표에 등록하지 않았습니다.

### 음악 앱·플레이어

홈/탐색/차트/보관함 메뉴 바로 위에 공통 미니플레이어를 둡니다. 미니·전체·대기열·앨범 미리보기는 기존 music controller와 플레이어를 재사용합니다. 차트 조회·정렬·자동 갱신은 현재 곡·위치·큐를 바꾸지 않습니다.

| 조작/상태 | 계약 |
|---|---|
| 곡 제목 / 행 재생 | 제목은 정보, 재생은 명시적 재생 명령 |
| 전체 / 짧게 / 셔플 / 숏츠 | 작은 한 줄 도구 모음. 짧게는 실제 preview 구간, 셔플은 명시 범위의 균등 순열 |
| 대기열 / 저장 목록 | 지금 듣는 순서와 저장한 곡 묶음은 별도. 같은 곡도 queueItemId로 구분 |
| 숏츠 | 세로 전체 화면, 위로 다음·아래로 이전, 영상 위 고정 대상 메뉴·키보드 대체 조작 |
| 댓글·공유·제작자 | 곡/후보 대상을 고정하고 같은 문맥으로 복귀. 제작자 계정과 참여 아이돌은 별도 |
| 재생 오류·자동재생 차단 | 실제 상태로 표시. 음원 없는 행에 가짜 시간·완청·표를 만들지 않음 |

```mermaid
flowchart TD
 T["발매 trackRef"] --> P["기존 PlaybackSession·queueItemId"]
 T --> E["회차 entryRef"]
 E --> C["ChartQuery·Snapshot·asOf"]
 C --> V["한 줄 차트"]
 V -. "명시 재생만" .-> P
 P --> M["미니·전체·대기열 같은 상태"]
 P --> S["숏츠 일시 초점·기존 큐 보존"]
 S --> O["고정 대상 댓글·공유·제작자"]
```

차트 원본은 **앨범 활동 / 주간 / 월드**입니다. 기존1차 주간·월드 시험은 종합/급등/추천/찜/실력/게임/응원 7종입니다.2차 월드의 팬 투표·게임 인기·곡 배틀·콘텐츠 및 개인/크루 필터는 위 기획안의 확장입니다. 앨범 활동은 기존 팬·보드 리그이며 유저 투표가 없습니다. 실제 매체가 있는 발매곡만 재생하고 가상 상대를 실제 음원 후보로 바꾸지 않습니다.

### 대회·평가·월드 공연

| 항목 | 현재 기획 기준 | 남은 결정 |
|---|---|---|
| 주간 | 실제 Asia/Seoul 매주 일요일 | 접수·마감 세부 시각 |
| 월드 | 운영 시즌 9주차, 기간 7일 | 공통 시즌 시작일·단계별 시각 |
| 출전 | 개인/크루 발매곡 1곡, 크루장·원소유자 회차 동의 | 수정·늦은 접수·탈퇴/철회 정책 |
| 평가 | 팬 평가 A / 고정 참여자 능력 B / 실제 무대 게임 G / 2차 게임 인기응원 C 분리 | 정규화·가중치·상한·동점·보상 모두 비앙카 장부 산정 항목 |
| 월드 본공연 | 같은 40칸의 기간/역할 프로필, 등록곡 주인공의 마지막 스퍼트 | 본공연 어댑터·기존 경제/성장 보존 정책 제작전 |

사람의 기본 표를 계정 등급·결제·NPC 팬 수로 증폭하지 않는 방향입니다. 같은 능력을 B/G 양쪽에 더하거나 공유·댓글·재화 소비를 표로 바꾸지 않습니다. 월드 미개막은 공식 접수·투표를 막고 일반 감상은 허용합니다. 주간/월드 병행·주간 점수 이월 없음 등 운영 비어 있음안과 40칸 매핑은 [P191 상세](../../기획서/산출_기획서_음원×페스티벌_v1_클로드.html#festival-world-plan)에 보존합니다.

음원이 없는 곡은 정보만 표시합니다. 영상 파일 참조가 공급되면 같은 플레이어에서 사용하며 별도 엔진을 만들지 않습니다. [자산 manifest](/assets/music-career/video-preview/manifest.json)에 이미지·음원·참조 원본을 구별합니다. 기존 케이팝 UI의 보라 톤을 잇고 외부 서비스 로고·실제 차트 수치를 복제하지 않습니다.

큰 소개·반복 설명은 줄이고 규칙 상세는 기본 접힘으로 둡니다. 기획서 로딩 상태는 헤더 안에 작게 표시한 뒤 콘텐츠 준비 시 제거하며, 지연 상태는 닫기/재시도를 제공합니다.

3. 실제 released 곡만 선택하고, 준비 후 범위 변경·동의 철회·역할 변경·중복을 재검증합니다. 성공 영수증 entryId로만 참여 화면을 엽니다.
4. 선택된 로비는 해당 entry의 실제 곡·아티스트·크루·포스터·현재 회차 순위만 표시하며 재신청 폼이 없습니다. World 기본 진입과 명시 대회 복귀를 구분합니다. 공통 음악행·작은 득표율·접힌 기록/자기 곡 권한 상세는 같은 대상을 가리킵니다. 순위가 없으면 집계 전이며 앨범 활동 순위를 대입하지 않습니다.

6. 샘플·정지 이미지·로컬 principal·예시 표를 실제 발매·동영상 생성·실계정 인증·공식 집계로 표시하지 않습니다.
7. unknown은 0으로 만들지 않고, 득표율 0/0·급등 0분모는 집계 전/신규로 표시합니다. UI 파생 상태만으로 저장 키·스키마·로그가 늘지 않습니다.

득표율은 해당 곡의 회차 유효표 ÷ 같은 회차 전체 유효표이며, 투표 참여율·종합점수와 다릅니다. 봇·샘플·제외표는 집계하지 않고 0/0은 null입니다. 상세 재생/투표·마감·40칸 수락 조건은 [P191](../../기획서/산출_기획서_음원×페스티벌_v1_클로드.html#festival-validation)에서 이어 봅니다.
