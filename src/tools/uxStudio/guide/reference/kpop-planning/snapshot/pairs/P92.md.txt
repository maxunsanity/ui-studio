# P92 · 필러 룰렛 · 사용 CSV

상태:

## 개요

필러 룰렛의 신규 CSV 5개와 기존 도착 기반·공용 시뮬레이터 관련 CSV 19개, 총 24개를 나열합니다. 실제 실행에서 읽는 표와 기획 참고를 구분합니다. 전체 등록 표는 P73에서 확인합니다.

기존 제안의 시작 예시 15/50/35를 weighted_preview에 사용합니다. 확정 게임 확률이 아닙니다. 보상은 시안 코인(sample_coin) 임시값이며 본게임 경제와 분리합니다. 빈 대사·미정값은 채우지 않습니다.

## 표 사이의 연결

outcome.csv의 filler_reward_id는 reward.csv의 filler_reward_id를 참조합니다. filler_resource_sample_coin은 시안 전용 코드이며 본게임 resource.csv의 외래키가 아닙니다. 대상 칸은 공용 board_tile.csv의 hit_roulette=1을 읽습니다.

config.csv는 시안 저장을 `p58:board-filler-proto:v01`에 기록합니다. 해당 저장이 없는 최초 실행에서 기존 `p58:board-proto:v01`을 읽기 전용으로 한 번 복제하고, 기존 저장키의 내용은 유지합니다. 본게임 데이터는 변경하지 않습니다.

## 등록과 보존

planning_csv_table.csv는 원본 파일을 한 번 등록하고 planning_csv_usage.csv는 기획별 사용 관계를 연결합니다. 신규 룰렛 결과표를 먼저 열며 기존 19개 관계도 유지합니다. 이전 CSV별_v01·CSV별_v02와 콘텐츠별_v03/P72 설명을 보존합니다.

## 구현 확인 범위

등록 키·실제 파일·주키·외래키·기획 링크를 확인합니다. 플레이 테스트와 연출 체감 검수는 현중이 진행합니다. 확정 확률·실제 보상·본게임 재화 연결은 이번 시안의 범위가 아닙니다.
