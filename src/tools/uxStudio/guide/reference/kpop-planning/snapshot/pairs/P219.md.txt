# P219 · 새 도시 진출 · 대표 개발 기획서

**본진에서 성장한 뒤 다른 지역을 열고 방문 보드에서 활동하고 귀환하는 콘텐츠입니다.**

**현재 상태:** 지역 방문 비교 시안과 기존 지역 원본이 있습니다. 실제 지역 방문·입장권·현지 팬·귀환 원장 연결은 제작 전입니다. [시티 투어 레이싱](시티투어_핵심제안서.html)은 독립 기획서로 관리합니다.

## 1. 개요

본진 성장 → 지역 조건 확인 → 입장권 사용 → 현지 방문·활동 → 정산·귀환으로 이어집니다. 레이싱 참가를 실제 도시 방문 완료로 기록하지 않습니다.

## 2. 필요 관련 시스템 기획서

| 문서 | 역할 |
|---|---|
| [P193 · 새 도시 진출 상세](../../기획서/산출_기획서_새도시진출_보완판_v1_클로드.html) | 지역·방문·정산·귀환 계약 |
| [기존 방문 기획 P109](새도시진출_기획서.html) | 기존 시즌 방문 계산과 비교 시안 |
| [성장·관계](성장관계_기획서.html) · [팀 스탯](팀결성_팀스탯_기획서.html) | 지역 열림 조건의 원본 |
| [앨범 발매](앨범발매_기획서.html) | 방문 중 곡 활동/지역 성적의 연결 대상 |
| [P231 · 시티 투어](시티투어_핵심제안서.html) | 앨범 재화·멤버 능력으로 달리는 독립 레이싱 |

## 3. 구동 방법·시뮬레이션

기존 방문 비교 시안은 [P109](새도시진출_기획서.html)와 하단 비교 자료에서 확인합니다. 시험 입장권·팬·정산은 실제 계정 원장과 구분합니다. 운영 지역 방문 모듈의 실제 저장/귀환 연결은 제작 전입니다.

앨범에서 참가하는 레이싱은 [시티 투어 기획서](시티투어_핵심제안서.html)와 [공용 게임 시뮬레이터](/docs/planning/game-simulator.html?module=simulator_module_music_city)로 연결합니다.

## 4. 상세 기획

| 구분 | 규칙/구현 범위 |
|---|---|
| 본진 | 기존 도시·시설·성장 원본 사용 |
| 지역 | 기존 영어권·중국어권·일본어권 지역 원본, 대표 도시 이름은 세계관 기획 대상 |
| 열림 | 기존 개인·팀·외국어 조건 참조. 미정 문턱을 충족으로 처리하지 않음 |
| 입장 | 입장권·방문 분량을 지역 방문 규칙으로 판정 |
| 현지 활동 | 지역별 활동·팬·곡 성적을 구분 |
| 귀환 | 완료/중도 귀환과 정산·수령의 중복 방지 필요 |
| 시티 투어 | 별도 앨범 레이싱 원장. 레이싱 급유 재화를 지역 방문 입장권으로 바꾸지 않음 |

방문 중 본진 진행과 크루 소속의 유지 범위, 시즌 초기화와 지역 기록의 보존 범위는 기존 시즌/도시 원본과 맞춰 연결합니다. 지역 조건·입장권 수량·방문 보상은 확정 원표와 연결하기 전 임의 값으로 운영하지 않습니다.

## 5. 필요 리소스·이미지 설명

| 리소스 | 사용 |
|---|---|
| 지역 지도·잠금/열림 표시 | 방문할 지역과 조건 확인 |
| 지역 방문 보드·현지 무대 | 현지 활동 |
| 현지 성적·정산·귀환 화면 | 방문 결과와 본진 복귀 |

기존 방문 비교 시안은 실제 운영 화면과 구분합니다. 자동차·차고·고가도로·레이싱 시상 UI는 [시티 투어](시티투어_핵심제안서.html#part-5)에 둡니다.

## 6. 관련 CSV·테이블 데이터

| 원본 | 역할 |
|---|---|

| 지역 방문/현지 팬/귀환 원장 | 운영 연결 제작 전 |

기존 원표와 방문 비교 계산을 참조하며 레이싱의 앨범 이벤트 재화/수령 원장과 합치지 않습니다.

## 7. 개발 진행·검수

| 항목 | 현재 상태 |
|---|---|
| 기존 지역/방문 비교 시안 | 기존 자료 참조, 실제 방문 원장과 구분 |
| 지역 조건·입장권·방문·귀환 | 운영 데이터/저장 연결 제작 전 |
| 현지 팬·곡 성적·정산 | 지역별 원장과 중복/복구 계약 구현 필요 |
| 앨범 레이싱 | P231·P232의 독립 시티 투어 기획/실행으로 연결 |
| 실제 브라우저/플레이 | 사용자 확인. 이번 문서 분리에서는 실행하지 않음 |
