# P118 · 오디션 히스토리 · 이전 기획(10/07 판)

히스토리입니다. 10/12 규격 정리 때 대표 기획서에서 옮긴 **이전 기획**입니다. 지금 기준은 [대표 기획서](/docs/planning/planning-docs-tool.html?face=development&doc=P100&plan=planning_development_plan_audition)입니다. 지우지 않고 보존합니다.

## (이전) 1. 개요


오디션은 게임에 들어오자마자 보는 첫 콘텐츠입니다. 랜덤으로 나온 후보 카드를 **둘씩 비교해 하나를 고르는 이상형 월드컵**으로 결승까지 줄여 가고, 끝까지 남은 한 장이 이번 시즌의 주인공 **연습생**이 됩니다. 마음에 들지 않으면 월드컵 한 판 전체를 다시 돌릴 수 있고 최대 3판까지입니다. 확정하면 계약 도장이 찍히며 그대로 [P96 몬스](/docs/planning/planning-docs-tool.html?face=development&doc=P96&plan=planning_development_plan_audition#mons-cutscene) 획득 컷씬으로 이어져 짝 몬스가 깨어납니다. 한 명으로 사옥에서 시작하고, 사옥이 커질 때마다 둘 중 하나를 고르는 짧은 오디션으로 멤버를 늘립니다(멤버 수 = 그룹 인원).

### 콘텐츠 경계

오디션 진입 · 후보 뽑기 · 2택 진행 · 남은 판(다시 돌리기) · 마지막 한 장 확정 연출 · 계약 확정 저장 · 사옥 짧은 오디션 · 교체 요청 접수를 담당합니다. 몬스 탄생은 P96, 카드 능력과 특기는 카드 기획, 사옥 증축은 보드 건물(P81), 오디션 칸은 없습니다(현중 10/02 16:53).

### 현재 기준과 목표

현재 기획 단계이며 게임 구현은 없습니다. 화면 기준은 제안서 [오디션 덱](/docs/planning/proposal-concept/audition.html)(이상형 월드컵 · 끝까지 남은 한 장 · 기회 3번 = 판 전체 다시 · 특기 라벨 · 한 명 시작 · 사옥에서 추가)이며, 현중 10/07 16:40 「오디션은 제안서처럼」을 따릅니다. 후보 수 · 다시 돌리기 비용은 **결정 대기**입니다.

현재 제외합니다

심사 점수 · 포지션 밀당 · 숨은 특징 맞히기 · 무대 두 번 · 오디션 주사위 · 순위(10/02 15:55 회의 결정)는 쓰지 않습니다. 후보 「16명 · 16장」 숫자는 10/04 결정으로 화면에 쓰지 않습니다.
- 게임 시작
- 후보 카드 뽑기
- 둘 중 하나 고르기 반복
- 결승
- 마지막 한 장 확정 연출
- 확정 / 판 다시(최대 3판)
- 계약 → [몬스 획득 컷씬(P96)](/docs/planning/planning-docs-tool.html?face=development&doc=P96&plan=planning_development_plan_audition#mons-cutscene)
- 사옥에서 시작

## (이전) 3. 구동 방법·시뮬레이션


게임용 오디션 모듈은 **미구현**입니다. 제안서 덱의 월드컵 화면 시연이 화면 참고입니다. 개발 순서는 2택 진행기(후보 뽑기 → 대진 → 결승) → 남은 판 → 확정 연출 → P96 컷씬 연결 → 사옥 짧은 오디션입니다.

미구현 · 오디션 모듈은 아직 공용 시뮬레이터에 등록되지 않았습니다.

[제안서 오디션 덱을 새 창으로 엽니다](/docs/planning/proposal-concept/audition.html) · [공용 시뮬레이터를 엽니다](/docs/planning/planning-docs-tool.html?face=development&doc=P94&plan=planning_development_plan_simulator)

등록 예정 키는 simulator_module_audition입니다.

관찰 순서 · 구현 후 검수

첫 실행 때 오디션이 바로 열리는지 → 두 카드가 겹치지 않고 특기 라벨이 보이는지 → 한쪽을 누르면 진 카드가 날아가고 다음 대진이 오는지 → 판 진행 점과 남은 판 램프가 맞는지 → 결승 뒤 마지막 한 장 연출이 나오는지 → 「판 다시」가 3판에서 멈추는지 → 확정 확인창이 실수를 막는지 → 확정하면 P96 컷씬 1(계약 도장)로 끊김 없이 이어지는지 → 사옥에서 시작하는지 → 사옥이 커질 때 짧은 오디션이 열리는지 확인합니다.
