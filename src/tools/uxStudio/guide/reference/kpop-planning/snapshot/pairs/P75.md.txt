# P75 · 핵심제안 시스템 개발 · 전체 안내

상태: 최신 아이돌 성장 v02 기준 전체 정리 · 2026년 10월 15일

**오디션에서 영입한 팀을 성장시키고, 성장한 팀과 시설을 건설·방어 시험에서 확인합니다.** 대표 기획서·제안 카드·시뮬레이터가 같은 현재 기준을 안내하도록 정리했습니다. 이벤트 게임은 이번 정리 대상에서 제외합니다.

## 1. 시작할 화면

[게임 시뮬레이터](/docs/planning/game-simulator.html)는 아이돌 성장으로 시작합니다. 주요 메뉴는 아이돌 성장 → 오디션 → 주사위 → 건설·증설 → 나쁜 기운 디펜스입니다. 옛 보드 설명·필러·몬스 애니메이션·리소스·기존 방어전은 **보조 도구·기존 테스트**에 접어서 둡니다. 기존 링크와 모듈 ID는 유지합니다.

## 2. 현재 대표 기획과 실행

|---|---|---|

## 3. 데이터 기준

성장 규칙은 `data/idol_ability_sim/v02/`, 오디션 생성은 `data/audition_sim/v01/`, 방어 규칙은 `data/bad_energy/v06/`를 각 영역의 기준으로 사용합니다. 연결은 `data/simulator/shared/v01/` 계약을 거칩니다. 같은 이름이라는 이유로 서로 다른 단위의 숫자를 합치지 않습니다.

성장이 쓰는 상태를 건설·방어는 복사해서 읽습니다. 3D 건설 시험값·전투 피해·전투 보상은 성장 경제에 되쓰지 않습니다. 기존 60일 경제 실험은 비교 자료이며 최신 성장의 대체 실행 경로가 아닙니다.

## 4. 제안 카드 읽는 법

[아이돌](/docs/planning/proposal-concept/idol.html), [오디션](/docs/planning/proposal-concept/audition.html), [건물 성장](/docs/planning/proposal-concept/growth.html), [악귀와 몬스](/docs/planning/proposal-concept/bad-data.html), [몬스 스킬](/docs/planning/proposal-concept/mons-skill.html) 카드에 현재 구현·실행 링크를 보완했습니다. 카드의 콘셉트 그림과 실제 플레이 화면은 구분하며, 구형 설명용 수치를 실행 데이터로 사용하지 않습니다.

## 5. 전체 정리 원칙

대표 기획서의 앞부분에는 현재 실행 기준을 둡니다. 이전 상세 설계·작업 로그는 접힌 기록으로 보존하고, 공용 보고와 증거는 삭제하지 않습니다. 중복되는 성장 메뉴와 오래된 「시뮬 없음」 설명을 최신 메뉴로 모읍니다.

## 6. 아직 별도인 영역

출연권 대전·게릴라 공연·새 도시 진출·시즌·운영 경제는 각 기획서의 개발 상태를 유지합니다. 이벤트 게임도 기존 항목·데이터·코드를 유지합니다. 이번 연결은 전체 게임 완성이나 계정 서버 연동을 뜻하지 않습니다.

4. 숫자는 60일 시뮬(이식 경제 · [발란스 툴](/docs/planning/balance-tool.html))이 기준이고, 디펜스 · 오디션처럼 자기 시뮬이 있는 콘텐츠는 그 시뮬 값이 기준입니다.
