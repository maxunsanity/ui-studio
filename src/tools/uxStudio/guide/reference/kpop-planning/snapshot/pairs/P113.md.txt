# 나쁜 기운 디펜스 통합 개발 기획서 v03 (신규)

작성자는 codex(단이)입니다. P113 · 핵심제안 시스템 개발에 등록합니다. 상태는 **구현 반영 · 제안(현중 플레이 검수 대기)**입니다. 현중의 “그럼 진행을 해봐..문서까지 전부다..” 직접 지시에 따라 종합 발란스 검토안, 블렌더 리소스, 연구소, 실제 방어전 연결을 한 기준으로 정리합니다.

현재 개발 대상은 공용 도시 시뮬레이터의 **나쁜 기운 디펜스**입니다. 원본 도시와 이전 방어전은 보존하며 새 모듈로 연결합니다. 이 문서의 시간·피해·쿨타임·배율·크기는 **시안 예시**입니다. 승률·체감 난이도·화면 가독성의 최종 검수는 현중이 진행합니다.

## 01. 현재 구현과 검토 파일 (신규)

[통합 디펜스 시뮬레이터](./나쁜기운디펜스_통합시뮬레이터_v03.html), [애니메이션·스킬 리소스 연구소 v02](./디펜스_애니메이션_스킬_리소스툴_v02.html), [짝 MD](./나쁜기운디펜스_통합개발_기획서_v03.md)를 제공합니다. 검토 파일에는 도시·몬스·악귀·보스·발사체·효과·카드 이미지를 포함합니다. 현중이 직접 파일을 열어 확인합니다.

공용 시뮬레이터 메뉴 ID는 simulator_module_bad_energy를 유지합니다. 실행 모듈은 bad_energy_current.js로 바꾸고, 조작부와 오버레이는 simulator-v02로 연결합니다. 공용 도시 렌더러와 같은 Three.js를 사용하며 기존 모듈의 컴파일 파일을 덮어쓰지 않습니다.

확인 순서는 편성과 난이도 값 선택 → 게이지 채우기 → 습격 경고 → 방어하기 → 전투 중 카드 선택 → 결과 → 보드 복귀입니다. 준비 화면에서 몬스 편성 A/B/혼합과 0~5마리를 선택합니다. 기본 10종을 모두 비교할 수 있습니다. 0마리는 옥상 지원 기본 공격만 사용하는 비교 조건이며 성장 카드는 제공하지 않습니다.

연구소는 개별 동작·발사체·효과·경고 표현을 확인하는 도구입니다. 통합 시뮬레이터는 실제 방어전의 출현·이동·공격·상태이상·성장·결과를 연결한 도구입니다. 선택 중에는 전투를 멈추지 않습니다. 별도의 일시 정지·배속 버튼은 현중 검토용 조작이며 자동 성장 규칙으로 쓰지 않습니다.

## 02. 총체적인 난이도 조절 (신규)

난이도는 적 공급, 체력, 건물 피해, 아군 처리 능력, 성장 공급과 전투 시간을 함께 봅니다. 방향은 해당 시점의 압박입니다. 방향을 늘렸다고 적 공급 예산을 방향마다 복제하거나 몬스 수에 비례해 숨은 보정을 넣지 않습니다.

준비 화면의 조절값은 한 판 시작 시 고정합니다. 원인 비교를 위해 한 항목씩 바꾸는 것을 권장합니다. 같은 시작값에서 새 스킬을 골라도 예정된 적 출현의 무작위 순서가 바뀌지 않도록 출현·성장·보스 호위의 난수 흐름을 분리합니다.

| 조절 항목 | 현재 비교 범위 · 시안 예시 | 적용 범위 |
| --- | --- | --- |
| 적 출현량 | 0.5~2배 · 기본 1배 | 일반 악귀의 생성 마릿수 예산입니다. 보스 1체는 유지합니다. |
| 적 체력 | 0.5~2배 · 기본 1배 | 일반 악귀와 보스의 체력입니다. |
| 건물 피해 | 0.5~2배 · 기본 1배 | 건물에 들어오는 일반 공격·포격 피해입니다. |
| 아군 기본 공격 | 0.5~2배 · 기본 1배 | 몬스와 옥상 지원의 기본 공격만 조절합니다. 스킬 피해는 스킬 표에서 조절합니다. |
| 길목 개방 시각 | 0.5~1.5배 · 기본 1배 | 작을수록 새 지상·공중 길목을 일찍 엽니다. |
| 성장 공급 주기 | 8·10·12·15초 · 기본 10초 | 선택 유효 시간 8초를 유지합니다. 기본안은 22회입니다. |
| 동시 활성 길목 | 3개 · 비교 4개 | 누적 등록 후보 수와 동시에 출현시키는 수를 분리합니다. |

현재 wave.csv의 budget은 **생성 마릿수 예산**입니다. 종합 발란스 v02의 적 종류별 가중 비용·살아 있는 적 상한·목표 승률은 완성된 실행 기능으로 기록하지 않습니다. 이번 실행은 정해진 물량과 종류 조합을 확인하는 첫 통합 시안입니다. 비용표와 승률의 확정은 현중 플레이 결과를 근거로 진행합니다.

건물 단계별 난이도 프로필, 아이돌 공통 능력·개인별 스킬 트리와 시즌 경제 배율은 이번 전투에 추측으로 곱하지 않습니다. 보드 게이지·보상·수리비·옥상 지원의 기존 값은 v01에서 읽습니다. 기존 값의 밸런스가 승인되었다는 뜻은 아닙니다.

## 03. 실제 도시 길목과 공중 5개 후보 (신규)

도시 원본의 16개 도로 노드·48개 방향 연결·40개 건물 배치를 사용합니다. 대상은 기존 연습실 city_02·city_04·city_22·city_24·city_25입니다. 건물마다 지상 3개 경로와 고정 공중 5개 후보를 등록합니다. 원본 도로나 건물을 이동시키지 않습니다.

원본 도로 자료에는 차도에서 건물 바깥 공격 지점으로 이어지는 마지막 보행 연결이 없었습니다. 비어 있는 땅에 **새 접근 연결(derived_new_connector)**을 별도 데이터와 표시로 추가합니다. 원본 지도에 이미 있던 길처럼 기록하지 않습니다. 길이는 약 23.25~30m이고, 종점은 건물 외벽에서 3.25m 떨어진 위치입니다. 경로 provenance에 새 연결과 원본 경로를 구분합니다.

모든 판은 지상 한 곳에서 시작합니다. 이미 등록한 후보를 시각표에 따라 개방하고 동시 상한 안에서 교대합니다. 보스는 AIR1을 지정 진입점으로 사용하며, 닫혀 있다면 상한 안에서 다른 공중 지점과 교대하여 엽니다. 몬스 1마리라고 영원히 한 방향만 사용하거나 5마리라고 5곳을 동시에 켜지 않습니다.

| 전투 시각 · 시안 예시 | 새로 사용 가능한 후보 | 동시 출현 규칙 |
| --- | --- | --- |
| 0초 | 지상 1개 | 등록된 후보에서 개방하며 동시 기본 3개 상한을 유지합니다. |
| 45초 | 지상 2개 | 등록된 후보에서 개방하며 동시 기본 3개 상한을 유지합니다. |
| 75초 | 공중 1개 | 등록된 후보에서 개방하며 동시 기본 3개 상한을 유지합니다. |
| 110초 | 지상 3개 | 등록된 후보에서 개방하며 동시 기본 3개 상한을 유지합니다. |

공중 생성 위치는 지면 42m이며, 일반 악귀의 원거리 공격 위치는 34m, 보스의 유지 위치는 42m로 설정합니다. 원본 건물의 최대 지붕 20m보다 높습니다. 건물 외곽과 수평 거리를 두고 접근한 뒤 원거리 공격합니다. 안개 안에서 생성 직후 건물을 때리는 흐름은 막습니다.

지상 출현 영역은 교차로에서 길을 따라 24m 이동한 위치입니다. 생성 지역을 가리는 안개를 벗어난 뒤에만 표적·피해 판정을 받습니다. 공중 후보도 생성 영역과 교전 위치를 구분합니다. 화면 밖 후보는 화면 가장자리 표식으로 층과 방향을 안내합니다.

## 04. 충돌과 몸 크기 (신규)

아군 기본 몬스 표시 배율은 이전 1.6에서 0.8로 절반 줄입니다. 악귀는 0.72, 공중 보스는 1.35의 별도 표시 배율을 사용합니다. 단순히 작은 충돌 원을 넣어 큰 몸이 겹쳐 보이지 않도록 실제 GLB 몸 크기로 반경을 맞춥니다.

아군의 최대 수평 반경 약 3.06m를 기준으로 충돌 반경 3.25m를 사용합니다. 일반 악귀는 종별 몸 크기와 안전 여유를 사용하고, 보스는 반경 5.15m를 사용합니다. 지상·공중 층과 높이를 구분하여 같은 높이에 있는 몸들을 분리합니다. 이동은 도로 경로와 건물 외곽 제약을 유지합니다.

밀집 상태에서는 반복 분리와 작은 허용 오차를 사용합니다. 도로·건물 제약 때문에 분리가 안 되면 마지막 유효 위치로 복귀하여 진행을 멈춥니다. 생성 지점이 막히면 새 적을 대기열에 두고, 몬스의 옥상 출발·귀환도 서로 다른 자리를 사용합니다.

빠른 발사체는 이전 위치에서 현재 위치까지의 선분 충돌을 계산합니다. 한 프레임에 표적을 지나쳐 피해가 누락되는 문제를 줄입니다. 표시를 굵게 만드는 설정과 논리 명중 반경은 분리합니다. 전체 밀집 상태와 증설된 건물의 충돌은 현중 플레이 검수에서 확인합니다.

## 05. 5분 안의 전투와 적 공급 (신규)

전투 시계는 최대 240초입니다. 종료 후 귀환·결과 연출은 최대 12초이며 기본 시간 예산은 252초입니다. 선택창 때문에 시계를 연장하지 않습니다. 수동 일시 정지는 검토 조작이므로 실시간 벽시계 길이와 구분합니다.

보스 출현 예약은 170초이며 마지막 일반 적 공급 예약은 220초에 끝납니다. 닫힌 층이나 혼잡한 생성점의 대기 때문에 실제 생성 시각은 늦어질 수 있습니다. 240초 안에 보스와 남은 적을 모두 처리하지 못하면 시간 초과 패배로 정리합니다. 건물이 먼저 부서지면 패배합니다. 종료·보스 사망 시 예약된 포격과 남은 공격 객체를 정리합니다.

| 웨이브 | 생성 시각 · 시안 예시 | 마릿수 예산 · 시안 예시 | 종류 |
| --- | --- | --- | --- |
| wave_1 | 1.5~34초 | 22 | ghost_rat · ghost_rabbit · ghost_snake |
| wave_2 | 37~71초 | 30 | ghost_horse · ghost_sheep · ghost_ox |
| wave_3 | 75~108초 | 36 | ghost_monkey · ghost_dog · ghost_rooster |
| wave_4 | 112~146초 | 42 | ghost_tiger · ghost_rat · ghost_pig |
| wave_5 | 150~185초 | 42 | ghost_dragon · ghost_rabbit · ghost_rooster |
| wave_6 | 189~220초 | 44 | ghost_ox · ghost_horse · ghost_snake · ghost_dog |
| boss_arrival | 170~170초 | 1 | boss_air_dragon |

일반 악귀의 기본 생성 예산은 216마리이며 보스 1체와 페이즈 호위는 따로 기록합니다. 진입점이 닫힌 층의 예정 적은 대기열에 둡니다. 새 위치를 임의로 만들어 내보내지 않습니다. 종료 때 대기 적을 한꺼번에 생성하지 않습니다.

악귀는 쥐·소·호랑이·토끼·용·뱀·말·양·원숭이·닭·개·돼지의 12지신을 어두운 몸·원소 균열·눈·장식으로 변형한 별도 버전입니다. 원래 12지신 모델과 일반 몬스는 보존합니다. 지상형은 길을 따르고, 공중형은 높이를 유지하며 건물에 원거리 공격합니다.

## 06. 실시간 카드 성장과 몬스 배정 (신규)

기본안은 전투 10초부터 220초까지 10초마다 최대 22번 성장 기회를 제공합니다. 세 후보 중 하나를 8초 안에 선택합니다. 선택하지 않으면 해당 기회를 건너뛰고 다음 예약 시각까지 기다립니다. 자동 선택·기회 쌓기·선택 중 감속은 넣지 않습니다.

판 안에서 보유할 수 있는 액티브 스킬은 팀 전체 최대 5종이며 각 스킬은 5단계까지 성장합니다. 새로운 판에서 모두 초기화합니다. 신규 스킬은 편성한 몬스에 순서대로 배정하고 강화는 기존 담당을 유지합니다. 카드에 실제 담당 몬스의 얼굴·이름, 발사체 그림, 신규/강화 단계와 설명을 같이 표시합니다.

중복되지 않는 유효 후보를 제공합니다. 스킬 5종을 보유하면 기존 스킬 강화만 후보가 됩니다. 최종 단계에 가까워 유효 후보가 3종 미만이면 가능한 후보만 표시하며, 후보가 없거나 몬스가 0마리이면 공급 불가로 기록합니다. 선택을 놓친 횟수와 공급할 수 없었던 횟수를 구분합니다. 성장 체감 목표는 5~10번 이상의 의미 있는 선택이며 실제 횟수는 현중 검수에서 확인합니다.

각 스킬에는 독립 쿨타임이 있습니다. 같은 몬스는 실제 기본 발사 이후 스킬을 쓰고, 다음 스킬 전에 기본 공격을 다시 섞습니다. 유도 연타의 여러 발이나 유지 빔은 하나의 스킬 시전입니다. 기본 공격 자체를 스킬로 치환하지 않습니다. 준비 화면의 편성과 조절값은 전투 중 바꾸지 않습니다.

## 07. 발사체·상태이상·쿨타임 (신규)

발사체 본체·궤적·피격 효과의 색을 맞추고 전투 화면의 표시 최소 두께를 별도 설정으로 사용합니다. 기본 몸체 5px, 궤적 2px, 빔 6px를 기준으로 카메라와 화면 크기에 맞춰 횡방향 표시를 확대합니다. 종방향 길이와 논리 명중 반경은 유지합니다. 실제 화면에서 읽히는지는 현중이 확인합니다.

## 08. 공중 보스의 3페이즈 (신규)

보스는 용형 공중 악귀입니다. 지상 길을 걷거나 건물에 몸을 비비지 않습니다. 공중에서 대기·이동하며 충전 → 발사 → 재사용 대기의 미사일 포격으로 건물을 공격합니다. 건물 위치의 예고 표시와 보스 충전 진행을 함께 보여 줍니다.

| 페이즈 | 체력 기준 | 포격 재사용 대기/예고 · 시안 예시 | 미사일/호위 · 시안 예시 |
| --- | --- | --- | --- |
| 1 | 100% | 9.0초 / 1.8초 | 1발 / 0마리 |
| 2 | 70% | 7.0초 / 1.8초 | 2발 / 2마리 |
| 3 | 35% | 5.4초 / 1.6초 | 3발 / 3마리 |

충전 중 누적 피해가 페이즈별 120·160·210에 도달하면 포격을 취소합니다. 취소 뒤 1.8초 경직과 4초 약점 노출을 제공합니다. 약점에 주는 피해 배율은 1.5배입니다. 체력 70%와 35%에서 전환 동작·알림·다음 포격과 호위를 연결합니다.

재사용 대기 뒤 다음 충전을 시작하므로 전체 포격 간격에는 충전·발사 동작과 경직·약점 시간이 추가됩니다.

1페이즈는 단발 포격, 2페이즈는 2발과 닭형 공중 호위, 3페이즈는 3발과 용형 공중 호위입니다. 연속 포격은 좌우 발사구와 애니메이션 사건 시점을 사용합니다. 전환·충전 취소는 현재 충전과 예고를 정리합니다. 이미 발사된 미사일은 유지하며, 보스 사망·전투 종료에서는 예약 포격과 비행 중 미사일까지 정리합니다.

혼잡한 생성점의 호위는 같은 예산의 대기열로 옮겨 출현할 공간이 생기면 생성합니다. 호위는 무제한 일반 적 공급의 대체가 아닙니다. 실제 생성 수·남은 적·건물 피해와 함께 살펴봅니다. 몬스 수가 적어 포격 취소가 어려운 정도와 특정 스킬 없이도 대응할 수 있는지는 현중의 플레이 검수가 필요합니다.

안개는 지속되는 독립 오브젝트입니다. 진입점이 닫혀도 그 출현 영역에 남아 있는 적이 있으면 안개를 유지합니다. 안개 안의 정확한 출생 위치·몸·체력 표시는 숨기고, 넓은 지역 위치는 표식으로 알려 줍니다. 안개 밖으로 나온 적과 공격 예고는 정상적으로 표시합니다.
