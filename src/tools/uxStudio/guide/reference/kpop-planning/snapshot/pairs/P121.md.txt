## (이전) 3. 구동 방법·시뮬레이션



공용 시뮬레이터에 **나쁜 기운 디펜스 시안 모듈**을 올렸습니다(10/07 단서 · 현중 「지금의 드론이 몬스라고 생각하면 돼 · 시뮬레이터로 만들어 봐」). 보드 게이지 → 경고 · 악귀 행렬 → 방어하기/그냥 두기 → 부서짐 · 수리 / 연습실 확대 전투 → 스킬 카드 → 보스 → 결과 → 보드 복귀까지 한 번에 돌아갑니다. 게임 본편 구현은 아닙니다. 수치는 모두 시안입니다.

시안 구현 · 공용 시뮬레이터 「나쁜 기운 디펜스」 탭 · 키 simulator_module_bad_energy

[나쁜 기운 디펜스 시뮬레이터를 엽니다](/docs/planning/game-simulator.html?module=simulator_module_bad_energy)[P88 월드 디펜스 시연 자료를 엽니다](/docs/planning/planning-docs-tool.html?face=development&doc=P88&plan=planning_development_plan_defense)[공용 시뮬레이터를 엽니다](/docs/planning/planning-docs-tool.html?face=development&doc=P94&plan=planning_development_plan_simulator)

왼쪽 판: 주사위 굴리기 · 루머 카드 · 게이지 채우기(시험) · 보유 몬스 수 0~5 · 스킬 카드 자동 선택(6초) · 배속 ×2 · 멈춤 · 내 연습실 목록과 수리 버튼 · 기록. 코드: `src/game/bad-energy-v01/engine.mjs`(규칙 · 화면 없음) · `src/ui/bad-energy-v01/preview.mjs`(화면 · 연출) · `src/simulator/v01/bad_energy.mjs`(등록).

옛 안 → 게임용 나쁜 기운 디펜스 모듈은 미구현입니다. 가장 가까운 시연은 P88 월드 디펜스 v05입니다. 등록 예정 키는 simulator_module_bad_energy입니다.

관찰 순서 · 구현 후 검수

주사위마다 게이지가 차는지 → 마지막 눈금에서 구름이 내 연습실로 흐르는지 → 창의 「그냥 두면」 줄에 수리비가 보이는지 → 그냥 두기 뒤 연습실 칸 보상이 줄고 연습이 멈추는지 → 수리하면 바로 돌아오는지 → 방어하기 뒤 연습실 한 채만 보이는지 → 몬스가 보유 수만큼(그로기 제외) 나오는지 → 악귀가 벽에 닿을 때만 내구도가 깎이는지 → 남은 악귀 0 전에는 이기지 않는지 → 끝나면 게이지가 0인지 확인합니다.
