# P174 · 뉴런

**이 문서는** 현재 팀의 성장·라포·시설 기반을 같은 기록으로 읽고, 아이돌과 관계가 어떻게 연결되는지 보여 주는 공통 정보 화면 뉴런을 설명합니다.

**보는 법** 1장 기록 조회의 범위 → 3장 현재 팀과 독립 시험 → 4장 4단계·관계·표시 → 6장 원표 → 7장 개발·검수 순서로 읽습니다. [개발·검수 범위](#part-7)

**지금 상태** 현재 팀 관찰·4단계 탐색·독립 표시 시험·공통 정보창의 코드 경로가 있습니다. 공용 관계 계산과 현재 뉴런 직접 조회의 차이는 4장에서 구분합니다. 팀 복합 등급·아카데미 개별 상세·전체 경제 기여 분해는 작업전 또는 연결 확인이 남아 있으며, 이번 실제 게임·카메라·저장 검수는 하지 않았습니다.

## 1. 개요

출처: (합침) [아이돌 성장 제안서](../../../../proposal-concept/idol.html), 현재 뉴런 공통 패널·팀 관찰기와 성장 테스트 도구.

뉴런은 **기록을 보여 주는 화면**입니다. 보드에서 얻은 변화가 건물·엔터파워와 아이돌 능력으로 이어지는 모습을 살펴보고, 멤버별 현재 능력·재능·세부·아카데미와 실제 관계를 읽습니다. 뉴런이 성장량이나 보상을 새로 계산해 지급하지는 않습니다.

```mermaid
flowchart LR
 A[현재 팀과 성장 기록] --> B[세션과 멤버 확인]
 C[시설과 관계 기록] --> B
 B --> D[뉴런 표시 모델]
 D --> E[팀과 관계]
 D --> F[개인 능력과 아카데미]
 D --> G[실제 변화의 가벼운 연출]
```

실제 기록을 보는 경로와 독립 임시 시험은 출처를 구분합니다. 표시 수치·비율과 원본의 미정 수치는 **발란스 대기**이며 실제 게임 값으로 확정하지 않습니다.

## 3. 구동 방법·시뮬레이션

화면 흐름: 공용 시뮬레이터 뉴런 또는 팀·멤버 정보창 → 전체·관계·개인 능력 → 세부 확인 → 기존 화면 복귀. 무거운 3D 화면은 링크를 눌러 열고 이 문서는 자동 실행하지 않습니다.

### [▶ 뉴런 시뮬레이터 열기](../../../../game-simulator.html?module=simulator_module_neuron_info)

1. 현재 연결이면 같은 세션·run의 실제 팀과 성장 기록을 읽습니다. 자료가 없으면 연결 대기로 표시합니다.
2. 팀 또는 멤버를 고르고 전체 → 관계 → 개인 6축 → 소속 세부 단계로 살펴봅니다. 선택한 멤버와 축은 공통 정보창에서도 이어집니다.
3. 독립 생성 시험 문맥에서는 「임시 시험」을 명시해 인원과 상황을 바꿔 표시를 재생할 수 있습니다. 시험 결과는 실제 저장에 쓰지 않습니다.
4. 화면에서 나가면 재생과 관찰을 정리합니다. 이번 문서 작업에서 새 실행·화면 캡처는 하지 않았습니다.

```mermaid
flowchart LR
 A[뉴런 등록 콘텐츠] --> C[공통 뉴런 패널]
 B[팀 또는 멤버 정보창] --> C
 C --> D[현재 팀 기록]
 C --> E[독립 문맥의 임시 시험]
 D --> F[선택과 확대]
 E --> F
```

<a id="part-4"></a>
## 4. 상세 기획

### 한 판 순서

| 점검 | 내용 |
|---|---|
| 시작·종료 | 현재 팀으로 뉴런을 열고 정보를 살펴본 뒤 기존 화면으로 돌아갑니다. |
| 입력·출력 | 유효한 팀·성장·시설·관계 기록을 받아 3D 표시 모델과 선택 상태를 만듭니다. |
| 상태와 전이 | 연결 대기 → 현재 기록 표시 또는 명시적 임시 시험 → 선택·확대 → 정리입니다. |
| 판정 | 세션·run·멤버와 기록의 유효성을 대조하고 현재값·재능·관계의 출처를 확인합니다. |
| 오류·예외 | 값 0과 미공급을 구분합니다. 기록이 없거나 다른 팀이면 가상 멤버·관계를 대신 넣지 않습니다. |
| 저장·복원 | 뉴런은 실제 기록을 읽기만 합니다. 시험 재생은 표시용 메모리에 두고 실제 게임을 되쓰지 않습니다. |
| 다른 모듈 | 공통 정보창·성장 테스트·보드 변화 표시와 연결하되 계산·지급은 원래 모듈이 맡습니다. |

### 네 단계로 확대하기

| 단계 | 보여 주는 범위 |
|---|---|
| 0 전체 | 보드·시설 기반과 바깥 엔터파워 |
| 1 팀 | 멤버와 확인된 관계 |
| 2 개인 | 선택한 아이돌의 6축과 아카데미 |
| 3 세부 | 소속 18세부와 아카데미를 함께 확인 |

고정 보기는 전체·이전·다음으로 단계별 이동하고 세밀 모드는 자유롭게 확대합니다. 멤버나 능력 축을 고르면 그 대상과 소속 세부를 맞춰 보여 줍니다. 모바일 정보창 안에서 같은 패널을 사용하며, 창의 기존 닫기와 복귀 동선을 따릅니다.

```mermaid
flowchart LR
 A[전체 기반] --> B[팀과 관계]
 B --> C[선택 멤버 6축]
 C --> D[18세부와 아카데미]
 D --> C
 C --> B
 B --> A
```

### 능력·재능·아카데미

개인 6축은 보컬·댄스·랩·비주얼·끼와 예능감·프로듀싱입니다. 각 축은 자기 세부 세 개를 가집니다. 현재 능력 띠와 재능 띠는 서로 다른 원본이므로 합쳐 표시하지 않습니다. 아카데미의 태도·성실성·영어·중국어·일본어는 별도 항목이며 기본 6축이나 18세부에 새 능력으로 더하지 않습니다.

값이 0이면 실제 0으로, 필드가 없거나 연결되지 않으면 대기로 표시합니다. 화면 점수의 단위가 바뀌면 공통 변환 설정을 한 번 적용합니다. 척도가 유효하지 않으면 임의의 기본값으로 채우지 않습니다.

### 라포는 실제 두 사람의 관계

한 쌍은 현재 팀의 서로 다른 멤버 두 명을 기준으로 표시합니다. 기획은 관계 허브·모험과 같은 현재 팀 라포 조회로 이어 읽고 저장된 관계를 우선하며, 원본 시작 규칙이 있을 때 없는 쌍만 같은 범위·성격 궁합으로 계산하는 방향입니다.

공용 `resolveCurrentTeamRapport` 계산은 존재하지만, 이번에 확인한 뉴런의 직접 경로는 `panel` → `rapport-source`에서 관계 원표와 검증된 체크포인트를 조회하는 경로입니다. 원표의 `*` 행에서 범위 시작값을 읽는 부분과 기록 충돌 시 대기 표시는 확인했으며, 이 직접 경로가 공용 성격 궁합 초기계산을 호출하는 연결은 확인하지 못했습니다. 상위 writer가 만든 궁합 결과의 전체 전달은 별도 확인 대상이며, 공용 계산 자체가 전역 미구현이라는 뜻은 아닙니다.

1명에게 가상 상대를 넣지 않고, 원본 규칙이 없는 쌍은 기록 대기입니다. 기존0·명시된 빈 값·변화 기록을 새 시작값으로 덮지 않으며 중복·충돌·다른 세션 기록을 임의로 합치지 않습니다. 뉴런의 표시 조회와 실제 관계 저장을 쓰는 주체를 구분합니다.

공통 뉴런 패널은 전달받은 유효한 관계만 표시하고 자체로 상대나 수치를 생성하지 않습니다. 관계 허브의 시험 중에는 같은 누적 사본의 관계선·네 축을 표시하며 실제 저장 변경과 구분합니다.

| 관계 축 | 읽는 시각 표현 |
|---|---|
| 상호 신뢰 | 색의 가까워짐 |
| 이해 | 관계선의 두께 |
| 협력 | 상대의 거리·배치 |
| 긴장 | 상대의 높이·분리 |

```mermaid
flowchart LR
 A[현재 멤버 두 명] --> C[쌍과 원본 확인]
 B[라포 기록과 축 정의] --> C
 C --> D[유효한 축을 관계선과 배치로 표시]
 C --> E[원본 없음 또는 불일치]
 E --> F[관계 기록 대기]
```

### 실제 변화와 임시 시험

같은 진행에서 새 기록의 실제 전후 차이가 있을 때 표시 신호를 만들 수 있습니다. 보드에서 받은 변화 → 건물 → 엔터파워 → 아이돌 능력의 흐름을 가볍게 보여 주며, 재진입이나 같은 기록의 중복 수신만으로 지급을 다시 실행하지 않습니다. 화면이 가려지거나 정보창이 열리면 경량 표시를 정리합니다.

P171 발란스 굴림에서 뉴런 보기가 켜져 있을 때는 뉴런 안의 확인된 변화선·빛을 유지하고, 돈·팬·엔터파워·나쁜 기운·콘텐츠·몬스가 다른 창으로 이동하는 표시는 목적 창의 빛과 기존 수신 배지로 바꿉니다. 뉴런으로 전환할 때 남은 비행과 필러는 표시 완료로 정리하며 같은 영수증을 나중에 다시 재생하지 않습니다. 숨겨진 필러를 출발점으로 기다려 굴림이 멈추지 않게 합니다.

이 규칙은 발란스 굴림의 뉴런 보기 ON에만 적용합니다. 계산·저장·보상 지급은 그대로이며, 뉴런을 끈 일반 모드의 비행과 03 개인 단계·08 팀 등급 상승의 기존 2초 강조를 유지합니다. 별도 게임 뉴런·공통 정보창의 동작은 바꾸지 않습니다.

독립 시험은 1·2·5·10명과 능력·라포·아카데미·건설·단계·0·누락 상황을 표시용으로 재생합니다. 10명은 배치 시험이며 실제 게임 팀 인원을 바꾸지 않습니다. 1명 관계 시험에서 가상 상대를 넣지 않습니다. 성장 테스트 도구의 메모리 사본도 명시적으로 표시하며 실제 저장과 다릅니다.

```mermaid
flowchart LR
 A[검증된 실제 전후 기록] --> B[변화 표시]
 C[독립 시험의 임시 데이터] --> D[시험 재생]
 B --> E[같은 공통 패널]
 D --> E
 E --> F[선택과 화면 표시]
```

### 필요 시스템

현재 팀 관찰기, 성장·시설·관계 저장 검증, 능력·재능·아카데미 정의, 공통 모바일 정보창, 3D 패널과 표시 자원 정리가 필요합니다. 팀 전용 6축·복합 등급의 뉴런 표현, 아카데미 개별 상세 진입과 모든 플레이 경로의 연출 검수는 작업전 또는 연결 확인이 남아 있습니다.

### 화면·연출 목록

| 화면·연출 | 역할 |
|---|---|
| 공통 뉴런 패널 | 팀·개인 능력·관계·시설을 4단계로 탐색 |
| 공통 캐릭터 정보창 | 팀·멤버·선택 축을 같은 창에서 이어 봄 |
| 플레이 경량 연출 | 실제 기록 변화만 간단한 선·빛으로 표시. P171 발란스 뉴런 ON은 내부 변화선을 유지하고 외부 전달은 목적 창 빛·수신 배지로 표시 |
| 독립 임시 시험 | 표시 대상·상황을 바꾸어 배치·동작 확인 |

### 남은 결정

미공급 학습·관계 값과 능력·시설의 수치·척도는 **발란스 대기** 또는 연결 대기로 유지합니다. 팀 복합 등급 표현과 실제 전체 경제의 기여 분해는 작업전입니다.

## 5. 필요 리소스·이미지 설명
