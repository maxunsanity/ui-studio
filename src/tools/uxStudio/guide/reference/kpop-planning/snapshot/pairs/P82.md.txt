# P82 · 도시 원본 · 사용과 게임 연결

**이 문서는** 보드 도시맵의 3D 원본(건물 40개 · 도로 · 중앙 숲)이 어떤 파일로 되어 있고, 게임과 시뮬레이터가 그것을 어떻게 읽는지 설명하는 문서예요.

**보는 법** 1장(파일) → 2장(게임에서 읽는 법) → 3장(남은 일)을 읽으세요. 숲·도로 제작 순서는 [P83](P83_설명.html), 도시 통합 화면은 [P84](P84_설명.html)에 있어요. 같이 여는 시뮬레이터: [그림·설정 시뮬레이터](/docs/planning/game-simulator.html?module=simulator_module_resources). 지난 기록은 [로그](P82_설명.log.md)에 있어요.

**지금 상태** **개발된 것**: 건물 40개 분리 모델과 전체 모델, 공연장 확대 모델, 도로·공원, 간판 공통 텍스처, 건물·숲·거리 배치 CSV, 3D 검수 화면과 연결 함수(`createCityGroup`). **현재 개발되지 않음, 진행 중**: 실제 기기 성능 측정, 캐릭터 이동 충돌·길찾기, 본게임 카메라 연결.

## 1. 파일

| 파일 | 용도 |
|---|---|
| `도시맵_전체.blend` | 건물 40개와 도로·공원 편집용 원본 |
| `models/city_01.glb` ~ `city_40.glb` | 도시 칸 ID별 분리 모델 |
| `models/city_35_high.glb` | 공연장 확대용 압축 모델 |
| `models/city_full.glb` | 전체 배치를 한 번에 가져오는 모델(편집·확인용) |
| `models/roads_park.glb` · `models/sign_atlas.png` | 도로·공원 · 간판 40개 공통 텍스처 |
| `config/buildings.csv` | 도시 ID · 기능 · 표시명 · 배치 · 치수 · 모델 연결 |
| `config/forest_units.csv` · `forest_placements.csv` · `street_blocks.csv` | 숲 유닛 · 식생 배치 · 포장 블록 |
| `runtime/city-viewer.js` | 3D 검수 화면과 연결 함수 |

## 2. 게임에서 읽는 법

- 게임은 `createCityGroup(base, options)`로 도시를 장면에 넣고, 칸 ID로 건물 모델을 찾아요.
- 건물 ID·표시명·위치·모델 경로는 CSV에서 읽어요. ID 중복·누락·빈 수치는 거부해요. 읽는 방식은 [P58 테이블 데이터 기초](../../기획서/기획서_테이블데이터기초_v0.1_이스라트.md)를 따라요.
- 배치 좌표·회전·크기·표시명은 CSV를 고치면 다음 로딩에 반영돼요. 치수·색·간판 글자는 모델에 구워져 있어서 다시 제작해야 바뀌어요.
- 공연장은 가까이 볼 때만 확대 모델을 불러와요.
- 보드 칸 배치와 역할은 [P87 보드 기본 구성](../작성기준_v02/보드기본구성_샘플.html)이 기준이에요.

## 3. 남은 일 (현재 개발되지 않음, 진행 중)

| 항목 | 내용 |
|---|---|
| 실제 기기 성능 | 모바일 FPS · 메모리 측정 |
| 이동 · 충돌 | 충돌 상자와 도로면 파일은 있지만 캐릭터 이동·길찾기는 연결 전 |
| 본게임 카메라 | 거리·줌에 따른 확대 모델 전환 기준 |
