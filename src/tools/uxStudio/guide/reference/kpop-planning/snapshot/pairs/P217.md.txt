## 1. 개요

출처: (합침) 제안서 [유료화](/docs/planning/proposal-concept/pay.html) · 책갈피 [P197 유료화 보완판](../../기획서/산출_기획서_유료화_보완판_v1_클로드.html) · 현중 11/01~11/02 지시

> **핵심** 돈은 **속도 · 꾸밈 · 소장**에만 씁니다. 투표 · 채점 · 순위로 가는 길에는 돈이 들어갈 자리가 없고, 결제는 능력을 빨리 키워 **무대 편성 점수에만 간접**으로 닿습니다.

```mermaid
flowchart LR
  A[유료 재화 하나] --> B[속도 · 주사위 · 추가 권]
  A --> C[꾸밈]
  A --> D[소장 · 팩 · 패스]
  B --> E[무대 편성 점수에 간접]
  A -.->|못 삼| F[투표 · 채점 · 순위]
```

### 콘텐츠 경계

- 맡는 것: 유료 재화 · 파는 것 · 안 파는 것 · 시즌 패스 · 확률 공개.
- 다른 문서에 맡기는 것: 자원 흐름 → [P212 게임 경제](게임경제_핵심제안서.html) · 배수 → [P209 배수 걸기](배수걸기_핵심제안서.html).

### 현재 기준과 목표

| 파는 것 | 안 파는 것 |
|---|---|
| 주사위 · 카드 팩(확률 공개) · **몬스 팩(확률 공개 · NEW 11/02)** · 시즌 패스 | 투표권 · 공유권 · 채점단 자리 |
| — | 카드 트레이드에 돈 · 유료 재화 끼우기(중복분 카드 1 ↔ 1만) |
| 추가 곡 만드는 권 · 다시 만들기 | 맞불 공연 · 게릴라 보호 |
| 무대 · 재킷 · 크루 홈 꾸밈 | 입장권 직접 판매 · 연고 도시 바꾸기 |
| 시즌 한정 콜라보 카드(속도 효과만 · 출전 불가) | 몬스 별 · 능력 · 조각 |

- 유료 재화는 하나이고 시즌을 넘어 이월됩니다.
- 아이돌 카드는 그 아이돌 전용이고 처음 1장만 능력이 됩니다(현중 11/02). 카드 팩은 능력을 빨리 모으는 「속도」 상품입니다. 카드는 무대 편성 점수에만 간접으로 닿고, 투표 · 채점에는 닿지 않습니다.

## 3. 구동 방법·시뮬레이션

화면 흐름: 상점 → 상품 → 결제 → 지급 · 스샷 미완 · 이식 비교 해당 없음

- 전용 유료화 정책 모듈은 별도 등록되어 있지 않습니다. 현재 공통 상점(simulator_module_shop)은 상품 조회·루비 차감·팩 보관·같은 진행 저장 코드 경로를 갖습니다. 실제 UI 정상이나 운영 결제 완료를 확인한 것은 아닙니다.
- 핵심제안 개발의 **판매 판정 시뮬레이터**에서 상품을 누르면 팔아도 되는지와 이유가 나옵니다. 숫자는 모두 임시 시안입니다.

<a id="part-4"></a>

## 4. 상세 기획

### 한 판 순서 (임시 시안)

| 점검 | 내용 |
|---|---|
| 시작·종료 | 상점에서 유료 재화로 구매 |
| 입력·출력 | 입력 = 결제 / 출력 = 속도 · 꾸밈 · 소장 아이템 |
| 상태와 전이 | 결제 → 유료 재화 → 상품 |
| 판정 | 순위에 닿는 상품은 목록에 없음 |
| 오류·예외 | 확률 상품은 확률 공개 화면 필수 |
| 저장·복원 | 유료 재화 · 유료 권은 계정 범위 이월 |
| 다른 모듈 연결 | 게임 경제 · 시즌 · 카드 |

### 몬스 팩 (NEW · 현중 11/02 12:52)

몬스 팩은 카드팩과 같은 아이템 구조(타입만 몬스)입니다. 무료로는 한 시즌에 튜토리얼 1 · 기획사 등급 6 · 엔터파워 5 · 미션 5 = 17개를 받고, **나머지는 유료 샵과 다른 보상**으로 받습니다. 몬스 팩은 속도 · 소장 상품이고, 몬스 힘은 투표 · 페스티벌 순위에 직접 닿지 않습니다. 같은 종은 자동 합성(행복도 · 시즌 안)이고 상한을 찍은 종은 나오지 않습니다. 가격 · 하루 횟수 · 확률표는 결정 대기입니다(세부 [P223](몬스보유_핵심제안서.html)).

### 아이돌 등급 카드팩 (NEW · 현중 11/02 16:38 · 가격 임시)

상점 팩 탭에 아이돌 등급 카드팩 5종을 루비로 팝니다(현중 16:38 「유료템이니깐 임시로」). 그 등급 이상 아이돌이 있어야 열리고, 없으면 가방에 보관합니다. 가격은 지금 「주사위 75 + 팩」 750 루비 × 단계 비율 × 5로 잡은 **임시값**입니다. 상점 등급 팩 5종은 두 겹 주머니의 **일반(normal) 주머니**로 뽑습니다(고급 주머니는 주간 월드스타 미션 보상에만 있음 · 세부 [P168](카드_기획서.html)).

| 상품 | 루비(임시) | 표 |
|---|---|---|
| 연습생 카드팩 | 260 | item_master_shop_sku_idol_stage_0 |
| 데뷔조 카드팩 | 430 | item_master_shop_sku_idol_stage_1 |
| 라이징 스타 카드팩 | 680 | item_master_shop_sku_idol_stage_2 |
| 톱스타 카드팩 | 1,020 | item_master_shop_sku_idol_stage_3 |
| 월드스타 카드팩 | 1,360 | item_master_shop_sku_idol_stage_4 |

기록: [발란스 툴 「아이돌 카드 · 팩 장부」](/docs/planning/balance-tool.html?topic=balance_topic_idol_cards) · 세부 [P225](../../../../_이전기획_보관/20261116_카드옛구조/삼중AI_공용_20260929/산출/개발진행기획_v01/콘텐츠별_v03/카드_핵심제안서.html). 카드는 능력이 되므로 하루 구매 한도 · 가격은 발란스 때 다시 봅니다.

### 시즌 패스 (임시 시안)

보상 = 주사위 · 꾸밈 · 추가 곡 만드는 권 · 입장권(패스로만). 보관함은 일반 카드 중 고른 카드 · 속도 효과만.

### 필요 시스템

유료 재화 · 상점 · 확률 공개 · 시즌 패스 · 이월.

### 화면·연출 목록

상점 · 확률 공개 · 시즌 패스.

### 남은 결정

- (NEW) 몬스 팩 가격 · 하루 횟수 · 확률 공개표 — 유료화 · 발란스

- 가격 · 패스 보상 크기 — 발란스 · 운영
- 무과금 카드북 범위 — 발란스 대기

### 공통 상점·프로토 결제·판매 분류 시안

공통 상점은 `shop-sim.mjs` → `shop.ts`의 기존 상품·비용·보상 로더를 사용합니다. 확인 뒤 루비 차감과 주사위 지급 또는 팩 보관을 계산하고, 공통 메뉴 거래가 같은 진행의 저장과 중복 요청·복구 경계를 맡습니다. 이 코드를 읽었다는 것과 실제 UI·저장·지급의 모든 조건을 통과했다는 것은 다릅니다.

루비 구매의 `buyGem`은 실제 결제가 아니라 항상 성공하는 프로토 결제입니다. `shop_tab`의 패스·꾸밈은 꺼져 있고 현재 상점 UI는 준비 중으로 표시합니다. 독립 판매 판정 시안은 자체 항목을 분류할 뿐 실제 상품·가격·결제·지갑을 읽지 않습니다. 모든 최신 상품을 포함한 판정표로 읽지 않습니다.

등급팩·몬스팩의 상품 정책과 임시 수치는 현재 P168·P223 등 소유 원본을 따릅니다. 이 정정은 기존 본문의 가격·팩 표·normal 주머니 설명을 다시 결정하거나 시안 항목을 고치는 작업이 아닙니다. 시즌 이월·확률 공개·운영 결제의 완료도 새로 판정하지 않습니다.
