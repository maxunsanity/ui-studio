# P103 · 게릴라 공연 · 사용 CSV

상태:

## 개요

게릴라 공연 기획의 근거로 사용하는 CSV 1개를 나열합니다. 공용 게임 표의 기획 원문이며 실행 로더에서 읽는 표가 아닙니다. 전체 등록 표는 P73에서 확인합니다. 빈 값과 빈 행을 임의로 채우지 않습니다.

[대표 기획서](/docs/planning/planning-docs-tool.html?face=development&doc=P102&plan=planning_development_plan_guerrilla) · [출연권 대전 P98](/docs/planning/planning-docs-tool.html?face=development&doc=P98&plan=planning_development_plan_casting) · [전체 테이블 P73](/docs/planning/planning-docs-tool.html?face=development&doc=P73)
