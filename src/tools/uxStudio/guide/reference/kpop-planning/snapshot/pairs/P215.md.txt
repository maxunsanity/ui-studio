# P215 · 홍보(리드 제너레이션) · 대표 개발 기획서

**이 문서는** 「홍보」의 두 갈래, 게임 안에서 내 곡을 알리는 것과 게임 밖에서 연락처를 받아 다시 부르는 것을 정리한 대표 개발 기획서입니다.

**보는 법** 1장 그림 → 4장 「한 판 순서」 → 핵심제안 개발의 「홍보 갈래 시뮬레이터」 순서로 읽습니다. 세부 결정과 근거는 책갈피 [P202 홍보(리드젠) 보완판](../../기획서/산출_기획서_홍보리드젠_보완판_v1_클로드.html)에 있습니다.

**지금 상태** 두 갈래를 설명하는 독립 문서 시안과 음악 모듈의 홍보 기록 부분 코드가 있습니다. 연락처·외부 미션·보상·순위와 팬의 통합 연결 및 실제 화면은 검수 전입니다.

## 1. 개요

출처: (합침) 제안서 [홍보](/docs/planning/proposal-concept/promo.html) · 책갈피 [P202 홍보(리드젠) 보완판](../../기획서/산출_기획서_홍보리드젠_보완판_v1_클로드.html) · 현중 11/01~11/02 지시

> **핵심** **게임 안 홍보**는 내 곡을 알려 순위와 팬을 움직이고, **게임 밖 리드젠**은 연락처를 받아 떠난 유저를 다시 부릅니다. 둘은 피드 클립 · 유통곡으로 이어지지만 **게임 밖 성과는 게임 순위에 넣지 않습니다.**

```mermaid
flowchart LR
  A[홍보] --> B[게임 안 · 피드 · 공유 · 총공]
  A --> C[게임 밖 · 혜택 미션 · 연락처]
  B --> D[순위 · 팬]
  C --> E[복귀 알림 · 마케팅]
  C -.->|안 들어감| D
```

### 콘텐츠 경계

- 맡는 것: 두 갈래 구분 · 혜택 · 미션 탭 · 홍보 덱 9장 · 보상 범위.
- 다른 문서에 맡기는 것: 게임 안 홍보 세부 → [P208 음원 · 영상](음원영상_핵심제안서.html) · 연락처 저장 → [P222 유저 저장](유저저장_핵심제안서.html).

### 현재 기준과 목표

| 갈래 | 무엇 | 순위에 |
|---|---|---|
| 게임 안 | 피드 찜 · 게임 안 공유 · 커버 · 크루 총공 | 들어감(하루 한도) |
| 게임 밖 | 혜택 · 미션(SNS 공유 · 사전 저장 · 연락처) | 안 들어감 |

- 게임 밖 보상으로 투표권 · 공유권 · 입장권 같은 순위 자원은 주지 않습니다.
- 리드젠은 마케팅 비용입니다(게임 매출 아님).
- 동의 문구 · 절차는 법무 검토입니다.

<a id="part-3"></a>

## 3. 구동 방법·시뮬레이션

화면 흐름: 혜택 · 미션 탭 → 미션 → 보상 / 피드 → 홍보 버튼 · 스샷 미완 · 이식 비교 해당 없음

- 전용 외부 리드젠 통합 모듈은 별도 등록되어 있지 않습니다. 관련 음악 모듈에는 파이널 공유 행동을 기록하는 부분 경로가 있습니다. 연락처 수집이나 실제 순위·팬·보상의 전체 연동 완료를 뜻하지 않습니다.
- 핵심제안 개발의 **홍보 갈래 시뮬레이터**에서 홍보 행동을 누르면 어느 갈래이고 순위에 들어가는지 봅니다. 숫자는 모두 임시 시안입니다.

<a id="part-4"></a>

## 4. 상세 기획

### 한 판 순서 (임시 시안)

| 점검 | 내용 |
|---|---|
| 시작·종료 | 혜택 · 미션 탭에서 시작 |
| 입력·출력 | 입력 = 홍보 행동 / 출력 = 홍보 점수(게임 안) · 연락처 · 보상(게임 밖) |
| 상태와 전이 | 미션 → 완료 → 보상 |
| 판정 | 게임 밖 성과는 순위 · 팬 사다리에 안 들어감 |
| 오류·예외 | 연락처 동의 철회는 바로 반영 |
| 저장·복원 | 연락처는 게임 저장과 분리 |
| 다른 모듈 연결 | 피드 · 크루 · 유저 저장 |

### 홍보 덱 9장 (원본 가안 유지 · 임시 시안)

현행 기획 참조인 P202·LG02는 7번을 게임 안 피드 클립·커스텀 블록 캐릭터의 15초 짤, 8번을 회사가 고른 유통곡·공식 앨범의 사전 저장 방향으로 설명합니다. 사진 업로드로 뮤비를 만드는 구안과 구별합니다. 9번은 오프라인 팝업·실물 상품 응모 방향입니다. 이것은 새 9개 미션 전체 순서·보상·동의 정책을 확정하거나 사용자 승인을 새로 선언한 것이 아닙니다.

### 필요 시스템

혜택 · 미션 탭 · 미션 판정 · 연락처 동의 저장 · 피드 클립 내보내기.

### 화면·연출 목록

혜택 · 미션 탭 · 미션 카드 · 동의 화면.

### 남은 결정

- 하단 메뉴 위치 — HUD 기획 확인
- 보상 크기 — 라이브 QA
- 동의 문구 — 법무 검토

### 현행 기획·이전 가안·실제 연결의 경계

게임 안 피드·공유·커버·크루 홍보와 게임 밖 혜택 미션·연락처는 현재 대표 문서와 P202·LG02의 구분을 따릅니다. 기존 제안 카드의 사진 뮤비·번호가 다른 9장·카드16 역할은 이전 가안으로 보존하며 현재 정책으로 합치지 않습니다. 동의 문구와 절차는 법무 검토 대기입니다.

독립 홍보 갈래 시안은 버튼을 누른 횟수를 메모리 예시 점수·미션 수로 보여 줍니다. 문자열의 하루 한도는 실제 날짜·한도 검사나 연락처 동의 저장을 실행한 증거가 아닙니다. 게임 밖 성과를 순위에 넣지 않는 방향과 실제 외부 증명·연락처·보상 처리는 구분합니다.

음악 모듈에는 공유 버튼 → 홍보 명령 → 같은 범위 기록 경로가 있습니다. 집계와 팬 사다리·순위의 전체 동작은 해당 기획·담당 범위에서 확인하며 여기서 완료로 승격하지 않습니다. 외부 리드젠의 운영표·연락처 저장·미션 지급 역시 이번 문서 정정에서 실행 검수하지 않았습니다.
