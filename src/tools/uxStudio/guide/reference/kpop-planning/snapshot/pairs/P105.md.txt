# P105 · 핵심제안 시스템 개발 진행 점검

상태: 2026년 10월 15일 · 비이벤트 시스템 전체 정리

현재 성장의 기준은 아이돌 성장 v02입니다. 오디션·건설·방어의 독립 시뮬레이터를 공통 데이터 계약으로 연결하고, 메뉴·기획·제안 카드의 기준을 맞춥니다. 과거 작업 수나 옛 검토 의견은 현재 완료율로 사용하지 않습니다.

## 1. 실행되는 것

| 영역 | 현재 확인 대상 | 대표 문서 |
|---|---|---|
| 오디션 | 16인 첫인상·서바이벌·영입·짝 몬스·서사 | P100 |
| 성장 | 대표4·세부12·학습2+일본어 보존, 카드·칸·시설, 팀/개별 표시 | P107 |
| 로컬 연결 | 같은 후보·몬스 ID, 성장 합계 단위, 시설별 단계 | P140 |
| 건설 | 30단계 재정비 예정·밀착3동·전체복셀, 성장 단계 가져오기 | P81/P106 |
| 방어 | 자동10·피니시5·AI·독립3동HP·보스3구간, 성장 팀 가져오기 | P104/P138 |
| 메뉴 | 최신 성장 기본, 주요5개 흐름, 보조 도구 접힘, 구URL 유지 | P75 |

## 2. 같은 데이터로 보는 범위

성장 v02가 팀·능력·시설 진행의 주인입니다. 대표 현재값은 세부 3개의 평균이고, 그룹 성장 합은 세부 12개의 합입니다. 학습 3언어와 재능 4축은 별도로 전달합니다. 실제 성장 배분은 영어·중국어이며 일본어는 보존값입니다. 건설과 방어는 스냅샷을 읽어 자신의 시험 상태를 만들며 원본 성장에는 피해·보상을 쓰지 않습니다.

## 3. 현재 구현과 후속 구분

| 후속 | 이유 |
|---|---|
| 운영 경제 통합 | v02 성장 팬·이식 팬 총합·구형 칸 팬의 의미가 다름 |
| 전투 보상·피해 되쓰기 | 저장 정책과 성장/전투 계수 검증 필요 |
| 성장 능력→전투 피해 | 기존 방어 균형을 바꾸므로 별도 수치 검증 필요 |
| 실제 미니게임 완성 | 후보와 연결 함수가 있어도 게임 본체 완성과 다름 |
| 추가 영입 본 연출 | 현재 간이 4인 선택과 기획된 3회 서바이벌 구분 |
| 계정 서버·다기기 | 현재 브라우저 로컬 계약 범위 |
| 전조합 장기 균형·15추가부지 | 리소스20종과 실제 검증5부지를 구분 |

## 4. 문서와 제안 카드

P100/P107은 최신 실행을 앞에 두고 옛 상세를 접었습니다. P75/P105는 전체 안내를 갱신했고 P106/P108은 최신 성장과 구형 경제 경계를 드러냈습니다. P140은 필드·단위·소유권·연결 실패 시 동작을 명시합니다. 아이돌·오디션·건물·악귀·몬스 스킬 카드에는 현재 시연과 실행 경로를 보완합니다.

## 5. 보존한 것

과거 공용 보고·증거·이벤트게임 자산은 보존합니다. 오래된 설명용 시뮬레이터는 보조 도구로 접고, 기존 URL은 계속 열립니다. 60일 경제 실험은 비교 자료로 남깁니다.

## 6. 검사 기준

- 후보·몬스 ID와 학습 3언어가 이어지는가.
- 대표 합과 세부 합의 차이를 변환 계약이 설명하는가.
- 같은 보드 칸의 시설 단계만 건설·방어로 넘어가는가.
- 오래된 탭이 최신 상태를 덮어쓰지 않는가.
- 메뉴·제안서·현재 기획이 같은 실행 모듈을 여는가.
- 이벤트 자산 변경이 없는가.

## 2. 10/12 검토 의견 이력

1. **중심 경제 고리가 비어 있다.** 경제 · 건물 성장 · 아이돌 능력 · 팬과 수익 제안은 서로를 가리키며 하나의 고리를 설명하는데, 이 고리를 다루는 개발 기획서가 없다. 지금 있는 것은 주사위를 굴려 칸에 도착하기(P74)와 도착 연출(P72)까지다. 도착한 뒤 돈이 얼마 들어오고, 그 돈이 어디로 가는지는 아직 개발 기획이 없다.
2. **전투 · 디펜스 쪽은 세 갈래가 겹친다.** 월드 디펜스(P88 · 이벤트) · 나쁜 기운 디펜스(P104) · 몬스(P96)가 모두 「악귀와 몬스」 제안에서 나왔다. P104가 「같은 싸움이지만 건물 하나」로 경계를 그었으니, P88의 발동 조건이 정해지면 두 문서의 관계를 한 줄로 정리하면 된다.
3. **기획서만 있는 콘텐츠 2개(캐스팅권 대전 · 게릴라 공연)는 시뮬 모듈이 없다.** 오디션은 10/12 시뮬 v01이 생겼다(옛 안 → 10/12 17시 「시뮬 없음」). 공용 시뮬레이터(P94)에 모듈을 붙이는 것이 다음 개발 단계다.
4. **10/15 보완:** P81의 별도 건설/방어 시험은 밀착3동(30단계로 재정비 예정)·전체복셀까지 구현했다. 기존 무료 보드는3단계다. 건물 성장의 일반 경제·기능/수익 통합은 이 시각 시험의 완료와 구분한다(P106).
5. **P75 전체 안내가 10/07 기준에 멈춰 있다.** 「콘텐츠 5개」로 적혀 있어 지금 10개와 맞지 않는다. 이 점검 문서가 지금 기준이고, P75 갱신은 따로 필요하다.
6. **보드 기본 구성(P87)은 대표 기획서가 「작성 예시」다.** 보드 제안(40칸 8역할)을 그대로 따르는 대표 기획서로 바꿔 쓸지 정해야 한다.
