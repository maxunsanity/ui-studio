# 나쁜 기운 디펜스 · 난이도 성장과 스킬 연구소 설계 v01

작성: codex(단이) · 2026-10-12 · P104 재설계 검토안 · 제안(검수 대기)

**모든 편성은 한 방향에서 시작합니다.** 시간이 지나면서 대응해야 할 방향을 단계적으로 늘립니다. 방향 수, 총 적 물량, 적의 강도, 성장 기회를 따로 조절합니다. 지상은 실제 길을 따라 이동하며, 지상·공중 몬스터는 몸이 서로 관통하지 않도록 처리합니다. 이 문서의 새 규칙·수치·스킬 배정은 설계안이며 현재 게임에 적용하지 않습니다.

## 01. 기준과 현재 구현의 차이

| 항목 | 현재 나쁜 기운 디펜스 | 이번 설계 |
| --- | --- | --- |
| 적 출현 | 건물 중심 반경82의 가상 입구4곳에서 무작위 출현합니다. | 실제 지도에서 유효한 진입로를 골라 한 방향부터 개방합니다. |
| 적 이동 | 건물로 직진한 뒤 가상 원형 고리를 돕니다. | 지상은 차도·보행 가능한 길, 공중은 장애물을 고려한 비행 경로를 사용합니다. |
| 몬스터 간 충돌 | 전용 엔진에 몸 반경과 상호 분리 처리가 없습니다. | 출현 자리 확인·앞뒤 간격·교차로 대기·공중 회피·이동 뒤 겹침 보정을 적용합니다. |
| 아군 외형 | 전용 뷰에서 모델 배율1.6을 사용합니다. | 이 전투의 현재 외형 대비0.5배를 사용합니다. 현재 배율 기준0.8이며 원본·다른 뷰어는 보존합니다. |
| 스킬 성장 | 24초·64초에 두 번, 몬스 역할 강화 카드를 고릅니다. | 한 판 학습·강화5~10회, 액티브 최대5개와 독립 쿨타임을 검토합니다. |
| 공격 | 기본 레이저에 역할별 강화가 붙습니다. | 기본 공격 사이에 준비된 액티브 미사일을 섞습니다. |
| 시간 | 마지막 보스는66초에 출현하며 잔적 처치의 종료 시한이 없습니다. | 전투·선택·진입/결과를 합쳐5분 안에 끝나도록 상한을 둡니다. |

현재 확인 경로는 `src/game/bad-energy-v01/engine.mjs`, `src/ui/bad-energy-v01/preview.mjs`, `data/bad_energy/v01/{rule,wave,enemy,skill}.csv`입니다. 옛4입구·원형 고리·2회 선택은 현재 실행 기록으로 보존하고, 새 검토안의 확정값으로 섞지 않습니다.

현재 P88 전투에는 같은 길의 앞뒤 간격과 아군의 건물 회피 일부가 있습니다. 이는 P104 전용 엔진의 전체 몬스터 충돌 처리가 이미 완료됐다는 뜻이 아닙니다. 도시의 기존 `road_node`, `road_edge`, `source_geometry`, `city_integration` 자료를 재사용할 수 있는지 건물별로 대조합니다.

## 02. 난이도의 조절 단위

### 방향 수를 가장 먼저 조절합니다

방향은 **출현 구역·경로·이동층으로 구분한 진입로**입니다. 예를 들어 서쪽 지상 길과 북동쪽 공중 경로는2방향입니다. 같은 방위에 지상·공중이 함께 있으면 각각의 진입로를 구분하며, 연구소에는 총 방향과 지상/공중 수를 함께 표시합니다.

| 구분 | 의미 | 조절 항목 |
| --- | --- | --- |
| 사용 가능한 방향 | 지도와 편성이 허용하는 후보입니다. | 경로 목록·지상/공중 비율·후보 상한 |
| 개방된 방향 | 현재 단계까지 공개된 후보입니다. | 최초1방향·개방 시점·개방 순서 |
| 출현 중인 방향 | 지금 적을 공급하는 진입로입니다. | 동시 공급 상한·진입로별 배분 |
| 압박 중인 방향 | 적이 남아 있거나 출현 중이라 대응이 필요한 방향입니다. | 동시 압박 상한·진입로 종료 조건 |

출현을 꺼도 이미 들어온 적이 남아 있으면 그 방향은 계속 압박 수에 포함합니다. 특히1마리 편성에서 옛 방향의 적이 남았는데 새 방향까지 열려 사실상2방향이 되는 상황을 막습니다.

### 편성별 시안

| 출격 몬스 | 시작 | 기본 동시 압박 상한 · 시안 | 후반의 구성 |
| --- | --- | --- | --- |
| 1마리 | 1방향 | 1방향 | 첫 방향을 비운 뒤 다른 길 또는 공중 경로로 교대합니다. |
| 2마리 | 1방향 | 2방향 | 1→2방향으로 증가합니다. |
| 3마리 | 1방향 | 3방향 | 1→2→3방향으로 증가합니다. |
| 4마리 | 1방향 | 4방향 | 1→2→3→4방향으로 증가합니다. |
| 5마리 | 1방향 | 5방향 | 1→2→3→4→5방향으로 증가합니다. |

상한은 편성 수와 별도 설정으로 둡니다. 현중의 앞선「1마리면1방향」을 기본 시안으로 보존합니다. 최신「시간에 따라 방향 증가」를1마리의 동시 압박에도 적용하는 안은 **후반2방향 비교안**으로 연구소에서 확인한 뒤 검수합니다. 어느 쪽도 묻지 않고 확정하지 않습니다.

### 서로 다른 난이도 항목을 분리합니다

| 조절 항목 | 조절하는 것 | 분리하는 이유 |
| --- | --- | --- |
| 동시 압박 방향 수 | 주의를 나누고 표적을 바꾸는 부담 | 물량을 그대로 두고 방향 대응만 비교할 수 있습니다. |
| 전장 전체 출현 예산 | 초당 적 수 또는 적 비용의 합 | 방향이2배가 돼도 물량까지 자동2배가 되지 않습니다. |
| 적 구성 | 소형·빠른 적·튼튼한 적·공중·보스 비중 | 각 대응 스킬의 역할을 비교합니다. |
| 적 강도 | 체력·속도·건물 피해 | 방향 증가와 같은 순간에 모두 올리지 않습니다. |
| 성장 공급 | 카드 시점·횟수·새 스킬/강화 비율 | 새 방향에 대응할 수단을 먼저 줍니다. |
| 이동 시간 | 출현부터 건물 공격 가능 지점까지의 시간 | 출현 즉시 건물 앞에서 싸우는 문제를 줄입니다. |
| 공간 용량 | 길 폭·몸 크기·동시 적 상한 | 겹침 방지 때문에 실제 출현이 막히는 현상을 구별합니다. |

전체 출현 예산을 개방된 진입로의 가중치로 나눕니다. `진입로 예산 = 전장 전체 예산 × 해당 가중치 / 출현 진입로 가중치 합`입니다. 적 종류마다 비용을 두면 보스와 작은 악귀를 같은1마리로 계산하지 않아도 됩니다. 이 예산은 출현 편성용이며 실제 피해·승패 공식이 아닙니다.

첫 비교에서는 방향 수만 바꾸고 전체 물량·적 체력·스킬 조건은 고정합니다. 방향 구성이 정해진 뒤 물량, 그 다음 적 강도를 조절합니다. 경기 중 숨겨진 승률 보정은 기본안에 넣지 않습니다.

## 03. 시간에 따라 방향을 늘리는 흐름

### 5마리 편성의 기준 시안

아래 시간은 **전투가 실제로 흐르는 시간** 기준의 시안 예시입니다. 카드 선택 중에는 전투 시계와 출현을 함께 멈춥니다.

| 전투 시간 | 목표 압박 방향 | 지상/공중 예시 | 단계 목적 |
| --- | --- | --- | --- |
| 0~35초 | 1 | 지상1 | 기본 공격과 길의 흐름을 읽습니다. |
| 35~70초 | 2 | 지상1·공중1 | 다른 이동층을 소개합니다. |
| 70~110초 | 3 | 지상2·공중1 | 표적 분담과 범위 공격을 확인합니다. |
| 110~150초 | 4 | 지상2·공중2 | 얼음·불·번개 등의 조합을 확인합니다. |
| 150~180초 | 5 | 지상3·공중2 | 이미 배운 스킬로 최대 압박에 대응합니다. |
| 180~210초 | 기존 방향 유지 | 출현 종료·잔적 마무리 | 새 방향은 추가하지 않고 전투를 종료합니다. |

실제 맵에 없는 길을 만들거나 빈 건물 위를 지상 길로 사용하지 않습니다.5방향을 확보할 수 없는 연습실은 유효한 방향 수를 미리 표시하고 그 수 안에서 구성합니다. 부족한 방향을 적 물량 급증으로 몰래 대체하지 않습니다.

### 새 방향의 개방 순서

1. 개방 전에 대응 스킬을 고를 기회를 제공합니다.
2. 예고 시안3초 동안 안개 오브젝트 가장자리·진입로 방향 표시로 새 위협을 알립니다. 정확한 생성 좌표는 가립니다.
3. 길·출현 자리·최소 접근 거리·동시 압박 상한을 확인합니다.
4. 새 진입로는 배정 예산의 시안50%로 시작하고5초에 걸쳐 원래 배분으로 올립니다. 다른 진입로의 배분은 같이 낮춰 전체 예산을 유지합니다.
5. 개방 순서는 같은 난수 시드에서 재현됩니다. 지상만·공중만·혼합 프리셋을 비교할 수 있습니다.

예고 중에는 새 방향에 적이 나오지 않습니다. 기존 적 때문에 압박 상한을 넘으면 새 개방을 대기시킵니다. 대기에도 최대 시간이 있으며 마지막 종료 시각을 뒤로 늘리지 않습니다. 연구소는 예약·실제 개방·대기 이유를 각각 보여줍니다.

### 5분 이내의 시간 예산

| 항목 | 기본 시안 | 상한 계획 |
| --- | --- | --- |
| 실제 전투 | 210초 | 출현 정지180초·전투 종료210초 |
| 학습·강화 선택 | 8회 | 5~10회로 조절합니다. |
| 선택 제한 | 회당5초 | 제한 뒤의 추천 자동 선택은 검수 항목입니다. |
| 진입·결과 연출 | 합계12초 | 전투 시계와 별도로 실제 경과에 포함합니다. |
| 전체 | 210 + 8×5 + 12 = 262초 | 10회여도272초이며300초 이내입니다. |

설정 저장 전에 `전투 상한 + 선택 횟수×선택 제한 + 진입/결과 상한 ≤ 300초`를 검사합니다. 메뉴·사용자 일시정지·앱이 뒤로 간 시간은 플레이 진행 시간과 분리해 기록합니다. 이들을 포함한 현실의 시계 시간을 무조건5분으로 제한하지는 않습니다.

시간 종료 때 내구도가 남았다는 이유만으로 자동 승리시키지 않습니다. **시간초과를 방어 실패로 처리하는 제안**과 별도 결과 처리 중 현중이 검수합니다. 보상·수리비는 기존 경제 기획과 연결하며 새 값을 이 문서에서 확정하지 않습니다.

## 04. 실제 지도·안개·충돌 설계

### 출현 위치와 이동 경로

| 구분 | 설계 |
| --- | --- |
| 지상 악귀 | 기존 지도 좌표계의 차도/보행 가능 노드와 연결선을 따라 이동합니다. 건물·숲·보드 바깥을 통과하지 않습니다. 건물 옆의 유효한 공격 자리까지 이어지는 경로만 등록합니다. |
| 공중 악귀 | 지도 위3차원 비행 경로를 사용합니다. 옥상 높이·장식·숲을 피할 여유를 두고 생성합니다. 건물 공격 가능 지점은 출현 지점과 구분합니다. |
| 생성 위치 | 건물의 실제 외곽, 악귀 공격 거리, 아군 추격 가능 영역과의 관계를 확인합니다. 원형 고정 반경82를 모든 연습실에 그대로 쓰지 않습니다. |
| 접근 시간 | 안개 밖으로 나온 뒤 교전/공격 지점까지 이동하는 시간의 최소값을 설정합니다. 최소 시안4초는 연구소에서 비교하며 실제 길 길이와 속도로 계산합니다. |
| 아군 추격 | 건물 방어 영역과 추격 상한을 함께 둡니다. 출현 자리까지 따라가 계속 공격하는 행동을 막습니다. |
| 공격 활성화 | 생성→안개 속 이동→안개 밖의 교전 진입→건물 공격의 순서입니다. 생성 순간에는 교전 대상으로 등록하지 않습니다. 안개 안 적이 범위 피해만으로 먼저 죽는 상황도 같은 등록 기준으로 막습니다. |
| 유효한 길 부족 | 맵 미검증으로 표시하고 출현을 막습니다. 임의 좌표의 새 길로 대체하지 않습니다. |

지상·공중 공격 자리를 예약합니다. 건물 둘레의 제한된 자리가 꽉 차면 뒤의 악귀는 경로에서 기다리거나 승인된 다른 자리로 향합니다. 모두 건물 중심의 한 좌표에 포개지지 않습니다. 아군도 같은 표적 주변의 비행 자리를 나눠 사용합니다.

### 안개는 제작 가능한 오브젝트로 둡니다

- 출현 구역마다 어두운 복셀 구름·낮은 연무 묶음을 별도 오브젝트로 제작합니다. 지상은 길 입구 높이, 공중은 비행 고도에 맞춥니다.
- `fog_area_id`로 출현 구역과 연결합니다. 원본 모델·설정·투명도·크기·고도·예고 반응을 별도로 전달합니다.
- 안개는 생성 좌표를 가리지만 도로 경계·이미 나온 적·공격 예고를 읽을 수 있도록 합니다. 카메라가 바뀌어도 생성점의 노출 여부를 확인합니다.
- 안개는 시각 오브젝트입니다. 몬스터 몸의 충돌·길 막힘·공격 판정은 별도의 영역 데이터가 맡습니다. 안개 메시를 물리 벽으로 사용하지 않습니다.

### 서로 겹치지 않는 이동 처리

| 대상 | 처리 |
| --- | --- |
| 출현 | 몸 크기와 안전 간격이 들어갈 자리인지 확인하고 비어 있을 때1마리씩 배출합니다. 막혔다고 같은 점에 여러 마리를 생성하지 않습니다. |
| 지상 앞뒤 | 몸 반경 합+여유 간격만큼 떨어집니다. 앞 악귀가 얼면 뒤 악귀도 감속·대기합니다. |
| 지상 나란히 | 도로 폭이 허용할 때만 별도 줄을 사용합니다. 분리 보정 후에도 도로와 건물 경계를 지킵니다. |
| 교차로 | 선착순·예약으로 통과하며, 반대편 두 행렬이 정면으로 계속 밀지 않도록 통행 우선권을 둡니다. |
| 공중 악귀·아군 | 높이가 겹치는 몸에 대해3차원 거리로 회피합니다. 아군끼리도, 아군과 공중 악귀 사이에도 같은 몸 분리 기준을 적용합니다. |
| 지상↔공중 | 실제 높이 구간이 겹치지 않으면 통과할 수 있습니다. 같은 화면 좌표라는 이유만으로 모두 막지 않습니다. |
| 출격·공격·복귀 | 대기/공격/귀환 자리를 따로 배정하며 이동 중에도 몸 분리를 유지합니다. 원래 옥상 한 점에 동시에 돌아와 겹치지 않습니다. |
| 사망 연출 | 보이는 몸이 사라지는 시점까지 점유를 관리하고, 몸 대신 잔상/연무로 바뀐 뒤 충돌을 해제합니다. |

몸 반경은 실제 모델 배율의 몸통 외곽에서 구합니다. 귀·빛 꼬리·입자·미사일을 전부 몸 반경에 넣어 길이 지나치게 막히지 않게 합니다. 아군50% 축소에 맞춰 몸 반경도 다시 산정하며 피해·체력·사거리는 자동 절반 처리하지 않습니다.

각 고정 계산 틱에서 원하는 이동→주변 탐색→감속/회피→길/장애물 확인→겹침 보정→유효 위치 확정 순서로 처리합니다. 분리할 수 없는 경우 이전 유효 위치에서 기다립니다. 벽을 뚫는 위치로 밀거나 순간 이동시키지 않습니다. 고속 이동은 이동 구간을 검사하며 계산 틱 사이의 관통도 처리합니다.

주변 탐색은 공간 격자로 나눕니다. 회피 범위와 몸 크기를 분리하고, 큰 악귀·보스는 별도 통행 폭을 요구합니다. 자동 회피만으로 겹침이 완전히 사라진다고 가정하지 않으며 출현 점유·줄 간격·교차로 예약·최종 위치 확인을 함께 사용합니다. 이는 경로 탐색·회피·물리 충돌이 별개라는 [Godot 공식 이동/회피 문서](https://docs.godotengine.org/en/stable/tutorials/navigation/navigation_using_navigationagents.html)를 참고한 자체 설계입니다. 현재 웹 시안을 Godot로 전환한다는 제안은 아닙니다.

출현 대기열·길의 수용량·전장 최대 생존 수를 각각 제한합니다. 입구가 풀렸다고 밀린 적을 한꺼번에 내보내지 않습니다. 마지막 출현 시각 이후의 미출현 적 처리 정책과 수량을 기록하고, 이를 처치 보상으로 계산하지 않습니다.

### 악귀 외형 재설계

설정에 맞는 악귀 상세안과 보존12지신을 나쁜 기운에 잠식된 모습으로 바꾸는 안을 비교합니다. 검수 전12지신 원본을 바꾸지 않습니다. 종별 실루엣, 지상/공중 구분, 작은 적/큰 적/보스 크기, 눈·표정·균열·연무·피격 반응을 전달 기준으로 둡니다. 어두운 색만 칠해 아군과 구분하는 방식은 피합니다. 외형 제작은 난이도·몸 크기 기준 검수 뒤에 진행합니다.

## 05. 학습·액티브 미사일 성장

### 학습 횟수와 보유 슬롯

- 한 판의 학습·강화 선택은 기본8회, 조절 범위5~10회로 제안합니다. 새 스킬 습득과 이미 가진 스킬 강화가 합쳐진 횟수입니다.
- 전투시간20·40·60·80·100·120·140·160초의8회는 시안 예시입니다. 첫 성장 이후 다음 방향을 예고합니다.
- 액티브 최대5개는 **팀 전체5칸**을 우선 비교안으로 둡니다. 각 스킬은 사용하는 몬스1마리에게 연결합니다.1마리 편성은 한 몬스가 여러 스킬을,5마리 편성은 여러 몬스가 나눠 가질 수 있습니다.
- **몬스마다5칸**이라는 해석도 연구소의 비교안으로 둡니다. 슬롯 기준과「5~10개 학습」의 의미는 현중 검수 항목입니다.
- 빈 칸이 없으면 기존 스킬 강화 선택을 제공합니다. 이미 가진 스킬의 중복 선택은 강화로 처리하며 자동으로 버리거나 교체하지 않습니다. 최대 강화 단계·새 스킬 확률·특정 원소 제한은 표로 조절합니다.
- 원소/동물에 따른 스킬 후보는 `mons_skill_pool`로 연결합니다. 종별 최종 능력을 이 문서에서 확정하지 않습니다. 판 안 성장은 기존 방향에 맞춰 판 종료 때 초기화하는 안입니다.

### 기본 공격과 액티브를 섞습니다

기본 공격→준비된 액티브1개→기본 공격→다음에 준비된 액티브 순서입니다. 액티브가5개 모두 준비돼도 연달아5개만 발사하지 않습니다. **몬스별로 액티브 사이 기본 공격을 최소1회 발사**하며 기본 공격 시계와 스킬별 쿨타임 시계를 분리합니다.

발사 대상이 없으면 발사/쿨타임을 소모하지 않습니다. 발사한 뒤에는 대상이 사라져도 미사일별 재추적/종료 규칙을 따릅니다. 쿨타임은 발사 시점부터 세며, 피해 도착 시점과 구분합니다. 여러 액티브가 준비되면 우선순위·순환 방식으로 고릅니다. 동시에 쿨타임이 돌아온 모든 아군의 스킬이 항상 같은 프레임에 몰리지 않도록 시작 위상을 조절합니다.

## 07. 검수·판단 항목과 후속 순서

### 설계 검수 항목

1. 1~5마리 어떤 편성도1방향에서 시작합니다.5마리의 시안은1→2→3→4→5이며 편성 수 때문에 처음부터5방향이 되지 않습니다.
2. 전체 출현 예산을 고정한 채 방향만 늘렸을 때, 진입로마다 옛 출현량을 반복해 총 적 수가 몰래 배로 늘어나지 않습니다.
3. 출현이 끝난 길에도 살아 있는 적이 남으면 압박 방향 수에 포함합니다. 새 개방은 설정한 동시 압박 상한을 지킵니다.
4. 지상 경로는 실제 맵과 일치하고 공중 출현은 건물에서 떨어집니다. 생성점과 교전 진입점은 다르며 안개가 정확한 생성점만 가립니다.
5. 출현·직선 길·좁은 길·교차로·지상/공중 높이 겹침·추격·복귀·사망에서 몸 간격을 확인합니다. 앞 적 정지, 빠른 적의 추월, 큰 적/작은 적 혼합이 필수 확인 사례입니다.
6. 액티브 최대5개와 학습·강화5~10회를 따로 기록합니다. 스킬별 쿨타임이 있고 몬스별 액티브 사이에 기본 공격이 실제로 섞입니다.
7. 선택 시간과 연출까지5분 예산에 포함합니다. 출현 대기열과 잔적 때문에 종료가 무한히 늦어지지 않습니다.
8. 아군을 현재 크기의50%로 줄여도 종을 구분할 수 있습니다. 몸 반경을 함께 검토하고 빛 꼬리를 몸 충돌로 계산하지 않습니다.
9. 연구소에서 같은 난수 시드와 설정을 재현·저장하고 방향·밀집·피해·상태이상·시간을 비교합니다.
10. 실제 플레이·긴 시연·체감 난이도는 현중이 검수합니다. 수행하지 않은 검증을 완료라고 기록하지 않습니다.

### 현중이 검수할 세 가지 해석

| 항목 | 우선 비교안 | 다른 비교안 |
| --- | --- | --- |
| 1마리 편성의 후반 방향 | 동시1방향을 유지하고 적을 비운 뒤 지상/공중 입구를 교대합니다. | 후반 동시2방향으로 늘리고 물량·성장 공급을 별도로 조절합니다. |
| 액티브 최대5개 | 팀 전체5개이며 사용할 몬스를 각각 지정합니다. | 몬스마다 최대5개를 보유합니다. |
| 5분과 카드 선택 | 제한된 선택 시간 뒤 추천 선택, 전투 시한에 적이 남으면 방어 실패 처리안을 검토합니다. | 선택을 무한 대기하면5분은 전투 시간만이라는 점을 따로 표시해야 합니다. |
