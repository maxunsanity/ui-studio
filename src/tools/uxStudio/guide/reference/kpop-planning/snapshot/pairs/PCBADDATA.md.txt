# 악귀와 몬스 · 기획사 보유 몬스가 도시를 지킵니다

**이 문서는** 몬스의 기획사 소유와 실제 출전, 도시 방어의 관계를 설명합니다.

**보는 법** 보유·획득 → 실제 편성 → 전투와 스킬 → 구현 경계 순서로 읽습니다. [대표 기획서](/docs/planning/삼중AI_공용_20260929/산출/개발진행기획_v01/콘텐츠별_v03/몬스_기획서.html)를 함께 봅니다.

**지금 상태** 보유 선택·전투·스킬의 소스 연결은 확인했으며 실제7007 화면·전체 전투 검수는 이번 문서 작업에서 수행하지 않았습니다.

[공용 시뮬레이터 실행](/docs/planning/game-simulator.html?module=simulator_module_bad_energy)

## 1. 몬스는 기획사가 모으는 수호신

몬스는 아이돌 한 명당 한 마리씩 고정되는 파트너가 아니라 기획사가 모으는 수호신입니다. 아이돌 노래의 힘으로 도시를 지킨다는 세계관과 실제 보유·편성 규칙을 구분합니다.

## 2. 실제 보유한 몬스로 자동 디펜스

기획사 보유 종에서 출전 명단과 순서를 정합니다. 공통 선택은0~10이며 디펜스 정원은10입니다. 미보유 종이나 이전 멤버의 짝 몬스를 자동으로 채우지 않고 명시적으로 선택한0명도 유지합니다.

## 3. 첫 몬스와 오디션은 다른 흐름

첫 몬스는 게임 시작 튜토리얼에서 받습니다. 오디션은 멤버를 합류시키며 몬스를 주지 않습니다. 이후 몬스 팩에서 새 종을 얻거나 같은 종을 자동 합성하고, 공용 행복 재화와 종별 합성 기록은 따로 보관합니다.

## 4. 몬스와 건물이 함께 방어합니다

출전 몬스는 시설과 길목을 맡아 자동으로 싸우고 건물 지원 방어와 함께 도시를 지킵니다. 출전0명일 때도 없는 몬스를 만들지 않고 기존 건물 지원 방어를 진행합니다. 공격·탐지·난이도 수치는 기존 전투 표의 임시값을 따릅니다.

## 5. 편성 정원과 스킬 대상 상한은 다릅니다

현재 전투는 실제 보유 출전을 읽지만 스킬 종류 상한은 원표에서5입니다. 스킬 코드는 이 상한으로 명단도 앞에서 자르므로 출전10마리 전원에게 자동 스킬이 배분된다고 단정할 수 없습니다. 색별 다섯 공격 역할은 현재 고정 규칙으로 쓰지 않습니다.

## 6. 현재 실행과 후속 범위를 나눕니다

자동 스킬·팀 피니시와 건물 방어는 공용 디펜스에서 확인하는 범위입니다. 실제 전투 전체·0명과10명 조합·모바일 화면 검수와 서버 계정 저장은 따로 확인합니다. 원정·보상 경제를 이 제안서의 설명만으로 연결 완료로 표시하지 않습니다.
