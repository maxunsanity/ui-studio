# P97 · 몬스 사용 CSV

기존 게임 정의 표2개와 디펜스 모델·애니·뷰어·배치 표8개를 함께 확인합니다. 기존 5색 게임 표는 이전 기획으로 보존하고 현재 기본10종 모델은 mons_catalog로 연결합니다.

| 표 | 역할 | 원본 |
| --- | --- | --- |
| mons | 이전 5색 몬스 정의 | [CSV](/game/mons.csv) |
| mons_skill | 후속 스킬 기획·현재 빈 표 | [CSV](/game/mons_skill.csv) |
| mons_catalog | 기본10종 모델·이름·원소 색과 리소스를 연결합니다. | [CSV](/data/mons_proto/v01/mons_catalog.csv) |
| mons_animation | 공중 대기·이동·공격 대기·단발 공격·복귀 클립을 정의합니다. | [CSV](/data/mons_proto/v01/mons_animation.csv) |
| mons_visual | 재질·복셀 간격·동작 혼합 설정입니다. | [CSV](/data/mons_proto/v01/mons_visual.csv) |
| mons_copy | 디펜스 모델과 애니메이션의 공통 문구입니다. | [CSV](/data/mons_proto/v01/mons_copy.csv) |
| mons_viewer_ui_text | 기본10종·그 외12지신 갤러리·상태 전환·공격 미리보기 안내입니다. | [CSV](/data/mons_viewer/v01/mons_viewer_ui_text.csv) |
| mons_defense_binding | 기존 공중 방어 7자리와 몬스 종·배치 크기를 연결합니다. | [CSV](/data/mons_defense/v01/mons_defense_binding.csv) |
| mons_defense_animation_binding | 대기·이륙·순찰·추적·공격·복귀와 애니 루프를 연결합니다. | [CSV](/data/mons_defense/v01/mons_defense_animation_binding.csv) |
| mons_defense_ui_text | 기존 드론 자리를 몬스로 표시하는 화면 문구입니다. | [CSV](/data/mons_defense/v01/mons_defense_ui_text.csv) |
