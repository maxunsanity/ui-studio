# P212 · 게임 경제 · 대표 개발 기획서

**이 문서는** 게임 안 돈과 자원이 어디서 들어와 어디로 나가는지 한 장부로 정리한 대표 개발 기획서입니다.

**보는 법** 1장 그림 → 4장 「한 판 순서」 → 핵심제안 개발의 「자원 장부」 순서로 읽습니다. 세부 결정과 근거는 책갈피 [P200 게임 경제 보완판](../../기획서/산출_기획서_게임경제_보완판_v1_클로드.html)에 있습니다.

**지금 상태** 현재 개발되지 않음, 진행 중.

## 1. 개요

출처: (합침) 제안서 [게임 경제](/docs/planning/proposal-concept/economy.html) · 책갈피 [P200 게임 경제 보완판](../../기획서/산출_기획서_게임경제_보완판_v1_클로드.html) · 현중 11/01~11/02 지시

> **핵심** 새로 생긴 돈(게릴라 · 지역 방문 · 페스티벌 보상)도 **같은 지갑(코인)**으로 들어오고, 코인은 **건물에만** 씁니다. 곡 만드는 권 · 투표권 · 공유권 · 입장권은 코인으로 사지 않는 **별도 자원**입니다.

```mermaid
flowchart LR
  A[칸 · 잭팟 · 게릴라 · 방문 · 페스티벌] --> B[코인 한 지갑]
  B --> C[건물 증설 · 건설]
  C --> D[엔터파워]
  D --> A
```

### 콘텐츠 경계

- 맡는 것: 돈 순환 · 자원 장부(얻는 곳 · 쓰는 곳 · 배수 · 판매 · 시즌 끝).
- 다른 문서에 맡기는 것: 결제 → [P217 유료화](유료화_핵심제안서.html) · 배수 → [P209 배수 걸기](배수걸기_핵심제안서.html) · 저장 → [P222 유저 저장](유저저장_핵심제안서.html).

### 현재 기준과 목표

| 자원 | 얻는 곳 | 쓰는 곳 | 판매 | 시즌 끝 |
|---|---|---|---|---|
| 코인 | 칸 · 잭팟 · 게릴라 · 방문 · 페스티벌 | 건물 | 안 팜 | 리셋 |
| 주사위 | 무료(자동 충전 · 미션 · 이벤트 칸 · 하루 800~900) · 유료 | 굴림 | 유료 재화로 | 리셋 |
| 곡 만드는 권 | 데뷔조 · 패스 · 유료 | 곡 만들기 | 추가분만 | 무료분 리셋 |
| 투표권 · 공유권 | 매일 | 투표 · 공유 | 안 팜 | 리셋 |
| 입장권 | 36번 칸 · 시티 투어 상위 · 패스 | 지역 방문 | 직판 안 함 | 리셋 |

## 3. 구동 방법·시뮬레이션

화면 흐름: 보드 보상 → 지갑 → 건물 화면 · 스샷 미완 · 이식 비교 해당 없음

- 실행: [발란스 시뮬레이터](/docs/planning/idle-sim.html)에서 기존 돈 순환을 봅니다. 새 돈 출처(게릴라 · 방문 · 페스티벌)는 아직 넣지 않았습니다(미구현).
- 핵심제안 개발의 **자원 장부**에서 자원을 누르면 얻는 곳 · 쓰는 곳 · 배수 · 판매 · 시즌 끝을 한눈에 봅니다. 숫자는 모두 임시 시안입니다.

## 4. 상세 기획

### 한 판 순서 (임시 시안)

| 점검 | 내용 |
|---|---|
| 시작·종료 | 시즌 시작에 지갑 0 · 시즌 끝 리셋(유료 재화는 이월) |
| 입력·출력 | 입력 = 보상 / 출력 = 건물 · 권 사용 |
| 상태와 전이 | 얻음 → 지갑 · 자원 → 씀 |
| 판정 | 코인은 건물에만 |
| 오류·예외 | 순위 자원은 코인으로 못 삼 |
| 저장·복원 | 서버 정본 · 시즌 범위 |
| 다른 모듈 연결 | 보드 · 게릴라 · 방문 · 페스티벌 · 유료화 |

### 지켜야 할 선 (임시 시안)

코인 사용처를 늘리지 않습니다. 순환은 「수익 → 건물 → 엔터파워 → 더 큰 수익」 하나입니다.

### 필요 시스템

지갑 · 자원 장부 표 · 시즌 끝 처리.

### 화면·연출 목록

지갑 HUD · 자원 상세 팝업.

### 남은 결정

- 새 돈 출처 3개의 60일 비중 — 발란스 담당 확인
