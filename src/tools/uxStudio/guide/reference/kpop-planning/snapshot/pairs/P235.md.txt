# P235 · 숏츠 · 핵심제안 개발 기획서

**이 문서는** 아이돌·팀 채널을 구독하고 짧은 공개 영상을 발견하는 독립 숏츠를 설명합니다.

**보는 법** 그림과 표로 흐름을 보고 [상세 책갈피 P236](../../기획서/산출_기획서_숏츠_상세_v1.html)에서 예외를 확인합니다.

**지금 상태** 로컬 UI 시안과 기존 음악 화면 연결. 관심사·구독·독립 피드는 임시 데이터이며 실제 추천·게시·계정 구독은 미개발입니다. 음악 감상·허용 투표는 기존 공통 화면의 검사와 재생 경로를 재사용합니다.

<a id="part-1"></a>
## 1. 개요

**좋아하는 아이돌의 새 영상과 아직 모르는 아이돌의 영상을 함께 발견합니다.**

~~~mermaid
flowchart LR
 O["처음 · 관심사 선택/나중에"] --> F["추천 / 구독 / 친구·크루"]
 F --> S["세로 숏츠 감상"]
 S --> C["아이돌·팀 채널 구독"]
 S --> M["음원 보기"]
 S --> P["원공연 보기 · 권한 확인"]
~~~

| 숏츠 | 스테이지 | 음원 보기 |
|---|---|---|
| 공개 게시물 발견·구독·반응 | 고정 관람 그룹의 공연·채널·PIP | 곡·앨범·전체 영상·차트·투표 |

<a id="part-3"></a>
## 3. 구동 방법·시뮬레이션

~~~mermaid
flowchart LR
 V["위아래 넘김 · 영상 위 메뉴"] --> C["찜·댓글·공유·채널"]
 V --> M["곡 보기 / 원공연 보기"] --> R["뒤로 · 원래 영상/위치"]
~~~

| 첫 진입 | 감상 |
|---|---|
| 장르·무대 스타일 선택, 나중에 가능 | 기존 세로 폼·오버레이·공통 플레이어 |

**게임 하단 진입:** 미디어 → 스테이지 · 숏츠 · 음원. 스테이지·숏츠는 로컬 UI 시안이며 음원은 기존 음악 화면과 공통 플레이어를 사용합니다. 별도 음악 앱·원장·서버를 중복 생성하지 않습니다.

~~~mermaid
flowchart LR
 M["미디어"] --> S["스테이지·숏츠 UI 시안"]
 M --> A["기존 음악 3탭·공통 플레이어"]
 A --> G["게임으로 복귀"]
~~~

| 화면 | 최소 조작과 경계 |
|---|---|
| 음악 | 둘러보기·차트·보관함 3탭과 한 줄 목록. 제목/커버 한 번으로 전체 플레이어 |
| 투표 | 허용된 대상만 한 번 투표하며 투표는 취소할 수 없음. 기간·소유·자격·한도의 기존 검사 유지 |
| 게임 왕복 | 감상 중 게임 장식·플로팅 표시 숨김, 게임으로 복귀. 보드에서 미디어 재진입 가능 |
| 범위 | 현재 크루명을 유지. 실제 공연·추천·계정 소셜·대규모 정렬·분리 앱 서버는 미개발 |


음악 원본·게임 복귀·BGM의 경계는 [P236 상세 연결](../../기획서/산출_기획서_숏츠_상세_v1.html#media-music-integration)에서 확인합니다.

[숏츠 UI 시안 실행](/docs/planning/game-simulator.html?module=simulator_module_shorts_ui_preview)

| 시안 화면 | 표현 범위 |
|---|---|
| 관심사·추천/구독/친구·크루 | 임시 숏츠와 관계 10사례 |
| 찜·댓글·구독·공유 시트 | 세션 메모리 상태. 계정 기록·외부 공유 없음 |
| 관련 곡·공연·차트 | 기존 음악 3탭·한 줄 목록·전체 플레이어와 원공연 왕복. 예시 차트 7종은 UI 시안 |

기존 복셀 포스터와 라이선스 샘플 음원을 사용하며 실제 영상·실시간 방송은 아닙니다. 우측 외부 패널의 100명/100만 명 전환은 예시 조건이며 실제 추천·매칭·부하 시험이 아닙니다. [UI 시안과 실제 미개발 범위](../../기획서/산출_기획서_숏츠_상세_v1.html#local-ui-preview).

[저장 없이 UI만 미리보기](/docs/planning/media-ui-preview.html?module=simulator_module_shorts_ui_preview)

<a id="part-4"></a>
## 4. 상세 기획

~~~mermaid
flowchart LR
 A["관심사·구독·관계·새 아이돌 후보"] --> B["권한·시청 중복 확인"]
 B --> C["취향·새로움·창작자 다양성"] --> D["다음 영상 묶음"]
~~~

| 피드 | 보여 주는 순서 |
|---|---|
| 추천 | 취향·구독·관계·새 창작자를 혼합. 같은 창작자 반복 제한 |
| 구독 | 구독 채널만 미시청 우선 → 공개 최신순 |
| 친구·크루 | 관계 대상만 미시청 우선 → 공개 최신순 |
| 아무것도 없음 | 선택한 관심사. 관심사도 없으면 다양한 공개 영상으로 시작 |

관계나 구독이 있어도 그 대상의 영상이 없을 수 있습니다. [8조합·빈 상태](../../기획서/산출_기획서_숏츠_상세_v1.html#shorts-case-matrix).

## 5. 필요 리소스·이미지 설명

~~~mermaid
flowchart LR
 A["발매 영상·활동 장면·공연 하이라이트"] --> S["공개 숏츠 게시물"] --> P["기존 감상 폼"]
~~~

추가 제작·연출 리소스: 게시/관심사/채널 화면. [매체·원본 연결](../../기획서/산출_기획서_숏츠_상세_v1.html#shorts-content-channel).

<a id="part-6"></a>
## 6. 관련 CSV·테이블 데이터

~~~mermaid
flowchart LR
 A["공개 콘텐츠 색인"] --> B["관심사·관계별 후보 축소"]
 B --> C["개인별 순서 확정"] --> D["짧은 큐·다음 커서"]
~~~

| 동접 100만 명에서 | 적용 |
|---|---|
| 최초/다음 묶음 요청 | 미리 나눈 후보에서 개인별 목록 생성 |
| 영상 넘김 | 받은 큐의 다음 영상 사용 |
| 추천 갱신 | 현재 영상 유지, 다음 후보부터 반영 |

숏츠 전체 발견에는 스테이지의 고정100명 제한을 적용하지 않습니다. [100만 편성·데이터](../../기획서/산출_기획서_숏츠_상세_v1.html#shorts-million). 주사위 환산: 해당 없음.
