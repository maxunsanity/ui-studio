# P109 · 새 도시 진출

**이 문서는** 다른 도시 방문의 기획과 기존 핵심제안 시즌 모델의 표·계산을 설명하는 상세 기획서입니다.

**보는 법** [2장](#part-2)의 현재 대표·상세 문서와 원형 제안·그림 → [4장](#part-4)의 시험 계산·단위 → [7장](#part-7)의 연결 대기·미검수 범위 순서로 읽습니다.

**지금 상태** 기존 core 자동 방문 계산은 코드 경로가 있습니다. 현재 지역 선택 활동의 로컬 시험·기록은 P219/P193에서 구분합니다. 실제 20칸 방문·입장권·현지 공연 원장·귀환·저장 복원은 연결 대기이며, 실구동 확인 범위는 7장에 적었습니다.

## 1. 개요

출처: (신규) [새 도시 진출 기획 기록 MD](../../../../proposal-concept/city-expand.md)와 핵심제안 시즌 계산·지역 표.

내 도시를 영구히 옮기는 대신 다른 도시의 20칸 보드를 다녀오는 방향입니다. 방문 중에는 현지 활동으로 수익을 얻고 내 도시의 시설 성장을 계속 진행하지 않는 기획입니다. 진입 조건·방문 길이·지역별 값은 결정되지 않았으며 **발란스 대기**입니다.

```mermaid
flowchart LR
 A[내 도시에서 성장] --> B[다른 도시 열림 조건]
 B --> C[방문]
 C --> D[현지 보드 활동]
 D --> E[방문 정산]
 E --> F[내 도시로 돌아오기]
```

이 그림은 제안의 목표 흐름입니다. 실제 독립 화면·저장 복원까지 완성된 플레이를 뜻하지 않습니다. 시즌 모델은 임시 조건과 지역 데이터를 사용해 방문 수익을 계산합니다.

## 3. 구동 방법·시뮬레이션

화면 흐름: 내 도시 → 진입 조건 확인 → 다른 도시 활동 → 정산 → 내 도시 복귀. 전용 20칸 실방문과 원장·저장 복원 연결은 대기 상태입니다. 기존 core 자동 방문 계산과 P219의 지역 선택 로컬 시험·기록은 서로 다른 범위로 읽습니다.

### ▶ 발란스 툴 열기

책갈피에서는 [P110 시즌 경제 참고](../발란스/핵심제안_발란스구조_기획서.md)에서 계산과 시험값을 읽고, [P219 현재 대표](새도시진출_핵심제안서.md)에서 지역 선택 시험과 실제 방문 연결 대기를 확인합니다. 실제 계산 툴의 실행 입구는 핵심제안 개발의 원형 HTML에 보존합니다.

핵심제안 모델의 시즌 시험은 팀 능력에 따른 지역 열림과 입장권, 지역별 방문 굴림 수·현지 수익·정산 보너스를 임시 표에서 읽습니다. 이는 자동 계산 결과이며 플레이어가 20칸 보드 화면에서 직접 방문하고 저장을 복원했다는 뜻은 아닙니다.

```mermaid
flowchart LR
 A[임시 지역 표] --> B[시즌 모델]
 C[팀 능력과 입장권] --> B
 B --> D[방문 굴림과 수익 계산]
 D --> E[시즌 결과에 정산]
```

## 4. 상세 기획

### 한 판 순서

| 점검 | 내용 |
|---|---|
| 시작·종료 | 목표: 조건을 만족하면 방문하고 정산 뒤 내 도시로 돌아옵니다. 전용 화면은 작업 전입니다. |
| 입력·출력 | 지역·조건·방문 굴림과 현지 칸 데이터를 읽어 수익과 정산을 계산합니다. |
| 상태와 전이 | 시즌 모델은 지역 열림 → 입장권 소모 → 방문 진행 → 굴림 소진 후 정산을 계산합니다. |
| 판정 | 진입 조건 A·B·C와 문턱은 결정 대기입니다. 현재 시즌 모델은 임시 능력 문턱과 입장권을 사용합니다. |
| 오류·예외 | 지역 선택 실패, 중도 귀환, 주사위 부족 등 실제 플레이 처리: 작업 전. |
| 저장·복원 | 내 도시의 위치와 방문 중 기록을 실제 저장·복원하는 기능: 작업 전. |
| 다른 모듈 | 아이돌 능력·보드·수익·내 도시 성장과 연결을 검토합니다. |

### 방문을 여는 조건 · 결정 대기

| 선택지 | 내용 | 결정 상태 |
|---|---|---|
| A 능력 | 팀 능력이나 성장 기준에 도달하면 지역이 열림 | 결정 대기 |
| B 찬스 | 찬스로 입장 기회를 얻음 | 결정 대기 |
| C 둘 다 | 능력으로 지역을 열고 입장권으로 방문 | 기획안 · 결정 대기 |

시즌 모델은 임시로 팀 능력에 따른 열림과 입장권을 함께 사용합니다. 같은 코드의 입장권 획득 위치 등은 시험 모델의 과거 가정이므로 현재 보드의 확정 입장 규칙으로 보지 않습니다. 그룹 능력 문턱, 획득 확률과 지역별 조건은 발란스 대기입니다.

현재 core는 멤버별 능력 합의 멤버 평균으로 지역 문턱을 비교합니다. 지역 표의 unlock_stage_id를 직접 판정하지 않으며, 자동 방문 정책에서는 열린 지역 중 표 순서가 가장 뒤인 지역을 선택합니다. 입장권 획득 위치는 city_ticket_tile_id 시험 설정과 지역 확률을 사용하는 경로로, 실제 지역 선택·외국어·운영 조건과 구분합니다.

```mermaid
flowchart LR
 A[팀 능력] --> B[지역 열림 시험]
 C[시험 입장권] --> D[방문 가능 여부]
 B --> D
 D --> E[방문 세션]
```

### 20칸 구성과 현지 활동 · 시험 표

`city_visit_tile.csv`에는 공용 20칸의 시험 틀이 있습니다. 출발·쉼·행운·정산의 코너 4칸, 무대 8칸, 거리 활동 6칸, 찬스 2칸으로 나뉩니다. 표의 지역 ID 빈칸은 공용 틀을 뜻합니다. 칸 구성과 효과는 기획·시험 자료이며 최종 확정이 아닙니다.

| 구분 | 시험 틀의 역할 |
|---|---|
| 코너 | 시작·쉼·행운·정산 자리 |
| 무대 | 현지 활동과 판정이 있는 자리 |
| 거리 활동 | 현지 수익을 시험하는 자리 |
| 찬스 | 현지 기회 자리 |

핵심제안 모델은 지역의 현지 팬·수익 배율과 칸 가중치·판정을 사용해 수익을 계산하고 방문 굴림이 끝나면 정산 보너스를 계산합니다. 현지 능력 증가의 6축 값은 세부 능력으로 옮길 기준이 없어 계산하지 않고 발란스 대기로 기록합니다. 지역 이름·팬·배율·보너스·방문 수는 임시이며 발란스 대기입니다.

현재 core 방문 돈은 (칸 기본 % + 고정 지역 팬 곡선 %)에 칸 가중·지역 배율·조건부 판정·주사위 배수를 반영하고 S 대비 %로 환산합니다. local_fan_base는 새로 지급되는 팬이 아니라 고정 시험 입력입니다. 방문 함수는 현지 팬이나 세부 능력을 지급하지 않고 능력 대기 로그만 남깁니다.

20칸은 판의 크기, visit_rolls는 방문 굴림 수, 원형의 시간 예시는 별도 기획입니다. 모델은 방문 중 본진 이동·시설 성장을 진행하지 않고 방문 굴림마다 돈을 더합니다. 남은 방문 굴림이 끝나면 누적 방문 수익에 정산 보너스 %를 추가하고 본진 진행으로 돌아갑니다.

```mermaid
flowchart LR
 A[지역 설정과 현지 칸] --> B[현지 팬과 칸 가중치]
 B --> C[판정과 수익 계산]
 C --> D[방문 수익 누적]
 D --> E[남은 굴림 종료]
 E --> F[정산 보너스]
```

### 필요 시스템

지역 열림·입장 기회, 방문 진행, 현지 보드 이동, 현지 수익, 정산과 내 도시 복귀가 필요합니다. 전용 20칸 실방문·원장·실제 저장 복원 연결은 확인 대기이며, P219의 지역 선택 로컬 시험과 구분합니다. 다른 도시를 [원정](../../../../proposal-fansim-expedition.html)과 같은 기능으로 취급하지 않습니다.

## 6. 관련 CSV·테이블 데이터

| 파일 | 역할 | 연결과 주의 |
|---|---|---|

| `data/game/board_tile.csv` | 내 도시 보드 칸과 시설 연결 | `tile_id`, `pos` · 방문 표와 별도 |

지역·현지 칸·팬 곡선·성장 단계의 core_proposal 원표는 직접 reader가 시즌 계산에 읽습니다. 스키마 현황의 미등록 상태와 실제 계산 소비를 구분하며, 열 목록이나 일부 ID 소속 대조를 정식 PK/FK 등록·운영 전수 검증으로 보지 않습니다. 빈 지역 ID는 공용 틀이며 필수 숫자칸이 비면 reader는 값을 만들지 않고 멈춥니다.

주사위 환산: 미완 · 방문 굴림 수는 표의 임시 시험값이며 실제 지급·소비 기준은 발란스 대기입니다.

## 7. 개발 진행·검수

확인 범위는 원문·허용 표·기존 core reader/계산의 정적 대조입니다. 지역 선택 로컬 시험·기록은 현재 P219/P193의 범위와 구분해 읽었습니다. 보호된 상위 직접 연결, 실제 20칸 이동·입장권·지갑 지급·현지 공연 원장·저장 복원·중도 귀환은 검수하지 않았습니다. 시즌 총굴림이 먼저 끝나는 경우의 방문 종료도 별도 확인 대상입니다.

| 요소 | 상태 | 확인 범위·다음 작업 |
