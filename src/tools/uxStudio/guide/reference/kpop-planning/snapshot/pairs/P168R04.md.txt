## 2026-10-27 · 모바일 카드덱 모음 구성 및 실제 연결

현중이 모바일 구성안을 확인한 뒤 기획서 등록과 시뮬레이터 적용을 직접 지시했습니다. 구현·기능시험·실제 화면 확인을 마쳤으며 산출은 제안(검수 대기)입니다.

### 사용자가 보는 순서

**덱 모음 → 선택 덱의 12장 → 카드 상세**를 기본 탐색으로 사용합니다. 위쪽의 카드/아이돌 능력 전환과 공통 재화·게이지·하단 메뉴는 유지합니다.

| 화면 | 배치와 필수 정보 | 조작 |
|---|---|---|
| 덱 모음 | 2열×2행으로 덱4개씩 표시합니다. 전체20덱은5페이지입니다. 표지·실제 연결 이름 또는 빈 자리·서로 다른 카드 수 n/12를 표시합니다. 전체 수집 수와 완성 덱 수도 같은 보유 기록에서 계산합니다. | 전체·멤버·만드는 일·회사·팬으로 분류하고 이전/다음 페이지를 선택합니다. |
| 덱 안 | 4열×3행으로12자리를 한 화면에서 확인합니다. 카드 번호·그림·별·이름·보유 상태·실제 총 장수를 표시합니다. 미보유 자리를 당겨 없애지 않습니다. | 한 장을 눌러 상세를 엽니다. 덱 모음으로 돌아오면 기존 분류·페이지를 유지합니다. |
| 카드 상세 | 그림·별·이름·덱과 번호·총 보유 장수·강화 능력·효과 대상·실제 성장 반영 상태를 표시합니다. 수치가 없는 효과를0으로 만들지 않습니다. | 12장 보기로 한 단계 돌아가거나 덱 모음으로 이동합니다. |
| 아이돌 능력 | 기존의 같은 세션 실제 멤버·6축·선택 축의3세부·현재/재능/단계 한도를 유지합니다. 최대 소수점 한 자리 표시를 적용합니다. | 카드로 돌아오면 진입했던 탐색 화면과 선택을 유지합니다. |

전체20덱은 멤버 합류 자리5개와 사업15개이며, 현재 팀원이 적어도 덱 정의를 줄이거나 뒤 자리를 당기지 않습니다. 분류의 현재 정의는 멤버5·만드는 일7·회사6·팬2입니다. 카드북 수집 종류 수와 중복을 포함한 총 장수는 구분합니다.

### 2026-10-27 후속 · 수집 전 공통 물음표 이미지

- 덱의 카드가0장이거나 보유가 미연결이면 공통 물음표 표지를 사용합니다. 해당 덱에서 카드를 한 장 이상 받으면 그 덱의 원래 표지를 표시합니다.
- 덱 안12장과 카드 상세도 같은 개별 보유 기준을 적용합니다. 보유0/미연결은 공통 물음표, 보유1장 이상은 해당 카드 그림입니다. 중복 장수가 늘어나도 같은 공개 상태를 유지합니다.
- 공통 이미지는 /data/simulator/assets/card-unrevealed.svg 한 장이며 표시 설정의 assets.unrevealed로 연결합니다. 미보유 물음표에 원래 그림을 흐리게 비치지 않습니다.
- 현재 아이돌 능력 정보의 확인된 멤버 그림과 오른쪽 검수용 원본 그림은 유지합니다. 이름·별·효과 설명·빈 자리/연동 대기 구분과 게임 수치는 이 이미지 공개 조건으로 바꾸지 않습니다.

### 모바일로 옮기는 정보와 검수 패널

모바일에 필요한 덱 분류·표지·수집 진행·12장 보유 상태·카드 효과/대상·아이돌 능력을 연결합니다. 오른쪽은 원본 자료와 검수 조작을 유지합니다. 테스트용 카드 획득·카드북 비우기·표지5단계 미리보기·원문 effect_amount·run/revision·CSV 키는 게임 조작처럼 새로 만들지 않습니다. 기존 테스트 획득은 오른쪽 검수 조작으로 구분합니다.

### 데이터·성장 계약

- 새 덱·새 카드·새 보상·성장 수치를 추가하지 않습니다. card_theme.csv의20덱과 card.csv의각12행, 현재 카드북의 세션별 보유 기록을 재사용합니다.
- 실제 멤버 이름은 같은 세션 성장 VM의 합류 자리 연결을 따릅니다. 그림에 적힌 옛 샘플 이름을 현재 아이돌로 확정하지 않습니다. 빈 자리와 실제 기록 미연결을 구분합니다.
- n/12는 보유 장수가1장 이상인 서로 다른 카드 자리 수입니다. 카드의 보유N장은 중복을 포함한 실제 총 장수입니다.
- 능력 주 효과는 팀 전원×각자의 흡수율, 라포·성격 보조는 해당 자리 멤버에게 가는 기존 계약을 유지합니다. 사업 덱12장은 덱 전체 효과를 모으는 조각이며 매 조각에 전체 효과를 반복 적용하지 않습니다.
- 실제 성장 적용의 전후 기록이 없으면 성장 반영 연결 대기입니다. 임시 effect_amount를 실제 성장 증가량으로 표시하지 않습니다.
- 표시용 분류·문구·4개 페이지 크기는 cardbook-collection-ui.json에서 관리합니다. 게임 CSV·확률·계산·저장 계약은 바꾸지 않습니다.

### 공간과 상태 보존

390×844 전체 폰 안에서 공통 상단·하단을 먼저 확보합니다. 덱 탐색에서는 중복 설명과 빈 조작 영역을 줄여 격자에 높이를 배분하고, 카드 상세와 능력 보기에서는 필요한 필러와 조작 영역을 복원합니다. 그림을 늘려 격자의 높이가 커지지 않게 제한하며 작은 창·긴 예외 문구에는 필요한 내부 스크롤을 허용합니다.

덱/분류/페이지/카드/능력 전환은 표시 상태만 바꿉니다. 팩 확인 중에는 카드 내부의 새 탐색·다른 팩 개봉·능력 전환을 잠그고 확인 조작만 다음 카드로 진행합니다. 외부 호스트 전체 탐색의 전역 차단을 새로 추가하는 범위는 아닙니다. 비활성화/복귀/스냅숏 갱신이 카드 획득을 재실행하거나 탐색을 초기화하지 않아야 합니다. 기존 어댑터가 이동한 설명·버튼 노드와 복원 위치를 보존합니다.

## 독립 시안의 기록과 범위

이 폴더의 index.html은 읽기 전용 구성안입니다. observed-ui.json의 덱별 수집과 멤버명은2026-10-27 14:39 도구 화면의 검수 기록입니다. 작사 덱12자리 외 개별 보유는 null로 두고 「보유 미연결」로 표시합니다. 미연결을0으로 채우지 않습니다. 아이돌 능력은 같은 run/session의 기록을 읽을 수 있을 때만 표시합니다.

preview.mjs는 카드북의 실제 mount를 호출하지 않습니다. 저장/삭제 어댑터는 예외로 차단합니다. 팩·실제 카드 획득·성장·정산을 실행하지 않습니다. 실제 연결에서 미정 효과량을 발명하지 않습니다.

## 기존 안 보존

이전 카드 화면은 큰 표지/선택 카드와 오른쪽 덱/12장 목록을 중심으로 사용했습니다. 새 모바일 탐색을 추가하되 기존 원본 카드 그림·효과 계약·오른쪽 검수 자료는 보존합니다.
