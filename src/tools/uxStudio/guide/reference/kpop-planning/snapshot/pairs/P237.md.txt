# P237 · 월드 인기·우승 · 기획 시뮬레이터

**이 문서는** 왼쪽 모바일 화면과 오른쪽 시험 입력으로 인기 기여·곡 등급·월드 순위를 비교하고, 단독 예시와 현재 연결 데이터를 구분하는 기획서입니다.

**보는 법** 1장 흐름 → 3장 [시뮬레이터 실행](/docs/planning/game-simulator.html?module=simulator_module_world_popularity_trial) → 4장 계산 → 7장 검증 순서입니다. 기존 [월드 기획 P207](월드페스티벌_핵심제안서.html#world-popularity-first)과 [상세 P191](../../기획서/산출_기획서_음원×페스티벌_v1_클로드.html#festival-popularity-first)을 함께 봅니다.

**지금 상태** 개발됨(공용 모바일 미리보기·오른쪽 입력·단독 시험·현재 세션의 팀/발매곡 읽기). 발란스 전송은 기존 전용 세션을 읽으며, 원본에 없는 인기·추천·찜 집계는 입력 대기입니다. 실제 인기 원장·회원 집계·최종 정책·게임 저장 연결은 현재 개발되지 않음, 진행 중입니다.

### 단독 테스트

1. 오른쪽 「단독 테스트 · CSV 예시」를 선택합니다. 예시 개인·크루·곡·시작값으로 바로 비교합니다.
2. 오른쪽 시험 활동으로 인기를 모으고, 왼쪽에서 곡에 기여합니다. 보유량·등급·점수가 즉시 바뀝니다.
3. 왼쪽 하단 「월드 순위」로 순위를 확인하고 곡을 눌러 돌아옵니다.
4. 출전곡과 시작값·규칙을 바꿔 비교하고, 오른쪽에서 마감 결과를 고정합니다.

### 발란스·현재 데이터 연결

| 순서 | 기존 기능을 사용하는 방식 |
|---|---|
| 발란스 전송 | [발란스 시뮬레이터](/docs/planning/idle-sim.html)의 기존 「시뮬 전송」으로 게임 시뮬레이터를 연 뒤 같은 화면에서 「월드 인기·우승」 선택 |
| 현재 세션 읽기 | 오른쪽 「현재 연결 데이터 · 발란스 전송 포함」. 동일 testPage·세션·실행·원본 버전의 팀/발매곡만 읽음 |
| 없는 입력 | 원본에 없는 인기 지갑·기여·추천·찜은 빈칸. 출전자 유형과 시험 시작값을 입력하고 「입력값으로 비교 시작」 |
| 곡이 없는 경우 | 연결 팀은 유지하고 제목을 직접 입력한 시험곡으로 비교. 실제 발매곡으로 기록하지 않음 |
| 원본 변경 | 다시 읽기 전 조작 중단. 다른 세션·곡·버전의 점수를 섞지 않음 |

메뉴 왕복은 현재 host 인스턴스의 비교를 유지합니다. 새로고침하면 단독 예시는 CSV부터, 발란스 전송은 현재 원본 확인부터 다시 시작합니다. 연결 정보는 읽기만 하며 오른쪽 입력과 왼쪽 행동은 이 모듈의 메모리에만 반영됩니다. 실제 게임 지갑·발란스 판에 되돌려 쓰지 않습니다.

### 한 판 순서 · 확정(기획 시뮬레이터 구현)

| 점검 | 처리 |
|---|---|
| 시작·종료 | 단독 CSV 또는 현재 연결 정보+명시 시험값 → 비교 → 명시 마감 → 새 비교 |
| 입력·출력 | 인기 획득·기여·추천·찜·규칙 → 등급·항목별 점수·순위 |
| 상태와 전이 | 비교 진행 중 / 미정값으로 집계 대기 / 마감 결과 고정 |
| 판정 | 지갑 부족·기여량 오류·미정 기준·중복 요청·잘못된 등급 문턱 차단 |
| 오류·예외 | 반영하지 않은 동작은 이전 상태를 보존하고 이유 표시 |
| 저장·복원 | 메모리만 사용, 새로고침 복원 없음 |
| 다른 모듈 연결 | 기존 host의 scope/세션·발란스 전송 원본에서 팀/발매곡 읽기. 실제 인기 지갑·회원·월드 원장 쓰기는 제작전 |

### 점수와 인기 등급 · 확정(시험 계산 구현) · 운영 기준 결정 대기

| 항목 | 계산 |
|---|---|
| 인정 인기 | 곡 누적 기여와 인기 인정 상한 중 작은 값 |
| 인기 반영 | 인정 인기 ÷ 인기100% 기준, 최대1 × 인기 비중 ÷ 비중합 ×100 |
| 추천 반영 | 고유 추천 인원 ÷ 반응100% 기준, 최대1 × 추천 비중 ÷ 비중합 ×100 |
| 찜 반영 | 고유 찜 인원 ÷ 반응100% 기준, 최대1 × 찜 비중 ÷ 비중합 ×100 |
| 종합 | 위 세 항목의 합. 표시 단위100점이며 실제 운영 배점 아님 |
| 인기 등급 | 인정 인기가 도달한 가장 높은 등급 문턱. 등급 보너스를 추가하지 않음 |
| 다음 등급 | 다음 문턱−인정 인기. 인정 상한이 그 문턱보다 낮으면 사유 표시 |
| 순위 | 점수 내림차순. 같은 점수는 공동 순위이며 임의 단독 우승자를 정하지 않음 |

처음 보이는 값은 [시험 정책 CSV](/data/simulator/world_popularity_trial_policy.csv)에서 읽습니다. 반응·재화·능력의 원단위를 그대로 더하지 않습니다. 인기 비중을 바꾸면 모든 곡을 같은 기준으로 다시 비교합니다. 비중이 비었거나 필요한 기준이 없으면 가짜0점·공식 순위를 만들지 않습니다.

- 획득만으로 곡 점수가 오르지 않고, 기여하면 선택한 지갑에서 차감되어 지정곡에만 반영됩니다.

- 같은 청취자 반응은 중복되지 않고 추천 취소가 찜을 지우지 않습니다.
- 미정 비중은 집계 대기, 마감은 결과 고정, 크루원 수는 점수 배수가 아닙니다.
