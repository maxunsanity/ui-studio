# 악귀 행렬과 장치 방어 v03
상태: 제안(검수 대기) · 지시 ID: 직접지시-악귀행렬-v03 · 작성: 단이(codex)

## 이번 기준
현중의 2026-10-07 직접 요청과 첨부를 따릅니다. 다수 악귀가 다섯 입구에서 줄지어 나타나 차도를 계속 순환합니다. 출현량이 초기 처치량을 앞서 도로에 적과 발밑 구름이 축적됩니다. 하늘 구름과 몬스 방어/스킬/합창 공격은 이번 실행에서 제외합니다. 원래 시안은 별도 보존합니다.

## 구조와 작업 순서
1. 기존 22대지(시설20·생활37/39), 15방공포·7드론, 도시40건물·도로·중앙 숲·공연장을 보존합니다.
2. entity_config에 드론(PET)과 방공포(NPC)를 정의하고 entity_instance로 건물 소켓에 연결합니다. movement_pattern·attack_pattern·skill·skill_effect를 따로 읽습니다. 모노카피바라의 엔터티/패턴/스킬 ID 연결 구조를 참고하며 기존 게임 데이터는 변경하지 않습니다.
3. 원본 차도에 닫힌 순환 경로를 계산합니다. 출현 → 이동 → 압박 → 장치 스킬 강화 → 출현 중단 → 잔적 소탕 → 실제 전멸 확인 → 클리어로 진행합니다. 기존 약5분 목표를 시안 계산으로 맞추며 타이머만으로 승리하지 않습니다.
4. 드론은 옥상에서 이륙하여 개별 높이·속도·판단 주기·접근 방향으로 순찰/추적/표적 변경/복귀합니다. 쌍포 기관총은 두 총구에서 실탄 궤적·섬광·반동을 표현하고 드론은 청록색 펄스 레이저를 사용합니다.
5. 악귀 HP막대·흰색/주황/청록 피격 숫자·발밑 연무·아래로 꺼지는 소멸을 구현합니다. 전체/도로 확대/건물 선택/장치 디자인 보기를 제공합니다.
6. CSV 스키마·ID·연결·차도/건물 충돌·시간/압박/잔적·저장 복구를 자동 검증하고 1440×900/430px 캡처와 공유 완료 보고를 남깁니다.

## 판단과 남은 검수
수치·화력·스킬·시각 치수는 모두 시안 예시입니다. '111 프로'는 뜻이 명확하지 않아 별도 기능으로 추정하지 않습니다. 첨부는 행렬 밀도와 피격 표현 참고입니다. 본게임 연결·최종 밸런스·몬스 재투입은 현중 검수 뒤 결정합니다.

## 파일과 본게임 적용 경계
- 계산 모듈: src/game/defense-proto-v03/data.mjs, engine.mjs입니다.
- 표시 모듈: src/ui/defense-proto-v03/preview.mjs, models.mjs, effects.mjs, labels.mjs입니다.
- 검사/내보내기: scripts/defense-proto-v03/io.mjs, test.mjs, simulate.mjs, export-assets.mjs입니다.
- 데이터: data/defense_proto/v03/입니다. 각 표는 schema.json의 자료형·ID·외래키 검사를 받습니다.
- 모델: data/res/defense_v03/res_drone_patrol_v03.glb, res_twin_machinegun_v03.glb, manifest.json입니다.
- 연결은 entity_config → model → asset → GLB 경로입니다. 미리보기는 같은 model 표를 읽는 3D 생성 함수를 사용합니다. 내보낸 GLB에는 관절이 있으며 비행/조준/발사는 패턴 엔진이 구동합니다.
- 본게임 경제·저장·UI·도시/보드 데이터에는 적용하지 않습니다. 독립 시안에서 검수할 수 있는 시스템과 자원을 마련합니다.
- 모노카피바라는 entity_config / enemy_pattern_config / pet_defense_config / petStrikeStyle의 ID로 연결한 표 구조를 읽기 전용 참고합니다. 원본 게임 규칙을 전부 복사한 것으로 주장하지 않습니다.
- 하늘 구름·몬스5 공격/스킬·합창 공격·위로 올라가는 소멸·기존 충전 포격은 이전 시안에 보존합니다.
- '111 프로'는 뜻이 명확하지 않아 별도 기능으로 추정하지 않습니다. 이후 현중 확인 대상입니다.
