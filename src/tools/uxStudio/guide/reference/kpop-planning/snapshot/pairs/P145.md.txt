# P145 · 찬스 카드 · 대표 개발 기획서

**이 문서는** 보드의 찬스 칸(8·23·38)과 팬덤 반응 칸(3·18·34)에 도착했을 때 뽑는 카드 27장(팬덤 반응 13 · 스케줄 변경 14)이 무엇이고, 각 카드가 [아이돌 능력](아이돌능력_기획서.html)의 어느 부분을 키우는지 정한 대표 개발 기획서예요.
**보는 법** 1장 개요 → 2장 관련 문서 → 3장 찬스 칸 시뮬레이터 사용법 → 4장 상세 기획(한 판 순서·보드 자리·카드 27장·성장 연결·루머) → 5장 그림 → 6장 표 → 7장 진행 순서로 읽어요. 같이 여는 시뮬레이터: [찬스 칸 시뮬레이터](../../../../game-simulator.html?module=simulator_module_chance_event).
**지금 상태** 두 덱의 카드 표, 켜진 카드만 모아 무게대로 1장 뽑기, 도착 요청·영수증 저장, 「루머」 카드 켜짐까지 동작해요. 개발 안 됨: 카드 효과의 실제 지급(지금은 효과를 보류하고 보여 주기만 함), 카드별 수치·덱 확률·나쁜 카드 비중(발란스 대기), 카드 그림과 뽑기 연출.

## 1. 개요

### 콘텐츠 경계

모노폴리GO의 찬스(Chance)·공동기금(Community Chest)을 우리 보드에 옮겨요(이식). 칸에 도착하면 그 칸 덱에서 카드 1장을 뽑고, 효과는 모두 **아이돌 성장**(6축 18세부 · 숨긴 값 태도·성실성 · 컨디션(숙소 휴식 배율) · 외국어 · 멤버 서사 · 찜 · 9건물 단계)으로 이어져요.

| 모노폴리GO | 우리 | 칸 | 톤 |
|---|---|---|---|
| Community Chest | **팬덤 반응** (`chance_fandom`) | 3 · 18 · 34 | 팬이 보내는 반응 · 대부분 좋은 쪽 |
| Chance | **스케줄 변경** (`chance_schedule`) | 8 · 23 · 38 | 일정이 끼거나 비거나 겹침 · 이동 포함 |

- 맡는 것: 두 덱의 카드 목록, 카드별 효과 규칙, 뽑는 방법, 카드가 닿는 성장 요소.
- 맡지 않는 것: 쟁탈전 규칙([쟁탈전](캐스팅권대전_기획서.html)), 나쁜 기운 게이지 규칙([나쁜 기운 디펜스](../../../../bad-energy-defense.html)), 수치(발란스 기획).

### 현재 기준과 목표

- 확정(시뮬): 칸 번호 8·23·38 = 스케줄 변경, 3·18·34 = 팬덤 반응. 시뮬레이터 코드가 덱과 칸이 맞지 않으면 요청을 막아요.
- 확정(표): `chance_card.csv`에서 `enabled=1`인 카드만 뽑기 후보예요. 지금 켜진 카드는 F01~F13, S01~S14, 그리고 「루머」(chance_rumor)예요. 옛 묶음 카드(chance_call·insert·empty·overlap·cheer·topic)와 pool_a01~d11은 꺼져 있어요(enabled=0).
- 목표: 카드 효과가 실제로 아이돌 성장·코인·팬에 지급되도록 결과 연결(개발 안 됨).

## 3. 구동 방법·시뮬레이션

화면 흐름: [보드·주사위] → [찬스 칸 화면] → [보드·성장 화면으로 돌아감] · 스샷 미완 · 이식 비교 해당 없음

1. 보드에서 3·18·34(팬덤 반응) 또는 8·23·38(스케줄 변경)에 도착하면 「도착 요청」이 만들어져요. 요청에는 도착 칸, 출발 칸, 굴림 수, 굴림 배수(1 이상), 돌아갈 화면(주사위·아이돌 성장·쟁탈전 중 하나), 도착 전 지갑(코인·팬·주사위)이 담겨요.
2. 화면에는 덱 이름이 적힌 덮인 카드가 떠요. 「공개」 버튼을 누르면 그 덱에서 켜진 카드만 모아 `weight` 칸의 무게대로 1장을 뽑아요. 무게 칸이 없으면 같은 비중으로 뽑아요.
3. 뽑힌 카드의 이름과 효과 문장이 카드 앞면에 보이고, 아래 접힌 「자세히」에서 후보 수·뽑는 방식·도착 정보·지갑·카드 원본 칸·효과 표 칸을 볼 수 있어요.
4. 효과는 지금 **보류**로 표시돼요(효과 지급 개발 안 됨). 영수증만 저장해요.
5. 「돌아가기」를 누르면 요청에 적힌 화면으로 돌아가요. 같은 도착은 한 번만 처리되고, 새로 열어도 저장된 요청·영수증이 그대로 이어져요.
6. 도착 없이 시뮬레이터를 열면 「따로 보기」 상태예요. 두 덱 버튼 중 하나를 눌러 카드 1장을 미리 뽑아 볼 수 있고, 이건 지급·영수증이 없어요.

열어 보기: [찬스 칸 시뮬레이터](../../../../game-simulator.html?module=simulator_module_chance_event)

## 4. 상세 기획

### 한 판 순서

| 점검 | 내용 |
|---|---|
| 시작·종료 | 찬스·팬덤 반응 칸 도착 → 돌아가기 |
| 입력·출력 | 입력: 도착 요청(칸·굴림 배수·지갑) / 출력: 뽑힌 카드 1장·영수증 |
| 상태와 전이 | 요청됨 → 뽑음 → 영수증 준비 → 확인 |
| 판정 | 켜진 카드 중 무게 비례 1장 |
| 오류·예외 | 덱과 칸이 안 맞음, 켜진 카드 없음, 무게 합 0 이하 → 막고 이유 표시 |
| 저장·복원 | 브라우저 저장(`kpopmonsters.chance-event-flow.v1`)에 요청·영수증 보관, 다시 열면 이어짐 |
| 다른 모듈 연결 | 주사위·아이돌 성장·쟁탈전으로 돌아감. 효과 지급 연결은 개발 안 됨 |

### 공통 규칙 (확정)

- 칸 도착 → 해당 덱에서 1장. 칸은 성장하지 않습니다.
- 보상형 효과(경험치·코인·팬)는 굴림 배수 × 기본값(선형). 이동 효과는 배수와 무관.
- 건물 연결 효과는 그 건물 30단계 단계 보너스를 함께 곱합니다(본관1+부속2).
- 6·16·26·36 「쟁탈 보드」는 모노폴리GO 정거장 대결입니다. 찬스 카드는 그 칸으로 **이동만** 시키고 규칙을 바꾸지 않습니다. 오디션 캐스팅과 다릅니다.
- 덱 비율·확률·나쁜 카드 비중은 「발란스 대기」.

### 등급 연동 스케줄 변경 풀 (033 시안 · 30장 · 지금 켜진 카드 아님)

옛 스케줄 변경 시안(033)은 방송·공연 등급에 따라 뽑히는 카드가 바뀌는 풀이에요. 칸은 8·23·38 그대로이고 칸 이름은 고정이에요. 카드는 성장하지 않고, 방송·공연 등급이 오르면 초반 카드가 풀에서 빠지고(취소선) 윗 등급 카드가 들어와요. 카드는 「방송 등급이 범위 안 + 공연 등급이 범위 안」일 때만 풀에 있어요.

- 방송 등급: 온라인 → 라디오 → 케이블TV → 공중파TV → 해외방송
- 공연 등급: 버스킹 → 클럽 → 소극장 → 중극장·홀 → 아레나·대형홀
