# P209 · 배수 걸기 · 대표 개발 기획서

**이 문서는** 주사위를 여러 개 걸어 한 번에 크게 받는 「배수 걸기」가 무엇을 키우고 무엇은 건드리지 않는지 정리한 대표 개발 기획서입니다.

**보는 법** 1장 그림 → 4장 「한 판 순서」 → 핵심제안 개발의 「배수 비교 시뮬레이터」 순서로 읽습니다. 세부 결정과 근거는 책갈피 [P198 배수 걸기 보완판](../../기획서/산출_기획서_배수걸기_보완판_v1_클로드.html)에 있습니다.

**지금 상태** 현재 개발되지 않음, 진행 중.

## 1. 개요

출처: (합침) 제안서 [주사위 투자](/docs/planning/proposal-concept/dice.html) · 책갈피 [P198 배수 걸기 보완판](../../기획서/산출_기획서_배수걸기_보완판_v1_클로드.html) · 현중 11/01~11/02 지시

> **핵심** 배수는 **돈과 성장에만** 붙습니다. 피드 · 팬 · 투표 · 순위 · 증축 비용에는 붙지 않습니다. 그래서 주사위를 많이 걸수록 빨리 크지만, 순위를 돈으로 살 수는 없습니다.

```mermaid
flowchart LR
  A[주사위 배수 걸기] --> B[코인 × 배수]
  A --> C[성장 × 배수]
  C --> D[무대 편성 점수에 간접]
  A -->|안 붙음| E[피드 · 팬 · 투표 · 순위]
```

### 콘텐츠 경계

- 맡는 것: 배수 사다리 · 배수가 붙는 곳과 안 붙는 곳 · 남는 굴림 수 표시.
- 다른 문서에 맡기는 것: 주사위 공급 · 가격 → [P217 유료화](유료화_핵심제안서.html) · 칸 수익 → [P213 도시](도시_핵심제안서.html).

### 현재 기준과 목표

| 어디 | 배수 |
|---|---|
| 칸 코인 · 사옥 · 잭팟 · 게릴라 돈 | 붙음 |
| 아이돌 성장(능력) | 붙음 |
| 팬 이동 · 피드 강도 · 투표권 · 페스티벌 점수 | 안 붙음 |
| 건물 증축 비용 | 안 붙음(받는 쪽에만) |

- 배수 사다리와 해금은 엔터파워에 따라 열리는 기존 시안을 그대로 씁니다.
- 화면에 「이 배수로 남는 굴림 수」를 함께 보여 줍니다.

## 3. 구동 방법·시뮬레이션

화면 흐름: 보드 → 배수 선택 → 굴림 → 도착 보상 · 스샷 미완 · 이식 비교 해당 없음

- 실행: 게임 시뮬레이터 모듈은 아직 없습니다(미구현).
- 핵심제안 개발의 **배수 비교 시뮬레이터**에서 배수를 바꾸면 코인 · 성장은 커지고 피드 · 팬 · 투표는 그대로인 것을 봅니다. 숫자는 모두 임시 시안입니다.

## 4. 상세 기획

### 한 판 순서 (임시 시안)

| 점검 | 내용 |
|---|---|
| 시작·종료 | 배수를 고르고 굴립니다. 주사위가 배수만큼 줄어듭니다 |
| 입력·출력 | 입력 = 배수 · 주사위 / 출력 = 코인 · 성장 |
| 상태와 전이 | 배수 해금은 엔터파워 단계로 열림 |
| 판정 | 받는 쪽 보상에만 곱합니다 |
| 오류·예외 | 주사위가 배수보다 적으면 그 배수는 고를 수 없음 |
| 저장·복원 | 배수 선택은 다음 접속에 유지(시안) |
| 다른 모듈 연결 | 도착 보상 · 잭팟 · 게릴라 · 성장 |

### 배수가 닿지 않는 곳 (확정 근거: 현중 10/01 16:33 · P198)

증축 비용 · 팬 이동 · 피드 강도 · 투표권 · 페스티벌 점수. 적게 나온 굴림 뒤 보정(확률 바꾸기)은 하지 않습니다.

### 필요 시스템

배수 사다리 · 해금 · 남는 굴림 수 표시 · 보상별 배수 적용 칸.

### 화면·연출 목록

배수 버튼(굴림 버튼 옆) · 남는 굴림 수 표시.

### 남은 결정

- 배수 사다리 값 · 해금 문턱 — 기존 시안 · 발란스 대기
- 주사위 자동 충전량 — 엔터 파워 단계별 하루 60 · 90 · 120(임시값)
