# 보드 제안 · 주사위로 기회를 열고, 받은 수익으로 기획사를 키웁니다 (신규)

**이 문서는** 40칸과 아홉 시설의 연결, 도착 뒤 성장·수익·건설이 나뉘는 흐름을 설명합니다.

**보는 법** 1장 보드의 가치 → 2장 현재 연결을 읽고 상세 배치·실행 경계는 P87에서 확인합니다. 옛 본문은 하단 이력에서 봅니다.

**지금 상태** 현재 보드 표와 시험 경로가 있으며 성장 배정·수치는 임시입니다. 전체 화면·운영 정산 완료를 뜻하지 않습니다.

## 1. 보드의 가치

주사위로 기회를 열고 받은 수익으로 기획사를 키웁니다. 도착한 칸에 따라 활동이 달라지며 건물이 자동으로 증설되지는 않습니다. 시설 선택·견적·구매는 별도 건설 경로입니다.

<a id="read-2"></a>

## 2. 40칸과 9시설의 현재 연결

보드는 40칸입니다. 사옥을 포함한 시설 연결은 25칸이고, 그중 사옥은 출발 칸이므로 일반 건물 도착(`tile_kind=building`)은 24칸입니다. 건물 없는 위치는 15칸입니다. 9시설은 각각 전체 30단계이며 비용·효과는 발란스 대기입니다.

| 시설 | 연결 칸 |
|---|---|
| 사옥 | 1 |
| 보컬 녹음실 | 7·9·22 |
| 댄스 연습실 | 4·24·25 |
| 프로듀싱 스튜디오 | 10·13·29 |
| 뷰티 스튜디오 | 17·19·20 |
| 예능 방송국 | 27·28·30 |
| 콘서트장 | 32·33·35 |
| 아카데미 | 2·37·39 |
| 팬샵 | 12·14·15 |

1은 사옥 출발, 11은 기숙사, 21은 본가, 31은 감옥 도착입니다. 6·16·26·36은 쟁탈이며 `content_kind=casting`을 읽는 진입과 임시 `tile_kind` 이름을 구분합니다. 8·23·38은 찬스입니다. 정산의 금액과 각 칸의 실제 수익 여부는 경제 보상 표를 따르며 모든 칸이 돈을 지급한다는 뜻은 아닙니다.

예능·콘서트·아카데미는 성장표에 임시 세부 배정과 실제 허브 읽기 경로가 있습니다. 최종 배정·수치와 전체 검수는 남아 있습니다. 도착 표시 시안과 경제 지급·성장은 서로 다른 경로입니다.

### 맞춰 둘 것(기존 기획과의 관계)
- 팬 수 값의 출처는 기존 팬 규칙을 그대로 따른다. 이 절은 화면 연출만 정하고 팬 계산·돈·경제 규칙은 건드리지 않는다.
- 악개는 화면 팬 수에 세지 않는다(현중 결정 42)는 점과 군중 연출을 어떻게 맞출지는 정해야 함.
- 보드 40칸·9건물(위 표)의 자리와 겹치지 않게 놓는다. 건물은 길 사이 빈 땅에 서고 칸 위에 서지 않는다는 규칙(코덱스-보드9건물맵 §1)을 따른다.
- 군중 사람 모델(저폴리, 걷기 반복 동작)과 연출 코드는 연출 단계에서 별도 지시한다.

## 3. 단계와 증설
- 9개 건물 모두 30단계다(사옥 포함).
- 사옥 외 8건물: 묶인 칸 3개 중 하나에 도착하면 그 칸의 효과(레슨·수익)를 받고, 그 건물을 1단계 증설할 수 있다.
- 사옥: 1번 출발 칸 정산 때 증설한다. 사옥 2·3·4·5단계에 캐스팅권(아이돌 캐스팅 입장권)이 생겨 아이돌 캐스팅으로 멤버를 1명씩 늘린다(시작 1명 → 최대 5명).
- 증설비·성장량·단계별 효과·외형 단계 구간: 「발란스 대기」.

## 4. 쟁탈 보드 6·16·26·36 (모노폴리GO 정거장 대결)
- 6·16·26·36 = 「쟁탈 보드」(모노폴리GO 정거장 대결). 오디션 캐스팅과 다르며 그대로 둡니다(현중 10/16).

## 5. 개발 영향
- 건물 유닛·증설 연출·방어 전환은 칸 단위가 아니라 9건물 단위로 다시 묶는다. 30단계 외형 구간과 방어 변형 단계는 「발란스 대기」.
