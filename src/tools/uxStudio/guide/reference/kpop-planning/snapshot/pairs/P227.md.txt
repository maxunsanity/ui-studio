# P227 · 성장·앨범·차트·파이널 · 종합 기획서

**이 문서는** 아이돌 성장과 카드·몬스·시설이 곡 제작·앨범·활동·최종 경쟁으로 이어지는 전체 관계를 설명합니다.

**보는 법** 1장 전체 연결 → 2장 문서 지도 → 4장 콘텐츠 관계 → 7장 개발 순서로 읽습니다. 실행과 시안은 각 대표 기획서에서 확인합니다.

**지금 상태** 기존 시험 구현을 보존하며 팬 기반 성장 차트·크루 자동 공유·주간/월드·9주 전환을 상세 기획하고 있습니다. 새 기획의 미반영 코드는 완료와 구분합니다.

## 1. 개요

출처: (합침) 제안서 [아이돌 성장](../../../proposal-concept/idol.html)·[음원](../../../proposal-concept/song.html)·[월드 페스티벌](../../../proposal-concept/fest.html) · 각 콘텐츠 상세 기획.

```mermaid
flowchart LR
  N0["아이돌·카드·시설·학습 성장"] --> N1
  N1["기간·미션·성장 문턱으로<br/> 곡 준비"] --> N2
  N2["앨범·방송·공연·음악방송<br/> 차트"] --> N3
  N3["한 곡 선택·파이널·보상"]
```

### 콘텐츠 경계

전체 콘텐츠가 어떤 원본을 주고받는지 설명합니다. 각 숫자와 세부 규칙은 연결된 정본에서 관리하고, 카드·몬스·시설·음원 값을 이 문서에 중복 정의하지 않습니다.

### 현재 기준과 목표

| 연결 | 기준 |
|---|---|
| 육성 → 곡 | 기존 성장·미션·기간으로 제작 조건 구성 |
| 곡 → 활동 | 데뷔곡 포함 최대8곡 발매, 방송·공연 활동 |
| 활동 → 차트 | 회차별 곡 성적·최고 기록·발매 이력 |
| 차트 → 파이널 | 발매곡 중 한 곡 선택, 홍보·투표·최종 경쟁 |
| 결과 → 성장 | 기존 보상·팬 등급·명예의 전당·시즌 정리 |
| 몬스·카드 | 각 보유·성장·원정·디펜스 원본을 유지해 연결 |

## 4. 상세 기획

### 앨범 소규모 차트 연결

앨범 발매로 열리는100명·약1일 순위 이벤트 게임입니다. 현재 로컬은 본인+가상99명을 명시합니다. 첫100위에서 출발하고 후속은 현재 보유 팬·계층과 직전 마감 최종성적으로 시작합니다. 보드 신규 팬 증가를 주력으로, 주사위 소모를 보조로 점수를 쌓아 현재 순위별 돈·팬·기존 능력을 적립하고 다음1번START에서 정산합니다. 만료 뒤 신규 효과는 끝나며 얻은 성장·미정산 적립·최종 성적은 보존합니다. 보통 활동은4~5번째 첫1위 도전, 성장 좋은5~8번째 입장1위도 가능하며 차수별 고정 등수는 없습니다. 메인 차트 말풍선·활동/다음 시작 예상 게이지는 같은 규칙을 읽습니다. [앨범 차트 정본](../%EA%B0%9C%EB%B0%9C%EC%A7%84%ED%96%89%EA%B8%B0%ED%9A%8D_v01/%EC%BD%98%ED%85%90%EC%B8%A0%EB%B3%84_v03/%EC%9D%8C%EC%95%85%EB%B0%A9%EC%86%A1%EC%B0%A8%ED%8A%B8_%EA%B8%B0%ED%9A%8D%EC%84%9C.html)에서 성장곡선·원본·계산·저장·실제 구현을 봅니다. 실제 유저 매칭 서버는 미구현이며 유저 투표는 없습니다.

### 콘텐츠 연결 계약

싱글 발매 후 크루가 있으면 같은 앨범을 내부 자동 공유하고 앨범 성장 차트에 자동 등록합니다. 앨범 차트는 유저 투표 없이 발매 차수·보유 팬 수·팬 계층·기존 성장 조건으로 테이블 범주를 골라 그 안에서 순위를 배정합니다. 주간·월드페스티벌은 별도 회차이며 조회/추천·일반 유저 표·유저 채점단을 분리해 평가합니다. 팬투표100%로 처리하지 않습니다.

총9주 시즌에서 주1회 페스티벌,9주차 월드 후 최종집계·돈 보상·계정 기록 보존을 마치고 기존 시즌 초기화 경로로 전환합니다. 순위 보상은 돈만 사용하며 조절 가능한 임시 %S 표와 회차별1회 영수증을 둡니다. 기존 START 활동 정산과 차트/페스티벌 순위 보상은 다른 원인입니다. 순위 외 추가 음악 보상 범위·동크루 일반표·대상 곡/팀/캐릭터·기간/한도/비중은 검수 대기입니다.

### 수락 기준

콘텐츠마다 원본의 역할·현재 연결 범위·미구현을 구분하고, 발매·활동·집계·보상이 같은 기록으로 이어져야 합니다. 공통 값과 자원을 중복 정의하지 않습니다.

### 뺀 것·옮긴 것·보존한 것

각 콘텐츠의 세부는 정본에 두고 이 문서는 전체 연결을 설명합니다. 변경 이력·이전 종합·연구 자료는 하단 로그에서 보존합니다.


### 후속 로컬 구현과 남은 연결

전체64단계는 자동 발매 후속과 성장 차트 계산 접점까지 로컬 구현을 진전시켰습니다. 돈은 견적만, 주간·월드는 조회 달력만 구현한 범위를 구분합니다. 자동 발란스는 동일 releaseFollowups/chartRegistrations/festivalCalendar를 결과 관측으로 전달하며 현황판에 수동 조작이나 별도 순위 계산을 추가하지 않습니다.

관련 통합시험과 별도 팬 단조 경계3,751건을 통과했습니다. 정확한 최신 통과 수와 명령은 공용 보고·검증 로그에 기록합니다. 실제 공용게임의 명시 시험 조건으로 신규 발매 자동 연결·메뉴 왕복·새로고침 보존을 확인했습니다. 새 주간/월드 참여집계·운영 순위/지갑지급·63일 초기화를 완료한 검수가 아닙니다.
