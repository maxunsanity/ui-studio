## 제작 순서

1. **거시 방향:** 전체 컨셉·플레이를 함축해 관계자들이 같은 게임을 이해한다.
2. **첫 5분:** 튜토리얼이 끝난 뒤의 메인 루프 5분을 버티컬 슬라이스로 만들고, 재미가 전달될 때까지 고친다. 따로 프로토타입은 만들지 않는다(10/05 회의 01:01:37 · 01:02:16 · 01:06:22). 일정은 상의 중이다.
3. **제작 준비:** 10~11월 목표로 기획 압축·툴·이미지 기초·그래픽 컨셉을 준비한다.
4. **개발 확인:** 12월 개발 착수 목표로 첫 5분 버티컬 슬라이스의 구현을 확인하고, 확인 뒤 이후 목표 일정을 다시 잡는다.

로그인 · 소셜 연동 · 결제는 시드라 쪽 것을 쓴다(10/05 회의 01:28:14 · 01:28:33).

기획서 툴·제작 툴은 전 단계에서 함께 준비한다. 단계의 확인 기준은 공통 방향 이해 → 첫 5분의 재미 → 제작 자료와 도구 → 실제 구간의 구현 확인이다.

## 날짜의 의미

표지의 ‘이번 주’는 9/28 회의가 제안한 순서를 설명하는 기존 카피다. 10~11월 준비·12월 착수·2월 빌드·3월 상용화는 당시 목표 발언이며, 현재 확정 일정이나 출시 약속이 아니다. 실제 개발 확인 뒤 목표를 다시 정하는 방향을 유지한다.
