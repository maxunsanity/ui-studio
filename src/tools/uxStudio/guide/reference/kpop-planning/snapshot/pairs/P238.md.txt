# P238 · 시나리오 노출 방법 · 핵심제안 개발 기획서

**이 문서는** 시즌 이야기와 멤버 이야기를 보드 플레이 중 어디에서, 언제, 얼마나 보여 줄지를 설명합니다.

**보는 법** 그림과 표로 노출 자리를 보고 [상세 책갈피 P239](../../기획서/산출_기획서_시나리오노출_상세_v1_클로드.html)에서 규칙과 예외를 확인합니다. 도착 판정과 휠은 [필러 룰렛](../필러룰렛_v01/필러룰렛_기획서.html)에서 봅니다.

**지금 상태** 현재 개발되지 않음, 진행 중. 칸 도착 대사 한 줄은 표·계산·단독 미리보기와 대사 생성 작업대까지 만들었고, 실제 보드 도착 화면에는 아직 연결하지 않았습니다. 조우 장면·기록·멤버 서사 열기·관통 서사는 제작전입니다.

<a id="part-1"></a>
## 1. 개요

**주사위 한 번이 이야기 한 조각을 남기고, 9주 동안 쌓인 조각이 내 아이돌 팀의 한 시즌이 됩니다.**

~~~mermaid
flowchart LR
 A["관통 서사 · 모든 유저 공통 9주"] --> X["보드 플레이 중 노출"]
 B["멤버 서사 · 내 멤버마다 8장"] --> X
 C["필러 장면 · 칸 도착 한 번"] --> X
 X --> R["기록 한 줄"] --> F["월드 페스티벌 회고"]
~~~

| 층 | 누가 보나 | 단위 |
|---|---|---|
| 관통 서사 | 모든 유저가 같은 주차에 | 주차 9개 |
| 멤버 서사 | 유저마다 내 멤버 | 멤버당 8장 |
| 필러 장면 | 유저마다 내 멤버가 배역 | 칸 도착 한 번 |

이야기는 새 자원을 주지 않습니다. 미리 만들어 사람이 확인한 문장만 쓰고, 내 멤버의 이름·호칭·존댓말·조사를 실행 때 맞춥니다. [세 층과 경계](../../기획서/산출_기획서_시나리오노출_상세_v1_클로드.html#three-layers).

## 3. 구동 방법·시뮬레이션

~~~mermaid
flowchart LR
 A["시험 팀 · 관계 단계"] --> B["칸·판정 고르기"] --> C["도착 · 필러 칸 대사"] --> D["왜 이 줄인지 보기"]
~~~

[칸 도착 대사 미리보기 실행](/docs/planning/filler-dialogue-preview.html)

| 탭 | 하는 일 |
|---|---|
| 미리보기 | 칸에 도착해 대사와 말투가 바뀌는 모습, 전수 검사 |
| 빈칸과 주문 | 칸마다 모자란 줄 수와 문장 주문서 |
| 후보 검수 | 써 온 후보를 여러 시험 팀으로 채워 보고 채택·보류·버림 |

시드로 만든 시험 팀만 쓰고 저장하지 않습니다. 게임 시뮬레이터 모듈이 아닌 단독 화면입니다. [구동과 생성 작업대](../../기획서/산출_기획서_시나리오노출_상세_v1_클로드.html#workbench).

<a id="part-4"></a>
## 4. 상세 기획

~~~mermaid
flowchart LR
 A["칸 도착"] --> B["판정 또는 칸 기능"] --> C{"장면 고르기"}
 C -- "없음" --> D["한 줄 대사"]
 C -- "있음" --> E["장면 · 넘기기 가능"]
 D --> R["기록 한 줄"]
 E --> R
~~~

| 노출 자리 | 보이는 것 | 나오는 때 |
|---|---|---|
| 도착 화면 · 필러 칸 | 독백·리액션 한 줄, 두세 멤버 조우 장면 | 칸 도착마다 (대부분 한 줄, 일부만 장면) |
| 챕터 알림 | 「○○의 이야기가 한 장 열렸습니다」, 주차 여는 장면 | 성장 단계가 오른 뒤 첫 도착, 주차 바뀐 뒤 사옥 첫 도착 |
| 「개인 서사」 버튼 | 멤버별 서사 장과 기록 | 언제든 |
| 주차 닫는 장면 | 그 주의 기록 한두 줄 | 주간 페스티벌 뒤 |
| 월드 페스티벌 회고 | 시즌 처음과 끝 | 9주차 |

판정은 그날만의 결과라 광탈 장면이 멤버를 영구히 깎지 않습니다. 실존 인물·연애·신체 장면은 만들지 않습니다. [한 판 순서](../../기획서/산출_기획서_시나리오노출_상세_v1_클로드.html#one-arrival) · [고르기·밀도](../../기획서/산출_기획서_시나리오노출_상세_v1_클로드.html#scene-pick) · [말투](../../기획서/산출_기획서_시나리오노출_상세_v1_클로드.html#cast-speech) · [남은 결정](../../기획서/산출_기획서_시나리오노출_상세_v1_클로드.html#open-decisions) · [아직 반영하지 않은 회의 결정](../../기획서/산출_기획서_시나리오노출_상세_v1_클로드.html#meeting-pending).
