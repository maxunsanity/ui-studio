# P93 · 악귀 디펜스 · 사용 CSV

상태: 제안(검수 대기)입니다.

## 개요

이 기획의 기능·기획 근거·리소스 자료로 사용하는 CSV 45개를 나열합니다. 실제 실행에서 읽는 표·기획 참고·리소스 제작 설정을 구분합니다. 공용 로더가 묶음 검사를 위해 읽는 모든 표의 목록은 P73에서 확인합니다. 수치는 시안 예시이며 빈 값과 대사를 임의로 채우지 않습니다.

## 보기 방법

왼쪽 CSV 목록에서 표를 선택하면 동일 내용판에 실제 행이 나타납니다. 모바일 내장 화면은 CSV 선택 목록을 제공합니다. 파일의 용도는 바로 설명하며 원본 경로·주키·사용 기획·근거는 접은 설명에서 펼쳐 봅니다. 목록 검색과 행 검색은 별도로 동작합니다. 참조 버튼·40행씩 보기·표시 열 선택·뒤로/앞으로·CSV/ZIP 복사본 받기를 제공합니다.

## 등록과 확장

planning_csv_table.csv는 원본 파일을 한 번씩 등록하고 planning_csv_usage.csv는 콘텐츠와 CSV를 연결합니다. 여러 기획이 쓰는 파일은 복제하지 않고 관계를 여러 개 연결합니다. sort_order=0은 처음 열 대표 CSV를 지정합니다. 새 파일은 영역·버전이 포함된 table_key로 구분합니다. 동일 공용 뷰어를 사용하며 화면 코드를 수정하지 않고 등록으로 표를 늘립니다.
