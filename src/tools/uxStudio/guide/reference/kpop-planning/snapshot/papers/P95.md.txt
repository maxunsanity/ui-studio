# P95 · 전투·AI 기획 참고 자료 (신규)

**이 문서는** 외부 기획 문서 일곱 건의 규칙·구조·공식을 주제별로 찾아보는 참고집입니다. 수치·명칭은 원문 예시입니다.

**보는 법** 아래 목차에서 필요한 주제를 찾고, 원문 수치 충돌과 「우리 게임 연결」의 제안 범위를 함께 읽습니다. 출처 약칭과 문서 정보에서 원자료 위치를 확인합니다.

**지금 상태** 외부 참고자료가 정리된 상태이며, 현재 게임 적용 정본이나 운영수치 확정을 뜻하지 않습니다. 이 문서에는 시뮬레이터 실행 입구가 없습니다.

상태: 참고 자료입니다. 외부 기획 문서 7건에서 **재사용할 수 있는 기획 규칙·구조·공식만** 주제별로 뽑았습니다. 수치는 원문 예시이며 K-POP MONSTERS 값이 아닙니다.

목차: 1 AI 상태 → 2 표적·어그로 → 3 패턴 → 4 예고·피드백 → 5 페이즈·기믹 → 6 보스 설계 절차 → 7 전투 공식 → 8 난이도 레버 → 9 유닛 교대·부활 → 10 비동기 PvP → 11 업적 → 12 테이블 설계 → 13 작성 기법·예외 처리 → 14 설계 원칙 → 15 원문 수치 충돌 → 16 우리 게임 연결

출처 약칭: 【AI】 몬스터 AI·전투 패턴 AI(PDF 10쪽) · 【플로우】 몬스터 AI·테이머 스위치 플로우(drawio) · 【광룡전투】 이오스 광룡 전투(PPT 8장) · 【광룡공식】 EOS 광룡 전투 공식 v0.01(PPT 18장) · 【보스】 보스 기획서(PDF 23쪽) · 【공성】 전투기획 포트폴리오 · 비동기 공성 PvP(PDF 43쪽) · 【업적】 여정(업적)(PDF 15쪽)

## 1. 몬스터 AI 상태 설계 (신규)

### 1-1. 감지 3단계 (거리로 긴장 곡선 만들기) (신규)

| 영역 | 거리 예 | 행동 | 예고 표시 |
|---|---|---|---|
| 인지 | 15~10m | 멈추고 n초 바라본 뒤 원래 이동으로 복귀 | 초록 게이지 |
| 주시 | 10~6m | 「n초 대기 → n m 접근」 반복 | 파랑 게이지 → 주시 마크 |
| 절대공격 | 5~4m | 다른 체크 없이 공격 판단 | 빨강 게이지(0.5초) |

- 가까운 영역이 바깥 영역 판정을 덮습니다(절대공격 > 주시 > 인지). 【AI p.2】
- 영역 경계 사이에 빈 거리를 둬 상태가 깜빡이지 않게 합니다. 【플로우】
- 감지 대기 시간을 색 게이지로 보여 주면 「곧 공격한다」는 예고가 됩니다. 【AI p.3~4】

### 1-2. 상태와 전이 (신규)

**읽기용 표시 대안** — 원문의 노드·전이·조건은 유지하고 표시 형식만 flowchart TB로 바꿉니다. 원래 stateDiagram-v2가 정상일 수 있으며, 로컬 표시 모듈 로드 실패에 대한 읽기 대안입니다. 원문 문법 오류 수정·현 게임 AI 구현·정책 승인을 뜻하지 않습니다.

```mermaid
flowchart TB
  start["[*]"]
  move["기본이동"]
  notice["인지"]
  watch["주시"]
  target["타겟체크"]
  judge["대상판단"]
  range["공격거리체크"]
  battle["전투"]
  pattern["패턴판단"]
  start --> move
  move -->|인지 영역 진입| notice
  notice -->|n초 후| move
  move -->|주시 영역 진입| watch
  watch -->|대상 이탈| move
  watch -->|절대공격 영역 진입| target
  target -->|비선공| watch
  target -->|선공 · 일반| judge
  target -->|선공 · 보스| range
  judge -->|붙은 적 n 이하| range
  judge -->|붙은 적 n 초과| watch
  range -->|사거리 충족| battle
  battle --> pattern
```

| 상태 | 핵심 규칙 |
|---|---|
| 타겟체크 | 선공·비선공을 여기서 실제로 결정합니다. 비선공은 감지 후에도 주시로 돌아갑니다. 【AI p.3】 |
| 대상판단 | 대상에 이미 붙은 적 수를 셉니다. 초과면 붙지 않고 주시로 대기합니다(집단 린치 방지). 보스는 이 체크를 건너뜁니다. 【AI p.1·3, 플로우】 |
| 공격거리체크 | 거리로 쓸 기술 종류를 고릅니다. 【AI p.3】 |
| 이동 타입 | 이동 / 이동 안 함(고정형) / 빠른 이동(붙을 자리가 있을 때). 【플로우】 |

### 1-3. 강제 전투 (근접 접촉) (신규)

| 단계 | 조건 → 결과 |
|---|---|
| 접촉 감지 → 거리 체크 | 3m 이내면 레벨 차 판정 |
| 레벨 차 판정 | 20 이상이면 무시, 20 미만이면 전투 확정 |

레벨 차가 큰 적은 무시해 저레벨 구역의 피로를 줄입니다. 【플로우】

### 1-4. 원문에 없는 것 (신규)

추적 거리 한계(리쉬)·귀환·리셋 규칙은 정의되어 있지 않습니다. 가져올 때 새로 정해야 합니다. 【AI】

## 2. 표적 선택·어그로 (신규)

### 2-1. 어그로 리스트 (신규)

| 항목 | 규칙 |
|---|---|
| 가중치 | 선타 30% + 받은 피해 70% 【플로우, AI p.7】 |
| 갱신 | 피격 N초 뒤, 소모된 HP 양으로 갱신 여부 판단 【AI p.7】 |
| 유지 | 갱신 후 n초 유지, 피격이 없으면 패턴 재판단 【플로우】 |
| 변경 시점 | 표적 변경은 HP 판단 이후에만 허용 【AI p.5】 |

### 2-2. 표적 변경 기준 (몬스터마다 하나를 지정하거나 랜덤) (신규)

| 기준 | 고르는 대상 |
|---|---|
| 피해량 | 가장 많이 때린 대상 |
| 선타 | 먼저 때린 대상 |
| 레벨 낮은 순 | 여럿이 공격할 때 레벨이 낮은 대상 |
| HP 낮은 순 | 여럿이 공격할 때 HP가 낮은 대상 |
| 기술별 지정 | 기본 공격 = 현재 대상, 돌진 = 맵의 랜덤 대상, 광역기 = 맵 무작위 【보스 p.17·22】 |

### 2-3. 다대다 자동 매칭 (순환 우선순위) (신규)

| 공격자 | 1순위 | 2 | 3 | 4 |
|---|---|---|---|---|
| C1 | M1 | M2 | M3 | M4 |
| C2 | M2 | M3 | M4 | M1 |
| C3 | M3 | M4 | M1 | M2 |
| C4 | M4 | M1 | M2 | M3 |

- 적 쪽도 대칭으로 같은 순환을 씁니다. 짝이 없으면 자기 번호에 가장 가까운 대상을 공격합니다. 【광룡전투 4장】
- 불균형일 때는 **교전 수가 적은 대상부터** 고릅니다(다음 대상의 교전 수가 1이면 0인 대상, 2 이상이면 1·0인 대상 순). 【광룡전투 4장】
- 수적 열세면 1:다 / 다:1 매칭을 허용합니다. 【광룡전투 1장】

## 3. 전투 패턴 설계 (신규)

### 3-1. 발동 우선순위 (신규)

**강제 > 조건 반응 > 쿨타임 스킬 > 기본 공격**

| 순위 | 분류 | 발동 방식 | 예 |
|---|---|---|---|
| 1 | 특수 패턴 | HP %에 도달하면 반드시 발동 | HP 30% 소환, 5% 최후의 저항 【보스 p.9】 |
| 2 | 조건 반응 스킬 | 거리·상태 해제 조건에서 우선 | 거리 10칸 이상이면 도약(갭클로저), 디버프 해제 순간 광역기 【보스 p.6·16·18】 |
| 3 | 스킬 | 개별 쿨타임 | 5·7·8·25초 【보스 p.6·8】 |
| 4 | 기본 공격 | 확률 가중치(합 100%) | 근접 70 / 원거리 30 【보스 p.6】 |
| — | 연계 | 선행 기술 명중 뒤 확률 연결 | 할퀴기 2회 뒤 80%로 회전 베기 【보스 p.14】 |

### 3-2. 판단 루프 (신규)

| 흐름 | 조건 |
|---|---|
| 전투 시작 → 자기 HP 확인 → 패턴 결정 | HP 구간으로 1차 결정 【플로우】 |
| 패턴 → n초 유지 → 재판단 | 유지 시간 동안 공격 반복 【AI p.7】 |
| 유지 중 HP 구간 도달 → 기믹 → 표적 재선정 → 패턴 결정 | 【플로우】 |
| 피격 → 어그로 갱신 → n초 유지 | 【플로우】 |

### 3-3. 일반형과 보스형 (신규)

| 구분 | 일반 몬스터 | 보스 |
|---|---|---|
| 선택 | 몬스터별 비중으로 기본 공격·스킬 랜덤 | 정해진 고정 순서(학습 가능) |
| 쿨타임 | 쿨 중에는 기본 공격 강제 | 같음 |
| 반복 방지 | 동적 가중치: 같은 패턴이 쌓이면 다른 패턴으로 강제 전환 | 고정 순서와 비중 사이 전환에도 사용 |
| 시간 조건 | — | 시간 경과로 버프·디버프 고정 발동 |

【AI p.6~7】

### 3-4. 자동 전투용 스킬 AI (신규)

- 일정 주기(5초)마다 사용 가능 여부를 확인하고, 쿨이 끝난 스킬 중 하나를 랜덤 사용합니다. 【광룡전투 1·5장】
- 자원 제약: 스킬은 MP를 쓰고, MP는 자연 회복이 없으며, 고갈되면 스킬을 못 씁니다. 충전은 아이템으로만 합니다. 【광룡전투 5장】
- 몬스터 쪽은 습득 조건 없이 스킬 그룹 전체를 씁니다. 【광룡공식 9장】

## 4. 예고·회피·피드백 (신규)

### 4-1. 예고 설계 (신규)

| 방식 | 예 | 예고 시간 |
|---|---|---|
| 자세 변화 | 이족 → 사족 보행이면 돌진 | 1초 주시 + 0.1초 전 범위 표시 【보스 p.4·17】 |
| 바닥 범위 표시 | 착지 지점·돌진 경로 | 2초 뒤 표시, 표시 후 1초 착지 【보스 p.16】 |
| 방향 신호 | 고개 들기 = 주변 안전 / 숙이기 = 주변 위험, 1타 뒤 반대 구역 | 전조 동작 【보스 p.10·18】 |
| 위험 색 | 눈 붉은 빛 = 반격 불가기 | 0.2초(좁은 범위로 보상) 【보스 p.11·19】 |
| 위협 모션 | 큰 기믹 직전 슈퍼아머 상태로 「공격하는 척」 | 【AI p.9】 |
| 화면 알림 | 특수 패턴 = 화면 중앙 알림 + 보스가 맵 중앙으로 이동 | 이동 시간 【보스 p.21·22】 |
| 회수 동작 | 공격 뒤 팔 돌리기 등 → 반격 틈을 보여 줌 | 【보스 p.10】 |

### 4-2. 피드백·연출 규칙 (신규)

| 규칙 | 내용 |
|---|---|
| 연출과 수치 분리 | 자동 전투에서 연출은 결과 계산에 관여하지 않습니다. 【광룡전투 1·2장】 |
| 무리 처치 연출 | 무리 HP를 한 게이지로 합치고 50/70/90/100% 지점마다 한 마리씩, 일부는 시간차를 두고 쓰러뜨립니다. 【광룡전투 1~2장】 |
| 카메라 | 이동 20~35°, 전투 25°/탑뷰 45°, 시작·종료만 연출 카메라. 이동 중 아군 전원을 화면 안에. 【광룡전투 3·6장】 |
| 감정 표정 | 비웃음(등장·1페이즈) / 아픔(약점·파훼) / 분노(HP 50%·2페이즈) / 슬픔(사망) 【보스 p.9】 |
| 디버프 UI | 아이콘에 중첩 수, 행동불능은 시간이 지날수록 흐려짐 【보스 p.17】 |
| 무력화 표시 | 머리 위 별 이펙트 【보스 p.11】 |
| 진행 메시지 | 시작 표기, 스테이지 전환 슬라이드, 종료 페이드, 패배는 메시지만, 보스만 추가 연출 【광룡전투 7~8장】 |

## 5. 페이즈·기믹 (신규)

### 5-1. HP 구간 설계 (신규)

| 구간 | 하는 일 |
|---|---|
| 100~50% | 1페이즈 = 학습. 기본 패턴 + 환경 파훼 가능 |
| 50% | 2페이즈 = **학습 배신**. 디버프 전부 해제, 방어 상승(약점 봉인), 같은 기술의 모션·범위 변경, 기술 삭제·추가, 기존 파훼 무효 |
| 30% | 소환·회복 미션(실패하면 HP 회복 → 30% 재도달 시 재발동) |
| 5% | 최후의 저항(고위험 광폭) → 끝나면 긴 무력화 |
| 0% | 사망 전용 연출 |

【보스 p.6~8·21~23】

### 5-2. 기믹 유형 (신규)

| 기믹 | 규칙 |
|---|---|
| 환경 파훼 | 보스 돌진을 오브젝트에 유도 → 행동불능 3초 + 능력치 영구 감소. 단계별 감소량 증가, **최대 3중첩 상한** 【보스 p.6·17】 |
| 파훼 후 응징 | 행동불능이 풀리는 순간 주변 광역기 → 욕심 딜에 긴장 【보스 p.18】 |
| 반격 봉쇄 | 반격 불가기를 섞어 반격 편중을 막음. 대신 확실한 전조와 좁은 범위 【보스 p.19】 |
| 약점 노출 창 | 특정 기술 중 약점을 치면 치명타 + 1초 경직 + 연계 삭제 【보스 p.9·19】 |
| 무적 + 사후 무력화 | 무적 추적기(6초) 뒤 반드시 어지러움(3초) = 공략 타이밍. 추적기는 대상보다 느리게(0.8배) 【보스 p.8·20·22】 |
| 회복 저지 미션 | 보스 무적 + 소환물이 보스로 이동, 흡수 시 1마리당 최대 HP 5% 회복, 제한 9초 【보스 p.21】 |
| 스택·무력화 게이지 | 적중·장판으로 스택 누적(정화 불가) → 5스택이면 기믹 시작 → 무력화 게이지를 깎으면 보스 HP 5% 감소 + 그로기, 실패하면 맵 전체 피해 + 스택 + 영구 장판 【AI p.10】 |
| 소환·도망 | 호위 소환, 반대 방향 후퇴. 본체 AI와 분리된 별도 AI로 만들고 목록은 열어 둠 【AI p.5·8~9】 |
| 맵 변형 | 페이즈 전환 때 장애물 출현 → 경로 방해 【보스 p.8·22】 |

## 7. 전투 공식 (신규)

### 7-1. 능력치 합산 (신규)

```
최종 능력치 = (캐릭터 능력치 + 아이템 능력치) × (1 + 스킬 효과)
```
【광룡공식 4장】

### 7-2. 합산 게이지 방식 (자동 전투 경량 계산) (신규)

```
적에게 주는 피해 = Σ(전투 가능한 아군의 최종 공격력)      ※ 사망 아군 제외
적 게이지 감소   = 적 전체 HP 합 − (아군 총 공격력 − 방어력)
```
【광룡공식 4장, 광룡전투 1~2장】

### 7-3. 생존 인원 보정 (신규)

```
받는 피해 = (적 평균 공격력 − 아군 최종 방어력) × (1 + (4 − N) / 3)
최소 피해 = 1
```

| 생존 N | 4 | 3 | 2 | 1 |
|---|---|---|---|---|
| 배율 | 1.00 | 1.33 | 1.67 | 2.00 |

인원이 줄수록 남은 쪽이 더 아프게 맞습니다. 최소 피해 1로 방어 무적화를 막습니다. 【광룡공식 4장】

### 7-4. 기술 피해와 계수 계층 (신규)

```
기술 피해 = 공격력 × 기술 계수
```

| 위협 단계 | 계수 | 예 |
|---|---|---|
| 지속 | 0.2 / 0.2초 | 6초 지속, 최대 30타 |
| 기본 | 0.6~0.8 | 다단 2타, 투사체 |
| 주력 | 1.0~1.2 | 도약(넘어짐), 돌진(기절) |
| 필살 | 1.3 | 반격 불가 |
| 광폭 | 2.0 | 최후의 저항 |

【보스 p.14~22】

### 7-5. 다중 피격 감쇠 (신규)

```
n번째 피격 피해 = 첫 피격 피해 × 0.6^(n−1)    → 1 / 0.6 / 0.36
```
【보스 p.15】

### 7-6. 상태이상 중첩 (신규)

```
지속 피해: 초당 x, 10초, 최대 3중첩, 중첩당 × 1.2  → x / 1.2x / 1.44x
능력 감소(파훼): 방어 −10/−15/−20%, 속도 −5/−7/−9%, 행동불능 3초, 3회 상한
```
【보스 p.7·17】

### 7-7. 부분 승리 비례 보상 (약탈) (신규)

```
보상 = 상대 누적량 × 비율 × (제압 수 / 배치 수)
보상 ≤ 1회 상한,  제압 수 = 배치 수이면 완전 승리 보너스 추가
```

| 검산 | 값 |
|---|---|
| 누적 10,000 × 50% × 5/5 | 5,000 → 상한 3,000 적용 |
| 완전 승리 보너스 | +1,000 |
| 최종 | 4,000 |

【공성 p.19】

### 7-8. 점수 (신규)

```
공격 승리 = 승리 기본점 + 가산 + 감산
공격 패배 = 패배 기본점 + 가산 + 감산
방어 승리 = 기존 점수 + 방어 성공 가산
방어 패배 = 기존 점수 + 방어 실패 감산
```
【공성 p.18】

### 7-9. 오프라인 진행 (신규)

```
오프라인 클리어 수 = 오프라인 시간 / 스테이지 클리어 시간
시작 지점 = min(현재 + 오프라인 클리어 수, 능력치 기준 최대 도달 지점)
```
【광룡공식 3장】

## 8. 난이도·밸런스 레버 (신규)

| 레버 | 쉽게 ↔ 어렵게 |
|---|---|
| 예고 시간 | 2초(여유) ↔ 0.2초(정밀) |
| 범위 | 좁게 ↔ 넓게, 시간에 따라 확대(3×3 → 5×5) |
| 쿨타임 | 길게 ↔ 짧게 |
| 기술 계수 | 0.2~2.0 계층 안에서 조절 |
| 무력화 시간 | 길게 ↔ 짧게(3초·5초) |
| 추적 속도 배율 | 대상보다 느리게(0.8) ↔ 빠르게 |
| 파훼 상한 | 중첩 수·단계별 감소량 |
| 기본 공격 비율·연계 확률 | 70:30, 80% |
| 생존 인원 보정 | 배율 곡선 기울기 |
| 회복 저지 미션 | 소환물 HP·속도·제한 시간·흡수당 회복량 |
| 보스 능력치 | 동급보다 높게 두고 파훼로 깎게 함 |

**제한 시간 정하는 원칙:** 「기본 이동속도 + 다단히트 기술로 1마리 이상 처리하면 성공」하도록 역산합니다. 【보스 p.21】

## 10. 비동기 PvP 구조 (신규)

### 10-1. 공격·방어 비대칭 (신규)

| 구분 | 조작 | 규칙 |
|---|---|---|
| 공격 | 유저 직접 | 배치만 조정(장비·스킬 변경 불가), 버프 적용 |
| 방어 | AI 자동, 유저는 결과만 | 버프 미적용(밸런스), 다른 모드 버프 중첩 금지 |

- **방어 공백 금지:** 방어 배치가 없으면 매칭이 깨지므로, 첫 입장 때 1팀을 강제 배치합니다. 배치가 없으면 매칭 대상이 될 수 없습니다. 【공성 p.3·9】
- 자동 배치 정렬 키: (공격+방어) 합 → 레벨/등급 → 생성일 → 직업/타입. 버튼 한 번으로 전 구역 배치 후 자동 저장. 【공성 p.12】

### 10-2. 진입~퇴장 체크 (신규)

콘텐츠 선택(입장 가능) → 로비(편성) → 자동 매칭 → 진입(입장권 차감) → 대기 → 전투 → 판정 → 보상·퇴장 【공성 p.3~4】

### 10-3. 승패 (신규)

| 결과 | 조건 |
|---|---|
| 승리 | 제한 시간 안에 방어 팀 전부 제압 |
| 패배 | 시간 초과 / 공격 팀 전멸 / 중도 나가기(획득량 0) |
| 무승부 | 없음 |

- 판정 수가 가변이면 「킬 수 0 = 전원 제압 판정」처럼 예외 값을 정의합니다. 【공성 p.37】
- 연습 모드: 내 공격 vs 내 방어, 같은 판정, 보상·입장권 없음. 【공성 p.41~43】

### 10-4. 보호·복수·입장 자원 (신규)

| 장치 | 규칙 |
|---|---|
| 손실 보호 | 일정 금액 이상 잃으면 6시간 매칭 제외. **보호 중 내가 공격하면 즉시 해제**(악용 차단) 【공성 p.4·15】 |
| 보호 표시 | 「잃은 금액 / 발동 금액」, 적용 중이면 남은 시간 【공성 p.15】 |
| 손실 상한 | 비율 × 절대 상한을 함께 걸기 【공성 p.19】 |
| 등급별 손실 완화 | 상위 등급일수록 피약탈 비율 하향(20% → 10%), 보호 발동액 = 창고 상한의 40% 【공성 p.5~6】 |
| 복수 | 나를 이긴 상대에게만, 같은 상대 1회, 입장권 1장, 매칭 조건 무시. 상대가 보호 중이면 진입 차단 【공성 p.27~29】 |
| 입장권 | 최대 5장, 30분마다 1장, 최대치에서는 충전 정지, 소진 시 유료 재화 【공성 p.4·21】 |
| 기록 | 공격·방어 기록 각 30개, 오래된 것부터 삭제 【공성 p.27】 |
| 시즌 | 초기화 대상(기록·승패·랭킹·버프)을 목록으로 확정 【공성 p.4】 |

### 10-5. 매칭 (신규)

- 점수 구간 컷으로 등급을 나누고 같은 등급 안에서 매칭합니다(컷 예: 100/200/350/550/900/1,300/1,650/2,200/2,750). 【공성 p.40】
- 재탐색에 비용을 받습니다(등급별 500~1,000). 【공성 p.5】

### 10-6. 생산·수확 루프 (접속 동기) (신규)

| 규칙 | 내용 |
|---|---|
| 생산 | 방어 배치된 구역마다 10분 주기 생산, 배치 평균 등급이 높을수록 많이 |
| 수확 | 자동 수령이 아니라 직접 눌러 수확 |

【공성 p.4·8·15·17】

## 11. 업적 구조 (신규)

### 11-1. 4분류와 보상 역할 (신규)

| 분류 | 의도 | 조건 예 | 보상 역할 |
|---|---|---|---|

| 성장 | 성장 중 유리한 행동 안내 | 레벨·채집·제작·지역 보스 | 그 단계에 필요한 아이템 |
| 과정 | 플레이 방향 안내 | 튜토리얼·덱 세팅·강화·진화 | 그 과정에 쓴 아이템 환급 |
| 목표 | 최종 목표 제시 | 수집·돌파·최고 레벨 | 뽑기 |

【업적 p.6~9】

### 11-2. 보상 단위 (신규)

- 작은 단위(코어 1~9)로 세분해 지급하고, 사용은 큰 단위(코어 10 = 엘리먼트 1)로 묶어 인플레이션과 잔돈 문제를 막습니다. 【업적 p.3】
- 보상량(코어 수)을 점 아이콘으로 보여 주면 난이도 표시를 겸합니다. 【업적 p.3·5】
- 전체 달성률 = 획득 코어 ÷ 획득 가능 코어. 카테고리별 % 별도. 【업적 p.3】

### 11-3. 조건 테이블 구조 (신규)

```
행동 타입 + 대상 필터(등급·종류·인덱스·그룹, 0 = 무관) + Value(횟수·레벨·단계)
```

- 새 조건도 같은 열 구조로 추가합니다. 실패도 조건이 됩니다(강화 실패 횟수). 【업적 p.11~15】
- 시간(0 없음/1 일/2 주/3 월/4 직접) × 반복(0 안 됨/1 반복/2 횟수 지정)으로 주기를 표현합니다. 【업적 p.10】
- 업적 묶음의 완료 조건(전부 / 비율)을 별도 행으로 두는 메타 업적 구조. 【업적 p.10】

## 14. 설계 원칙 (신규)

1. 위협 패턴마다 회피법·파훼·사후 무력화 중 하나를 반드시 짝짓습니다. 【보스】
2. 플레이 편중을 막습니다: 갭클로저(원거리 방심), 반격 불가기(반격 편중), 파훼 후 광역기(욕심 딜). 【보스】
3. 2페이즈는 학습한 패턴을 배신합니다. 【보스】
4. 파훼·디버프에는 상한을 둬 보스가 무력해지지 않게 합니다. 【보스】
5. 추적형 공격은 대상보다 느리게 해 「피하는 법」을 명확히 합니다. 【보스】
6. 실패해도 같은 지점에서 다시 시도하는 루프를 둡니다(회복 → 재발동). 【보스】
7. 감지를 거리 단계로 나누고 게이지로 예고합니다. 【AI】
8. 한 대상에 몰리는 적 수를 제한합니다. 【AI】
9. 랜덤 비중 위에 쿨 강제·동적 가중치를 얹어 같은 패턴 연속을 막습니다. 【AI】
10. 기믹 AI는 본체 AI와 분리하고 목록은 열어 둡니다. 【AI】
11. 자동 전투에서는 연출과 계산을 분리합니다. 【광룡전투】
12. 최소 피해를 보장합니다. 【광룡공식】
13. 변경은 전투 사이 대기 구간에 일괄 적용합니다. 【광룡공식】
14. 비동기 PvP는 방어 공백을 허용하지 않습니다. 【공성】
15. 손실은 비율 + 절대 상한 이중으로 막고, 보호 중 공격하면 보호를 해제합니다. 【공성】
16. 부분 승리는 비례 보상, 완전 승리만 보너스. 【공성】
17. 직접 수확 + 미수확분 약탈로 접속 동기를 만듭니다. 【공성】
18. 업적 보상은 분류마다 역할을 나눕니다(재화 / 단계 아이템 / 환급 / 뽑기). 【업적】
19. 수치는 기술 표 하나를 단일 원천으로 둡니다. 【보스 · 공성】
