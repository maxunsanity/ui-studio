## 1. 제일 큰 것 — 시점은 하나다

내가 「아이돌 시선 + 빠순이 시선」 두 개로 설명하자 대표가 끊고 반려했다.

> **"주인공이 둘일 수는 없고, 전지적 시점에서 빠순이로 시작하지만 결국 엔터사 대표가 되는 게 목표"**
> "이 관점을 2개로 놓고 해 버리면 너무 어려워요"
> **"이건 고민할 게 아니고 결정을 해 드리는 거예요. 고민하면 계속 충돌이 나니까"**
> "기획사 대표 시점인데 **스타트를 빠순이로 시작한다.** 이렇게만 하면 돼요"

개발 동료도 같은 편이었다 — "관점이 스위칭 되는 게 문제", "말이 그냥 빠순이인 거지 아이돌일 필요는 없잖아".

### 왜 반려됐나

| 근거 | 내용 |
|------|------|
| **빠순이로 머무는 시간이 짧다** | 2달 시즌 중 **길어야 일주일**. 유저는 빨리 벗어나고 싶어한다 |
| **그래서 시즌마다 다시 시작해야** | "이미 내가 하이브야 최고야" 하면 신규가 들어왔을 때 **전부 하이브인 게임**이 된다 |
| 라포 | 빠순이에서 시작해야 아이돌과 **라포 형성 기간**이 생기고 성장을 한 테이크로 끌고 갈 수 있다 |

### 내가 냈던 논리는 살아 있다

> "엔터 사장은 한 명인데 빠순이는 1000명. **대상이 많은 쪽으로 서비스**하는 게 좋았다"

대표는 이걸 부정하지 않았다. **시작점만 빠순이, 시점은 전지적**으로 절충됐다.

### 그래서 무엇이 남고 무엇이 빠지나

| | |
|--|--|
| **빠진다** | 주인공 둘 · 시점 둘 · 「엔터 시선 / 빠순이 시선」이라는 프레임과 이름 |
| **남는다** | **빠순이로 시작한다**는 출발점 · **덕통사고 → 엔터 사장** 12단 사다리 · 40칸 22/13/5 구조 자체 |
| **새로 붙는다** | **시즌마다 빠순이부터 다시.** 직함·급이 시즌과 어떻게 엮이는지 다시 봐야 한다 ([049](./049_시즌_아이돌교체.md)) |

> 칸마다 붙는 두 줄(아이돌이 겪는 것 / 내가 하는 것)은 **연출 문구로는 남길 수 있다.**
> 반려된 건 **플레이 관점이 둘인 것**이지 칸 설명이 두 줄인 게 아니다.
> 개발 동료의 말이 이 자리의 답이다 — **"대리 만족. 내 아이돌이 행복하니까 나는 행복해."**

## 2. 대표가 새로 던진 숙제

### ① 잭팟 시퀀스 ★ 대표의 진짜 관심사

> **"우리 목표는 슬롯 머신이잖아요"**
> "결국에 우리는 **중독을 일으키는 게임**이니까 어떻게든 잭팟 시퀀스를 넣고 **거기에 올인하게** 만들어야 되지 않나"

대표가 설계안까지 직접 냈다.

```
어떤 칸이 잭팟 시퀀스다
   ↓ 들어가려면 100만 골드를 낸다
주사위 10번 안에 뭔가를 끝내야 한다
   ↓ 못 끝내면 참가비만 날아간다
   ↓ 끝낸 사람이 쌓인 돈을 다 가져간다
터지는 주기(30분? 1시간?)는 우리가 튜닝한다
```

- 전체 유저 누적이냐 개인 누적이냐 — **미정** (대표가 물었고 답 안 남)
- 내가 "잭팟이라는 말이 노골적"이라 하자 대표: **"그냥 잭팟이라고 해 주세요"**
- 모노카피바라 잭팟은 **너무 안 터져서 실패**했다고 내가 인정함

> **개발 동료의 대안이 더 좋다** — "잭팟이란 게 **팬이 아이돌을 직접 만나는 거** 아니에요? 내러티브적으로."
> 아이돌이 판 위를 랜덤하게 돌아다니고, **같은 칸에 도착하면 대박.** 「쫓아간다」는 느낌이 나고 세계관 몰입에도 좋다.

### ② 비용 디테일 — 숙제로 받음

> "서비스의 성공은 **디테일**이라고 생각한다. 아이돌 하나 성공까지 **약 150억**이 든다"

캐스팅(길거리 · 오디션 · 온라인) → 숙식 → 매일 의상·화장 → 성형 → 보컬 트레이너 → 밴드 교육 …
**이 마일스톤과 비용을 조사해서 최대한 게임에 녹여라.** 공연장도 소극장부터 돔까지 **볼륨과 관객수**를 정리.

회의 끝에 **"비용들 정리되면 보내 주세요"**로 과제가 됐다.

> **이견 있음** — 개발 동료: "그건 **엔터사 입장의 디테일**이고, 빠순이는 엔터 비용 구조에 관심이 없다.
> **빠순이 쪽 용어를 더 파는 게 낫지 않나.**" 결론은 안 났다.

### ③ 판매 연동 · 주제곡

- **"게임에 나오는 거 전부 다 구조로 팔 거예요"** — 밴 스킨 · 자동차 등
- 주제곡 세 곡 중 하나 선택. **이번 주 저작권 등록.** 시즌마다 **10곡 이상** 공급
- 협업 아이돌한테 곡을 받고, 안 주면 우리 곡을 쓴다

## 3. 통과한 것 / 지적받은 것

### 통과 (문제 제기 없음)

64칸 → **40칸**(GO와 동일) · 건설 → **덕질**(12항목 6단) · **응원봉**(GO의 집) ·
정거장 약탈 → **딱지** · 감옥 → **병가** · 모험 → **입덕**(원정·총공·시안) ·
보드 성장(버스킹→클럽→아레나) · **밴 이동 연출** · **전투 없음**(대표도 동의)

> 보드 성장은 대표도 바로 이해했다 — **"공중파가 생긴다."**

### 지적받은 것

| 무엇 | 누가 | 내용 |
|------|------|------|
| **덕질 12개 중 고르기** | 개발 동료 | **"12개 중 고르는 건 괴로운 결정이지 흥미로운 결정이 아니다. 피로도."** 나도 인정, 줄일 수 있다고 답 |
| **찬스 카드** | 개발 동료 | 「CF 들어옴」은 아이돌 시점이라 빠순이면 "엄마한테 용돈 받았어"로 바꿔야 한다고 함 → **전지적 확정으로 이 문제는 사라졌다.** 대표: "내가 전지적 시점이면 왜 안 돼요? 내가 이 사람을 컨트롤하고 있는데" |
| **타일 성장 방식** | 개발 동료 | 스테이지 넘김과 타일 업그레이드가 **동시에 가면 헷갈린다.** 나: "실시간으로 바뀌는 건 아니다. 아직 기획 안 함" |
| **천음 리그 업로드** | 나 | UGC 업로드에 부정적이라고 밝힘. "긍정적으로 생각해서 기획 중" |

### 대표가 초반에 낸 제안 (보류)

정거장 약탈을 **「후원 주고받기」**로 — 뺏기는 건 내가 후원하는 것, 뺏어 오는 건 후원을 받는 것.
정거장에서 5명 중 누가 많이 줄지 골라 찍는 재미. 나는 메모만 하고 넘어갔다.
→ 지금 [064 딱지](./064_팬덤게이트_딱지.md)와 **방향이 다르다.** 다시 볼 것.

### 내가 낸 것 중 반응 있던 것

**공공기금을 모아 공연장을 키운다** — 테일러 스위프트가 잠실 공사 때문에 한국 공연을 못 하는 실제 사례.
성장은 했는데 설 무대가 없는 상황을 게임 목표로. 대표 반응은 "생각해 볼게요" 수준.

## 안 정한 것

- 잭팟 누적이 **전체냐 개인이냐**
- 잭팟을 **「아이돌과 같은 칸에서 만나는 것」**으로 갈 것인가
- 시즌이 바뀔 때 **직함·덕력**이 어디까지 리셋인가 ([049](./049_시즌_아이돌교체.md)와 충돌 가능)
- 덕질 12항목을 **몇 개로 줄일 것인가**
- 「후원 주고받기」를 딱지에 얹을 것인가
