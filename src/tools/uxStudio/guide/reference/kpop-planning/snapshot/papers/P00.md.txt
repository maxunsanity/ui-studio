## 1-0. 두 컨셉 한눈에
| | **A안 · 건설 + 도착 성장** | **B안 · 도착 성장만** |
|---|---|---|
| 한 줄 | 하단 **건설 탭**에서 코인으로 **랜드마크 5**를 지어 **스테이지 클리어**. 따로 **건물 6은 도착할 때마다 자람** | 스테이지·건설 탭 없음. **칸에 도착할 때마다** 건물 6이 자라는 것뿐 |
| 무엇을 짓나/키우나 | 랜드마크 5(코인으로 지음) + 건물 6(도착으로 자람) — **둘은 다른 대상** | 건물 6(도착으로 자람) |
| 참고 | 건설 = 모노폴리 GO·모노카피바라 / 도착 성장 = GO에 없음 | GO에 없는 구조만 |
| 목표 | 짧게: 이 판 깨기 · 길게: 건물 정체 올리기 | 건물 정체 올리기(버스킹 → 소극장 → 아레나) |
| 판 전환 | 랜드마크 5 완성 시. 건물 6 단계는 따라감 | 건물 정체 합계 조건(또는 판 전환 없이 도시가 커짐) |
| 장점 | 검증된 목표·코인 소비처 + 우리만의 성장 | 차별점 가장 선명, 헌법 제2조(건물 = 아이돌 계기판)와 딱 맞음 |
| 위험 | 성장 줄이 두 개라 첫 화면 설명이 늘어남 | 스테이지 클리어 쾌감이 없음, 코인 소비처를 따로 만들어야 함 |

> 건설 대상 정리: **랜드마크 5 ≠ 건물 6.** 랜드마크는 판마다 바뀌는 동네 명소(코인으로 짓고 판에 남음), 건물 6은 아이돌이 쓰는 시설(도착으로 자라고 다음 판으로 따라감). 숫자 5는 가안.

## A안 · 건설 + 도착 성장 (현중 11:02 말 그대로)
### A-1. 흐름
```
주사위(×배수) → 칸 도착 ─┬─ 코인 ──→ 하단 건설 탭 → 랜드마크 5 → 스테이지 클리어 → 다음 동네
                        └─ 그 건물 성장 포인트 → 몸집 → 정체 → 칸이 한 단계 위로 (다음 판으로 따라감)
```
### A-2. 건설 줄(GO·모노카피바라식)
1. 판마다 랜드마크 5, 각 3~5단계, 단계마다 코인 비용.
2. 랜드마크 단계 보상 = 주사위·코인·스태프 팩.
3. 5개 다 최대 → 스테이지 클리어 → 다음 동네. 랜드마크는 그 판에 남음(도시 앨범).
### A-3. 도착 성장 줄 = B-2 규칙 그대로
### A-4. 두 줄이 안 부딪히는 이유
- 건설은 **코인**, 도착 성장은 **주사위 배수(투자)** 를 씀 → 자원이 다름.
- 대박은 코인만 크게 → 건설은 빨라지지만 건물 6은 안 큼(제6조 유지).
### A-5. 화면
하단 탭 「건설」 추가(03장 LX-1 「혜택」 자리 조정). 건설 탭 = 이 판 전경 + 랜드마크 5 카드 + 코인 버튼. 도착 때는 B-4 줌 연출.

---

## B안 · 도착 성장만 (스테이지 없음 · GO에 없는 것)
### B-1. 흐름
주사위(×배수 = 투자) → 칸 도착 → 코인 **+ 그 건물 성장 포인트** → 몸집 눈금 → 정체 변신 → 칸 한 단계 위로 → (계속)
### B-2. 도착 성장 규칙 v0 (A·B 공통)
1. **성장 포인트 = 도착 × 주사위 배수.** ×1 도착 +1, ×3 도착 +3. 「쓴 만큼 큼」(제5조). 대박은 코인만, 건물은 안 키움(제6조·R-04-2).
2. **몸집:** 포인트가 쌓이면 층·창·불빛이 조금씩(연출 T1).
3. **정체:** 몸집 최대 → 다른 건물로 변신 3단(굿즈 Lv.1·2·3). 그 건물 칸 전부 이름·연출·기본 수입이 오름(연출 T2).
4. **꾸밈:** 정체 변신·카드 보상으로 간판·스킨(연출 T3). 카드팩은 몸집 눈금·정체 변신 때만.
5. 건물 없는 칸(코너·정산·쟁탈·팬덤 반응·생활)은 포인트 없음. 쟁탈 4칸은 연결 건물 +1 후보.
6. 새 게이지 금지. 건물이 곧 계기판. 도착 때만 게이지가 잠깐 뜸.
7. (B만) 판 전환: 건물 정체 합계가 일정 이상이면 다음 동네. 건물 단계는 그대로 따라감.
### B-3. 모노폴리 GO와 다른 점 (핵심)
| 비교 | 모노폴리 GO | 도착 성장(A·B 공통) |
|---|---|---|
| 무엇이 크나 | 판마다 정해진 랜드마크 | 아이돌이 쓰는 건물 6 |
| 어떻게 | 건설 버튼에 코인 투입 | **도착하면 자동** |
| 어디가 | 내가 고른 곳 | **내가 간 곳**(주사위가 떨어진 곳) |
| 판을 깨면 | 새 판 0부터, 전 판은 두고 떠남 | **건물 단계가 따라옴**(도시만 바뀜) |
| 칸 | 칸은 그대로(집·호텔 무작위) | 칸 이름·연출·수입이 건물과 같이 오름 |
| 모습 | 같은 모양이 커짐 | **다른 건물이 됨**(버스킹 → 소극장 → 아레나) |
| 의미 | 도시 수집 | 아이돌 성장 계기판(헌법 제2조) |
### B-4. 화면
하단 건설 탭 없음. 도착 시 줌인 연출(연출 v0)이 성장 피드백. 도시 패널 = 건물 6 상태가 항상 보임.

## 1-1. 돈은 어디서 쓰나 (클로드 R54 과금 자리와 맞춤)
| 과금·소비 자리 | A안 | B안 |
|---|---|---|
| 코인 쓰는 곳 | **건설 탭(랜드마크)** — 주 소비처 | 건설 없음 → 스태프·꾸밈·음방 준비로 돌려야 함(**빈칸, 설계 필요**) |
| 주사위 팩 | 주사위 = 배수(투자) = 건물 성장 + 코인 → 건설 | 주사위 = 배수 = 건물 성장. 코인 쓸 곳이 약해 동기가 성장 하나로 좁음 |
| 카드팩 | 상점 팩(PM-7) + 성장 드롭(몸집·정체 때만) + 랜드마크 보상 | 상점 팩(PM-7) + 성장 드롭만 |
| 시즌 패스 | 스테이지 클리어가 패스 진행과 붙기 쉬움(PM-15) | 패스 진행 기준을 건물 단계로 새로 잡아야 함 |
| 꾸밈 | 건물 6 꾸밈(PM-12) | 같음 |
→ 과금 설계는 A가 훨씬 수월, B는 코인 소비처를 새로 만들어야 성립.
