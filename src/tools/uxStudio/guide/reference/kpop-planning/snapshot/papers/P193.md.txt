# P193 · 새 도시 진출 · 상세 기획서

**이 문서는** 기존 성장으로 지역을 열고 방문해 현지 활동·팬·곡 성적을 남기는 규칙을 정리합니다. 앨범 재화로 달리는 시티 투어 레이싱은 독립 기획서에서 관리합니다.

**보는 법** 1장 지역 흐름 → 4장 조건·방문·정산 → 7장 연결 순서로 읽습니다. 방문 비교 시안은 대표 기획서에서 확인합니다.

**지금 상태** 현재 개발되지 않음, 진행 중.

## 1. 개요

출처: (합침) 제안서 [새 도시 진출](../../../proposal-concept/city-expand.html) · [성장 관계](../%EA%B0%9C%EB%B0%9C%EC%A7%84%ED%96%89%EA%B8%B0%ED%9A%8D_v01/%EC%BD%98%ED%85%90%EC%B8%A0%EB%B3%84_v03/%EC%84%B1%EC%9E%A5%EA%B4%80%EA%B3%84_%EA%B8%B0%ED%9A%8D%EC%84%9C.html)·[음원과 페스티벌](./%EC%82%B0%EC%B6%9C_%EA%B8%B0%ED%9A%8D%EC%84%9C_%EC%9D%8C%EC%9B%90%C3%97%ED%8E%98%EC%8A%A4%ED%8B%B0%EB%B2%8C_v1_%ED%81%B4%EB%A1%9C%EB%93%9C.html).

```mermaid
flowchart LR
  N0["본진에서 성장"] --> N1
  N1["조건 충족·입장권 사용"] --> N2
  N2["지역 방문·현지 활동"] --> N3
  N3["정산·복귀·지역 성적"]
```

### 콘텐츠 경계

본진 시설·성장 원본을 바탕으로 지역 열림·방문·현지 활동·정산을 관리합니다. 곡의 활동과 지역 성적은 [음원](../%EA%B0%9C%EB%B0%9C%EC%A7%84%ED%96%89%EA%B8%B0%ED%9A%8D_v01/%EC%BD%98%ED%85%90%EC%B8%A0%EB%B3%84_v03/%EC%9D%8C%EC%9B%90%EC%98%81%EC%83%81_%ED%95%B5%EC%8B%AC%EC%A0%9C%EC%95%88%EC%84%9C.html), 시티 투어와 최종 경쟁은 [페스티벌](../%EA%B0%9C%EB%B0%9C%EC%A7%84%ED%96%89%EA%B8%B0%ED%9A%8D_v01/%EC%BD%98%ED%85%90%EC%B8%A0%EB%B3%84_v03/%EC%9B%94%EB%93%9C%ED%8E%98%EC%8A%A4%ED%8B%B0%EB%B2%8C_%ED%95%B5%EC%8B%AC%EC%A0%9C%EC%95%88%EC%84%9C.html)에 연결합니다.

### 현재 기준과 목표

| 항목 | 규칙 |
|---|---|
| 본진 | 기존 도시·보드 원본 사용 |
| 지역 | 영어권·중국어권·일본어권, 대표 도시 이름 결정 대기 |
| 열림 | 기존 개인·팀·외국어 성장 조건 참조 |
| 방문 | 입장권과 방문 분량 사용 |
| 현지 기록 | 지역별 활동·팬·정산·곡 성적 |
| 독립 시티 투어 | P231·P232의 앨범 레이싱 참조. 실제 방문 기록과 별개 |

지역 방문과 연고 도시는 기존 지역 목록을 참조합니다. 레이싱의 앨범 리그/경기 원장은 지역 방문 원장과 분리합니다.


## 4. 상세 기획

### 한 판 순서 (임시 시안)

| 점검 | 내용 |
|---|---|
| 시작·종료 | 지역 조건과 입장권 확인 후 방문, 분량 종료 또는 중도 귀환 |
| 입력·출력 | 성장·지역·입장권 → 현지 활동·팬·정산·복귀 |
| 상태와 전이 | 잠김 → 열림 → 방문 → 정산 → 본진 |
| 판정 | 실제 성장 조건·입장권·현재 방문 상태 |
| 오류·예외 | 미공급 조건·입장권 부족·동시 방문·중복 정산 |
| 저장·복원 | 지역 열림·활동·팬·입장권·방문·수령을 같은 시즌으로 보존 |
| 다른 모듈 연결 | 성장·도시·팬·음원·시티 투어·시즌 |

```mermaid
flowchart LR
  N0["조건·입장권 확인"] --> N1
  N1["현지 보드·무대"] --> N2
  N2["정산과 복귀"] --> N3
  N3["지역 성적 보관"]
```

### 지역·열림·입장권 (임시 시안)

지역의 언어와 멤버 외국어·팀·단계를 연결합니다. 능력 조건과 방문 비용을 따로 판정하고, 미정 문턱을 열림으로 처리하지 않습니다. 지역 ID는 공용 지역 표를 사용합니다. 입장권 공급·수량·방문 분량은 해당 원본과 발란스 규칙으로 정합니다.

### 현지 활동과 본진 (임시 시안)

현지 팬은 지역별로 기록하고 총수 표시와 구분합니다. 방문 중 본진 시설 성장의 중지·재개 범위를 명시합니다. 크루 소속과 교류는 유지하며, 홍보·투표는 해당 페스티벌 회차의 자격과 평가 규칙으로 확인합니다.

### 발매곡·독립 시티 투어와의 관계

발매곡의 언어·장르·무대 성과를 현지 활동과 곡 이력에 연결하는 것은 지역 방문의 후속 기획입니다. [시티 투어 대표](../개발진행기획_v01/콘텐츠별_v03/시티투어_핵심제안서.html) · [시티 투어 상세](산출_기획서_시티투어_상세_v1.html)는 앨범 재화·아이돌 능력으로 진행하는 독립5팀10바퀴 레이싱을 관리합니다. 레이싱 참가를 실제 지역 방문/입장권 사용/귀환 완료로 기록하지 않습니다.

### 정산·귀환 (임시 시안)

방문 분량을 마치면 정산하고 귀환합니다. 중도 귀환은 완료 보너스와 구분합니다. 같은 방문의 귀환·수령 기록을 보관해 재접속과 중복 요청이 추가 수익을 만들지 않게 합니다.

### 필요 시스템

공용 지역 · 조건 · 입장권 · 방문 진행 · 현지 팬·활동 · 곡 이력 · 정산·귀환 · 시티 투어 참조.

### 화면·연출 목록

지역 조건·입장권 · 현지 보드·공연 · 지역 성적 · 정산·귀환.

### 남은 결정

- 대표 도시 이름 — 결정 대기
- 진입 문턱·입장권·방문 분량 — 발란스 대기
- 지역 방문 활동과 곡 성적의 연결 — 별도 기획
