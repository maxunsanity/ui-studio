# 성장 테스트 도구 통합 기획 (T03)

**이 문서는** [시뮬레이터](../../../game-simulator.html)의 **성장 메뉴 6개**(아이돌 성장 · [팬 증가](../시스템기획/S05_팬덤.md) · 클릭 성장 · 능력 허브 · 관계 허브 · [뉴런](../개발진행기획_v01/콘텐츠별_v03/뉴런_기획서.html))를 하나의 시험 도구로 묶은 기획입니다. 시작을 누르면 지금 팀의 능력·[라포](../개발진행기획_v01/콘텐츠별_v03/라포AI탐험_기획서.html)·팬이 한 회씩 계속 변하고, 정지하면 그 값에서 멈춥니다. 실제 저장·지갑·보상은 바꾸지 않는 **시험 전용** 도구입니다.

**보는 법**
- 1장: 모든 메뉴의 공통 조작(시작/정지/1회 진행, 화면 배치)
- 2장: 메뉴 6개가 각각 무엇을 보여 주는지
- 3~5장: 같은 팀을 어떻게 읽는지, 무엇을 계산하고 무엇은 계산하지 않는지
- 7장: 앞으로 붙일 것
- 시뮬레이터: [아이돌 성장 열기](/docs/planning/game-simulator.html?module=simulator_module_idol_growth) (7007에서 열림 확인 10/30)
- 날짜별로 보려면: [날짜별 기록](T03_성장테스트도구_날짜별기록.md)

**지금 상태**
- **개발됨**: 성장 메뉴 6개 공통 작업대, 시작·정지·1회 진행, 속도 ×0.5/1/2/5/10, 시험 주사위 배수, 시험 사본 이어가기 (코드: `src/simulator/growth-lab/`, 설정: `data/simulator/growth-lab.json`)
- **현재 개발되지 않음, 진행 중**: 7장의 추가 관측(카드·미션·[모험](../개발진행기획_v01/콘텐츠별_v03/라포AI탐험_기획서.html) 기여 분해, 승급 준비도, 언어 전용 계산, 실제 게임 복제 등)
- 화면 속도·배수와 아직 정해지지 않은 원본 값은 임시입니다. 확정 수치가 아닙니다.

## 1 모든 성장 메뉴의 공통 조작

**대상/조건 선택 → 시작 → 수치 변화 관측 → 정지 → 같은 값에서 재개** 순서입니다. 시작·정지와 1회 진행은 오른쪽 하단, 현재 값·진행 횟수·시작과 차이·곡선은 오른쪽 상단에 고정합니다. 가운데 조건 영역만 스크롤됩니다. 공통 진행 정보는 접힌 상태로 시작하고 필요할 때 펼칩니다.

| 위치 | 정보와 조작 |
|---|---|
| 왼쪽 모바일 | 원래 지갑·팀, 능력 6축, 관계 4축, 팬 3층, 기존 3D 뉴런 |
| 오른쪽 고정 상단 | 무엇이 변하는지, 누적 진행 횟수, 현재 수치, 시작과 차이, 최근 곡선 |
| 오른쪽 가운데 | 대상·콘텐츠, 정밀 조건, 전체 전후 수치, 최근 계산 과정, 원본/대기 사유 |
| 오른쪽 고정 하단 | 진행 속도, 시험 주사위 배수, 시작/정지, 1회 진행, 상태 |

속도 ×0.5/1/2/5/10은 화면 진행 간격입니다. 게임 성장량을 바꾸는 값이 아닙니다. 주사위 배수 목록은 dice_mult_unlock_rule.csv를 읽으며 실제 해금·소모를 변경하지 않습니다. 관계·팬 시험에는 원본에 없는 주사위 효과를 덧붙이지 않습니다.

조건을 바꾸면 진행을 멈추고 새 조건으로 새 시험을 준비합니다. 속도와 주사위 배수 변경은 다음 회차부터 이어 적용합니다. 탭 이동·페이지 숨김·도구 폐기 때 자동 정지하고 밀린 회차를 몰아서 실행하지 않습니다.

## 2 메뉴 순서와 역할

아이돌 성장 → 팬 증가 → 클릭 성장 → 능력 허브 → 관계 허브 → **뉴런** 순서입니다.

| 메뉴 | 연속 관측 | 원본 계산 |
|---|---|---|
| 아이돌 성장 | 18세부 또는 선택 세부의 점진 상승·재능 이후 감속·단계 상한 | growth-step-runtime |
| 팬 증가 | 하루 추가 팬·능력 입력에 따른 팬 7층 이동, 모바일 3층 | replaySolo |
| 클릭 성장 | 콘텐츠 반복·지속 가산·첫 회 즉시 가산·상한·이월 | previewGrowth 12단계 |
| 능력 허브 | 개별/전체 멤버, 시작 능력·재능·시험 단계·건물 단계에 따른 성장 | 아이돌 성장과 같은 엔진 |
| 관계 허브 | 선택 쌍의 사건 반복·가까워짐·멀어짐·4축/단계·조건 차단 | initializeSourcePairs, previewRelationship |
| 뉴런 | 관계 선 변화 또는 능력 성장 모드를 기존 3D에 투영 | 위 계산 결과 + 기존 createNeuronPanel |

뉴런은 관계 허브 뒤에 둡니다. 시험 사본은 3D의 displayOnly 시험 경로로만 전달하고 실제 저장 체크포인트로 가장하지 않습니다. 관계 모드는 관계 확대, 능력 모드는 멤버 능력 확대로 시작합니다.

## 3 같은 팀과 시험 사본

현재 scope·session/run이 일치하는 저장을 우선합니다. 유효한 저장이 없고 handoff만 있으면 전송 당시 값으로 표시합니다. 임의 팀이나 미공급 능력값을 만들지 않습니다. 점수 배율은 idol_ability_talent.csv의 ability_score_mult와 공통 scaleScore/unscaleScore를 사용합니다.

한 회차는 기존 계산기로 직전 시험 결과에서 계산합니다. 직접 시작값·관계 시작값·첫 회 즉시 효과는 최초 회차에만 넣습니다. 시작과 차이는 처음 시험값을 기준으로 누적합니다. 조건을 열거나 결과가 갱신될 때 입력 노드를 재생성하지 않습니다.

자료 대기가 없는 결과는 메뉴를 떠날 때 같은 scope·session의 메모리 시험 사본에 이어집니다. 다음 성장 메뉴에는 ‘시험 사본 이어짐’을 표시합니다. 자료 대기가 있는 결과는 다른 메뉴의 확정 입력으로 이어 주지 않습니다. 실제 저장 버전이 바뀌면 시험 사본과 결과를 버리고 새 원본을 읽습니다. 재접속하거나 페이지를 다시 열 때 실제 저장에 시험 결과를 덮어쓰지 않습니다.

실제 지갑·주사위·보상·저장 revision은 변경하지 않습니다. 시뮬레이터 공통 프레임 안에서만 모바일을 표시합니다.

## 4 감소·누락·조건의 정확한 표시

현재 라포가 하한 0이면 음수 사건을 반복해도 더 내려가지 않습니다. 이를 억지로 감소시키지 않습니다. ‘중간 관계에서 가까워짐/멀어짐’을 직접 고르면 원본 축의 최소·최대 중앙을 시험 시작값으로 넣습니다. 현재 관계 기본값과 명확히 구분합니다. 사건 크기·[성격](../시스템기획/S18_멤버성격생성_MBTI방식_v01.md)·선배 고정·조건·상하한은 원본 계산기를 따릅니다. 쿨다운 경과 자료가 없는 사건은 연속 재적용하지 않고 멈춥니다.

팬의 실제 0과 미공급 null을 구분합니다. 가상 팬은 ‘팬층 시험 예시 불러오기’를 누를 때만 채웁니다. 예시·하루 추가 팬은 시험 입력이며 실제 보유 팬/지급량이 아닙니다. 원본의 머글 미정은 유지합니다.

클릭 성장 기본 콘텐츠는 원본 목록에서 세부 성장 출처를 골라 바로 시험할 수 있게 합니다. 언어·숨긴 능력의 전용 시작값이 없으면 0으로 만들지 않고 자료 대기로 표시합니다. 수치가 임시인 원본은 임시 표시를 유지합니다.

모든 화면 속도·시안 설정과 미확정 원본 값은 **임시(나중에 결정)**입니다. 확정 수치나 승인으로 기록하지 않습니다.

## 5 계산 범위

성장 입력 시험은 입력·주사위 시험 배수·레슨 효과·재능·단계 상한을 계산합니다. 자동 승급, 보드 도착 확률, 실제 돈/주사위 소모, 카드 소유/최초 지급, 일일 상한·전체 소득은 실제 게임 정산을 재생한 결과가 아닙니다.

클릭 성장은 기존 출처·보정·상한·이월을 재사용합니다. 지속 가산은 매 회, 즉시 가산은 첫 회만 적용합니다. 실제 카드 보상 지급이라고 부르지 않습니다. 팬은 기존 하루 이동표를 사용하며 실제 수익·습격 정산은 별도입니다.

## 6 경험에서 반영한 기준

| 겪은 문제 | 이번 기준 |
|---|---|
| 무슨 시험인지 모름·결과만 한 번 표시 | 메뉴별 목적, 바로 변하는 현재 수치, 시작/정지/1회 진행 |
| 실행 버튼이 아래로 밀림 | 결과와 조작부를 고정하고 가운데만 독립 스크롤 |
| 공통 정보가 공간을 차지함 | 기본 접힘·필요할 때 펼침 |
| 화면이 자동 스크롤되거나 입력 초점이 사라짐 | 매 회 값·그래프·표 셀만 갱신, 입력 DOM 유지 |
| 배수·점수 단위 혼동 | 원본 배수 목록·점수 공통 변환, 속도와 성장 배수 분리 |
| 임시 라포가 실제처럼 보임 | 명시적 시험 시나리오·displayOnly 뉴런 |
| 다른 저장의 오래된 팀을 읽음 | 세션·scope 검증·버전 변경 시 시험 분기 무효화 |
| 누락 import가 전체 부팅을 막음 | 새 모듈 먼저 생성하고 문법·실제 진입 확인 |
| 웹뷰 전체로 커지는 연출 | 공통 모바일 프레임 내부에만 화면 배치 |
| 저장 용량·다중 writer 충돌 | 메모리 시험만 진행하고 저장/정산을 쓰지 않음 |

## 7 앞으로 붙일 관측 (현재 개발되지 않음, 진행 중)

아래는 모두 **현재 개발되지 않음, 진행 중**입니다. 정해지지 않은 값은 빈칸(발란스 대기)으로 둡니다.

| 추가 관측 | 필요한 원본 |
|---|---|
| 레슨·최초 카드·미션·모험 성장 기여 분해 | 실제 receipt와 사건 장부 |
| 승급 준비도와 막힌 문 | [P107](../개발진행기획_v01/콘텐츠별_v03/아이돌능력_기획서.html)/[P147](../개발진행기획_v01/콘텐츠별_v03/팀결성_팀스탯_기획서.html)의 실제 카드 소유·능력·언어·승급 판정 |
| 태도·성실성·컨디션 영향 | 숨긴 상태와 효과 원본 |
| 언어 3종·아카데미·기반 성장 | 학습/기반 정본과 전용 현재값 |
| 공연·연습·출동·여정 경험 | 경험 규칙·기존 누적 기록 |
| 1~5명 참여의 실제 배분 비교 | 같은 구성과 배분 엔진 |
| 돈·주사위·시간 대비 목표 도달 | 전체 보드 경제 원장·일일 상한 |
| 관계 원인·회복·쿨다운 이력 | 실제 관계 사건 receipt와 경과 시간 |
| 팬 병목·이탈·수익 | 팬 7층·부정 사건·수익 장부 |
| 시험 재현 | 조건·표 버전·세션·seed·결과 묶음 |

효과나 보너스를 임의로 만들지 않고 원래 계산기의 자료 연결을 먼저 확대합니다. 전체 게임 실행용 시험 복제는 저장 분리·revision·재지급 방지 계약을 먼저 확정해야 합니다.
