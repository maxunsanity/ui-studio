# 002 · 모노카피바라와 같은 점 / 다른 점

> 기획서 본문 쓰기 **전** 정리. 확정 헌법 아님. 컨셉 대화(2026-09-14) 기준.

한 줄: **손맛(주사위·판·모으기·보내기)은 닮고, 내가 누구인지·판이 왜 도는지·칸이 뭔지는 다르다.**

---

## 같은 점 (빌려와도 어색하지 않은 것)

| 감각 | 모노카피바라 | kpopmonsters에서도 |
|------|--------------|-------------------|
| 판을 돈다 | 주사위 굴려 칸에 떨어짐 | 같음. 도착은 운·행운 |
| 모은다 | 카드·성장 | 최애·덕질템·카드 감각 |
| 보낸다 | 여정·출동·기다리기 | 응원·파견·결과 기다리는 맛 |
| 시즌 기분 | 시즌·이벤트로 판 분위기 바뀜 | 새 보드 드롭·시즌 테마 |
| 가벼운 날 / 무거운 날 | 칸마다 무게가 다름 | 탭 몇 번 vs 한판 미니게임 |

→ 플레이어가 손에 익힐 **기본 버릇**은 같이 가져가도 된다.

## 다른 점 (여기가 kpopmonsters 얼굴)

| | 모노카피바라 | kpopmonsters |
|---|--------------|--------------|
| 나는 누구 | 보드 위 모험·경영 쪽 캐릭터 | **빠순이 → (나중) 기획사 사장** |
| 이야기 척추 | 보드·성장·시즌 루프 | **덕질 성장담** (팬으로 시작해서 사장까지) |
| 칸이 의미하는 것 | 보드 시스템·콘텐츠 칸 | **아이돌 일정** (연습·방송·공연·생활). 빠순이는 특수칸으로 들어옴 |
| 판의 느낌 | 익숙한 고정 뼈대 위에서 콘텐츠 | **보드가 생성**됨 (“○○○ 보드가 생성되었습니다”) |
| 칸 수 | (기존 64칸 뼈대) | **칸 수는 거의 고정**, 안에 깔리는 미션만 갈아끼움 |
| 뭐가 바뀌나 | 시즌·이벤트·콘텐츠 | **바닥 덕질은 유지**, 위에 시즌 미션만 교체 |
| 유저가 고르는 것 | (보드 위 선택·빌드) | **시즌 방향·빌드만** 고르고, 실제 낙점은 주사위 |
| 미션 밀도 | 칸 = 게임 콘텐츠 | 칸 = **아이돌의 하루** (전부 풀게임 X) |
| 바깥 무대 | 인게임 이벤트 중심 | 팬 창작 리그·큰 잔치 등은 **보드 밖 무대**로 둘 후보 (시드) |

## 한눈에

- **같음:** 굴리고, 모으고, 보내고, 시즌 타는 손맛  
- **다름:** 주인공이 빠순이인 점, 칸이 “덕질 하루”인 점, 판이 “새로 떨어지는” 점, 사장으로 커가는 점  

이 네 줄이 안 섞이면, 모노카피바라 복사 게임이 아니라 **덕질 성장 게임**으로 보인다.
