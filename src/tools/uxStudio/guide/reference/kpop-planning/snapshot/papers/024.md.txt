# 024 · 같다름 — 모노폴리 GO 보드 구성

> status: draft · **025 본문 전** 준비. 패턴: [002](./002_모노카피바라_같은점_다른점.md) · [009](./009_같다름_칸역할매칭.md).  
> 근거 시드(모노카피): [89 GO 해체](../../../../모노카피바라%20프로젝트/monocapibara/docs/planning/economy/89_MONOPOLY_GO_TEARDOWN.md) · [26 보드구성](../../../../모노카피바라%20프로젝트/monocapibara/docs/planning/26_BOARD_FULL_COMPOSITION.md) · [30 칸카탈로그](../../../../모노카피바라%20프로젝트/monocapibara/docs/planning/30_TILE_CATALOG.md) · [39 정거장UI](../../../../모노카피바라%20프로젝트/monocapibara/docs/planning/39_STATION_UI.md) · `land_tier_config` T1–T8.  
> 우리 쪽: [023](./023_칸역할_덕질매칭.md) · [017](./017_미션_성장단계_배치.md) · [020](./020_성장사다리_빠순이에서_사장.md) · 연구시드 R01.

> ⚠ **현행과 싸우는 대목이 있다 (2026-09-17 확인).**
> 이 문서는 칸을 **빠순이가 하는 일**로 읽는다. 현행은 반대다 — **색 난 대지 22칸 = 아이돌 일정(엔터)**, 빠순이는 **특수칸(창구)**로 들어온다.
> 기준은 [048](./048_피치_두시선.md) · [045](./045_현행Board1_핸드오프.md) · [034](./034_보드1_1차잠금.md).
> **버리지 않는다.** 여기 쌓인 덕질 행동·풀은 다른 보드·시나리오 필러·시즌 미션의 **재료**로 그대로 쓴다.

한 줄: **판의 뼈대(40칸·8색 대지·정거장 약탈·코너 리듬)는 GO/모노와 같고, 판이 왜 바뀌는지·대지가 뭔지·약탈이 뭔지는 덕질 성장으로 갈아끼운다.**

## 0. 전제 (이 문서에서 잠그는 것)

| # | 결정 | 근거 |
|---|------|------|
| P1 | **1차 보드 = Monopoly GO 40칸 뼈대** | 89 §제2조(등급A). Cap 전용 24칸은 보드 밖/후순위 ([023] §1 A안) |
| P2 | **LAND = 한 역할 가족 × 8색(티어)** | GO 부동산 8색 · 모노 `land_tier_config` T1–T8 |
| P3 | **레벨↑ = 같은 루프의 내용·깊이 진화** | 키우기 렌즈([005](./005_핵심시각_키우기.md)). GO의 “테마 보드 클리어→다음 도시 스킨”과 **판타지 축이 다름** |
| P4 | Cap `TERRITORY`/`TRAIN`/`DUNGEON`… | 1차 40칸에 **안 넣음**. 필요 시 보드 옆 이벤트·후순위 ([023] §2-3) |

## 1. 같은 점 (빌려와도 어색하지 않은 뼈대)

| 감각 | Monopoly GO / 모노카피 | kpopmonsters에서도 |
|------|------------------------|-------------------|
| **루프** | 사각 링을 돈다. 주사위→착지→효과 | 같음. 도착은 운 |
| **칸 = 역할 1개** | LAND·정거장·찬스… 한 칸 한 기능 (26 D4) | 역할 유지, **내용만 덕질** |
| **수입 밀도** | GO: 부동산 22+GO ≈ **57.5%**가 상시 수입 (89) | LAND 비중을 높게 유지 → 응원 노동이 주수입 |
| **8색 대지** | 색=세트·등급. 모노 T1–T8=보상 등급·색 | **같은 역할(응원노동→재화)**, 색=강도/세트 |
| **정거장 ×4** | Railroad → Bank Heist / Shutdown (89·39) | **경쟁 미니** 4칸. 약탈/방어 감각만 덕질로 |
| **코너 4** | GO · Jail/Visit · Free Parking · Go To Jail | 하루 기준점 · 번아웃 · 회복 · 강제 멈춤 |
| **찬스 / 커뮤니티** | Chance 3 + Chest 3 (GO) · 모노는 CHANCE 3 + COMMUNITY 4 | 운 사건 / 팬덤 협력 저금통 |
| **유틸 ×2 · 세금 ×2** | GO 전기·수도 2 + 세금 2 (89) | **두 종류의 소액/정기 장치** + **큰 지출 2** |
| **짓기→클리어** | 랜드마크 완공 = 보드 완료 → 다음 보드 (89 §제3조) | **엔진으로만** 유지. 클리어 보상에 아이 호흡·직함 스탬프 ([023] §0) |
| **정거장 이중 롤** | 등급 롤 × 방식(Shutdown/Heist) (39 §2-A) | 등급 × (차트공격/줄싸움 등) — 수치 미확 |

→ 플레이어가 손에 익힐 **보드 버릇**은 GO와 같게 가져간다.

## 2. 다른 점 (여기가 kpopmonsters 얼굴)

| | Monopoly GO / 모노카피 | kpopmonsters |
|---|------------------------|--------------|
| **내가 도는 이유** | 도시 랜드마크 깨고 **다음 보드(테마 스킨)** | 같은 판 위에서 **빠순이가 자라고 아이를 키움** |
| **보드 진화의 판타지** | 스테이지/테마 클리어가 1차 보상 감각 | **레벨·직함·아이돌 호흡**이 칸 내용 깊이를 바꿈. 클리어는 엔진 노트 |
| **LAND가 하는 일** | GO: 렌트 · 모노: **전투 8단→돈** (29 §29.1) | **응원 노동→덕질 재화** (스밍·투표·차트…). 전투판타지 ❌ |
| **8색의 의미** | 지명·렌트 티어 / 모노 잔돈→큰몫 라벨 | **덕질 강도 세트** (입문응원→키우기정점). 13개 다른 집안일 IP ❌ |
| **STATION 약탈** | 상대 도시 Shutdown · 금고 Heist · 방패→펫 (39) | **차트전쟁 공격·수비 / 줄싸움 / 총공 레이드** |
| **STATION 방어** | 쉴드·펫이 막아냄 (×0.35) | **팬덤 방어진·쉴드 슬로건·총공 수비** (이름 미확) |
| **JAIL** | 수감 · 더블 탈출 | **번아웃 형태** (관심소진·안티상처·돈탈진…) — 레벨마다 변주 |
| **COMMUNITY** | 공동 금고 + 친구 미니 (GO) | **총공 모금·나눔·팬덤 저금통** |
| **CHANCE** | 현금 ± 카드 | **당첨·낙첨·알고리즘 떡상·논란** |
| **UTILITY** | GO: 지불→후반 순자산 수입 · 모노: 슬롯 1칸 | **GO처럼 2종** 권고: 예) 광고포인트 / 알바·부업 운 |
| **TAX** | 소득·사치 세금 | **앨범 풀버전 · 티켓·원정비** 같은 큰 지출 |
| **Cap 24칸** | 악마·던전·영지·수련… (26 §1-2) | **1차 제외**. 한판 이벤트·후순위로 주차 |
| **시즌/레벨 스킨** | GO: 보드마다 도시 테마 교체 | **구조 고정**, 풀·카피·감정 가중만 레벨에 따라 교체 ([004](./004_보드와_미션.md) 바닥+시즌) |

## 3. 레벨→보드 진화 — 핵심 같다름

| | GO / 모노 | kpopmonsters (025에서 전개) |
|---|-----------|------------------------------|
| 무엇이 바뀌나 | **다음 보드** = 새 도시 스킨·건설비 곡선 (89 3단) | **같은 40칸 역할** 위에서 LAND 8색의 *깊이*·STATION 스케일·JAIL 변주가 레벨과 함께 자람 |
| 플레이어 감각 | “도쿄 깼다 → 파리” | “입덕 보드 돌던 손이, 총대·내판 보드에서도 **같은 버릇**으로 돈다” |
| 고정 | 40칸 역할 슬롯 | **역할·개수·코너 리듬** |
| 교체 | 랜드마크 아트·보드 이름 | **미션 풀(010–016) 가중 · 카피 · ○/● 비중 · 짓기 슬롯 목표** |
| 금지로 둘 것 | — | “레벨=테마 스테이지 클리어가 본체”로 읽히게 쓰기. 클리어는 **엔진**만 ([023] §0) |

---

## 4. 한눈에

- **같음:** 40칸 루프 · 8색 LAND 가족 · 정거장×4 약탈/방어 · 코너 · 찬스/커뮤니티 · 유틸≈2 · 세금2 · 짓기 클리어 엔진  
- **다름:** LAND=덕질 노동 · 약탈=차트/줄 전쟁 · 감옥=번아웃 · **보드 진화=성장(레벨)이지 GO 테마 클리어 판타지 아님** · Cap 환상칸 1차 제외  

이 네 줄이 안 섞이면, 모노폴리 GO 테마 수집기가 아니라 **덕질이 자라는 보드**로 보인다.
