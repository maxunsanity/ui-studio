# 022 · 40칸 루프 보드 기본 시안

> status: draft · HTML 시안.  
> 맞물림: [009](./009_같다름_칸역할매칭.md) · [023](./023_칸역할_덕질매칭.md) · [004](./004_보드와_미션.md) · [021](./021_보드에_사다리_얹기.md).

> ⚠ **현행과 싸우는 대목이 있다 (2026-09-17 확인).**
> 이 문서는 칸을 **빠순이가 하는 일**로 읽는다. 현행은 반대다 — **색 난 대지 22칸 = 아이돌 일정(엔터)**, 빠순이는 **특수칸(창구)**로 들어온다.
> 기준은 [048](./048_피치_두시선.md) · [045](./045_현행Board1_핸드오프.md) · [034](./034_보드1_1차잠금.md).
> **버리지 않는다.** 여기 쌓인 덕질 행동·풀은 다른 보드·시나리오 필러·시즌 미션의 **재료**로 그대로 쓴다.

한 줄: **40칸 루프(모노 뼈대) 기본 시안.** 칸마다 역할 태그·이름·한 줄 설명. Board 1·2·3은 역할 동일·테마·짓기(랜드마크)만 교체. 스토리 챕터 슬라이드가 아님.

## 보는 법

1. 상단 HOWTO: **루프 보드 기본** (챕터 슬라이드 아님).
2. Board 1 / 2 / 3 탭 — 배너 「{테마} 보드가 생성되었습니다」.
3. 사각 링 40칸을 시계방향(GO→)으로 읽는다. 칸 위: `[노동]` 등 역할 + 이름 + 설명.
4. 오른쪽 랜드마크 5슬롯에 +1 짓기 → 다 채우면 보드 클리어 → 다음 보드 해금.
5. 이중 배지: 아이돌호흡 | 내직함 (레이어, 보드 대체 아님).
6. (옵션) 주사위 → 랜덤 칸 하이라이트.

## 시안이 보여주는 것

1. **40칸 LOOP** (모노폴리 사각 링 · 코너 GO / JAIL / PARK / GOTO_JAIL)
2. 칸 위 **역할 태그** `[노동]` `[관계]` `[수련]` `[경쟁]` `[협력]` `[운]` `[지출]` `[출발]` `[멈춤]` `[회복]`
3. 타일 믹스(023 스케일): LAND~13 · TERRITORY~5 · TRAIN~5 · STATION4 · COMMUNITY3 · CHANCE3 · TAX2 · UTILITY1 · 코너4
4. **Board 1·2·3** 진행 UI (같은 40역할 · 테마 스킨 + 랜드마크만 다름)
5. 랜드마크 짓기 미터 → 클리어 시 다음 보드 해금
6. Cap 던전·악마 칸 **없음**

칸 이름·랜드마크는 시안이다. SSoT는 023·009·004·021.
