## 이게 뭐냐

**엔터사·투자자에게 “왜 K-pop × 보드/타이쿤이 팔리는가”를 5분 안에 보여주는 상품성 콘텐츠 1차.** 시스템 본문(시즌 루프·카드 규칙·Lead 수치)은 다시 쓰지 않고, **파트너 가치·콘텐츠 기둥·데모 스토리·체크리스트**만 묶는다.

## 언제 쓰나

제안서 B 초안·피치 덱 앞장 · 파트너 미팅 오프닝 · 아트/굿즈에 “무엇을 팔지”를 넘길 때. 단이 흐름·클로드 LeadGen과 **교차 링크로만** 맞춘다.

## 한 줄

> **판(40칸)·건물(상징+입구)·카드·원정·공유 모험은 Mono에 있고, 우리는 K-pop 스킨·샘플 IP 팩·굿즈 실루엣으로 상품을 판다.**

## 자세히

### ① 왜 팔리는가 (파트너·엔터사 시점)

1. **이미 있는 엔진:** Mono의 보드·건설·카드·원정·모험·시즌을 재발명하지 않는다. K-pop은 **스킨·서사·굿즈**.
2. **한눈에 보이는 회사:** 40칸 일정 + 가운데 도시에서 “우리 사옥이 자란다”. R1 상징(LP·헤드폰…)이 **0.5초 인지 + 굿즈**.
3. **시즌마다 새 얼굴:** 보드를 갈아엎지 않고 **IP 팩만 스왑** → 파트너 계약 주기와 맞춤 (실계약 IP는 미확정·샘플만).
4. **노출·머천·리드:** 인게임 노출 → R1 실루엣 머천 → LeadGen(혜택 탭·홍보 덱)으로 **앱 밖 연락** (본문=클로드 문서).
5. **데모 비용 낮음:** 샘플 그룹 5인(슬롯 풀필)으로 피치 가능. 실제 제휴는 `asset_pack`만 교체.

### ② 콘텐츠 기둥 ↔ Mono 시스템 (맵만 · 본문 비복제)

| 기둥 | Mono 기능 | 케이팝 스킨·상품 얼굴 | 상세 문서 |
|---|---|---|---|
| A. 일정 보드 | 보드·주사위·배수 | 40칸 **엔터 스케줄** | 단이 시즌루프 v2 |
| B. 건물 성장·상징 | 건설·성장 | **상징1+입구** · 굿즈 실루엣 | R1 건물상징굿즈 |
| C. 카드북 | 카드·팩·★ | ~20덱 · 멤버 슬롯5 + 비멤버 | 클로드 카드 v2 · 단이 카드맵 |
| D. 원정=성장 | 원정 채움 | 연습·트레이닝 파견 → 레벨 | 중재 M-1 · 카드 v2 |
| E. 모험=공유 | 모험 엽서·UGC | 음방·짤·공유 → Lead 입구 | LeadGen v1 |
| F. 시즌 축제 | 시즌·레이어 | 피날레·다음 IP | 단이 시즌루프 · 05 |

> 단이 시즌 루프 본문·클로드 카드/LeadGen 본문은 **복제하지 않음**. 위는 상품성 포장용 맵.

### ③ 5분 데모 스토리 (피치용 · 튜토리얼 확정 아님)

1. **0:00** — “우리는 기획사 사장. 보드 40칸은 일정표다.” (Mono 보드 스킨)
2. **0:45** — 샘플 IP 팩으로 **슬롯 5**를 채운 데모 그룹(어우동·논개·이날치·신사임당·황진이). **활성은 1~5 가변** 설명 한 줄.
3. **1:30** — 첫 굴림 → 연습/공연 착지 → 비용·팬 반응이 한 화면 (단이 흐름 링크).
4. **2:30** — 도시에서 **LP·헤드폰** 등 상징이 커짐 = 회사가 큼 = **그 실루엣이 굿즈** (R1).
5. **3:30** — 카드 한 장 획득 연출만 보여 주고, 규칙은 “카드 문서 링크”.
6. **4:15** — 숏폼/공유 미션 자리 = Lead 경로 (**LeadGen 링크로 넘김**, 수치 안 씀).
7. **4:45** — “다음 시즌은 **보드 유지·IP 팩만 교체**.” 파트너 로고 슬롯 빈칸.

### ④ 파트너 가치 한 장

| 가치 | 무엇을 받나 | 비고 |
|---|---|---|
| 노출 | 시즌 보드·건물·카드 얼굴에 IP | 기간=시즌 팩 |
| 머천 실루엣 | R1 상징 → 키링·뱃지·스킨 | SKU는 후속 |
| 리드 경로 | 홍보 덱·혜택 탭 | **클로드 LeadGen** — 여기 재작성 금지 |
| 교체성 | `idol_id`·`asset_pack` 스왑 | 샘플≠실계약 |
| 운영 부담 | 시스템 재개발 없이 스킨/팩 | Mono 기본 |

### ⑤ Q-001 용어 (상품성 문서에서 쓰는 법)

| 용어 | 뜻 | 잘못된 말 |
|---|---|---|
| **풀(pool)** | 시즌 후보·캐스팅 풀 | “멤버 20명”으로 풀을 호출 |
| **슬롯(slot)** | 멤버 정원 **5** | 슬롯=덱20 |
| **활성(active)** | 실제 선택 1~**가변≤5** | “항상 5명 고정 활성” |
| **~20덱** | 카드북 덱 수 대략 | 멤버 수=20 |

샘플 5인 = **멤버 슬롯 5를 채우는 데모 IP 팩**. 실파트너 IP로 팩만 교체.

### ⑥ 체크리스트 (상품성 · 제안)

- [ ] P-1 파트너 피치에 Mono=기능 / K-pop=스킨 한 줄이 있는가
- [ ] P-2 5분 데모가 단이 흐름·R1·LeadGen을 **링크만**으로 잇는가
- [ ] P-3 굿즈 이야기가 R1 상징과 같은 실루엣인가
- [ ] P-4 시즌=보드 유지·IP 교체가 명시되는가
- [ ] P-5 풀/슬롯/활성이 멤버20·덱20과 혼동되지 않는가 (Q-001)
- [ ] P-6 Lead·카드 수치를 본 문서에 새로 쓰지 않았는가
- [ ] P-7 status가 **제안(검수 대기)** 인가
