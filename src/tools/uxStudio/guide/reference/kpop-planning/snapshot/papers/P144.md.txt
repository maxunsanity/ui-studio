# 종합 제안 · 모노폴리GO 경제를 우리 게임에 옮긴 방식

**이 문서는** 모노폴리GO의 경제 장치 하나하나가 우리 게임(케이팝몬스터즈)에서 무엇이 되었는지 한 표로 보여 주는 종합 제안서입니다.

**보는 법** 같이 여는 시뮬레이터: [발란스 시뮬레이터](/docs/planning/idle-sim.html). 아래 대응표를 먼저 보고, 궁금한 줄의 설명을 읽습니다.

**지금 상태** 아래 대응은 모두 게임에 들어가 있습니다(숫자는 임시 값).

## 대응표

| 모노폴리GO | 우리 게임 |
|---|---|
| 주사위 | 주사위(기획사 대표의 투자) · 무료 하루 800개 |
| 주사위 배수 | 배수 ×1~×1000 · 엔터파워([P172](개발진행기획_v01/콘텐츠별_v03/엔터파워_기획서.html))로 열림 |
| 번영도(넷 워스) | 엔터파워(건물 9개 단계 합) |
| 보드([S03](시스템기획/S03_보드주사위경제.md)) 40칸 · 출발 | 보드 40칸 · 1번 사옥(출발) |
| 감옥 | 31번 감옥(도착하면 갇힘 · 더블로 탈출) |
| 모서리 칸 | 11번 기숙사 · 21번 본가(쉬는 칸) |
| 땅·건물([P106](개발진행기획_v01/콘텐츠별_v03/건물성장_기획서.html)) | 건물 24칸(9종 · 각 30단계) |
| 공동기금·찬스([W02](전체기획서/02_보드찬스칸연출_클로드.md)) | 팬([P108](개발진행기획_v01/콘텐츠별_v03/팬과수익_기획서.html)) 반응 칸(3·18·34) · 찬스 칸(8·23·38) |
| 세금 | 정산 칸(5·40) |
| 철도 | 쟁탈전([P98](개발진행기획_v01/콘텐츠별_v03/캐스팅권대전_기획서.html)) 칸(6·16·26·36) |
| 넷 워스 마일스톤 | 팬 마일스톤 8단 |
| 하이스트·셧다운 | 쟁탈전 · 나쁜 기운([P104](개발진행기획_v01/콘텐츠별_v03/나쁜기운디펜스_기획서.html)) 디펜스(수리비 = 지은 비용의 50%) |

## 배수

| 배수 | ×1 · ×2 · ×5 | ×10 | ×20 | ×50 | ×100 | ×200 | ×500 | ×1000 |
|---|---|---|---|---|---|---|---|---|
| 필요한 엔터파워 | 처음부터 | 50 | 100 | 180 | 260 | 340 | 420 | 500 |

처음 기본 배수는 ×5입니다. 1일차에는 ×10까지, 2일차에는 ×20까지만 쓸 수 있고 3일차부터는 제한이 없습니다. (모두 임시 값)
