</section><section class="part" id="part-4"><h2>4. 상세 기획</h2><h3>앨범 소규모 차트 연결</h3>
<p>앨범 발매로 열리는100명·약1일 순위 이벤트 게임입니다. 현재 로컬은 본인+가상99명을 명시합니다. 첫100위에서 출발하고 후속은 현재 보유 팬·계층과 직전 마감 최종성적으로 시작합니다. 보드 신규 팬 증가를 주력으로, 주사위 소모를 보조로 점수를 쌓아 현재 순위별 돈·팬·기존 능력을 적립하고 다음1번START에서 정산합니다. 만료 뒤 신규 효과는 끝나며 얻은 성장·미정산 적립·최종 성적은 보존합니다. 보통 활동은4<del>5번째 첫1위 도전, 성장 좋은5</del>8번째 입장1위도 가능하며 차수별 고정 등수는 없습니다. 메인 차트 말풍선·활동/다음 시작 예상 게이지는 같은 규칙을 읽습니다. <a href="../%EA%B0%9C%EB%B0%9C%EC%A7%84%ED%96%89%EA%B8%B0%ED%9A%8D_v01/%EC%BD%98%ED%85%90%EC%B8%A0%EB%B3%84_v03/%EC%9D%8C%EC%95%85%EB%B0%A9%EC%86%A1%EC%B0%A8%ED%8A%B8_%EA%B8%B0%ED%9A%8D%EC%84%9C.html">앨범 차트 정본</a>에서 성장곡선·원본·계산·저장·실제 구현을 봅니다. 실제 유저 매칭 서버는 미구현이며 유저 투표는 없습니다.</p>

<h3>콘텐츠 연결 계약</h3>
<p>싱글 발매 후 크루가 있으면 같은 앨범을 내부 자동 공유하고 앨범 성장 차트에 자동 등록합니다. 앨범 차트는 유저 투표 없이 발매 차수·보유 팬 수·팬 계층·기존 성장 조건으로 테이블 범주를 골라 그 안에서 순위를 배정합니다. 주간·월드페스티벌은 별도 회차이며 조회/추천·일반 유저 표·유저 채점단을 분리해 평가합니다. 팬투표100%로 처리하지 않습니다.</p>
<p>총9주 시즌에서 주1회 페스티벌,9주차 월드 후 최종집계·돈 보상·계정 기록 보존을 마치고 기존 시즌 초기화 경로로 전환합니다. 순위 보상은 돈만 사용하며 조절 가능한 임시 %S 표와 회차별1회 영수증을 둡니다. 기존 START 활동 정산과 차트/페스티벌 순위 보상은 다른 원인입니다. 순위 외 추가 음악 보상 범위·동크루 일반표·대상 곡/팀/캐릭터·기간/한도/비중은 검수 대기입니다.</p>
<p><a href="../%EA%B0%9C%EB%B0%9C%EC%A7%84%ED%96%89%EA%B8%B0%ED%9A%8D_v01/%EC%BD%98%ED%85%90%EC%B8%A0%EB%B3%84_v03/%EC%9D%8C%EC%95%85%EB%B0%A9%EC%86%A1%EC%B0%A8%ED%8A%B8_%EA%B8%B0%ED%9A%8D%EC%84%9C.html#part-4">비교 그룹·팬·점수·순위·돈 상세</a> · <a href="../%EA%B0%9C%EB%B0%9C%EC%A7%84%ED%96%89%EA%B8%B0%ED%9A%8D_v01/%EC%BD%98%ED%85%90%EC%B8%A0%EB%B3%84_v03/%EC%9B%94%EB%93%9C%ED%8E%98%EC%8A%A4%ED%8B%B0%EB%B2%8C_%ED%95%B5%EC%8B%AC%EC%A0%9C%EC%95%88%EC%84%9C.html#part-4">주간·월드 평가·투표 UI</a> · <a href="../%EA%B0%9C%EB%B0%9C%EC%A7%84%ED%96%89%EA%B8%B0%ED%9A%8D_v01/%EC%BD%98%ED%85%90%EC%B8%A0%EB%B3%84_v03/%EC%8B%9C%EC%A6%8C_%ED%95%B5%EC%8B%AC%EC%A0%9C%EC%95%88%EC%84%9C.html#part-4">9주 달력·보존/초기화</a></p>
<p>기능/UI 조작은 게임 시뮬레이터,발란스 시뮬레이터는 같은 규칙의 자동 시험,현황판은 자동 결과 조회,발란스 툴은 원본과 입출력 비교입니다. 게임 팬 계층과 실제 사람 표를 섞지 않습니다. 신규 발매 자동 연결과 성장 배정기 접점은 구현했으며 과거 활동합계 차트는 비교 기록으로 보존합니다. 팬 원본·운영 범주·주간/월드 실제 평가·지급·63일 전환은 연결 대기입니다. 실제 서버는 현재 만들지 않습니다.</p>
<h3>개발 경계</h3>
<p>기존 돈 지갑·팬 계층·성장·보드·미션·저장을 재사용합니다. 수익용 팬 weight를 차트 계수로 복사하지 않으며 팬 인구를 실제 조회/투표자로 생성하지 않습니다. 신규 계약은 발매 후 자동 후속 작업·소규모 비교 그룹/점수·회차 유형·평가 원장·돈 순위 보상·보존 후 전환입니다. 정본에서 필드·계산 순서·중복/실패·UI·수락 시험을 관리하고 종합 문서는 연결만 유지합니다.</p>

<h4>전체 개발 순서</h4>
<p><a href="../%EA%B0%9C%EB%B0%9C%EC%A7%84%ED%96%89%EA%B8%B0%ED%9A%8D_v01/%EC%BD%98%ED%85%90%EC%B8%A0%EB%B3%84_v03/%EC%9B%94%EB%93%9C%ED%8E%98%EC%8A%A4%ED%8B%B0%EB%B2%8C_%ED%95%B5%EC%8B%AC%EC%A0%9C%EC%95%88%EC%84%9C.html#part-7">월드페스티벌 상세 개발 계획</a>의58개 작업을 기준으로 원본·문서 분리→공통 기록·저장→앨범→크루→활동·정산·차트·지역→파이널→현황판·발란스→검증·기록 순서로 연결합니다.</p>
<h3>수락 기준</h3>
<p>콘텐츠마다 원본의 역할·현재 연결 범위·미구현을 구분하고, 발매·활동·집계·보상이 같은 기록으로 이어져야 합니다. 공통 값과 자원을 중복 정의하지 않습니다.</p>
<h3>뺀 것·옮긴 것·보존한 것</h3>
<p>각 콘텐츠의 세부는 정본에 두고 이 문서는 전체 연결을 설명합니다. 변경 이력·이전 종합·연구 자료는 하단 로그에서 보존합니다.</p>
<h3>후속 로컬 구현과 남은 연결</h3>
<p>전체64단계는 자동 발매 후속과 성장 차트 계산 접점까지 로컬 구현을 진전시켰습니다. 돈은 견적만, 주간·월드는 조회 달력만 구현한 범위를 구분합니다. 자동 발란스는 동일 releaseFollowups/chartRegistrations/festivalCalendar를 결과 관측으로 전달하며 현황판에 수동 조작이나 별도 순위 계산을 추가하지 않습니다.</p>
<p>관련 통합시험과 별도 팬 단조 경계3,751건을 통과했습니다. 정확한 최신 통과 수와 명령은 공용 보고·검증 로그에 기록합니다. 실제 공용게임의 명시 시험 조건으로 신규 발매 자동 연결·메뉴 왕복·새로고침 보존을 확인했습니다. 새 주간/월드 참여집계·운영 순위/지갑지급·63일 초기화를 완료한 검수가 아닙니다. <a href="../../%EC%A6%9D%EA%B1%B0/20261103_142753_%EB%8B%A8%EC%9D%B4_9%EC%B0%A8_%EC%95%A8%EB%B2%94%ED%81%AC%EB%A3%A8_%EC%9B%94%EB%93%9C%ED%8E%98%EC%8A%A4%ED%8B%B0%EB%B2%8C_%ED%86%B5%ED%95%A9%EA%B0%9C%EB%B0%9C/release-followup-actual.jpg">실제 발매 자동 연결 검수 화면</a></p>
<p><a href="/docs/planning/balance-tool.html?topic=balance_topic_music">음악 발란스 주제</a>는 같은 음악 원본을 읽는8행 상태표입니다. 로컬 이벤트는 팬/보드 목표와1회 반영 한도를 원표에서 표시하고 실제 저장 결과를 조회합니다. 현황판은 자동 결과 조회이며 제작·발매·투표 조작을 넣지 않습니다.</p>
