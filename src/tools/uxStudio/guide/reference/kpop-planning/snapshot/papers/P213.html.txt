</section><section class="part" id="part-4"><h2>4. 상세 기획</h2>

<h3 id="한-판-순서-임시-시안">한 판 순서 (임시 시안)</h3>

<div class="table-scroll"><table><thead><tr><th>점검</th><th>내용</th></tr></thead><tbody><tr><td>시작·종료</td><td>칸 도착 때마다</td></tr><tr><td>입력·출력</td><td>입력 = 건물 단계 · 그 건물 팬 / 출력 = 코인 · 연출</td></tr><tr><td>상태와 전이</td><td>건물 단계는 증축으로만 오름</td></tr><tr><td>판정</td><td>아이돌 능력은 수익식에 직접 안 들어감</td></tr><tr><td>오류·예외</td><td>건물이 없으면 기본 수익(기존 규칙)</td></tr><tr><td>저장·복원</td><td>시즌 범위</td></tr><tr><td>다른 모듈 연결</td><td>보드 · 건물 · 팬 · 피드</td></tr></tbody></table></div>

<p>계산 경로를 나눠 읽습니다. 공통 경제는 건물 단계 수익의 S 대비 %에 판정·주사위 배수·이벤트 버프를 적용한 뒤 팬 항을 더하고 파손 계수를 반영합니다. core 계산은 단계 수익과 칸 팬 곡선·칸 가중을 사용합니다. 표시 시안의 단계값·팬값을 곱하는 가중합과 모두 같은 식은 아닙니다.</p>

<p>아이돌 능력은 독립 수익항으로 더하지 않는 기획입니다. core의 판정 플래그가 켜진 칸은 능력이 판정 가중에 간접 영향을 줄 수 있습니다. 공통 경제의 건물팬 계수는 미공급이고 배정 방식은 발란스 대기입니다. 현재 추가 팬 항은 계산상 0이며 실제 건물별 배정은 하지 않습니다. 이 0은 미정 계수의 확정값이 아닙니다.</p>

<p>표의 ‘건물이 없으면 기본 수익’은 기존 기획을 보존한 표현입니다. 현재 공통 경제의 workplace는 시설 단계가 0이면 도착 수익을 0으로 처리하므로 이 예외와 구별합니다. 기본 수익 적용 정책은 확인 대기입니다.</p>

<h3 id="hud-임시-시안">HUD (임시 시안)</h3>

<p>상단 = 엔터파워 · 팬덤 게이지(한 막대) · 오늘 데일리 내 부문 순위 칩 하나를 더합니다.</p>
