# 컷씬 연출 지식 · 참조 목차

버전 1.0 · 2026-09-22

이 폴더의 MD는 제작 중 직접 읽는 본문이다. 외부 링크는 정의와 사실의 출처이며, 콘티·수식 적용·편집 명령·실패 복구는 우리 프로젝트를 위해 작성한 제작 규약이다. 모든 내용이 원문의 번역이거나 재현 검증된 구현인 것은 아니다.

## 빠른 읽기 순서

전체 제작은 **D11 조회 규약 → 인원별 D03/D04/D05 → D02 연속성 → D09 모션 검수** 순서로 읽는다. 카메라 이동이 있으면 D06, 음성이 있으면 D07, 좌표 계산이나 교환은 D08을 추가한다. 제작 때마다 현재 파일을 읽고 문서 ID·버전·해시·사용 절을 기록한다.

| 사용자의 지시 | 먼저 읽을 문서 | 함께 확인할 것 |
|---|---|---|
| 얼굴 클로즈 | D01, D08 | D02 컷 연결·현재 얼굴 리그 |
| 두 사람이 자연스럽게 대화 | D04, D02, D09 | D07 대사와 반응 시간 |
| 세 명이 말하고 한 명이 중재 | D05, D02 | 제삼자 시선·3인 자산 |
| 혼자 생각하다 결심 | D03, D01 | 독백 유형·시선·표정 |
| 한 바퀴 돌아줘 | D06, D08 | 배경 뒷면·가림·축 복귀 |
| 발이 뜨고 상하체가 따로 논다 | D09 | 원본·골반 이동·부분 마스크 |
| 반응을 더 오래 보여줘 | D04, D07 | 대사/카메라/반응 중 변경 대상 |
| 영상을 참고해 비슷하게 | D11, 인원별 문서 | 관찰/추정·원본 시간·자산 호환 |

## 저장과 조회

`manifest.json`은 파일·태그·기법 ID·내용 해시를, `chunks.json`은 문서별 절 본문을 저장한다. MD가 기준 원본이고 인덱스는 다시 만들 수 있는 파생 데이터다. `lookup.py`는 이 폴더의 MD를 읽는 간단한 로컬 검색 도구다. 외부 서비스·API 키·벡터 DB 없이 사용할 수 있다.

```text
python3 lookup.py "두 사람 대화 반응" --limit 4
python3 lookup.py "360 회전" --limit 3
python3 lookup.py "C05" --limit 3
```

검색 점수는 문자열 일치 기반으로 적합성을 확정하는 값이 아니다. 반환된 본문과 조건을 읽은 뒤 선택한다. 의역이나 복잡한 의미 검색은 AI가 이 목차와 본문을 함께 읽어 판단한다. 에디터 자동 호출 연결은 아직 미구현이다.

## 검증 상태

문서·인덱스·검색 경로와 기법 연결을 확인한다. 실제 모델을 사용한 각 기법의 시각 검수는 별도다. 인터넷에 접속하지 않아도 본문을 읽을 수 있고, 원문 재확인이 필요할 때만 출처 링크를 연다.
