## 2. 기본 가정 (문서·답변에서 온 것만)

1. **시점 기본 = 합친 판(전지적)** — 제1조. v1의 「사장 뷰 기본」은 철회 (패치_02 P2-5 참고).
2. **얼굴·캐릭터 없음** — Q-003 답 (030 · 077). 슬롯 = 밴 + 장소 + 점(dots). `cutscene/` 인물 씬은 이 슬롯 밖.
3. **팬 뷰 = A** — Q-001 답. 장소 프레임은 같고 **한 줄만** 팬 문구. 19·20·37·39는 외관도 안 씀 → 대체 장면.
4. 배경은 코드 `placeOf()` 그대로: 초록 3급↑·노랑 4급↑ = 아레나 앞 · 초록 그 외·19·20·37 = 지방 도로 · 나머지 = 홍대 밤. **단 지방 도로 6칸은 Q-002 현중 확인 대기** (§4).
5. 착지 그림은 코드 `landFileOf()` 그대로. 40칸이 부르는 파일 전부 `_img/`에 있음(누락 0).

## 5. 기존 자료끼리 어긋나는 곳 (판단 안 함 · 표시만)

1. **팬 뷰 art:false 18칸 vs Q-001 A** — HTML은 팬 뷰 18칸 그림을 끄고, Q-001 답은 같은 장소 프레임을 쓰라고 함. HTML 반영은 Codex/제나 몫.
2. **19·20·37·39 대체 장면** — Q-001 답이 「대체 장면」을 요구. HTML fan 이름(현생·학교 / 현생·회사 / 용돈 / 알바)만 있고 그림은 없음. 누가 무엇을 그릴지 미정.
3. **090 에셋 계획 vs 코드** — 090은 「40칸마다 그림을 안 그린다 · 칸 종류마다 한 장」(A 착지 10장: land-stage/practice/camp/rest/fan/gate/chance/company …), 코드는 칸별 파일(land-office · land-physical …)을 44개 부름. 파일 이름 체계도 다름. 공유 그림: land-train 4칸(7·12·17·22) · land-gate 4칸(6·16·26·36) · land-cheer 3칸(3·18·34) · land-chance 3칸(8·23·38).
4. **코어덱 07 「조립·매번 다름」 vs 칸당 그림 1장 고정** — 현행은 배경×착지 그림 조합뿐. 「매번 다름」을 어디까지로 볼지 미정.
5. **아이돌 말 조우 컷 (D-059 · 092)** — 도착 슬롯에 자리 없음. 별도 컷인지 도착 슬롯 변주인지 미정.
6. **HTML 주석 「19칸」 vs D-074 팬 뷰 20칸** — 코드 실제는 20칸. 주석만 옛 값.
7. **제1조 vs 02 C6 「사장 뷰 기본」** — 내 00·04 문구도 같은 오류. 패치_02 P2-5로 올림.
