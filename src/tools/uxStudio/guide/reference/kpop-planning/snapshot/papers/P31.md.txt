## 이게 뭐냐 (신규)

유저가 자기 **얼굴·카드 초상·로비 아바타**를 만드는 방식에 대한 **현중–이스터즈 합의 초안**. 사진 업로드·AI 얼굴 생성을 빼고, **블록/복셀 파츠 조합**만 범위로 둔다.

## 한 줄 (신규)

> **파츠로 만든다. 사진으로 만들지 않는다. 시즌엔 레거시 캐릭터 1개. 상대에게 보이는 정보가 Lead gen의 장점이다.**

## 초안 범위 (이번 문서가 다루는 것) (신규)

### ① 생성 플로우 (튜토리얼 / 시즌) (신규)

| 구간 | 무엇을 | 메모 |
|---|---|---|
| 튜토리얼 | 첫 파츠 조합으로 **내 아바타 1개** 확정 | 사진 권한·업로드 UI 없음 |
| 시즌 중 | 파츠 획득·교체·색 변경 (경로 상세는 후속) | 카드 획득·상점·미션 등과 링크 가능 |
| 시즌 끝 | **레거시 1개**만 다음 시즌으로 이관 | 카드 1장과의 병행 여부는 **미정**(체크) |

### ② 파츠 카탈로그 초안 (분리 시트 방향) (신규)

9/29 카톡 컨셉(복셀 치비 · 파츠 모듈 · 표정 6 · 4k poly 이하)을 **시트/표로 분리**해 관리하는 방향.

| 슬롯(가안) | 예시 | 비고 |
|---|---|---|
| 눈 · 코 · 입 | 형태·색 | 얼굴 핵심 |
| 헤어 | 스타일·색 | |
| 몸 · 팔 · 다리 | 체형·의상 톤 | |
| 신발 · 소품 | 액세서리 | |
| 표정 | **6종**(카톡) | 감정 연출 |
| 피부/메인 색 | 팔레트 | |

- 시트는 아트·기획 공용 **파츠 ID 목록**으로 둔다(개수·가격·획득 경로는 후속 잠금).
- 아이돌 IP 스킨과 유저 파츠는 **별 레이어**(유저 얼굴 ≠ IP 초상).

### ③ 카드 vs 로비 아바타 (신규)

| 표면 | 역할 | 초안 |
|---|---|---|
| **카드 초상** | 덱·전투·교환에 붙는 얼굴 | 동일 파츠 세트의 **2D/썸네일** |
| **로비 아바타** | 로비·탐험·공유에 서는 몸 | 동일 파츠 세트의 **3D/전신** |
| 원칙 | **한 세트, 두 표면** | 카드만/로비만 따로 꾸미는 이중 커스텀은 v0 비범위 |

### ④ 시즌 이관 1개 (신규)

- 회의: 시즌 이월 = **하나 남김**(블록 커스텀 캐릭터 · 또는 카드 1장).
- 본 초안 제안: 유저 아바타 쪽은 **레거시 캐릭터 1개**를 기본 후보로 둔다.
- 카드 1장과 **둘 다**인지 **택1**인지는 현중·중재 체크(아래 A-3).

### ⑤ Lead gen 연결 — 상대에게 보이는 정보 (신규)

- 현중: Lead gen 핵심 장점 = **상대 정보를 알게 됨**.
- 연결: 커스텀 아바타·카드 초상·공유 이미지(홍보 덱 「캐릭터 스타일리스트」 등)가 **상대·동료·피드에 보이는 정보**가 된다.
- 수집하는 것(이메일·전화·SNS)과 **보이는 것(외형·취향 단서)**을 섞지 말 것 — LeadGen v1은 연락 경로, 본 문서는 **노출 외형**.
- 사진 원본 저장은 최소·원칙적으로 **없음**(업로드 자체 비범위).
