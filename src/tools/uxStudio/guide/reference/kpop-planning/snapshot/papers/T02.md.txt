# T02 · 시뮬레이터 오른쪽 정보창 검수 기획

**이 문서는** 등록된 시뮬레이터의 오른쪽 정보창에 어떤 관찰 항목을 보여 주고, 공용 표시와 개별 콘텐츠의 확인 범위를 어떻게 구분하는지 설명합니다.

**보는 법** 목차 → 공용 표시 흐름 → 모듈별 확인 항목 → 미등록 목록 순서로 읽습니다. 실행은 [게임 시뮬레이터](../../../game-simulator.html)에서 해당 콘텐츠를 엽니다.

**지금 상태** 개발됨. 공용 목록 읽기·표시·첫 펼침·수동 접기 유지가 구현되어 있으며, 등록 모듈과 검수 목록의 동기화 및 실제 화면 확인은 진행 중입니다.

## 1. 개요

출처: [기획서 툴 기본 양식](../시스템기획/S17_기획서툴_제작기본양식_v02.md)의 공용 실행·진행 정보 경계와 등록된 각 콘텐츠의 관련 기획을 따릅니다.

오른쪽 정보창은 현재 진행 정보와 함께 플레이하며 대조할 항목을 보여 줍니다. 항목이 표시되어 있다는 사실은 자동 시험 결과나 실제 플레이 통과를 뜻하지 않습니다. 이 기능은 게임 상태·재화·능력을 변경하지 않습니다.

```mermaid
flowchart LR
 A[등록 모듈 선택] --> B[공용 진행 정보]
 B --> C{검수 목록 원본이 있는가}
 C -->|있음| D[확인 항목 · 관련 기획 · 펼침 조작]
 C -->|없음| E[예상 성장 자리만 · 목록 동기화 필요]
 D --> F[플레이하며 원본과 대조]
```

## 3. 구동 방법·시뮬레이션

1. [게임 시뮬레이터](../../../game-simulator.html)에서 콘텐츠를 고릅니다.
2. 공용 진행 정보와 그 뒤의 확인 항목을 함께 읽습니다.
3. 같은 DOM 항목은 처음 한 번 펼쳐지고 이후 사용자가 접은 상태를 유지하는지 대조합니다. 새로 삽입된 항목은 처음 펼쳐집니다.
4. 모두 펼치기·모두 접기는 기존 항목에도 명시적으로 적용합니다.
5. 관련 기획 링크로 이동하여 원본문서의 범위와 실제 표시를 비교합니다.

폰 내부·대화상자·모달·수동 접기 대상으로 표시된 영역은 공용 펼침 대상에서 제외합니다. DOM 항목 자체를 새로 만들면 새 항목으로 취급되므로, 모든 화면 재생성에서 접힘이 영구 저장된다고 보지 않습니다.

## 4. 상세 기획

### 공용 설치와 공급 경계

- 일반 도구에서는 공용 진행 정보 다음에 검수 목록을 둡니다. 모듈을 바꾸면 이전 목록과 관찰자를 해제합니다.
- 아이돌 성장의 공용 외곽 설치는 별도 경로로 넘어가며, 내장 보드 검수 모드는 해당 콘텐츠의 검수 목록을 직접 연결합니다.
- 이벤트는 공용 목록 설치를 건너뛰고 전용 어댑터를 사용합니다. 성장 전용 시험 도구도 공용 검수 목록 설치 대상에서 제외됩니다.
- 목록이 없는 모듈은 현재 공용 코드에서 예상 성장 자리만 표시합니다. 검수 항목·관련 기획·전체 펼침 버튼이 이미 공급되는 것처럼 쓰지 않습니다.
- 예상 성장 원본 값이 비면 발란스 대기로 표시합니다. 표시를 위해 숫자를 채우지 않습니다.
