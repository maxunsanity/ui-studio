# 038 · 팬덤 스테이지

**이 문서는** 초기(9월 말) 기획 때 쓴 **옛 컨셉 기록**이에요. 요약: 제로돌→서동요. GO 랜드마크 건설 자리. 게이트는 약탈. 지금 게임의 [미션](삼중AI_공용_20260929/산출/시스템기획/S11_미션.md)은 [S11 미션](삼중AI_공용_20260929/산출/시스템기획/S11_미션.md)과 미션 표를 따르고, 이 문서는 아이디어 재료로만 남겨 둬요.

**보는 법** 처음부터 순서대로 읽어요. 지금 규칙과 다른 부분이 있으니 숫자·규칙은 책갈피의 대표 기획서로 확인하세요. 시뮬레이터 없음.

**지금 상태** 이 문서 내용은 게임에 그대로 들어가지 않았어요. 여기 적힌 내용을 게임에 쓰는 것은 현재 개발되지 않음, 진행 중이에요.

## 팬덤 게이트 (옛 정거장)

- 칸 이름: **팬덤 게이트** (시스템 이름「팬덤 스테이지」와 **다름**)
- 역할: **딱지** 창구 ×4 — 남의 덕질에 내 이름을 건다 ([064](./064_팬덤게이트_딱지.md))
- GO에서는 정거장. 이중 롤(딱지 / 가로채기) · 수치 미정.

### 정정 (2026-09-17 · 유저)

**덕질(쌓기)은 아이돌 일정 칸 22곳 전부에서 한다.** 게이트에서만 쌓는 게 아니다.
GO도 건설은 대지에서 하고 정거장은 약탈 자리다. 덕질 불가는 **A&R 미팅(13)·매니지먼트 미팅(29)** 둘뿐.

| | 어디서 |
|--|--------|
| **쌓기 (덕질)** | 아이돌 일정 22칸 |
| **딱지** | 팬덤 게이트 ×4 (뺏는 게 아니라 이름이 바뀜) |
| **못 함** | A&R 미팅 · 매니지먼트 미팅 |

→ **화면 반영은 커서 몫.** `board-40-places-table.html` 게이트 칸 설명이 아직 「쌓고 약탈하는 창구」다. **딱지 창구**가 맞다 — [064](./064_팬덤게이트_딱지.md)가 기준.
