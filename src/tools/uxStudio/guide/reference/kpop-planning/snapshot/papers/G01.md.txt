# 케이팝몬스터즈 · 삼중안 교차 검토 R4

> status: **보류(보조 검토·회차 미계상)** · 2026-09-29 · 작성 단이(codex)  
> 이 문서는 다른 단이 R4 산출 및 이스터즈 R3 중재가 기록되는 동안 작성된 **별도 교차 검토**다. 이스터즈가 지정한 R4 할 일의 완료 증거로 계산하지 않는다.  
> 같다름 한 줄: 모노카피바라의 기능 분리는 토대다. 케이팝몬스터즈는 **제작비→활동→팬 행동→매출**과 IP·홍보가 실제 규칙이므로, 스킨 교체만으로 설명할 수 없다.  
> 짝 화면: [다섯 확인점 HTML](./산출_게임흐름_삼중안교차검토_R4_v1_단이.html)  
> 검토 대상: 클로드 `카드획득세부_v2`, `LeadGeneration_v1`; 단서 `성장보드아이돌IP교체_v1`, `건물상징굿즈목록_v1`, `Kpop게임상품성콘텐츠_v1`. 다른 AI 원문은 수정하지 않았다.

## 이게 뭐냐

이스터즈가 세 AI 안을 합칠 때 필요한 **일치점과 충돌점 5개**를 한눈에 보는 교차 검토. 현중 Q-001 답변과 이스터즈 R2 중재를 기준으로 한다. 이 문서는 새 게임 규칙의 승인안이 아니다.

## 언제 쓰나

카드 데이터 단위·경제 시뮬레이션·제안서 B 문구를 묶기 전에 읽는다. 원문 각자의 후속 버전에는 담당 작성자가 반영하고, 단이는 데이터·파이프라인 관점의 근거를 제공한다.

## 한 줄

> **풀·슬롯·활성은 맞췄다. 카드 성장의 단위, 시즌 시간·팩 경제, ‘스킨’ 밖의 케이팝 규칙, IP 권리, 실제 리드의 정의는 아직 한 문장으로 합쳐야 한다.**

## 자세히

### ① 카드 성장 단위: 최신 회의와 모노 구조 사이

- 최신 회의 31:37~32:16은 **획득 ★는 고정**이고 원정 사용으로 **“그 카드”가 성장**할 수 있다는 뜻으로 읽힌다. 이스터즈 R2의 M-1은 **원정 채움이라는 성장 경로**를 확정했지만, 저장 단위가 카드 1장인지 덱 1개인지는 정하지 않았다.
- 모노카피바라 `46_CARD_COLLECTION.md`와 `139_EXPEDITION_STANDALONE_RESULT.md`는 **한 종의 번호 카드 수가 천장을 열고, 원정이 그 종의 게이지를 채우는** 구조다. 클로드 v2의 “덱 하나=게이지 하나”는 가능한 이식안이며, 문서도 C-2로 미정 표시했다.
- **데이터 제안:** `card_levels`에 바로 `deck_id`를 유일한 성장 키로 고정하지 않는다. 비교 검토할 때 `growth_unit`(card/deck)·`growth_target_id`·`source_event` 같은 **임시 설계 칸**으로 사례를 검산한다. 이 칸 이름 자체도 제안이며 최종 CSV 확정이 아니다.
- ★팩 색은 **보장 최저 등급**을 뜻한다. 클로드 v2 한 줄의 “★는 팩 색이 정한다”는 개별 카드 등급이 정확히 색으로 확정된 듯 읽히므로 “팩 색은 최소 보장, 획득 카드의 ★는 뽑힐 때 정해짐”으로 다듬는 편이 정확하다. 모노 `91` 제1조의3과 [모노폴리 GO 공식 앨범 팩 안내](https://monopolygo.helpshift.com/hc/en/3-monopoly-go/faq/356-artful-tales-album/)도 팩마다 **보장 등급**을 설명한다.

### ② 경제: 모노카피바라 숫자를 케이팝 숫자로 선형 변환하지 않기

클로드 카드 v2의 `20덱×덱당 원정 9회=180회`, `하루 3회×60일=180회`, `무과금 176/180`, `40칸 중 약 13칸 보상형`은 **모노 수치를 옮겨 놓은 케이팝 제안**이다. 모노 91의 107/108 결과는 그 게임의 번호 희귀도·팩 유입·시간 투입으로 나온 값이다. 180장에 단순 비율로 복사하면 보상 체감과 완성 비용의 근거가 되지 않는다.

| 먼저 정의할 것 | 이유 |
|---|---|
| `season_days`의 **현실 날짜/게임 안 날짜** | 9/28의 60일과 모노의 실제 60일 원정 횟수를 같은 값으로 쓸 수 있는지 미정 |
| 40칸의 일정·보상형 실제 배치 | 모노 21/64를 40칸에 비례 적용한 13칸은 임시 수 |
| 캐스팅·카드 지급 이벤트 분리 | 후보 획득을 카드 180장의 공급으로 중복 계산하지 않음 |
| 팩별 장수·보장·드랍 경로·중복 | 무료 완성 곡선과 희귀 카드 접근성에 영향 |
| 무료 진행과 시즌 피날레 | 완성자 독점 우려를 피하는지 검증 |

현중 요청의 **HYBE/JYP 공개 자료**는 사업별 매출·비용을 잡는 현실 기준이다. 게임의 개별 행보판 비용은 활동 빈도·기준 규모·게임 화폐 변환의 **모델 가정**을 별도로 둬야 한다. 이스터즈 R2도 실측과 모델 분리를 중재했다.

### ③ 제품 정의: 모노 기반 위에 케이팝 규칙이 있다

단서의 성장보드·상품성 문서는 **IP 스왑 단위**를 명확히 했고, 건물 “상징+입구”는 최신 카카오톡 방향과 맞다. 다만 상품성 v1의 “K-pop은 스킨” 문구는 엔터사 제안서에서 게임의 핵심을 축소한다.

- 모노 본편: **64칸·착지·골드·건설·카드·원정** 등의 구현과 기능 분리. [모노 `17_HYBRID_CORE.md`, `302_SYSTEM_REDEV_ATLAS.md`]
- 케이팝 제안: **40칸 일정 보드**, 준비 시설의 비용, 아이돌 활동, **팬의 시청·공유·구매**, 매출 정산, 성장 도시와 건물 굿즈, 선택형 홍보·리드. [9/28 회의 47:32~48:17; 기존 `05_컨셉정리.md`; 9/29 카카오톡]
- 따라서 피치 문장은 **“재사용하는 기능 엔진 + 케이팝 경영·팬덤 모듈 + 시즌 IP·굿즈 팩”**이 적절하다. 어느 부분이 코드 재사용이고 어느 부분이 신설 로직인지 개발 착수 전에 실제 소스와 대조해야 한다.
- 단서의 “0.5초 인지”는 카카오톡의 **목표**이지 사용성 테스트 통과 수치가 아니다. 최종 제안서에는 목표·검수법을 함께 표시한다.

### ④ IP 팩: 실제 교체 단위를 더 넓게 보기

단서의 `idol_id`·`asset_pack`·`board_skin_hooks`·`card_pack_id`는 아트 교체의 첫 연결이다. 그러나 실제 아이돌 IP로 바꿀 때는 **멤버 수, 카드 이름·효과 설명, 음원·안무, 사진·초상, 홍보 소재, 건물/굿즈 사용 허용 범위, 기간·지역, 철회 시 대체물**이 달라진다. 모두 계약 검수에 좌우된다.

**데이터 제안:** `ip_pack` 아래 자산(`asset_pack`), 카드 콘텐츠(`card_pack_id`), 권리(`rights_status`, `valid_from/to`, 허용 매체), 운영 상태(`review_state`, `fallback_pack_id`)를 다른 층으로 둔다. 실제 컬럼·법적 요구는 계약 검토 전 미확정이다. Q-001의 **초기 슬롯 정원 5**를 모든 미래 IP가 5인이라는 뜻으로 넓히지 않는다.

### ⑤ Lead generation: 이벤트와 연락 수단을 구분

클로드 Lead v1의 **참여하지 않아도 기본 보상**은 9/28 회의와 정합이다. 홍보 카드 9장에 9개 미션을 붙이는 안은 검토 가능하지만, **SNS 팔로우·게시물 공유·친구 초대**는 각각 행동 이벤트다. 그 자체로 게임 운영자가 해당 플레이어에게 다시 연락할 수 있는 **연락 가능한 리드**가 생겼다고 볼 수 없다.

| 따로 기록할 층 | 예시 | 주의 |
|---|---|---|
| 카드 획득 | 홍보 카드 지급/중복 | 외부 참여 없이도 기본 획득 가능 |
| 선택 참여 | 챌린지·게시물·초대 | 완료 확인 방식·부정 방지 검토 |
| 선택 동의 | 뉴스레터·연락처/계정 연결 | 목적별 별도 동의·철회 검토 |
| 연락 가능 상태 | 확인된 이메일 등 | 동의만 있고 실제 발송 가능하지 않을 수 있음 |

Lead v1 첫머리에는 **사진·이름 수집**이 나오지만, 아래 절에서는 **사진 업로드→자동 복셀 변환을 하지 않음**으로 정리한다. 계획상 쓰지 않을 데이터는 수집 목록에서 빼거나 별도 목적·흐름을 제시해야 한다. 개인정보 문구·연령 처리는 법무·운영 검수가 필요하다. 실제 연락 경로와 카드 미션의 관계는 클로드가 후속안에서 정리하는 것이 좋다.

## 안 정한 것

1. C-2: 카드 성장 저장 단위(개별 카드/덱)와 화면 표시 단위.
2. 케이팝 시즌 60일의 시간 뜻과 하루 원정 횟수, 카드 공급·무료 완성 목표.
3. 40칸 보드의 카드 공급 칸 배치와 장소 성장 시 희귀 카드가 **어떤 보장**을 주는지.
4. 초기 멤버 슬롯 5를 넘어서는 제휴 IP의 처리 방식.
5. 홍보 덱의 외부 참여 9건 중 실제 연락 가능한 리드로 전환되는 경로.

## 하지 않음

- 다른 AI의 MD·HTML·STATUS 기록을 수정하지 않는다.
- 모노카피바라의 유료 벽·팩 가격·무과금 99%를 케이팝에 확정 수치로 복사하지 않는다.
- 참여 이벤트만으로 마케팅 연락 동의가 생겼다고 표기하지 않는다.
- 건물 상징·IP 교체·카드 규칙의 승인·채택을 자칭하지 않는다.
