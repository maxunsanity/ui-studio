## 0. 한 줄
**몬스는 계정이 가지고, 아이돌에게 붙여 주며, 판마다 대표 1마리만 나가고 나머지는 상한 있는 보조만 합니다. 성장은 중복 조각으로 오르는 별 등급 하나뿐이고, 돈으로는 겉모습(변형)만 사며, 몬스의 힘은 팬 투표 · 페스티벌 순위에 직접 들어가지 않습니다.**

## 1. 결정안 (P176 10장 질문 1~10)
| # | P176 질문 | 클로드 결정안 | 이유 |
|---|---|---|---|
| M1 | 1:1 고정 해제 · 계정 소유 | **예** · 계정 범위 저장(P203 U2) | 멤버 교체 = 몬스 교체 문제를 끊음 |
| M2 | 매칭 B · A · C | **B 느슨한 짝 + 궁합 보너스** | 수호신 설정은 살리고 자유도도 남김(P176 추천과 같음) |
| M3 | 아이돌 보유 칸 · 등급으로 열림 | **예** · 칸 수 · 열림 시점은 발란스 대기 | 아이돌 성장과 이어짐 |
| M4 | 대표 1마리 + 보조 평균 · 상한 | **예** | 많이 모아도 힘이 끝없이 커지지 않음 |
| M5 | 기분 1/N · 디펜스 · 정산을 「대표 수」 기준 | **예** · 디펜스 `party_scale` 뜻 바꾸기는 개발 확인 | 멤버 수와 값이 같이 움직이는 문제 해소 |
| M6 | 소속사 몬스 = 한 명 | **예** · 새 구조에서도 「대표 1명」으로 셈 | 현중 21:08 ⑦ 유지 |
| M7 | 같은 종 여러 마리 · 별 · 변형 | **예** · 단 **한 판 대표끼리는 같은 종 제외 유지** | 수집은 풀고 무대 다양성은 지킴 |
| M8 | 몬스 카드 새로 | **예** · 아이돌 카드와 표 분리 · **획득은 플레이 · 시즌 보상 중심, 유료는 변형만** | P197 「순위에 닿는 힘은 팔지 않음」과 같은 선 · 「곡 뽑기 금지」와 같은 결 |

| M10 | 새 종 시즌마다 | **예** · 시즌 보상 · 새 도시 진출(P193) 지역 몬스로 | 시즌 · 지역에 새 얼굴 |

## 2. 다른 기획과의 연결
| 기획 | 연결 | 선 |
|---|---|---|
| 음원 × 페스티벌 P191 | 대표 몬스는 데뷔곡 피드 카드 · 무대 연출에 **얼굴로** 나옴 | 투표 · 채점 점수엔 몬스 힘이 안 들어감 |
| 유료화 P197 | 몬스 변형(색 · 무늬)은 판매 가능 | 별 · 능력 · 조각 직접 판매 없음 |
| 시즌 P194 | 몬스 · 별 등급은 계정 범위로 남음 · 한 판 안 스킬 강화는 그대로 판 끝 초기화 | 시즌 보상으로 새 종 |
| 새 도시 진출 P193 | 지역마다 그 지역 몬스 종(시즌 추가분) | 지역 이름은 IP 확인 대기 |
| 게임 경제 P200 | 「몬스 조각」을 자원 장부에 새 줄로(시즌 끝 = 유지) | 값은 발란스 대기 |
| 유저 저장 P203 | 보관함 · 별 · 변형 · 붙은 아이돌 = 계정 범위 | 서버 정본 |

## 3. 참고(웹)
- 중복을 「나쁜 뽑기」로 만들지 않는 방법(중복 → 조각 · 한계 돌파)이 업계 표준입니다. 다만 우리는 뽑기 판매가 아니라 **플레이 보상으로만** 중복이 나오게 해서, 별 등급이 돈으로 바로 오르지 않게 했습니다.
