# 카드 · 아이돌 전용 단계 카드와 사업 덱

**이 문서는** 아이돌 전용 단계 카드와 사업 15덱의 수집·최초 효과·중복을 설명합니다.

**보는 법** 개인 카드 → 사업 카드 → 획득·효과 → 현재 연결과 남은 확인 순서로 읽습니다. [대표 기획서](/docs/planning/삼중AI_공용_20260929/산출/개발진행기획_v01/콘텐츠별_v03/카드_기획서.html)를 함께 봅니다.

**지금 상태** 경제 코드의 단계 카드·팩·최초 효과 연결과 실제 화면·트레이드 실행 확인을 구분합니다. 최신 팩 상세는 동시 갱신 중인 대표 기획서를 따릅니다.

[공용 시뮬레이터 실행](/docs/planning/game-simulator.html?module=simulator_module_cardbook)

## 1. 아이돌과 함께 여는 단계 카드

카드는 그 아이돌 전용 단계 카드와 사업 덱으로 나눕니다. 개인 카드는 해당 아이돌의 능력, 사업 카드는 최초 획득 당시 합류한 팀원의 능력으로 이어집니다.

## 2. 단계마다 같은 12속성

단계가 오를 때마다 12칸이 열립니다. 연습생·데뷔조·라이징 스타·톱스타·월드스타의 5단계로 아이돌 한 명은 60칸을 가집니다. 카드에는 속성만 표시하며 높은 단계일수록 장당 능력이 큽니다.

## 3. 실제 합류한 아이돌의 전용 카드

고정 샘플 인물 다섯 명이 카드북의 영구 주인은 아닙니다. 실제 합류한 아이돌에게 카드가 붙고 아이돌 사이에 이동하지 않습니다. 같은 멤버의 ID·단계와 성장 기록을 읽습니다.

## 4. 개인 단계 카드와 사업 15덱

현재 기획은 고정20덱이 아닙니다. 아이돌마다 열린 단계 덱이 생기고 사업 15덱은 유지합니다. 원표의 기존20테마·240행은 남아 있으며, 개인 단계 카드의 틀·값 계산과 기존 저장 호환에 쓰는 행을 현재 카드북 구성과 구분합니다.

## 5. 카드 표에는 단계와 속성

개인 카드는 아이돌 없는 60칸 틀을 두고 받을 때 아이돌에게 붙입니다. 단계마다 같은 12속성과 칸→세부 능력 연결을 사용합니다. 단계별 배분과 효과량은 원표에서 읽고 이 제안서에 새 값을 정하지 않습니다.

## 6. 사업 덱은 최초 획득 때의 팀에

사업 15덱은 제작·회사 운영·팬 활동으로 구성됩니다. 카드를 처음 얻었을 때 합류한 팀원에게 각자의 세부 능력에 맞춰 적용합니다. 나중에 합류한 멤버에게 과거 카드를 소급 지급하지 않습니다.

## 7. 아이돌 팩과 사업 카드 팩

모험·탐험·미션·수집 보상·상점의 아이돌 팩과 보드·완공 덤·이벤트 등의 사업 카드 경로를 구분합니다. 출동·보드 미니게임 팩의 실제 연결은 대표 기획서의 남은 항목을 따릅니다.

## 8. 처음 한 장만 능력

같은 아이돌·단계·칸을 처음 얻었을 때만 능력 효과를 적용합니다. 중복은 보유 장수만 늘고 능력을 다시 지급하지 않습니다. 덱12장을 완성했다고 이미 지급한 전체 효과를 다시 지급하지 않습니다.

## 9. 받을 때 붙는 카드 ID

현재 개인 카드 ID는 아이돌 합류 자리·단계·칸을 구분합니다. 카드북은 합류 아이돌의 열린 단계 덱과 사업 덱을 보여 주며, 서로 다른 종류 수와 중복을 포함한 보유 장수를 따로 읽습니다.

## 10. 카드는 승급 한도가 아닌 능력

승급은 아이돌 성장 기획의 능력·학습 조건과 실제 보드 승급 흐름을 따릅니다. 카드 장수 자체를 새 승급 조건으로 만들지 않습니다. 카드 수집과 멤버 단계 판정은 서로 다른 책임입니다.

## 11. 다른 콘텐츠 효과를 새로 만들지 않기

카드가 올린 능력과 다른 콘텐츠의 실제 판정은 구분합니다. 카드로 페스티벌 참가 슬롯을 채우거나 투표 점수를 직접 더하는 별도 규칙을 이 문서에서 만들지 않습니다. 다른 콘텐츠에서 카드를 쓰는 추가 기획은 아직 정하지 않습니다.

## 12. 수집 완성과 진행률

개인 카드 한 단계12칸 완성은 수집 테마 한 개로 셉니다. 사업15덱과 개인 카드의 완성을 함께 세며 보상은 등록된 수집 보상과 공용 보상 묶음을 읽습니다. 완성 보상을 처음 효과와 혼동하지 않습니다.

## 13. 시즌과 보관함은 별도 정책

시즌 종료·유료 보관함·이월 혜택은 이 정리에서 새로 결정하지 않습니다. 과거 보관함 설명은 아래 이전 기획에 보존하며, 현재 적용 범위는 시즌 기획과 대표 카드 기획을 함께 확인합니다. 모든 카드나 성장치가 자동 보존된다고 약속하지 않습니다.

## 14. 소유 기록과 실제 성장 기록

카드 장수가 늘어난 기록과 실제 능력이 증가한 기록은 다릅니다. 같은 요청 재시도·화면 다시보기로 처음 효과를 더 지급하지 않으며, 대상·정산·저장이 확인되지 않으면 연결 대기로 구분합니다.

## 15. 중복분 트레이드는 기획과 실행을 구분

기획은 중복분만 유저끼리 트레이드하고 돈·유료 재화를 끼지 않는 방향입니다. 상대·한도는 친구 기획 뒤에 정합니다. 이번에 확인한 게임·시뮬레이터·친구 모듈과 등록표에서는 별도 트레이드 실행 연결을 확인하지 못했으며 전역 미구현 판정으로 확대하지 않습니다.

## 16. 같은 표를 읽는 실행인지 확인

경제 카드북은 단계 카드·사업 카드와 두 겹 주머니 표를 읽습니다. 별도 카드 화면에도 독립 로더가 있으므로 새 팩·상세 효과가 모든 실행에서 같다고 단정하지 않습니다. 상세 모델의 이전 테마 분류와 새 단계 카드 연결은 추가 확인 대상입니다.

## 17. 남은 것은 새 장수 선택이 아닙니다

9장과12장 중 고르는 옛 질문은 현재 기준이 아닙니다. 현재는 단계마다12칸이며, 팩 공급량·확률·임시 무게·트레이드 상대와 한도·실행별 연결·시즌 보관 정책의 확인이 남습니다. 굿즈의 품목·대상·기간도 새로 결정하지 않습니다.
