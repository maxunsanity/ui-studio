## 간략

**머리표** 시스템 기획 · S15 · 소셜 · 모노 127 · 131 · 262 · 93 이식 · **당시 이식 범위는 확인 필요 · 보류** · 현재 LOCAL 부분 코드와 운영 검수는 구분

**제목** 소셜 · 친구 — 친구 기획사 소식을 보고, 내 기록장에 남긴다

**훅(기획)** 시설을 완공하면 기록장에 한 장이 남는다. 「친구들에게 보여주기」를 누를 때만 친구 소식에 뜬다.

**두 줄 요약**
- 기획 규약: 친구 소식(친구들 글)과 내 기록장(내 글)을 한 화면 두 탭으로. 글은 콘텐츠가 끝날 때 자동으로 「나만 보기」로 생기고, 자랑 · 공개는 내가 고를 때만.
- 친구는 코드 · 초대 링크 → 요청 → **수락**으로만 맺는 기획이다. LOCAL 요청 · 수락/거절과 테스트 봇의 부분 코드가 있으며, 같은 창구 뒤에서 서버로 바꾸는 것은 LIVE 이전 목표다.

**규약 그림** — 이식 기획의 흐름이다. 모든 콘텐츠 완료 · 공개 · 수락이 실제 게임이나 서버에 연결됐다는 검수 결과는 아니다.

```mermaid
flowchart LR
  E[콘텐츠 끝<br/>시설 완공 · 스케줄 결과 · 팬 마일스톤] --> P[글 1건<br/>나만 보기]
  P --> M[내 기록장]
  M -->|친구들에게 보여주기| F[친구 소식]
  F -->|담기| O[친구 기록장<br/>인용 액자]
  C[코드 · 초대 링크] --> R[요청 대기] -->|수락| FR[친구]
  FR --> F
```

1. **남긴다** — 시설 완공 · 스케줄 결과 · 팬 마일스톤이 끝나면 글 1건이 내 기록장에(나만 보기).
2. **보여 준다** — 「친구들에게 보여주기」 → 친구 소식에 뜬다.
3. **담는다** — 친구가 「담기」 → 그 친구 기록장에 인용 액자로.
4. **맺는다** — 코드 · 초대 링크로 요청 → 상대가 수락해야 친구.

| 왜 지금 | 이게 핵심 | 이게 아닌 것 |
|---|---|---|
| 작성 당시 착수 사유: 모노 소셜 넷이 남았고 케이팝 기획서가 없다(S10 F18 · 2차 5단계) | 담벼락(친구 전부 · 골라 보내기 없음) · 보상 없음 · 수락으로만 친구 · LIVE 권위 목표: 서버가 진실 | 약탈 · 공격 · 복수 · 펫 방어 · 모험 엽서 · 전체 공개 · 채팅 |

### 4. 서버로 옮기기 (이식)
