## 이게 뭐냐

**카드 한 장이 태어나서(캐스팅·덱 구성) → 나오고(획득 경로) → 쌓이고(★·중복·레벨) → 쓰이는(편성·탐험·대결) 전 과정.** 현중 요청 「카드 획득이 가장 중요 — 회의록·자료로 카드가 어떻게 만들어지는지 분석」에 대한 답.

## 언제 쓰나

카드북·보드·탐험·상점·이벤트를 설계할 때 **「이 시스템은 어떤 카드를 몇 ★로 주나」** 를 여기서 찾는다.

---

## 한 줄

> **카드는 모든 곳에서 나온다. ★는 운이 정하고, 레벨은 사장이 보낸 만큼 오른다. 모은 카드는 쓰여야 의미가 있다.**

## 자세히

### ① 카드가 태어나는 과정 — 캐스팅이 카드북을 만든다

<div class="flow"><div>캐스팅 16명<br><small>15분 · 카드 아님</small></div><div>멤버 N명 선택<br><small>1~20명 가변</small></div><div>카드북 개방<br><small>멤버 덱 N + 기타 덱</small></div><div>카드 수집<br><small>180장</small></div><div>월드 페스티벌<br><small>등급별 입장</small></div></div>

- **캐스팅 16명은 카드가 아니다.** 「나의 아이돌 후보」다. 능력치가 다른 16명을 15분 안에 빠르게 모은다 — 카드가 「툭툭툭」 쏟아지는 맛 (회의 03:30~03:54).
- **선택한 N명이 카드북의 멤버 덱이 된다.** 5명이면 멤버 덱 5개. 싱글이면 1개, 20인 그룹이면 20개 (회의 32:43~33:23).
- **탈락한 후보는 버리지 않는다** → **연습생 풀**로 남아 탐험 보조·재선정·다음 시즌 후보 (WORLD FESTIVAL §8.3 손메모 「카드라기보다 연습생 풀」).
- **멤버 덱 9장 = 그 아이돌의 성장 서사.** GDD 템플릿: 연습생(★1) → 데뷔(★2) → 솔로(★3) → 완성체(★4) → 천음·골드(★5). 서사를 **카드 이름**에 담는다 (예: 「마지막 기회 오디션」·「솔로 데뷔 무대」).
- 나머지 덱은 **덱 풀**에서 채운다 (회의 33:23~40:28 · GDD §9~11):

| 덱군 | 예 (9장씩) | 역할 |
|---|---|---|
| 스태프 | 비주얼 크리에이티브 · 작곡가 · 작사가 · 프로듀서 · 코리오그래퍼 · 트레이너 · 세션 | 제작·훈련 |
| 매니지먼트 | 로드 매니저 · 스케줄러 · 연습생 스카우터 · A&R | 운영 |
| 정령 | 악당(빨강)으로 들어와 정화되면 수호정령 | 탐험 |
| 홍보 | SNS 에디터 · 숏폼 챌린지 기획자 · PR | **리드젠** |
| 컨디션 | 피지컬 · 심리상담사 · 멘탈 코치 | 회복 |
| 비즈니스 | 유통 · 법무 · 굿즈 MD · 투자자 | 자본 |
| 보스 · 무대 · 지역 · 팬덤 | — | 시즌 서사·이벤트 |

→ 20덱 = **멤버 N + 덱 풀에서 (20−N)**. 멤버가 많으면 스태프 덱이 줄어든다. 덱 풀 우선순위는 체크(C-3).

### ② 카드가 나오는 곳 — 「모든 시스템」

| 경로 | 무엇이 나오나 | ★ 범위(가안) | 비고 |
|---|---|---|---|
| **일정 착지** | 그 일정과 맞는 덱의 팩 | ★1~3 | 연습실 → 트레이너·코리오 / 녹음실 → 작곡·작사 |
| **건물 성장** | 성장 완료 시 스태프 팩 | ★2~4 | 그 시설 담당 덱 (GDD 「랜드마크 업 → 스태프 팩」) |
| **성장 장소 한정** | 급이 오른 무대(예: 아레나홀)에 **도착했을 때만** | ★4~5 | 회의 42:58 — 보드를 키워야 나오는 희귀 카드 |
| **탐험 · 원정** | 정령 카드 · 탐험 전용 카드 | ★1~5 | 정령 정화 완료 시 |
| **미션** | 일일·주간 · 멤버 팩 | ★1~4 | |
| **이벤트 · 시즌 패스** | 골드 · 보스 · 팬덤 | ★4~5 | 골드 이벤트 |
| **홍보(리드젠)** | 홍보 덱 · 특별 보상 | ★1~5 | 참여 안 해도 기본 보상 |
| **캐스팅** | (카드 아님) 멤버 후보 | — | 튜토리얼 |
| **교환** | 친구 교환 · 별 교환소 | — | 골드는 이벤트 때만 |

- 팩은 **색 = 최소 ★ 보장** (GO: 노랑 ★2 · 분홍 ★3 · 파랑 ★4 · 보라 ★5). 어디서 나왔는지보다 **무슨 색 팩인지**가 기대감.
- ⚠ GDD v1.4는 「보드는 카드를 드롭하지 않음」이었으나 9/28 회의는 「모든 시스템에서」 → **체크 C-1.**

### ③ 카드가 쌓이는 규칙

| 규칙 | 내용 | 출처 |
|---|---|---|
| ★ 고정 | ★는 얻을 때 정해짐. 합성·★성장 없음 | 회의 29:32~30:10 |
| 중복 → 별 | 겹치면 별로 환산 (골드는 더 큼) → **별 교환소**에서 팩·주사위·꾸밈 | GO 스티커 방식 |
| 골드(★5) | 덱마다 1장 · 교환은 **골드 이벤트 기간만** | GO · GDD §7 |
| **카드 레벨** | ★와 별개. **원정·파견·탐험에 보낸 횟수**로 Lv ↑ → 탐험 능력치 | 회의 31:37~32:16 (모노카피바라) |
| 속성 | 카드마다 탐험 속성 → 조합이 탐험 결과를 바꿈 | 회의 31:27~31:31 · 41:00 |
| 교환 | 친구 간 교환 (GO는 SNS·레딧 교환 문화) | 회의 32:32~32:43 |

- **★(운)와 레벨(노력)을 UI에서 다른 모양으로.** ★는 별, 레벨은 숫자 배지.

### ④ 덱 완성 보상

| 덱 | 완성 보상 (시즌 내) |
|---|---|
| 멤버 덱 | 그 멤버 무대 연출 · 담당 건물 스킨 |
| 스태프 덱 | 담당 시설 수익·성장 버프 |
| 정령 덱 | 탐험 슬롯 +1 |
| **홍보 덱** | **기본 보상 + 리드젠 완료 시 특별 보상** (금액은 라이브 QA) |
| 카드북 완성 | 기념 액자 · 시즌 기록 — **독점 콘텐츠 입장권 아님** (대표 우려) |

### ⑤ 카드가 쓰이는 곳 — 한 카드는 한 곳에만

| 쓰는 곳 | 필요한 카드 | 결과 |
|---|---|---|
| 무대 편성 (9슬롯) | 멤버 3 · 스태프 4 · 정령 2 | 무대력 → 수익·명성 |
| 탐험 · 정령 정화 | 정령 + 멤버 (공연) | 수호정령 · 카드 레벨 ↑ |
| **음방 1위 대결** | 방송 성격에 맞춘 덱 (댄스·비주얼 등) | 주간 순위 (회의 45:38) |
| 앨범 제작 | 멤버 1 · 작곡 · 작사 · 프로듀서 · 세션 | 곡 → 실제 음원 연계 가능 (회의 44:29) |
| 스케줄 파견 | 멤버 | 현금 · 명성 · 카드 레벨 |

- **한 카드는 한 곳에만** (GDD §16) → 편성·제작·파견이 같은 카드를 두고 경쟁 = 사장의 배분 결정.

### ⑥ 공정성 — 대표 우려 반영

- **완성자만 들어가는 콘텐츠 금지** (회의 12:09~13:48). 늦게 온 사람, 돈 많은 사람, 첫날 사람이 섞이면 분란.
- → **리그·등급 분리**: 1성 유저끼리 · 2성끼리 · 3성끼리 엔드 콘텐츠 (회의 15:44) · 음방 대결도 리그 분리 (GDD 16.3).
- → **천장**: 오래 못 얻으면 선택권 (GPT 리서치 「천장형 누적 보장」).

### ⑦ IP 교체 — 샘플 5 → 실제 아이돌

- 멤버 덱 **9장 템플릿**은 고정, 아이돌만 바뀜 → 시즌마다 **멤버 덱만 새 아트** (GDD: 45장 신규 · 135장 공용·리컬러).
- 첫 시즌 = 어우동 등 샘플 5인, 이후 콜라보 IP가 **같은 슬롯**에 들어감.
- 실존 이름을 못 쓰는 카드는 패러디 표기 가능 (회의 41:23 「이종범 → 이성범」 식) — **체크 C-5 (법무)**.
