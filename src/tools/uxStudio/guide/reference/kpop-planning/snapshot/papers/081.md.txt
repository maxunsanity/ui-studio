## 이게 뭐냐

**일정 보드에서 일어난 일이 남는 곳.** 비하인드가 쌓이고, 남들이 보고, 주간 순위가 난다.

> **왜 「입덕」인가** — 팬이 실제로 쓰는 말이다. 처음 빠진 날부터 지금까지를 가리킨다.
> 여기 들어오면 **내가 이 아이돌한테 빠진 뒤로 있었던 일이 전부 있다.** 그게 이 집이 하는 일과 정확히 같다.
> [016 미션풀](./016_미션풀_관계성장창작.md)·[020 직함](./020_성장사다리_빠순이에서_사장.md)에 「덕통사고 → 입덕」이 이미 있어 말이 이어진다.

## 한 줄

**일정 보드는 「오늘」이고, 입덕은 「남은 것」이다.**

## ★ 겹치면 안 되는 지점 (먼저 확인한 것)

처음엔 「투어 = 팀을 내보낸다 / 개인 활동 = 멤버를 내보낸다」로 짰다가 **판과 정면으로 겹쳤다.**

| 겹쳤던 것 | 일정 보드에 이미 있는 것 |
|-----------|----------------------|
| 개인 쪽에 「예능·라디오·화보」 | 노랑 사다리에 **라디오 · 케이블 예능 · 공중파 예능 · 인터뷰** |
| 팀 쪽에 「지역·무대」 | 초록 사다리가 **버스킹 → 클럽 → 소극장 → 중극장 → 아레나** |
| 개인 쪽에 「개인 방송」 | 15번 칸이 **개인방송** |

**모노카피바라는 안 겹쳤다.** 보드는 전투·건설이고 모험은 카드 파견이라 하는 일이 달랐다.
**우리는 보드가 이미 스케줄이라 그 방법이 안 통한다.**

### 그래서 자리를 이렇게 나눈다

| | **일정 보드** | **입덕** |
|--|--------------------------|----------|
| 무엇 | 아이돌이 **어디 가나** | 거기서 **뭐가 나왔나** |
| 때 | **오늘** | **지나간 것 모아 보기** |
| 누구와 | 혼자 (내 판) | **남과 견주기** |
| 주사위 | 쓴다 | 안 쓴다 |

> **입덕은 새로 내보내는 데가 아니다.** 판에서 이미 일어난 일이 남는 데다.

## 이름을 다 바꾼 이유

옛 이름들은 **「내보내기」 시절**에 지은 것이라 하는 일과 안 맞는다.

| 옛 이름 | 새 이름 | 왜 바꿨나 | 모노 원래 |
|---------|---------|-----------|-----------|
| 커리어 시즌 | **입덕** | 「시즌」이 3개월([065](./065_시즌구조.md))과 겹쳤다. **팬이 쓰는 말**로. 처음 빠진 날부터 지금까지가 여기 다 있다 | 모험 |
| 투어 | **원정** | 못 가는 데로 **보내고 기다린다**. 피크민 「보내기」 그대로 | 여정 |
| 개인 일정 | **총공** | 마감 전에 **다 같이 깎는다**. 피크민 「달라붙기」 그대로 | 출동 |
| — | **비하인드** | 스케줄 뒤에 남는 사진·영상·음원. 팬덤이 쓰는 말 | 엽서 |
| — | **내 것 · 남들 것** | 「기록장」이 상위 이름과 겹쳐서 쉬운 말로 | 기록장 · 친구 소식 |
| — | **시안** | 팬이 꾸며서 내고 팬덤이 고른다. 빠순이가 실제로 쓰는 말 | (천음 리그에서) |

**「원정 / 총공」으로 간 이유** — 둘 다 **팬덤이 실제로 하는 일**이고, 피크민에서 온 두 모양과 정확히 맞는다.
원정 = 못 가는 데로 보낸다(여정) · 총공 = 마감 전에 다 같이 민다(출동).

## 1. 무엇이 남나 — 비하인드

**판에서 좋은 일이 있으면 비하인드가 남는다.** 따로 내보내지 않는다.

| 판에서 | 남는 비하인드 |
|--------|---------------|
| 무대 칸 **대박** | 그날 무대 · 음악 / 영상 |
| 팬미팅 · 개인방송 | 만남 · 이미지 / 영상 |
| 생활 · 자유시간 | 일상 한 컷 · 이미지 |
| **급이 오른 날** | 그 자리가 커진 기록 |
| **판이 바뀐 날** | 동네를 졸업한 기록 |
| 덕질 6단 달성 | 밥차·전광판이 크게 들어간 날 |

**전부 판에서 이미 일어나는 일이다.** 입덕은 그걸 **모아서 보여줄 뿐**이다.

### 등급이 전부를 바꾼다

모노카피바라가 엽서에 쓰는 방식 그대로 (`adventure_postcard_tier_visual`).

| 판정 | 비하인드 |
|------|----------|
| 대박 | 길고 좋다 · **금테 · 도장 · 별 셋** |
| 중박 | 보통 · 은테 · 별 둘 |
| 운빨망빨 | 짧다 · 테 없음 · 별 하나 |

### LLM이 만든다

모노는 글 조각 249개를 미리 써두고 뽑는다. 우리는 **매번 만든다.**

```
입력  아이돌 · 어느 칸 · 누가 · 준비도 · 판정 · 지금 급 · 시즌 몇 주차
  ↓
출력  비하인드 한 장 — 음악 / 이미지 / 영상 중 하나
```

**틀은 고정한다.** 형식·길이·말투를 묶고 내용만 만든다. 말투 규칙은 [067](./067_서사.md) 그대로 — 자랑 말고 기록 · 좋은 일에도 그늘 한 점 · 과장 금지.

## 2. 어디에 쌓이나 — 내 것 · 남들 것

모노 127 구조 그대로.

| | 무엇 |
|--|------|
| **내 것** | 내 비하인드만. 시즌이 끝나면 **한 장으로 묶인 이야기**가 된다 |
| **남들 것** | 남의 비하인드가 흐른다 |

개념 이름은 **내 것 · 남들 것**이다. 전화기에서 누르는 이름은 모노와 같이 **내 기록장 · 친구 소식**이다.

**모노가 못 박은 것을 지킨다**
- **딱지·어부지리는 「남들 것」에 안 태운다** (모노: 약탈·선물은 피드에 안 올림)
- 공유해도 **내 것이 사라지지 않는다**
- **풀 UGC 광장을 만들지 않는다**

### 화면 (2026-10-29)

현중 확인. 친구 소식과 내 기록장은 모노카피바라 소식 화면과 같은 카드로 본다. 글만 늘어놓은 목록이 아니다.

| | 화면 |
|--|------|
| **친구 소식** | 맨 위에 받은 편지. 그 아래 친구 글, 최근 것이 먼저. 그림이 있으면 그림 카드, 없으면 색 칸에 제목 |
| **내 기록장** | 내 글과 담아 둔 글만. 날짜 줄로 나뉜다. 처음에는 나만 보고, **친구들에게 보여주기**로 연다. 연 뒤에는 **다시 나만 보기** |
| **카드에서** | 좋아요, 댓글, 남의 글은 **담기**. 담으면 내 기록장에 원작 액자로 남고, 원작 글은 그대로다 |
| **받은 편지** | 열어 본 뒤 **나중에** 또는 **기록장에 두기**. 목록에 그냥 열어 둔 것으로는 빠지지 않는다 |

봇은 도구 왼쪽에 두고, 기본은 아무도 넣지 않는다. 넣은 친구의 첫 소식만 올라오고, **봇 소식 한 번 더**를 누르면 다음 소식이 온다. 친구를 빼면 그 친구 글은 소식에서 빠지고, 이미 담아 둔 글은 내 기록장에 남는다.

담기 하루 한도는 모노 `social_feed_config`의 `share_daily_max`를 읽는다. 이 기획서에 새 숫자를 적지 않는다. 받은 편지를 기록장에 두는 것은 그 한도를 쓰지 않는다. 모노와 같다.

문장·도장·배지·그림은 모노 표에서 가져온다. 여기 없는 봇 이름이나 글을 만들지 않는다.

## 3. 하는 것 셋 — 원정 · 총공 · 시안

모노 **여정·출동**은 둘 다 **피크민에서 가져온 것**이다. 모양이 이렇다.

| 모노 | 피크민 모양 | 덕질에서 같은 모양 |
|------|-------------|--------------------|
| **여정** | 목적지 골라 **보내고 기다림**. 돌아오면 물건을 들고 온다 | **원정** — 못 가는 데로 보낸다 |
| **출동** | 큰 걸 앞에 두고 **여럿이 달라붙어 깎음**. 시간 초과 = 실패 | **총공** — 마감 전에 다 같이 민다 |

### 원정 (모노 여정)

**내가 못 가는 데로 보낸다.** 판이 홍대면 해외는 못 간다 — 거기로 보낸다.

| | |
|--|--|
| 예 | 지방 공연에 슬로건 · 해외 팬미팅에 서포트 · 시상식에 광고 |
| 고르는 것 | 어디로 · 무엇을 얼마나 |
| 기다린다 | 결과가 온다 |
| 나오는 것 | **비하인드** · 코인 |

**판 안 덕질과 겹치지 않는다.** 덕질은 **판 안에서 한 단씩** 키우는 것이고, 원정은 **판이 못 닿는 데로 한 번에** 보내는 것이다.

### 총공 (모노 출동)

**큰 걸 앞에 두고 마감 전에 다 같이 민다.**

| | |
|--|--|
| 앞에 놓인 것 | 차트 1위 · 투표 · 초동 |
| 시간 | **마감이 있다.** 음방 집계가 끝나면 끝 |
| 누가 | 나 + 친구 + **서버 전체** |
| 못 넘기면 | **실패.** 시간 초과 = 보상 없음 (모노 출동 그대로) |
| 나오는 것 | **비하인드** · 전 서버 보상 |

> **판에서 뺐다.** 3·18·34 칸은 **응원**(작게 한 번씩 미는 것)으로 바뀌었다 ([039](./039_공동기금_GO표기.md)).
> 총공은 *시간 정해놓고 다 같이 몰아붓는 것*이라 **판 밖**이 맞다. 칸 밟아서 하는 일이 아니다.

### 시안 (천음 리그에서)

**팬이 공식 소스로 꾸며서 내고, 팬덤이 고르고, 1등이 다음 주 전 서버 판에 걸린다.**
원정·총공과 달리 **내가 만든 것**이고, 그래서 이것만 순위가 붙는다. 전면 기획 → [082](./082_시안.md)

### 그 결과가 비하인드다

모노에서 **엽서**가 여정·출동의 결과물이듯, 우리 **비하인드**는 원정·총공의 결과물이다.
그리고 판에서 일어난 일(§1)도 같이 쌓인다.
**비하인드는 겨루지 않는다** — 쌓이고 공유될 뿐이다 (§4).

## 4. 어떻게 겨루나 — 시안 (2026-09-18 다시 정함)

**전면 기획은 [082 시안](./082_시안.md)으로 뺐다.** 여기엔 왜 그렇게 됐는지만 남긴다.

### 처음엔 비하인드로 겨루려 했다 — 안 된다

천음 리그 제안을 그대로 가져와 **비하인드에 순위를 매기려** 했는데, 세워 보니 무너진다.

| 무너지는 지점 | 왜 |
|---------------|-----|
| **겨룰 내용물이 없다** | 비하인드는 게임이 만든다. 판정 등급 말고는 다 똑같이 생겼다 |
| **투표 35%가 죽는다** | 고를 이유가 없으면 아무도 진지하게 안 찍는다. 제안서에서 투표가 제일 무거운 건 그게 **취향 판단**이라서다 |
| **돈이 이긴다** | 그 35%가 비면 후원·조회가 자리를 먹는다. 제안서 §6이 막으려던 상태가 기본값이 된다 |
| 순위의 뜻 | 「누가 주사위를 많이 굴렸나」 = **과금 순위표**에 음방 차트 옷을 입힌 것 |

### 그래서 겨루는 건 팬이 만든 것으로

**사람마다 다른 것**이 있어야 순위가 선다. 그건 팬이 만든 것뿐이다.
다만 **파일 업로드는 못 한다** — 우리 아이돌은 실존 인물이고, 제안서 자신이 「실존 아이돌 초상 무단 금지」를 써 뒀다.

→ **공식 소스로 게임 안에서 꾸미기.** 제안서의 「크리에이터 키트」가 그 장치다.
→ 부문 셋은 **문구 · 광고 시안 · 자리 꾸미기** — 우리 덕질 항목 그대로.
→ **후원 지표는 뺀다.** 현질이 순위를 사면 딱지·총공에서 지킨 선을 여기서 깬다.
→ 1등 보상은 재화가 아니라 **그 시안이 다음 주 전 서버 판에 걸리는 것**.

### 제안서에서 그대로 가져온 것

주간 사이클(월 열림 → 금 마감 → **일 블라인드** → 월 발표) · 로그 정규화 · 1인 최고 1개만 보상 ·
Top 차등 · 명예의 전당 · 참가상·도약상·개근·팬 픽 추첨 · 공유는 **실제 유입만** · 레벨 게이트는 **덕력**으로 ·
부계정·품앗이·봇 필터. **업로드에 딸린 것(검수·핑거프린트·해시·저작권·AI 표기)은 통째로 사라진다.**

### 「천음 게이지」는 총공으로 갔다

전 서버 공동 목표는 [총공](./071_파견.md)이 가져갔다 ([D-042](../../DECISIONS.md)).
**한 주에 협력 하나(총공) · 경쟁 하나(시안).**

## 5. 왜 퍼지나 — 목적 4

제안서가 진짜 원한 것. 원문 근거 셋.
- 공유 점수를 **"링크로 실제 들어온 사람 수"** 로만 셈
- KPI에 **"공유 링크 경유 신규 설치 수"**
- 「공유 링크 복사」 원탭 — 원문 표현: *"창작자가 알아서 게임 밖에 퍼뜨리게 만드는 장치"*

**비하인드는 그 자체로 공유거리다.** 만들 필요 없이 이미 한 장짜리다.
**시안은 내가 만든 것이라 더 퍼진다** — 팬덤은 자기가 만든 걸 자기가 퍼뜨린다.

> 팬덤은 원래 인증하는 문화다. **만들라고 하면 몇 명만 하고, 인증하라고 하면 다 한다.**

---

## 6. 판과 입덕 — 한눈에

```
일정 보드          입덕
─────────────────────      ─────────────────────
주사위를 굴린다          →   그날 일이 비하인드로 남는다
칸에 떨어진다                    ↓
덕질한다                     「내 것」에 쌓인다
급이 오른다                      ↓
판이 바뀐다                  원정·총공에서도 나온다
                                 ↓
                            「남들 것」에 흐른다
                                 ↓
                            시안 — 내가 만들어 겨룬다
                                 ↓
                            밖으로 공유 → 새 유저
```

**판은 만들고, 입덕은 남긴다.**

모노 160이 못 박은 것을 지킨다.
> **"원정·보드에 바이럴을 얹지 않는다."**

---

## 7. 굿즈 — 판이 아니라 여기다 (2026-09-22 · D-066)

현실 매출의 **22~25%**가 굿즈다. **콘서트보다 크다.** 그런데 40칸 어디에도 자리가 없었다.

**판에 칸을 만들지 않는다.** 40칸은 GO 뼈대라 하나만 늘려도 깨진다. **입덕 쪽에 둔다.**

| 왜 여기가 맞나 |
|---|
| 입덕은 이미 **판에서 남은 것이 쌓이는 집**이다. 비하인드가 여기 모인다 |
| 굿즈는 **판을 돌아서 생긴 결과물**이지, 판 위에서 밟는 자리가 아니다 |
| 비하인드·시안으로 이미 「만들어진 것」을 다루고 있어서 **파는 것**이 자연스럽게 붙는다 |

대표 지시도 같은 방향이다 — 게임 안에서 만들어지는 것(굿즈·음원·영상)은 **전부 판매 대상**으로 둔다 (D-060).

**안 정한 것:** 굿즈가 코인으로 사는 것인지 현금인지 · 비하인드가 굿즈로 바뀌는 건지 따로 파는 건지

---

## 안 정한 것

- 「입덕 / 원정 / 총공 / 시안」이 최종 이름인가
- 총공 마감 실패 시 얼마나 아픈가
- 비하인드가 **어떤 순간에 나오나** (전부? 대박만? 하루 상한?)
- 형식 틀 (길이·구도·음악 길이)
- LLM 비용 · 실패 시 대체
- 시안 보상 크기 · 덕력 게이트 → [082](./082_시안.md)
- 3개월 시즌과 주간 리듬의 관계
- **이벤트 · 카드 대전** — 모노 모험 아래 있지만 아직 안 넣음
- **원정**(카드 키우는 파밍) — 우리에게 카드가 없어 빈 자리

## 하지 않음

- **입덕에서 새 일정을 내보내기** (판과 겹친다)
- 유저가 작품을 만들어 올리기
- 일정 보드에 순위·바이럴 얹기
- **비하인드로 순위 매기기** (2026-09-18 폐기 · §4)
- 딱지·어부지리를 「남들 것」에 태우기
- 메뉴 이름에 「시즌」 쓰기
