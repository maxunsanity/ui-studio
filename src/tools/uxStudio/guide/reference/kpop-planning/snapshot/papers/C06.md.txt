# D02 · 대화 축·시선·동작 연속성

문서 버전: 1.0 · 갱신: 2026-09-22 · 상태: 제작 참조 초안 / 실제 씬 검수 전

## 원리와 근거

연속 편집은 이어지는 컷에서 시간·방향·행동 관계를 이해할 수 있도록 구성한다. 두 인물 사이 축의 한쪽에서 촬영하면 화면의 좌우 관계를 유지하기 쉽다. 축을 바꿀 때는 새 공간 관계를 알려줄 연결이 필요하다. [Yale 편집 분석](https://filmanalysis.yale.edu/editing/), [StudioBinder 대화 축](https://www.studiobinder.com/blog/what-is-the-180-degree-rule-film/).

아래 좌표 검사와 정책은 우리 에디터의 구현 설계다. 예술적 선택을 자동 금지하는 절대 법칙으로 만들지 않는다.

## 저장할 상태

| 항목 | 의미 |
|---|---|
| axisActors | 현재 대화의 기준 배우 두 명 |
| axisEpoch | 배우 배치가 바뀌어 기준을 갱신한 구간 ID |
| cameraSide | 기준 축 어느 쪽에서 촬영하는지 |
| screenOrder | 전체 컷에서 보이는 배우의 좌우 순서 |
| gazeTarget | 각 배우가 실제로 바라보는 대상 |
| transitionReason | 축 변경·주관 전환·새 인물 공개의 이유 |

화자와 축을 동일시하지 않는다. A의 대사를 B가 듣는 컷이어도 A–B 관계는 유지된다. 세 사람이면 D05의 활성 대화 쌍과 전체 배치를 같이 사용한다.

## 수학적 보조 검사

월드 업 벡터 u, 배우 위치 a와 b, 카메라 위치 c를 읽는다. 수평 평면에 투영한 v=b-a와 w=c-a에 대해 s=dot(cross(v,w),u)를 계산한다. 같은 axisEpoch에서 s의 부호가 달라지면 축 교차 후보다. v 길이가 거의 0이거나 s가 허용오차 안이면 안정된 방향 판단을 유보한다.

부호만으로 최종 승인하지 않는다. 배우가 회전했거나 아주 가까운 정면 구도면 화면상의 시선도 확인해야 한다. 카메라 롤이 있거나 바닥이 기울어진 경우 기준 업 벡터를 명시한다. `cameraSide` 값의 +/−에 특정 감정을 부여하지 않는다.

## 컷 연결 검사 순서

1. 이전 컷 마지막 프레임과 다음 컷 첫 프레임을 나란히 확인한다.
2. 같은 인물의 화면 위치, 바라보는 방향, 몸 방향, 손·발 자세를 기록한다.
3. 동작 시간은 장면 시간으로 연속 재생하고 카메라 전환 시 애니메이션을 재시작하지 않는다.
4. 배우가 공간에서 이동했다면 그 이동을 관객이 알 수 있었는지 확인한다.
5. 의도적인 축 변화이면 전체 구도, 축 가까운 중립 구도, 연속 카메라 이동 등 이해 가능한 연결을 설계한다.
6. 새 축과 변경 이유를 기록하고 뒤쪽 컷을 같은 기준으로 재검사한다.

중립 구도 한 장을 넣었다고 항상 혼란이 해결되는 것은 아니다. 전환 후 인물 위치가 이해되는지 재생으로 확인한다.

## 구체적인 실패 예와 수정

A가 오른쪽을 보며 말하다 컷이 바뀐 뒤 B도 오른쪽만 보면 두 사람이 같은 곳을 보는 것처럼 느껴질 수 있다. 먼저 B의 `gazeTarget`이 A인지 확인한다. 그것이 맞다면 카메라가 축 반대편인지, 눈 회전이 적용되지 않았는지 분리한다. 머리 방향을 임의로 반전해 카메라 오류를 가리지 않는다.

A가 인사하며 오른손을 든 중간에 B의 반응 컷으로 넘어가더라도 A의 동작은 계속 진행된다. A로 돌아왔을 때 모션 시작 자세를 다시 보여주면 시간 연결이 끊긴다. 카메라 트랙과 배우 트랙의 독립 재생을 먼저 수정한다.

## AI 실행 지시

```text
현재 컷 전후의 axisEpoch, cameraSide, screenOrder, gazeTarget을 비교하라.
축 변경 후보이면 오류인지 의도인지 분류하고 근거를 남겨라.
오류는 카메라 후보를 다시 계산한다. 의도적 변경은 연결 컷과 새 축을 제안한다.
동작 프레임은 유지하고 카메라 수정으로 배우 모션을 재시작하지 마라.
```

완료 기준: 모든 대화 컷에 축·시선 근거가 있고, 축을 바꾼 지점의 이유와 화면 연결을 확인할 수 있다. 단순히 모든 부호가 같다는 것만으로 합격하지 않는다.
