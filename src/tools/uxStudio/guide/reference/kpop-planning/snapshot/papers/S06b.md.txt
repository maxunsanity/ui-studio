**이 문서는** 10/12에 작성된 보드 연출 3박자·무대·UI 연출 허브의 이식 규약과 당시 임시 시안을 보존한 시스템 기획입니다.

**보는 법** 아래 현재 읽기 범위를 먼저 보고, 간략 → 세부의 박자·표·허브 규약 → 확인 대기 순서로 읽습니다. 공통 구조의 확인 범위는 [S14 구현 구조](S14_구현구조.md)와 함께 봅니다.

**지금 상태** 제안(검수 대기)입니다. 포트의 일부 연출 API·reader·저장 요청 코드가 있으며 메인 연결과 실제 구동·저장은 미검수입니다. 아래 원문의 「없음·문서만」은 10/12 작성 당시 표현이며, 현재 전체 기능의 부재나 완료를 판정하지 않습니다.

> 근거는 모노 무대 · 보드 연출 기획서(71 · 112 이동 경로 기믹 · 112 이동 무대 아트 레시피 · 281–284) · 모노 UI 연출 허브(`ui-fx-hub.html`) · 모노 연출 표 · 7007 제안서 · 현중 결정만. 값은 「(이식) 임시 시안」과 근거를 같이 적는다.

> 절 표기(현중 10/12): **(이식)** 그 줄의 구조나 방법이 모노에 있음 · **(신규)** 케이팝 이름 · 값 · 현중 결정만. 제목에 표기가 없는 절은 줄 끝마다 단다. 목차 · 간략 · 문서 정보는 표기하지 않음.

## 현재 읽기 범위

- 무대 API는 있으나 주사위·이동·착지의 동시 정지와 메인 보드의 실제 소비는 미검수입니다.
- 설정은 기본값에서 CSV를 요청하고 실패하면 기존값을 유지합니다. 문서 임시값과 코드 기본값의 차이는 남아 있으며 실제 로드값은 미검수입니다.
- family 표 요청은 캐시 준비 코드로 확인했습니다. 재질·색·폴리시가 실제 화면에 적용되는지는 미확인입니다.
- 허브 다섯 화면은 명세이며 포트 공통 클립과 구분합니다. 기획된 허브의 현재 진입 주소는 확인한 경로 범위에서 미확인입니다.
- 툴 임시 저장·게임용 reader·POST 저장 helper는 코드로 구분됩니다. 실제 서버 파일쓰기·검증·저장 성공은 미검수입니다.
- 표의 상대경로·csvRoot·번들 공급은 실제 페이지 설정과 함께 확인해야 하며, 현재 로드 성공 여부는 미확인입니다.

## 간략

**머리표** 시스템 기획 · S06b · 보드 연출 계승 · 모노 71 · 112 × 2 · 281–284 + UI 연출 허브 이식

**제목** 보드 연출 계승 — 주사위가 멈추고, 말이 뛰고, 칸에 내려앉는 0.1초까지

**훅** 주사위가 「쿵」 눌렸다 튀고, 카메라가 말을 따라가다 도착 칸으로 다가가면, 그 칸의 건물이 옆에서 미끄러져 들어와 딱 멈춘다.

**두 줄 요약**
- 보드 연출 = **주사위 → 이동 → 착지** 세 박자. 박자 값은 표 하나(`ui_fx_boardcam`), 칸 겉모습은 무리별 재질(`ui_fx_boardcam_family`), 멈춤 반응은 CSS만(`ui_fx_board_polish`).
- 연출 값은 **UI 연출 허브**에서 바로 돌려 보고 표에 저장한다(카메라 · 창 · 결과 · 릴 · 휠 다섯 화면).

```mermaid
flowchart LR
  D[주사위<br/>diceMs · 멈춤 반응] --> H[이동<br/>stepMs · 카메라 따라감]
  H --> L[착지<br/>landZoom · 칸 그림 들어옴]
  L --> C[칸 결과 창<br/>창 · 결과 · 릴 · 휠]
  T[UI 연출 허브] -.표 값.-> D
  T -.-> H
  T -.-> L
  T -.-> C
```

1. **굴린다** — 주사위가 돌다 멈출 때 눌림 → 튐 → 퍼지는 고리 → 빛 쓸림.
2. **간다** — 카메라가 말을 따라가며 한 칸씩(처음엔 천천히 · 뒤로 갈수록 빨리).
3. **내린다** — 도착 칸으로 확대 · 그 칸 그림이 옆에서 들어와 착지 순간 함께 멈춘다.
4. **고친다** — 허브에서 손잡이를 돌려 보고 「표에 저장」.

| 왜 지금 | 이게 핵심 | 이게 아닌 것 |
|---|---|---|
| S06a에 연출 표 이름과 칸 목록만 있고 박자 규칙 · 값 · 확인 툴이 없다(2차 4단계 · 제나 · 이스라트 12:2x) | 착지 순간 세 가지가 **한 번에** 멈춘다 · 연출은 CSS 변형 · 투명도만 · 값은 표 하나가 진실 · 허브 = 표를 고치는 곳 | 전투 연출(대결 컷 · 전투 끝 컷 · 전투 칸 재질) · 판이 바뀌는 무대 교체 · 새 화면 설계 |
