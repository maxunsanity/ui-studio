# ① GPT 리서치 보고서 — 2D 방치형 아이돌 기획사 경영 시뮬레이션 재미 고도화

**성격:** GPT 딥리서치. 첨부 기획서를 진단하고 재미를 높이는 방안 제안. 논문·경쟁작·법령·Unity 문서 23개 인용. **수치는 모두 「설계 예시값·가안」이라고 밝힘.**

## ①-1 핵심 요약 (Executive Summary)

- 기획서는 60일 시즌 · 40칸 도시 보드 · 8 랜드마크 · 180장 카드북 · 20종 수호정령 · 명성과 그림자를 **이미 갖췄다.**
- 그런데 **「아이돌에게 돈을 쓰고 → 팬덤이 성장하고 → 팬덤이 행동해 → 더 큰 돈과 명성」** 이라는 경영 인과가 화면·경제에서 안 드러난다.
- 재미를 가를 네 영역 = 기획서 스스로 미해결로 둔 것: **랜드마크 비용·수익 곡선 · 60일 전부 리셋의 장기 리텐션 · 다른 도시 8 랜드마크 확장 · 수치 밸런스.**
- 핵심 권고 세 가지
  1. **상단 약 1/3 = 살아 움직이는 기획사+팬덤 디오라마**, 하단 2/3 = 경영 의사결정 UI.
  2. **팬을 숫자가 아니라 「경제 에이전트」로** — 스트리밍·구매·응원·확산·방어를 하는 존재로 시각화. 근거: K-pop 팬은 프로슈머(정보 획득·확산·생산)라는 국내 연구.
  3. 차별점은 「아이돌 육성」이 아니라 **「팬덤을 관찰하고 키우는 경영 시뮬레이션」.**
- 경제: 연습실·녹음실·안무실·MV 세트장 = **비용/투자 시설**, 방송국 = **노출+혼합 수익**, 팬샵·콘서트홀·아레나 = **직접 수익**. 비용이 먼저 빠지고 팬 행동을 거쳐 수익이 돌아오는 모습을 보여 줄 것.
- 리셋: 「시즌 끝 전부 초기화」 그대로보다 **순수 리셋 vs 소규모 영구 레거시**를 A/B 테스트. (AdVenture Capitalist의 Angel Investor 예)

## ①-2 기획서 진단과 재미 구조 재정의

- 시스템 수는 부족하지 않다 (6도시 · 40칸 · 8 랜드마크 5레벨 · 명성 0~100 · 그림자 · 봉합전 · 수호정령 공명·연결 · 20덱×9장 · 60일 · 12화 이벤트).
- 문제: **각각은 재미있을 수 있지만 하나의 경제 이야기로 묶는 접착제가 없다.**
- 새 코어 루프 제안:

> **투자 → 아이돌 활동 → 콘텐츠 발생 → 팬덤 반응 → 팬 행동 → 수익/명성 → 더 큰 투자 → 리스크 발생 → 팬덤과 정령으로 방어**

- 주사위는 없앨 필요 없음. 다만 **「게임의 목적」이 아니라 「기획사 시뮬레이션을 움직이는 스케줄 엔진」** 으로 보이게. 예: 방송 칸 → 명성+7이 뜨는 게 아니라, 아이돌이 방송국으로 이동 → 팬이 휴대폰을 꺼냄 → SNS 버블 → 팬샵·음원 수익이 뒤따라 뜀.
- idle 장르는 「playing → planning」으로 옮겨 가는 장르 (66개 idle 게임 분석 연구 · Neko Atsume 연구). → 만렙 판타지 = **「CEO처럼 정책을 정하면 기획사가 자동으로 살아 움직이는 것」.**
- 2025 콘진원 해외 이용자 조사: 감성 요소(그래픽·캐릭터·서사)도 중요하지만 개선 요구 1순위는 **성장·강화 구조**. → **비용 지출의 이유와 결과가 눈에 보이는 것**이 더 중요.

## ①-3 화면 구성 · 팬덤 표현 · UI/UX

- 「게임 화면은 상단 약 1/3」 규칙은 이 장르에 **유리**하다. idle 경영의 핵심 = 내가 만든 시스템이 알아서 도는 걸 **관찰하는 만족감**. 상단 33% = 기획사 생태계의 CCTV/디오라마.
- 권장 화면 (세로):

```
상단 약 33%   LIVE AGENCY / FANDOM DIORAMA
              연습실 → 녹음실 → 방송국 → 팬샵 · 아이돌 이동 · 팬 이동 · 응원봉
              -320C  +팬 1.2K  +780C · [컴백!] [SNS 급상승] [팬덤쉴드]
지표 줄       현금 125K +4.3K/분 · 팬 3.42M · 명성 78 · 순익 +34%
하단          오늘의 스케줄 / 자동 운영 정책 — 성장 · 제작 · 홍보 · 팬덤 · 투어
              이번 정산: 수익 +18.6K / 지출 -12.4K / 순이익 +6.2K
탭            [회사] [아이돌] [보드] [카드] [투어]
```

- **상단에서는 숫자보다 원인과 결과가 보여야 한다.** 녹음실 위 -180 → 방송국 앞 팬 몰림 +240 → 팬샵 계산대 +350 → 콘서트홀 +명성 12 순차 팝업. 「왜 돈을 벌었는지」를 엑셀 없이 이해.

### 만렙 팬덤을 「군집 행동」으로

- 팬 행동 4단계
  - **유입 팬** — 전광판 쳐다봄, 버스킹 주변 멈춤, 휴대폰 촬영
  - **활동 팬** — 영상 공유, 스트리밍, 방송국 앞 집결
  - **코어 팬** — 팬샵 구매, 팬미팅 대기, 투표, 응원봉 동기화
  - **핵심 팬덤** — 콘서트 티켓, 대규모 단체 응원, 팬 프로젝트, 글로벌 번역·확산, 악플/스캔들 시 **팬덤 쉴드**
- **데이터상 팬 수와 화면상 팬 개체 수를 분리.** 렌더링 3층:
  - 가까이 **Hero Fans 20~30명** — 의상·응원봉·행동 개별
  - 중간 **Crowd Cluster 40~80개** — 한 군집 = 수십~수천 명
  - 멀리·객석 — **응원봉 웨이브·실루엣·파티클·깃발·휴대폰 플래시**
- 팬 3천 → 300만이 되어도 캐릭터가 1,000배 되는 게 아니라 **군집 밀도·행동 종류·응원봉 면적·파티클·줄 길이·팬샵 회전율**이 는다.
- 만렙 연출 예: 팬샵 여러 줄 대기열·쇼핑백·품절 팻말·재입고 트럭 / 방송국 출근길 촬영·플래카드 / 콘서트홀 응원봉이 멤버 감정색으로 갈렸다 후렴에서 한 웨이브로 / SNS 이벤트 시 말풍선이 군집 사이로 전염 + 서울→오사카→파리→뉴욕 확산선 / 스캔들 시 일부 팬 회색 이탈, 코어 팬이 하트·쉴드로 방어.
- 참고작: K-Pop Academy(아이돌 생활 공간 상시 표시) · Monthly Entertainment(데뷔·수익·팬·월드투어·앨범). 차별점 = **팬덤 집단 반응까지 동시에 보이는 화면.**

### 12초 마이크로 시퀀스 (원문 도식)

```
[루프 · 12초 시퀀스]
게임 시계 → 기획사 AI : 다음 스케줄 실행
기획사 AI → 경제 : 제작비·운영비 선차출            → UI : 비용 팝업
기획사 AI → 아이돌 : 연습/녹음/방송/공연 배정
아이돌 → 건물/스태프 : 활동 수행
건물 → 팬덤 군집 : 콘텐츠·노출·무대 발생
팬덤 군집 : 시청 → 공유 → 응원 → 구매
팬덤 군집 → 경제 : 굿즈·공연·음원·광고 수익      → UI : +수익 / +팬 / +명성
  (명성 상승으로 그림자 조건 충족 시)
  경제 → 팬덤 : 악플·역공명 발생 · 팬덤 → 경제 : 쉴드 소비 → UI : 방어 또는 손실
[5회 루프 후 60초 정산] → UI : 총수익 − 총지출 = 순이익
```

- 핵심: 팬은 돈 만드는 장식물이 아니라 **아이돌 콘텐츠를 경제 가치로 바꾸는 중간 단계.**
- 메인 화면 상시 지표는 **현금 · 순이익/분 · 활성 팬 · 명성** 넷이면 충분. 카드·정령·쉴드·주사위·토큰·품질은 이벤트 때만. (2025 이용자 조사: 이탈 1위 = 시간 부족 → 2~3분만 열어도 상태를 알아야)

## ①-4 경제 모델 · 건물 · 반복 시퀀스 · 밸런싱

- 가장 큰 문제: **모든 랜드마크가 방치 수익 합산 대상처럼 쓰여 있다.** 연습실·안무실·MV 세트장이 돈을 찍어 내면 경영 감각이 약해짐 → 비용 시설 / 수익 시설 분리.

### 건물 8종 (가정값 · 단위 C · 정산 60초)

| 건물 | 역할 | Lv1 예시 | 시퀀스 효과 | 성장 목적 |
|------|------|----------|------------|----------|
| 연습실 | **비용 센터** | -120C | 훈련 | 능력치·공연 품질 ↑ |
| 녹음실 | 투자+후속 수익 | 제작 시 -180C | 곡 제작 | 완성곡이 이후 로열티 |
| 안무실 | **비용 센터** | -140C | 퍼포먼스 훈련 | 다음 무대 효율 +6% 가안 |
| MV 세트장 | **고비용 투자** | -320C | MV 공개 | 팬 유입·컴백 버프 |
| 방송국 | 혼합 | +260 / -90C | 방송 출연 | 순 +170C + 명성·신규 팬 |
| 팬샵 | **직접 수익** | +360 / -90C | 굿즈 구매 | 활성 팬에 비례 |
| 콘서트홀 | 이벤트 수익 | +900 / -420C | 콘서트 | 티켓·MD·명성 + 던전 슬롯 |
| 아레나 | 고위험 고수익 | +2,200 / -1,300C | 대형 공연 | 만렙 현금 싱크 + 팬 폭증 |

- 생기는 선택: 연습실 업 = 당장 돈 ↓ 공연 수익 ↑ / MV 투자 = 몇 사이클 현금 나쁨, 팬 증가율 ↑ / 팬샵 = 안전 현금 / 아레나 = 명성·팬덤 충분할 때만 이득.

### 건물 밖 경제 항목

| 분류 | 수익 | 지출 |
|------|------|------|
| 음악 | 음원/앨범 로열티 | 작곡·녹음·믹싱·마스터링 |
| 방송/홍보 | 출연료·광고·스폰서 | 스타일링·PR·교통·홍보비 |
| 팬덤 | 굿즈·팬미팅 | MD 생산·팬 이벤트 운영 |
| 공연 | 티켓·현장 MD·투어 | 대관·세션·무대·운송 |
| 아이돌 | 광고 계약·브랜드 협업 | 숙소·식비·트레이닝·회복 |
| 회사 | 투자·파트너 보너스 | 직원 급여·사옥 유지 |
| 리스크 | 보험/쉴드 효과 | 스캔들·악플·일정 취소·역공명 |
| 시즌 | 패스/이벤트 보상 | 시즌 이벤트 운영비·보스 대응 |

### 식 (설계 제안)

- 수익 = (Σ 건물수익) × (1 + 명성/100) × 정령배율 × 팬수요배율 + 이벤트수익
- 기존 식은 유지 가능. 단 **수익 시설만 직접 수익, 비용 시설은 수익 시설의 계수를 강화**하도록.
- 팬수요배율 = min(2.2, 1 + 0.12·ln(1 + 활성팬/1000)) — 팬 10배 → 굿즈 10배가 되면 숫자 폭발하므로 완만하게.
- 지출 = 고정운영비 + 아이돌/스태프비 + 콘텐츠제작비 + 마케팅비 + 이벤트비 + 기대리스크비 · 현금(t+1) = 현금 + 수익 − 지출
- **공식을 숨기지 말고 매 정산 요약:** 「방송 +3.8K / 팬샵 +4.2K / 공연 +6.5K / 기타 +4.1K = +18.6K · 훈련 -2.1K / 제작 -3.6K / 운영 -2.5K / 홍보·리스크 -4.2K = -12.4K · 순이익 +6.2K」

### 3단계 경제 예시 (가안)

| 단계 | 상태 | 수익 | 지출 | 순이익 | ROI | 의도 |
|------|------|-----:|-----:|------:|----:|------|
| 초기 | 1인 · 명성 20~30 · 서울 초반 | 1,450C | 1,100C | +350C | 31.8% | 빠듯, 선택의 의미 큼 |
| 중기 | 3~4인 · 명성 60~80 · 3~4도시 | 18,600C | 12,400C | +6,200C | 50.0% | 자동화·팬덤 시너지 체감 |
| 만렙 | 5인 · 명성 90+ · 6도시 · Lv5 | 235,000C | 155,000C | +80,000C | 51.6% | 폭발적이나 비용도 큼 |

- 초기=1로 보면 수익 12.8배 → 162.1배, 지출 11.3배 → 140.9배, 순이익 17.7배 → 228.6배 (원문 그래프).
- **만렙에선 지출 애니메이션도 더 화려하고 잦게** — 5명이 다른 스케줄, MV·월드투어·콘서트·마케팅팀·스타일리스트·경호·운송이 동시에 돈을 씀 = 「대형 기획사」 느낌.
- 업그레이드 곡선: 비용(L) = Base × 2.1^(L−1) · 효과(L) = Base × 1.65^(L−1). 비용 시설 ROI는 연결된 매출 시설을 통해 → **생산 체인의 병목 찾기**가 재미.
- 주사위 확률은 유지하되 도착 운이 성장 병목이 되지 않게: 랜덤 = **속도를 흔드는 요소**, 필수 진행은 **천장형 누적 보장** (예: 방송국 8회 지나치면 다음 2회 안 방송 출연 보장 · ★5 미획득 누적 포인트로 선택권).

## ①-5 성장 · 보상 · 리텐션 · 자동화 · 이벤트

- 성장 3층: **마이크로**(12초 즉시 보상) · **메조**(분~하루: 랜드마크 업·스케줄·카드 세트·정령 연결 최적화) · **매크로**(도시 해금·5인 완성·60일 피날레·명예의 전당).
- 기획서 일정(5일마다 1화 · 20일 봉합전 · 25일 데뷔 · 30~50일 합류 · 55일 도쿄 · 56~60일 피날레)은 「해금 일정」에 가깝다 → **구간마다 경영 질문 자체를 바꿀 것.**

| 구간 | 경영 질문 | 대표 이벤트 |
|------|----------|------------|
| 1~10일 | 돈이 부족한데 무엇부터 투자할까? | 첫 오디션·버스킹·첫 팬레터 |
| 11~20일 | 훈련과 데뷔 중 무엇을 우선할까? | 데뷔 준비·첫 그림자 |
| 21~30일 | 명성을 올리면 위험도 올라가는데 밀어붙일까? | 방송·봉합전·첫 컴백 |
| 31~40일 | 여러 멤버와 건물을 어떻게 자동화할까? | 부산·투어·팬덤 세분화 |
| 41~50일 | 글로벌 확장에 얼마나 재투자할까? | 파리·뉴욕·대형 팬 프로젝트 |
| 51~60일 | 최대한 벌 것인가, 시즌 순위를 노릴 것인가? | 도쿄·돔·전 서버 피날레 |

- **자동화 = 회사 조직이 생기는 과정.** 초기 직접 스케줄 → 중기 매니저가 반복 스케줄 → 후반 정책 프리셋: **성장 우선 · 컴백 우선 · 현금 우선 · 월드투어 · 회복 우선.** 자동화는 의사결정이 아니라 **반복 노동만** 없앤다 (idle 연구: 재미는 최적화·자율성).
- 이벤트는 보상량만 다른 게 아니라 **경제 규칙을 잠시 비틀 것:**
  - 컴백 주간 — 제작비 +50%, 팬 유입 크게 ↑
  - 팬 프로젝트 — 팬이 광고판·생일카페·응원 이벤트를 **자발적으로** 엶 → 명성 ↑, 관리 안 하면 팬덤 파벌 갈등
  - 월드투어 — 티켓 ↑, 항공·운송·컨디션 비용 급증
  - 스캔들 위기 — 광고·방송 ↓, PR 인력·팬덤 쉴드 중요
  - 수호정령 공명 — 돈을 포기하고 멤버를 던전에 배치 → 장기 전투 효율
- 팬덤 이벤트 = 개발사가 보상 주는 게 아니라 **팬이 스스로 시작하고 플레이어가 대응** — 일반 타이쿤과의 가장 뚜렷한 차별점.

### 소프트 레거시 (반드시 테스트)

- 전부 리셋은 500년 환생 서사와 맞지만 60일 경제를 다 잃는 위험.
- **선택형 미세 레거시 — 시즌 끝에 하나만 고름:** 레거시 고문(스태프 1명, 분야 +3%) · 팬클럽 유산(첫 5일 팬 유입 +5%) · 기념 랜드마크 스킨 · 카드 기억 조각(다음 시즌 같은 덱 ★1 1장 보장).
- 무한 누적 금지, **다음 시즌에만.** 핵심은 숫자가 아니라 「지난 시즌이 완전히 사라지지 않았다」는 감정.
- 소프트런치 A군(기록만) vs B군(기록 + 레거시 1슬롯). KPI는 결제가 아니라 **「다시 새 아이돌을 키울 의향」** 먼저 — 시즌 재참여율 · 종료 후 72시간 복귀율 · 다음 시즌 첫 7일 플레이 일수.

| 경쟁작 | 핵심 | 배울 점 | 차별점 |

- 결론: **K-Pop Academy의 「살아 있는 캐릭터」 + Idol Manager의 「경제 리스크」 + AdVenture Capitalist의 「자동화 성장」**, 그 사이를 팬덤으로 연결. 「좋은 일만 생기고 숫자만 오른다」는 피할 것.
- 수익화 의존 순서: **코스메틱 > 시즌패스 > 편의성 > 선택형 광고 > 랜덤 상품.**
  - 코스메틱: 아이돌 의상·사옥 외관·도시 스킨·응원봉·팬샵 인테리어·무대·정령 스킨 (상단 디오라마에 반복 노출)
  - 시즌패스: 현금·주사위보다 한정 무대·의상·응원 패턴·명예의 전당 장식
  - 편의성: 광고 제거·자동 정산·프리셋·스케줄 슬롯 → 「자동 클릭」 대신 **매니저 계약·자동 스케줄러·CEO 플래너**로 포장
  - 광고: 보상형만 (오프라인 30분 ×2, 던전 15분 단축, 스케줄 재선택 1회, 앙코르 +20%)
  - **유료 랜덤 카드팩은 핵심 매출원 X** — 리셋과 충돌, 확률형 아이템 표시 의무(게임산업법 시행령 2026.3 시행)
- 가격 테스트 가안: 광고 제거 ₩8,800~12,000 · 60일 시즌패스 ₩9,900~14,900 · 사옥/콘서트 코스메틱 ₩3,900~8,900 · 응원봉·팬덤 스킨 ₩2,500~5,900 · 스타터 ₩4,900~7,900.
- **팬 수·명성·순위를 직접 팔지 말 것** — 「좋은 경영 → 좋은 활동 → 팬덤 성장」이 무너짐.

## ①-7 기술 · 아트

- 엔진 미지정, 예시 Unity 6. **팬 100만 명을 100만 객체로 만들지 말 것.**

- Sprite Atlas(기능/도시 단위) · SortingGroup(파츠 캐릭터 정렬) · Addressables(도시·시즌 단위 다운로드).
- 기획서의 「시즌2부터 멤버 덱 45장만 신규, 135장 공용·리컬러」 원칙을 **월드 스프라이트에도 확장.**
- 팬덤 컬러: 사랑·용기·희망·공감·자유 5색이 객석을 나눠 점유 → 「천음」 순간 한 파동으로 합쳐짐 = 시스템 성장과 세계관 클라이맥스를 같은 시각 언어로.

## ②-1 설계 원칙 — 완성은 보상이 아니라 열쇠

- 분업 의도: 아이돌 던전 vs 도깨비 던전 분리 = 「트랙 A·B 분리」의 게임 버전. **정령은 도깨비 던전에서, 아이돌은 축제에서 크고, 합쳐지는 곳은 축제 본무대 하나.**
- 전부 파견형: 무게는 조작이 아니라 **「누구를 어디에 보내나」.** 하루 2시간 = 회수→재편성→재파견 3~4회. 파견 시간 차등(버스킹 짧게, 축제·거울 길게)으로 로그인 리듬.
- 버스킹 던전 = 새 카드군 주 공급처, 1인씩 보내 팬덤 색 구성 → 축제 팬덤 선택과 직결. 결과가 좋을수록 명성 ↑ → 도깨비 던전 난도·보상 ↑ (「명성=유인」).
- 시즌 1 = 확정 2종 + 버스킹 = 3종. 회상·도시·거울은 시즌 2~3.

# ③ 팬덤 정원 (Fandom Garden) 시스템 메모 v0.1

**성격:** 게임 시스템 제안 메모. Story Beginz · 어우동 · 2026-09-26 · v0.1 가안. **위상 명시:** 화수·각성·공명 시점·멤버 정체성은 정본 화수표(v5정합) 불변, 이 메모는 **팬덤 수치의 시각화·성장 규칙만.** 충돌 시 설정집 v5 > 정합 문서 > 정본 화수표 > 이 메모.

## ③-0 한 줄

팬 수를 「10,000명」 대신 **씨앗 → 모종 → 새싹 → 봉오리 → 개화 → 희귀 개화**로 보여 주고, 팬 행동(팬레터·팬샵·팬미팅·방송) = 물·비료·햇빛, 악플·스캔들·안티 = 시듦·병충해·가시덩굴. 여기에 IP 고유 **봉합(솔기)** 을 얹어 「떠났다 돌아온 팬」에 서사적 가치.

**원칙: 팬 = 꽃이 아니라 팬덤의 성장 상태 = 꽃. 팬은 끝까지 사람, 꽃은 오버레이.**

## ③-1 왜 이 IP에 맞나

- 사상 — 천음 = 잇는 소리, 수호정령 = 봉합의 산물 → 팬덤도 「이어져서 자라는 것」.
- 토큰 — 5감정색이 멤버별로 고정 → 토큰 추가 없이 멤버별 꽃 분화.
- 서사 — 명성 양면성(유명 ↑ = 위험 ↑ / 구원 ↑) · S2 안티-팬덤 역공명 · S3 「전 인류 합창」 = 정원 번성 · 가시덩굴 · 전 세계 만개.
- 흡수 — 팬레터·팬샵·팬미팅·팬덤 쉴드·팬덤 덱을 **정원 언어 하나로.**

## ③-2 성장 단계

| 단계 | 정의 | 트리거 | UI |
|------|------|--------|-----|
| 씨앗 | 막 유입된 관심층 | 버스킹·오디션·방송 노출·숏폼 바이럴 | 작은 점, 무색 |
| 모종 | 팬이 되기 시작 | 콘텐츠 1~2회, SNS 팔로우, 첫 팬레터 | 연한 줄기 |
| 새싹 | 활성 팬 | 스트리밍·응원 참여 | 멤버색 잎 1장 |
| 봉오리 | 소비 팬 | 굿즈·팬샵, 팬미팅 | 멤버색 봉오리 |
| 개화 | 핵심·충성 팬 | 쉴드 생성, 악플 방어, 앨범·콘서트 매출 | 만개, 발광 |
| 희귀 개화 / 꽃다발 | 전설 팬·팬클럽 리더·글로벌 거점 | 시즌 한정, 지역 커뮤니티 | 금테·보라 아우라 |

- 표시 예: 씨앗 2,300 / 모종 1,100 / 새싹 800 / 봉오리 500 / 개화 220 / 희귀 12 — **총량이 아니라 분포** → 「어디가 막혔는지」 읽힘.

## ③-3 멤버별 꽃 (가안 · 상표·문화권 검토 후 확정)

| 멤버 | 감정/색 | 꽃 | 비고 |

| 논개 | 용기 🔥 flame | 동백, 붉은 튤립 | 추운 데서 피는 꽃 = 두려움 속 용기 |
| 이날치 | 희망 🌱 sprout | 해바라기, 민들레 | 꺼진 자리에서도 돋는 결 (잿불이 사상) |
| 신사임당 | 공감 🌊 wave | 수국, 물망초, 연꽃 | 물가 군락, 서로 기대어 핌 |
| 황진이 | 자유 ⚡ bolt | 엉겅퀴, 억새, 들풀 | 기존안(난초·코스모스)에서 조정. 속성 bolt 단일(땅 아님) |

## ③-4 봉합 문법 — 이 IP만의 비틀기

- 일반 식물 메타포면 다른 육성 게임과 구분 안 됨 → 우동 고유값 **「솔기」**: 끊긴 상처 → 아문 봉합.
- **꽃 = 장식이 아니라 팬 행동의 UI 언어.**
  - 좋은 상태: **물**(콘텐츠·SNS·라이브·소통) · **햇빛**(무대·방송·명성) · **비료**(굿즈·이벤트·팬미팅·시즌패스) · **개화**(매출·쉴드·바이럴)
  - 나쁜 상태: **시듦**(소통 부족·휴식 과다·공백기) · **병충해**(악플·스캔들·안티 침투) · **잡초화**(무관심층·이탈) · **가시덩굴화**(안티팬덤·팬덤 전쟁)
- **4.1 시듦과 회복 = 상처와 솔기** — 시든 꽃은 채도 죽고 wd-ink-900 다크. 회복하면 줄기에 **보라(wd-dokkaebi-700) 솔기**. **떠났다 돌아온 팬이 새 팬보다 귀함** (「흉터가 명예로운 흔적」 — 흉이 사상). 솔기 팬 = 이탈 저항 ↑, 쉴드 기여 ↑, 별도 집계.
- **4.2 팬덤 쉴드 = 보호 꽃** — 개화 팬 N명 이상이면 화단 가장자리에 보호 꽃(멤버색 + 보라 아우라). 악플·스캔들 때 **보호 꽃이 먼저 소모**, 빈 자리는 「지켜준 흔적」 솔기. **보호 꽃 수 = 쉴드 내구도** (게이지 대신 꽃 개수).
- **4.3 안티팬덤 = 가시덩굴 (색 분리 필수)** — 무관심 = 잡초, 이탈 = 시듦, 안티 = 가시덩굴. 가시덩굴 색은 보라와 **반드시 분리** → 도감 §5 미해결 「보스 한기색(차단·격리)」과 같은 토큰, **청록/강철 회청** 권장. S2 팬덤 전쟁 = 두 정원 경계에서 가시덩굴 침투.

## ③-5 성장 재료 (기존 시스템 매핑)

| 기존 시스템 | 정원 언어 | 효과 |
|------------|----------|------|
| 팬레터·SNS·라이브·팬소통 | 물 | 씨앗→모종, 모종→새싹 ↑, 시듦 방지 |
| 방송·무대·명성 | 햇빛 | 씨앗 유입 ↑ (명성 ↑ = 가시덩굴 유입도 ↑, 양면성) |
| 굿즈·팬샵·시즌패스 | 비료 | 새싹→봉오리, 매출 |
| 팬미팅·팬사인회 | 개화 촉진제 | 봉오리→개화, 희귀 개화 확률 |
| 콘서트(해방전) | 만개 이벤트 | 화단 전체 동시 개화 + 보호 꽃 대량 |
| 휴식 과다·공백기 | 가뭄 | 전 단계 시듦 |
| 악플·스캔들 | 병충해 | 보호 꽃 소모 → 이후 개화 팬부터 시듦 |

## ③-6 화면

- **A 팬덤 정원 탭** — 멤버별 5 화단 + 중앙 센터 화단. 화단 크기 = 팬 총량, 색 밀도 = 개화율. 상단 지표 3: 씨앗 유입률 / 개화율 / 이탈률. 부지표: 솔기 팬 · 보호 꽃 · 가시덩굴 침투도.
- **B 팬 개체** — 작은 사람 실루엣 + 머리/어깨에 단계 아이콘. 충성 팬 = 꽃 배지, 솔기 팬 = 보라 스티치 테두리. 커뮤니티 = 실루엣 군집 + 꽃밭 바닥 레이어.
- **C 시즌 목표** — S1 12화 첫 천음 = 서울 정원 첫 만개 · S2 월드 투어 = 도시별 정원 개척, 도시마다 가시덩굴 종류 다름(사천간부 군단 색) · S3 전 인류 합창 = 지구 규모 만개(「팬덤 = 최종 무기」).

## ③-7 주의

- **사람이 사라지면 안 됨** — 실루엣이 꽃으로 완전히 바뀌면 S3 합창이 정원 가꾸기로 축소. 꽃은 항상 오버레이·바닥 레이어.
- **색 규칙 불변** — 멤버색 = 그 멤버 팬덤만 · 보라 = 봉합(회복·쉴드)만 · 안티 = 별도 한기색. 섞이면 도감·애니와 어긋남.
- **수치 노출** — 분포는 보여 주고 전환 확률은 숨김. 정원은 「읽는」 화면이지 「계산하는」 화면이 아님.

## ③-8 미해결

- 보스 한기색 토큰 신설 (가시덩굴과 공유) · 꽃 종류 확정(문화권·상표) · 단계별 전환 수치·재료 효과 밸런스 시트(별도 xlsx) · 참조 `kpop monstarz 게임 디자인 통합 v1.4.html`이 프로젝트 지식에 없음.

→ 우리 기획과: 「팬덤을 숫자가 아니라 단계 분포로」는 우리 **038 팬덤 스테이지(제로돌→서동요 5단)** · **067 서사 조각**과 같은 자리. 「팬 행동 = 성장 재료」는 02에서 말한 **팬덤 콘텐츠 ②(팬덤이 알아서 하는 덕질)** 와 맞닿는다. ①의 팬 4단계(유입·활동·코어·핵심)와 ③의 6단계는 **같은 생각의 두 버전**.
