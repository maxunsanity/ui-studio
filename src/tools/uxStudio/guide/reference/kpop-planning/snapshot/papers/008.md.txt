# 008 · 같다름 — 사다리 보드화

> status: draft · [021](./021_보드에_사다리_얹기.md) 본문 쓰기 **전** 준비. 모노카피바라의 **보드 시즌·파워/빌드 성장** vs kpopmonsters의 **직함 사다리 × 보드 드롭**만 비교.
> 전제: [002](./002_모노카피바라_같은점_다른점.md) · [004](./004_보드와_미션.md) · [007](./007_같다름_성장사다리.md) · [017](./017_미션_성장단계_배치.md) · [020](./020_성장사다리_빠순이에서_사장.md). 017=미션 호흡, 020=직함 — **겹쳐 두고 합치지 않음**.

> 📌 **축은 살아 있는데 Board1과 아직 안 붙었다 (2026-09-17 확인).**
> 현행 보드(40칸)에 이 축이 어떻게 얹히는지는 미정. 기준은 [045](./045_현행Board1_핸드오프.md).

한 줄: **고정 판 위에서 시즌이 바뀌며 “내 편이 커지는” 손맛은 같고, 커지는 것이 칸 파워가 아니라 직함이며·판 자체가 챕터마다 새로 떨어지는 점이 다르다.**

---

## 같은 점

| 감각 | 모노카피바라 | 사다리를 보드에 얹을 때도 |
|------|--------------|---------------------------|
| 시즌이 판 기분을 바꿈 | 보드 시즌·이벤트로 콘텐츠·파워가 바뀜 | 보드가 생성될 때마다 바닥은 두고 시즌 레이어가 바뀜 |
| 고정 뼈대 위에서 빌드 | 칸 수·판 골격은 익숙, 위에 콘텐츠 | **고정 칸 수**(수치는 나중에). 안에만 갈아끼움 |
| 도착은 운 | 주사위로 어디에 떨어질지 | 같음. 유저는 **시즌 빌드 방향만** 고름 |
| 가벼운 날 / 무거운 날 | 칸마다 무게 | ○ 일상 · ● 티나는 순간·게이트 |
| 여러 장을 돌아 강해짐 | 시즌 런으로 파워 누적 | 보드를 클리어·생존하며 **티나는 순간** 스탬프 → 다음 직함 |

→ 플레이어가 이미 아는 **굴리고 · 시즌 타고 · 점점 커지는** 버릇은 유지한다.

---

## 다른 점 (이번 작업의 얼굴)

| | 모노카피바라 | kpopmonsters 사다리×보드 |
|---|--------------|--------------------------|
| 뭐가 커지나 | 캐릭터 **파워·시즌 진행·빌드 스탯** | **팬의 직함**(020 1~12). 스탯 바가 아니라 자리·돈의 성격·권한 |
| 같은 칸의 의미 | 시즌이 바뀌어도 “그 칸 콘텐츠”가 본체 | **직함이 바뀌면 같은 타일이 다른 하루가 됨** (출석: stage 2=영웅담, stage 8=팀 KPI) |
| 판의 수명 | 익숙한 **고정 보드** 위에서 시즌·파워가 쌓임 | 보드는 **챕터 단위로 드롭**. 「○○○ 보드가 생성되었습니다」 |
| 성장의 보이는 방식 | 파워/빌드가 판 위에서 강해짐 | **이중 미터** — 축A 아이돌 호흡(017) · 축B 내 직함(020). 한 바로 합치지 않음 |
| 유저가 고르는 것 | 보드 위 선택·빌드가 더 넓을 수 있음 | 로비/프리보드에서 **덕질 시즌 런 방향**(총대/미디어/현장…)만. 낙점은 주사위 |
| 승급 | 시즌 보스·파워 문턱 | “사장 칸” 한 번에 착지 ❌ → 보드 생존 + 티나는 순간 스탬프 → **다음 보드 드롭·직함 컷씬** |
| 상대 | 보드·시즌 콘텐츠 | 같이 크는 **아이돌**. 팬만 레벨업하면 공허 |

모노카피는 “같은 판에서 내가 세진다”.  
여기는 “**직함이 바뀌면 같은 칸이 다시 쓰이고**, 챕터가 바뀌면 **판 자체가 새로 떨어진다**”.

---

## 이중 미터 (합치지 말 것)

```
축A  아이돌 호흡 (017)     신인초 → 중기 → 성장후 → 사장근처
축B  내 직함 (020)         1 덕통사고 → … → 12 사장
         ↓
     같은 보드 칸 위에서 두 축이 겹쳐 보임
     (출석 ○ 하나에도 “아이돌이 작은가?” × “내 직함은?”)
```

- 아이돌 XP와 경력 XP를 **한 게이지로 합치면** 키우기 렌즈가 죽는다.
- 017은 보드 **미션 호흡**, 020은 **팬의 자리**, 덕력은 모노 번영도 숫자. 셋 합치지 않음 → [047](./047_덕력.md).

---

## 보드 드롭 vs 고정판 파워

| | 모노카피 감각 | 여기 |
|---|--------------|------|
| 판 | 오래 아는 한 장 위에서 시즌 | **한 보드 = 한 챕터**. 끝나면 다음 보드가 생성 |
| 안에 깔리는 것 | 시즌 콘텐츠·파워 재료 | **바닥** = 지금 020 단계의 ○ 매일 덕질 (010/011…) · **시즌** = 티나는 순간 / ● 게이트 / 아이돌 시대 이벤트 |
| 빌드 | 파워·시즌 빌드 | 시즌 방향만 — 분기 가중으로 칸이 기운다 (강제 루트 아님) |
