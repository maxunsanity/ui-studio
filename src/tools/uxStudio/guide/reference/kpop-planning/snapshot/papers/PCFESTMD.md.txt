# 월드 페스티벌 — 앨범 활동부터 최종 순위까지

**이 문서는** 앨범 발매·판매 활동부터 월드 페스티벌의 최종 순위 경쟁·시상까지 연결하는 현재 제안입니다.

**보는 법** [10장 제안 덱](./fest.html#slide-1) → [P207 쉬운 기획](/docs/planning/삼중AI_공용_20260929/산출/개발진행기획_v01/콘텐츠별_v03/월드페스티벌_핵심제안서.html#world-full-journey) → [P191 2차 상세](/docs/planning/삼중AI_공용_20260929/산출/기획서/산출_기획서_음원×페스티벌_v1_클로드.html#festival-phase2) 순서입니다.

**지금 상태** 현재 개발되지 않음, 진행 중 · 2차 기획만.1차 신청/음악 앱 구현과 새 투표·인기 재화·배틀·외부연동·시즌마무리 기획을 구분합니다. 운영 수치는 발란스 대기이고 제안은 검수 대기입니다.

## 1장 · 앨범 발매부터 월드 순위 경쟁까지

**앨범 발매·판매활동 → 앨범 차트 → 월드 신청 → 등록 로비 → 팬 투표·게임 인기 → 곡 배틀·내 무대 → 실시간 종합 순위 → 시상·다음 시즌**.

크루 가입과 시티투어는 선택이다. 월드 의무 진입 관문으로 추가하지 않는다. 판매·실제 음원 유통은 권리·정산 계약에 따르는 별도 운영이며 판매 실적을 출전 자격으로 자동 요구하지 않는다. 첫 장은 전체 순서를 이해시키는 정적 도해다.

## 2장 · 활동한 앨범 한 곡으로 월드 준비

게임 안 앨범 활동/START 정산과 실제 회사의 음원 판매·외부 유통을 구분한다. 앨범 차트는 기존 팬·성장·앨범 실적을 비교하는 무투표 이벤트다. 시티투어는 선택 활동이며 재화 급유·랩 수를 월드 G에 곧장 넣지 않는다.

같은 실행의 실제 released 곡 한 곡, 발매 고정 명단, 소유와 권한, 회차별 곡 사용 동의, 공식 기간을 검증한다. 월드는 시즌 9주차 7일이다. 시작일이 비어 있으므로 날짜·요일·가짜 카운트다운을 만들지 않는다. 제작·발매·성장·기존 정산을 우회하지 않는다.

## 3장 · 개인·크루 신청과 등록 로비

개인 출전자는 **개인 유저 명의**다. 아이돌 한 명의 솔로곡에 한정하지 않으며 솔로·유닛·팀곡을 모두 지원한다. 크루 소속 유저가 개인 명의로 신청한 곡도 개인 차트에 표시한다. 크루 출전은 현재 크루장 신청과 원소유자의 회차별 사용 동의를 갖춘 공유곡 한 곡이다. 크루원 개인곡 합산이 아니다.

기존 대회 → 한 화면 신청(곡·고정 명단·내용 확인) → 실제 성공 영수증/entryId → 등록 로비 경로를 유지한다. 같은 유형의 개인/크루 중복을 잠그고 최신 소유·동의·권한을 제출 직전 재검사한다. 로비는 같은 곡·회차·재생·순위를 연결하며 새 플레이어·새 신청 체계를 만들지 않는다.

## 4장 · 팬 투표와 SNS·외부 음악 성적

팬은 곡 발견 → 공식 앱/웹에서 곡·회차 선택 → 명시 확인 → 접수/반영 결과를 본다. 월드 기간 투표와 비동기 곡 선택을 기본안으로 검토한다. 특정 시각 참여에만 추가 표/배점을 주지 않는 방향이다.

YouTube·Instagram·TikTok 등은 공식 투표의 유입 경로다. 같은 게임 주계정과 표 예산·중복 경계를 사용하며 여러 SNS 연결로 표를 늘리지 않는다. 외부 Poll은 개별표·변경/취소·계정 매칭·API/권한이 확인되기 전 공식 수입 대기다. 조회·좋아요·댓글은 자동 표/인기 재화가 아니다.

멜론 등 음악 성적은 허용된 곡ID·기간·권역·출처·권한·전 후보 동등 공급이 있을 때만 A의 별도 하위항목으로 검토한다. API 문서의 존재와 게임 점수화 허용은 다르며 실제 연결/제휴를 완료했다고 쓰지 않는다. 자세한 공식 근거는 [외부 연결 상세](/docs/planning/삼중AI_공용_20260929/산출/기획서/산출_기획서_음원×페스티벌_v1_클로드.html#festival-phase2-external)를 따른다.

자기 곡 사람표·점수형 추천 제외 방향과 자기 곡 게임/인기 사용 가능을 구분한다. 자기 찜 보관 기능은 점수와 별개다.

## 5장 · 게임 인기와 개인 콘텐츠 12종

**내부 게임 검증 결과 → 인기 재화 획득 → 지정 앨범에 사용 → 인정 사용 기여 C**. 획득/잔액은 곡 점수가 아니다. 같은 결과의 직접 C와 사용 C를 이중 가산하지 않는다. 사용 영수증·차감·기여를 함께 처리하며 분할/일괄 사용이 부당한 점수 차이를 만들지 않게 정책을 정한다. 신규 인기 재화의 명칭·ID·경제·획득량·사용량·이월은 미정이며 원표 등록/실제 지급 기능은 없다.

| 분류 | 기획 가칭 | 원인·혜택 |
|---|---|---|
| 공통 4종 | 공연게임 대결, 스테이지 타이밍, 관객 호응 리듬, 콘셉트 카드 | 검증 G 또는 인기 획득→지정곡 사용→C |
| 개인 특화 6종 | 내 팀 원테이크, 댄스 브레이크, 팬콜/인터뷰, 팬캠 디렉팅, 세트리스트, 시티 앙코르 | 개인 명의의 팀/유닛도 지원. 혼자 선택하는 공연/인기 경로, 베스트 컷·개인 기록·발견 슬롯 혜택안 |
| 크루 특화 2종 | 파트 응원 릴레이, 현장 응원 큐 퍼즐 | 협동 경험. 개인보다 높은 상한/추가 표 없이 같은 C 예산 |

12종은 완성 게임 목록이 아니다. 같은 공식 슬롯의 대안으로 고르며 모든 종목을 매일 다 해야 하는 숙제 구조를 피한다. 개인/크루의 같은 최고점 접근을 목표로 하되 실제 플레이 시간·무료 기회·공개 매칭 대기를 함께 검수한다. 크루 규모·재가입·결제가 최고점/공식 기회를 추가하지 않게 한다.

크루 미션 청구 보상은 계속 `crew_currency` 한 종류다. 기본 게임의 인기 획득과 미션 청구를 구분하며 미션 청구가 인기 재화를 추가 발급하지 않는다. 인기 재화는 기존 크루재화·앨범 이벤트 재화의 이름/잔액을 바꾸거나 소급 환산하는 안이 아니다. 기존 P191의 새 개인 응원 화폐 미추가 방향과의 변경 관계는 최신 직접 요청에 따른 수정 제안으로 정본에서 명시한다.

## 6장 · 곡 선호 배틀과 직접 공연게임 대결

- **A 곡 선호 배틀:** 관객이 동등한 하이라이트의 배정 두 곡을 비교·선택/건너뛰기. 유효 표본 뒤 승무패/승점과 상대 보정을 산출하는 비동기 라운드안. 져도 탈락하지 않는다.
- **G 공연게임 대결:** 출전자가 전략·타이밍을 직접 조작한 별도 경기 결과. 관객 선호표를 G로 복사하지 않는다.

노출·상대 반복·최소 표본·같은 계정/이해관계·마감·재심을 검수한다. 휴식/매체 오류는 자동패가 아니다. 비교 선택수·승점·배틀 등수를 세 번 더하지 않고 인정 원본 한 경로만 최종에 반영한다. 승점·공식 경기 수·동점·보정 수치는 발란스 대기다.

## 7장 · 인기 기여 중심의 같은 곡 차트

모든 차트의 공통 출전 유형 필터는 **전체 / 개인 출전자 / 크루 출전자**다. 개인/크루는 entryMode이며 현재 소속이나 참여 아이돌 수로 바꾸지 않는다. 곡/회차/원본별 차트가 같은 최종 경쟁으로 이어진다.

| 축 | 인정 원본 |
|---|---|
| A 팬 평가 | 명시 팬표, 관객 곡 선호 배틀, 유효 추천/찜, 허용된 외부 음악 성적의 별도 하위항목 |
| B 실력 | 출전곡 고정 참여자 원단위 능력의 기준 시점 동결·참여 가중 평균 |
| G 공연게임 | 제한된 공식 슬롯의 실제 무대·조작 경기 성과 |
| C 게임 인기응원 | 게임에서 얻은 인기의 지정곡 인정 사용 기여. 획득/잔액/총공 버튼 클릭은 별도 점수 아님 |

최신 방향은 곡에 인정된 인기 기여를 주축으로 하고 추천·찜을 보조 평가로 두는 구조입니다. 위 A/B/G/C는 기존 시험 원본 분류로 보존하며 실력·공연게임·별도 투표의 포함 방식은 독립 가산 / 인기 획득 연결 / 참고 분리 가운데 결정 대기입니다. 급등은 별도 발견이고 등수를 우승 보너스로 다시 가산하지 않습니다. 운영 비중·등급 문턱은 발란스 대기입니다.

접수와 집계 인정을 구분하고 동일 정책/대상집합 snapshot의 순위 변화를 표시한다. 미공급은 집계 대기다. 외부 일간/주간 자료를 초 단위 실시간처럼 연출하지 않는다. 차트 조회·필터·자동 갱신은 재생곡·큐·위치를 바꾸지 않는다. 내역은 해당 entry·곡·회차로 연결한다.

## 8장 · 시상·회고·10주차 선택

월드 마감 → 검수·잠정/최종 구분 → 각 부문 시상·앵콜 → 내 팀 회고·권리/보관/미정산 확인 → 기존 경로의 다음 시즌 준비다. 앵콜·감상·회고가 지난 회차 점수를 추가하지 않는다.

| 달력 | 현재/제안 구분 |
|---|---|
| 활동63일 + 휴식3일 | 현재 season_config.csv. 다음 시즌은 상대67일 이후. 10주차 전체가 쉬는 주간은 아님 |
| 활동63일 + 시즌 외 준비7일 | 10주차 마무리/프리시즌의 권장 검토안. 휴식3→7일과 다음 시작을 별도 검수. 다음 시즌 상대71일 이후 방향이며 미확정 |

활동 시즌을70일로 바꾸는 안이 아니다. 개막 날짜·정확한 시각·잔여 재화·보상·이월·초기화는 기존 시즌 담당의 정책을 따른다. 보상·미정산·보존 성공보다 초기화를 먼저 실행하지 않는다.

## 9장 · 신청·감상·공연의 UI 분담

앨범은 제작·발매·활동, 공연은 보드의 해당 방송국/공연장 도착에서 시작하는 상태·PIP, 페스티벌은 신청/참여 로비입니다. 음악 앱은 같은 곡·공연·대회 차트의 감상과 허용 반응/투표를 맡습니다. 다른 콘텐츠 이동은 모바일 내부 확인, 음악 앱 내부 상세는 직접 이동합니다. 공연/투어 완료가 대회 신청 의무는 아닙니다.

## 10장 · 개별 시험과 연동 제작

### 주간·월드 UI 추가 정정

주간과 월드는 신청 UI를 각각 제작하고 실제 플레이는 해당 기간의 대회만 엽니다. 주간은 간결한 반복 참여, 월드는 화려한 시즌 무대·출전 방법·참여 혜택/시즌 기록 설명을 보강합니다. 개별 시험에서는 두 UI를 각각 직접 확인합니다. 추가 보상 수량은 결정 대기입니다.

## 주간 개인 신청 UI

주간은 개인만 내 발매 앨범 한 곡을 선택해 신청합니다. 첫 화면에 앨범 목록과 신청만 두며 개인/크루·대회 선택·별도 준비 단계를 넣지 않습니다. 성공 후 같은 앨범·회차의 게임 상단 버프 중 팝업을 유지합니다. 실제 효과·수치·종료 시각은 기존 원본을 연결하고 미정값을 창작하지 않습니다. 월드는 개인/크루·등록 로비·화려한 무대 안내를 유지합니다.

## 개인·크루 신청과 주간 버프의 최신 흐름

주간·월드의 일반 입구는 모두 개인 신청입니다. 내 발매 앨범을 선택하고 같은 화면에서 신청하며, 월드는 성공 뒤 내 출전곡 참여 로비를 엽니다. 개인/크루 선택·선택되지 않은 곡 확인·별도 준비 단계를 두지 않습니다. 크루 소속·직책과 관계없이 크루장과 멤버도 개인 월드에 출전할 수 있습니다.

크루 월드 신청은 크루 페이지에서 크루장에게만 켭니다. 현재 멤버가 공유된 발매곡 한 곡에 내부 투표하고 변경·취소할 수 있습니다. 투표 결과는 참고용이며, 크루장이 득표와 무관하게 최종 공유곡·원소유자 사용 동의를 확인해 신청합니다. 내부 곡 투표는 관객의 공식 페스티벌 투표·점수·재화와 별개입니다. 개인 출전과 크루 출전을 서로 잠그지 않습니다.

주간 버프는 신청한 경우에만 해당 주의7일째부터 공통 주간 마감까지 적용합니다. 7일째 중간에 신청하면 신청 이후 남은 기간만 받습니다. 신청일부터24시간을 새로 주지 않으며, 신청 전 활동을 소급하지 않습니다. 미신청·다음 주·월드 기간에는 주간 버프가 없습니다. 다음 주에는 새로 신청합니다. 게임 시뮬레이터의 표시는 현재 게임 일차·실제 굴림 시계를 사용하며 실제 서버 시계와 구분합니다.
