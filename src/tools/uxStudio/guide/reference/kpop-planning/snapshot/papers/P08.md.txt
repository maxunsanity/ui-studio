# Lead generation 기획안 v1 — 홍보 덱과 「혜택」 탭

> status: **제안(검수 대기)** · 2026-09-29 · 작성 claude · 삼중AI R3 · 현중 필수 ②
> 같다름 한 줄: 모노폴리 GO·모노카피바라는 **게임 안에서만** 유저를 붙잡는다. 우리는 **게임을 떠나도 다시 부를 수 있는 연결**(이메일·전화·SNS)을 **카드 수집 안에** 넣는다. 벤치마크는 게임이 아니라 **토스 혜택 탭**. (9/28 회의 37:10~39:30 · 53:32~57:23)

> 근거: 9/28 회의록 · GDD v1.5 덱 15(홍보·팬덤) · 카드획득 v1 · 웹 출처(아래)

---

## 이게 뭐냐

**유저가 앱을 떠나도 우리가 다시 연락할 수 있는 정보(이메일·전화번호·SNS 계정·사진·이름)를 동의를 받고 얻는 설계.** 회의 정의: 「그중 하나만 넣어도 다 리드 제너레이션」(54:20~55:05).

## 언제 나오냐

- **카드를 얻는 순간** — 홍보 덱 카드는 「무언가를 하고 오면」 얻는다.
- **하단 「혜택」 탭** — 토스처럼 메뉴 하나를 통째로 쓴다.
- **게임 밖** — 시즌 시작·새 IP 공개·굿즈 판매 알림.

---

## 한 줄

> **홍보 덱 9장 = 리드 9개. 안 해도 카드는 얻지만, 하고 오면 더 준다.**

## 간략

| | |
|--|--|
| 자리 | **홍보 덱 9장** (카드북 20덱 중 하나) + 하단 **「혜택」 탭** |
| 원칙 | **안 해도 기본 보상, 하면 특별 보상** (회의 38:00~38:31) |
| 얻는 것 | 이메일 · 전화번호 · SNS 연결 · 공유 게시물 · 커스텀 캐릭터 이미지 |
| 보상 크기 | 회의: 덱 완성 특별 보상은 **현금 가치로 크게** — 금액은 **라이브 QA 때** 결정 (57:23) |
| 벤치마크 | 토스 혜택 탭 · 오늘도 환생(이메일 입력) (53:56~56:07) |
| 지켜야 할 것 | 마케팅 동의는 **별도·선택** · 수신 동의 **2년마다 확인** · 만 14세 미만 보호 · 사진 저장 최소 |

## 자세히

### ① 왜 넣나 — 회의 한 문장

> 「지금은 이런 거 없으면 게임 팔기 힘들어요. 그래서 이 부분이 킥이에요.」 (39:18)

- **토스**는 하단 메뉴 5개 중 하나를 **혜택 탭**으로 통째로 쓰고, 오래돼도 빼지 않는다 (55:47~56:22). 혜택 탭의 **행운퀴즈**는 분당 15만 명 이상이 동시에 참여할 수 있는 광고 상품이다 ([toss ads 가이드](https://toss-ads.gitbook.io/guide/reward/luckyquiz)).
- **오늘도 환생**은 플레이 중 어느 날 「이메일을 넣으면 뭔가 할 수 있는」 창을 띄워, 게임을 떠난 사람과도 계속 연락했다 (55:12~55:47).
- 엔터사 입장(제안서 B)에서 **팬의 연락처는 다음 앨범·콘서트·굿즈의 첫 고객 명단**이다.

### ② 홍보 덱 9장 = 리드 미션 9개 (가안)

| # | ★ | 카드 (가안) | 하고 오는 것 | 얻는 리드 |
|---|---|---|---|---|
| 1 | ★1 | SNS 콘텐츠 에디터 | 공식 SNS 팔로우 | SNS 계정 |
| 2 | ★1 | 뉴스레터 편집자 | **이메일 등록** (시즌 소식 받기) | 이메일 |
| 3 | ★2 | 숏폼 챌린지 기획자 | 제공 음원·안무로 **숏폼 챌린지** 올리기 | 게시물 · 해시태그 |
| 4 | ★2 | 팬카페 운영자 | 친구 초대 1명 | 신규 유저 |
| 5 | ★3 | 팬사인회 기획자 | **알림톡 신청**(전화번호) — 팬사인회 잭팟 알림 | 전화번호 |
| 6 | ★3 | 캐릭터 스타일리스트 | 내 **커스텀 블록 캐릭터** 이미지를 공유 | 게시물 |
| 7 | ★4 | 뮤비 에디터 | 게임이 만든 **15초 짤**(카드 조합)을 내 SNS에 게시 | 게시물 · 도달 |
| 8 | ★4 | 음원 유통 담당 | 게임 속 곡 **실제 음원 사전 저장** (유통 파트너) | 음원 플랫폼 팔로우 |
| 9 | ★5 골드 | 「팬덤을 만드는 사람」 | **오프라인 팝업·굿즈 응모** (이름·연락처) | 실명 연락처 |

- 회의 근거: 카드 등록 때 인스타 연결 (37:10) · 숏폼 챌린지 (37:30) · 15초 짤 (38:44) · 음원 유통 (44:29).
- **같은 카드를 다른 경로로도 얻을 수 있다** (팩·교환) → 안 해도 덱은 완성 가능 = 「안 해도 주긴 줘」 (38:00).
- **하고 오면**: 그 카드 즉시 + 보너스(별·주사위) · 덱 완성 시 **특별 보상**.

### ③ 「혜택」 탭 — 하단 메뉴 하나

| 칸 | 내용 |
|---|---|
| 오늘의 혜택 | 하루 1개 리드 미션 (퀴즈·출석·SNS) |
| 홍보 덱 진행 | 9장 중 몇 장 · 다음 미션 |
| 알림 신청 | 시즌 시작 · 새 IP 공개 · 굿즈 판매 · 팬사인회 잭팟 |
| 내 연결 | 연결한 SNS·이메일 · **동의 철회 버튼** |

- 토스처럼 **메뉴 자리 하나를 양보하는 결정**이 필요하다 → 체크 L-1.

### ④ 게임 밖으로 이어지는 흐름

<div class="flow"><div>카드 획득<br><small>홍보 덱</small></div><div>동의·연결<br><small>이메일·전화·SNS</small></div><div>게임 밖 알림<br><small>시즌·IP·굿즈</small></div><div>돌아옴 · 구매<br><small>재방문·굿즈</small></div></div>

- 굿즈 알림은 **건물 굿즈**(9/29 카톡 「건물을 굿즈로 판매」)와 직결 → 상품성 콘텐츠 기획과 연결.
- 새 콜라보 IP 공개 알림 → **IP 교체 시즌의 첫날 유입**.

### ⑤ 지켜야 할 것 (한국 기준)

| 항목 | 규칙 |
|---|---|
| 동의 분리 | 게임 이용 동의와 **마케팅 목적 수집·이용 동의를 따로**, 선택으로 ([개인정보 포털 Q&A](https://talk.privacy.go.kr/talk/know/knowBbsDetailView.do?nttId=3388)) |
| 광고 수신 | 광고성 정보 전송은 **사전 수신 동의** · 동의 사실을 **2년마다 확인** ([정보통신망법](https://www.law.go.kr/LSW/lsLawLinkInfo.do?chrClsCd=010202&lsJoLnkSeq=1000688185&lsId=000030&print=print)) |
| 만 14세 미만 | 법정대리인 동의 — K-pop 유저층 특성상 **연령 확인 필수** |
| 사진 | 업로드 → 복셀 변환은 **부적절 업로드 위험** (회의 16:37~17:15) → **블록 커스터마이징**으로 대체 |
| 보상과 동의 | 동의하지 않아도 **게임 핵심 진행은 막지 않는다** (기본 보상 원칙과 같음) |
| 제3자 제공 | 콜라보 기획사·광고주에 넘기려면 **별도 동의** |

→ 최종 문구·절차는 **법무 검토** (체크 L-5).

### ⑥ 성과를 무엇으로 보나

| 지표 | 뜻 |
|---|---|
| 리드 전환율 | 홍보 카드 미션 시작 → 완료 비율 |
| 옵트인 유지율 | 수신 동의 유지 (2년 확인 포함) |
| 재방문율 | 게임 밖 알림 → 앱 복귀 |
| 공유 도달 | 숏폼·15초 짤 조회 |
| 굿즈 전환 | 알림 → 구매 |

## 안 정한 것 (체크)

| # | 체크 |
|---|---|
| L-1 | 하단 메뉴 중 **무엇을 「혜택」 탭으로 바꾸나** (현재 일정 보드 · 덕질→투자 · 활동 미션 · 입덕 · 상점) |
| L-2 | 홍보 덱 9장의 미션 확정 (위 표는 가안) |
| L-3 | 특별 보상의 형태·크기 (회의: 라이브 QA 때) |
| L-4 | 15초 짤·음원 사전 저장의 제작·유통 범위 (회의: MV는 과함) |
| L-5 | 법무 — 동의 문구 · 연령 확인 · 제3자 제공 |

## 하지 않음

- 동의하지 않은 사람의 진행 막기
- 사진 업로드 → 자동 복셀 변환
- 리드 수를 순위·경쟁 요소로 만들기
