</section><section class="part" id="part-3"><h2>3. 구동 방법·시뮬레이션</h2><h3>공용 게임 상단 메뉴</h3>
<p>상위에는 <strong>앨범 발매·페스티벌·응원 크루</strong>를 둡니다. 앨범 하위에는 <strong>음원 제작·시티 투어</strong>, 페스티벌 하위에는 <strong>방송·공연·음악 차트·음악 앱·배점/투표 시험</strong>을 둡니다. 현재 공용 메뉴 데이터의 소속을 따르며 다른 메뉴를 열면 해당 하위 행을 숨깁니다. 관계·순서·문구는 <a href="/data/simulator/menu.json">공용 메뉴 데이터</a>를 읽으며, 다른 보조 도구의 정리는 별도입니다.</p>
<p><a href="/docs/planning/planning-docs-tool.html?face=development&doc=P208&plan=planning_development_plan_todo_song">7007 P208 목록·카드</a> → 실행 → <a href="/docs/planning/game-simulator.html?module=simulator_module_music_production">공용 게임의 음원 제작</a> 또는 하단 <strong>앨범</strong>입니다.</p>
<ol>
<p>1. 정규 앨범은 팀 칸 멤버 전원으로 고정되어 멤버를 고르지 않습니다. 솔로 · 유닛 · 팀은 뮤비 제작 때 고릅니다(R-06-7).</p>
<li>보컬·랩·코러스·제작 파트를 고릅니다. 확인되지 않은 목소리 정보는 이 앨범용으로 확인하며 실제 멤버 프로필은 바꾸지 않습니다.</li>
<li>간편의 콘셉트 하나를 고르거나 프로에서 스타일·언어·빠르기·길이·가사를 조절합니다.</li>
<li>제작비와 보유 돈을 보고 <strong>만들기</strong>를 누릅니다. 연결 중에는 중복 생성을 막습니다.</li>
<li>완료되면 공연 이미지와 연결된 곡을 공통 영상 플레이어로 보고 이어지는 재킷·앨범 정보 화면에서 곡명·소개·재킷을 다듬습니다. <strong>다시 만들기</strong>는 같은 곡을 유료 재생성합니다.</li>
<li>기존 기간·성장·미션·엔터파워 조건을 채우면 <strong>앨범 제작 완료</strong>로 넘어갑니다. 샘플 완료만으로 발매되지 않습니다.</li>
</ol>
<p>직접 플레이·8곡 연속 발매·실제 정산 화면 검수는 사용자 확인 항목입니다. 이번 변경 후 자동 플레이나 브라우저 조작 시험을 새로 실행하지 않습니다.</p>
</section><section class="part" id="part-4"><h2>4. 상세 기획</h2><h3>모바일은 현재 단계부터 보여 줍니다</h3>
<p>앨범 진행 표시는 작은 점과 현재 단계 이름으로 줄입니다. <strong>팀 전원 고정 · 곡 고르기 → 파트 → 간편/프로 음악 → 재킷·정보 → 제작/발매</strong>에서 현재 선택과 필수 버튼을 먼저 보이며, 이전·다음·제작·발매 버튼은 기존 하단 공통 슬롯에 둡니다. 본문만 세로로 스크롤하고 가로 잘림이나 버튼 내부 스크롤을 만들지 않습니다.</p>
<p>멤버와 음악 옵션은 읽을 수 있는 크기를 유지합니다. 제작비 상세·발매 전 예상 순위·참여 파트의 계산 설명은 선택 영역 뒤에 배치하며, 참여자 상세는 요약 아래에서 펼칩니다. 재킷은 작은 정사각형 미리보기와 편집 필드를 함께 보여 주고 긴 소개·부가정보는 아래로 이어집니다. 비용·부족 사유·실패 안내를 생략하거나 임의로 잘라 숨기지 않습니다.</p>
<h3>영상 미리보기와 뮤직비디오 제작 상태</h3>
<p><strong>현재 미리보기:</strong> 10차의 공통 영상 플레이어와 공연 이미지3종을 재사용합니다. 동영상 파일을 새로 만드는 기능이 아니라, 공연 이미지와 해당 앨범에 연결된 검증 샘플을 함께 보여 주는 시험 시뮬레이터입니다. 별도의 audio/video 플레이어를 중복 생성하지 않습니다.</p>
<p>샘플 준비 후 <strong>영상으로 미리보기</strong>를 누르면 이미 생성된 music controller의 openAlbumVideo(album,current,{preview:false})를 호출합니다. 앨범 초안·제작·발매 원장, 생성 작업·제작비·환불을 쓰지 않습니다. 같은 공통 플레이어로 복귀/닫기를 처리하며 원곡·저작자·라이선스 링크는 유지합니다.</p>
<p><strong>뮤직비디오 제작: 기획 준비중.</strong> 실제 동영상 생성·동작 영상 공급은 추가 기획/연결 대상입니다. 10차의 현재 결과는 정지 공연 이미지와 지속 미디어 플레이어이며 실제 영상 생성 완료로 표시하지 않습니다. 나중에 실제 파일이 공급되면 기존 album.media.videoSrc 또는 album.video.src의 검증된 /assets/ 경로로 연결합니다.</p>

<h3>제작 전에 보는 대략의 시작 순위</h3>
<p><strong>팀 칸 전원 고정 · 곡 고르기 → 현재 멤버 능력·팬으로 예상 순위 확인 → 음악/재킷 → 발매 때 실제 시작 순위 확정</strong> 순서입니다. 첫 음반도 현재 팀과 참여 멤버의 능력을 반영합니다. 다음 음반은 같은 계산에 직전 앨범의 최종 성적을 더합니다. 화면의 예상은 대략의 범위이며 발매 때의 능력·팬·새 상대에 따라 달라집니다.</p>
<p>팀 평균과 참여자 평균이 모두 원점수500이고 팬이 없는 수학 예시는 <strong>대략40~53위</strong>입니다. 음반 차수로 등수를 강제하지 않으며 2번째부터도 같은 공통 계산을 씁니다. 가중치·곡선·상한·예상 범위 폭은 <a href="/data/music_career/music_career_rules.json">음악 규칙 데이터</a>의 <code>albumLeague.entry</code>에서 조절합니다.</p>
<h3>음악 다음에 재킷, 발매 다음에 차트</h3>
<p><strong>음악 완성 → 재킷·앨범 정보 확인 → 제작 완료 → 발매 → 약2.8초 순위 공개 → 이 곡 차트</strong> 순서입니다.</p>

<p>앨범 참여계수는 보컬100%·랩60%·코러스40%·제작70%의 <strong>로컬 현재 세팅값</strong>을 데이터에서 읽습니다. 복수파트는 가장 큰 계수를 쓰고 대상 능력 비율을 그 멤버 안에서 나눕니다. 플레이어가 보상 숫자를 직접 입력하지 않습니다.</p>

<h3>솔로·유닛·팀의 참여와 보상</h3>
<p><strong>정규 앨범은 팀 칸 전원 참여입니다.</strong> 솔로 · 유닛 · 팀 선택은 뮤비 제작 때만 고르고 뮤비 크레딧에만 표시합니다(R-06-7, 11/13 #35). <span class="yr-old">아래 솔로 · 유닛 보상 설명은 앨범에 멤버 선택 UI가 있던 구 계산 구조의 기록이며,</span> 정규 앨범의 추가 능력 대상은 팀 칸 멤버 전원입니다.</p>

<h3>시티 투어에서 이벤트 재화 사용</h3>
<p>앨범 활동으로 정산받은 이벤트 재화는 <a href="%EC%83%88%EB%8F%84%EC%8B%9C%EC%A7%84%EC%B6%9C_%ED%95%B5%EC%8B%AC%EC%A0%9C%EC%95%88%EC%84%9C.html">시티 투어</a> 참가비로 소비합니다. 기존 하늘길 계산/봇을 재사용한 투어 밴5팀 가로 레이스이며, 1등의 공연 수익은 기존 돈 영수증으로 한 번 지급합니다. 앨범 추가 능력·팬 보상과 별도이고 실유저 대결은 서버 검증 결과만 정산합니다. 현재 로컬 시험은 기존 봇4팀으로 표시하며 실제 서버는 연결하지 않았습니다.</p>
<h3>현재 팀 연계와 시험 자료의 경계</h3>
<p>앨범 제작·발매·차트·시티 투어는 같은 현재 session/run/season/team의 관측을 사용합니다. 같은 창의 성장 알림으로 지갑·능력을 다시 읽고, 우측 앨범 데이터 연결에서 입력 상태와 조건 대기를 구분합니다. 원시 팬층 누락/손상은0으로 바꾸지 않습니다. 선택 공급자의 데뷔 기준일·미션 완료 영수증·팬층은 동일 revision/checkpoint 증거일 때만 메모리에서 채택하며 돈·능력·멤버·전체 저장을 교체하지 않습니다. 공급 API·현재 빠진 원천과 비어 있음 조건은 <a href="%EC%95%A8%EB%B2%94%EB%B0%9C%EB%A7%A4_%EA%B8%B0%ED%9A%8D%EC%84%9C.html">앨범 연계 계약</a>을 따릅니다.</p>
<p>명시 시티 단독 시험은 현재 시험 멤버로 고정 참여자 있는 시험곡·리그·최초 급유 재화를 준비합니다. 이 시험 준비를 실제 연계 팀에 적용하지 않습니다. 실제 노래 생성/제작비 청구는 생략한 메타데이터 시험이며, 기존 초안·편집·종료 이벤트는 보존합니다.</p>
