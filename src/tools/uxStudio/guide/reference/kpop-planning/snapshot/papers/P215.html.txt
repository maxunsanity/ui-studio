<p>화면 흐름: 혜택 · 미션 탭 → 미션 → 보상 / 피드 → 홍보 버튼 · 스샷 미완 · 이식 비교 해당 없음</p>

<ul>

<li>이 문서 하단 <b>홍보 갈래 시뮬레이터</b>에서 홍보 행동을 누르면 어느 갈래이고 순위에 들어가는지 봅니다. 숫자는 모두 임시 시안입니다.</li>
</ul>
