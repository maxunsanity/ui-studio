# 05 · 제나가 기획(이올카)에 필요한 것 — 4항

```
상태: 제안(검수 대기) — 승인 아님
```

연출 시안·유닛 오버시·도로 비주얼을 이어가려면, 이올카가 아래 4항을 **기획 산출**로 명시해 주면 된다.  
(제나가 기획 본문을 쓰지 않기 위한 요청 목록.)

| # | 필요 | 왜 연출에 필요한가 | 현재 메모 |
|---|------|-------------------|-----------|
| **(1)** | **칸ID · 이름 · 용도 · 사장/팬 뷰** | 유닛 라벨·도착 컷씬 슬롯·시점 분기 배경이 칸 정의에 묶임 | 034/056/D-074 + catalog. C4·C7 라벨 정렬은 현중 미결 ⑥ |
| **(2)** | **성장 · MAX 변화** | 언제 도시 전체룩·건물 단품이 성장맥스 SSoT로 가는지 트리거 | 050/062/063. Board1 MAX=노랑3+초록3 홍대. 아레나/해외 아님 |
| **(3)** | **D-074 사적금지** | 팬 뷰에서 그리지 않을 POI(사적 내부·외관) 목록 | D-074: 사적인 곳 4 → 현생·지갑 등. 클로드 Q-001 A(컷씬): 19·20·37·39 외관 미사용 |
| **(4)** | **좌표 · 도로 잠금 여부** | 단품 배치·도로 비주얼이 「잠긴 원본」인지 「아직 후보」인지 시안에 표기 | **Q-001 A 이미 잠금** (citypack x/z). 위치맵·DualNavMesh 보고 있음. 단품 퀄은 별개(제안/검수 대기) |

## 이올카에게 부탁

1. (1)~(3)을 보드 기획 SSoT 문장으로 한곳에 모으거나, 기존 034/056/050/062/063/D-074를 **이올카 소유**로 갱신·가리키기.
2. (4)는 「좌표=잠금 A · 도로 개념도≠월드 · DualNavMesh 규칙 유지」를 기획 쪽에서 한 줄로 재확인.
3. 답이 오면 제나는 시안/스티어만 갱신. Codex·concept_key·클로드 팩은 이 요청으로 **수정하지 않음**.
