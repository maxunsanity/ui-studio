# D06 · 접근·후퇴·추적·팬·360도 경로

문서 버전: 1.0 · 갱신: 2026-09-22 · 상태: 제작 참조 초안 / 실제 씬 검수 전

## 용어와 근거

팬/틸트는 카메라 방향 변화이며, 공간을 따라 움직이는 촬영은 위치 변화다. 아크는 피사체 둘레를 도는 경로다. [Yale 촬영 분석](https://filmanalysis.yale.edu/cinematography/), [StudioBinder 아크 샷](https://www.studiobinder.com/camera-shots/camera-movements/arc-shot/). 아래 수식과 안전 검사는 우리 에디터 구현을 위한 설계다.

## 움직이기 전에 결정할 것

이동의 이유, 시작 구도, 끝 구도, 주목 대상, 이동 시간, 배우 동작 범위, 공간 장애물을 지정한다. ‘카메라웍이 약하다’는 지시를 무조건 속도 증가로 바꾸지 않는다. 구도 차이, 주목 대상 변화, 동선, 접근 강도 중 무엇이 부족한지 비교안을 만든다.

접근은 감정 변화가 시작되거나 정보가 중요해지는 구간의 후보다. 후퇴는 관계나 공간을 다시 드러낼 후보다. 추적은 배우가 이동한다는 전제가 필요하다. 팬은 옆 대상을 보여줄 수 있지만 모든 대사마다 좌우로 흔들면 주의가 분산될 수 있다.

## 경로 데이터

`mode, subjectIds, targetAnchor, start/endTransform, path, duration, easing, lensTrack, axisTransition, collisionPolicy`를 저장한다. 촬영 카메라와 사용자가 마우스로 돌리는 작업 카메라를 분리한다. 작업 화면을 돌려도 촬영 결과를 바꾸지 않는다.

## 아크·360도 계산 예시

바닥 평면의 중심 O=(ox, oy, oz), 반지름 r, 높이 h, 각도 θ를 사용한다. Y-up 좌표계의 예시는 다음과 같다.

```text
p(θ) = (ox + r*cos(θ), oy + h, oz + r*sin(θ))
θ(t) = θ0 + Δθ * smoothstep(clamp(t / duration, 0, 1))
smoothstep(u) = 3u² - 2u³
```

타깃은 얼굴이나 두 배우의 중심 중 의도에 맞게 고른다. 두 배우의 평균 위치만 보면 한쪽 얼굴이 뒤통수에 가릴 수 있으므로 경로 전체에서 렌더 검사를 한다. 이동 중심과 바라보는 타깃은 서로 다른 값으로 둘 수 있다.

Δθ=360도에서는 시작/끝 위치가 같아도 회전 의도가 사라지면 안 된다. 시작·끝 쿼터니언만 보간하면 짧은 회전 또는 정지로 처리될 수 있어, 누적 각도와 경로 샘플을 보존한다. `smoothstep`은 정지에서 출발해 정지하는 한 경로의 예시이며 연속 추적 전체에 반복 적용하면 속도가 꿀렁일 수 있다.

## 경로 검사 절차

1. 시작과 끝 구도가 의도한 인물 크기와 시선 관계를 만족하는지 본다.
2. 경로를 일정 간격으로 검사하고 장애물·가림 변화가 큰 곳은 더 촘촘히 검사한다.
3. 점 충돌만 보지 말고 카메라 근평면과 여유 공간을 고려한다. 얇은 벽은 연속 충돌 검사 또는 추가 표본이 필요하다.
4. 배우가 회전하거나 손을 올리는 시간에도 얼굴이 보이는지 확인한다.
5. 360도 후 대화로 돌아올 경우 새 축과 다음 컷 연결을 검사한다.
6. 미완성 배경 뒷면이 보이면 경로 축소, 부분 아크, 배경 보강을 제안한다.

## 지시 변환 예

‘한 바퀴 돌다가 얼굴 클로즈’는 먼저 회전과 접근을 분리한 2구간 안을 만든다. 하나의 나선 경로로 합칠 수도 있지만 공간과 가림 검사가 더 어렵다. 사용자에게 추가 질문 없이 가능한 후보를 만들되 경로·속도·최종 얼굴 구도를 기록한다.

‘두 사람이 걸으며 대화’는 걷기 리소스와 실제 루트 이동이 먼저다. 배우를 바닥에서 미끄러뜨리고 카메라로 숨기지 않는다. 걷기가 없으면 정지 대화안을 대안으로 표시한다.

## AI 실행 지시

```text
이동 이유와 시작/끝 구도를 적은 뒤 경로를 제안하라.
360도이면 누적 각도를 보존하고 전 경로의 얼굴 가림·충돌·배경을 검사하라.
경로가 실패하면 속도를 높여 숨기지 말고 반지름·높이·회전량 대안을 제시하라.
```
