## 한 줄

**게임 한 편이 아니라 판 하나다.** 판은 그대로 두고 **아이돌을 콜라보로 데려와** 시즌마다 갈아끼운다.

---

## 1. 무엇을 파는가

| | |
|--|--|
| 우리가 가진 것 | 40칸 판 · 덕질/덕력 · 팬덤 스테이지 · 지역 성장 |
| 매 시즌 데려오는 것 | **아이돌 IP 하나** (시즌 1 BTS → 시즌 2 에이티즈 → …) |
| 시즌마다 만드는 것 | **시즌팩** — 그 팀의 이름·칸 문구·대사·아트·실제 성장 경로 |

---

## 2. 안 바뀌는 것 / 바뀌는 것

| 안 바뀜 (우리 자산) | 바뀜 (시즌팩) |
|---------------------|----------------|
| 40칸 구성 · 칸 역할 | 칸에 적히는 이름 |
| 덕질 · 덕력 · 직함 | 아이돌·멤버·소속사 |
| 팬덤 스테이지 5단 | 서사 조각 문안 |
| 지역 사다리 구조 | 그 팀이 실제로 거쳐온 지역 |
| 판정·룰 | 아트·음악·목소리 |

**판정 기준: 새 시즌을 얹을 때 판을 고쳐야 하면, 그건 시즌팩에 있어야 할 게 판에 박힌 것이다.**

---

## 3. 왜 아이돌 쪽이 받아들이나

| 그쪽이 얻는 것 | |
|----------------|--|
| **데뷔 초 서사를 다시 판다** | 지금 팬은 그 시절을 못 봤다. 게임에서 같이 산다 |
| 신규 팬 유입 | 게임으로 입덕하는 경로 |
| 굿즈·티켓·앨범 연계 | 시즌 중 실제 컴백과 붙일 수 있음 |
| 리스크 낮음 | 판은 검증된 손맛. 우리가 만드는 건 그 팀의 옷 |

## 4. 왜 우리에게 남는가

- 새 시즌 = **새 게임이 아니라 새 옷.** 제작비가 판이 아니라 팩 단위
- 시즌마다 **그 팀 팬덤이 통째로 신규 유저**
- **덕력은 계정에 남는다** → 시즌 갈아타도 유저가 손해 보지 않음 → 이탈이 적음

---

## 5. 시즌 한 바퀴 (초안)

```
시즌 열림  「○○○ 시즌이 시작되었습니다」
   ↓  아이돌 성장 리셋 (22칸 처음부터 · 049)
   ↓  빠순이 덕력·직함은 그대로
플레이     덕질 → 서사 쌓임 → 색 칩 10개로 급 +1 → 여섯 칸이 차면 지역이 커짐
   ↓
시즌 닫힘  그 팀의 마지막 무대 · 서사 완성본
   ↓
다음 시즌   새 아이돌, 같은 판
```

---

## 6. 아직 안 정함

- 시즌 길이 (몇 개월)
- 지난 시즌 아이돌은 어디로 가나 (보관 / 졸업 / 다시 고를 수 있나)
- 시즌 동안 실제 컴백·콘서트와 어떻게 붙이나
- 1시즌을 실제 IP 없이 열 수 있는 대비책
