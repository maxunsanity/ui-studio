# 009 · 같다름 — 칸 역할 매칭 (보드 기본)

> status: draft · **023 본문 전** 준비. 모노카피바라 칸 종류 ↔ 덕질 보드.

> ⚠ **현행과 싸우는 대목이 있다 (2026-09-17 확인).**
> 이 문서는 칸을 **빠순이가 하는 일**로 읽는다. 현행은 반대다 — **색 난 대지 22칸 = 아이돌 일정(엔터)**, 빠순이는 **특수칸(창구)**로 들어온다.
> 기준은 [048](./048_피치_두시선.md) · [045](./045_현행Board1_핸드오프.md) · [034](./034_보드1_1차잠금.md).
> **버리지 않는다.** 여기 쌓인 덕질 행동·풀은 다른 보드·시나리오 필러·시즌 미션의 **재료**로 그대로 쓴다.

한 줄: **모노/모노카피의 ‘칸 역할’은 빌리고, 칸 안의 전투·마법은 덕질 하루로 갈아끼운다. 판을 깨는 루프는 가져가되, 1차 판타지는 ‘보드 수집’만이 아니다.**

## 같은 점
| | 모노폴리GO / 모노카피 | kpopmonsters에도 |
|---|---|---|
| 루프 한 장 | 40 또는 64칸을 돈다 | N칸 루프 (40 후보 가능) |
| 판 진행 | 랜드마크/건설 깨면 **다음 보드** | 판 클리어 → 다음 보드 생성 |
| 칸 = 역할 1개 | LAND·정거장·찬스… | 역할은 유지, **내용만 덕질** |
| 코너 리듬 | GO·감옥·공원·경찰 | 하루 기준점·멈춤·회복·강제 멈춤 |

## 다른 점
| | 모노카피 | kpopmonsters |
|---|---|---|
| LAND | 전투→골드 | **응원 노동→덕질 재화** (스밍·투표·차트) |
| TERRITORY | 영지 휴식/해적/용병 | **관계·선택 성장** (덕메·같이보기·팬계정) |
| TRAIN | 스킬 3택1 | **덕질 스킬 3택1** (총공·번역·영업…) |
| 1차 목적 감각 | 판 깨고 다음 도시 | 판은 **척추**, 판타지는 **아이 키우기+내 직함** |
| Cap 전용 24칸 | 악마·던전·타워… | 1차엔 **안 옮기거나** 보내기/한판 이벤트로 빼기 |

## 결정 후보 (합의 필요)
1. N = **40(모노 뼈대만)** vs 64(Cap 포함)
2. 1차 목적 = 보드 클리어만? → 권고: **보드 클리어는 진행 엔진**, 클리어 보상으로 아이돌 호흡·직함 스탬프가 같이 움직임
