# 047 · 덕력

**이 문서는** 초기(9월 말) 기획 때 쓴 **옛 컨셉 기록**이에요. 요약: 레벨 아님. 오르면 한 번에 굴리는 [주사위](삼중AI_공용_20260929/산출/개발진행기획_v01/콘텐츠별_v03/P74_설명.html) 상한이 열린다. 지금 게임의 [미션](삼중AI_공용_20260929/산출/시스템기획/S11_미션.md)은 [S11 미션](삼중AI_공용_20260929/산출/시스템기획/S11_미션.md)과 미션 표를 따르고, 이 문서는 아이디어 재료로만 남겨 둬요.

**보는 법** 처음부터 순서대로 읽어요. 지금 규칙과 다른 부분이 있으니 숫자·규칙은 책갈피의 대표 기획서로 확인하세요. 시뮬레이터 없음.

**지금 상태** 이 문서 내용은 게임에 그대로 들어가지 않았어요. 여기 적힌 내용을 게임에 쓰는 것은 현재 개발되지 않음, 진행 중이에요.

---

## 이게 뭐냐

**덕질에 쏟아부은 코인의 누적.** 모노폴리 GO의 넷워스, 모노카피바라의 번영도 자리.
레벨이 아니다.

## 언제 나오냐

**덕질에 코인을 쓸 때마다, 쓴 만큼 오른다.** 안 깎이고, [시즌](proposal-concept/season.html)이 바뀌어도 남는다.
덕력이 오르면 **한 번에 굴리는 주사위 수 상한**이 열린다.

### ⚠ 횟수가 아니라 금액이다 (2026-09-22 · D-061)

전에는 「덕질할 때마다 오른다」였다. **횟수 기반이었다.**
그런데 자리를 맞춘 **GO 넷워스는 금액 기반**이다 — 비싼 걸 지으면 많이 오른다.

| | 전 | **지금** |
|---|---|---|
| 도시락을 보냈다 | 덕력 +1 | **싼 만큼 조금 오른다** |
| 전 스태프 케이터링을 보냈다 | 덕력 +1 | **비싼 만큼 많이 오른다** |

**쓴 돈이 사라지는 게 아니라 덕력으로 모양을 바꾼다.** 코인은 빠져나가는 게 아니라 쌓이는 것이다.

D-044의 다른 둘은 **그대로 횟수로 센다** — 항목 단 +1, 응원봉 +1.
**금액으로 세는 건 덕력 하나다.**

---

## 모노 대응

| 모노카피바라 / GO | 우리 |
|-------------------|------|
| 건설 | **덕질** (쌓는 행위) |
| **건설비 → 넷워스** | **덕질에 쓴 코인 → 덕력** (금액 그대로 쌓임) |
| **번영도** (영구 숫자 · UI에 레벨이라고 안 씀) | **덕력** |
| 번영 칭호 | **직함** ([020](./020_성장사다리_빠순이에서_사장.md)) |
| 그 판 랜드마크 단 | **팬덤 스테이지** (제로돌→서동요) |
| 월드 스테이지 N | **맵 스테이지** ≈500 |
| 골드 | **코인** |

모노 문서 이름: 공명도 아님. [84 번영도](../../../../모노카피바라%20프로젝트/monocapibara/docs/planning/economy/84_PROSPERITY_SYSTEM.md).

## 잠금

| | |
|--|--|
| **쓸 말** | 덕력 · 덕력이 오르다 |
| **화면 감각** | `덕력 128` (가칭 표기). **레벨 128** 금지 |
| **뜻** | 덕질에 **쓴 코인**의 누적. 팬심·애정·퀴즈 점수가 아님 |
| **높다** | 더 무거운 덕질(총대·정산·나중 사장)을 맡겨도 되는 능력 |
| **쌓는 행위** | **덕질에 코인 쓰기**. 덕력은 그 누적 숫자 |
| **자리** | **직함**. 덕력과 합치지 않음 |
| **그 판의 단** | 팬덤 스테이지. 덕력과 별층 |
| **팬심** | **다른 축이다** ([095](./095_팬심.md)). 덕력은 내가 얼마나 했느냐 · 팬심은 그게 지금 얼마나 먹히느냐. **효율 = 덕력 × 팬심** |
| **아이돌이 큰 것** | **준비도** ([066](./066_결과칸_16.md)). 같은 지출에서 같이 오르지만 **한 게이지로 합치지 않음** — 덕력은 안 깎이고 준비도는 판마다 리셋 |

하단 시스템 메뉴 6종에 **칸을 추가하지 않음.** 모노도 번영도는 HUD 숫자지 탭이 아님. 덕질 탭 설명에만 적는다.
