<section class="part" id="part-1"><h2>1. 개요</h2>

<p>출처: (합침) <a href="/docs/planning/proposal-concept/idol.html" data-paper-path="docs/planning/proposal-concept/idol.html">아이돌 성장 제안서</a>, 현재 뉴런 공통 패널·팀 관찰기와 성장 테스트 도구.</p>

<p>뉴런은 <b>기록을 보여 주는 화면</b>입니다. 보드에서 얻은 변화가 건물·엔터파워와 아이돌 능력으로 이어지는 모습을 살펴보고, 멤버별 현재 능력·재능·세부·아카데미와 실제 관계를 읽습니다. 뉴런이 성장량이나 보상을 새로 계산해 지급하지는 않습니다.</p>

</section><section class="part" id="part-3"><h2>3. 구동 방법·시뮬레이션</h2>

<p>화면 흐름: 공용 시뮬레이터 뉴런 또는 팀·멤버 정보창 → 전체·관계·개인 능력 → 세부 확인 → 기존 화면 복귀. 무거운 3D 화면은 링크를 눌러 열고 이 문서는 자동 실행하지 않습니다.</p>

<h3 id="뉴런-시뮬레이터-열기"><a href="/docs/planning/game-simulator.html?module=simulator_module_neuron_info" data-paper-path="docs/planning/game-simulator.html">▶ 뉴런 시뮬레이터 열기</a></h3>

<ol>
<li>현재 연결이면 같은 세션·run의 실제 팀과 성장 기록을 읽습니다. 자료가 없으면 연결 대기로 표시합니다.</li>
<li>팀 또는 멤버를 고르고 전체 → 관계 → 개인 6축 → 소속 세부 단계로 살펴봅니다. 선택한 멤버와 축은 공통 정보창에서도 이어집니다.</li>
<li>독립 생성 시험 문맥에서는 「임시 시험」을 명시해 인원과 상황을 바꿔 표시를 재생할 수 있습니다. 시험 결과는 실제 저장에 쓰지 않습니다.</li>
<li>화면에서 나가면 재생과 관찰을 정리합니다. 이번 문서 작업에서 새 실행·화면 캡처는 하지 않았습니다.</li>

<h3 id="능력재능아카데미">능력·재능·아카데미</h3>

<p>개인 6축은 보컬·댄스·랩·비주얼·끼와 예능감·프로듀싱입니다. 각 축은 자기 세부 세 개를 가집니다. 현재 능력 띠와 재능 띠는 서로 다른 원본이므로 합쳐 표시하지 않습니다. 아카데미의 태도·성실성·영어·중국어·일본어는 별도 항목이며 기본 6축이나 18세부에 새 능력으로 더하지 않습니다.</p>

<p>값이 0이면 실제 0으로, 필드가 없거나 연결되지 않으면 대기로 표시합니다. 화면 점수의 단위가 바뀌면 공통 변환 설정을 한 번 적용합니다. 척도가 유효하지 않으면 임의의 기본값으로 채우지 않습니다.</p>

<h3 id="라포는-실제-두-사람의-관계">라포는 실제 두 사람의 관계</h3>

<p>한 쌍은 현재 팀의 서로 다른 멤버 두 명을 기준으로 표시합니다. 기획은 관계 허브·모험과 같은 현재 팀 라포 조회로 이어 읽고 저장된 관계를 우선하며, 원본 시작 규칙이 있을 때 없는 쌍만 같은 범위·성격 궁합으로 계산하는 방향입니다.</p>
<p>공용 <code>resolveCurrentTeamRapport</code> 계산은 존재하지만, 이번에 확인한 뉴런의 직접 경로는 <code>panel</code> → <code>rapport-source</code>에서 관계 원표와 검증된 체크포인트를 조회하는 경로입니다. 원표의 <code>*</code> 행에서 범위 시작값을 읽는 부분과 기록 충돌 시 대기 표시는 확인했으며, 이 직접 경로가 공용 성격 궁합 초기계산을 호출하는 연결은 확인하지 못했습니다. 상위 writer가 만든 궁합 결과의 전체 전달은 별도 확인 대상이며, 공용 계산 자체가 전역 미구현이라는 뜻은 아닙니다.</p>
<p>1명에게 가상 상대를 넣지 않고, 원본 규칙이 없는 쌍은 기록 대기입니다. 기존0·명시된 빈 값·변화 기록을 새 시작값으로 덮지 않으며 중복·충돌·다른 세션 기록을 임의로 합치지 않습니다. 뉴런의 표시 조회와 실제 관계 저장을 쓰는 주체를 구분합니다.</p>

<p>공통 뉴런 패널은 전달받은 유효한 관계만 표시하고 자체로 상대나 수치를 생성하지 않습니다. 관계 허브의 시험 중에는 같은 누적 사본의 관계선·네 축을 표시하며 실제 저장 변경과 구분합니다.</p>

<h3 id="실제-변화와-임시-시험">실제 변화와 임시 시험</h3>

<p>같은 진행에서 새 기록의 실제 전후 차이가 있을 때 표시 신호를 만들 수 있습니다. 보드에서 받은 변화 → 건물 → 엔터파워 → 아이돌 능력의 흐름을 가볍게 보여 주며, 재진입이나 같은 기록의 중복 수신만으로 지급을 다시 실행하지 않습니다. 화면이 가려지거나 정보창이 열리면 경량 표시를 정리합니다.</p>

<p>P171 발란스 굴림에서 뉴런 보기가 켜져 있을 때는 뉴런 안의 확인된 변화선·빛을 유지하고, 돈·팬·엔터파워·나쁜 기운·콘텐츠·몬스가 다른 창으로 이동하는 표시는 목적 창의 빛과 기존 수신 배지로 바꿉니다. 뉴런으로 전환할 때 남은 비행과 필러는 표시 완료로 정리하며 같은 영수증을 나중에 다시 재생하지 않습니다. 숨겨진 필러를 출발점으로 기다려 굴림이 멈추지 않게 합니다.</p>
