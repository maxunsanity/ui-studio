# S05 · 팬덤 — 기획사 전체 현재 팬 총합 (이식)

**이 문서는** S05 팬덤 시스템 기획서입니다. 팬이 늘고 바뀌는 기획, 용도별 팬 합과 엔터 파워·팬 마일스톤의 현재 표·계산 범위를 나눠 읽습니다.
**보는 법** 간략 → 2절 규칙 → 읽고 쓰는 곳·표 순서로 읽습니다. [발란스 시뮬레이터](/docs/planning/idle-sim.html)는 기존 참고 입구이며, 이 문서의 정적 대조와 실제 화면·게임·저장 검수는 구분합니다.
**지금 상태** 현재 원표와 부분 계산·조건부 팬 writer, 현재팀 읽기 전용/독립시험 경로가 있습니다. 배정·수익 계수와 일부 방아쇠 입력은 대기이며 상위 게임·서비스·실저장은 이번 읽기 감사에서 확인하지 않았습니다. 숫자는 임시 값이며 전체 개발 완료를 뜻하지 않습니다.

## 발란스 값 · 지금 표 기준

**팬 층** 머글 → 라이트 → 코어 → 콘크리트 · 우리 팬 = 라이트 + 코어 + 콘크리트 · 현재 HUD의 3활성층입니다. 옛 `fan` 층은 removed 원표와 4층 호환 모델을 구분해 읽습니다.

**휴덕** 하루 미접속부터라는 당시 임시 기준입니다. 현재 helper는 경과 일수의 `>`/`>=` 조건이 서로 다르고, 경제 호출의 미접속 일수는 미공급이어서 모든 경로에서 같은 날 발동한다고 단정하지 않습니다.

**악개** 팀 평균의 1.176배 이상인 멤버에게 생긴다는 임시 조건입니다. 화면 팬 수에는 안 세지만 아래 원기획의 팬 합·수익 포함/감산과 현재 `toxic`/`anti` 입력은 용도가 달라 정합 확인 대기입니다.

**팬 수익 보너스** 팬 800명에서 절반 · 최대 0.55배 · 팬샵 1,000명당 0.05배는 당시 도구의 배수 설명입니다. 현재 같은 숫자의 S 대비 % 모델·일반 단계기본 배수 모델과 입력 미공급을 구분하며 운영 수익 완료로 읽지 않습니다.

**팬 마일스톤** 8단(1 · 3 · 7 · 15 · 30 · 50 · 75 · 100%) 문턱은 현재 원표에 있고 돈·주사위는 보상 마스터를 통해 읽습니다. 수령 계산과 실제 버튼·저장·지급 검수는 별도입니다.

(모두 임시 값)

## 간략

**머리표** 시스템 기획 · S05 · 팬덤 · 모노 F07 번영(LP) 이식(바꿔서 옮김 · 번영을 팬덤에 합침)

**제목** 팬덤 — 건물 9개에 나누는 팬이라는 기획과 도착 돈·대박 보상의 현재 참조 범위

**훅** 건물·아이돌을 키워 팬을 늘리고 건물 9개에 랜덤으로 나눠 수익을 키우는 원기획입니다. 현재 건물별 배정·팬 수익 계수는 대기이며, 배수의 문은 엔터 파워가 엽니다.

**두 줄 요약**
- 원기획의 팬 합 = 건물 9개에 나뉜 팬의 현재 합(악개 감산·비율 대기/합 포함은 당시 결정 기록 · 도시별 아님 · 시즌 누적 아님)입니다. 현재 HUD의 3층 합·수익 입력·독립시험 합은 다른 용도로 읽습니다. 모노 번영도는 따로 두지 않으며 배수 열림은 엔터 파워가 맡습니다.
- 원기획은 건물 규모·아이돌 능력 두 길의 팬 증가와 해당 건물 팬의 도착 수입·팬 합의 대박 보상을 설명합니다. 현재 코드에는 판정·팬반응 카드의 별도 계산/조건부 writer도 있고, 도착/잭팟 팬 항은 계수 대기입니다. 코드가 있다는 이유로 원정책을 새로 승인하지 않습니다.

```mermaid
flowchart LR
  A[건물 단계 오름 S04<br/>building_master_level.effect_fan_gain] --> F[팬덤<br/>기획사 전체 현재 팬 총합]
  B[아이돌 능력 오름<br/>idol_stat.fan_gain] --> F
  M[엔터 파워 문턱 = 배수 열림 dice_mult_unlock_rule]
  F --> I[도착 수입 · 대지 팬 S03]
  F --> J[대박 보상 = 통 + 팬 합 S03]
  F --> H[상단 숫자 HUD S06]
  S[시즌 끝 리셋 S09 · 보류] -.-> F
```

**그림 읽기:** 위 도식은 건물·아이돌을 중심으로 팬을 늘리는 원계획 방향입니다. 현재의 판정·팬반응 카드·조건부 writer와 배정/계수 대기는 본문에서 따로 구분하며, 이 그림을 전체 운영 연결 완료로 읽지 않습니다.

1. **는다** — 원기획은 시설 단계·아이돌 능력의 두 길입니다. 현재 판정·카드 계산, 건물 보정과 조건부 직접 증설 지급은 이 기획과 범위를 나눠 봅니다.
2. **모인다** — 팬을 건물 9개에 랜덤으로 나누는 기획입니다(균등인지는 발란스 대기). 현재 배정 함수는 placeholder이며 화면 팬 합과 같은 저장 정본이라고 단정하지 않습니다.
3. **연다** — 엔터 파워가 문턱을 넘으면 다음 배수가 열린다(팬이 여는 게 아니다).
4. **번다** — 해당 건물 팬과 팬 합으로 수익을 키우는 기획입니다. 현재 기본 수익·통 지급은 별도이고, 계수 공백은 팬 추가항 0이며 최종 계수 0 승인과 다릅니다.

| 왜 지금 | 이게 핵심 | 이게 아닌 것 |
|---|---|---|
| 모노 번영은 따로 두지 않고, 배수 열림 기준은 10/26 17:39 결정으로 엔터 파워가 됐다(14:05·17:42의 팬 총합 기준은 대체됨) | 원계획: 팬 합 = 건물 9개 팬의 합 · 두 길로만 는다 · 도착 돈과 대박 보상의 기준 **현재 읽기 범위:** 두 길·건물별 팬 합은 원계획이고 현재 HUD/판정·카드/수익 입력의 적용 범위는 구분합니다. | 새 게이지가 아니다 · 시즌 누적 점수가 아니다 · 도시별 숫자가 아니다 |
