<p><strong>보는 법</strong> 그림과 표로 노출 자리를 보고 <a href="../../%25EA%25B8%25B0%25ED%259A%258D%25EC%2584%259C/%25EC%2582%25B0%25EC%25B6%259C_%25EA%25B8%25B0%25ED%259A%258D%25EC%2584%259C_%25EC%258B%259C%25EB%2582%2598%25EB%25A6%25AC%25EC%2598%25A4%25EB%2585%25B8%25EC%25B6%259C_%25EC%2583%2581%25EC%2584%25B8_v1_%25ED%2581%25B4%25EB%25A1%259C%25EB%2593%259C.html">상세 책갈피 P239</a>에서 규칙과 예외를 확인합니다. 도착 판정과 휠은 <a href="../%25ED%2595%2584%25EB%259F%25AC%25EB%25A3%25B0%25EB%25A0%259B_v01/%25ED%2595%2584%25EB%259F%25AC%25EB%25A3%25B0%25EB%25A0%259B_%25EA%25B8%25B0%25ED%259A%258D%25EC%2584%259C.html">필러 룰렛</a>에서 봅니다.</p>
<p><strong>지금 상태</strong> 현재 개발되지 않음, 진행 중. 칸 도착 대사 한 줄은 표·계산·단독 미리보기와 대사 생성 작업대까지 만들었고, 실제 보드 도착 화면에는 아직 연결하지 않았습니다. 조우 장면·기록·멤버 서사 열기·관통 서사는 제작전입니다.</p>
