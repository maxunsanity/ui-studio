## 0. 한 줄 요약

**특정 레벨 이상 플레이어가 매주 뮤직·이미지·영상 창작물을 올리고, 조회·투표·공유·좋아요·후원을 합산한 점수로 순위를 매겨 Top 50에게 카드팩·주사위·골드를 지급하는 주간 서바이벌형 창작 리그.**

설계 목표 3가지:
1. **창작자에게 무대를** — 게임 밖 바이럴(공유)을 게임 안 보상으로 연결.
2. **관람자에게도 할 일을** — 투표·응원 자체가 일일 루틴이 되도록 투표자 보상.
3. **돈·봇이 이기지 않게** — 로그 정규화 + 지표 상한 + 어뷰징 필터.

## 1. 참여 자격 (레벨 게이트)

| 행동 | 조건(가안) | 이유 |
|---|---|---|
| 작품 **열람·좋아요** | 전 레벨 | 유입 장벽 최소화 |
| **투표** | Lv.5 이상 + 계정 생성 3일 경과 | 부계정 투표 1차 방어 |
| **공유** | 전 레벨 (점수 반영은 유효 유입만) | 외부 바이럴 |
| **후원** | Lv.10 이상 | 자전 후원 차단 |
| **작품 제출** | **Lv.20 이상** + 휴대폰 본인인증 1회 | 1인 1계정 · 제재 실효 |

- 참가 레벨 ≈ 1~2주 플레이 지점 권장.
- 레벨 도달 시 **리그 초대장** 연출(우편 + 팝업).

## 3. 제출 규정

### 3.1 부문

| 부문 | 예시 | 파일 스펙(가안) |
|---|---|---|
| 🎵 **뮤직** | 커버, 리믹스, 오리지널, 응원가 | mp3/wav · 최대 4분 · 30MB |
| 🖼️ **이미지** | 팬아트, 포토카드, 굿즈 시안, 4컷 | png/jpg · 장변 4096 · 10MB · 최대 4장 |
| 🎬 **영상** | 댄스 커버, 팬 MV, 숏폼 | mp4 · 9:16/16:9 · 최대 3분 · 300MB |

- 1인 주당 **부문별 1작, 최대 3작**. 순위=작품 단위, **보상=1인 최고 순위 1개만**.
- 필수 입력: 제목, 부문, 설명(200자), 소스 표기, **AI 사용 여부**.

### 3.2 검수·권리

- 공식 크리에이터 키트(일러스트·로고·MR) 권장.
- 자동 필터: 선정성/폭력, 오디오 핑거프린트, 중복 해시.
- 금지: 타사 IP·실존 아이돌 초상 무단, 도용, 혐오·비방.
- 홍보용 2차 이용 동의(명예의 전당·SNS). 저작권은 창작자 보유.

## 4. 점수 산정

### 4.1 유효 지표

| 지표 | 유효 기준 | 1인 제한 |
|---|---|---|
| 조회 | 음원·영상 5초+ / 이미지 상세 3초+ | 계정당 작품별 1일 1회 |
| 좋아요 | 로그인 좋아요 | 작품별 1회 |
| 공유 | 공유 링크 **유니크 유입** (클릭만 X) | 기기 1회 |
| 투표 | 무료 1일 3표 (Lv.30+ 4표) | 동일 작품 1일 1표 |
| 후원 | 응원봉(골드·유료) | 작품별 1일 상한 |

### 4.2 정규화 + 가중합

부문 안 로그 정규화 후:

```
N = ln(1+값) / ln(1+부문최댓값) × 100
점수 = (조회N×0.10 + 좋아요N×0.15 + 공유N×0.20 + 투표N×0.35 + 후원N×0.20) × 10
→ 만점 1,000
```

가중: 투표 35% · 공유 20% · 후원 20% · 좋아요 15% · 조회 10%.

후원 이중 장치: 로그 정규화 + 1인 후원은 작품 총 후원의 30%까지만 반영.

동점: ① 투표 ② 공유 유입 ③ 선제출.  
통합 Top 50. 쏠림 시 **부문별 최소 10석 쿼터** 옵션.

## 6. 어뷰징 — 「역공명 필터」

부계정 투표 · 봇 조회 · 품앗이 · 자전 후원 · 도용.  
제재: 경고→주 박탈→4주 정지→영구. Top50 정밀 검수 후 보상 확정, 박탈 시 승계.

## 7. 화면 구성 (요약)

- 리그 메인: 테마·마감·투표권 · 부문 탭 · 정렬 · 작품 카드
- 상세: 플레이어 + 좋아요/투표/공유/후원 · 댓글·신고
- 창작자 대시보드: 순위·지표 기여·50위 경계 추정 · 공유 링크 원탭
- 명예의 전당: 주차별 1–3 · 누적 Top10 크리에이터

## 8. 세계관 연동 (선택)

- 주간 테마 = 5감정 로테이션(사랑→용기→희망→공감→자유)
- 천음 게이지 공동 목표 → 전 서버 주사위 ×1
- 어뷰징 필터 네이밍 = 역공명
