# **0. 한 줄 요약**

팬 수치를 '10,000명' 같은 숫자 대신 씨앗→모종→새싹→봉오리→개화→희귀 개화의 생장 단계로 보여주고, 팬 행동(팬레터·팬샵·팬미팅·방송)을 물·비료·햇빛 같은 성장 재료로, 악플·스캔들·안티팬덤을 시듦·병충해·가시덩굴로 표현함. 여기에 이 IP 고유 문법인 봉합(솔기)을 얹어 '떠났다 돌아온 팬'에게 서사적 가치를 부여함.

**원칙: 팬 = 꽃이 아니라, 팬덤의 성장 상태 = 꽃. 팬의 정체는 끝까지 사람이며 꽃은 오버레이임.**

# **1. 왜 이 IP에 맞는가**

- **사상 정합 —** 천음=잇는 소리, 수호정령=봉합의 산물. 팬덤 역시 '이어져서 자라는 것'으로 같은 사상 위에 놓임.

- **토큰 정합 —** 5감정색(❤️🔥🌱🌊⚡)이 멤버별로 이미 고정돼 있어, 멤버별 꽃 종류 분화가 토큰 추가 없이 가능함.

- **서사 정합 —** 명성의 양면성(유명해질수록 위험 ↑ / 구원 ↑), S2 안티-팬덤 역공명, S3 '전 인류 합창'이 각각 정원의 번성·가시덩굴·전 세계 만개 비주얼로 그대로 이어짐.

- **기존 시스템 흡수 —** 팬레터·팬샵·팬미팅·팬덤 쉴드·팬덤 덱 등 이미 별도 시스템으로 존재하는 요소를 하나의 정원 언어로 묶음.

# **2. 성장 단계**

| **단계**           | **정의**                             | **유입/전환 트리거**                        | **UI 표현**      |
|--------------------|--------------------------------------|---------------------------------------------|------------------|
| 씨앗               | 막 유입된 관심층                     | 버스킹·오디션·방송 노출·숏폼 바이럴         | 작은 점, 무색    |
| 모종               | 팬이 되기 시작한 초기층              | 콘텐츠 1~2회 소비, SNS 팔로우, 첫 팬레터    | 연한 줄기        |
| 새싹               | 활성 팬                              | 스트리밍·응원 참여                          | 멤버색 잎 1장    |
| 봉오리             | 소비 팬                              | 굿즈·팬샵 소비, 팬미팅 참여                 | 멤버색 봉오리    |
| 개화               | 핵심·충성 팬                         | 쉴드 생성, 악플 방어, 앨범·콘서트 매출 기여 | 만개, 발광       |

|---------------|----------------|--------------------|----------------------------------------------------------------------------------------------------------------|
| 어우동 (센터) | 사랑 ❤️ red    | 장미, 모란         | 센터 정원 = 전체 정원의 중심 화단                                                                              |
| 논개          | 용기 🔥 flame  | 동백, 붉은 튤립    | 추운 데서 피는 꽃 = 두려움 속의 용기                                                                           |
| 이날치        | 희망 🌱 sprout | 해바라기, 민들레   | 꺼진 자리에서도 돋는 결 (잿불이 사상)                                                                          |
| 신사임당      | 공감 🌊 wave   | 수국, 물망초, 연꽃 | 물가 군락, 서로 기대어 피는 형태                                                                               |

# **4. 봉합 문법 적용 — 이 IP만의 비틀기**

> *일반 식물 메타포에 머물면 타 육성 게임과 구분되지 않음. 우동 고유값은 '솔기'임. 정원에도 끊긴 상처 → 아문 봉합의 문법을 그대로 적용함.*

## **팬 행동을 꽃의 “상태 변화”로 표현**

## 이게 핵심입니다. 꽃은 단순 장식이 아니라 **팬 행동의 UI 언어**가 되어야 합니다.

## **좋은 상태**

## **물 주기** = 콘텐츠 공급 / SNS / 라이브 / 팬소통

## **햇빛** = 무대 노출 / 방송 출연 / 명성 상승

## **비료** = 굿즈, 이벤트, 팬미팅, 시즌 패스

## **개화** = 매출 발생, 쉴드 생성, 바이럴 확산

## **나쁜 상태**

## **시듦** = 소통 부족, 휴식 과다, 공백기 장기화

## **병충해** = 악플, 스캔들, 안티팬 침투

## **잡초화** = 무관심층, 이탈 팬

## **가시덩굴화** = 안티팬덤, 팬덤 전쟁

## 기획서의 스캔들/악플/역공명/안티팬 요소를 “정원 훼손”으로 연결하면 훨씬 직관적

## 

## **4.1 시듦과 회복 = 상처와 솔기**

- 시든 꽃(소통 부족·공백기 장기화·이탈 직전)은 채도가 죽고 wd-ink-900 다크로 물듦 — '끊긴 상처' 상태.

- 회복 시 줄기에 보라(wd-dokkaebi-700) 솔기가 남음. 한 번 떠났다 돌아온 팬은 새 팬보다 귀하게 표시됨 — '흉터가 명예로운 흔적'(흉이 사상)의 게임적 구현.

- 솔기 팬은 이후 이탈 저항이 높고 쉴드 기여도가 높은 특수 팬층으로 별도 집계.

## **4.2 팬덤 쉴드 = 보호 꽃**

- 개화 팬 N명 이상이면 화단 가장자리에 보호 꽃이 생성됨. 색은 해당 멤버색 + 보라 아우라.

- 악플·스캔들 발생 시 팬 본체보다 보호 꽃이 먼저 소모됨. 소모된 자리는 빈 솔기로 남아 '지켜준 흔적'이 됨.

- 보호 꽃 수 = 현재 쉴드 내구도. 숫자 게이지 대신 꽃 개수로 직관화.

## **4.3 안티팬덤 = 가시덩굴 (색 분리 필수)**

- 무관심층 = 잡초, 이탈 팬 = 시듦, 안티팬덤 = 가시덩굴로 단계 구분.

- 가시덩굴 색은 보라(봉합색)와 반드시 분리함. 도감 문서 §5 미해결 항목 '보스 한기색(차단·격리) 신설'과 동일 토큰으로 묶을 것 — 청록/강철 회청 계열 권장. 게임과 애니 양쪽에서 '역공명'이 같은 색으로 읽히게 함.

- S2 팬덤 전쟁 = 두 정원의 경계에서 가시덩굴이 침투하는 연출로 직결.

# **5. 성장 재료 (기존 시스템 매핑)**

| **기존 시스템**                   | **정원 언어** | **효과**                                                       |
|-----------------------------------|---------------|----------------------------------------------------------------|
| 팬레터 / SNS / 라이브 / 팬소통    | 물            | 씨앗→모종, 모종→새싹 전환율 ↑, 시듦 방지                       |
| 방송 출연 / 무대 노출 / 명성 상승 | 햇빛          | 씨앗 유입량 ↑ (단, 명성이 높을수록 가시덩굴 유입도 ↑ = 양면성) |
| 굿즈 / 팬샵 / 시즌 패스           | 비료          | 새싹→봉오리 전환, 매출 발생                                    |
| 팬미팅 / 팬사인회                 | 개화 촉진제   | 봉오리→개화 전환, 희귀 개화 확률                               |
| 콘서트 (해방전)                   | 만개 이벤트   | 화단 전체 동시 개화 + 보호 꽃 대량 생성                        |
| 휴식 과다 / 공백기                | 가뭄          | 전 단계 시듦 진행                                              |
| 악플 / 스캔들                     | 병충해        | 보호 꽃 소모 → 이후 개화 팬부터 시듦                           |

# **6. 화면 구성 제안**

## **A. 팬덤 정원 탭**

- 전체 정원 뷰: 멤버별 5개 화단 + 중앙 센터 화단. 화단 크기 = 팬 총량, 색 밀도 = 개화율.

- 상단 지표 3종: 씨앗 유입률 / 개화율 / 이탈률.

- 솔기 팬 수·보호 꽃 수·가시덩굴 침투도를 부지표로 표시.

## **B. 팬 개체 표현**

- 팬은 작은 사람 실루엣, 머리 위 또는 어깨에 성장 단계 아이콘 오버레이.

- 충성 팬은 꽃 배지, 솔기 팬은 배지에 보라 스티치 테두리.

- 팬 커뮤니티는 실루엣 군집 + 꽃밭 바닥 레이어로 집합 표현.

## **C. 시즌 목표 연결**

- S1 12화 첫 천음 = 서울 정원 첫 만개.

- S2 월드 투어 = 도시별 정원 개척, 도시마다 가시덩굴 종류 상이(사천간부 군단 색).

- S3 전 인류 합창 = 지구 규모 전 세계 만개 비주얼. 팬덤=최종 무기 테마의 시각 귀결.

# **7. 주의 사항**

- **사람이 사라지면 안 됨 —** 팬 실루엣이 꽃으로 완전히 대체되면 S3 '전 인류 합창'이 정원 가꾸기로 축소됨. 꽃은 항상 오버레이·바닥 레이어로 유지.

- **색 규칙 불변 —** 멤버색은 그 멤버 팬덤에만. 보라는 봉합(회복·쉴드)에만. 안티는 별도 한기색. 세 계열이 섞이면 도감·애니와 어긋남.

- **수치 노출 —** 분포는 보여주되 정확한 전환 확률은 숨김. 정원은 '읽는' 화면이지 '계산하는' 화면이 아님.

# **8. 미해결 / 후속**

- 보스 한기색 토큰 신설 (디자인 스펙 추가 필요) — 가시덩굴 색과 공유.

- 꽃 종류 확정 — 문화권별 상징 충돌·상표 검토.
