# S11a · 출석 — 접속한 날의 주사위 받기

**이 문서는** 같은 날의 중복 수령을 막고, 이어서 접속한 날에 맞는 주사위를 받는 출석 흐름을 설명합니다.

**보는 법** 목차 → 입장과 받기 흐름 → 날짜·저장·시즌 경계 순서로 읽습니다. 출석은 [본편 도시맵](../../../game-prototype.html)의 로비와 상점에서 확인합니다.

**지금 상태** 개발됨. 출석 계산·팝업·로비 자동 진입·상점 입구가 연결되어 있으며, 실제 화면과 저장 실패·시즌 정책의 확인은 남아 있습니다.

## 1. 개요

출처: [HUD와 도시맵](../전체기획서/03_HUD도시맵_클로드.html) · [칸·상점·카드덱](S07_칸콘텐츠_상점_카드덱.md) · [상점](S07b_상점.md)의 출석 입구와 지급 경계를 함께 읽습니다.

출석은 접속한 날에 한 번 받는 상시 보상입니다. 플레이 행동으로 진행을 채우는 [미션](S11_미션.md), 일정 시간이 지난 뒤 받는 [상점 무료 선물](S07b_상점.md), [시즌 회차](S09_시즌틀.md)와 구분합니다.

```mermaid
flowchart LR
 A[로비 진입] --> B{오늘 받았는가}
 B -->|받음| C[로비 유지]
 B -->|아직 · 다른 창 없음| D[출석 팝업]
 D -->|닫기| C
 D -->|받기| E[수령 기록 · 공통 지갑 반영]
 E --> F[즉시 저장 요청 · 비행 · 알림]
 F --> C
```

## 3. 구동 방법·시뮬레이션

[본편 도시맵](../../../game-prototype.html)에서 로비로 들어갑니다. 오늘 받지 않았고 다른 창이 없으면 출석 창이 열립니다. 상점의 출석 버튼으로도 같은 창을 엽니다.

1. 연속 일수와 오늘 받을 기본 보상, 날짜별 보상 칸을 확인합니다.
2. 받기를 누르면 버튼을 잠그고 수령 기록과 공통 지갑을 갱신합니다.
3. 즉시 저장을 요청한 뒤 지갑 비행·수령 알림을 보여 주고 창을 닫습니다.
4. 같은 날 다시 열면 받기가 잠깁니다. 받지 않고 닫았다면 다음 로비 진입 때 다시 확인합니다.

다른 창이 열려 있으면 자동 출석 창을 겹쳐 열지 않습니다. 현재 직접 보드로 들어가는 진입 옵션은 로비 입장 확인을 거치지 않으므로, 로비가 없는 시작 화면까지 자동 노출된다고 보지 않습니다.

## 4. 상세 기획

### 날짜와 지급

| 규칙 | 현재 동작 |
|---|---|
| R-S11a-1 | 공용 게임 시각을 기기 로컬 날짜로 바꾸어 접속일을 판별합니다. 보드 굴림 수나 시즌 일차로 날짜를 대신하지 않습니다. 개발용 시각 이동은 공용 시각에 반영됩니다. |
| R-S11a-2 | 마지막 받은 날짜가 오늘이면 추가 수령을 막습니다. |
| R-S11a-3 | 마지막 받은 날짜가 어제이면 연속 일수를 늘리고, 그 외에는 첫날부터 받습니다. |
| R-S11a-4 | 보상표의 마지막 날짜를 넘기면 마지막 칸 보상을 계속 읽습니다. |
| R-S11a-5 | 출석 기본량을 공통 지갑으로 지급하고 출석 장부를 남깁니다. 굴림 배수를 출석에서 따로 곱하지 않습니다. |
| R-S11a-6 | 수령 상태를 반영한 뒤 즉시 저장을 요청합니다. 저장 요청과 저장 성공은 구분합니다. |

출석 표는 첫날부터 끊기지 않는 날짜 순서와 0 이상 정수 보상이어야 합니다. 맞는 날짜 행이 없거나 순서·값이 잘못되면 출석 표 오류로 처리합니다.

표의 오늘 보상은 기본 지급량입니다. 활성 공통 지급 보정이 있으면 공통 지갑에서 적용하므로, 출석에서 계산한 기본량과 실제 지갑 증가량을 대조해야 합니다. 출석 전용 보정값을 새로 만들지 않습니다.

### 창과 입구

| 규칙 | 현재 동작 |
|---|---|
| R-S11a-7 | 로비 진입 때 미수령 여부를 확인하고, 다른 창이 없으면 자동으로 엽니다. |
| R-S11a-8 | 오늘 이미 받았다면 로비 진입만으로 다시 열지 않습니다. |
| R-S11a-9 | 받지 않고 닫아도 수령으로 기록하지 않으며 다음 로비 진입 때 다시 확인합니다. |
| R-S11a-10 | 출석 창은 무료 선물·복귀 지급과 별도의 창입니다. |
| R-S11a-11 | 상점 출석 버튼은 같은 출석 창을 여는 보조 입구입니다. |

화면에는 제목, 연속 일수·오늘 기본량, 보상 날짜 칸, 받기, 닫기, 안내를 둡니다. 받은 칸·오늘 칸을 구분하며, 이미 받은 날의 받기 버튼은 잠깁니다. 표시 문장은 공용 UI 문구표를 읽습니다.

### 저장과 시즌 경계

| 규칙 | 현재 동작과 남은 확인 |
|---|---|
| R-S11a-12 | 출석 상태는 `live.attend.streak`와 `live.attend.lastDay`에 보관합니다. |
| R-S11a-13 | 현재 새 시즌 함수는 연속 일수와 마지막 받은 날짜를 비웁니다. |
| R-S11a-13b | 출석 소스는 이 동작과 기존 시즌 시간층 기획의 차이를 표시하고 있습니다. 최종 이월 정책으로 임의 통일하지 않고 [시즌 틀](S09_시즌틀.md)과 함께 확인합니다. |

저장 공간 문제 등으로 쓰기에 실패하면 저장기는 오류를 남기고 미저장 상태를 유지합니다. 출석 화면의 즉시 저장 요청만으로 새로고침 후 보존이나 실패 때의 중복 방지가 확인됐다고 판단하지 않습니다.

### 수락 기준

같은 날 중복 수령 차단, 날짜별 보상 공급, 로비와 상점의 같은 창 연결, 미수령 닫기, 저장 성공·실패 경계를 실제 화면과 저장 원본에서 각각 확인합니다. 코드 읽기를 플레이 검수나 정책 승인으로 바꾸지 않습니다.
