<section class="part" id="part-1"><h2>1. 개요</h2>

<p>출처: (합침) <a href="/docs/planning/proposal-concept/audition.html" data-paper-path="docs/planning/proposal-concept/audition.html">오디션 제안서</a>, 후보 생성·이야기 조합 소스와 이름·성격·배경 표.</p>

<p>새 진행을 준비할 때 후보 묶음을 만듭니다. 후보마다 고유 ID와 이름·성격·재능·처음 능력·배경·이야기가 함께 생기며, 같은 진행에서 다시 만날 때 별개의 사람을 새로 만들지 않습니다. 후보 수·초기 범위와 가중치는 현재 실행의 임시값으로 <b>발란스 대기</b>입니다.</p>

</section><section class="part" id="part-3"><h2>3. 구동 방법·시뮬레이션</h2>

<p>화면 흐름: 오디션 시작 → 후보 만남·소개 → 선택과 합류 → 메인·성장 → 공통 인물정보. 이번 문서 작업에서 새 실행·화면 캡처는 하지 않았습니다.</p>

<p><b>멤버 이야기 텍스트 미리보기</b>는 인물을 새로 조합해 배경과 소개, 성장 0~4 단계의 이야기, 마지막 회고를 한 번에 읽어 보는 기획 확인 도구입니다. 이야기의 흐름과 문장 조합을 살펴보는 용도이며, 여기서 읽는 것만으로 실제 게임의 성장 단계나 이야기 해금, 저장 내용이 바뀌지 않습니다. <a href="/docs/planning/member-story-preview.html" data-paper-path="docs/planning/member-story-preview.html">멤버 이야기 텍스트 미리보기 열기</a>. 실제 실행 화면 확인은 현중이 직접 할 예정입니다.</p>

<h3 id="오디션-시뮬레이터-열기"><a href="/docs/planning/game-simulator.html?module=simulator_module_audition" data-paper-path="docs/planning/game-simulator.html">▶ 오디션 시뮬레이터 열기</a></h3>

<ol>
<li>새 진행을 시작하면 실행 설정의 후보 수만큼 한 묶음을 만듭니다. 같은 진행을 다시 열면 후보와 기존 선택 기록을 이어 봅니다.</li>
<li>후보 소개에서 이름·성격·배경과 원본 이야기의 일부를 읽고 명함·패스·캐스팅을 선택합니다.</li>
<li>대진 또는 직접 캐스팅으로 합류한 후보는 같은 후보 ID와 생성 자료를 성장 화면에 전달합니다.</li>
<li>공통 인물정보에서 검증된 현재 성장 단계에 맞는 이야기를 봅니다. 시험용 단계 선택은 실제 승급이 아닙니다.</li>
</ol>

<p>화면별 전달 범위는 구분합니다. 현재 보드용 변환은 소개와 <code>step_0</code>~<code>step_4</code>를 전달하며 프롤로그·에필로그를 그 목록에 새로 넣지 않습니다. 생성 멤버의 전체 <code>story</code>는 합류 자료에 따로 담기고, 정보창은 확인된 공개 조건으로 조회합니다. 전체 서사 생성과 모든 화면의 같은 장 공개를 동일한 완료 범위로 보지 않습니다.</p>

<p>이 도구에서는 인물을 새로 조합한 뒤 그 인물에게 붙은 배경을 확인하고, 소개부터 성장 0~4 단계와 마지막 회고까지 이어서 읽습니다. 이야기가 같은 배경과 경험을 자연스럽게 이어 가는지, 빠지거나 어색한 문장이 없는지 살펴보는 데 사용합니다.</p>

<p>미리보기는 실제 게임에서 성장 단계를 올리거나 잠긴 이야기를 해금하는 조작이 아닙니다. 생성해서 읽어 본 인물을 실제 진행의 멤버나 저장 기록으로 바꾸지도 않습니다. 실제 공개 여부는 게임의 현재 멤버와 성장 단계에 따라 별도로 판단합니다. 미리보기 화면은 만들어졌으며, 실제 실행 화면 확인은 현중이 직접 할 예정입니다.</p>

<h3 id="필요-시스템">필요 시스템</h3>

<p>오디션은 후보 생성기에 시드·후보 수·원본 표를 전달하고 생성된 후보와 배경·이야기를 오디션 자료로 연결합니다. 후보 생성기는 시드 난수, 이름·프로필 목록, 성격·배경 연결, 18세부 능력·재능, 서사 틀, 후보 저장과 전달이 필요합니다. 표의 빈 값에 생성기 임시 설정을 쓰는 경우에는 출처와 발란스 대기를 남깁니다. 실제 관계 쌍이나 포지션 규칙이 아직 부족한 값은 완성된 결과로 바꾸지 않습니다.</p>
