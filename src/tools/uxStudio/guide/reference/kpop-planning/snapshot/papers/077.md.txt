## 이게 뭐냐

**주사위를 굴리고 말이 움직이는 동안 화면이 어떻게 되는지.** 착지 전까지.

## 왜 정해야 하나

하루에 수십 번 보는 화면이다. **여기가 이 게임의 손맛**이고, 남한테 보여줄 때 제일 먼저 보이는 것이기도 하다.

---

## 세 게임의 자리

| | 모노폴리 GO | 모노카피바라 | 우리 |
|--|-------------|--------------|------|
| 판 | **항상 보임** (링 전체) | **숨김.** 찾기 때만 올라옴 | **항상 보임** (얼굴) |
| 보여주는 범위 | 링 전체 + 카메라가 따라감 | **앞 12칸만** | ? |
| 이동 | 말이 칸을 따라 튐 | 워커가 시트 위를 감 | ? |
| 착지 후 | 카드 | 시트 내려가고 무대만 | 아래 패널 |

---

## 시안 A · 말이 판 위를 돈다 (GO 그대로)

```
판은 늘 보인다 → 주사위 → 말이 칸마다 통통 튀며 이동 → 멈춤
```

| 좋은 점 | 나쁜 점 |
|---------|---------|
| 익숙하다. 설명이 필요 없다 | **40칸이 작아서 지나가는 칸이 안 보인다** |
| 판이 얼굴로 계속 남는다 | 12칸 지나가면 그냥 빨리 감기처럼 보인다 |
| 만들기 제일 쉽다 | 우리만의 것이 없다 |

---

## 시안 B · 앞길 띠 (모노 그대로)

```
판 위에 앞 12칸이 띠로 깔린다 → 워커가 좌에서 우로 → 착지하면 띠가 접힌다
```

| 좋은 점 | 나쁜 점 |
|---------|---------|
| 지나가는 칸이 **하나씩 읽힌다** | 띠가 판을 가린다 |
| 모노에서 검증됨 | 모노는 판이 숨어 있어서 되는 방식이다 |
| | **우리 얼굴(40칸)을 덮는다** |

---

## 시안 C · 스케줄표가 넘어간다 ★ 추천

**이동 = 날짜가 지나가는 것.**

```
판은 늘 보인다
   ↓ 주사위
위쪽에 날짜 띠가 뜬다        9/12 · 9/13 · 9/14 …
   ↓ 좌에서 우로 흐른다
지나가는 날마다 한 줄이 스친다   "연습" · "연습" · "사녹 대기"
   ↓ 동시에 판 위 말도 간다
멈춘다 → 그 날짜가 오늘이 된다
   ↓
아래 패널에 오늘이 펼쳐진다
```

| 좋은 점 | 나쁜 점 |
|---------|---------|
| **보드가 아이돌 스케줄이라는 컨셉이 연출로 증명된다** | 만들 게 조금 많다 |
| 지나간 칸이 **"그날 뭘 했는지"** 로 읽힌다 | 날짜 개념을 확실히 정해야 한다 |
| 판을 안 가린다 (띠가 위에 얇게) | |
| **사옥의 「하루 +1」이 자연스럽게 붙는다** | |
| 시즌 3개월이 **매번 체감된다** | |
| GO에도 모노에도 없다 | |

**왜 추천하나**

우리 판은 부동산이 아니라 **일정표**다. 그런데 지금 이동은 그냥 말이 도는 것뿐이라, **판이 일정표라는 게 연출에서 안 보인다.**

날짜가 흐르면 세 개가 한 번에 붙는다.
- 사옥(1) 통과 = **하루가 넘어감** ([069](./069_사옥.md))
- 시즌 = **3개월** ([065](./065_시즌구조.md))
- 스케줄 변경(8·23·38) = **일정표가 흔들림** ([033](/docs/planning/_이전기획_보관/20261016/033_스케줄변경_상태연동.md))

지금은 이 셋이 문서에만 있고 화면에 없다.

---

## 시안 D · 팬 앱 타임라인

**빠순이가 보는 화면으로.** 위에서 아래로 일정이 흐르는 팬 앱.

```
타임라인이 위→아래로 흐른다
   ↓
오늘 일정에 멈춘다
   ↓
아래에 그 칸의 두 줄이 붙는다
```

| 좋은 점 | 나쁜 점 |
|---------|---------|
| **팬 앱 감각이 화면 구조가 된다** | **판이 사라진다.** 우리 얼굴이 일정 보드인데 |
| 앱 감각이 진짜 덕질 같다 | 40칸이 어디 갔는지 모르게 된다 |

→ 이동 연출로는 안 맞고, **나중에 다른 화면**(활동 미션·파견)에서 쓸 만하다.

---

## 한때 추천했던 C + A (보류)

날짜 띠를 판 위에 얇게 올리는 안. **나쁘지 않지만 2순위로 내린다.** 띠는 글씨라서 화면이 심심하고, 엔터 게임 느낌이 안 난다.
날짜가 흐르는 감각 자체는 살린다 — 아래 E의 도착 태그에 날짜를 붙이면 된다.

---

## 시안 E · 밴 이동 ★ 확정

**이동 = 밴을 타고 다음 스케줄로 가는 것.** 아이돌이 하루를 어떻게 보내는지 그대로다.

### 이름

| 모노폴리 GO | 모노카피바라 | 우리 |
|-------------|--------------|------|
| (없음 · 판 위에서 말만 튄다) | 보드 시트 슬라이드 | **연출 공간** (위) |
| (없음) | (없음) | **필러 공간** (아래) |
| 주사위 굴림 | 주사위 굴림 | 주사위 굴리기 |

- **연출 공간** — 밴이 어디 있는지 보여주는 칸. 화면 맨 위.
- **필러 공간** — 주사위가 도는 칸. 연출 공간 바로 아래, 보드 바로 위.

### 순서

```
주사위 굴리기 누름
   ↓ 1초   [필러 공간]  주사위가 링을 돌며 회전 중
   ↓ 1초   [연출 공간]  밴 창밖 야경이 흐른다 · "이동 중 · N칸"
   ↓       [연출 공간]  한 번 번쩍 → 도착한 곳의 밴 사진으로 배경이 바뀜
           [보드]       그 칸이 켜지고 아래 패널이 열린다
```

### 도착 배경 세 가지

밴이 어디에 서 있느냐 = 그 칸이 어떤 자리냐.

| 배경 | 어떤 칸일 때 | 그림 |
|------|--------------|------|
| **아레나 앞** | 초록(공연) 3급 이상 · 노랑(방송) 해외방송 | 무대 앞에 선 밴 |
| **지방 도로** | 초록 저급(버스킹·대학가) · 개인 시간 · 멤버 시간 · 본가 | 시골길 달리는 밴 |
| **홍대 밤** | 나머지 서울 일정 전부 | 밴 창밖 도시 야경 |

**보드가 성장하면 같은 칸이라도 배경이 올라간다.** 버스킹 칸이 아레나까지 크면 지방 도로가 아레나 앞으로 바뀐다 → [062](./062_보드성장.md)

### 왜 이걸로 갔나

| | |
|--|--|
| **엔터 게임 얼굴이 된다** | 부동산이 아니라 밴·스케줄·무대다. 한 화면만 봐도 무슨 게임인지 안다 |
| **판을 하나도 안 가린다** | 두 칸 다 보드 위쪽에 따로 있다 |
| **기다리는 1초가 심심하지 않다** | 필러 공간이 그 1초를 먹는다. 모노·GO엔 이 칸이 없다 |
| **보드 성장이 눈에 보인다** | 급이 오르면 배경 사진이 바뀐다 |
| **시즌 교체가 쉽다** | 밴 데칼과 배경만 갈면 된다 → [049](./049_시즌_아이돌교체.md) |

---

## 안 정한 것

- 한 칸 = 하루인가, 몇 칸이 하루인가 (도착 태그에 날짜를 붙일지)
- 지나간 칸을 이동 중에 보여줄지 (지금은 안 보여준다)
- 배수 굴림·연속 굴림일 때 1+1초를 줄일지
- 빨리 감기·스킵
- 필러 공간에 주사위 말고 다른 것도 돌릴지 (응원봉·포카)

## 하지 않음

- 판을 숨기기 (모노 방식 — 우리 얼굴이 판이다)
- 연출·필러 두 칸이 판을 덮기
- 이동 중에 착지 결과를 미리 보여주기
- 밴 안에 아이돌 얼굴 넣기 (시즌마다 다시 그려야 한다)
