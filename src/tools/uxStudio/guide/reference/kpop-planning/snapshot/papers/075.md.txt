## 이게 뭐냐

**일정 보드 40을 기획 쇼케이스로 만든다.**
칸을 누르거나 아래 콘텐츠를 누르면, 지금까지 정한 기획이 **UI와 연출로** 뜬다.

## 언제 쓰나

남한테 보여줄 때. 그리고 **커서한테 넘길 때** — 화면이 곧 기획서다.

---

## 한 줄

**누르면 기획이 보인다. 플레이는 없다.**

## 화면 네 단

왼쪽은 인게임(밴만 · 얼굴 없음). 오른쪽은 일정 보드와 설명.

```
┌──────────────┬──────────────────────────┐
│ ① 왼쪽 폰   │ ② 일정 보드 40칸             │
│ 밴 연출      │ 지금 그대로               │
│ 주사위 필러  │                          │
│              ├──────────────────────────┤
│              │ ③ 도착한 칸의 효과        │
│              │ 지금 그대로 (판정·보상)   │
│              ├──────────────────────────┤
│              │ ④ 콘텐츠 목록            │
│              │ 인게임 + 나머지 여섯      │
└──────────────┴──────────────────────────┘
```

---

## ① 왼쪽 폰 — 연출 (밴만 · 얼굴 없음)

**칸에 도착했을 때 화면이 어떻게 되는지.** 왼쪽 크림색 폰 안에 밴만 넣는다. 아이돌 얼굴은 안 그린다.

| 들어가는 것 | 내용 |
|-------------|------|
| **착지 순서** | 주사위 → 이동 → 착지 → 무엇이 먼저 뜨나 |
| **화면 구성** | 그 순간 화면에 뭐가 보이나 (배너 · 카드 · 패널) |
| **연출 의견** | 어떤 느낌이어야 하나 · 얼마나 크게 |

칸 종류마다 다르다.

| 칸 종류 | 착지하면 |
|---------|----------|
| **무대 칸** (노랑·초록) | 등급 배너 → **그날 무대 카드** → 코인. 대박이면 한 급 위 무대 이름이 크게 |
| **결과 칸** (연습·합숙·팬·자유·생활) | 등급 배너 → 준비도가 오르는 게 보임 (컨디션·기량·케미) |
| **팬덤 게이트** | **전용 화면**으로 넘어감 — 이중 롤(등급 × 딱지/어부지리) |
| **총공** | 주간 팀 상자 진행 |
| **스케줄 변경** | 카드 한 장 뽑기 |
| **회사 칸** | 코인이 나가는 짧은 컷 |
| **사옥** | 한 바퀴 — 코인 + **하루가 넘어감** |

**그리고 판이 바뀌는 순간**은 여기서 따로 크게 다룬다 → [063 연출](./063_보드성장_연출.md)
칸 이름이 바뀌는 그 한 컷이 **GO에 없는 기능**이라 제일 크게 보여야 한다.

## ② 중단 — 일정 보드 40칸

**지금 그대로.** 다만 칸 위에 보이는 게 늘어난다.

| 추가 | 무엇 | |
|------|------|--|
| **응원봉** | 칸 **왼쪽 아래**에 막대로 켜진다. 5개면 **물결** — 칸 테두리가 분홍으로 뛴다 ([062](./062_보드성장.md)) | ✅ |
| 시선 토글 | 둘 다 / 엔터 / 빠순이 | ✅ 원래 있던 것 |
| **급 배지** | 노랑·초록 칸 **오른쪽 위**에 「2급」. 나머지 색엔 안 붙는다 | ✅ |

**응원봉이 켜지는 칸은 무작위다.** 고를 수 없다 — GO가 집을 고르지 않는 것 그대로 ([D-036](../../DECISIONS.md)).

---

## ③ 하단 — 도착한 칸의 효과

**지금 그대로.** 판정과 보상이 나오는 자리. 다만 빠진 게 있다.

| 지금 있음 | 더 넣을 것 | |
|-----------|-----------|--|
| 칸의 두 줄 (아이돌은 / 나는) | **여기서 열리는 덕질** — 그 칸에 열린 항목만 (밥차·슬로건·전광판…) | ✅ |
| 모노폴리 GO에서는 | **색 칩** — 이 칸을 덕질하면 차는 색 · 지금 몇 / 10 | ✅ |
| 대박·중박·운망 풀 | **준비도** — 이 칸이 올리는 것. 무대 칸은 「안 줌 · 코인만」 | ✅ |
| 성장 사다리 | **안 정한 것** — 이 칸에 남은 것 | ☐ 아직 |

**양식은 전 칸 똑같이.** 순서가 항상 같아야 읽기 빠르다.
**아이돌 일정 22칸에만 붙는다.** 정산·미팅·병가·코너·게이트엔 안 붙는다 — 거기선 덕질을 안 하니까.

### 이 칸이 올리는 준비도 ([D-033](../../DECISIONS.md))

| 칸 | 올리는 것 |
|----|-----------|
| 연습 8 | **기량** |
| 합숙 2 | **케미** |
| 자유시간 2 · 생활 거점 2 | **컨디션** |
| 팬 일정 2 | **서사 조각** |
| **방송 3 · 공연 3** | **안 줌 — 코인만** |

## ④ 최하단 — 콘텐츠 목록

**지금 걸 「인게임」이라고 부른다.** 이 보드 전체가 인게임이다.
그 아래에 나머지 여섯을 **작게** 깐다.

```
[ 인게임 ]                                  ← 지금 보고 있는 이것

  일정 보드 · 덕질 · 활동 미션 · 입덕      ← 작게
                              └ 원정 · 총공   ← 입덕을 누르면 펼쳐진다
```

**입덕이 상위 집이다.** 그 아래 원정·총공이 들어간다 ([081](./081_입덕_전면기획.md)).

### 원래 이름을 같이 적는다

헷갈리지 않게 **모노카피바라 이름**을 옆에 작게 붙인다.

| 우리 | 모노카피바라 원래 이름 | 문서 |
|------|------------------------|------|
| **인게임** | 보드 · 40칸 루프 | [056](./056_보드_컨셉.md) |
| 일정 보드 | 보드 도전 | [056](./056_보드_컨셉.md) |
| 덕질 | 건설 | [059](./059_덕질_개요.md) · [061](./061_덕질_6단_물량.md) |
| 활동 미션 | 미션 | [072](./072_활동미션.md) |
| **입덕** | **모험** (상위 집) | [081](./081_입덕_전면기획.md) |
| ├ 원정 | 여정 | [070](./070_투어.md) |
| └ 총공 | 출동 | [071](./071_파견.md) |

> 옛 이름(투어 · 파견 · 커리어 시즌)은 **2026-09-18에 갈았다.** 042는 아직 옛 이름이라 다시 써야 한다.

누르면 **그 시스템 기획이 ③ 자리에 뜬다.** 칸을 누른 것과 같은 자리를 쓴다.

## 효과 셋

| 효과 | 언제 | 어떻게 | |
|------|------|--------|--|
| **색 칩이 찬다** | 덕질할 때 | 보드 아래 **색 칩 8** 막대가 오르고, **10개면 터진다** | ✅ |
| **응원봉이 켜진다** | 덕질할 때 | **무작위** 칸에 하나. **5개면 물결** | ✅ |
| **이름이 바뀐다** | 급이 오를 때 | 옛 이름에 줄 → 새 이름이 찍힘. **제일 크게** ([063](./063_보드성장_연출.md)) | ✅ 원래 있던 것 |

**칩 10개가 터지면 무슨 일이 나나** ([D-026](../../DECISIONS.md))

| 색 | 터지면 |
|----|--------|
| **노랑 10** | **방송 칸 하나**가 한 급 — **무작위로 고른다** |
| **초록 10** | **공연 칸 하나**가 한 급 — **무작위로 고른다** |
| 나머지 6색 10 | 코인 · 주사위 · 서사 조각 |

패널의 **「덕질 한 번」** 버튼이 이 셋을 한 번에 보여 준다 — 덕력 +1 · 색 칩 +1 · 무작위 칸에 응원봉 1개.
**덕질은 상시다.** 칸에 착지해야 하는 게 아니다 ([D-019](../../DECISIONS.md)).

**대박 연출이 이름 바뀌는 연출보다 크면 안 된다.** 대박은 그날 한 번이고 성장이 아니다.

## 안 하는 것

- 주사위 굴리기 · 실제 플레이
- 수치·밸런스 보여주기
- 판이 **자동으로** 바뀌기 (버튼으로만)
- 칸마다 다른 양식 (전 칸 같은 순서)
