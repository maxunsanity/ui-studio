## 모노카피바라와의 거리

**이 드라이브 묶음 중 게임 메카닉이 가장 가깝다.**  
참조에 **피크민 · 모노폴리 GO** 명시. 코어가 `주사위 보드 → 카드 수집 → 탐험 파견(여정/발견)`.

| Prism Hunt | 모노카피바라(현 뼈대) | 비고 |
|---|---|---|
| 보드게임(주사위) | Cap×Mono 64칸·2d6·배수 | 같은 축 |
| 카드 수집 | 9×12 앨범 · 원정/여정/출동 얼굴 | 같은 축 |
| 여정(Journey) 협동 | 던전 여정(보내기·대기·엽서) | 매우 유사 |
| 발견(Discovery) 솔로 | 원정·출동과 역할 겹침 가능 | 경계 정리 필요 |
| AI 서사 자동 생성 | 엽서·필러 시나리오(조각→AI 훅) | 톤·범위 다름 |
| 시즌 랭킹 | 타이쿤·카드시즌·앨범(ID 분리) | 합치지 말 것 |

## 한 줄
> 내가 모은 아이돌과 몬스터의 조합으로 탐험을 보내면, AI가 세상에 단 하나뿐인 소설·영상·일러스트를 만들어 준다.

## 코어 루프
```
[보드게임(주사위)] → [카드 수집] → [탐험 파견(여정/발견)]
        ↑                                    ↓
[시즌 랭킹] ← [보상] ← [AI 서사 자동 생성]
        ↑                                    ↓
[새 그룹·빌런 해금]        [SNS·플랫폼 2차 활용]
```

## 탐험 이분법
- **여정(Journey):** 협동형 — 일반 / 정기 / 스페셜
- **발견(Discovery):** 솔로 파견
- 여정은 앱 종료 후에도 백그라운드 진행

## 차별화 3축 (요지)
1. 캐릭터×던전×프롬프트 조합으로 서사 재플레이 폭이 큼  
2. 빌런 봉인·흡수 → 아군 파워업  
3. 유저 AI 콘텐츠가 IP 2차 창작으로 역류

## 6대 원칙 (요지)
인기 IP · 시즌제(카드 시즌≈3개월) · AI 이벤트 내장 · 3탭(고르기→보내기→결과) · 자동 경쟁(명시 PvP 없음) · 콘텐츠 순환

## 장르 포지션 (원문 표 요지)
수집(성급×진화×속성) · 탐험(피크민·모노폴리 GO) · AI 서사 · K-pop 트랜스미디어 IP
