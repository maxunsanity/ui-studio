# 📄 1장 · 왜 이 조사를 했나

> **"서비스의 성공은 디테일이다"** — 대표, 2026-09-18 회의

아이돌 하나를 성공시키는 데 **실제로 얼마가, 어디에** 드는지 모르면
게임의 **칸 배치와 비용 비율을 근거 없이** 잡게 된다.

**조사 목적 셋**
1. 비용의 **종류와 비율**을 안다
2. 그 비율을 **우리 40칸에 맞춰 본다**
3. 안 맞는 곳을 **찾아낸다**

# 📄 4장 · 나가는 돈 — 비용의 종류와 비율 ★

**대표가 물은 그것.** 데뷔 앨범 1회 활동 기준 · **중소 규모 · 합 약 3.6억**

| 항목 | 금액 | 비율 |
|------|-----:|-----:|
| **프로모션 · 바이럴** | 1억 ~ 2억 | **28%** |
| **뮤직비디오** | 6,000만 ~ 1억 | **22%** |
| **곡 · 녹음** | 6,000 ~ 8,000만 | **19%** |
| **의상** | 약 6,000만 | **17%** |
| **스타일링** (헤어·메이크업 2개월) | 약 3,200만 | **9%** |
| **안무** (A급) | 1,000만 | **3%** |
| **재킷 촬영** | 1,000만 | **3%** |

> ⚑ **비율은 보도된 금액의 중간값으로 우리가 계산한 것이다.**
> 회사가 공개한 비율표가 아니다. PPT에 쓸 때 이 단서를 꼭 붙여야 한다.

**더 잘게**

| | |
|--|--|
| 외부 작곡가 곡값 | 3곡에 약 **1,500만** |
| 녹음 | 약 **1,200만** |
| 스타일리스트 | 월 **1,000만** |
| 헤어숍 | 월 **600만** |
| 바이럴 마케팅 | 약 **1억 500만** |
| MV 1편 (촬영+후반+사진+의상+미용+안무 **합산**) | **1억 5,000만 이상** ⚑ |

> ⚑ **MV가 두 가지로 보도된다** — 촬영만 6,000만~1억 / 부대비용 합산 1.5억.
> PPT에는 **"촬영 6천~1억 / 부대 포함 1.5억"**으로 나눠 적는 게 안전하다.

# 📄 7장 · 정산 — 왜 데뷔해도 돈이 안 들어오나

```
모든 수입은 기획사가 먼저 받는다
   ↓ 유통 수수료 · 저작권료 · 실연료 공제
   ↓ 회사가 투자 원가를 먼저 회수
남은 것을 아티스트와 나눈다
```

| | |
|--|--|
| 초기 배분 | **1/N**로 협의 → 연차가 쌓이면 **슬라이딩 시스템** |
| 데뷔 초반 | 회사가 **더 높은 비율**을 가져간다 |
| **"첫 정산을 받았다"** | = **회사가 투자금 회수를 끝냈다**는 뜻 |
| 실제 사례 | *"데뷔 후 3년 동안 정산 20만원"* |

> **우리 게임의 정산 칸(5 · 40)이 왜 아픈지가 여기서 설명된다.**
> 모노폴리 GO의 세금은 이유가 없다. 우리는 **"회사가 원가를 먼저 가져간다"**는 현실이 근거다.

# 📄 9장 · 그래서 우리 판은 — 맞은 것 / 안 맞는 것

## ✅ 맞았다

| 현실 | 우리 판 |
|------|---------|
| **연습생 육성이 제일 큰 덩어리** (2년 10억) | **연습 8칸 = 판의 1/3.** 근거 없이 잡았는데 현실과 맞는다 |
| **회사가 원가를 먼저 회수** | 정산 칸(5·40)이 **왜 아픈지**의 근거가 생겼다 |
| **굿즈가 콘서트보다 큰 매출** | *"게임에 나오는 거 전부 다 팔 거예요"*가 **업계 구조 그대로** |
| **14.9억 → 431억, 30배 격차** | 우리 급 사다리가 **정확히 이 격차를 건넌다** |

## ⚠ 안 맞는다 — 고쳐야 할 것

| # | 무엇 | 현실 |
|---|------|------|
| **①** | 덕질 12항목에 **의상·스타일 계열이 없다** | 비용의 **26%** |
| **②** | 프로모션(붙이기·찍어주기)이 **제일 비싼 항목이 아니다** | 비용의 **28%로 1위** |
| **③** | 40칸에 **굿즈가 없다** | 매출의 **22~25%** |

# 📄 11장 · 이 숫자를 어떻게 쓸 것인가

개발 동료의 이견을 같이 둔다.

> *"그건 **엔터사 입장의 디테일**이고, 빠순이는 엔터가 쓰는 돈이나 비용 구조는 관심사가 아니다."*

**맞는 말이다.** 그래서 이렇게 가른다.

| 화면에 보이는 것 | 뒤에서만 쓰는 것 |
|------------------|------------------|
| **공연장 관객 수** (200 → 2,000 → 18,000) | 비용 비율 · 정산 로직 |
| 코인이 나가고 들어오는 것 | 원가 회수 순서 |
| *"표를 사야 볼 수 있게 됐다"* 같은 **조각** | 431억 대 14.9억 |

> **숫자는 칸 배치의 근거로 쓰고, 화면에는 감각만 내보낸다.**
