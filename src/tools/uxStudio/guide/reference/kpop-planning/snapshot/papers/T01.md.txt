# T01 · 로컬 서버 브라우저

작성: 별도 UI 개발(단이, codex) · 2026-11-04 · 제안(검수 대기)

## 01 개요

로컬 개발 서버·웹 도구·CLI 작업을 한 macOS 창에서 확인합니다. 이번 변경은 웹 파일 캐시 비우기, 루틴 관리 제거, 왼쪽 목록 가독성과 검색·접힘 개선입니다. 기존 프로젝트 목록과 웹 저장을 보존합니다.

## 02 필요 관련 시스템 기획서

이 문서는 macOS 앱의 공용 정본입니다. 공통 기준은 [S17](../시스템기획/S17_기획서툴_제작기본양식_v02.md)을 참조합니다. 서버와 등록 정보는 Backend.swift, 웹 동작 연결은 UI.swift, CLI는 CLISessions.swift·CLISessionUI.swift에서 확인합니다.

현재 버전에서 루틴 관리 기능을 제거했습니다. 이전 정책·코드·확인 기록은 Archive/20261104-routine-removal과 공용 백업에 보존하며 현재 실행 규칙으로 사용하지 않습니다.

## 03 구동 방법·화면 확인

설치본은 /Users/max/Applications/로컬 서버 브라우저.app입니다. max 폴더 바로가기로 같은 앱을 엽니다. 등록 프로젝트를 선택하면 해당 로컬 페이지를 표시합니다.

상단 캐시 비우기 또는 보기 → 웹 파일 캐시 비우기(⌘⌥E)를 누릅니다. 완료 안내 후 최신 파일이 필요할 때 새로고침(⌘R)을 누릅니다. 캐시 비우기 자체는 웹뷰를 다시 불러오지 않습니다.

검색에는 이름·주소/포트를 입력합니다. 기타 프로젝트와 발견한 포트의 접힘은 목록 표시만 바꾸며 현재 페이지를 바꾸지 않습니다.

## 04 상세 기획

| 기능 | 처리 | 보존 |
|---|---|---|
| 캐시 비우기 | WebKit memoryCache·diskCache만 삭제합니다. 완료 후 중복 잠금을 해제합니다. | 프로젝트 JSON·쿠키·local/sessionStorage·IndexedDB·FetchCache·Service Worker 저장을 유지합니다. |
| 수동 새로고침 | 버튼·⌘R에서 현재 페이지를 다시 읽습니다. | 파일 변경으로 진행 중 화면을 자동 갱신하지 않습니다. |
| 등록 목록 | 그룹 카드·등록/실행 개수·이름/포트 검색을 제공합니다. | 기존 UUID·이름·폴더·주소·명령·순서를 보존합니다. |
| 목록 접힘 | 기타·발견 포트를 접고 펼칩니다. 검색 중 결과만 펼칩니다. | 검색 해제 후 원래 접힘과 현재 웹 선택을 유지합니다. |
| 웹·모바일 | 보기·배율·양쪽 주소 이동 동기화를 제공합니다. | 캐시 비우기에 저장 초기화를 섞지 않습니다. |
| CLI | 목록·지원 Terminal 내용/원창/명시 입력을 제공합니다. | 기존 작업에 자동 입력·중단하지 않습니다. |
| 루틴 관리 | UI·store·타이머·발신 코드의 실행본 연결을 제거합니다. | 과거 설정·요청·ACK는 삭제하지 않습니다. |

캐시 처리는 WebCache.swift에 분리합니다. allWebsiteDataTypes()나 앱 데이터 폴더 삭제를 사용하지 않습니다. 서버 상태 확인용 URLSession과 웹 파일 캐시를 구분합니다.

목록은 SidebarPresentation.swift의 카드·상태점·아이콘·선택/hover를 사용합니다. 제목20pt·상세14.5pt·행76pt, 사이드바 기본360/min280을 적용합니다. 너비 조절과 CLI 하단 최소화를 유지합니다.

## 05 필요 리소스·이미지 설명

기존 앱 아이콘과 BrowserChrome의 밝은 배경·흰 카드·민트 강조를 사용합니다. 폴더·네트워크·접힘·검색은 시스템 SF Symbols를 사용합니다. 새 외부 이미지·폰트·패키지는 추가하지 않습니다.

## 06 관련 데이터

| 데이터 | 위치/수명 | 이번 변경 |
|---|---|---|
| 등록 프로젝트 | ~/Library/Application Support/Local Server Browser/projects.json | 삭제·초기화·재생성하지 않습니다. |
| 서버 로그 | 같은 폴더 Logs/ | 캐시 대상에 넣지 않습니다. |
| 창·배율·보기 | UserDefaults | 기존 값을 사용합니다. |
| 웹 파일 캐시 | 앱 WebKit default 저장소의 memoryCache·diskCache | 명시적 버튼/메뉴에서만 비웁니다. |
| 쿠키·웹 저장 | 동일 WebKit 저장소 | 삭제 allowlist에서 제외합니다. |
| 옛 루틴 기록 | 기존 routine-settings·RoutineRequests 경로 | 실행본에서 사용하지 않고 보존합니다. |

새 게임 표나 발란스 수치는 만들지 않습니다. 앱 UI·캐시 정책을 게임 콘텐츠 표와 섞지 않습니다.
