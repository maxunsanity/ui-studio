# P58 · 테이블 데이터 기초 · 시스템을 연결된 표로 옮기는 기획

**이 문서는** 케이팝몬스터즈의 시스템(아이돌 · 몬스 · 건물 · 보드 · 카드 · 수익 · 디펜스 · 시즌 등)을 서로 ID로 이어진 CSV 표로 옮기는 첫 기획서예요. 지금 표 구조의 기준은 [P148 테이블 데이터 조합 구조](../개발진행기획_v01/콘텐츠별_v03/테이블데이터_조합구조_기획서.html)예요.

**보는 법** 1장(원칙) → 2장(단계)을 읽으세요. 같이 여는 도구: [게임 테이블 도구](../../../game-table-tool.html). 표 목록 초안 · 확인 필요 목록 원문은 [로그](기획서_테이블데이터기초_v0.1_이스라트.log.md)에 있어요.

**지금 상태** **개발된 것**: `data/game/` 표들과 연결 검사 도구, 게임 테이블 도구 화면, 임시 리소스 폴더 `data/res/temp/`. **현재 개발되지 않음, 진행 중**: 4단계 간단한 밸런스 시뮬, 확인 필요 칸 채우기. 표 구조는 [P148](../개발진행기획_v01/콘텐츠별_v03/테이블데이터_조합구조_기획서.html)의 마스터 표 방식으로 옮겨 가는 중이에요.

## 1. 원칙

- 밸런스 · 화면 · 리소스 · 시뮬이 같은 표를 읽어요. 값을 바꿀 곳은 표 한 곳뿐이고, 문서와 표가 다르면 표를 기준으로 고쳐요.
- 작업은 kpopmonsters 저장소 안에서만 해요. 모노카피바라는 구조만 읽어요.
- 기획원본에 없는 칸이나 값은 만들지 않고 「확인 필요」로 비워요.
- 숫자는 모두 프로토타입 시작값이에요.

## 2. 단계

| 단계 | 내용 | 상태 |
|---|---|---|
| 1단계 | 표 틀 · 칸 정의 · ID 규칙 · 로더 · 연결 검사 | 개발됨(`data/game/`) |
| 2단계 | 기획원본에서 시작값 채우기 + 근거 문서 · 줄 | 개발됨, 빈 칸은 확인 필요 |
| 3단계 | 편집 화면 | 개발됨([게임 테이블 도구](../../../game-table-tool.html)) |
| 4단계 | 간단한 밸런스 시뮬 | 현재 개발되지 않음, 진행 중 |
| R단계 | 블렌더 임시 리소스 | 개발됨(`data/res/temp/`) |
