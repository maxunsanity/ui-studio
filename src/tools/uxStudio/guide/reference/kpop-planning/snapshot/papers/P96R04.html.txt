<p>이번 제작 범위는 모델10종, 공중 대기·이동·공격 대기·발사 반동·복귀 5클립, 추가 공중 부유·주변 빛 입자·이동 빛 꼬리, 뷰어 8자 비행 시연입니다. 획득·교감·기분·대화·섭외권·필살기·피격·쓰러짐·승패 동작은 후속 기획이며 이번 구현으로 표시하지 않습니다. 섭외권 동작은 현중의 별도 제시 뒤 제작합니다.</p>
<p>10종은 기본 도감의 종 수입니다. 현재 방어전의 공중 유닛 7자리와 쌍포 15기를 유지합니다. 보유 몬스 최대 5마리와 방어 시뮬레이터 7자리 사이의 편성 규칙은 이 모델 시안으로 확정하지 않습니다. 12지신 12종과 이전 5색 임시 모델은 기본 후보에서 제외하고 별도로 보존합니다.</p>

<p>그림은 이미지 생성 도구로 만든 콘셉트입니다. 실행 모델은 코드로 제작한 복셀 메시 시안이며 블렌더 원본 <code>.blend</code> 파일은 없습니다. 그림과 실행 모델을 동일한 완성도나 동일한 메시로 간주하지 않습니다.</p>
<ul>
<li>기본 모델: <code>data/res/mons_basic_v01/&lt;mons_id&gt;.model.json</code>과 <code>.glb</code>.</li>
<li>기본 목록·색: <code>data/mons_proto/v01/mons_catalog.csv</code>. 이름·종·원소·대표색·몸색·파일 연결을 관리합니다.</li>
<li>부위 형상: <code>.model.json</code>의 부위별 복셀 색상·부모·피벗.</li>
<li>애니 길이·반복: <code>animation.csv</code>. 키프레임: 별도 <code>animation_tracks.json</code>.</li>
<li>Y 위, Z+ 정면, 발밑 원점. 복셀 한 칸은 0.32 장면 단위입니다. 실제 모델 높이는 약 5.12~7.68 장면 단위이며 종별 바운드는 <code>manifest.json</code>을 따릅니다.</li>
<li><code>root</code>는 게임의 월드 배치이고 기본5클립은 내부 <code>rig</code>부터 재생합니다. 기본10종 런타임에서는 중간 <code>guardian_hover</code> 노드로 추가 부유를 더합니다. <code>emitter</code>는 빈 공격 발사 원점 노드이며 메시가 아닙니다.</li>
<li>부위별 강체 메시를 회전하는 구조입니다. 공통 이름은 <code>rig</code>, <code>body</code>, <code>head</code>, <code>ear_l/r</code>, <code>eye_l/r</code>, <code>paw_fl/fr/bl/br</code>, <code>tail</code>, <code>crest</code>, <code>mane</code>, <code>emitter</code>입니다. 종에 불필요한 부위는 빈 노드로 유지할 수 있습니다. 추가 파츠는 아홀로틀 gill_l/r, 슈가글라이더 membrane_l/r, 천산갑 armor/head_scales, 카피바라 fruit이며 부모 연결을 유지합니다.</li>
<li>키는 [정규시간,x,y,z]이며 시간에 클립 길이를 곱합니다. 위치는 rest+입력값×factor, 회전은 rest+degToRad(입력값×motion_factor)를 쿼터니언으로 변환하고, 스케일은 rest×(1+(입력값−1)×motion_factor)입니다. factor는 rig.position만 hover_factor이고 나머지는 motion_factor입니다. 모델 기준 회전은 라디안입니다.</li>
<li>part.pivot은 부모 기준 로컬 이동, part.rotation은 Euler 라디안입니다. voxel.position은 해당 부위 기준 로컬 장면 좌표이며 voxel.size도 장면 단위입니다. 개별 voxel.color가 sRGB HEX이고 별도 팔레트 사전은 없습니다.</li>
<li>큐브의 내부면을 제외한 메시와 vertex color를 사용합니다. GLB에는 5개 클립이 포함됩니다.</li>
</ul>
<h3>교체 절차</h3>
<ol>
<li>기본10종의 식별 특징과 실제 모델 정면·측면·뒤태를 확인합니다. 12지신을 기본 목록에 섞지 않습니다.</li>
<li><code>mons_id</code>와 원소 매핑을 유지하고 형상·복셀 색상·부위 피벗을 제작합니다. 날개를 모든 종에 붙이지 않습니다.</li>
<li>Y-up/Z+ 정면, 발밑 기준, root/rig 분리, emitter 위치를 맞춥니다. 공중 경로를 root 애니메이션에 굽지 않습니다.</li>
<li>위 5클립의 ID·길이·반복·0초 발사 계약을 유지합니다. 귀·꼬리 등 종별 파츠는 공통 리그 이름과 역할에 연결합니다.</li>
<li>현 웹 시뮬레이터는 GLB 대신 모델 JSON을 읽어 공통 라이브러리로 모델을 생성합니다. GLB는 다른 엔진 전달용입니다. JSON과 GLB를 함께 갱신하거나 별도 GLB 로더 연결부를 작성해야 합니다. GLB만 교체하면 현재 뷰어에는 반영되지 않습니다.</li>
<li>데이터만 수정할 때는 exporter → check → 시뮬레이터 build 순서로 확인합니다. generator는 기본 데이터를 다시 만드는 도구여서 수작업 수정값을 덮어쓰므로 원본 제작 규칙을 바꿀 때만 사용합니다.</li>
<li>새 모델의 루프 경계·공격 후 복귀·정지/재개·emitter 위치를 검수합니다. 피해를 발생시키는 새 애니 이벤트를 추가하지 않습니다.</li>
</ol>
<h3>원본 수정과 파일 생성 범위</h3>
<p>영속 조형·색 변경은 generate.mjs의 creatures·C·종별 switch를 수정합니다. catalog.color/body_color만 바꿔도 실제 복셀 색은 바뀌지 않습니다. JSON을 직접 수정할 경우 voxel.color를 바꾸고 generate는 생략합니다.</p>
<p>generate는 활성 catalog.csv·animation.csv·animation_tracks.json·visual.csv·copy.csv·schema.json 6개와 기본10종 모델 JSON을 덮어씁니다. export-assets는 이 입력과 공통 모델/애니 모듈에서 기본10종 GLB와 manifest를 만듭니다. 기본 GLB 합계는 2,821,400바이트, 종마다 759<del>1,237복셀·9</del>13메시입니다.</p>
<h3>재생성 명령</h3>
<p>프로젝트 루트에서 실행하며 기존 프로젝트의 Three.js·esbuild 의존성을 사용합니다. 전체 게임 저장이나 서버를 재시작할 필요는 없습니다.</p>
<pre><code class="language-sh">node scripts/mons-proto-v01/generate.mjs
node scripts/mons-proto-v01/export-assets.mjs

<p>12지신 보존 원본은 <code>data/mons_zodiac_extra/v01/</code>, 실행 리소스는 <code>data/res/mons_v01/</code>입니다. 기본10종 생성 명령은 이 리소스를 덮어쓰지 않습니다. 보존 생성기 원본은 data/mons_zodiac_extra/v01/source/*.original.mjs이며 재생성이 필요하면 scripts/mons-zodiac-extra-v01/generate.mjs --regenerate-extra와 export-assets.mjs --regenerate-extra를 사용합니다.</p>

<h3>제작팀 전달 · 비행 이펙트 규격</h3>
<p>수치는 모두 조절 가능한 시안입니다. <code>data/mons_fx/v01/flight.json</code>이 효과와 추가 부유의 원본 데이터이고 <code>src/ui/mons-proto-v01/flight-fx.mjs</code>가 공용 실행 모듈입니다.</p>
<ul>
<li>기존 5클립 위에 상하 3.6초·좌우 7.2초 주기의 부유를 더합니다. 공중 대기에서 추가 높이 진폭 ±0.34, 좌우 진폭 ±0.12 장면 단위이며 이동·공격에서는 상태별 비율로 줄입니다. 종별 위상 간격은 0.71라디안입니다. 기본 클립의 부유와 더해지므로 전체 높이 진폭을 ±0.34로 해석하지 않습니다.</li>
<li>몸 주변 입자 18개와 최대128개의 빛 가루를 재사용합니다. 대기 초당12개, 이동 초당48개를 방출합니다. 최대2초 뒤 사라집니다.</li>
