# AI 컷씬 마스터 제작 규약

이 폴더에서 컷씬을 제작하거나 수정할 때 README.md를 먼저 읽는다.

1. 사용자 지시를 brief에 보존하고 실제 자산 목록에서 actor/resource ID를 확인한다.
2. master.py prepare로 리소스와 관련 MD 본문을 읽을 컨텍스트를 준비한다. 누락 파일을 가상의 파일로 대체하지 않는다.
3. 출력된 knowledge.md 전체에서 이번 작업에 필요한 절을 읽고 적용 이유와 한계를 기록한다. 필요하면 문서를 추가해 새 컨텍스트를 만든다.
4. storyboard.template.json을 기준으로 단이가 콘티를 작성한다. 사용자에게 전문 양식 작성을 떠넘기지 않는다.
5. 화자/청자/촬영 대상과 배우 행동/카메라 시간을 분리한다. 미검수 모션을 사용 가능한 모션으로 올리지 않는다.
6. validate 결과를 확인하고 오류를 고친다. render로 같은 데이터의 MD 콘티를 출력한다.
7. 에디터 연결과 시각 재생 검수가 없으면 씬 제작 완료로 보고하지 않는다. 콘티 준비 완료와 재생 완료를 구분한다.
8. 원본 씬과 잠금·리비전을 보존한다. 사용자 수정은 해당 씬에 적용하고 전역 선호로 자동 확장하지 않는다.

모든 단계는 사용자가 허용한 제작 범위 안에서 진행한다. 이 문서는 매 단계 승인 요청을 요구하지 않는다.
