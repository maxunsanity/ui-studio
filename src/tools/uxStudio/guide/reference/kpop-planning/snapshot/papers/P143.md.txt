### 2-2. 옛 4축 → 6축 대응
| 옛 ID | 새 축 | 처리 |

| vocal | 보컬 | 그대로, 세부 3 |

### 2-3. 레슨 시설 · 칸 · 카드 연결
- 칸 → 건물 → 축(2-1 표). 팬샵(12·14·15)·숙소(2·37·39)·사옥(1)은 6축을 직접 올리지 않는다. 팬샵 = 팬·수익(능력 가중치 빈칸), 숙소 = 휴식·태도·외국어 주 성장, 사옥 = 멤버 자리·아이돌 캐스팅.
- 카드: 작곡 카드→작사·작곡, 「플로우 타기」 대박→플로우. 카드 효과 값은 「발란스 대기」.
- 6·16·26·36칸은 「캐스팅 보드」(모노폴리GO 정거장 대결에 해당, 오디션 캐스팅과 다름)다. 이 툴에서 성장 연결을 넣지 않고 규칙도 바꾸지 않는다.

### 2-4. 9건물 30단계 (본관1 + 부속2)
- 건물 9개 모두 30단계. 구간: 1~10 본관, 11~20 + 부속1, 21~30 + 부속2(구간 경계는 「발란스 대기」, 그림 `docs/planning/proposal-concept/_assets/building-dance-growth-30lv-v01.png`).
- 증설: 묶인 칸 도착 시 1단계(사옥은 출발 칸을 지날 때). 사옥 7·13·19·25에서 캐스팅권(+1, 최대 5명).
- 툴 표: 건물 × 단계(30) 표 자리와 비용·효과 열을 만들고 값은 비운다.

### 2-5. 주사위 굴림 배수
- 입력 둘: 굴림 횟수, 굴림당 배수(×1~×1,000). 굴림 1번 비용 = 배수 × 기본 비용, 칸 보상·성장 = 배수 × 기본 값(선형). 이동은 배수와 무관하게 굴림 1번에 1번.
- 「하루 1,000개」 전제 화면·계산(하루 소모 · 배수 문턱 등)은 지우거나 「폐기」 표시 후 새 입력으로 바꾼다.
- 배수 중간 단계·기본 비용·보상 값은 「발란스 대기」.
