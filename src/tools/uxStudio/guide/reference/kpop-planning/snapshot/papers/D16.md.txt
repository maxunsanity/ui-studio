## 이게 뭐냐

이스터즈 v0 합의 초안(파츠 커스텀·사진 비범위·레거시1·한 세트 두 표면)을 **시각 카탈로그 UI 목업**으로 그린 디자인컨셉. CSS/SVG 기하 치비. 외부 이미지 URL 없음.

## 한 줄

> **눈·코·입 · 헤어 · 몸 · 색 · 표정6(+소품 옵션) 시트로 고른다. 같은 파츠로 카드·로비를 그린다. 성장 보드 위. 레거시×1.**

---

## 시각 범위

| # | 화면 | 내용 |
|---|---|---|
| 1 | 파츠 분리 시트 | 눈 · 코/입 · 헤어 · 몸 · 색 · 표정6 · 소품(옵션) 카탈로그 목업 |
| 2 | 한 세트 두 표면 | 동일 파츠 → 카드 초상(2D) + 로비 아바타(전신) |
| 3 | 성장보드 | 아바타가 성장-city/board 위에 선다는 전제(사진 ID 아님) |
| 4 | 레거시 | 시즌 이관 **1**개 캐리오버 표시 |

## 하지 않음

| ID | 항목 |
|---|---|
| X-업로드 | 사진 업로드 · 카메라 · 드롭존 UI |
| X-AI얼굴 | AI 얼굴 생성 |
| X-이중 | 카드/로비 완전 별도 세팅 |
| — | 파츠 가격·드롭·개수 잠금 · 이스터즈/클로드/단이 원본 수정 |

## 파츠 슬롯 가안 (시각 ID)

| 슬롯 | 예시 ID | 비고 |
|---|---|---|
| 눈 | `eye_round_b` 등 | 형태·색 |
| 코·입 | `nm_dot_sm` 등 | 얼굴 핵심 |
| 헤어 | `hair_tb_ind` 등 | 스타일·색 |
| 몸 | `body_hd_ind` 등 | 체형·의상 톤 |
| 색 | `pal_warm_ind` 등 | 팔레트 |
| 표정 | `ex_idle`~`ex_wink` | **6종**(카톡) |
| 소품 | `acc_*` / `acc_none` | **옵션** |

데모 세트(카드=로비 동일): `eye_round_b` · `nm_dot_sm` · `hair_tb_ind` · `body_hd_ind` · `pal_warm_ind` · `ex_idle`

## 보드 전제

- 보드 = **성장형**(growth board / 성장 도시)
- 아바타는 그 월드 **위에 서는** 플레이어 치비
- 유저 파츠 ≠ 아이돌 IP 초상(별 레이어) — IP교체 문서 링크만
