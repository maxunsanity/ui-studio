## 조회가 제한된 자료

Blender stable/4.5 카메라 문서는 본문 조회 실패. 공식 개발 문서의 검색 본문만 확인했으며 설치 버전 API 명세로 확정하지 않는다. Three.js 카메라 문서는 목차는 열렸지만 상세 클래스 페이지 조회에 실패해 이 묶음에 API 명세를 추가하지 않았다. D08의 계산은 수학적 설계 설명이다.

AAAI 카메라 계획 자료는 검색 소개만 확인되고 본문 조회가 제한되어 채택 규칙의 근거로 쓰지 않았다. 이 자료들은 정밀 검토 완료 목록에 포함하지 않는다.

## 유지보수

출처가 수정돼도 이전 제작의 근거를 지우지 않는다. 요약과 적용안 변경 시 문서 버전·확인 날짜·이유를 갱신한다. 영상 사례의 실제 재생 분석과 페이지 설명 확인을 별도 상태로 관리한다.
