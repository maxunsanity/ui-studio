## 간략

**머리표** 시스템 기획 · S13 · 이벤트 운영 · 모노 이벤트 문서 62개 중 운영 · 타이쿤 · 시즌 14개 이식(나머지는 S13a · b · c)

**제목** 이벤트 운영 — 회차를 켜고 끄고, 자리에 꽂고, 보드에서 재화를 떨어뜨린다

**훅** 굴릴 때마다 「이벤트 재화 +1」. 시즌 내내 돌아가는 개인 마일스톤과 50명 순위가 매일의 이유가 된다.

**두 줄 요약**
- 이벤트 하나 = **틀(`event_template`) + 회차(켬 · 길이 · 재화) + 패키지(재화 얻기 · 놀이 · 보상)**. 회차가 꺼져 있으면 드랍도 화면도 없다.
- 늘 켜진 두 축: **3일 개인 마일스톤**(가운데 · 도전)과 **시즌 순위**(오른쪽 1번 · 경쟁 · 50명). 나머지는 하루짜리 회차가 돌아가며 켜진다.

```mermaid
flowchart LR
  T[틀 event_template] --> R[회차<br/>켬 · 길이 · 재화 · 자리]
  R -->|열려 있음| D[시설 칸 도착 드랍<br/>event_acquire]
  D --> W[이벤트 재화]
  W --> P[패키지 놀이<br/>S13a · b · c]
  P --> B[보상 계획표<br/>S07 6-3]
  B --> G[지갑 · 보관함]
  R -->|끝남| X[남은 재화 사라짐]
```

1. **켠다** — 회차가 열리면 그 이벤트 탭이 보이고 보드 드랍이 시작된다.
2. **모은다** — 시설 칸에 도착하면 열린 이벤트마다 확률로 재화가 떨어진다(× 굴림 배수).
3. **쓴다** — 이벤트 창에서 재화로 놀이를 하거나, 점수가 쌓여 마일스톤 · 순위가 오른다.
4. **닫는다** — 회차가 끝나면 남은 재화는 사라지고, 순위는 정산된다.

| 왜 지금 | 이게 핵심 | 이게 아닌 것 |
|---|---|---|
| S07 6절에 틀 · 표 · 보상 계획만 있고, 회차를 어떻게 켜고 어디에 꽂고 무엇을 검사하는지, 개인 마일스톤 · 순위가 어떻게 도는지가 없다(2차 3단계) | 회차가 꺼지면 아무것도 안 떨어진다 · 배수는 적립에만 · 보상은 계획표 · 운영 표와 실지급이 같아야 한다 | 케이팝 「시즌」(60일)과 이벤트 회차는 다르다(R-S07-22) · 전투 이벤트(보스전 · 카드 시즌전 · 라바 전투)가 아니다 · 상점이 아니다 |

**3-2. 회차가 보이는 조건 다섯** (이식) — 다섯 모두 맞아야 탭이 뜬다

1. 회차가 켜짐 2. 지금이 시작 ~ 끝 사이(또는 고정) 3. 틀이 있고 켜짐 4. 회차 재화가 풀에 있고 다른 켜진 회차와 겹치지 않음 5. 표시 이름이 있음 → 「(접두) 표시 이름」

| ID | 규칙 | 근거 |
|---|---|---|
| R-S13-6 | **회차가 꺼져 있으면 드랍하지 않는다**(재화도 탭도 없음) | 모노 103 H3 · 98 (이식) |
| R-S13-7 | 회차 재화는 **틀마다 20개 풀**에서 꽂는다(`item_evt_{틀}_{01~20}` 모양). 같은 모양이라도 회차마다 다른 재화 | 모노 98 P2 · P3 (이식) |

| R-S13-10 | 표시 이름은 바꿀 수 있고 id는 고정 | 모노 98 P4 (이식) |
| R-S13-11 | 케이팝은 날짜별 일정표 대신 **시즌당 횟수 · 길이**(`runs_per_season` · `run_hours`)로 둔다. 실제 날짜 깔기는 운영 툴 몫 | S07 R-S07-17c · 6-2 (신규) |

