## C. 안A · 순수 가상 · 미잠금

| 열 | 내용 |
|---|---|
| **정의** | 판매·차트·수익 = 전부 게임 내. 실스토어·실정산·실차트 API·실음원 연동 **없음**. |
| **플레이 감각** | 「우리 그룹 음원이 도시에서 팔린다」— 메타는 게임 안. 진짜 유통 기대는 낮춤. |
| **구현/법무** | 구현·법적 부담 최소. 라이선스·SKU·정산 설계 불필요(시즌1 감각). |
| **#MS / 정령음방 함의** | #MS 판매처·트리거 그대로 가상 루프. 정령음방 §C.3 「실유통 깊이」=가상만 쪽과 정합 **가능**(판결 아님). 앨범 상류=「무엇을 만드나」만 · 실배송 없음. |
| **리스크** | 「진짜 팔린다」 메타 약함. 회의「과함」과 정합 가능하나 브랜드 확장감은 얇음. |
| **잠금** | **미잠금** |

## D. 안B · 실유통 연출만(시뮬) · 미잠금

| 열 | 내용 |
|---|---|
| **정의** | 실차트 UI·발매 티저·티커 연출. 실제 유통·정산·음원 파일 배송 **없음**. 「시뮬」명시. |
| **플레이 감각** | 「팔리는 느낌」·마케팅 컷 가능. 메타감은 실유통에 가깝게 연출. |
| **구현/법무** | UI/연출 비용↑. 실유통 계약 없음. 「가짜」기대 관리·카피 주의(법무 부담 감: A보다 큼, C보다 작음 — **숫자 없음**). |
| **#MS / 정령음방 함의** | #MS 스트리밍 허브·발매 창을 「실차트 룩」으로 읽기. 음방 티커=연출 배너(≠PvP 본규칙). 정령음방 MV/실유통 깊이=연출만 쪽과 조율 **가능**. |
| **리스크** | 기대 관리 · 「가짜」 인식 · 실차트와 혼동 시 항의·신뢰 리스크. |
| **잠금** | **미잠금** |

## E. 안C · 하이브리드 · 미잠금

| 열 | 내용 |
|---|---|
| **정의** | 인게임 가상 수익 루프 유지 + 실세계 메타(티저·링크·이벤트). **실정산 = 별레이어** 명시. |
| **플레이 감각** | 브랜드·이벤트 확장. 「게임 밖에도 닿는다」 메타. 시즌1에 실정산까지 넣을지는 **open**. |
| **구현/법무** | 법무·SKU·정산·라이선스 부담↑. 시즌1은 메타만·정산 후순위 후보(파생 C′ 인접). |
| **#MS / 정령음방 함의** | #MS 수익 유형은 가상 유지 · 실메타는 별창. 정령음방 앨범 상류가 실배송/실음원과 닿을 **경계만** 표시 — 본문 재작성 없음. 음방 티커 ≠ 실차트 API. |
| **리스크** | 법무·SKU·정산 · 「어디까지 진짜인가」 설명 비용 · 시즌1 과부하 가능(회의「과함」과 긴장). |
| **잠금** | **미잠금** |
