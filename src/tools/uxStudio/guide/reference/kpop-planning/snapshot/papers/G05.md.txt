## 2. 카드 원본을 만드는 제작 과정

1. **IP 팩 정의** — 샘플 5개 컨셉을 실제 아이돌 IP로 바꿀 수 있도록 `ip_pack_id`, 멤버 명단, 사용 가능 이미지·이름·음원 권리, 계약 범위, 시즌 기간을 별도 데이터로 둔다. 실제 제휴 전에는 샘플을 계약 IP처럼 표시하지 않는다.
2. **카드 역할 정의** — 멤버, 제작 스태프, 매니지먼트, 수호 정령, 홍보·콘텐츠, 무대·시설·굿즈 등 역할을 나눠, 각각이 어느 플레이 결정에 쓰이는지 먼저 적는다. 최신 회의에는 멤버·스태프·정령·홍보 예시가 나온다. 나머지는 기존 문서의 후보로 두고 검수한다.
3. **덱·세트 설계** — 카드북은 **~20덱×9장** 맥락을 유지한다. [Q-001](../../질의응답/Q-001_덱구조_멤버20.md)(현중): **멤버 슬롯/정원=5**, 튜토리얼·초반 **활성 선택 수=가변(1~5)**, 슬롯 밖(미선택·비활성 후보)=**비멤버 덱 쪽**. 문서·데이터에서 **풀(후보) · 멤버 슬롯(정원) · 활성 선택 수**를 분리한다. 스태프·정령·홍보 등 **역할 덱은 폐기하지 않는다**(20인 시즌 α 확장은 후속). A/B/C 선택지 폐기. 카드 장수에 맞춰 콘텐츠를 억지로 늘리지 않는다.
4. **개별 카드 명세** — 고유 ID, IP/시즌, 카드 역할, 별 등급, 효과, 레벨 성장식, 아트·카피·음원 사용권, 획득 풀, 중복 처리, 진열·굿즈화 가능 여부를 한 행으로 관리한다.
5. **획득 규칙 연결** — 카드 원본을 특정 이벤트·장소·성과의 보상 풀에 연결한다. 별 등급 확률과 중복 보정은 원본의 품질 판단과 별도 테이블로 둔다.
6. **검수·발행** — 권리·세계관·아트·경제 밸런스·오표시를 확인한 카드만 시즌 팩에 발행한다. IP가 바뀌어도 엔진·이벤트 구조는 재사용한다.

## 3. 게임 안에서 카드가 생기는 경로

| 경로 | 플레이 행동 → 이벤트 | 카드 연결 방식 | 근거 강도 |
|---|---|---|---|
| 일정 보드 | 예산 선택 → 주사위 → 특정 일정 칸 착지 → 결과 | 일정 종류와 결과에 맞는 풀에서 지급 | 최신 회의의 ‘모든 시스템에서 획득’ 방향. 세부 규칙 **제안** |
| 성장한 장소 | 해당 시설 성장 → 조건 달성 → 그 장소에 도착 | 장소 한정 카드 풀 해금 또는 지급 | 9/28 회의 42:38~43:17의 **아레나 홀 예시** |
| 아이돌·정령 파견 | 편성 → 파견 → 결과 회수 | 결과에 맞는 카드·성장 재료 후보 | 기존 WORLD FESTIVAL 문서의 설계. 최신 회의의 정령 전투 방식은 **미정** |
| 카드북·공연 | 덱 편성 → 공연 → 결산 | 카드 사용 경험, 기념 카드 등 | 기존 WORLD FESTIVAL 문서. 완성자 독점 접근 조건은 9/28 회의에서 재검토 요구 |
| 홍보 카드 | 기본 홍보 활동, 선택형 숏폼·소셜 참여 | **기본 보상은 모두**, 선택 참여에는 추가 보상 | 9/28 회의 37:10~39:18, 53:32~57:23 |

획득 규칙은 **이벤트 → 자격 확인 → 카드 풀 선택 → 등급 결정 → 중복 처리 → 지급 기록** 순서로 한 모듈에서 처리한다. 보드·탐험·홍보는 카드 시스템에 이벤트만 전달한다. 카드 획득 효과를 각 기능에 따로 박아 넣지 않는다.

## 4. 플레이어에게 보여 줄 명확한 약속

- **별 등급:** 획득할 때 정해지는 카드 종류. ★1을 경험치로 ★5로 바꾸지 않는다. [9/28 29:32~30:10]
- **레벨:** 같은 카드 안에서 쓰며 성장하는 값. 어떤 행동이 경험치를 주는지 별도 규칙으로 정한다. [31:27~32:16]
- **중복:** 교환·보정·재료화 중 무엇을 채택할지 미정. 삭제나 강제 합성으로 가정하지 않는다.
- **희귀 카드:** 장소 성장과 활동의 결과로 노린다. 주사위 운만으로 필수 성장이 영구 막히지 않도록 누적 보정 또는 대체 경로를 검토한다. 이는 **단이 제안**이다.
- **카드북 완성:** 개인 성과와 축제의 깊은 선택지를 열되, 미완성·늦게 입장한 플레이어도 시즌 축제의 역할을 가지게 재설계한다. [9/28 12:09~16:01]

## 6. 이스터즈 중재가 필요한 결정

1. 후보 16명은 모든 샘플 IP 공통인지, 샘플별 가변인지. 튜토리얼 목표 시간은 사용자 테스트로 정할지.
2. ~~20덱 고정 vs 멤버수 가변(A/B/C)~~ → **Q-001 반영:** 카드북~20덱 · 멤버 슬롯/정원=5 · 활성=가변(1~5) · 슬롯 밖→비멤버 · 역할 덱 유지. 상세=`질의응답/Q-001_덱구조_멤버20.md`. α(역할 덱 확장)는 후속 체크.
3. 카드 지급의 필수 경로·희귀 카드의 대체 경로·중복 처리.
4. 정령의 전투/정화 방식, 페스티벌 참가 조건, 시즌 이월 카드.
5. 홍보 덱에서 수집할 정보 종류와 보상 상한. 회의 중 금액 예시는 확정값이 아님.
