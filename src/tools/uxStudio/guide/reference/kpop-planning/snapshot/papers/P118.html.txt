<p>오디션은 게임에 들어오자마자 보는 첫 콘텐츠입니다. 랜덤으로 나온 후보 카드를 <b>둘씩 비교해 하나를 고르는 이상형 월드컵</b>으로 결승까지 줄여 가고, 끝까지 남은 한 장이 이번 시즌의 주인공 <b>연습생</b>이 됩니다. 마음에 들지 않으면 월드컵 한 판 전체를 다시 돌릴 수 있고 최대 3판까지입니다. 확정하면 계약 도장이 찍히며 그대로 <a href="/docs/planning/planning-docs-tool.html?face=development&amp;doc=P96&amp;plan=planning_development_plan_audition#mons-cutscene">P96 몬스</a> 획득 컷씬으로 이어져 짝 몬스가 깨어납니다. 한 명으로 사옥에서 시작하고, 사옥이 커질 때마다 둘 중 하나를 고르는 짧은 오디션으로 멤버를 늘립니다(멤버 수 = 그룹 인원).</p>
<div class="cards"><div class="card"><h3>콘텐츠 경계<span class="origin-tag" style="font-size:.5em;font-weight:500;opacity:.55;margin-left:.4em;white-space:nowrap;vertical-align:middle">(신규)</span></h3><p>오디션 진입 · 후보 뽑기 · 2택 진행 · 남은 판(다시 돌리기) · 마지막 한 장 확정 연출 · 계약 확정 저장 · 사옥 짧은 오디션 · 교체 요청 접수를 담당합니다. 몬스 탄생은 P96, 카드 능력과 특기는 카드 기획, 사옥 증축은 보드 건물(P81), 오디션 칸은 없습니다(현중 10/02 16:53).</p></div><div class="card"><h3>현재 기준과 목표<span class="origin-tag" style="font-size:.5em;font-weight:500;opacity:.55;margin-left:.4em;white-space:nowrap;vertical-align:middle">(신규)</span></h3><p>현재 기획 단계이며 게임 구현은 없습니다. 화면 기준은 제안서 <a href="/docs/planning/proposal-concept/audition.html" rel="noopener" target="_blank">오디션 덱</a>(이상형 월드컵 · 끝까지 남은 한 장 · 기회 3번 = 판 전체 다시 · 특기 라벨 · 한 명 시작 · 사옥에서 추가)이며, 현중 10/07 16:40 「오디션은 제안서처럼」을 따릅니다. 후보 수 · 다시 돌리기 비용은 <b>결정 대기</b>입니다.</p></div></div>
<div class="note"><b>현재 제외합니다</b><p>심사 점수 · 포지션 밀당 · 숨은 특징 맞히기 · 무대 두 번 · 오디션 주사위 · 순위(10/02 15:55 회의 결정)는 쓰지 않습니다. 후보 「16명 · 16장」 숫자는 10/04 결정으로 화면에 쓰지 않습니다.</p></div>

</section><section class="part hist"><h2>(이전) 구동 방법·시뮬레이션(신규)</h2>
<p>게임용 오디션 모듈은 <b>미구현</b>입니다. 제안서 덱의 월드컵 화면 시연이 화면 참고입니다. 개발 순서는 2택 진행기(후보 뽑기 → 대진 → 결승) → 남은 판 → 확정 연출 → P96 컷씬 연결 → 사옥 짧은 오디션입니다.</p>
