# 080 · 모험 — 비하인드와 주간 차트

> status: **흡수됨 — 더 안 고침** · 2026-09-18
> 이 문서의 내용은 셋으로 갈라져 들어갔다. **여기 말고 아래를 본다.**
> **집 구조·비하인드 → [081 입덕](./081_입덕_전면기획.md)** · **겨루기 → [082 시안](./082_시안.md)** · **보내기 → [070 원정](./070_투어.md) · [071 총공](./071_파견.md)**
> ⚠ 아래 본문은 **「투어·파견」 옛 이름**이고, **비하인드로 순위를 매기려던 안**이다. 그 안은 [081 §4](./081_입덕_전면기획.md)에서 **폐기**됐다 — 게임이 만든 것으로는 겨룰 수 없다.
> 모노카피바라 엽서 소스 조사(249행 조각 표 등)만 아직 여기가 원본이다.
> 뿌리 둘: **모노카피바라 모험**(게임이 결과물을 만들어 준다) + **천음 리그 제안**(경쟁으로 밖에 퍼뜨린다)
> 게임 소스 확인: `adventure_narrative_fragment_config.csv` · `adventure_postcard_tier_visual.csv` · `adventure_match_grade_config.csv` · `adventure_step_config.csv` · `adventure_reward_bundle.csv`

---

## 이게 뭐냐

**아이돌을 보내면 콘텐츠가 나오고, 그걸 남들과 겨루는 것.**

세 덩이다.
1. **보낸다** — 파견(솔로) · 투어(팀)
2. **받는다** — **비하인드** (음악 · 이미지 · 영상). **LLM이 만든다**
3. **겨룬다** — **주간 차트**. 기록장에 쌓이고 소식으로 흐르고 밖으로 나간다

---

## 한 줄

**유저는 누구를 보낼지만 고른다. 결과물은 게임이 만들어 준다. 그걸 차트에서 겨룬다.**

---

## 모노카피바라가 실제로 어떻게 하고 있나 (소스 확인)

엽서는 **조립**된다. 유저가 쓰는 게 아니다.

| 표 | 무엇 | 크기 |
|----|------|------|
| `adventure_narrative_fragment_config` | 글 조각. **슬롯 3단**(open·body·close) × **결과 3등급**(perfect·good·partial) × 컨셉 13종 | **249행** |
| `adventure_postcard_still_map` | 컨셉 × 결과 → **스틸 이미지** | 52행 |
| `adventure_postcard_tier_visual` | 결과 → **금테·왁스 도장·별3·리본** / 은테·별2 / 테 없음·별1 | 4행 |
| `adventure_match_grade_config` | PERFECT·GOOD·PARTIAL → 별 · 보상배율 · **엽서 tier** | 4행 |
| `adventure_role_config` | 역할 — 돌파 · 지킴 · 길잡이 … | 5행 |
| `adventure_step_config` | 출발 → 진행 중 → 피날레 → **기억** | 4행 |
| `adventure_reward_bundle` | 보상 한 줄이 `postcard ADVENTURE_MEMORY 1` — **엽서 자체가 보상** | — |

**즉 — 결과 등급이 글도 그림도 테두리도 전부 바꾼다.** 유저는 **누구를 보냈나**만 골랐다.

우리는 같은 자리에 **LLM**을 넣는다. 조각을 뽑는 대신 **만든다.**

---

## 1. 보낸다

| | 누가 | 무엇 |
|--|------|------|
| **파견** ([071](./071_파견.md)) | 멤버 **한 명** | 예능 · 라디오 · 화보 · OST |
| **투어** ([070](./070_투어.md)) | **팀** | 지나온 동네 공연 |

**고르는 것**
- 어디로 보낼지
- 누구를 보낼지 (자리마다 잘 맞는 준비도가 다르다 · [066](./066_결과칸_16.md))

**주사위를 쓰지 않는다.** 판 밖이다.

---

## 2. 받는다 — 비하인드

돌아오면 **비하인드**가 나온다. 스케줄 뒤에 나오는 사진·영상·음원. 팬덤이 실제로 쓰는 말이다.

| 형식 | 어디서 잘 나오나 |
|------|------------------|
| **음악** | 라디오 · OST · 합동 무대 |
| **이미지** | 화보 · 팬미팅 · 공연 |
| **영상** | 예능 · 무대 · 비하인드 클립 |

### 등급이 전부를 바꾼다 (모노 그대로)

| 등급 | 비하인드 |
|------|----------|
| **대박** | 길고 좋다 · **금테 · 도장 · 별 셋** |
| 중박 | 보통 · 은테 · 별 둘 |
| 운빨망빨 | 짧다 · 테 없음 · 별 하나 |

**뭐가 등급을 정하나** — 누구를 보냈나 × 그 자리와 맞나 × 준비도(컨디션·기량·케미)

### LLM이 만든다 ★

모노는 **249개 조각을 미리 써두고 뽑는다.** 우리는 **매번 만든다.**

```
입력:  아이돌 · 멤버 · 어디로 · 무슨 자리 · 준비도 · 등급 · 지금 급 · 시즌 몇 주차
   ↓ LLM
출력:  비하인드 한 장 (음악 / 이미지 / 영상 중 하나)
```

**같은 자리에 같은 멤버를 보내도 매번 다르다.** 그래서 모을 이유가 생긴다.

**틀은 고정한다.** 모노가 슬롯 3단(열기·본문·닫기)을 고정한 것처럼, 우리도 형식·길이·말투를 고정하고 **내용만** 만든다.
말투 규칙은 [067](./067_서사.md)에서 잡은 것 그대로 — 자랑 말고 기록 · 좋은 일에도 그늘 한 점 · 과장 금지.

---

## 3. 쌓인다 — 기록장 · 소식

모노 127 「친구 소식 · 기록장」 구조 그대로.

| | 무엇 |
|--|------|
| **내 기록장** | 내 비하인드만 쌓인다. 시즌 이야기가 된다 ([067](./067_서사.md)) |
| **친구 소식** | 남의 비하인드가 흐른다 |

**모노가 못 박은 것을 지킨다**
- **딱지·어부지리는 소식에 안 태운다** (모노: 약탈·선물은 피드에 안 태움)
- 보내면 내 것이 사라지지 않는다
- 풀 UGC 광장을 만들지 않는다

---

## 4. 겨룬다 — 주간 차트 ★

**여기가 천음 리그 제안을 가져오는 자리다.**

제안서는 **유저가 만든 작품**을 겨루게 했다. 우리는 **게임이 만들어 준 비하인드**를 겨룬다.
그래서 **업로드·검수·저작권·AI 표기가 전부 사라진다.**

> 이름은 **주간 차트**. 음악방송 주간 순위가 팬덤이 제일 원하는 것이고, 우리 판이 방송 게임이라 말이 이어진다.

### 제안서에서 그대로 가져오는 것

| | 제안서 | 우리 |
|--|--------|------|
| **주간 사이클** | 월 오픈 → 금 마감 → 일 블라인드 → 월 발표 | **그대로** |
| **블라인드 타임** | 일 18:00~20:59 순위 비공개 | **그대로** — 방송 순위 발표 전 비공개와 같은 감각 |
| **점수 지표 5** | 조회 · 좋아요 · 공유 · 투표 · 후원 | **그대로** (비하인드에 붙는다) |
| **가중치** | 투표 35 · 공유 20 · 후원 20 · 좋아요 15 · 조회 10 | **그대로** |
| **로그 정규화** | 규모 차이를 눌러 「많이 사랑받은 것」이 이기게 | **그대로** |
| **부문** | 뮤직 · 이미지 · 영상 | **그대로** — 비하인드 형식이 셋이다 |
| **1인 최고 1개만 보상** | 한 사람이 여러 칸 독점 방지 | **그대로** |
| **Top 50 보상** | 순위별 차등 | **그대로** (우리 재화로) |
| **못 든 사람** | 참가상 · 도약상 · 개근 · 팬 픽 추첨 | **그대로** |
| **레벨 게이트** | Lv.20 이상 제출 | **덕력**으로 바꿈 |
| **명예의 전당** | 주차별 1~3 · 누적 Top10 | **그대로** |
| **어뷰징 필터** | 부계정 투표 · 봇 조회 · 품앗이 · 자전 후원 | **그대로** |
| **공유 유입 점수** | 클릭이 아니라 **실제 들어온 사람 수** | **그대로** ← **이게 제안서의 진짜 목적** |

### 제안서에서 안 가져오는 것

| | 왜 |
|--|-----|
| 작품 업로드 (파일·용량·형식) | **게임이 만든다.** 올릴 게 없다 |
| 검수 · 오디오 핑거프린트 · 중복 해시 | 도용이 날 수 없다 |
| 저작권 표기 · AI 사용 여부 체크 | 게임이 만든 것이다 |
| 공식 크리에이터 키트 | 유저가 만들지 않는다 |
| 「천음」 · 「역공명」 이름 | 우동 IP 세계관 말이다 |
| 5감정 테마 | 우리 다섯 단(제로돌~서동요)과 겹친다 |

### 전체 화력 (제안서 §8에서)

제안서에 이런 게 있다.
> 리그 총 투표 수가 목표를 넘으면 **전 서버 보상**을 여는 공동 목표 → 경쟁에 **협동 레이어**

**차트에도 얹는다.** 서버 전체 투표가 목표를 넘으면 **모두가** 받는다.
경쟁만 있으면 진 사람이 상하는데, 이게 있으면 **아무도 빈손이 아니다** — [064](./064_팬덤게이트_딱지.md)에서 정한 톤 그대로.

---

## 5. 밖으로 — 이게 목적이다

제안서가 진짜 원한 것은 **바이럴**이다. 근거가 원문에 있다.

- 공유 점수를 **"링크로 실제 들어온 사람 수"** 로만 셈
- KPI에 **"공유 링크 경유 신규 설치 수"**
- 창작자 화면에 「공유 링크 복사」 원탭 — 원문: *"창작자가 알아서 게임 밖에 퍼뜨리게 만드는 장치"*

**우리 비하인드는 그대로 공유거리다.** 만들 필요 없이 이미 한 장짜리 이미지·영상이다.

```
비하인드 한 장  →  밖에 올림  →  그 링크로 들어온 사람  →  차트 점수
```

**팬덤은 원래 인증하는 문화다.** 만들라고 하면 몇 명만 하고, 인증하라고 하면 다 한다.

---

## 우리 판과 안 섞는다

모노 160이 못 박은 것을 지킨다.

> **"원정·보드에 바이럴을 얹지 않는다."**

| | |
|--|--|
| **행보판 40칸** | 주사위 · 덕질 · 급 성장. **차트 없음** |
| **모험** (이 문서) | 보내기 · 비하인드 · 기록장 · 소식 · 차트 |

**두 집을 나눈다.** 섞으면 판이 흐려진다.

---

## 모험이 무엇을 덮는지 — 확인 중 ⚠

**내가 문서 두 장(115·160)만 보고 「모험 = 엽서 콘텐츠」라고 좁게 판단했는데 틀렸다.**

유저 확인: 모노카피바라에서 **모험은 상위 집**이고 그 아래에 **여정 · 출동 · 이벤트 · 카드 대전 · 보드 대전**이 들어간다.
실제로 데이터에도 `adventure_season_*` 20여 개 · `adventure_boss_*` 별도 · 던전 여정(294) · 카드 대전 툴이 따로 있다.

**그러니 042의 「여정 = 커리어 시즌」 매핑은 틀리지 않았다.** 여정은 모험 안에 있는 것이다.

**자리는 정해졌다 (2026-09-18).** 이 문서의 내용은 **입덕** 안으로 들어간다 → [081](./081_입덕_전면기획.md).
옛 이름 「커리어 시즌」은 폐기됐다.

---

## 안 정한 것

- 비하인드 **형식 틀** (길이·구도·음악 길이)
- LLM 비용 · 생성 실패 시 대체(모노처럼 조각 몇 개를 예비로)
- 차트 보상 크기 · 덕력 게이트 수치
- 파견·투어가 각각 어느 형식을 잘 내놓나
- 시즌(3개월)과 주간 차트의 관계
- 전체 화력 목표치

## 하지 않음

- 유저가 작품을 **만들어 올리기**
- 행보판에 차트·바이럴 얹기
- 딱지·어부지리를 소식에 태우기
- 보내면 내 비하인드가 사라지기
- 「천음」·「역공명」 이름 쓰기
