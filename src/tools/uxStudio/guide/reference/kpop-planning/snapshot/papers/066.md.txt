## 이게 뭐냐

**준비도** — 아이돌이 다음 무대에 얼마나 준비됐나. **컨디션 · 기량 · 케미** 셋으로 이뤄진다.
그리고 그걸 올려 주는 **결과 칸 16개**.

| | 누가 쌓나 | 리셋 |
|--|-----------|------|
| **덕력** | 빠순이 | **없음** (계정) |
| **준비도** | **아이돌** | **판마다** |

**판이 넘어가면 준비도는 0부터다.** 홍대에서 쌓은 준비도가 국내 무대에 그대로 통하지 않는다.
무대가 커지면 거기서 다시 준비한다. 모노카피바라도 판을 깨면 HP·ATK·DEF가 초기화된다.

## 언제 나오냐

**그 일정에 코인을 넣었을 때.** 넣은 만큼 오른다.
착지 판정(대박·중박·운망)은 **크기를 정하지 않고 배수만 정한다.**

```
연습 일정에 착지한다
   → 연습실을 빌리고 트레이너를 붙인다 (코인이 나간다)
   → 넣은 코인만큼 기량이 오른다
   → 판정이 대박이면 그 오름폭에 배수가 붙는다
```

**돈을 안 넣으면 안 큰다.** 착지만으로는 아무것도 안 오른다 — 그 일정을 그냥 보낸 것이다.
현실도 같다. 연습실을 안 빌리면 연습이 안 된다.

## 자세히

### ① 컨디션 = HP 자리

모노는 **LAND 전투에서 HP가 닳고 휴식 칸에서 회복**한다. 우리도 같다.

```
무대에 선다 (노랑·초록)   →  컨디션이 닳는다
자유시간 · 본가 · 합숙소   →  컨디션이 찬다
```

**컨디션이 낮으면 무대 판정이 나빠진다.** 그래서 **쉬는 칸이 손해가 아니게 된다** — 코인을 안 주는데도 값진 칸이 되는 이유다.

> **병가(31)와는 엮지 않는다.** 병가는 모노폴리 GO 감옥 그대로다 — 밟으면 가고, 더블로 나온다. 새로 기획할 게 없다.

### ② 기량 = ATK 자리

연습 8칸이 **기량**을 올린다. 기량이 높으면 **무대 판정이 좋아진다.**

```
연습실에서 굴린다  →  기량 ↑
   ↓
음방 · 공연 칸에 떨어졌을 때  →  대박이 잘 난다
```

**연습이 판의 3분의 1인 이유가 여기서 나온다.** 소모가 아니라 **무대의 밑천**이다.

### 어떻게 미나 — 확률이다

**올리는 건 돈, 쓰는 건 확률.** 둘을 헷갈리면 안 된다.

| | 무엇 |
|---|---|
| **스탯을 올리는 것** | 그 일정에 **넣은 코인** (D-062) |
| **스탯이 미는 것** | 무대에서 **대박이 나올 확률** |

기량·케미·컨디션은 **대박이 나올 확률**을 민다. 결과 크기를 키우는 게 아니다.

```
기량 낮음  →  대박 8%
기량 높음  →  대박 14%
```

모노도 같다 — 등급롤 확률은 고정이고 스탯은 **전투 승률**을 민다. 우리는 전투가 없으니 **판정 확률**을 민다.

| | 미는 것 |
|--|---------|
| **기량** | 방송 · 공연 대박 확률 |
| **케미** | **공연** 대박 확률 |
| **컨디션** | 낮으면 확률이 **깎인다** |

| 칸 | 올리는 것 |
|----|-----------|
| 2 피지컬 · 4 미디어 대응 · 9 컨디셔닝 · 10 공부 | 그 분야 기량 |
| 7 하 · 12 중하 · 17 중상 · 22 상 | 기량 (뒤로 갈수록 크게) |

### ③ 케미 = DEF 자리

합숙 2칸(안무·보컬)이 **케미**를 올린다. 자유시간의 **멤버 시간(20)**도 조금.
케미가 높으면 **공연 쪽**이 좋아진다 — 군무는 혼자 잘해서 되는 게 아니다.

### 서사 조각 = 스킬 자리

**팬미팅 · 개인방송**에서 조각이 나온다. 무대가 아니라 **사람 얘기가 나오는 칸**이라 그렇다.
모노에서 TRAIN·던전이 **스탯 대신 스킬**을 주는 것과 같은 자리. → [067](./067_서사.md)

> 무대 칸은 **기록**을 남기고, 생활 칸은 **이야기**를 남긴다.

### 무대 칸은 준비도를 안 준다 ★

모노 88이 못 박은 것: **「LAND는 골드·전투만 — ATK 안 줌」**
역할이 겹치면 칸이 흐려진다. 우리도 같다.

| 칸 | 주는 것 |
|----|---------|
| 노랑 3 · 초록 3 | **코인 · 그날 무대 · 색 칩** |
| 결과 칸 16 | **준비도 · 서사 조각 · 코인 작게** |

| 중박 | 평소만큼 |
| 운빨망빨 | 거의 안 오른다 |

## 수치 잡을 때 지킬 것 (모노 교훈)

모노가 실제로 겪고 고친 것이다. 그대로 빌린다.

| | 내용 |
|--|------|
| **1:1로 나눠라** | 모노는 ATK가 테마 둘을 차지해서 MAXHP가 **3.3배 뒤처졌다.** 셋 중 하나가 칸을 독식하면 안 된다 |
| **base 대비 %로 봐라** | 같은 **+12**가 ATK엔 3.75%, DEF엔 13.3%였다. **횟수가 아니라 크기**로 판정 |
| **등급별 같은 패턴** | 모노는 대박12 / 보너스8 / 중박5 / 운빨2를 세 스탯에 같은 모양으로 재사용했다 |

## 연습 8칸이 왜 이렇게 많나 — 현실 근거 (2026-09-21)

**감으로 잡았는데 현실과 맞았다.**

| | |
|--|--|
| 우리 판 | 결과 칸 16 중 **연습이 8칸** — 판의 약 1/3 |
| 현실 | **연습생 육성 2년에 약 10억.** 데뷔 준비(3.6억)보다 크고 생애 주기에서 제일 긴 구간 |
| 회사 부담 | 교육비·숙식비를 **전액 선투자**하고 데뷔 후 정산에서 회수 |

> *"연습이 판의 3분의 1인 이유"*가 이제 근거를 갖는다 — **현실에서도 제일 많이 드는 데가 연습생이다.**
> 그리고 그 구간은 **수입이 0**이다. 쉬는 칸이 손해가 아닌 것과 같은 결이다.

상세 → [085](./085_경제_현실과판.md) · 원자료 `R22`

## 안 정한 것

- 컨디션·기량·케미의 **수치와 상한**
- 기량·케미가 확률을 **몇 %** 밀어주나
- 컨디션이 낮으면 판정이 **얼마나** 나빠지나
- ~~리셋 단위~~ → **판마다 리셋** (확정)
- [036 상태바](./036_아이돌_상태바_백로그.md)에 셋을 다 보여주나

## 하지 않음

- 무대 칸(노랑·초록)에 준비도 주기 (모노 88 원칙)
- 컨디션·기량·케미를 **한 숫자**로 합치기 (준비도는 묶음 이름이지 한 숫자가 아니다)
- 컨디션을 **병가와 엮기** (병가는 GO 감옥 그대로)
- 자유시간·생활 거점에 코인을 크게 주기 (쉬는 칸이다)
- 수치를 문서에 하드코딩 (표는 CSV로)
