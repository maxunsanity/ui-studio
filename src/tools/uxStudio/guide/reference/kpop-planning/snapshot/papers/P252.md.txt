## 1. 역할 분리 및 전체 연결 구조

### 1-1. 게임(아티스트) vs 독립 음악 앱(청취자·팬) 역할 분담
| 영역 | 케이팝몬스터즈 게임 (아티스트 측) | 독립 음악 앱 (청취자·팬 측 · 외부 제작 연동) |
|---|---|---|
| **정체성** | 팀 육성·음반 제작·보드 활동·페스티벌 출전 신청 | 감상·발견·차트 확인·공연 관람·숏츠·투표·인기 응원·직접 업로드 |
| **핵심 기능** | 멤버 캐스팅, 보드 6칸/월드 40칸 무대 활동, 주간·월드 신청 | 5탭 상업용 음악 앱 UX, 음원/영상 업로드, 숏츠 편집, 사람/AI 검수 연계 |
| **데이터 기준** | 게임 내 팀·예명·유닛·발매곡·인기 재화 획득량 생성 | API 연동으로 내 발매곡·크루 음악·차트·투표·보관함 단일 원장 동기화 |

- **기존 내부 시안과의 변경점:** 초기 로컬 시안 단계에서는 게임 안에 음악 3탭과 임시 시뮬 화면을 함께 두었으나, **최종 확정안은 게임과 별개로 실행되는 상업용 독립 음악 앱**으로 분리하되, 계정·음원·보관함·투표·인기 원장은 단일 API 계약으로 공유합니다.
- **상업용 UX 원칙:** 외부 개발·시험용 보조 패널이나 수치 조작 화면은 모두 제거하고, 실제 이용자가 쓰는 상업용 음악 앱(5탭 표준 구조)으로 정돈합니다.

### 1-2. 상업용 음악 앱 5탭 정보 구조 (IA)
1. **홈 (Home):** 내 팀의 최신 발매곡·크루 신곡 강조 박스, 오늘의 추천 차트, 진행 중인 주간/월드 페스티벌 배너, 아티스트 페이지 바로가기
2. **검색 · 둘러보기 (Explore):** 장르별(댄스 팝·발라드·힙합·R&B)·분위기별 탐색, 아티스트/유닛/예명 통합 검색, 내 크루 음악 모아듣기
3. **차트 (Charts):** 일반(참고/신곡), 주간 페스티벌(동레벨 100명), **월드 페스티벌 5개 탭(`전체 · 국가 · 친구 · 크루 · 인기`)**
4. **공연 · 숏츠 (Stage & Shorts):**
   - **공연(스테이지):** 고정 100명 관람 그룹 무대, 주간 경쟁자 무대, 월드 상위권 관람 키 무대, 보드 6칸·월드 40칸 실황·다시보기·내 공연 PIP
   - **숏츠(Shorts):** 세로형 짧은 영상 발견(추천 / 구독 / 친구·크루 피드), 채널 구독, 앱 내 하이라이트/사진 컷씬 편집
5. **보관함 (Library):** 찜한 곡(하트)·찜한 숏츠, **2단계 확정 투표 입구**, 보유 인기 재화 지갑 및 사용 이력, 업로드·검수 알림함

## 2. 통합 계정 · 내 음악/크루 음악 · 크레딧 연동

- **통합 계정 자동 동기화:** 게임 계정과 음악 앱 계정이 연동되어, 이용자가 앱에 로그인하면 **내 팀이 발매한 곡**, **내가 속한 크루의 공유 음악**, **유닛·예명 크레딧**이 자동으로 모아집니다.
- **내 음원 강조 표시:** 음원 목록·차트·보관함에서 내 팀 발매곡은 전용 박스와 `'내 발매곡'` 배지로 즉시 구분합니다.
- **예명·유닛 크레딧 반영:** 게임 내 아이돌 멤버에게 부여한 예명과 솔로/유닛/전체 팀 참여 정보가 앨범·트랙 크레딧 및 아티스트 페이지에 그대로 노출됩니다.
- **내 순위 고정 표시:** 50위 밖으로 밀려난 내 곡도 차트 목록 하단(또는 상단 내 순위 카드)에 현재 내 순위와 점수를 고정 표시합니다.

## 3. 음원 이원화 · 직접 업로드 · 숏츠 편집 · 사람/AI 검수

### 3-1. 음원 이원화 (내부 발주곡 vs 창작곡)
| 구분 | 내부 발주곡 (사전 제작) | 창작곡 (이용자 업로드) |
|---|---|---|
| **공급 방식** | 외부 음원 제작처 발주·수급 곡 (**4장르×각 8곡 = 32곡**, 주력 댄스 팝 12곡 확장 시 **36곡**) | 이용자가 직접 만든 음원 파일(**`mp3`, 3분 이내**) 앱 내 업로드 |
| **장르 분류** | 댄스 팝 · 발라드 · 힙합 · R&B (4장르 표준 ID 체계 유지) | 장르 태그 선택 + 앨범 표시 **`「창작」`** 배지 자동 부착 |
| **주간 페스티벌** | 창작곡과 동일한 주간 100명 순위표에서 공정 경쟁 (창작 별도 가산 없음) | 주간 100명 출전 허용 (크루 공유 및 영상 다듬기 흐름 연결) |
| **월드 페스티벌** | 전체·국가·친구·크루·인기 탭 경쟁 | **월드는 내부곡 영상끼리만 겨룬다(현중 11/24 18:02)** |

#### 3-1-1. 내부 발주곡 4장르 × 4분위기 × 3단 템포 가이드 (32~36곡)
외부 음원 제작처에 정식 발주하는 내부곡은 한 시즌 최대 발매 8곡 기준으로 한 장르만 내도 겹치지 않게 **장르별 8곡(주력 댄스 팝 12곡 확장 가능)**으로 구성하며, 기존 게임 설정의 장르·분위기·템포·보컬·언어 체계를 그대로 따릅니다.

| 장르 (ID) | 수량 (확장) | 기준 BPM · 조성 · 사운드 | 대표 분위기 | 보컬 · 인게임 주 사용처 |
|---|---|---|---|---|
| **댄스 팝** (`dance_pop`) | 8곡 (**12곡**) | 120 BPM · C major · 경쾌한 신스, 팝 드럼, 중독성 훅 | 청량 · 에너제틱 | 그룹/유닛 타이틀, 댄스 숏츠 챌린지, 주간/월드 주력 무대 |
| **발라드** (`ballad`) | 8곡 | 76 BPM · C major · 피아노·스트링, 후반 클라이맥스 | 감성 · 서정 | 보컬·화음 중심, 팬송·기념 앨범·서사 컷씬 무대 |
| **힙합** (`hiphop`) | 8곡 | 94 BPM · A minor · 강한 808/드럼, 리드미컬 그루브 | 파워풀 · 퍼포먼스 | 랩 플로우·딕션+강렬한 훅, 퍼포먼스·경연 스테이지 |
| **R&B** (`rnb`) | 8곡 | 92 BPM · C major · 부드러운 EP·세븐스 코드, 따뜻한 베이스 | 몽환 · 무드 | 섬세한 음색·코러스, 야간/도시 콘셉트·감상용 플레이리스트 |

- **R&B ID 분리 및 3단 템포 배분:** 임시로 댄스 팝에 묶여 있던 `R&B`를 정식 `rnb` ID로 분리하고, 분위기 4종(`청량·파워풀·몽환·감성`)과 템포 3단계(**느리게 80 / 보통 110 / 빠르게 140 BPM**)를 장르 안에서 고르게 배분합니다.
- **보컬 편성 9종 · 언어 3종 배분:** 보컬 편성 9종(남/여/혼성 솔로·듀오·그룹 + 연주곡)을 기본 32곡 기준 **그룹 15곡(여6·남6·혼3) · 솔로 8곡(여4·남4) · 듀오 6곡(여2·남2·혼2) · 연주곡 3곡**(36곡 시 댄스 팝 그룹·솔로 중심으로 +4곡)으로 안배하고, 언어 3종은 **한국어 55~60% · 영어 25~30% · 일본어 10~15%** 비중으로 제작합니다.

#### 3-1-2. 외부 제작처 납품 규격(3구간) · 메타데이터 · 권리 조건
- **납품 길이(3구간 세트):** 인게임 길이 규격에 맞춰 **3분(180초 풀곡) + 1분(60초) + 30초(숏츠·미리듣기 핵심 컷)** 3개 구간을 모두 납품합니다(앱 임시 미리듣기 20초 연동 포함).
- **보컬판 · 인스트(MR) · 포맷:** 모든 보컬곡은 **가창 완성본 + 인스트루멘털(MR)** 세트로 납품하며, 마스터 **`WAV`(44.1/48kHz, 24bit)** + 스트리밍용 **`MP3`(320kbps)** 동시 제출, **`-14 LUFS` 전후(트루 피크 `-1.0 dBTP` 이하)** 음압 정규화를 적용합니다.
- **메타데이터 · 권리 범위:** 트랙 ID·장르(`dance_pop/ballad/hiphop/rnb`)·분위기·템포 구간(80/110/140)·실제 BPM·조성·보컬 편성·언어·하이라이트 초수 표를 첨부합니다. **게임 내 사용, 독립 음악 앱 스트리밍, 홍보 영상 활용**이 모두 포함된 **상용 독점(매절) 저작권**으로 계약합니다(기존 테스트 샘플 10곡은 개발 확인용이며 발주 수량과 별도).
### 3-2. 앱 내 직접 업로드 & 사진 컷씬·숏츠 편집기
- **직접 업로드 규격:**
  - **창작 음원:** `mp3` 포맷, 재생 시간 **3분(180초) 이내**, 저작권·이용약관 동의 체크 후 등록.
- **사진 컷씬 자동 연출 & 숏츠 편집 기능:**
  - 주간 페스티벌은 영상 등록이 필수이며, 음원만 올린 이용자를 위해 **게임 내 아이돌 이미지를 연속 연출하는 자동 뮤직비디오**로 대체하고 **사진 컷씬 편집(순서·전환·자막) 기능**을 제공합니다.
  - 앱 내 **숏츠 편집기**에서 보유한 공연 실황/뮤직비디오/사진 컷씬 구간을 잘라 세로 숏츠 게시물로 바로 생성·게시·수정·삭제할 수 있습니다.

### 3-3. 사람 / AI 검수 파이프라인
- **검수 대상:** 외부 업로드 창작 음원(`mp3`)과 공개 숏츠 게시물.
- **검수 흐름:** 업로드 완료 → **검수 중(비공개/제한 노출)** → **사람 또는 AI 검수 통과** 시 정식 등록 / **반려** 시 사유와 함께 재업로드 안내를 알림함으로 전송.
- **안전 경계:** 검수 통과 전까지는 공개 상위 노출에서 제외하며, 권한 철회·삭제 시 캐시 재생까지 즉시 중단합니다.

## 4. 앨범 제작·발매 흐름 및 3종 차트 분리

### 4-1. 게임 내 앨범 제작·발매 규칙
- 한 곡 = 한 장의 싱글이며, 데뷔곡 포함 **시즌 최대 8곡**을 팀이 함께 사용합니다(솔로/유닛으로 바꿔도 팀 시즌 한도 8곡 유지).
- 제작 흐름: **참여 멤버 선택(솔로/유닛/팀) → 파트 지정(보컬·랩·코러스·제작) → 간편/프로 옵션 & 제작비 확인 → 음원 연결 및 미리보기 → 재킷·곡명·소개 편집 → 발매 조건 충족 후 발매 완료**.
- 발매 전 예상 시작 순위는 현재 팀 평균 능력·참여자 능력·보유 팬 수·직전 앨범 성적으로 계산해 범위로 안내합니다.

### 4-2. 세 차트의 역할·보상·데이터 완전 분리
| 차트 구분 | 데이터 기준 | 보상 종류 | 용도·핵심 규칙 |
|---|---|---|---|
| **앨범 차트 (발매 직후 1일)** | **더미 데이터 고정** | 한 바퀴 보상 연계 | 실시간 랭킹과 분리된 24시간 앨범 이벤트. 대표곡 우대 + 구작 누적 기여 반영 |
| **주간 페스티벌 (1~8주)** | **실시간 (동레벨 100명)** | 레이싱 연료 + 7일째 버프 | 친구 먼저 묶고 빈자리는 엔터파워 비슷한 상대로 충원. 등수별 월드 가산점 이월 |
| **월드 페스티벌 (9주차)** | **실력별 리그 + 1~5분 스냅샷** | 인기 재화 C | 실력별 리그(1부·2부…) 편성 → 그룹당 **상위 4~10% 동시 차트 인** → 파이널 1,000명 |

### 4-3. 월드 페스티벌 승격 · 6개 순위 탭 · 크루 협업 · 곡 배틀
- **실력별 리그 + 동시 차트 인 승격 (1,000만 명 예시):**
  - 9주차 시작 전 `1~8주 가산점`과 엔터파워로 **실력별 리그(1부·2부·3부…)**를 나누고 리그 내 100명 그룹을 배정합니다.
  - **1차 예선(1~2일):** 그룹당 상위 5명(5%) 차트 인 → 50만 명 진출
  - **2차 본선(3~4일):** 그룹당 상위 5명(5%) 차트 인 → 2.5만 명 진출
  - **3차 준결(5일):** 그룹당 상위 4명(4%) 차트 인 → **파이널 1,000명 확정**
  - 그룹이 100명 미달이거나 동점이면 비율 절삭 후 **와일드카드**로 정원을 맞춥니다.
- **월드 5개 순위 탭 (1~5분 준실시간 스냅샷):**
  - **`전체` · `국가` · `친구` · `크루` · `인기`** 5개 탭을 제공합니다.
  - 서버는 **1,000등까지 정밀 계산**하고 화면에는 **상위 50명**까지 노출하며, 50위 밖 이용자는 **내 순위와 내 점수**를 별도 고정 표시합니다.
  - 전 서버 통합 탭은 **1~5분 주기 스냅샷(준실시간)**으로 동기화해 동접 수백만 명 부하를 안정적으로 처리합니다.
- **크루 협업 출품:**
  - 창작곡을 만든 이용자가 **음악 파일만 크루에 공유**하면, 음원 제공자를 포함한 **크루원 각자가 영상을 제작**합니다.
  - **크루 내 투표(참고 지표)**를 거쳐 **크루장이 최종 월드 출전 영상 1편을 확정**합니다(주간·월드 출품 모두 가능).
  - 원소유자가 공유를 철회하면 새 크루 출품은 즉시 차단되며, 이미 공식 접수된 출품은 회차 마감 규칙을 따릅니다.
- **인기 재화 & 곡 선호 배틀:**
  - **인기 응원:** 월드 차트 → 인기 → 곡 선택 → 수량 확인 → 사용 → 해당 곡의 기여 인기와 인기 탭 순위 갱신(투표·찜·레이싱 연료와 완전 분리).
  - **곡 선호 배틀:** 두 곡 중 선호 곡을 고르는 별도 배틀 모드를 제공하며, 결과는 추천/공식 투표와 분리된 배틀 원장에 기록합니다.
- 월드는 내부곡 영상끼리만 겨룬다(현중 11/24 18:02).

## 5. 공연 · 스테이지 상세 규칙

### 5-1. 고정 100명 관람 그룹 · 주간 명단 · 다른 그룹 보기
- **집합 정의:** `F`(유효 친구), `C`(가입 크루원, 본인 제외), `S = F ∪ C`(중복 제거 합집합), `E`(같은 등급 일반 충원 후보), `T`(선발된 일반 유저), `N = S ∪ T`.
- **기본 관람 명단 (`N`):**
  - 입장 시 **등급별 기본 100명**을 고정 배정합니다.
  - 친구·크루(`S`)는 중복을 제거해 **전원 포함**하며, `S`가 100명을 넘으면 초과를 그대로 허용합니다(일반 충원 `T = 0`).
  - `S`가 100명 미만이면 부족분만 같은 등급 일반 유저(`T`)로 채웁니다. 후보가 모자라면 `미충원` 상태를 표시합니다.
- **주간 대회 모드 (`V = W ∪ S`):** 해당 주간 실제 경쟁 상대(`W`) 전원에 친구·크루(`S`)를 겹침 없이 추가해 노출합니다.
- **다른 그룹 보기 (명시 재설정):** 설정에서 그룹을 바꾸면 **일반 충원(`T`)만** 새로운 같은 등급 유저로 교체하고, 친구·크루(`S`), 주간 상대(`W`), 출전곡·점수·투표·시청 이력·보유 관람 키는 그대로 유지합니다.

### 5-2. 보드 6칸 + 월드 40칸 실황 · PIP · 월드 상위권 관람 키
- **보드 6칸 콘셉트 (발매 전 / 발매 후 무대):**
  - `방송 27`: 거리 인터뷰 → 예능 방송국 (`인터뷰·예능·무대 토크`)
  - `방송 28`: 온라인 홍보방송 → 라디오 방송국 (`보이는 라디오·라이브`)
  - `방송 30`: 신인 소개방송 → 음악 방송국 (`신인 소개·음악방송`)
  - `공연 32`: 거리 버스킹 → 라이브 공연장 (`소규모 라이브`)
  - `공연 33`: 공원 버스킹 → 쇼케이스 공연장 (`신곡 쇼케이스`)
  - `공연 35`: 오픈마이크 무대 → 콘서트장 (`오픈마이크·콘서트`)
- **월드 40칸 공연 보드 전환:** 월드 페스티벌 신청 성공 후 게임 보드로 복귀하면 연습실·녹음실·공연장 등이 월드 간판으로 전환되고 **1회 안내 모달(`월드 공연 보드로 전환됐어요`)**이 표시되며, 앱과 보드 양쪽에서 **내 공연 PIP**와 실황/다시보기 상태를 확인할 수 있습니다.
- **월드 상위권 관람 키:** 내 100명 명단(`N`)·주간 명단(`V`) 밖의 월드 상위권 무대를 둘러볼 때만 **월드 전용 관람 키**를 사용합니다(기존 `N`/`W` 명단은 덮어쓰지 않음).
- **오디오 초점 전환:** 한 번에 하나의 활성 오디오만 재생하며, 게임↔앱 또는 PIP↔전체 화면 전환 시 이전 재생 위치를 보존합니다.

## 6. 독립 숏츠 상세 규칙 (관심사 · 피드 · 100만 동접 · 왕복)

### 6-1. 최초 관심사 온보딩 & 3종 피드
- **최초 관심사 선택:** 장르(`댄스 팝 · 발라드 · 힙합 · R&B` 복수 선택)와 무대 스타일(`공연 · 댄스 · 보컬 · 비하인드 · 인터뷰`)을 고르며, `'나중에'`로 건너뛰어도 감상을 막지 않습니다(임의 기본값 강제 생성 금지).
- **3종 피드 구성:**
  1. **추천:** 취향(관심사·실제 시청 반응) + 구독 채널 + 친구·크루 채널 + 새 창작자를 혼합하되, 같은 창작자 연속 노출을 제한하고 미시청을 우선합니다.
  2. **구독:** 사용자가 명시적으로 구독한 아이돌/팀 채널만(팀 구독 시 멤버 개인·제작자 타 팀 자동 구독 금지). 비구독 영상 혼입 금지.
  3. **친구·크루:** 유효한 관계(`전체 / 친구 / 크루` 필터)의 공개 게시물만 미시청 우선 → 최신순 정렬.
- **관계 8조합 & 빈 상태 처리:** `(친구 F 있음/없음) × (크루 C 있음/없음) × (구독 S 있음/없음)` 8가지 조합 모두에서 빈 상태 안내와 즉시 이동 버튼(추천 이동·채널 찾기)을 제공하며, 조회 실패를 `'관계 없음'`으로 잘못 덮어쓰지 않습니다.

### 6-2. 동접 100만 명 대응 2단계 편성 & 왕복 복원
- **2단계 피드 편성:**
  1. **1단계 후보 축소:** 관심사별 공통 후보·채널 신작·관계 게시물·새 창작자 색인에서 제한된 후보를 취득(인기 채널 신작도 구독자에게 복사하지 않고 공유 신작 색인 + 증분 커서 사용).
  2. **2단계 개인별 확정:** 최신 권한·숨김·시청 이력·중복을 걸러 짧은 재생 큐와 다음 커서를 전달(추천 계산 경로와 영상 CDN 전달 경로 분리).
- **음원 보기 ↔ 숏츠 ↔ 스테이지 왕복 및 위치 복원:**
  - `숏츠 → 곡 보기` / `숏츠 → 원공연 보기` / `음원 → 관련 숏츠` / `스테이지 → 하이라이트` 이동 시 각 화면의 **현재 `shortId`·피드·커서·영상 재생 위치·음원 큐·스테이지 PIP 상태**를 그대로 보존해 뒤로 돌아와도 끊기지 않습니다.

## 7. 단일 원장 · API 계약 · 예외/운영 경계

### 7-1. 보관함 찜 · 2단계 확정 투표 · 원장 단일화
- **보관함 찜 통합:** 음원과 숏츠에서 찜(채운 하트 `'찜 완료'`)한 항목을 단일 보관함에 유지합니다. 단, **곡 찜**과 **숏츠 게시물 찜**은 대상을 구분해 혼동하지 않습니다.
- **2단계 확정 투표 (원장 검증):**
  - 감상 → 찜 → 보관함(또는 곡 상세) → 대회/회차 확인 → **`'이 곡에 투표하시겠습니까?'` → 확정**.
  - 음원 목록에서의 직접 1클릭 투표는 금지하며, **확정된 투표는 취소할 수 없습니다.**
  - 확정 순간 서버가 최신 팀·회차·자격·남은 한도·중복 여부를 일괄 검증합니다.
