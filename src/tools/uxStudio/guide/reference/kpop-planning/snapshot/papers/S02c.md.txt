# S02c · 플레이 로그 툴

**이 문서는** 실제 플레이 기록을 같은 날·같은 성장 지점에서 비교한다는 원목표와, 실시간 저장본·파일 분석 두 도구의 현재 범위를 설명하는 기획서입니다.

**보는 법** 「기록 받기」 → 「비교하기」 순서로 읽습니다. 기존 생산자 이름은 발란스 시뮬레이터이며, 실시간 도구 P110R02와 실측 분석 P110R03은 아래에서 역할로 구분합니다.

**지금 상태** 실시간 저장본 스냅샷·JSON 파일 분석의 입력/비교/렌더 코드가 있습니다. [P171](../개발진행기획_v01/콘텐츠별_v03/발란스시뮬레이터_기획서.md)의 로그 생산·내려받기와 실제 도구 연결·업로드·저장 성공은 이번 읽기 감사에서 확인하지 않았습니다. 비교 화면 전체가 미개발이라는 뜻도, 운영 검수 완료라는 뜻도 아닙니다.

## 기록 받기

이전 문서는 발란스 시뮬레이터의 「📥 로그」가 굴림마다 일차·주사위·도착 칸·돈·팬·능력·건물 단계를 JSON Lines로 남기며 최근 2만 줄까지 받는다고 설명했습니다(임시 값). 이 생산자의 현재 동작은 이번 미확인입니다.

실시간 저장본 도구(P110R02)는 게임 프로필 설정의 `save_key`가 가리키는 브라우저 저장본을 읽습니다. 실측 분석(P110R03)은 `ledger` 배열과 `rolls` 숫자가 있는 JSON 객체(전체 저장본 또는 `state`를 가진 객체), 또는 두 도구의 브리지 라이브러리를 읽습니다. JSONL 생산 로그와 이 객체가 자동 호환된다는 뜻은 아닙니다.

초기에 한 번 읽고 이후 「불러오기」로 저장본을 다시 읽으며, 축 변경은 이미 읽은 상태를 다시 그립니다. 기준 자동 플레이 결과는 캐시합니다. 「저장 → 실측 분석」은 브리지의 최근 12개 보관이며 게임 저장·파일 내려받기·게임 장부 비우기와 다릅니다. 실제 조작은 미검수입니다.

## 비교하기

원목표는 같은 일차에서 실제 기록과 시뮬 계산의 돈·팬([P108](../개발진행기획_v01/콘텐츠별_v03/팬과수익_기획서.md))·엔터파워([P172](../개발진행기획_v01/콘텐츠별_v03/엔터파워_기획서.md))·능력([P107](../개발진행기획_v01/콘텐츠별_v03/아이돌능력_기획서.md)) 평균을 나란히 보고 차이가 벌어지는 지점을 찾는 것입니다.

현재 도구는 각 스냅샷의 자기 일차에 해당하는 기준 건설률과 돈·팬·주사위/루비·굴림/바퀴·보관된 장부 집계를 보여 줍니다. 실시간의 일차/팬 축 선택과, 모든 선택 기록을 공통 cutoff까지 잘라 다시 합산하는 기능은 다릅니다. EP·능력 평균의 전체 비교도 현재 읽은 도구에서 확인한 지원 지표가 아닙니다.

충전(`charge`)·상점(`buy`)의 부분 집계와 받은 주사위 합은 있지만, 개발용 지급·선물·출석·마일스톤·환불까지 무료/유료로 가르는 원정책 전체와 같지는 않습니다. 원목표와 남은 비교 범위를 보존하며 실측 파일·실시간 연결의 정상 작동을 새로 판정하지 않습니다.
