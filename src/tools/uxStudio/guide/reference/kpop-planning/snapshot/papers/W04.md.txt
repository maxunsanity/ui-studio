# 04 · 성장·건물·경제

**이 문서는** 전체 기획서 4장으로, 아이돌 성장·건물([P106](../개발진행기획_v01/콘텐츠별_v03/건물성장_기획서.html)) 증설·엔터재화(엔터파워)·돈의 순환이 서로 어떻게 맞물리는지 설명합니다.

**보는 법** 같이 여는 시뮬레이터: [발란스 시뮬레이터](/docs/planning/idle-sim.html). 「건물」 → 「엔터파워」 → 「성장·40자리」 → 「경제」 순서로 읽습니다.

**지금 상태** 건물 증설, 엔터재화 표(11/18 라이브)·발란스 툴 확인판, 1일차·2일차 배수 잠금, 성장 단계, 팀 합류, 기획사 스탯(스태프 고정 능력치 합 · 코드 기준)은 개발되어 있습니다. 11/18 결정(엔터재화 · 기획사 능력 평균 표 · 팀 등급 = 팀 아이돌 능력 합)을 바꾸는 코드는 현재 개발되지 않음, 진행 중입니다. 세션의 캐스팅 문턱 판정은 아직 건물 기준으로 동작하며, 현중 12:34 지시로 지금 상태 유지입니다. 아래 숫자는 현재 세팅값입니다.

## 건물

건물은 9종(사옥 · 보컬 녹음실 · 댄스 연습실 · 콘서트장 · 뷰티 스튜디오 · 예능 방송국 · 프로듀싱 스튜디오 · 팬샵 · 아카데미)이고 각각 30단계까지 오릅니다. 보드([S03](../시스템기획/S03_보드주사위경제.md))의 건물 칸 24곳에 도착해 돈이 충분하면 그 건물이 자동으로 한 단계 오릅니다. 단계가 오를수록 그 칸의 돈 보상과 레슨 성장이 커집니다. 부서진 건물은 지은 비용의 50%로 고칩니다. 건물 비용 배율은 시즌 1·2 모두 `cost_scale = 40`, `season_repeat_cost_mult = 1.0`입니다.

건물은 시즌 안의 계기판이며, 시즌이 끝나면 건물 단계·맵 위 팬·건물 악개·도착 팬 돈만 초기화됩니다. 건물 레벨업으로 받은 엔터재화는 엔터파워에 남고, 시즌 초기화 뒤 같은 단계를 다시 올리면 다시 받습니다(11/18).

## 엔터파워

엔터파워는 잠금·상한 해제용 영구 지표이며, **네 지급처에서 받은 엔터재화를 쌓은 값**입니다(현중 11/18 10:06 · 옛 4원천 식은 버림).

| 지급처 | 비중 | 무료 1년 합(라이브) |
|---|---:|---:|
| 건물 레벨업 | 45% | 4,046 |
| 스태프 카드(덱 칸 첫 입장) | 25% | 2,250 |
| 아이돌 능력 단계 상승(전직 4번) | 20% | 1,802 |
| 팬 카드(덱 칸 첫 입장) | 10% | 902 |
| **합** | | **9,000** |

팬클럽 회장 카드의 엔터재화는 칸당 한 번 제한 없이 새 회장마다 그대로 줍니다(회장 1명당 +902 · 현중 11/19 13:55). 상한은 없습니다(현중 11/19 14:55).

무료 유저 1년 9,000개 · 하루 12시간 기준이고(현중 09:48), 상한은 없습니다(현중 11/19 14:55). 엔터파워는 최고 도달 값(받은 누계)과 지금 값(최고 도달 값 − 시즌 투자) 두 값이며, 해금은 최고 도달 값으로 읽고 게이지에 두 값을 모두 표기합니다(현중 12:44). 시즌 시작 투자는 안 함 · 10% · 20% · 30% 중 하나입니다(현중 10:27~10:28). 한 번 오른 엔터파워는 내려가지 않고 계약 해지로도 빠지지 않습니다(현중 09:24). 값 출처는 `data/game/enter_currency_config.csv` · `enter_currency_grant.csv`(11/18 12:49 발란스(비앙카) 적용)이고 상세는 [P172 1-1](../개발진행기획_v01/콘텐츠별_v03/엔터파워_기획서.html)입니다. 코드의 엔터파워 계산은 아직 옛 4원천 식으로 동작하며, 바꾸는 코드는 현재 개발되지 않음, 진행 중입니다.

배수는 이 엔터파워로 엽니다. 처음부터 ×1 · ×2 · ×5, ×10은 312, ×20은 1,075, ×50은 1,872, ×100은 2,688, ×200은 3,518, ×500은 4,358, ×1000은 5,208입니다(라이브 `dice_mult_unlock_rule.csv` · 11/18 12:49). 처음 기본 배수는 ×5입니다. 1일차에는 ×10까지, 2일차에는 ×20까지만 쓸 수 있고 3일차부터는 제한이 없습니다.

## 성장·40자리

활성 자리는 40자리입니다. 아이돌 30 · 스태프 6(아이돌 연계) · 순수 기획사 3 · 팬클럽 회장 1. 배치 칸에는 이름(담당 업무)이 보입니다. 카드는 자리마다 12장, 합 480장입니다.

아이돌 성장 단계 문턱(멤버 평균 능력, 현재 세팅)은 연습생 0 · 데뷔조 205 · 라이징 스타 500 · 톱스타 800 · 월드스타 1,200입니다. 아이돌 12종 카드 합은 108,000(세부 18개 각 6,000), 연계 스태프 6자리 72종 합은 16,200입니다. 스태프 한 명의 고정 능력은 등급에 따라 `+600 / +1,200 / +1,800 / +2,700 / +3,600`이고, 아이돌 짝 라포 보너스는 단계 1·2·3에 `+5% / +10% / +15%`(같은 아이돌 더하기, 상한 15%)입니다. 스케줄 레슨 3칸의 성장량(`lesson_gain`)은 새벽 녹음 0.5 · 댄스 연습실 배틀 1.2 · 오디션 심사석 2.0입니다.

캐스팅 칸은 엔터파워로 30명까지 엽니다. `cast01~04`는 `650 / 1,353 / 2,078 / 2,816`에 +1명씩(누적 2~5명), `cast05~12`는 `3,566 / 4,324 / 5,090 / 5,862 / 6,639 / 7,422 / 8,209 / 9,000`에 `+2 / +2 / +2 / +3 / +3 / +4 / +4 / +5`명입니다. 출격 팀 칸은 처음 5명이고, `team_slot_06~10`은 `4,020 / 5,051 / 6,094 / 7,147 / 8,209`에 하나씩(11/18 12:49 라이브 값) 열려 최대 10명입니다.

기획사 능력은 엔터재화가 아니라 지금 앉은 스태프 기준 평균 능력을 보여 주는 표이고, 아이돌 능력을 키우는 공식(앞으로 얻는 양)에 들어갑니다(현중 11/18 13:55). 스태프 · 팬클럽 회장 능력은 앉아 있는 동안 앞으로 얻는 양에만 붙습니다(13:31). 팀 등급은 팀 아이돌 능력 합으로 정하고(13:56), 지금 문턱은 루키 0 · 대세 1,100 · 톱티어 2,400 · 국민돌 8,300 · 글로벌 아이콘 8,600(8,600 = 무료 유저 1년 재능선 첫 멤버 도달에 맞춤 · 현중 11/19 14:57 · `data/idol_ability_sim/idol_team_grade.csv` need_value)입니다. 지금 코드는 배치된 스태프 고정 능력치의 합을 씁니다. 게임 화면에 스태프 배치 상태가 없으면 기획사 스탯 0 · 루키로 보입니다. → 바뀜(11/19 비앙카 · 현중 11/19 08:47 결정 「팀 등급 마지막 단계는 18,000으로 해」): 팀 아이돌 능력 합 문턱 루키 0 · 대세 2,000 · 톱티어 5,000 · 국민돌 12,000 · 글로벌 아이콘 18,000(옛 값. 1인 1,800 상한은 현중 11/19 10:37에 없앰 → 현중 11/19 13:51 루키 0 · 대세 1,000 · 톱티어 3,000 · 국민돌 7,000 · 글로벌 아이콘 8,400로 바뀜 → 현중 11/19 14:57 루키 0 · 대세 1,100 · 톱티어 2,400 · 국민돌 8,300 · 글로벌 아이콘 8,600로 바뀜) → 바뀜(11/19 비앙카 · 현중 11/19 08:46 결정 「각각의 스태프에 해당 되는 능력만 오르면 되는 거구」 · 유르넷 전달): 카드 %는 그 스태프가 맡은 세부에만 붙음(자리별 · 직무→세부 = card_line_split 18세부) · 기획사 3자리 · 회장 카드는 각자 효과 줄 · seat_card_star.staff_gain_pct ★1~5 1.67 · 2.67 · 3.33 · 5 · 6.33(한 사람 12장 37.68%)

## 경제

기준은 한 시즌 63일(9주)입니다. 주사위 1개는 50원입니다.

| 유저 | 하루 주사위(현재 세팅) | 63일 기준 |
|---|---|---|
| 무료 유저 | 800~900개(일일 미션·미니게임 포함). 미션을 다 깨는 기준 896.1개 | 약 5.0만~5.6만 개 |
| 헤비 유저 | 구매 6,349개 + 무료 = 약 7,149개 | 실결제 **2,000만 원** = 구매 주사위 **40만 개** |

첫 시작은 주사위 50개·돈 0입니다. 시즌이 넘어가면 돈·주사위·루비·인기·행복·우정 포인트는 그대로 가져가고, 연료만 주 끝에 소멸합니다. 12분마다 1개씩 최대 30개까지 자동 충전됩니다.
