<p>화면 흐름: 보드 · 시설 → HUD 팬덤 게이지 → 마일스톤 보상 · 스샷 미완 · 이식 비교 해당 없음</p>

<ul>
<li>공통 코드: 팬 계산·세 활성층 HUD·마일스톤 수령 계산 경로가 있습니다. 이 문서의 전용 표시·보상 화면과 상위 게임 진입의 직접 연결은 미확인입니다.</li>
<li>문서 시안: 팬덤 게이지 시뮬레이터는 시설·능력의 팬 생김과 피드·페스티벌의 등급 바뀜을 별도 메모리로 보여 줍니다. 인원·비율은 임시이며, 원표·게임 지갑·상대 팬 기록과 연결되지 않습니다.</li>
<li>조회·저장: 현재팀 조회는 읽기 전용입니다. 공통 팬 계산의 writer는 선택한 로컬 저장 공간과 테스트 scope 조건에 따라 팬 기록에 닿을 수 있습니다. 이 문서 시안의 메모리와 같은 저장 방식이 아니며, 실제 저장 성공은 미검수입니다.</li>
</ul>

<p>한 막대를 등급 색(라이트 · 팬 · 코어 · 콘크리트)으로 쌓고, 막대 위 눈금 = 마일스톤 단(기존 8단 시안). 사람 수가 많아지면 무리 단위(1 → 10 → 100 …)로 바꿔 그립니다.</p>

<p>위 네 층은 P196·문서 시안의 제안입니다. 현재 <code>fan_tier</code> 원표의 별도 팬 층은 라이트로 합침/removed이고, 공통 HUD는 라이트·코어·콘크리트만 합합니다. 원문의 여덟 단계 문턱과 현재 보상 그룹, 문서 시안의 다섯 후보 눈금은 서로 다른 자료입니다. 현재 보상 항목은 보상 마스터를 읽으며, 원 제안의 옛 금액을 현재 지급값으로 사용하지 않습니다.</p>
