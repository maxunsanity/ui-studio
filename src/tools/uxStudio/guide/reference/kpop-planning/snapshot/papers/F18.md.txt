## 3. 성장형 · Board1 상한 정의 (지시 고정)

파이널 기획에 아래를 **그대로** 박아라. 재해석으로 해외/아레나를 Board1 MAX에 넣지 마라.

| 항목 | 정의 |
|------|------|
| 보드성장 = 지역성장 | 같은 말 (050·062) |
| 급 영구 상승 | 같은 색 **덕질 10개** → 성장 칸 **하나** +1 |
| 대박 | **그날만** 위 급. 영구 성장 아님 |
| 성장 칸 | 노랑 27·28·30 · 초록 32·33·35 뿐 |
| Board1 노랑 | 전부 **온라인** (라디오↑·지상파·해외 아님) |
| Board1 초록 | **버스킹 → 클럽** (소극장·아레나 아님) |
| Board1 상한·판 넘김 | 노랑3+초록3 **여섯**이 전부 상한 급 |
| **MAX 룩** | 그 여섯이 찬 **홍대 판 맥스 밀도·나이트·연출** = 컨셉아트 SSoT |
| MAX ≠ | Board5 아레나·해외 · 시상식/그래미 상시 사다리 |
| 판 전환 표현 | **도착 컷씬 세트가 바뀜** (맵만 갈아끼우기 1순위 아님) |
| 성장 본체 톤 | 모험·원정 · 비용=주사위/코인 연료 |
| 장르·시점 | 방치형 경영 시뮬 · 주시점=기업 대표 · 상단=스펙터클(잭팟·dots) |
| D-074 | 뼈대 하나 · 팬은 사적 내부 비공개 |

## 4. 연출 파트에 넣을 기획 범위

이올카 `02_연출파트_기획안.md`의 S0~S7을 파이널에 **구현 로드맵**으로 흡수하라.

필수 포함:

1. 밴 이동 · POI 착지 · Board1 도착 컷씬 슬롯
2. 상단 dots · 상태 애니 (군중 메시 금지)
3. 급 상승 이름교체 연출 (063) — 대박 카드보다 **항상 크게**
4. 판 전환 연출 + **도착 컷씬 스왑**
5. Board1 MAX 밀도 룩 (= 컨셉아트) — 아레나 오독 방지 캡션
6. 리스크/빈칸 표 (이올카 R1~R10) — 미결은 미결로
7. 충돌·정렬 **제안** 섹션 (자기 승인 문구 금지)
8. soft 네이밍: board 21 「온에어 방송국」→ 광장/송출 포인트류 **제안**만

범위 밖 (이 지시에서 하지 않음):

- Board2+ 장소표 본문 작성 · 수치 밸런스 확정
