# 095 · 팬심 — 혼자 하면 덕질, 같이 하면 팬덤

> status: **draft** · 2026-09-22 · **구조는 확정, 수치는 예시**
> 한마디로: **「혼자 하면 덕질, 같이 하면 팬덤」**
> 같다름 한 줄: 모노폴리 GO에도 모노카피바라에도 **없다.** 둘 다 개인 숫자만 있고 **모두가 같이 보는 값**이 없다.
> 덕력 → [047](./047_덕력.md) · 한 바퀴 → [094](./094_경제흐름.md) · 총공 → [071](./071_파견.md) · 보드 성장 → [062](./062_보드성장.md) · 딱지 → [064](./064_팬덤게이트_딱지.md)
> **용어:** 일정 보드 = 40칸 전체 · 일정 = 한 칸 → [052](./052_용어대조_GO.md)

# 기 · 판에 남이 없다

지금 일정 보드에 **나와 아이돌 둘뿐이다.**

그런데 덕질은 혼자 하는 게 아니다. 총대가 있고 홈마가 있고 눈팅족이 있다.
그리고 우리가 이미 만들어 둔 규칙 중 **「남」이 있어야 성립하는 것**이 셋이나 된다.

| 규칙 | 지금 문제 |
|---|---|
| **총공** ([071](./071_파견.md)) | 여럿이 같이 미는 것인데, **그 여럿이 어디 있나** |
| **팬덤 게이트 · 딱지** ([064](./064_팬덤게이트_딱지.md)) | 남의 현수막을 내 걸로 바꾸는 것인데, **남이 없다** |
| **전광판 · 생일카페** ([061](./061_덕질_6단_물량.md)) | 밖에 보이라고 하는 것인데, **볼 사람이 없다** |

우리가 만든 게 **빠순이 게임인데 팬덤이 없다.** 그게 지금 판의 제일 큰 구멍이다.

---

# 승 · 팬심이 그 「남」이다

## 1. 무엇인가

**이 시즌 아이돌이 지금 얼마나 떴는지.** 한 사람 것이 아니라 **전 서버가 같이 보는 하나의 값**이다.

시즌마다 아이돌이 한 팀이고 **모든 플레이어가 같은 애를 키운다** (D-047). 그러니 팬심도 하나다.

| | **덕력** | **준비도** | **팬심** |
|---|---|---|---|
| 누구 것 | 나 | 내 아이돌 | **모두** |
| 무엇 | 내가 쓴 코인 누적 | 무대에 설 몸 | **세상이 얼마나 아나** |
| 하는 일 | 얼마나 굴리나 | 무대에서 잘하나 | **얼마나 빨리 크나** |
| 깎이나 | 안 깎임 | 판마다 리셋 | **오르내린다** |

## 2. 공식 — 기본선 + 열기

```
팬심 = 기본선(floor) + 열기(heat)
```

**이 둘로 갈라놓은 것이 「오르내리면서 우상향」의 답이다.**

```
팬심
 │                                        ╱╲    ╱╲
 │                          ╱╲    ╱╲     ╱  ╲  ╱  ╲
 │           ╱╲    ╱╲      ╱  ╲  ╱  ╲   ╱    ╲╱    ╲
 │    ╱╲    ╱  ╲  ╱  ╲    ╱    ╲╱    ╲ ╱
 │   ╱  ╲  ╱    ╲╱    ╲  ╱
 │  ┄┄┄┄┄┄━━━━━━━━━━━━━━━━━━━━┄┄┄━━━━━━━━━━━━━━━━━  ← 기본선 (안 내려감)
 └──────────────────────────────────────────────▶
      총공✔        급↑          총공✔      판 클리어
```

### 기본선 — 달성으로만 오른다. 안 내려간다

| 무엇 | 뜻 |
|---|---|
| **총공 성공** | 마감 안에 팬덤이 목표를 쳤다 |
| **급 +1** | 아이돌이 실제로 더 큰 무대에 섰다 |
| **판 클리어** | 한 시기를 넘겼다 |

**이미 이룬 것은 없어지지 않는다.** 아무리 방치해도 시즌 초로는 안 돌아간다.

### 열기 — 매일 식는다. 밖에 보이는 것만 올린다

| 올리는 것 | 안 올리는 것 |
|---|---|
| 전광판 · 지하철 광고 · 생일카페 · 팝업 | **밥차 · 간식 · 편지** |
| 무대 **대박** | 연습 · 합숙 |
| **시안** 참여 ([082](./082_시안.md)) | |

**밥차는 아이돌한테 가고, 전광판은 남들이 본다.** 남이 봐야 팬덤이 커진다.
[060 서포트 6종](./060_서포트_6종.md)의 묶음이 여기서 처음으로 의미를 가진다.

> **먹이기 · 보내기 → 아이돌 쪽** (준비도)
> **붙이기 · 열어주기 · 찍어주기 → 팬심 쪽**

### 식는 법

**비율로 깎는다.** 매일 열기의 일정 %가 빠진다. 활동이 멈추면 열기는 0으로 수렴하고 기본선만 남는다.

> ⚠ **실시간이 아니라 날짜 기준이다.** 접속 못 한 사람만 손해 보는 구조를 만들지 않는다.
> 접속 압박은 **주사위 cap**이 이미 하고 있다 ([094](./094_경제흐름.md)). 여기까지 하면 이중이다.

## 3. 능력 — 아이돌이 빨리 큰다

```
팬심 낮음  →  덕질 1번 = 응원봉 1개
팬심 높음  →  덕질 1번 = 응원봉 더 많이
                    ↓
              같은 색 10개가 빨리 찬다
                    ↓
              급이 빨리 오른다 = 아이돌이 빨리 큰다
```

**왜 하필 응원봉인가**

| | |
|---|---|
| **픽션이 맞는다** | 팬덤이 크면 나 혼자 드는 게 아니라 **여럿이 같이 든다** |
| **성장 속도에 바로 닿는다** | 급이 오르는 유일한 길이 응원봉 색 10개다 ([062](./062_보드성장.md)) |
| **관리할 이유가 된다** | 응원봉은 랜덤이라 색이 안 맞으면 계속 해야 한다. 팬심이 높으면 **그 고통이 줄어든다** |

**안 건드리는 것** — 코인(축이 둘이 된다) · 덕력(내가 쓴 것이다) · 무대 판정 확률(준비도가 이미 한다).

## 4. 단계 — 무명에서 신드롬까지

숫자로 안 보여 준다. **단계 이름으로 보여 준다.**

| 단계 | 감각 | 열리는 것 | 현실 근거 |
|---|---|---|---|
| **무명** | 아무도 모른다 | — | |
| **알려짐** | 아는 사람은 안다 | **지하철 광고** | 역별 300~700만. 팬덤이 모여야 낸다 |
| **화제** | 실검에 걸린다 | **전광판 · 해외 원정** | 코엑스 월 8,000만. 작은 팬덤은 못 한다 |
| **대세** | 어디를 켜도 나온다 | **큰 방송 캐스팅 · 팬사인회 회차 ↑** | 뜬 애만 부른다 |
| **신드롬** | 모르는 사람이 없다 | **시상식 · 돔 공연** | |

**급과는 다른 축이다.**

| | 무엇을 재나 | 어디 |
|---|---|---|
| **급** | 아이돌이 **어디까지 설 수 있나** | 내 판 |
| **팬심** | 세상이 **얼마나 아나** | 서버 전체 |

**아레나에 설 실력이 돼도 아무도 모르면 안 부른다.** 둘 다 필요하다.

# 전 · 그런데 혼자서는 못 올린다

## 5. 이게 이 시스템의 진짜 얼굴이다

전 서버 집계라서 **내 덕질 하나는 한 방울**이다.

전광판을 걸어도 팬심은 조금 오른다. 그리고 내일이면 식는다.
**내가 아무리 해도 팬덤이 식으면 안 뜬다.**

이건 버그가 아니라 **설계다.** 현실이 그렇다 — 혼자 아무리 태워도 팬덤이 안 움직이면 안 뜬다.

## 6. 팬심이 낮으면 게임이 어떻게 되나

**실패도 설계해야 한다.** 팬심이 바닥일 때의 게임이 어떤 느낌인지 정해 둔다.

| | 팬심 낮음 | 팬심 높음 |
|---|---|---|
| 응원봉 | 하나씩 | 여럿 |
| 급 오르는 속도 | 느리다 | 빠르다 |
| 열리는 콘텐츠 | 기본만 | 원정 · 시상식 |
| 체감 | **"해도 티가 안 난다"** | **"뭘 해도 터진다"** |

> ⚠ **바닥이 있어야 한다.** 0까지 내려가서 덕질이 아무 효과가 없어지면 **플레이어가 못 움직인다.**
> 죽은 상태를 만들지 않는다. **최소치에서 멈춘다.**

## 7. 무력감을 막는 장치 셋

**"내가 뭘 해도 안 변하는데"** — 이게 이 설계의 제일 큰 위험이다.

| 막는 법 | 어떻게 |
|---|---|
| **① 내 기여가 보인다** | 팬심 옆에 **「이번 주 내가 보탠 것」**. 전체는 못 움직여도 **내 몫은 내 것** |
| **② 총공이 뒤집는 자리** | 평소엔 식지만 총공 때 다 같이 밀면 확 오른다. **내 한 방울이 모이는 걸 눈으로 본다** |
| **③ 숫자가 아니라 단계** | 「팬심 3,482」가 아니라 **「화제」**. 단계가 올라가는 순간이 **사건**이 된다 |

# 결 · 총공 — 같이 밀면 뜬다

## 8. 총공이 이 게임의 심장이 된다

지금 총공은 *"다 같이 미는 것"* 인데 **그래서 뭐가 좋은지가 없었다** ([071](./071_파견.md)).
**여기가 그 답이다.**

| | |
|---|---|
| 평소 | 열기가 **서서히 식는다** |
| **총공 주간** | 다 같이 밀어서 **확 올린다** |
| **성공하면** | **기본선이 오른다** — 안 내려가는 몫을 벌었다 |
| 실패하면 | 열기만 조금 오르고 기본선은 그대로 |

**"다음 총공까지 버티자"** 가 생긴다. 총공이 **주간 리듬**이 된다.

혼자서는 못 올리는 값을, 일주일에 한 번 다 같이 올린다. **그게 팬덤이다.**

## 9. 시즌 한 바퀴 — 팬심이 그리는 곡선

```
1~2주   무명 · 알려짐     아무도 모른다. 밥차 보내고 연습시킨다
                          ↓  첫 총공
3~4주   화제              전광판이 열린다. 판이 눈에 띄게 커진다
                          ↓  급 +1 · 총공
5~6주   대세              큰 방송이 부른다. 팬사인회가 잦아진다
                          ↓  총공 · 판 클리어
7~8주   신드롬            시상식 · 돔. 시즌의 끝
```

**시즌 끝에서 팬심은 리셋된다.** 새 아이돌이니 다시 무명부터다.
덕력은 남고([047](./047_덕력.md)) 팬심은 리셋 — **내가 쌓은 건 남고, 세상이 아는 건 다시 시작**이다.

## 10. 다른 것과 어떻게 붙나

| 무엇 | 팬심과의 관계 |
|---|---|
| **총공** ([071](./071_파견.md)) | 팬심을 **올리는 주간 이벤트**. 성공하면 기본선 |
| **딱지 · 팬덤 게이트** ([064](./064_팬덤게이트_딱지.md)) | 남의 현수막이 실재하려면 팬덤이 있어야 한다. **팬심이 그 근거** |
| **시안** ([082](./082_시안.md)) | 팬덤이 만든 것이 팬심을 올린다 |
| **원정** ([070](./070_투어.md)) | 해외 목적지가 팬심 단계로 열린다 |
| **잭팟** ([092](./092_잭팟_전면기획.md)) | 팬심이 높으면 팬사인회 회차가 잦아진다 |
| **급** ([062](./062_보드성장.md)) | 응원봉이 늘어 급이 빨리 오른다 |
| **시즌** ([065](./065_시즌구조.md)) | 시즌마다 리셋 |

## 11. 화면에 어떻게 보이나

- **숫자를 안 보여 준다.** 단계 이름과 게이지만
- 일정 보드 **위쪽에 상시 표시** — 지금 우리 애가 어디쯤인지
- 단계가 오르는 순간은 **연출로 끊어 준다** — 실검 화면 · 기사 헤드라인 한 줄
- 옆에 **「이번 주 내가 보탠 것」** 작게

> 094 §7 「숫자는 숨기고 장면만 보인다」와 같은 선이다.

## 안 정한 것

| 무엇 | 메모 |
|---|---|
| **응원봉 배율 폭** ★ | **1개 → 2개 추천.** 더 벌리면 팬심이 게임을 먹고 덕력이 무의미해진다 |
| **식는 비율** | 하루에 열기의 몇 % |
| **기본선 상승폭** | 총공 1회 · 급 +1이 각각 얼마 |
| 단계 경계값 | 다섯 단계의 경계 |
| **서버 단위** ★ | 전 서버인가 지역 서버인가. **인원이 너무 많으면 내 한 방울이 안 보인다** |
| 무대 대박이 열기에 들어가나 | 개인 판의 대박을 서버 집계에 넣는 게 맞나 |
| 총공 주기 | 주 1회가 맞나 |

## 하지 않음

- 팬심을 **수입원**으로 쓰기 — 배율까지만. 축은 덕력 하나
- 팬심으로 **개인 순위 매기기** — 돈이 순위를 사는 자리는 계속 막는다
- 덕력과 합치기
- **실시간 감쇠** — 접속 못 한 사람만 손해 보는 구조
- 팬심을 **0까지** 떨어뜨리기 — 죽은 상태를 만들지 않는다
