<p><strong>이 문서는</strong> 보드의 쟁탈 칸에 도착한 팀이 상대 기획사의 시설을 골라 전투하고, 결과를 확인한 뒤 같은 메인 보드로 돌아오는 과정을 설명합니다. 시설 선택, 몬스 출전, 방어·건물 적중, 보상과 저장의 경계를 함께 읽는 문서입니다.</p>
<p><strong>보는 법</strong> 목차 → 1~7장 순서로 읽습니다. 자세한 판정·정산은 <a href="캐스팅권대전_세부_기획서_v06.html">P158</a>과 함께 봅니다. 같이 여는 도구: <a href="../../../../game-simulator.html?module=simulator_module_stage_battle">쟁탈 칸부터 실행</a> · <a href="../../../../game-simulator.html?module=simulator_module_casting_battle">시설 선택부터 확인</a>.</p>
<p><b>지금 상태</b> 개발됨(도착 · 선택 · 판정 · 영수증 · 모드 분기 코드의 부분 구현 기준). 방패 → 기획사 지킴이(공용 기분 판정) → 건물 파손 순서의 수비(11/13 몬스 4축 로비 규칙)는 정산 계산에 들어갔습니다(11/16). 상대 봇의 방패 수는 표 값이 비어 있어 0으로 동작하고, 방패로 막는 판의 전투 연출은 현재 개발되지 않음, 진행 중입니다. 최종 보상 값 · 단위는 비앙카 장부 산정 항목이고 주사위 · 카드의 정식 지급 조건은 작업 전입니다. 이번 실제 구동 · 전투 · 정산 · 저장은 아직 검수하지 않았습니다.</p>

<section class="part" id="part-1"><h2>1. 개요</h2>

<p>쟁탈 칸은 보드 6·16·26·36번입니다. 보드가 도착 정보와 같은 팀의 진행을 전용 도구에 넘기면, 플레이어는 상대 시설을 고르고 사격 전투를 봅니다. 상대가 방어했는지 시설이 적중됐는지에 따라 결과와 보상을 계산합니다. 공격자가 받는 돈과 상대가 잃는 돈은 별도로 계산합니다.</p>

<p>정식 도착의 성장 세션 지급, 직접 시연의 표시 전용 결과, 격리된 보상 시험 지갑은 서로 다른 경로입니다. 시험용 배지나 카드 연출만 보고 실제 재화나 카드가 지급됐다고 해석하지 않습니다.</p>

<p><a href="/docs/planning/game-simulator.html?module=simulator_module_stage_battle" data-paper-path="docs/planning/game-simulator.html">눌러서 쟁탈 칸부터 실행</a> · <a href="/docs/planning/game-simulator.html?module=simulator_module_casting_battle" data-paper-path="docs/planning/game-simulator.html">눌러서 시설 선택부터 확인</a> · <a href="/docs/planning/game-simulator.html?module=simulator_module_dice" data-paper-path="docs/planning/game-simulator.html">눌러서 메인 보드 실행</a></p>

<ol>
<li>공용 시뮬레이터에서 현재 팀과 같은 진행을 확인하고 쟁탈 칸에 도착합니다. 쟁탈 전용 검토 화면은 도달 가능한 쟁탈 칸을 시험하기 위한 경로이며 일반 메인의 자연스러운 무작위 이동과 구분합니다.</li>
<li>같은 진행에 미완료 도착이 있으면 그 요청을 이어갑니다. 시설 선택 화면에서는 상대와 선택 가능한 시설·단계를 확인합니다.</li>
<li>정식 팀은 실제 선택한 기획사 보유 몬스 ID만 전달합니다. 보유 몬스가 없으면 준비 안내를 표시하며 시연용 몬스로 자동 채우지 않습니다.</li>
<li>선택한 시설에 대해 10초 전투와 판정·결과를 확인합니다. 현재 표의 시간과 수치는 시뮬레이터 설정이며 최종 발란스 승인을 뜻하지 않습니다.</li>
<li>보상을 확인하고 메인으로 돌아갑니다. 같은 영수증의 다시 보기와 재개는 새 추첨이나 중복 지급이 아닙니다.</li>
</ol>

<p>직접 시설 보기의 명시적 시연은 표시 전용입니다. 보상만 보기와 보상 시험도 정식 보드 도착과 분리합니다. 문서를 여는 것만으로 무거운 시뮬레이터·3D 화면이 실행되지 않습니다. 이번 문서 작업에서는 실제 화면 진입·플레이를 확인하지 않았습니다.</p>

<h3>기획사 보유와 출연권 공격 편성</h3>
<p>플레이어 공격은 기획사에서 <strong>실제 보유하고 선택한 몬스0~10마리</strong>와 선택 순서를 읽습니다. 명시0·빈 보유이면 공격을 시작하지 않고 편성을 안내합니다. 멤버마다 연결하던 몬스·카탈로그 전체·이전 저장본의 임의 종으로 보충하지 않습니다. 공용 행복 잔액을 종별 우선순위로 사용하지 않습니다.</p>
<p>상대 NPC 편성은 현재 상대 프로필에 등록된 편성 명단을 읽습니다. 방어·시설 판정·시간·보상·저장 규칙은 유지합니다. 출전은 소유 종을 재화처럼 소비하는 거래가 아니며 보유·합성·행복을 차감하지 않습니다. 획득과 다른 사용처는 <a href="%EB%AA%AC%EC%8A%A4%EB%B3%B4%EC%9C%A0_%ED%95%B5%EC%8B%AC%EC%A0%9C%EC%95%88%EC%84%9C.html#mons-three-uses">P223</a>을 따릅니다.</p>

<h3 id="돈팬-계산과-상대-손실">돈·팬 계산과 상대 손실</h3>

<p>공격자 돈의 현재 계산은 <code>내림(도착 기준 R × 주사위 배수 × 결과 계수 × 메가 계수)</code>입니다. 메가는 적중에만 적용합니다. 상대 손실은 상대 보유 상태와 손실 규칙을 따로 읽으므로 공격자 보상과 항상 같은 액수가 아닙니다. 상대의 명시적 잔액 0을 결측값으로 바꾸지 않습니다.</p>
