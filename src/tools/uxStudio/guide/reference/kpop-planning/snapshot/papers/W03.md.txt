# 03 · HUD · 도시맵 · 로비

**이 문서는** 전체 기획서 3장으로, 게임 화면이 위에서 아래로 어떻게 나뉘는지(상단 HUD · 3D 도시 · 240px 필러 피드 · 하단 도크)와 로비에서 어디로 들어가는지를 11/13 확정 기준으로 정리합니다.  
**보는 법** 목차 → 0장 한 줄 → 2장 그림 → 3장 규칙(R-03) → 4장 화면(V-03) → 5장 같이 볼 문서. 화면 수치의 정본은 [제나 화면 상세 스펙](../../보고/20261113_2220_제나_G1_M9_화면상세스펙_P1_P7.md)이고, 배치 시험은 [UX 스튜디오(T04)](../툴기획/T04_게임UX기획스튜디오.html)에서 합니다. 시뮬레이터는 [게임 시뮬레이터](/docs/planning/game-simulator.html)입니다.  
**지금 상태** 현재 개발되지 않음, 진행 중 (보드 · 필러 룰렛 첫 판 · 240px LogBox 피드는 개발됨. 본편 로비 껍데기(`lobby-g1.html`)는 만들지 않으며, 로비 · HUD · 몬스 로비 화면은 시안 보고만 하고 게임 시뮬레이터에 붙이지 않습니다).

## 0. 한 줄

**도시 위에 로그가 쌓이고, 로비 한 장에서 다 엽니다.** 화면 위쪽은 기울어진 3D 도시, 그 아래 240px 필러 피드에 그날의 장면이 쌓이고, 하단 도크 다섯 칸에서 카드북 · 스케줄 · 몬스 로비 · 상점으로 들어갑니다.

- 이게 아닌 것: 상단 3D 휠, 필러 칸 안의 버튼, 시안을 게임 시뮬레이터에 붙이기, 건물별 몬스 배치와 공 · 방 수치(옛 `S12_로비`), 시즌이 끝날 때 사람과 카드까지 초기화.

## 1. 컨셉

| 칸 | 내용 |
|---|---|
| 뭔가 | 한 화면을 상단 HUD → 3D 도시 · 사옥 → 240px 필러 피드 → 하단 실행 · 도크로 나눕니다. 로비 → 스케줄 메인 → 상세의 3화면이 기본 길입니다 |
| 왜 지금 | 11/13에 화면 상세 스펙(G1~G10 · M1~M9)이 나왔고, 같은 날 본편 로비 껍데기는 만들지 않고 시안만 보고하기로 정했습니다 |
| 이게 핵심 | 도시는 쓴 돈이 보이는 곳이고, 피드는 그날의 이야기가 쌓이는 곳입니다. 숫자가 비어 있어도 줄을 숨기지 않고 0으로 보여 줍니다 |
| 이게 아닌 것 | 화면을 새 게이지로 채우기 · 필러 안에 버튼 넣기 · 현황판 화면과 게임 로비 화면 섞기 |

## 3. 규칙 (R-03)

| ID | 규칙 | 내용 | 근거 |
|---|---|---|---|
| R-03-1 | 화면 기준 크기 | 설계 프레임 390×844, 모바일 검수 430×844, 데스크톱 · 검수 도구 1440×900. 누르는 요소는 44×44px 이상, 글자 11px 이상 | 제나 스펙 P0-1 |
| R-03-2 | 화면 층 | 위에서 아래로 상단 슬림 HUD → 중앙 무대(3D 사옥 · 도시) → 필러 피드 → 하단 실행 · 도크 | 제나 스펙 G1 |
| R-03-3 | 상단 HUD | 칩 4~5개: 등급 · 엔터파워 / 재화 3종(돈 · 루비 · 주사위) / 총 팬 · 방패 남은 수(최대 3) · 컨디션 요약 / 딥링크 · 알림 | 제나 스펙 G1 |
| R-03-4 | 하단 도크 | 주사위 굴리기와 배수 버튼, 그 아래 5칸 고정: 보드 · 카드북 · 스케줄 · 몬스·혜택 · 상점 | 제나 스펙 G1 |
| R-03-5 | 필러 피드 | 높이 240px 고정, 최근 24개를 쌓고 새 항목이 맨 아래. 피드 안에는 버튼을 두지 않고 다음 · 건너뛰기 · 굴리기는 바깥 버튼 줄(40px)에 둠 | 제나 스펙 G5 · [09장](09_팬덤정원아바타필러_클로드.html) |
| R-03-6 | 상단 3D 휠 없음 | 휠은 띄우지 않고 그 자리는 3D 도시 · 사옥이 채움. 판정은 필러 룰렛(1차 15 / 50 / 35%, 1차 대박 때 5.05%로 2차)으로 봄 | 제나 스펙 G5 · [02장](02_보드찬스칸연출_클로드.html) |
| R-03-7 | 도시와 건물 | 건물은 시즌 안에 쓴 돈으로만 자람. 시즌이 끝나면 건물 단계 · 맵 위 팬 · 건물 악개 · 도착 팬 돈만 초기화되고 40칸 보드 뼈대는 그대로 | [헌법](00_헌법_기획서기조.md) 제4 · 5 · 7조 · [04장](04_성장건물경제_클로드.html) |
| R-03-8 | 보드 6칸 3단 변신 | 방송 27 · 28 · 30, 공연 32 · 33 · 35칸이 첫 앨범 전 → 발매 후 → 9주차 월드 신청 후 순서로 간판이 바뀜 | 제나 스펙 G9 |
| R-03-9 | 9주차 공연 작은 화면 | 모바일은 도크 위 오른쪽 아래 128×72px(드래그 가능, 도크를 가리지 않음), 데스크톱은 오른쪽 보조 칸 위. 펼치면 보드 음악이 줄고 공연 소리로 바뀜 | 제나 스펙 G9 |
| R-03-10 | 소리는 하나만 | 한 번에 켜지는 소리는 하나. 보드 음악과 공연 · 음악 앱을 오갈 때 이전 재생 위치를 기억 | 제나 스펙 P0-1 |
| R-03-11 | 빈 숫자 표기 | 값이 비어 있는 항목은 줄을 숨기지 않고 회색 칩에 `+0` 또는 `0 (0으로 동작)`으로 적음 | 제나 스펙 P0-1 · 헌법 제12조 |
| R-03-12 | 닫기 · 뒤로 | 모달과 상세는 닫으면 직전 화면으로 돌아가고 스크롤 · 탭 위치를 되살림 | 제나 스펙 P0-3 |
