## 3. 시스템 규칙 R-06

### 3-1. 음원 이원화

| 구분 | 창작곡 | 내부곡 (정식 발주) |
|---|---|---|
| 만드는 쪽 | 유저가 직접 등록 | 외부 음원 제작사 발주 |
| 형식 | `.mp3` 3분 이내 | 4장르 × 각 8곡 = 32곡 (댄스 팝 12곡이면 36곡) |
| 표시 | 내 앨범에 「창작」 | 일반 앨범 |
| 검수 | 사람/AI 검수(검수 중 · 통과 · 반려) | 발주 때 검수 |
| 주간 | 출전 가능, 내부곡과 같은 100명 순위표(전용 탭 · 가산점 없음) | 출전 가능 |
| 월드 | 출전 없음. 월드는 내부곡 영상끼리만 겨룬다(현중 11/24 18:02) | 통합 순위 |

| 규칙 | 내용 (현재 세팅값) |
|---|---|
| R-06-1 장르 | `dance_pop` · `ballad` · `hiphop` · `rnb` 4장르. `rnb`는 댄스 팝에 묶지 않고 정식 ID로 분리 |
| R-06-2 발주 규격 | 분위기 4(청량 · 파워풀 · 몽환 · 감성) × 템포 3단(80 · 110 · 140 BPM), 보컬 편성 9종, 언어 한 55~60% · 영 25~30% · 일 10~15%, 3구간(180 · 60 · 30초), 보컬판 + MR, `WAV` + `MP3 320kbps`, -14 LUFS, 상용 독점 권리 |
| R-06-3 샘플 | 지금 시뮬의 테스트 샘플 10곡(`music_samples.json`)은 발주곡이 들어오면 대체. 그 전까지 샘플 10곡으로 동작 |
| R-06-4 창작곡 검수 전 | 검수 중에는 공개 상위 노출에서 빠짐. 내 보관함 · 크루 공유는 보임 |
| R-06-5 곡 만드는 방식 | 확률형 곡 뽑기 없음(헌법 제9조) |

### 3-2. 앨범

| 규칙 | 내용 (현재 세팅값) |
|---|---|
| R-06-6 발매 조건 | 데뷔조 1명 이상 |
| R-06-7 정규 앨범 팀 고정 (#35) | 정규 앨범은 **팀 칸 멤버 전원** 참여 · 크레딧. 앨범에서 멤버를 골라 넣는 옵션은 숨김. 솔로 · 유닛은 **뮤비 제작 때만** 고르고 뮤비 크레딧에만 표시 |
| R-06-8 시즌 발매 상한 | 한 시즌 최대 **8곡**(데뷔곡 포함, 창작곡 포함) |
| R-06-9 앨범 6칸 | 방송 3칸(27 · 28 · 30) · 공연 3칸(32 · 33 · 35). 첫 앨범 전에는 신인 활동 이름(거리 인터뷰 · 거리 버스킹 등)으로 같은 보상, 발매 뒤 정식 방송국 · 공연장 이름과 조명 |
| R-06-10 START 정산 | 첫 발매 전 START 정산 = 0. 발매 뒤 출발점 통과 때마다 정산(7일째까지) |
| R-06-11 더미 100명 랭킹 | 1위 돈 4,300 · 팬 17 · 능력 상한 34,000 · 카드 5 / 3 / 1 · 몰아 굴리기 최대 34.7%. 내 화면 정산 전용, 주간 · 월드 점수에 넣지 않음 |
| R-06-12 뮤비 | 사진 조합 컷씬 툴, 앨범 음악 박자에 맞춤. 영상이 없으면 아이돌 이미지 자동 연출. 내 캐릭터 모션샷 포함 |

### 3-3. 독립 음악 앱 연동 계약 (#1~#8)

| 번호 | 기능 | 게임 → 앱 / 앱 → 게임 |
|---|---|---|
| #1 | 계정 · 크루 · 예명 | 내 음악 · 크루 음악 모아듣기, 예명 · 뮤비 유닛 크레딧 |
| #2 | 보드 · 공연 실황 | 방송 3칸 · 공연 3칸 · 9주차 40칸 보드 ↔ PIP ↔ 스테이지 6채널 |
| #3 | 관람방 · 오디오 | 고정 100명 관람방, 다른 그룹 바꿔 보기, 월드 상위 관람 키, BGM ↔ 공연 소리 전환 |
| #4 | 음원 이원화 · 곡 등록 | 창작곡 등록 + 내부곡 목록 |
| #5 | 업로드 · 편집 · 검수 | `mp3` · `mp4` 업로드, 숏츠 · 컷씬 편집, 검수 배지 |
| #6 | 원장 · 보안 | 유효 재생 · 일일 한도 · 봇 차단, 투표 · 찜 · 인기 재화 원장 |
| #7 | 차트 · 배틀 | 앨범 더미 차트 분리, 주간 100명, 월드 리그 · 5탭, 스냅샷 갱신 시각 |
| #8 | 크루 · 외부 연계 | 크루 대표 1편, 결과 알림, 웹 딥링크 |

| R-06-14 막지 않음 | 앱이 없어도 게임은 끝까지 진행. 앱 연결 · 업로드 · 크루 참여는 선택 |
| R-06-15 이월 | 시즌 끝 건물만 초기화될 때 앱의 음원 · 숏츠 · 채널 · 구독 · 인기 재화 · 보관함은 모두 이월 |
