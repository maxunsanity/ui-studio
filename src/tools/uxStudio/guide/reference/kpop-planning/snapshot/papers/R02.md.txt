# 팬에서 엔터 사장까지 — 현실 사례 시드

- 작성일: 2026-09-14 (KST)
- 성격: **조사 메모·시드**. 기획 SSoT가 아님. 성장사다리(020)의 원재료.
- 톤: 실명·URL이 있는 것만 사례로 적는다. 이름 없는 반복은 **패턴**으로 표시. 없는 실명은 만들지 않음.
- 범위: 한국 K팝 산업 + 글로벌 K팝 인접(팬이벤트·MD·카페·통역·팬마케팅). 메이저 기획사 사장 신화와 팬 출발을 섞지 않음.

## 핵심 시각 (게임으로 옮길 때)

현실에서 **빠순이 → 빅4 사장**은 거의 없다. 대신 반복되는 길은 셋이다.

1. **같은 아이돌을 키우다 그 옆 스태프가 된다** (소형 기획사·글로벌 마케팅·통역).
2. **팬 노동이 준프로가 되어 인접 사업이 된다** (생카·공구·MD·카페·콘서트 프로모션).
3. **업계 안에서 키운 뒤 독립한다** (매니저·A&R·프로듀서 → 자기 회사). 이 길은 대개 **팬 출발이 아니다.** 사장 후반 참고용.

게임의 본체는 1+2다. 3은 후반 권한의 맛만 빌린다.  
「내가 키운 아이를, 언젠가 내가 무대를 연다」는 **감정 루트**이지, 한국 연예산업의 표준 이력서가 아니다.

## 패턴 (이름 없는 반복)

이름보다 **단계가 반복**되는 것들. 게임에 쓸 때는 패턴으로 표기하되, 가짜 실명을 붙이지 말 것.

### P1. 팬서포터즈 → 팬매니저
스포츠경향: 현장 줄 세우기·질서 정리를 하던 팬서포터즈 출신이 실제 팬매니저로 많이 들어간다. 스타쉽은 팬서포터즈를 **팬마케팅 인턴으로 정식 채용**한 적 있음. SM은 대외활동·수료증·현직 만남. YG프렌즈는 현장 프렌즈에 활동비. 동시에 무보수 착취 논란(큐브 2024) — 게임에서 “무료 노동으로 입사”를 미션 보상으로 쓰지 말 것.  
출처: [스포츠경향 2024](https://sports.khan.co.kr/article/202406271601013)

### P2. 공식 팬클럽·팬계정 경험이 채용 우대
JYP 팬마케팅 공고: **공식 팬클럽 활동 경험 우대.** SNS·팝업·MD·현장 팬 관리가 직무. YG FC팀: 팬클럽·팬플랫폼 운영 경력. 모드하우스 커뮤니티 매니저: K팝 팬덤 이해. 잡플래닛은 팬계정·콘텐츠 수치를 자소서에 쓰라고 권함.  
출처: [JYP 공고](https://recruit-apply.jype.com/ko/o/229438), [YG FC팀](https://lab.incruit.com/jobs/2605140000809), [모드하우스](https://www.wanted.co.kr/wd/209134), [잡플래닛](https://www.jobplanet.co.kr/contents/news-8342)

### P3. 총대·생카·공구의 준프로화
실명 “총대 → 기획사 사장”은 찾지 못함. 대신 Calista Lim처럼 **생카·공구 채널이 포트폴리오**가 되고, Kick Café·KKANG처럼 상시 공간이 된다. 총대는 대관·특전 발주·모금 정산 — 이미 프로듀서/이벤트 PM 일. 게임의 중기 게이트.

### P4. 팬미디어(번역·팬튜브·정보계) → 업계 언어 일
Kim Soyeon, April Kim. 팬이 이미 하던 번역·은어 학습이 통역·라이터 직업이 됨. Growth Career의 “Fan to Pro” 부트캠프, Weverse America 인턴(That Fangirl Life, 실명 비공개)도 같은 축.  
출처: [Growth Career](https://growthcareer.xyz/), [That Fangirl Life](https://thatfangirllife.com/2026/06/fandom-as-my-fuel-turning-fangirling-into-a-career/)

### P5. 콘서트 프로모팅 / 로컬 허브
Ashlee: 팬 공백을 메우려고 로컬 이벤트를 열다 투어 프로모터가 됨. 팬이 **무대를 소비하다 무대를 연다.** 한국 내 대형 콘서트 주최사(CJ·Live Nation 등) 사장 사례와는 층이 다름.

### P6. 메이저 내부 사다리 (팬 출발 아님)
캐스팅/연습생 매니저 → A&R → 아티스트 전담 디비전 → 팬비즈니스(위버스·MD·콘) → 임원 → 독립 레이블.

### P7. 로드매니저
한겨레: 현장 매니저는 운전·일정·잡무가 섞이고, “기획사를 차리려고 매니저가 됐는데 집안일”이라는 증언. 한국일보: 최근 명문대 출신이 밑바닥 매니저로 들어오는 흐름, 하이브는 아티스트 의전(로드)에 대졸·외국어. **팬 출신 로드 실명은 못 찾음.** 후반 직업 칸의 무게로만.

## 사람들이 실제로 지나가는 단계

관찰된 순서. 한 사람이 다 밟는 건 드물고, **분기**가 본체다.

```
입덕 · 매일 덕질
    → 커뮤니티 / 팬계정 / 총공
        → A. 총대·생카·공구·MD     → 준프로 이벤트/커머스 창업
        → B. 번역·팬튜브·정보계     → 통역·콘텐츠·팬마케팅
        → C. 팬서포터즈·현장 자원   → 인턴·팬매 신입
            → 팬매니저 / (드물게) 로드
                → 마케팅 리드 · A&R 보조 · 연습생 케어
                    → 팀장·이사
                        → 독립 (이벤트사 / 팬테크 / 인디 레이블)
```

티나는 전환 5개 (플레이 게이트 감각):

1. **남이 나를 운영자로 부른다** — 총대·번역계·공식 팬베이스.
2. **돈이 내 주머니가 아니라 남의 정산이 된다** — 모금·대관·티켓.
3. **회사 메일/패스가 생긴다** — 팬에서 스태프.
4. **같은 아이돌의 무대를 뒤에서 연다** — Angie, April, Calista.
5. **다음 아이를 내가 뽑는다** — 김계란, 우왁굳, 방재혁, 김영선. (여기부터 팬 서사가 약해지고 제작자 서사가 됨)

## 공백 · 신화

| 신화 / 빈칸 | 실제 |
|-------------|------|
| 팬클럽 회장·총대가 대형 기획사 사장이 된다 | **실명 사례 없음.** 총대는 준프로 이벤트 쪽으로 새는 경우가 문서화됨. |
| 빅3/빅4 사장은 원래 빠순이 | 방시혁·박진영·이수만·양현석은 작곡/가수/프로듀서 출발. 김영선은 스타일리스트. |
| 팬이면 그 아이돌 매니저가 된다 | 문서화된 것은 **소형사 글로벌 마케팅**(Angie)과 **통역**(April). 로드매니저 실명 없음. |
| 생카 총대 = 엔터 입사 | 생카는 대관·MD·정산 학교. 입사는 별도 채용/인턴. |
| 덕질만으로 임원 | 반짝씨가 꿈으로 말함. 실현된 실명 임원 이력은 못 찾음. |
| 성장 아이돌을 키우면 반드시 같이 성공 | Angie는 데뷔 전 팬→스태프. 대부분은 아이돌이 커져도 팬으로 남거나, **다른 회사의 다른 아이돌**을 담당. |
| 여성 팬 → 엔터 CEO가 흔하다 | 김영선은 업계 내부. 팬 출발 CEO는 글로벌 소형(Ashlee, Rhianna) 층. 김영선 본인이 여성 CEO 편견을 인터뷰에서 말함. |

조사 공백: 한국 국내 **실명 팬카페 회장/총대 → 소속사 입사** 기사, 실명 로드매니저 팬 출신, 생일카페 사장이 연예기획사로 전환한 법인 기록. 있으면 020을 고친다. 지금은 없는 칸을 채우지 말 것.

## 게임 설계에 남기는 제약

- 사장 엔딩은 **이벤트사·인디 레이블·팬테크·자기 아이돌 데뷔** 중 하나. 하이브 카피 엔딩은 신화.
- 무보수 팬서포터즈를 “취업 미션”의 정답으로 두지 않음 (018과 톤 맞춤).
- 같은 아이돌을 끝까지 담당하는 루트는 **희귀 게이트**(Angie/April 맛). 기본은 분기.
- 017의 신인초→사장근처는 **미션 호흡**. 이 파일의 사다리는 **팬의 사회적 직함**. 둘을 한 축으로 접지 말 것 — 007에서 나눔.
