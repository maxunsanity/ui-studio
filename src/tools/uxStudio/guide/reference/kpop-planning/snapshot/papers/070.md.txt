# 070 · 원정 — 못 가는 데로 보내기

> status: **draft** · 2026-09-18 본문 다시 씀 · [081 입덕](./081_입덕_전면기획.md) 아래 둘 중 하나
> 같다름 한 줄: 모노카피바라 **여정**은 피크민의 **「보내고 기다리기」**다. 목적지를 고르고, 보내고, 기다리면 물건을 들고 온다. 주사위를 안 걸고 실패도 없다.
> 우리 **원정**도 같은 모양이다 — **내가 못 가는 데로 서포트를 보내고 기다린다.**


> **이름 바뀜 (2026-09-18)** — 모노폴리 GO·모노카피바라 대조
> | 모노폴리 GO | 모노카피바라 | **우리** |
> |---|---|---|
> | (없음) | **여정** (던전 여정) | **원정** |
> | 건설 | 건설 | 덕질 *(판 안에서 하는 쪽)* |
> | 넷워스 · 재산 | 번영도 | 덕력 |
>
> 옛 이름 「투어」는 *돌아다니는 것*이라 하는 일과 안 맞아 바꿨다.
> **옛 본문(「지나온 동네로 다시 공연 간다」)은 폐기다.** 원정은 **아직 못 가본 데**로 가는 것이지 갔던 데로 돌아가는 게 아니다.

---

## 이게 뭐냐

**내가 못 가는 데로 보내는 것.**

판이 홍대면 아이돌은 홍대만 돈다. 그런데 부산에서 공연이 있고, 해외에서 팬미팅이 있고, 연말에 시상식이 있다.
거기는 **판이 안 닿는다.** 나도 못 간다.

그래서 **보낸다.** 슬로건을, 밥차를, 광고를, 조공을. 그리고 기다린다.

## 언제 나오냐

**입덕** 안 **「원정」**. 판 밖이라 주사위를 안 쓴다 — 주사위가 떨어져도 할 게 남는 자리다.

---

## 한 줄

**나는 못 가. 그래도 내 이름은 거기 가.**

---

## 왜 필요한가

| | |
|--|--|
| 감정 | 팬덤이 실제로 하는 일이다. **총대한테 부탁하고, 배송을 걸고, 사진을 기다린다.** 못 가는 사람이 하는 덕질이 이것이다 |
| 실리 | 판이 못 닿는 데서 **코인**과 **비하인드**가 온다 |
| 구조 | **주사위 없는 벌이.** 주사위가 바닥나도 게임이 안 끊긴다 |
| 판과 안 겹침 | 판 안 덕질은 **한 단씩 키우는 것**, 원정은 **판 밖으로 한 번에 보내는 것** |

---

## 어떻게 도나

```
입덕 → 원정
   ↓
어디로 보낼지 고른다        부산 · 해외 팬미팅 · 시상식
   ↓
무엇을 얼마나 보낼지 고른다   슬로건 / 밥차 / 광고 · 물량 1~3
   ↓
자리 하나가 잠긴다           보내는 동안 그 자리는 못 쓴다
   ↓
기다린다                    물량이 클수록 오래
   ↓
돌아온다                    코인 + 비하인드 + 서사 조각
```

| | |
|--|--|
| 주사위 | **안 쓴다** (모노 여정과 같음) |
| 아이돌 | **판에 그대로 있다.** 멤버가 빠지지 않는다 |
| 준비도 | 안 깎이고 안 오른다 — 무대가 아니라 **내가 보내는 것**이다 |
| 실패 | **없다.** 늦게 올 뿐 (실패는 [총공](./071_파견.md)에만 있다) |
| 급 | **안 오른다.** 급은 덕질 10개로만 ([D-026](../../DECISIONS.md)) |
| 딱지 | **안 붙는다.** 판 밖은 겨루는 데가 아니다 ([064](./064_팬덤게이트_딱지.md)) |

---

## 어디로 보내나 — 늘 판보다 한 걸음 앞

**지나온 데가 아니라 아직 못 간 데다.** 판이 커지면 목적지도 같이 커진다.

| 지금 판 | 원정이 가는 곳 |
|---------|----------------|
| 홍대 | 지방 소극장 · 대학 축제 |
| 국내 | 아시아 팬미팅 · 해외 쇼케이스 |
| 해외 | 시상식 · 스타디움 |

판이 넘어가면 옛 목적지는 닫히고 새 목적지가 열린다. **판이 되돌아가지 않는 것과 같다** ([062](./062_보드성장.md)).

> 그래서 원정은 **"우리 애가 곧 갈 데"**를 미리 보여주는 자리이기도 하다.

---

## 무엇을 보내나

판 안 덕질과 **같은 물건**이다. 가는 데가 다를 뿐.

| 보내는 것 | 결 |
|-----------|-----|
| **슬로건 · 응원 물품** | 싸고 빠르다 |
| **밥차 · 간식차** | 중간 |
| **광고 · 전광판** | 비싸고 오래 걸린다. 비하인드가 제일 좋다 |
| **조공 · 화환** | 시상식 전용 |

**물량은 1~3단.** 많이 보낼수록 오래 걸리고 크게 돌아온다.
판 안 덕질처럼 6단까지 쌓이지 않는다 — **원정은 한 번 보내고 끝이다** ([061](./061_덕질_6단_물량.md)과 다른 점).

---

## 자리는 몇 개냐 — 덕력이 연다

한 번에 보낼 수 있는 **자리 수**가 정해져 있다. 그 수를 여는 건 **덕력(재산)**이다.

| | |
|--|--|
| 시작 | 자리 1개 |
| 덕력이 오르면 | 자리 2개 · 3개 … |

덕력은 **주사위 굴림 상한**을 여는 숫자다([D-004](../../DECISIONS.md)). 원정 자리도 같은 자리에 붙인다 — **덕력은 언제나 상한만 연다.** 아이돌을 직접 세게 만들지 않는다.

---

## 돌아오면 뭐가 있나

| | |
|--|--|
| **코인** | 목적지가 멀수록 · 물량이 클수록 |
| **비하인드** | 한 장. 이게 진짜 보상이다 ([081](./081_입덕_전면기획.md) §1) |
| **서사 조각** | 그 목적지에서만 나오는 이야기 ([067](./067_서사.md)) |

> *"부산은 못 갔다. 대신 밥차를 보냈다. 사진이 왔다. 우리 애가 웃고 있었다."*

**등급이 붙는다.** 대박이면 비하인드가 길고 금테, 운빨망빨이면 짧다 — 모노 엽서 그대로.

---

## 판 안 덕질과 뭐가 다른가

| | **덕질** (판 안) | **원정** (판 밖) |
|--|------------------|-------------------|
| 어디 | 아이돌 일정 22칸 | 판이 안 닿는 곳 |
| 언제 | 상시 ([D-019](../../DECISIONS.md)) | 보내고 **기다린다** |
| 쌓이나 | **6단까지 커진다** | 한 번 보내고 끝 |
| 급 | **10개면 한 급** | 안 올린다 |
| 색 칩 | 찬다 | **안 찬다** |
| 나오는 것 | 서사 조각 · 응원봉 | **비하인드** · 코인 |

**겹치지 않는다.** 덕질은 *키우는 것*, 원정은 *닿는 것*이다.

---

## 안 섞는 것

| 아님 | 그건 |
|------|------|
| **총공** | 마감 걸고 다 같이 깎는 것. 실패가 있다 ([071](./071_파견.md)) |
| **행보판** | 주사위 · 착지 · 덕질 ([056](./056_보드_컨셉.md)) |
| **응원** 칸 (3·18·34) | 판 안에서 작게 한 번씩 미는 것 ([039](./039_공동기금_GO표기.md)) |
| **지나온 동네** | 원정은 **못 가본 데**만 간다 |

---

## 안 정한 것

- 자리 수 곡선 — 덕력 얼마에 자리가 하나 더 열리나
- 물량 1~3단이 시간·보상을 얼마나 밀어 올리나
- 목적지가 판마다 몇 개 · 다 돌면 어떻게 되나
- 목적지마다 서사 조각이 몇 개인가
- 기다리는 시간을 주사위나 코인으로 당길 수 있나 (BM 자리)

## 하지 않음

- **지나온 동네 다시 가기** (옛 본문 · 폐기)
- 원정으로 급 올리기 · 색 칩 채우기
- 주사위·배수 쓰기
- 원정에 딱지 붙이기
- 실패 만들기 (실패는 총공 몫)
- 빠순이가 직접 그 자리에 가기 — **보내는 것까지만** ([018](./018_미션_미사용_금지.md) 사생 금지선)
