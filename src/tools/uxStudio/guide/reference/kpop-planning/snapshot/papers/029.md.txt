# 029 · 참조 소설 읽을거리

> status: bookmark · **보드·미션 SSoT 아님.** 나중에 읽으며 톤·장면을 참고할 목록.
>
> 같다름 한 줄: 모노카피바라는 외부 웹소설을 기획 책갈피로 두지 않는다. 우리는 **초기 아이돌 키우기·빠순이 중간층**을 보기 위해 아래만 적어 둔다.

## 읽을 것

1. **《데뷔 못 하면 죽는 병 걸림》** — 팬덤·커뮤니티·투표·여론. “같이 키운다”의 정치·리얼리즘.
   → **조사 완료 (2026-09-17 · 118화).** 화별 요약 `2026-09-17_웹툰_데뷔못하면죽는병걸림_화별요약.md` · 보드 감각 정리 `2026-09-17_웹툰_보드감각_정리.md`
2. **《내 새끼 데뷔시키려다 내가 데뷔하게 생김》** — 여덕이 최애 데뷔를 미는 한풀이. 우리 본체 감정과 가장 직설.
3. **《1교시. 아이돌 탐구 영역》** — 팬이 최애 쪽으로 안까지 끌려 가는 훅. 공개 자료는 얇음.
4. **《다시 한번 아이돌》** · **《아이돌 공략법으로 데뷔합니다》** — 연습생·데뷔 재도전, 연습/공략 게이지 감각. 팬 층은 약함.
5. **《이번 생은 우주대스타》** · **《성스러운 아이돌》** — 방송·팬이벤트·화제성, 해외는 일정 스팟 톤.
