# 079 · 천음 리그를 우리 판에 넣기 (제안)

> status: **채택됨 — 총공과 시안으로 갈라 들어감** · 2026-09-18 갱신
> **읽는 법:** 이 문서는 *천음 리그에서 무엇을 가져올까*를 고르던 메모다. 결론은 아래 둘로 갔다.
> **협동 쪽(주간 리듬 · 전 서버 게이지 · 블라인드 · 진 사람도 받기) → [071 총공](./071_파견.md)**
> **경쟁 쪽(만들어 내기 · 투표 · 순위 · 1등이 판에 걸림) → [082 시안](./082_시안.md)**
> ⚠ 아래 본문은 총공이 **판 3·18·34 칸**에 있던 시절에 쓴 것이다. **총공은 판 밖으로 나갔고 그 칸은 [응원](./039_공동기금_GO표기.md)이다.**
> ⚠ 「창작물 업로드는 우리 게임에 없다」고 적은 부분도 **바뀌었다** — 파일은 안 올리되 **게임 안 꾸미기**로 들어간다 ([082](./082_시안.md)).
> 원문: `_external/2026-09-14_제안서/01a_천음리그_전문_v1.0.md`
> **원문은 게임 밖 창작 게시판**이다. 팬이 영상·그림·음악을 올리고 투표받는 것.
> 우리 판(40칸)과 자리가 다르므로 **그대로 넣지 않는다.** 쓸 수 있는 구조만 옮긴다.

---

## 이게 뭐냐

천음 리그 제안에서 **우리 게임 안에 들어갈 수 있는 것**만 골라 자리를 잡은 것.

---

## 먼저 — 그대로 못 쓰는 이유

| | 천음 리그 | 우리 |
|--|-----------|------|
| 하는 일 | 팬이 **작품을 만들어 올린다** | 아이돌이 판을 돌고 팬이 **덕질한다** |
| 자리 | 게임 밖 게시판 | **판 안** |
| 필요한 것 | 업로드·검수·저작권·법무 | 없음 |

**창작물 업로드는 우리 게임에 없다.** 만들려면 검수·저작권·미성년·AI 표기까지 전부 따라온다.
대신 **그 구조가 주는 재미**는 우리 칸에 옮길 수 있다.

---

## 옮길 것 넷

| | 천음 리그의 것 | 우리 어디에 | 무엇이 되나 |
|--|----------------|-------------|-------------|
| 1 | **천음 게이지** (공동 목표 → 전 서버 보상) | **총공** | 서버 전체가 같이 채우는 게이지 |
| 2 | **블라인드 타임** (마감 전 순위 숨김) | **총공** 주간 | 일요일 저녁 결과 가리기 |
| 3 | **주간 사이클** (열림→쌓임→마감→발표) | **총공** | 주 단위 리듬 |
| 4 | **팬 픽 · 도약상 · 참가상** (진 사람도 받음) | **총공 · 딱지** | 아무도 빈손이 아니게 |

**넷 다 「총공」으로 간다.** 총공이 지금 GO 상자를 그대로 가져와서 밋밋했는데, 여기서 살이 붙는다.

---

## 1. 천음 게이지 — 전 서버가 같이 채운다

**원문**
> 리그 총 투표 수가 목표치를 넘으면 **전 서버 보상(주사위 ×1)** 을 여는 「천음 게이지」 공동 목표.
> 경쟁 리그에 **협동 레이어**가 생긴다.

**우리 문제**
지금 [총공](./039_공동기금_GO표기.md)은 **친구 두 명과 짜는 팀**이다. 모노폴리 GO 구조 그대로다.
그런데 진짜 총공은 **팬덤 전체가 시간 맞춰 한 곳에 몰리는 것**이다.

**그래서 두 겹으로**

| | 무엇 | 크기 | 받는 사람 |
|--|------|------|-----------|
| **팀 총공** | 친구와 상자 채우기 (지금 것 · GO) | 작게 | 우리 팀 |
| **전체 총공** | **서버 전체가 한 게이지** | 크게 | **모두** |

**내가 못 채워도 남이 채우면 나도 받는다.** 그래서 아무도 손해가 아니다 — [064](./064_팬덤게이트_딱지.md)에서 정한 톤 그대로.

> 게이지 이름은 **천음**을 그대로 쓰지 않는다. 그건 우동 IP 세계관 말이다.
> 우리 말로는 **「화력」** 이 맞다 — 총공 화력.

---

## 2. 블라인드 타임 — 마지막에 가린다

**원문**
> 일 18:00~20:59 순위·점수 비공개. *"서바이벌 예능의 최종 발표 전 순위 공개 중단 문법."*
> 막판 투표 독려 + 순위 조작 가시성 저하.

**우리 총공 주에 그대로**

```
월       총공 열림 · 이번 주 목표 공개
화~금    화력이 쌓인다 (게이지가 보인다)
토       마감 임박
일 저녁   ★ 게이지가 가려진다
월       결과 · 보상
```

**우리 판이 방송 게임이라 말이 이어진다.** 스탠바이·온에어 칸도 있고.

---

## 3. 주간 사이클 — 총공에 리듬

원문은 요일마다 할 일이 정해져 있다. 우리 총공도 같은 모양으로 간다.

| 우리 | 무엇 |
|------|------|
| 월 | 열림 · 이번 주 **목표** 공개 |
| 화~금 | 총공 칸(3·18·34)에 착지할 때마다 화력이 쌓임 |
| 토 | 마감 임박 표시 |
| 일 저녁 | **가려짐** |
| 월 | 결과 · 보상 · 다음 주 시작 |

**매주 같은 리듬이라 돌아올 이유가 생긴다.**

---

## 4. 진 사람도 받는다

**원문**
> "나는 50위 못 들어도 매주 뭔가 받는다"는 감각이 **참가 유지율을 결정**한다.

| 원문 | 우리 |
|------|------|
| 참가상 (제출만 해도) | **총공에 한 번이라도 참여** → 작게 |
| 도약상 (30계단 상승) | **지난주보다 많이 냈으면** → 작게 |
| 개근 투표자 (7일 투표) | **주 내내 총공 칸을 밟았으면** → 작게 |
| 팬 픽 추첨 (1위작 투표자) | **화력을 많이 낸 사람 중 추첨** |

**딱지에도 같은 걸 건다.** 딱지를 떼인 사람도 빈손이 아니게.

---

## 안 가져오는 것

| 무엇 | 왜 |
|------|-----|
| **창작물 업로드 전체** | 검수·저작권·미성년·AI 표기가 다 따라온다. 우리 판에 자리 없음 |
| 뮤직·이미지·영상 부문 | 위와 같음 |
| 점수 공식 (로그 정규화·가중합) | 작품 순위용. 우리는 순위 매길 작품이 없다 |
| 어뷰징 필터 상세 | 업로드가 없으면 필요 없음 |
| Top 50 · 레전드 팩 | 우리는 카드가 없다 |
| 5감정 테마 | 우리 다섯 단(제로돌~서동요)과 겹쳐 보인다 |
| **「천음」·「역공명」 이름** | 우동 IP 세계관 말. 우리 말로 바꾼다 |

---

## ⚠ 이름이 겹친다 — 응원봉

원문에서 **응원봉은 후원 아이템**이다.

> 후원 | 응원 아이템 **「응원봉」** (골드·유료재화)

**우리 응원봉은 덕질하면 칸에 켜지는 것**이다 ([062](./062_보드성장.md)).
둘 다 쓰면 반드시 헷갈린다. **우리가 응원봉을 지키는 쪽 추천** — 판 위에 실제로 켜지는 물건이라 이름이 더 맞다.

---

## 정리하면

**천음 리그에서 우리가 가져오는 건 「창작 리그」가 아니라 「주간 협동의 리듬」이다.**

```
총공 (3 · 18 · 34)
  ├─ 팀 총공     친구와 상자        ← 지금 것 (GO)
  ├─ 전체 총공   서버 전체 화력     ← 새로
  ├─ 주간 리듬   월 열림 → 일 가림 → 월 결과   ← 새로
  └─ 진 사람도   참가·도약·개근·추첨          ← 새로
```

**총공 세 칸이 판에서 제일 살아난다.** 지금은 GO 상자를 그대로 둔 밋밋한 칸이다.

---

## 안 정한 것

- 전체 게이지 목표치 · 보상 크기
- 팀 총공과 전체 총공이 **같은 칸**인가 따로인가
- 주간 리셋과 시즌(3개월)의 관계
- 게이지 이름 (화력? 다른 것?)
