## 이게 뭐냐

**성장 보드 얼굴(R1 상징)과 아이돌 IP를 시즌마다 교체하기 위한 샘플 컨셉 5 + 스왑 필드 초안.** 카드 드랍·Lead·시즌 루프 본문은 다루지 않는다.

## 언제 쓰나

데이터/아트에 “어떤 키가 바뀌는지”를 넘길 때 · 파트너에게 “샘플 → 실IP” 교체 비용을 설명할 때 · 단이 시즌·클로드 카드의 **스킨 계약**만 맞출 때.

## 한 줄

> **규칙 고정 · 세계관 팩 스왑. 샘플 5 = 슬롯 5 데모. 시즌이 바뀌면 도시·건물·아이돌이 새 세계관으로 바뀌고, 키운 캐릭터는 카드로 남아 옵저버가 된다(10/1).**

## 자세히

### ① 층위 분리 (필수 용어)

| 층 | 키워드 | 예시 |
|---|---|---|
| 풀(pool) | 시즌 후보·캐스팅 풀 | 16명 후보 등(회의값·미잠금) |
| 슬롯(slot) | 멤버 정원 **5** | 그룹에 잡아 두는 자리 |
| 활성(active) | 선택 수 **1~5 가변** | 튜토리얼 1명 가능 |
| 비멤버 쪽 | 슬롯 밖 미선택·비활성 후보 | 비멤버 덱 쪽을 채움 (Q-001) |
| 카드북 | ~**20덱** | 덱 수 ≈20 · **멤버 수 아님** |

> 샘플 5인은 “20멤버”가 아니라 **슬롯 5를 채운 데모**. Options A/B/C 폐기됨.

### ② 샘플 멤버 컨셉 5 (데모 IP 팩 · 실계약 아님)

| group_slot | idol_id (가안) | display_name | 컨셉 한 줄 (데모) | board_skin_hooks (잠금6만) | 상징 톤(R1.1) |
|---|---|---|---|---|---|
| 1 | `sample_oudong` | 어우동 | 무대 중심·카리스마 페이스 | `concert_hall` | LP |
| 2 | `sample_nongae` | 논개 | 수호·방어·팬 쉴드 이미지 | `agency_hq` | 별+사옥 |
| 3 | `sample_inachi` | 이날치 | 리듬·사운드·녹음 훅 | `recording_studio` | 헤드폰 |
| 4 | `sample_saimdang` | 신사임당 | 창작·비주얼·브랜드 | `broadcast_station` | TV |
| 5 | `sample_hwangjini` | 황진이 | 팬덤·매력·머천 얼굴 | `fanshop` | 선물상자 |

- `group_slot` 1~5 = **멤버 슬롯 인덱스** (정원 5).
- 활성 수가 3이면 slot 1~3만 활성이고 4~5는 비활성(비멤버 쪽 취급 가능) — **규칙 수치·덱 배분은 클로드/단이**.
- 이름은 **역사·민속 샘플 라벨**. 실파트너 예명·초상으로 교체 전제.

> **board_skin_hooks open (중재 R3):** `concert_hall` · `recording_studio` · `dance_academy` · `fanshop` · `broadcast_station` · `agency_hq` **6만**. N 후보(연습실·아레나홀·하트아치 등)=주석/별표 · 배열 미열림. 틴트·FX는 `symbol_tint`/`asset_pack`으로 — hooks 키 확장 아님.

### ③ 성장 보드 얼굴 ↔ R1 상징

| 보드/도시 요소 | R1 상징 | IP 스왑 시 바뀌는 것 | 안 바뀌는 것 |
|---|---|---|---|
| 콘서트홀 | LP | 색·로고·리본·`ip_skin_pack` | 상징 종류=LP, 입구 규칙 |
| 녹음실 | 헤드폰 | 동일 | 기능·성장축 |
| 댄스 아카데미 | 운동화 | 동일 | 기능 |
| 팬샵 | 선물상자 | 패키지 스킨 | 수입 얼굴 역할 |
| 방송국 | TV | 방송 프레임 스킨 | 캐스팅/노출 역할 |
| 기획사 | 별+사옥 | 사옥 팔레트·별 뱃지 | 경영 허브 |

성장: 상징 **종류 고정**, 크기·광택·이펙트만 변화 (R1·01). IP가 바뀌어도 “LP가 헤드폰으로” 바뀌지 않음.

### ④ 스왑 구조 필드 (초안 · 시스템 비침범)

```
ip_pack:
  pack_id: "demo_sample5_v1"          # 시즌/파트너 팩 ID
  display_label: "샘플5 · 검수대기"
  member_slot_cap: 5                  # Q-001 슬롯 정원
  # active_member_count 는 런타임(1~cap) — 데이터 기본값 아님
  idols:
    - idol_id: sample_oudong
      display_name: 어우동
      group_slot: 1                   # 1..member_slot_cap
      asset_pack: "ap_oudong_v1"      # 초상·모션·보이스 훅
      board_skin_hooks: ["concert_hall"]  # open=잠금6만 · N미열림
      card_pack_id: "cp_oudong_v1"    # 멤버 덱 스킨 훅 (규칙=클로드)
      symbol_tint: "#f472b6"          # R1 상징 위 틴트만
  # 슬롯 밖 후보(풀의 미선택)는 별도 pool_entries → non_member_deck_side
  board_skin_pack: "bsp_demo_v1"      # 보드 칸 텍스처·일정 아이콘
  building_skin_pack: "build_demo_v1" # R1 ip_skin_pack 과 동일 계층
  season_keeps_rules: true            # 10/1: 규칙만 유지 · 도시(여럿)·건물·아이돌은 시즌마다 교체
  season_resets: [buildings, idols, fans]   # 9/30: 카드만 남음
```

| 필드 | 의미 | 스왑 시 |
|---|---|---|
| `idol_id` | 안정 키 | 실IP로 새 키 발급·매핑 |
| `display_name` | 표기명 | 교체 |
| `group_slot` | 슬롯 1~5 | 팩 안에서만 의미 |
| `asset_pack` | 비주얼·오디오 묶음 | **주 교체 단위** |
| `board_skin_hooks` | 보드/도시 후킹 태그 | **잠금 6키만 open** · N=별표 |
| `card_pack_id` | 카드 아트·이름 훅 | 규칙·★·레벨 본문 비포함 |
| `member_slot_cap` | 정원 5 | 시즌 설정(가변 가능하나 Q-001 기본 5) |

시스템은 `schedule_board` · `building` · `cards` · `expedition` · `leadgen` 모듈을 유지. IP는 **데이터 팩**.

### ⑤ 시즌 교체 시나리오 (한 컷)

1. 시즌 N: `demo_sample5_v1` 장착 · 슬롯5 · 활성≤5.
2. 시즌 종료·축제(단이 흐름 링크).
3. 시즌 N+1: **같은 칸 규칙·같은 성장 규칙**에 **새 세계관 도시**와 새 팩. 건물·팬은 처음부터, 지난 시즌 키운 캐릭터는 옵저버(혜택 세부 결정 대기).
4. R1 상징 종류 유지 · 틴트/로고/`asset_pack`만 변경.
5. 카드·Lead **규칙 문서 불변** · `card_pack_id` 아트만 교체.
