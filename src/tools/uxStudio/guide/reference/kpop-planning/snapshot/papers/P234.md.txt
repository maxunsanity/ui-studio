**구현과 정책의 구분:** 자유 시험에서는 가져온 데이터도 인기 재화를 무제한으로 사용하며, 사용 영수증·곡별 기여를 공통 실행/세션/시즌/내 팀 범위로 보관합니다. 화면 재진입·새로고침으로 재사용하지 않고 기존 전체 초기화가 새 범위를 엽니다. 인기 기여 차트는 사용한 인기의 누적량을 비교하는 시험 순위입니다. 실제 활동의 인기 획득 공급·유한 지갑·지급량·상한·최종 우승 점수 비중은 발란스/운영 연결 대기입니다. 인기 기여 순위와 기존 월드 종합 시험 순위를 같은 점수라고 표시하지 않습니다.

### 세 차트 보상·앨범 누적·월드 보드 전환

**2026-11-10 15:16 KST - 현중 직접 지시 반영 · 제안(검수 대기)**

| 차트 | 보상 종류 | 용도 |
|---|---|---|
| 일반 랭킹 | 한 바퀴 보상 | START 통과 정산·일반 성장 |
| 주간 페스티벌 | 레이싱 연료 | 레이싱 사용 |
| 월드 페스티벌 | 인기 재화 | 월드 출전곡 인기 기여 |

**현중 직접 정정:** 일반 차트·주간 차트·월드 차트의 세 개로 구분합니다. 주간과 월드는 개최 기간이 겹치지 않습니다. 일반은 한 바퀴 보상, 주간은 레이싱 연료, 월드는 인기 재화로 획득 내역과 표시를 분리합니다. 지급 수량·상한·정확한 획득 사건은 발란스 대기이며 인기 재화를 연료로 대체하지 않습니다.

**앨범 누적 기여:** 대표곡 한 곡을 우대하고 지난 발매곡들도 낮은 가중치로 기여하는 기존 기획을 일반 한 바퀴 보상에 명확히 연결하는 제안입니다. 1개와 8개의 차이를 보유곡 기여·직전 성적 계승·출전곡 선택 폭으로 구분합니다. 앨범 수만으로 활성 버프를 8중 적용하지 않습니다. 대표곡/구작/시간 감쇠 계수는 정본 미정값을 보존합니다.

**월드 신청과 보드 복귀:** 성공한 월드 신청의 출전곡·현재 팀을 확인한 뒤 게임으로 돌아오면 같은 보드의 연습실·녹음실 등에 공연용 간판과 월드 표시를 적용합니다. 표시가 준비된 뒤 폰 내부 모달 「월드 공연 보드로 전환됐어요」와 「공연 보드 확인」 버튼을 보여 줍니다. 신청 실패·취소·보기만 한 경우·주간에는 표시하지 않습니다. 확인한 같은 시즌/팀의 전환 알림은 재진입·새로고침·개인/크루 중복 출전으로 반복하지 않습니다. 표시가 준비되기 전에 알림을 소비하지 않습니다.

**기간·보존:** 일반 연결은 실제 월드 기간의 유효 신청을 확인합니다. 단독 테스트는 명시적으로 선택한 월드 시험만 전환하며 주간 시험으로 바꾸면 일반 보드로 복원합니다. 개인/크루 성공 기록은 보존합니다. 다음 시즌·새 공통 시험 데이터는 별도 범위로 처리합니다. 월드 종료 시 원래 시설 간판을 복원합니다.

**현재 구현 범위:** 월드 간판·표시 프로필과 1회 복귀 모달은 이번 로컬 연결 대상입니다. 건물 위치·레벨·기존 경제 writer를 바꾸거나 공연 결과·인기 재화·상금을 이 표시만으로 새 지급하지 않습니다. 실제 공연 조작/정산·월드 일반 성장 효과의 유지/대체·세 보상의 최종 지급표·누적 기여 계수는 후속 연결/발란스 대기입니다.




**현재 단독 테스트 · 2026-11-10 13:58 KST · 제안(검수 대기)**

게임 시뮬레이터 단독 테스트는 상위 메뉴를 주간 페스티벌과 월드 페스티벌로 나눕니다. 폰 하단도 주간·월드로 바로 엽니다. 일반 월드 입구는 개인 출전이며, 크루 출전은 응원 크루의 고정된 크루장 전용 신청 버튼에서만 시작합니다. 크루 화면에는 앨범의 데뷔 준비·앨범 활동·차트·파이널 단계표를 표시하지 않습니다. 주간 신청 뒤에는 레이싱 입장과 주간 진행·레이싱 기록을 바로 볼 수 있습니다. 레이싱 입장은 같은 발매 앨범의 기존 시티 투어 자동차 레이싱으로 연결합니다. 기록은 기본 펼침으로 표시합니다.

단독 테스트에서 월드 메뉴(개인·크루)에 진입하면 현재 주간 신청·버프·자동 연료/레이싱 진행을 새 시험 상태로 초기화합니다. 원본 신청 영수증은 이력으로 보존하고 현재 유효한 신청에서 제외합니다. 다시 주간에 들어오면 앨범 선택·신청부터 시작합니다. 앨범·공통 팀·이미 지급된 공통 재화·월드 신청·크루 투표는 지우지 않습니다. 이전 자동 진행 기록은 다음 실제 보드 저장에서 보관하며 활성 기록과 분리합니다. 이 초기화는 단독 테스트만의 조작이며 실제 운영 일정·게임 일차·일반 연결 플레이의 버프 정책을 바꾸지 않습니다.

자유 테스트에서는 이전 앨범의24시간 차트가 진행 중이어도 새 앨범을 먼저 발매할 수 있습니다. 기존 차트·실적·제작비 결제·발매곡을 보존하고 새 곡의 이벤트 참가는 순서대로 대기합니다. 기존 순차 차트 진입 경로를 사용하며 일반 연결 플레이의 차트 잠금과 운영 수치는 변경하지 않습니다.

주간·월드의 일반 입구는 모두 개인 신청입니다. 내 발매 앨범을 선택하고 같은 화면에서 신청하며, 월드는 성공 뒤 내 출전곡 참여 로비를 엽니다. 개인/크루 선택·선택되지 않은 곡 확인·별도 준비 단계를 두지 않습니다. 크루 소속·직책과 관계없이 크루장과 멤버도 개인 월드에 출전할 수 있습니다.

크루 월드 신청은 크루 페이지에서 크루장에게만 켭니다. 현재 멤버가 공유된 발매곡 한 곡에 내부 투표합니다. 한 번 투표하면 바꾸거나 취소할 수 없습니다. 투표 결과는 참고용이며, 크루장이 득표와 무관하게 최종 공유곡·원소유자 사용 동의를 확인해 신청합니다. 원소유자는 일반 크루원이어도 크루 페이지에서 자기 곡의 회차 사용 동의·철회를 할 수 있습니다. 내부 곡 투표는 관객의 공식 페스티벌 투표·점수·재화와 별개입니다. 개인 출전과 크루 출전을 서로 잠그지 않습니다.

주간 버프는 신청한 경우에만 해당 주의7일째부터 공통 주간 마감까지 적용합니다. 7일째 중간에 신청하면 신청 이후 남은 기간만 받습니다. 신청일부터24시간을 새로 주지 않으며, 신청 전 활동을 소급하지 않습니다. 미신청·다음 주·월드 기간에는 주간 버프가 없습니다. 다음 주에는 새로 신청합니다. 게임 시뮬레이터의 표시는 현재 게임 일차·실제 굴림 시계를 사용하며 실제 서버 시계와 구분합니다.

## 주간 · 개인 앨범 신청과 상단 버프

주간 페스티벌은 개인만 참여합니다. 들어가자마자 내 발매 앨범 선택과 신청만 보여 주고, 신청한 해당 주의7일째에만 게임 창 상단 버프 중 팝업을 표시합니다. 월드도 일반 입구는 개인 신청이며 크루 신청은 크루 페이지에서 크루장만 진행합니다.

## UI 기획 · 개별 화면 시험과 연동 제작 계획

앨범·공연·음악 앱·페스티벌은 각각 열어 시험할 수 있는 모듈로 만듭니다. 연동에서는 같은 팀·곡·공연·대회 정보를 사용하고 각 모듈의 진행 결과를 공유합니다. 감상 입구는 음악 앱에 모으며, 제작·활동·신청 UI를 하나의 거대한 화면으로 합치지 않습니다.

현재 개발되지 않음, 진행 중 · 이번에는 UI 기획과 메모리 시안을 작성했습니다. 기존 앨범/신청/음악 앱은 재사용하고 실제 공연 공급·공식 평가/인기 경제는 후속 제작으로 구분합니다.

### 주간·월드의 별도 UI

주간·월드 신청 UI는 별도로 제작합니다. 실제 플레이는 현재 주간 기간이면 주간만, 월드 기간이면 월드만 신청할 수 있게 표시합니다. 시뮬레이터의 개별 시험 입구에서는 두 화면을 각각 열어 해당 기간·미개막 상태를 시험합니다. 월드는 시즌 피날레용 무대·포스터·색/빛 연출과 출전 방법·참여 경험·시즌 기록 안내를 강화합니다. 내 출전곡 소개·시즌 순위 경쟁은 기존 흐름을 사용하고, 베스트 컷·발견 노출·시즌 회고 혜택은 기존 후속 기획으로 구분합니다. 추가 보상 종류·수량·인기 경제는 결정/발란스 대기입니다.

### 메뉴별 시험 시작점

앨범 발매 상위 메뉴의 기본 진입은 음원 제작입니다. 새 공통 테스트에서는 음원 제작 전 음악 선택 화면으로 시작하고 자동 시험 발매를 실행하지 않습니다. 작성 중인 초안은 이어가고 기존 발매곡은 보존합니다. 시티 투어는 제작·발매된 곡과 필요한 리그를 준비한 뒤 차량 선택·급유로 바로 시험합니다. 곡이 필요한 하위 콘텐츠의 준비와 제작 메뉴의 미제작 출발을 구분합니다.

### 화면 구성·주동작·복귀

| 화면 | 먼저 보는 내용 | 버튼·배치 | 이동/복귀 |
| --- | --- | --- | --- |
| 앨범 제작 | 현재 단계·선택 음악·참여 팀·큰 재킷 | 음악/재킷/제작·발매 주동작과 비용·오류를 하단 고정. 참여 옵션은 접기 | 음악→재킷→제작 완료→발매. 같은 초안 보존 |
| 앨범 활동 | 발매곡·앨범 이벤트 차트·남은 시간·현재 활동 | 보드에서 활동 / 같은 곡 감상 / 페스티벌 신청. 자세한 계산은 접기 | 선택 이동은 모바일 내부 확인, 같은 곡으로 복귀 |
| 보드 공연 | 보드 유지·현재 곡/장소·내 공연 작은 창 | 작은 창에 같은 공연 보기·줄이기·닫기. 주사위와 주요 조작을 가리지 않음 | 유효 장소 도착→공연 시작. 작은 창을 눌러 같은 공연 관람 |

| 주간 신청 UI | 개인 전용·내 발매 앨범 목록·선택 상태 | 앨범 선택과 주간 신청 버튼만 | 신청 완료·보드 복귀 → 해당 주7일째에 상단 버프 |
| 월드 신청 UI | 월드 기간·시즌 무대·내 앨범·참여 경험/혜택, 크루 입구 별도 | 화려한 무대·내 앨범 선택과 신청, 상세 안내 접기 | 월드의 성공 출전곡만 월드 활동 로비 |
| 페스티벌 참여 | 현재 회차·등록곡·참여 중·순위 또는 집계 전 | 순위·다른 곡 듣기 / 대회 보기. 재신청 폼 숨김 | 같은 회차 음악 앱→같은 출전곡 로비로 복귀 |

### 개별 시험과 연동의 경계

| 모듈 | 개별 화면 | 시험 준비 | 연동할 원본 |

| --- | --- | --- |

| 앨범↔보드 | 발매곡의 활동 입구→보드→곡 차트 | 같은 팀·곡·기존 활동/START 영수증. 왕복으로 새 발매/지급 없음 |
| 보드↔공연 | 해당 장소의 실제 공연 시작→PIP→확인→관람→복귀 | 같은 공연 ID·채널·곡·종료 상태. 취소는 이동만 취소, PIP 닫기는 공연 취소 아님 |
| 대회↔음악 앱 | 신청 성공→활동 로비→확인→같은 회차 차트→복귀 | 같은 round/entry·개인/크루·곡. 조회/재생이 투표 제출이 아님 |
| 누락·오류 | 곡 없음·사용자 초안·공연 없음·미개막·동의 없음·원본 연결 대기 | 없는 원본은 대기/빈 화면. 다른 공연·곡·회차로 대신 채우지 않음 |
| 공유·복원 | 발란스 가져오기→여러 메뉴 조작→재접속→전체 초기화 | 가져온 데이터/결과 공통 유지·시험 재화 무제한. 초기화 전 새 수신/메뉴 진입이 덮어쓰지 않음 |

시험 조작·상태 선택은 오른쪽/외부 검수 패널에 둡니다. 모바일 본문에는 현재 행동·대상·비용/실패 사유를 먼저 보입니다. 다른 콘텐츠 이동은 모바일 내부 확인을 거치며, 같은 음악 앱의 곡/공연 상세 이동은 직접 처리합니다. 페스티벌 점수 설정·투표 시험·월드 인기·우승은 기존의 접힌 보조 도구 안에 함께 둡니다. 음악 앱의 하위 메뉴는 음원·공연·숏츠이며 같은 음악 앱 안에서 각각 시험합니다.

## 1. 역할과 기준

| 기준 | 내용 | 근거 구분 |
|---|---|---|
| 공연은 독립 기능 | 앨범은 곡 공급, 공연은 상태/실황, 페스티벌은 인정 성과를 받음 | 사용자 지정 |
| 고정 시청 그룹 | 등급별 기본 100명을 입장 때 결정 | 사용자 지정 |
| 친구·크루 전원 | 중복을 제거해 전원 포함. 100명을 넘으면 초과 허용 | 사용자 지정 |
| 빈자리 충원 | 친구·크루 합계가 100명 미만이면 같은 등급 유저로 충원 | 사용자 지정 |
| 주간 명단 | 주간 경쟁 상대 전원 + 친구·크루 별도 추가. 같은 사람은 한 명 | 사용자 답변 |
| 재설정 | 다른 그룹으로 바꾸는 설정 제공 | 사용자 지정 |

| 세부 갱신·재설정·키 처리 | 아래의 상태/화면/예외 규칙 | 제안(검수 대기) |

~~~mermaid
flowchart LR
 P["P233 · 그림/표 중심 간략"] --> D["P234 · 상세 규칙"]
 A["앨범·친구·크루·등급·주간 원본"] --> S["독립 공연·고정 시청 그룹"]
 S --> V["PIP·6채널 실황"]
 S --> F["페스티벌 공식 성과"]
~~~

100명은 한 번에 재생하는 영상 수가 아니라 내가 공연을 공유받는 타인 유저 명단의 기본 규모입니다. 같은 유저의 여러 곡/6채널 공연은 한 명입니다. 내 공연은 별도 고정 PIP이며 타인 100명에 다시 세지 않는 세부안입니다.

시청 명단과 순위 매칭 명단은 다릅니다. 관람 그룹을 바꿔도 주간의 경쟁 상대·득점·순위는 바뀌지 않습니다. 시청 명단은 계정의 친구·크루 관계를 반영하므로 다른 관객과 반드시 같은 집합일 필요는 없습니다. 상호 시청을 강제로 보장하는 방이나 채팅방 생성은 이번 범위가 아닙니다.

## 2. 일반 그룹 인원 계산

### 2-1. 집합과 단위

| 기호 | 뜻 | 포함·중복 |
|---|---|---|
| F | 현재 유효한 친구 유저 | 계정 ID 기준 |
| C | 현재 가입 크루의 유저 | 본인은 타인 목록에서 제외 |
| S | F와 C의 합집합 | 친구이면서 크루원이면 한 명 |
| E | 같은 등급의 일반 충원 후보 | 본인·S·접근 불가 대상 제외 |
| T | E에서 최초 배정/재설정으로 선택한 일반 유저 | 중복 없음 |
| N | 일반 관람 명단 S와 T의 합집합 | 친구·크루·일반 포함 사유 보존 |
| W | 해당 주간의 실제 경쟁 상대 | 3장의 원본 매핑 적용 |

기본 목표는 100명입니다. 일반 충원 수는 max(0, 100 − S의 인원)이고, 충분한 같은 등급 후보가 있으면 N의 인원은 max(100, S의 인원)입니다. 후보가 부족하면 실제 충원 가능한 수만 넣습니다.

~~~mermaid
flowchart TD
 F["친구 F"] --> S["S = 친구 ∪ 크루"]
 C["크루 C"] --> S
 S --> D{"중복 제거 후 인원"}
 D -->|100명 미만| T["같은 등급 후보에서 부족분 T 선택"]
 D -->|100명 이상| A["S 전원 · 일반 충원 없음"]
 T --> N["N = S ∪ T · 입장 명단 고정"]
 A --> N
~~~

### 2-2. 일반 인원 사례

| 사례 | 친구 | 크루 | 양쪽에 겹침 | S | 일반 충원 T | 최종 N |
|---|---|---|---|---|---|---|
| 관계 없음 | 0 | 0 | 0 | 0 | 100 | 100 |
| 소규모 관계 | 20 | 30 | 10 | 40 | 60 | 100 |
| 양쪽 합계로 초과 | 80 | 70 | 20 | 130 | 0 | 130 |
| 친구만 초과 | 120 | 0 | 0 | 120 | 0 | 120 |
| 양쪽 각각 100명 미만 | 60 | 60 | 30 | 90 | 10 | 100 |
| 같은 등급 일반 후보 70명뿐 | 0 | 0 | 0 | 0 | 70 | 70 · 30자리 미충원 |

친구/크루를 각각 100명까지 자르거나 먼저 접속한 관계자만 남기지 않습니다. S가 초과하면 전원에게 접근할 수 있는 목록을 제공하고, 페이지/검색/필터로 나눠 표시합니다. 100명 초과가 동시에 100개 넘는 영상을 자동 재생한다는 뜻은 아닙니다.

### 2-3. 포함 사유와 중복

같은 계정은 한 행만 두고 친구·크루·주간 상대 배지를 함께 붙입니다. 한 사유가 없어져도 다른 사유가 유효하면 유지합니다. 계정이 같은 여러 팀/앨범은 인원 중복으로 세지 않고 해당 유저 행의 공연/곡 목록으로 연결합니다.

일반 충원 T만 같은 등급으로 제한합니다. 친구·크루·주간 상대는 다른 등급이어도 필수 포함입니다. 차단·비공개·삭제·공연 사용 권한은 최신 상태를 적용하고 시청 가능한 공연과 단순 명단 포함을 구분합니다.

<a id="stage-weekly-roster"></a>
## 3. 주간 경쟁 상대 · 친구/크루와 별도

사용자 답변 기준으로 주간은 실제 경쟁 상대 전원을 먼저 유지하고 친구·크루를 추가합니다. 일반 관람의 S 때문에 주간 상대를 줄이지 않습니다.

**주간 시청 명단 V = W ∪ S. 인원 = W 인원 + S 인원 − 겹친 인원.**

~~~mermaid
flowchart LR
 W["주간 원본 경쟁 상대 W · 전원"] --> U["합집합 · 같은 사람 한 명"]
 S["친구·크루 S · 별도 추가"] --> U
 U --> V["주간 관람 명단 V"]
 V --> C["같은 6개 채널"]
 R["일반 그룹 재설정"] -.-> P["W·주간 순위는 유지"]
~~~

| W | S | W와 S 겹침 | 주간 총인원 | 화면 요약 |
|---|---|---|---|---|
| 100 | 40 | 10 | 130 | 경쟁 상대 100 · 관계자 추가 30 |
| 100 | 120 | 30 | 190 | 경쟁 상대 100 · 관계자 추가 90 |
| 100 | 0 | 0 | 100 | 경쟁 상대 100 |
| 60 | 0 | 0 | 60 | 원본 경쟁 상대 60 |

W의 크기는 실제 주간 매칭 원본 그대로이며 여기서 임의로 100명으로 늘리거나 자르지 않습니다. 일반 그룹 N/T는 별도로 보존하고, 주간 화면에는 V를 사용합니다. 주간 상대가 적다고 다른 유저를 새 경쟁 상대처럼 채우지 않습니다. 대회 밖 유저를 더 보고 싶으면 일반 내 그룹으로 이동합니다.

### 3-1. 원본이 유저가 아니라 출전곡인 경우

주간 원본의 entryId/roundId와 소유 계정 또는 크루를 보존합니다. 개인 출전 한 건은 소유 유저에, 크루 출전 한 건은 등록 크루/공식 곡 행에 연결합니다. 크루 한 출전 건을 회원 전원의 개인 출전으로 늘리지 않습니다.

인원 표시는 중복 없는 유저 수와 크루 출전 건수를 따로 나타냅니다. 원본이 개인/크루 혼합이면 모든 경쟁 entry를 빠짐없이 보여 주고, 공식 곡의 소유자/크루 표시를 통해 시청 명단과 연결합니다. 크루를 유저 수로 임의 환산하지 않습니다. 정확한 원본 매핑은 기존 주간 매칭 공급 계약에 맞춥니다.

앨범 하루 이벤트의 본인+가상99명을 실제 주간 유저 매칭으로 바꿔 부르지 않습니다. 주간 매칭 원본이 없으면 주간 상대 확인 중이며 일반 그룹을 유지합니다.

### 3-2. 회차 변경

주간이 시작되면 해당 roundId의 W를 읽고 고정합니다. 새 회차는 새 W로 교체하되 이전 회차 기록은 보존합니다. 친구 추가·크루 이동·관람 그룹 변경으로 W나 순위를 다시 매칭하지 않습니다. 상대가 오프라인이어도 명단에는 남습니다.

<a id="stage-assignment"></a>
## 4. 입장·등급·동접·관계 갱신

### 4-1. 최초 배정

~~~mermaid
sequenceDiagram
 participant U as 유저
 participant S as 시청 그룹
 participant O as 등급·관계 원본
 U->>S: 최초 입장
 S->>O: 현재 등급·친구·크루·주간 상대 조회
 O-->>S: 유효한 원본 목록
 S->>S: 중복 제거·일반 충원·명단 버전 확정
 S-->>U: 내 그룹 인원·관계 배지·6채널
 U->>S: 재접속/채널 전환
 S-->>U: 기존 명단 복원·공연 상태만 갱신
~~~

입장은 매번 앱 탭을 여는 행위가 아니라 해당 관람 그룹의 최초 배정 시점입니다. 명단은 명시적인 다른 그룹 보기와 필수 관계/주간 회차 갱신을 제외하면 유지합니다. 현재 등급을 기록하고, 등급이 올랐다고 일반 유저를 자동으로 갈아 끼우지 않습니다. 새 그룹 배정 시점에는 최신 등급을 사용합니다.

등급은 기존 게임의 등급 정본을 연결합니다. 이 기획에서 새 등급명·경계값을 만들지 않습니다. 등급 원본이 공급되지 않으면 등급 확인 중으로 두고 임의 평균·팬 수로 대신하지 않습니다.

### 4-2. 후보 부족과 오프라인

일반 충원 후보는 같은 등급에서 공개 공연을 공유할 수 있는 유저입니다. 온라인/최근 활동 유저를 우선하는 세부안이며, 오프라인 친구·크루·경쟁 상대도 포함합니다. 인원이 부족하면 실제 인원과 미충원 수를 표시합니다. 다른 등급·가짜 유저로 몰래 채우지 않습니다.

한번 들어간 유저가 로그아웃해도 명단에서 제거하지 않습니다. 공연 중·최근 공연·공연 없음 상태만 달라집니다. 빈자리를 자동으로 새로운 유저로 계속 돌려 보여 주지 않습니다. 새로 들어온 가용 후보로 미충원을 보충하는 정책은 아래 4-3에 한정합니다.

### 4-3. 필수 관계 변경 · 세부안

| 변화 | 제안 처리 |
|---|---|
| 새 친구/새 크루원 | S에 포함하고 일반 충원 일부만 줄여 목표 인원 조정 |
| 친구 해제/크루 탈퇴 | 남은 포함 사유 확인. 다른 사유가 없으면 관계 대상에서 제외 |
| S 증가로 100명 초과 | 일반 충원은 빼고 S 전원 유지 |
| S 감소·후보 부족 해소 | 같은 등급으로 부족분만 보충. 나머지 기존 일반 유저는 유지 |
| 등급 상승 | 현재 명단 유지. 다음 명시 재설정에 최신 등급 적용 |
| 새 주간 회차 | 해당 회차 W만 갱신. 일반 그룹 N은 유지 |
| 차단/공개 권한 변경 | 최신 접근 권한 반영. 노출 불가 공연을 재생하지 않음 |

이는 전체 그룹을 몰래 새로 뽑는 동적 추천이 아니라 필수 관계와 빈자리의 최소 갱신입니다. 변경 사유와 명단 버전을 표시하고, 새로 들어온 유저도 다음 갱신 전까지 유지합니다.

### 4-4. 동접 시나리오

| 상황 | 배정/노출 |
|---|---|
| 동접 100명 | 같은 등급·공개 가능한 대상이 적으면 미충원 표시. 공연 중인 사람이 적어도 명단은 유지 |
| 동접 100만 명 | 최초/명시 재설정 때 같은 등급 후보를 분산 배정. 이후 전역 접속 증감으로 고정 명단을 회전시키지 않음 |
| 친구/크루가 100명 초과 | 전원을 명단에 포함하고 목록을 나눠 불러옴. 실제 공연 영상은 선택된 것만 재생 |
| 특정 채널에 공연 없음 | 그 채널의 최근 공연/공연 없음 표시. 그룹 밖 공연을 끼워 넣지 않음 |
| 주간 경쟁 상대가 오프라인 | 명단·순위 대상 유지. 최신/최근 무대를 구분 |

동접 규모는 배정 처리와 전송 방식에 영향을 주지만 내가 볼 수 있는 대상 집합의 규칙을 바꾸지 않습니다. 100만 동접을 처리했다는 실측 근거는 아직 없습니다.

## 5. 보드별 채널·내 PIP·목록

~~~mermaid
flowchart TD
 V["현재 관람 모드의 고정 명단"] --> C["보드별 6채널"]
 C --> L["공연 중 · 새 무대 · 최근 공연"]
 L --> P["공통 영상 플레이어"]
 B["내 공연 실제 시작"] --> I["게임 우측 PIP"]
 I --> P
 P --> M["음악 앱 · 같은 곡/회차"]
~~~

### 5-1. 관람 모드

| 모드 | 대상 집합 | 인원 표시 |
|---|---|---|
| 내 그룹 | N = 친구·크루 + 일반 충원 | 총인원 · 친구/크루 배지 · 미충원 |
| 주간 대회 | V = 주간 W + 친구·크루 S | 경쟁 상대 수 · 겹치지 않는 관계자 추가 |
| 월드 상위권 | 관람 키로 허용된 해당 월드 상위권 | 상위권 출전 목록·순위·갱신 시각 |

6채널은 어느 모드에서도 같은 원본 보드를 기준으로 구분합니다. 일반 명단 100명을 채널마다 따로 뽑아 600명으로 늘리지 않습니다. 친구·크루·주간 상대 필터는 기존 명단을 좁혀 보는 기능이며 새 사람을 배정하지 않습니다.

### 5-2. 6칸 콘셉트

| 보드 | 발매 전 | 발매 후 | 무대 |
|---|---|---|---|
| 방송27 | 거리 인터뷰 | 예능 방송국 | 인터뷰·예능·무대 토크 |
| 방송28 | 온라인 홍보방송 | 라디오 방송국 | 소개·보이는 라디오·라이브 |
| 방송30 | 신인 소개방송 | 음악 방송국 | 신인 소개·음악방송 |
| 공연32 | 거리 버스킹 | 라이브 공연장 | 거리/소규모 라이브 |
| 공연33 | 공원 버스킹 | 쇼케이스 공연장 | 공원/신곡 쇼케이스 |
| 공연35 | 오픈마이크 무대 | 콘서트장 | 오픈마이크/콘서트 |

명칭·점등은 [앨범 첫 발매 기획](../개발진행기획_v01/콘텐츠별_v03/앨범발매_기획서.html#album-board-activation)의 제안과 같습니다. 기존 성장 단계와 기본 활동을 유지합니다.

### 5-3. 목록과 중복

첫 화면은 내 그룹/주간/월드 모드 → 보드 채널 → 한 줄 공연 목록입니다. 명단의 모든 유저를 동시에 영상 창으로 띄우지 않습니다. 현재 공연 중인 무대와 아직 못 본 무대를 먼저, 최근 무대는 별도로 보여 주는 세부안입니다.

유저 행은 하나이며 공연 목록을 펼쳐 볼 수 있습니다. 같은 performanceId의 영상·숏츠·다른 카메라 각도는 같은 공연으로 묶습니다. 같은 사람의 다른 실제 공연은 새 공연이지만 자동 연속 노출은 제한합니다. 정확한 순서·연속 제한은 정책 데이터로 둡니다.

시청 이력은 실제 재생 확인으로 기록하고 그룹 변경·앱/탭 전환으로 초기화하지 않습니다. 미시청 무대가 없으면 새로운 공연을 기다리는 중과 직접 다시보기를 제공합니다. 자동 추천 소진이 관람 대상 유저의 명단 삭제를 뜻하지 않습니다.

### 5-4. 내 공연 PIP와 소리

내 공연은 공개 관람 그룹 배정/다른 사람의 접속 여부와 관계없이 실제 시작 때 게임 우측 PIP에 표시합니다. 공연 중·곡·채널을 보여 주고, 누르면 같은 공연을 크게 봅니다. 줄이기/닫기는 공연 취소가 아닙니다. 화면 복귀 때 사용자가 줄이거나 닫은 선택을 유지합니다.

기존 음악이 재생 중이면 PIP는 음소거로 시작합니다. 소리를 켜면 공통 오디오 초점을 전환하고 이전 곡/큐/위치를 보존합니다. PIP·스테이지·음악 앱이 동시에 소리를 내지 않게 합니다. 좁은 화면은 주사위/주요 조작·자막을 가리지 않는 우측 작은 창 또는 최소화 표시를 사용합니다.

### 5-5. 실황 상태

| 실제 상태 | 표시 |
|---|---|
| 공연 시작·매체 준비 | 공연 중 · 현재 지점에 합류 |
| 공연 시작·영상 지연 | 공연 중 + 영상 연결 중 |
| 종료·재생 가능한 자료 있음 | 다시보기 |
| 연결 끊김·현재 진행 불명 | 상태 확인 중 |
| 허용된 자료 없음 | 공연 정보만 표시 · 영상 없음 |

발매 영상과 게임 장면으로 재현한 무대는 게임 내 공연 재현으로 구분합니다. 끝난 영상을 처음부터 틀며 LIVE라고 표시하지 않습니다. 인터뷰만 한 사건을 노래 공연 결과로 자동 환산하지 않습니다.

### 5-6. 독립 숏츠와 음원 보기의 연결

[독립 숏츠 간략 P235](../개발진행기획_v01/콘텐츠별_v03/숏츠_핵심제안서.html)와 [상세 P236](산출_기획서_숏츠_상세_v1.html)은 공개 게시물 발견·아이돌/팀 구독을 담당합니다. 스테이지의 고정100명 관람 명단을 숏츠 전체 후보의 상한으로 사용하지 않습니다.

~~~mermaid
flowchart LR
 S["공개 숏츠 발견"] -->|같은 원곡| M["음원 보기"]
 S -->|원공연·권한 확인| P["스테이지 관람"]
 P -->|허용된 하이라이트| H["관련 숏츠 문맥"]
 P -->|사용 곡| M
~~~

숏츠를 보고 구독해도 내 N/W 명단이나 키 관람권이 생기지 않습니다. 스테이지 안의 관련 숏츠는 현재 공연/관람 대상과 매체 권한을 적용하며, 키 전용 원본·실황·다시보기를 공개 숏츠로 우회하지 않습니다. 별도로 공개 허용된 하이라이트는 그 공개 권한대로 감상할 수 있습니다.

같은 게시물은 shortId를 공유해 찜/댓글을 화면마다 복사하지 않습니다. 원공연은 canonical performanceId로 연결하되 다른 편집본은 별도 게시물입니다. 같은 원곡/공연만 따라 이동하고 돌아오면 원래 모드·명단·채널·PIP 상태와 재생 위치를 복원합니다. [왕복·큐·시간 대응 상세](산출_기획서_숏츠_상세_v1.html#shorts-cross-navigation).

<a id="stage-regroup"></a>
## 6. 다른 그룹 보기 · 일반 충원만 교체

~~~mermaid
flowchart TD
 U["설정 · 다른 그룹 보기"] --> P["새 일반 대상 미리보기"]
 P --> C{"명단 교체 확인"}
 C -->|적용| N["일반 T만 새 T로 교체"]
 C -->|취소/실패| O["기존 명단 유지"]
 N --> K["친구·크루·주간 상대·점수·시청 이력 유지"]
~~~

### 6-1. 화면과 변경 범위

설정에는 현재 그룹의 등급·총인원·친구/크루·일반 충원·미충원 수와 다른 그룹 보기 기능을 둡니다. 새 그룹에서 바뀌는 일반 유저 수를 보여 주고 적용합니다. 이는 관람 명단 변경이며 새 게임/시즌 초기화가 아닙니다.

| 항목 | 처리 |
|---|---|
| 일반 충원 T | 새로운 같은 등급 대상으로 교체 |
| 친구·크루 S | 유지 |
| 주간 경쟁 상대 W | 유지 |
| 현재 주간/월드 출전곡·점수·순위 | 유지 |
| 투표·인기 사용·공식 공연 결과 | 유지 |
| 공연 시청 이력 | 유지. 옛 공연을 새 미시청으로 바꾸지 않음 |
| 기존 키 사용/관람권 | 유지 |
| 그룹 버전·배정 시각 | 새 버전으로 갱신 |

재설정은 내 그룹 모드에서 수행합니다. 주간 모드에서 다른 그룹 보기를 선택하면 주간 상대는 변경되지 않음을 표시하고 일반 그룹 설정으로 이동합니다. 친구·크루만으로 100명 이상이면 교체할 일반 대상이 없으므로 그 이유를 표시합니다.

### 6-2. 후보 선택과 실패

현재 일반 유저는 우선 제외하고 같은 등급의 새 후보를 선택합니다. 이전 관람 그룹과도 가능한 한 겹치지 않게 하는 세부안입니다. 친구·크루·주간 상대를 임의로 제외해서 새 인원처럼 보이게 하지 않습니다.

새 후보가 부족하면 바뀔 인원/유지될 인원을 보여 주며, 새 대상이 전혀 없으면 바꿀 다른 유저가 없어요로 종료합니다. 동일 명단인데 성공했다고 표시하지 않습니다. 재설정 비용·대기시간·횟수 제한은 결정 대기이며 이 기획에서 수치를 만들지 않습니다.

적용은 새 전체 명단을 확정한 뒤 한 번에 교체합니다. 실패·취소·통신 중단 시 기존 명단을 유지합니다. 같은 변경 요청 재시도는 중복 교체하지 않으며 여러 기기에서 동시 요청하면 최신 명단 버전을 확인합니다.

### 6-3. 새 계정/시즌/등급

명의·팀·시즌과 시청 계정의 연결을 구분합니다. 개인의 재접속이나 팀 성장만으로 새 그룹/시청 기회를 반복 생성하지 않습니다. 시즌이 바뀔 때 일반 그룹을 보존할지 새로 배정할지는 시즌 원본과 함께 결정할 항목입니다.

<a id="stage-world-key"></a>
## 7. 월드 상위권 관람 키

키는 기본 그룹 밖의 상위권 공연을 찾는 월드 기간 한정 관람 권한입니다. 기본 그룹과 주간 경쟁 상대를 보는 데에는 이 키를 요구하지 않습니다.

~~~mermaid
flowchart TD
 U["월드 상위권 보기"] --> T{"공식 월드 기간?"}
 T -->|아니요| L["기간 안내 · 내 그룹 유지"]
 T -->|예| A{"이번 월드 관람권 있음?"}
 A -->|있음| V["공식 상위권 목록·무대"]
 A -->|없음| K["관람 키 확인·사용"]
 K --> R["해당 월드 관람권 발급"]
 R --> V
~~~

### 7-1. 접근 범위

| 대상 | 키 필요 | 100명 그룹과의 관계 |
|---|---|---|
| 내 공연 PIP | 없음 | 별도 내 공연 |
| 내 그룹 N | 없음 | 그대로 유지 |
| 주간 V | 없음 | 경쟁 상대 + 관계자 유지 |
| 친구·크루·주간 상대이면서 상위권인 유저 | 없음 | 기존 포함 권한으로 관람 |
| 내 명단 밖 상위권 발견 목록 | 필요 | 월드 전용 별도 모드. N/W를 덮어쓰지 않음 |

친구·크루가 상위 등급/상위권이어도 기존 포함 권한을 키로 다시 잠그지 않는 세부안입니다. 월드 상위권 관람 모드만 별도로 엽니다. 상위권의 기준·범위·공식 순위 구간은 결정 대기이며 임의 Top100을 만들지 않습니다.

### 7-2. 사용과 만료 · 세부안

키를 사용해 해당 월드 회차 동안 상위권 모드를 여는 방식으로 제안합니다. 무대마다 반복 사용시키는 방식은 현재 안에 넣지 않습니다. 키 획득처·수량·비용·소모량·만료 후 잔여 키 처리는 결정 대기입니다.

사용 시 공식 월드 기간·현재 회차·키·기존 관람권을 확인합니다. 이미 권한이 있으면 다시 소모하지 않습니다. 권한 발급과 소모를 함께 확정하고, 요청 실패/재시도/기간 종료 경합으로 키만 사라지지 않게 합니다.

기간 종료 시 상위권 모드를 닫고 내 그룹으로 복귀하는 세부안입니다. 다음 월드에 이전 관람권이 자동으로 통하지 않게 회차를 구분합니다. 관람 종료가 기존 시청/투표/점수 기록을 지우지는 않습니다.

### 7-3. 순위와의 관계

키는 관람 대상 확장입니다. 공식 출전 자격·투표 예산·표의 무게·G 배수·주간 매칭을 바꾸지 않습니다. 상위권 시청 후 투표할 때도 음악 앱의 같은 계정/회차 한도를 따릅니다. 심사·곡 선호 배틀의 공식 후보 배정과 관람 키는 별개입니다.

 B->>P: 종료·검증 결과
 P->>F: 곡·회차·공식 기회에 맞는 결과
 F->>F: 중복·기간·상한 확인
 F-->>V: 인정 상태·잠정 순위·기준시각
 Note over V,F: 명단 재설정·재생·키 사용은 재득점 아님
~~~

| 항목 | 근거 | 중복 방지 |
|---|---|---|
| A 팬 평가 | 음악 앱의 인정 투표·기존 유효 선호 규칙 | 같은 계정/회차 예산 |
| B 실력 | 접수 기준으로 동결한 아이돌 능력 | 공연 성장분을 다시 합산하지 않음 |
| G 공연게임 | 검증한 공식 무대/대결 결과 | 같은 결과·공식 슬롯 한 번 |
| C 인기 응원 | 획득 후 지정곡에 실제 사용한 인기 | 획득·소비를 이중 가산하지 않음 |

시작/영상 노출/시청/키 사용 자체로 표나 G를 주지 않습니다. 크루 회원 전원을 시청 명단에 넣어도 회원 수가 곧 공식 공연 점수는 아닙니다. 관람 그룹 크기가 커졌다고 투표 예산도 커지지 않습니다.

공식 공연이 인정되면 해당 회차 잠정 순위를 갱신합니다. 상대 성적에 따라 상승·유지·하락할 수 있습니다. 기존 돈·팬·능력 지급은 [방송·공연 활동](../개발진행기획_v01/콘텐츠별_v03/방송공연활동_기획서.html)의 보드/START 정산을 따릅니다. 점수 갱신으로 보상을 재지급하지 않습니다.

주간/월드의 같은 공연 이중 인정, 과거 공연의 새 회차 소급 인정은 자동 적용하지 않습니다. 기간·공식 기회·기록 채택·상한과 실제 조작/배틀은 후속 기획입니다. 게릴라 공격/출연권/잭팟의 기존 결과는 공식 무대 G와 구분하고 기존 직접 가산 금지를 유지합니다.

### 8-2. 데이터 연결 · 필드명은 구현 설계에서 조정

| 묶음 | 기록할 근거 | 목적 |
|---|---|---|
| 관람 그룹 | viewerAccountId, groupId, rosterRevision, assignedGrade, assignedAt | 최초 배정·등급·고정 명단 |
| 포함 사유 | userAccountId와 friend/crew/fill/weekly 사유 집합 | 중복 인원 제거·관계 갱신 |
| 주간 원본 | roundId, matchGroupId, entryId, 개인/크루 소유 참조 | 실제 경쟁 상대 전원 유지 |
| 재설정 | requestId, 이전/새 그룹 버전·새 충원 대상 | 실패 복구·동시 변경·중복 요청 |
| 월드 권한 | worldRoundId, keyReceipt, watchGrant, 유효 기간 | 회차별 관람권과 소모 일치 |
| 공연 | canonical performanceId, sourceEventId, boardPos, owner/team/album/entry, 시작/종료/status, mediaRef | 같은 공연 원본과 채널 |
| 시청 | viewerAccountId + performanceId + 실제 재생 상태 | 앱/탭/그룹 변경 중복 유지 |
| 결과 | resultId, officialSlot, rulesRevision, scoreReceipt | 검증·한 번 인정·정정 |

그룹 인원과 공연 수, 출전 entry 수, 실제 시청자 수는 별도 지표입니다. 한 유저의 공연/곡을 여러 명으로 세지 않고 NPC 관객을 실제 접속자로 세지 않습니다.

### 8-3. 조회 범위와 저장

명단의 유저 ID/그룹 버전과 공연 상태를 분리합니다. 공연이 시작/종료될 때마다 명단 전체를 다시 배정하지 않습니다. 채널은 현재 모드의 명단과 해당 보드의 실제 공연을 교집합으로 조회합니다. 상위권 모드만 해당 월드 권한의 상위권 목록을 씁니다.

100명을 넘는 필수 관계자와 공연 목록은 페이지·검색·필터로 나눠 읽되 총인원과 대상 접근권을 줄이지 않습니다. 고동접에서 배정/목록 조회를 나눠 처리하더라도 같은 그룹 버전과 포함 대상을 유지합니다. 실제 전송·부하 구성은 구현 설계와 검증 대상입니다.

새 공연 시청 이력·영상 원문을 브라우저 한 판 저장에 무한 누적하지 않습니다. 저장 위치·크기·만료/압축·불완전 저장 복구를 계산한 뒤 구현합니다. 기존 사용자 저장을 지우거나 덮는 시험은 하지 않습니다.

이 절은 **로컬 UI 구현과 확인한 범위**입니다. 실제 공연·추천·계정 소셜 등 운영 기능 개발 완료나 실제 서버 검증 결과를 뜻하지 않습니다. 위 장의 실제 서비스 규칙은 구현 대상으로 유지합니다.

음악 앱을 음원 기본의 공통 관람 입구로 사용합니다. 음악/차트/보관함을 유지하고 곡 상세의 같은 곡 스테이지·홈의 지금 공연 중·별도 숏츠 발견으로 이동합니다. 보드 PIP는 같은 실제 공연으로 연결하는 기획이며 공급은 후속입니다. 기존 음악 앱 컨트롤러·단일 플레이어와 게임 복귀를 재사용합니다. 음원·공연·숏츠 개별 시험도 같은 음악 앱의 하위 메뉴에서 엽니다.

### 기존 음악 화면 재사용과 게임 왕복

BGM은 현재 소유한 실제 발매 앨범의 검증된 재생 src에만 허용합니다. 시안 fixture나 다른 팀의 곡을 내 BGM으로 바꾸지 않습니다. 선택은 메모리에만 두고 해당 곡을 반복하며 보드 왕복에 유지합니다. 다른 명시 재생으로 초점을 넘기거나 BGM을 끝내면 기존 반복 설정을 복원합니다. 새로고침 뒤 선택·재생 복원은 보장하지 않습니다.

격리된 실제 UI에서 음악→생성 1회 결제→재킷→제작→발매→새로고침 보존과 미디어의 실제 곡 1회 선택·BGM·게임 복귀·보드에서 미디어 재진입·내 발매곡 명시 연결을 확인했습니다. 이는 실제 추천/공연 서버나 계정 구독·대규모 정렬·부하 검증의 완료를 뜻하지 않습니다.

영상으로 표시하는 시안 매체는 영상 포스터와 라이선스 샘플 음원입니다. 실제 동영상 생성·실시간 방송으로 표시하지 않습니다.
