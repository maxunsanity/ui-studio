## 2. 처음 케미 3단계

| 규칙 | 내용 |
|---|---|
| R-CHM-1 정하는 때 | ① 아이돌이 슬롯에 들어올 때(기존 아이돌 · 배치 스태프 각각과) ② 스태프 자리에 새 인물이 들어올 때(그 자리와 짝이 되는 아이돌 각각과). 적용 범위는 아이돌 ↔ 아이돌, 아이돌 ↔ 스태프(확정 세팅 Q2). 팬클럽 회장 · 스태프 ↔ 스태프는 이 통합 스펙에 넣지 않습니다 |
| R-CHM-2 계산 | 처음 라포 = 쌍마다 균등 랜덤 0~10(`rapport_pair.csv` 기본값) + 성격 궁합 값(`personality_compat.csv`, 16유형 × 16유형 × 4축)의 합 |
| R-CHM-3 단계 | 처음 라포 합이 위 문턱 이상이면 **찰떡**, 아래 문턱 미만이면 **최악**, 사이는 **보통** |
| R-CHM-4 미리보기 | 캐스팅 · 스태프 고용 전에 케미 미리보기를 보여 줍니다(P240 17-1, 상세 2-5). 미리보기는 단계 이름만 보입니다 |
| R-CHM-5 막지 않음 | 최악이어도 같은 팀 · 같은 스케줄에 넣을 수 있습니다(헌법 제8조) |

- 11/17 클로드 구현: 게임 시뮬 스케줄 파티 화면에 고른 짝마다 처음 케미(찰떡 · 보통 · 최악)를 보여 줌(`src/simulator/shared/chem-preview.mjs`). 아이돌 짝 처음 값 = 짝 초기화 값에서 긴장 축을 뺀 축 평균(구조 확인용 규칙), 스태프 짝 = `staff-rapport.mjs` 처음 값. 막지 않음. 캐스팅 · 스태프 고용 전 미리보기는 아직(캐스팅 화면).

- **현재 세팅값 실태:** `personality_compat.csv` 544행의 `value`가 **전부 0**이고(`comfort_ok` 1 = 160행, 0 = 384행), 찰떡 · 최악 문턱 열도 아직 없습니다. 그래서 지금은 모든 쌍이 랜덤 0~10만으로 정해지고, 문턱이 없으면 **전원 「보통」**으로 읽힙니다.
- 통합 세팅: 비앙카가 궁합 값과 문턱을 넣으면 그대로 3단계가 나뉩니다. 확정 비율은 찰떡 20% · 보통 60% · 최악 20%(8장 Q1)이며, 이 비율이 나오도록 문턱을 맞춥니다.

| 규칙 | 내용 |
|---|---|
| R-TP-1 대상 | 처음 케미가 **최악**인 쌍. 아이돌 ↔ 아이돌, 아이돌 ↔ 스태프 양쪽 |
| R-TP-2 초반 어긋남 | 최악 쌍은 라포 오름이 느린 상태로 시작합니다(값은 기존 라포 규칙 그대로, 별도 감소 없음) |

| R-TP-6 보너스 | 화해 뒤 그 쌍에 「전화위복」 특별 보너스(라포 보너스에 가산 +, 찰떡 보너스의 1.5배). 수치는 비앙카 장부 값을 `turnaround_bonus` 열에 넣습니다 |

| R-TP-8 건너뛰기 | 장면을 건너뛰어도 기록과 판정은 처리합니다(P239 넘기기 규칙) |

|---|---|---|
| 찰떡 | 처음부터 잘 맞음 | 찰떡 보너스(비앙카 장부 수치) |
| 보통 | 기본 | 0 |
| 최악 | 초반에 어긋남 | 0 (라포 오름만 느림) |

## 5. 필러 룰렛 · LogBox · 대사창과의 연결

| 순서 | 무엇 | 현재 세팅 |
|---|---|---|
| 1 | 28칸 도착 | 보드 28칸 전부 필러 룰렛 |
| 2 | 필러 룰렛 판정 | 1단계 대박 15% · 중박 50% · 운망 35%, 1단계 대박이면 5%로 2단계 단발(대박 50% · 중박 30% · 운망 20%) |
| 3 | 대사창 | 판정 **뒤에** 장면 대사가 하단 필러 칸에 한 줄씩 쌓임. 장면이 없으면 판정 리액션 한 줄 |
| 4 | 필러 칸 | **240px 고정 LogBox 피드**, 최근 24개 유지, 최신이 맨 아래 |
| 5 | 버튼 | 필러 칸 안에는 버튼 없음. 「넘기기」 · 「건너뛰기」 · 「굴리기」는 버튼 구역 |
| 6 | 위 3D 휠 | 띄우지 않음 |

| 장면 조건 | 쓰는 값 | 지금 상태 |
|---|---|---|
| 주차 | `week >= N` · `perweek` (시즌 63일 = 9주 × 7일) | 개발됨(11/13 14:05 게임 시뮬 63일) |
| 장소 | `filler_scene_place` 12개 → 우리 칸 | 개발됨, 아카데미 · 본가 · 팬 찬스 · 스케줄 찬스는 장면 없음 |
| 나이 | 손위 · 동갑 · 손아래(`older` · `same`) | 개발됨(인계 멤버 값) |
| 라포 · 긴장 | `rapport a b >= 단계` · `tension a b >= 단계` | 개발됨 |
| 서사 단계 | `story a >= N` | **현재 개발되지 않음, 진행 중** — 게임 상태에 멤버 서사 단계가 없음 |
| 케미 단계 | `chem a b = worst / turned` (이 문서 신규 조건) | **현재 개발되지 않음, 진행 중** |
