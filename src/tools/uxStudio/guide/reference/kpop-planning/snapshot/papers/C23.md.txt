## 검토한 지식

- D01 / ‘얼굴 클로즈’ 지시의 처리 순서: 마지막에 B 얼굴을 강조해야 함 → 마지막 컷은 B의 눈·턱을 기준으로 구도를 계산하고 가림 검사
- D02 / 컷 연결 검사 순서: 같은 위치에서 대화를 이어감 → A–B 대화 축을 유지하고 카메라 컷에서 배우 동작 시간을 유지
- D04 / 네 역할을 따로 적는다: B의 망설임을 말보다 먼저 보여줄 필요 → 화자 A의 대사 중에도 촬영 대상을 B로 분리
- D07 / 네 시간축을 분리한다: 무음 콘티이며 대답 전 침묵 필요 → 음성 효과를 완료로 표시하지 않고 자막과 카메라를 독립 배치
- D08 / 얼굴 가림과 초점: B 얼굴 마지막 구도의 눈 가림 위험 → 얼굴 여러 기준점과 최종 렌더를 검수 대상으로 남김
- D09 / 모션 세그먼트의 필수 기록: 원본 인사 모션은 시작이 웅크림인 기존 실패가 있음 → 미검수 모션 ID를 배치하지 않고 작은 인사 구간 검수를 미결로 남김
- D11 / 제작할 때 문서를 읽는 순서: 관련 이론을 거쳐 콘티를 작성해야 함 → 현재 문서 해시·절·적용 이유를 콘티에 기록
