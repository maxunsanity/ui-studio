# 087 · 컷씬 에디터 연구 — 2D / 3D

## 만들려는 것

**준비된 캐릭터·배경 리소스와 사용자의 콘티 지시로 실제 컷씬을 구성하는 연출 툴. 2D와 3D를 모두 지원한다.**

사용자가 단이에게 연출 의도를 전달하면, 단이는 이를 툴이 읽을 수 있는 연출 지시로 정리하고 툴이 리소스 배치·동작·카메라·시간 흐름을 구성한다. 콘티 작성 방식 자체도 계속 연구한다.

## 기존 프로젝트와 같은 점 / 다른 점

- 같은 점: 기존 기획서 툴의 데이터 기반 목차와 문서 열람 방식을 사용한다. 리소스를 재사용하고 연출 내용을 데이터로 관리한다.
- 다른 점: 이 챕터는 게임 규칙이 아니라 제작 도구 연구다. 특정 보드나 아이돌 콘텐츠로 사용 범위를 제한하지 않는다.
- 모노카피바라의 컷씬 도구 구현은 이번에 확인하지 않았다. 기능이 같거나 재사용 가능하다고 전제하지 않는다.

## 자료를 모으는 규칙

1. 연구 파일은 `docs/sources/research/`에 둔다. 확정 게임 기획과 구분한다.
2. `data/planning_doc_catalog.csv`에 고유 문서 번호와 경로를 등록하고 `content=cutscene`으로 묶는다. 검토 중인 문서는 `status=draft`로 둔다.
3. 이 문서의 목록에 링크와 한 줄 설명을 추가한다. 미결 질문은 `data/planning_open.csv`에도 `cutscene`으로 등록한다.
4. 사실·사용자 결정·단이의 제안·미검증 가정을 구분한다. 외부 자료에는 출처와 확인 날짜를 남긴다.
5. 실험 결과가 쌓이면 요약을 갱신한다. 실패한 방식도 이유를 남긴다.
