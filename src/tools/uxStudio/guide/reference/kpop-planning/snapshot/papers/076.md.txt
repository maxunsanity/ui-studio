# 076 · 착지 연출 — 칸에 도착하면 화면이 어떻게 되나

> **10/01 기준 · 수정 필요(이스터즈)** — 착지로 건물이 크지 않는다(B안, 9/30 17:17). 도착 수입에 주사위 배수가 붙는다(9/30 14:48). 투자에도 배수가 붙는지는 결정 대기. 아래 본문은 옛 기준이다. 원본: `_backup/2026-10-01_1031_책갈피정리_이스터즈/`. 기준: `삼중AI_공용_20260929/회의/20260930_1315_이스터즈_현중결정기록_도시숲메인연출_이동수단.md`

> 같다름 한 줄: 모노폴리 GO·모노카피바라는 착지하면 **등급 배너 → 결과**가 거의 전부다.
> 우리는 결과 다음에 **한 줄이 더** 붙는다 — 아이돌이 겪은 것과 내가 느낀 것. 시점이 둘이라서가 아니라 **대리 만족**이다 (D-046).
> 규칙 → [056](./056_보드_컨셉.md) · 판 바뀌는 연출 → [063](./063_보드성장_연출.md)

---

## 이게 뭐냐

**칸에 떨어졌을 때 화면이 어떻게 흘러가는지.** 칸 종류마다 다르다.

## 언제 나오냐

주사위 → 이동 → **착지.** 하루에 몇 번씩 나오는 화면이라 **짧아야 한다.**

---

## 한 줄

**결과를 보여주고, 반대편이 뭐라 하는지 한 줄 붙이고, 끝.**

---

## 공통 뼈대 — 네 박자

칸 종류가 달라도 순서는 같다. **길이만 다르다.**

```
① 착지        말이 그 칸에 선다 · 칸이 한 번 튄다
② 등급         대박 / 중박 / 운빨망빨 배너
③ 결과         그 칸이 주는 것
④ 반대 시선    엔터가 나왔으면 빠순이 한 줄, 창구면 엔터 한 줄
```

**④가 우리만 있는 박자다.** GO·모노는 ③에서 끝난다.

| 무게 | 칸 | 길이 |
|------|----|------|
| **가벼움** | 연습 · 자유시간 · 생활 · 코너 | 1~2초. 패널만 바뀜 |
| **보통** | 합숙 · 팬 일정 · 스케줄 변경 · 총공 · 회사 칸 | 2~3초. 카드 한 장 |
| **무거움** | **무대 칸 · 팬덤 게이트** | **전용 화면.** 판이 가려짐 |

---

## 칸 종류별

### ① 무대 칸 (노랑 3 · 초록 3) — 제일 큼

**이 판에서 제일 기다린 순간이다.** 크게 쓴다.

```
착지          칸이 튀고 조명이 한 번 지나간다
등급 배너      대박 / 중박 / 운빨망빨
   ↓ 전용 화면으로
무대 카드      그날 선 무대 이름이 크게
   대박 →  한 급 위 무대 이름 + "오늘만" 도장
   중박 →  같은 급 · 더 좋은 슬롯
   운망 →  한산한 자리 · 그래도 섰다
지역명         룰렛으로 붙는다 (마포·홍대 / 대학가 …)
코인           들어온다
빠순이 한 줄    "사녹이면 본방 사수지."
```

**「오늘만」 도장이 핵심이다.** 대박은 그날 한 번이고 급이 오르는 게 아니라는 걸 **연출이 말해줘야 한다**.
급이 진짜 오르는 건 덕질 10개일 때고, 그건 [063](./063_보드성장_연출.md)의 **이름 바뀌는 연출**이다. **그게 항상 더 커야 한다.**

### ② 결과 칸 — 연습 · 합숙 (기량 · 케미)

```
착지          칸이 튄다
등급 배너      짧게
준비도         올라가는 막대가 보인다   기량 ▲  (합숙이면 케미도)
코인           작게
빠순이 한 줄    "연습실 브이로그면 무한재생."
```

**막대가 오르는 걸 보여주는 게 전부다.** 숫자가 아니라 **차오르는 게** 보이면 된다.
운빨망빨이면 거의 안 오른다 — 그것도 보여준다.

### ③ 결과 칸 — 자유시간 · 생활 거점 (컨디션)

**유일하게 코인이 안 나오는 칸이다.** 그래서 연출이 조용해야 한다.

```
착지          칸이 천천히 밝아진다 (튀지 않음)
컨디션         차오른다
서사 조각       생활 거점이면 한 줄이 붙는다
빠순이 한 줄    "사생 금지. 마음만 쉬게 둔다."
```

> **쉬는 칸은 쉬는 것처럼 보여야 한다.** 여기서 요란하면 "손해 본 칸"이 된다.

### ④ 팬 일정 (팬미팅 · 개인방송)

```
착지          칸이 튄다
등급 배너
그날 결과       추첨 · 하이터치 · 팬콜 …
서사 조각       ★ 한 줄이 붙는다 (이 칸의 주된 산출)
빠순이 한 줄    "눈 마주친 것 같았는데."
```

**여기는 코인보다 조각이 주인공이다.** 조각이 붙는 걸 크게 보여준다.

### ⑤ 팬덤 게이트 — 전용 화면

**무대 칸과 함께 둘뿐인 「판이 가려지는」 칸이다.**

```
착지          게이트 문이 열리는 컷
① 등급 롤      대박 / 중박 / 운빨망빨
② 방식 롤      딱지  또는  어부지리
   ↓ 방식에 따라 갈림
```

| 딱지 | 어부지리 |
|------|----------|
| 남의 덕질이 뜬다 (밥차 6단) | 남의 덕질이 뜬다 |
| 현수막 이름이 **내 것으로 바뀐다** | **남의 코인이 나가고** 그 자리에 덕질이 들어간다 |
| 밥차는 그대로 | **밥차가 한 단 커진다** |
| — | 현수막 이름도 내 것 |

**둘 다 「부서지는」 연출을 쓰지 않는다.** 이름표가 바뀌고, 물건은 오히려 커진다.
GO는 건물이 닫히고 금고가 털리지만, 우리는 **아무것도 안 뺏는다** → [064](./064_팬덤게이트_딱지.md)

당한 쪽에는 알림이 간다 — *"누가 네 밥차에 이름 걸었어."*

### ⑥ 응원 (3 · 18 · 34)

> **이름 바뀜 (2026-09-18)** — 이 칸은 「총공」이 아니라 **응원**이다.
> 큰 협력(총공)은 **판 밖 입덕**으로 옮겼다 ([081](./081_입덕_전면기획.md)). 칸에 남은 건 작게 한 번씩 미는 쪽.

```
착지          주간 팀 상자가 뜬다
인증           내 몫이 한 번 더해진다
3단 채움        한 주치가 찬다 (매주 리셋)
빠순이 한 줄    "친구랑 조금씩. 밟을 때마다 한 번."
```

**혼자 뽑는 복권처럼 보이면 안 된다.** 팀이 같이 차는 게 보여야 한다.

### ⑦ 스케줄 변경 (8 · 23 · 38)

```
착지          스케줄표가 흔들린다
카드 한 장      끼움 / 비움 / 겹침 / 콜
결과           일정이 바뀐 스케줄표
빠순이 한 줄    "총공 일정 다시 짠다. 멘탈도."
```

> **복권 박스가 아니라 스케줄표가 흔들리는 톤.** ([033](/docs/planning/_이전기획_보관/20261016/033_스케줄변경_상태연동.md))

### ⑧ 회사 칸 (정산 · A&R · 매니지먼트 · 병가)

**팬이 못 들어가는 자리다. 화면이 닫혀 있어야 한다.**

```
착지          회사 문 / 계산기 컷 (짧게)
코인           나간다
빠순이 한 줄    옆에 작게 한 줄만     "밖에서 일정표만 새로고침."
```

| 칸 | 컷 |
|----|-----|
| 정산 · 대형 정산 | 계산기 · 코인이 빠짐 (대형이 더 큼) |
| A&R · 매니지먼트 | **문이 닫혀 있다** · 주사위 눈 × 배수 |
| 병가 | 강제 이동 · 며칠 멈춤 (GO 감옥 그대로) |

**빠순이 한 줄을 크게 쓰지 않는다.** 여기는 회사 일이라 옆에 한 줄만 — [048](./048_피치_두시선.md)의 「예외」 규칙.

### ⑨ 코너 — 스탠바이 · 온에어

```
착지          아무 일도 안 일어난다
빠순이 한 줄    "본방 10분 전, 채팅창만 뜨거움."
```

**평소엔 비어 있는 게 기획이다.** 시즌·특집 때만 여기에 이벤트가 켜진다.
그때 **불이 들어오는 연출**을 쓴다 — 평소가 조용해야 켜질 때 커 보인다.

### ⑩ 사옥 (1) — 한 바퀴

```
통과          하루가 넘어간다 (날짜가 한 칸)
코인           들어온다
빠순이 한 줄    "D-day 하루 줄었다."
```

**날짜가 도는 게 보여야 한다.** 그래야 시즌 3개월이 체감된다 → [065](./065_시즌구조.md)

---

## 덕질은 착지 연출이 아니다

**덕질은 상시 버튼이다.** 칸에 떨어져서 하는 게 아니다 ([059](./059_덕질_개요.md)).

| | 언제 | 연출 |
|--|------|------|
| **착지** | 주사위 굴려서 | 이 문서 |
| **덕질** | 아무 때나 | 색 칩 차기 · 응원봉 켜지기 · (10개면) 이름 바뀌기 |

둘을 같은 화면에 섞지 않는다.

---

## 연출 규칙 다섯

| | |
|--|--|
| 1 | **짧다.** 하루에 수십 번 보는 화면이다 |
| 2 | **반대 시선 한 줄이 항상 붙는다.** 이게 우리 얼굴이다 |
| 3 | **이름이 바뀌는 연출이 항상 제일 크다.** 대박보다 크게 |
| 4 | **쉬는 칸은 조용하게.** 요란하면 손해처럼 보인다 |
| 5 | **회사 칸은 닫혀 있게.** 빠순이 대사는 옆에 한 줄만 |

## 안 정한 것

- 실제 시간 (몇 초)
- 스킵 되나
- 소리
- 전용 화면 두 곳(무대·게이트)의 레이아웃

## 하지 않음

- 대박을 급 상승처럼 보이게 (그날 한 번이다)
- 게이트에서 부서지는 연출
- 쉬는 칸에 요란한 보상 연출
- 회사 칸에서 빠순이 대사를 크게
- 착지에 덕질을 섞기
