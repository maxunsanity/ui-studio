# 아이돌 제작 비용 — 캐스팅부터 성공까지 (자료 조사)

> 날짜: 2026-09-21 · **조사 시드 · SSoT 아님**
> 요청: 대표 — *"기획사의 아이돌 캐스팅부터 성공까지 비용의 종류 및 비율"* (D-049)
> 출처: 국내 언론 보도 (2013~2021). **회사 규모·연도에 따라 편차가 매우 크다.**

---

## 먼저 · 이 숫자를 어떻게 읽어야 하나

| 주의 | 내용 |
|------|------|
| **연도가 섞여 있다** | 2013년 기사와 2021년 기사가 같이 있다. 물가·제작 규모가 다르다 |
| **회사 규모 편차가 크다** | 같은 「데뷔 1팀」인데 **10억 ~ 40억**까지 보도된다 |
| **공개 회계가 아니다** | 대부분 *기획사 관계자* 증언이다. 감사받은 수치가 아니다 |
| **그래서** | 게임에 쓸 때는 **절대액보다 「항목과 비율」**을 가져오는 게 맞다 |

---

## 1. 한눈에 — 생애 주기 4단계

```
① 캐스팅        길거리 · 오디션 · 온라인
     ↓
② 연습생 육성    2년 기준 약 10억          ← 제일 길고 제일 많이 든다
     ↓
③ 데뷔 준비      앨범 1회 기준 약 3억
     ↓
④ 활동 유지      연 2회 활동 시 약 7억/년
```

**데뷔 전후 총합 — 보도 기준 15억 ~ 20억.** 한 중소 기획사는 데뷔 앨범 하나에만 **40억**을 썼다고 밝혔다.

| 보도 | 총액 |
|------|-----:|
| 최소선 | **10억** |
| 평균 | **20억** |
| 데뷔 전후 합 | **15억+** |
| 중소 기획사 실제 사례 | **40억** |

> **손익분기** — 중소 기획사는 대체로 **2년 안에 데뷔**시켜야 손익을 맞춘다.

---

## 2. ② 연습생 육성 — 제일 큰 덩어리

| 항목 | 금액 |
|------|------|
| 회사 전체 연습생 운영 | **월 3,000만원** 규모 (기획사 관계자) |
| 연습생 1인당 | 연 **수천만 ~ 1억** |
| 2년 누적 | 약 **10억** |

**들어가는 것** — 숙소 · 식비 · 보컬 레슨 · 댄스 레슨 · 외국어 레슨 · 연습실 임대 · 직원 임금

> 계약된 연습생의 교육비·숙식비는 **회사가 전액 선투자**한다. 데뷔 후 정산에서 회수한다.
> 데뷔해도 *"3년 동안 정산 20만원"* 같은 사례가 보도될 만큼 회수가 느리다.

**평균 데뷔까지** — 초등 6학년쯤 시작해 **약 6년**.

---

## 3. ③ 데뷔 준비 — 항목과 비율 ★

대표가 물은 **「비용의 종류 및 비율」**이 여기다. 앨범 1회 활동 기준.

| 항목 | 금액 | 비율 |
|------|-----:|-----:|
| **프로모션 · 바이럴** | 1억 ~ 2억 | **약 28%** |
| **뮤직비디오** | 6,000만 ~ 1억 | **약 22%** |
| **곡 · 녹음** | 6,000 ~ 8,000만 | **약 19%** |
| **의상** | 약 6,000만 | **약 17%** |
| **스타일링** (헤어·메이크업 2개월) | 약 3,200만 | **약 9%** |
| **안무** | A급 1,000만 | **약 3%** |
| **재킷 촬영** | 약 1,000만 | **약 3%** |
| | **합 약 3.6억** | 100% |

> 비율은 위 보도 금액의 중간값으로 **내가 계산한 것**이다. 회사가 공개한 비율표가 아니다.
> "평균 이상의 데뷔음반이면 **3억**은 든다"는 보도와 대체로 맞는다.

### 더 잘게

| | |
|--|--|
| 외부 작곡가 곡값 | 3곡에 약 **1,500만** |
| 녹음 | 약 **1,200만** |
| 스타일리스트 | 월 **1,000만** |
| 헤어숍 | 월 **600만** |
| MV 1편 (촬영+후반+사진+의상+미용+안무 합산) | **1억 5,000만 이상** 추산 사례 |
| 바이럴 마케팅 | 약 **1억 500만** |

> **MV 수치가 두 가지로 보도된다** — 촬영만 6,000만~1억 / 부대비용 다 합쳐 1.5억.
> 게임에 쓸 땐 **「촬영」과 「부대」를 나누는 게** 덜 헷갈린다.

---

## 3-B. 규모가 두 층으로 갈린다 ★ (2차 조사)

**같은 「아이돌 1팀」인데 중소와 대형이 30배 차이가 난다.** 이게 이번 조사에서 제일 큰 발견이다.

| | 연간 음악 제작비 (한국콘텐츠진흥원) |
|--|-----:|
| **대기업** | 평균 **431억 1,000만원** |
| **중소기업** | **14억 9,000만원** |
| 격차 | **약 30배** |

### 대형 기획사 기준 — 대표가 말한 150억이 맞다

| 항목 | 금액 |
|------|-----:|
| 신인 1팀 **시장 안착**까지 | **최소 100억 ~ 150억** |
| 신인 론칭 (아티스트 개발 + 사전 마케팅)만 | **100억 이상** |
| 뮤직비디오 1편 | **15억** |
| 앨범 마케팅 1회 | **20억 이상** |

> 앞의 §3(3.6억)은 **중소 기준**이고, 여기는 **대형 기준**이다. 같은 항목인데 자릿수가 다르다.
> 대표가 회의에서 말한 *"성공까지 약 150억"*은 **대형 기획사 기준으로 맞는 숫자**다.

> ⚠ **그리고 이 격차가 시장을 바꾸고 있다** — 신인 아티스트의 차트 진입이 전년 대비 **약 40% 급감**했다.
> *"중소돌의 기적이 사라진다"*는 게 지금 업계 화두다.

---

## 3-C. 버는 쪽 — 매출 구성 비율 (2차 조사)

대표는 비용만 물었지만, **버는 쪽을 모르면 게임 경제를 못 짠다.**

| 수익원 | JYP (2025) | SM |
|--------|-----:|-----:|
| **음반** | 25% | **43%** (음반+음원) |
| **음원** | 11% | ↑ |
| **MD (굿즈)** | **22%** | **25%** |
| **콘서트** | 17% | 18% |
| **광고** | 5.7% | — |

> **굿즈가 콘서트보다 크다.** 둘 다 20% 넘는다.
> 대표가 *"게임에 나오는 거 전부 다 구조로 팔 거예요"*라고 한 게 **업계 구조 그대로**다.

**4대 기획사 2024년 매출** — 하이브 2조 2,557억 · SM 9,897억 · JYP 6,018억 · YG 3,650억

### 정산 — 왜 데뷔해도 돈이 안 들어오나

```
모든 수입은 기획사가 먼저 받는다
   ↓ 유통 수수료 · 저작권료 · 실연료 공제
   ↓ 회사가 투자 원가를 먼저 회수
남은 것을 아티스트와 나눈다
```

- 처음엔 **1/N**으로 협의하고, 연차가 쌓이면 **슬라이딩 시스템**으로 바꾼다
- **"첫 정산을 받았다" = 회사가 투자금 회수를 끝냈다**는 뜻이다
- 그래서 *"데뷔 후 3년 동안 정산 20만원"* 같은 사례가 나온다

## 4. 공연장 규모 — 확인된 것만

대표가 같이 요청한 **"소극장부터 돔까지 볼륨과 관객수"**. **확인된 수치만** 적는다.

| 우리 급 | 공연장 | 수용 |
|---------|--------|-----:|
| 버스킹 | 거리 | — (지나가는 사람) |
| **클럽** | 홍대 라이브클럽 | **4~500명이면 꽉 참** |
| **소극장** | 일반 소극장 | 약 **200석** |
| **중극장·홀** | **예스24 라이브홀** | 스탠딩 포함 **2,037** · 좌석 **1,051** |
| — | 잠실올림픽보조경기장 | 좌석 **2,187** · 스탠딩 포함 **3만** |
| **아레나** | **고척 스카이돔** | 약 **18,000** |
| **아레나** | **서울아레나** (음악 특화) | **18,269** |
| 그 위 | **잠실올림픽주경기장** | **69,950석** · 최대 **10만** |

> 재미있는 역전 — **클럽(4~500)이 소극장(200)보다 많이 들어간다.** 스탠딩이라서.
> 우리 사다리 순서(클럽 → 소극장)는 **머릿수가 아니라 「급」** 기준이라는 걸 명시해 둬야 한다.
>
> ⚠ 아직 못 채운 칸 — 올림픽홀급 · KSPO DOME.

## 5. 게임에 어떻게 넣을까 (제안)

조사만 하면 숙제가 반만 끝난다. **어디에 붙일지**까지 적어 둔다.

| 조사 결과 | 우리 자리 |
|-----------|-----------|
| **연습생 2년 10억이 제일 큰 덩어리** | 연습 8칸이 판의 1/3인 게 **현실과 맞는다** ([066](../../planning/066_결과칸_16.md)). 근거로 쓸 수 있다 |
| **프로모션이 데뷔 비용 1위(28%)** | 덕질의 **붙이기(전광판·지하철)·찍어주기**가 제일 비싼 항목이어야 한다 ([061](../../planning/061_덕질_6단_물량.md)) |
| **의상·스타일링이 26%** | 지금 덕질 12항목에 **의상·스타일 계열이 없다.** 넣을지 검토 |
| **회사가 전액 선투자 → 느린 회수** | 정산(5)·대형 정산(40) 칸이 **왜 아픈지**의 근거 |
| **2년 안에 데뷔 못 하면 적자** | 시즌 3개월의 압박감 — 단 **"못 하면 죽는다"는 안 쓴다** ([083](../../planning/083_대표회의_시점확정.md)) |
| **공연장 수용 인원** | 급 사다리 5단에 실제 숫자를 붙이면 **성장이 체감**된다 |

> **개발 동료의 이견도 같이 둔다** — *"그건 엔터사 입장의 디테일이고 빠순이는 비용 구조에 관심이 없다."*
> 그래서 **숫자를 화면에 다 보여주는 게 아니라, 판의 비율과 칸 배치의 근거로 쓰는 쪽**을 제안한다.

---

## 안 정한 것

- 게임 화폐(코인)와 현실 원화의 **환산 기준**을 둘 것인가
- 연습생 육성 2년을 **시즌 3개월 안에** 어떻게 압축하나
- 공연장 가운데 세 급(클럽·소극장·중극장) **수치 채우기**
- 덕질 12항목에 **의상·스타일 계열**을 넣을지
