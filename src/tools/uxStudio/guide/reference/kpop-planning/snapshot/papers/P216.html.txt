</section><section class="part" id="part-3"><h2>3. 구동 방법·시뮬레이션</h2>

<p>화면 흐름: 친구 탭 → 친구 맺기 · 소식 → 파트너 이벤트 · 스샷 미완 · 이식 비교 해당 없음</p>

<ul>
<li>실행: 하단 friend.mjs는 메모리·DOM에서 움직이는 독립 시안입니다. 실제 파트너 기여·보상·선물 API·저장은 이 시안에 연결되지 않습니다.</li>
<li>이 문서 하단 <b>파트너 이벤트 시뮬레이터</b>는 한 번 굴리면 표시된 인원 모두에게 임시 난수를 더해 목표 막대를 채웁니다. 숫자는 모두 임시 시안이며 실제 각자의 기여 수신을 검수한 결과가 아닙니다.</li>
</ul>
