# 023 · 칸 역할 ↔ 덕질 매칭 (세밀)

**이 문서는** 초기(9월 말) 기획 때 쓴 **옛 컨셉 기록**이에요. 요약: 40칸 권고. 대지=응원노동, 영지=관계성장. [보드](삼중AI_공용_20260929/산출/개발진행기획_v01/콘텐츠별_v03/P74_설명.html) 클리어 vs 키우기. 지금 게임의 [미션](삼중AI_공용_20260929/산출/시스템기획/S11_미션.md)은 [S11 미션](삼중AI_공용_20260929/산출/시스템기획/S11_미션.md)과 미션 표를 따르고, 이 문서는 아이디어 재료로만 남겨 둬요.

**보는 법** 처음부터 순서대로 읽어요. 지금 규칙과 다른 부분이 있으니 숫자·규칙은 책갈피의 대표 기획서로 확인하세요. 시뮬레이터 없음.

**지금 상태** 이 문서 내용은 게임에 그대로 들어가지 않았어요. 여기 적힌 내용을 게임에 쓰는 것은 현재 개발되지 않음, 진행 중이에요.

## 0. 먼저 답 — 보드 획득이 1차 목적인가?

**반만 맞다.**

| 층 | 목적 | 플레이어 감각 |
|----|------|----------------|
| **엔진(필수)** | 이 보드를 깨고 **다음 보드**를 연다 | GO/모노카피랑 같은 “판 깨기” |
| **판타지(본체)** | 신인을 **키웠다** + 내가 **한 단계 커졌다** | 키우기·사다리(017×020) |

보드만 모으는 게임이 되면 모노폴리 GO 카피가 된다.  
키우기만 보면 보드가 장식이 된다.  
→ **보드 클리어 = 엔진**, **키우기/직함 = 왜 깨는지**.

### 늘리는 것 / 맞서는 것 (대치)

| 늘리면 기분 좋은 것 | 그걸 막는·맞서는 것 |
|---------------------|---------------------|
| 보드 완공 · 다음 판 | **주사위/행동력** 고갈 (굴릴수록 바닥) |
| 덕질 재화(응원포인트) | **지갑·알바 시간** (TAX·큰 지출 칸) |
| 아이돌 노출·차트 | **경쟁·운** (STATION·CHANCE) |
| 직함 스탬프 | **잘못된 낙점·번아웃** (JAIL·휴덕) |
| 관계(덕메·총대 신뢰) | **팬싸움·정산 실패** (위험 선택) |

설계 키: 보드를 빨리 깨고 싶으면 주사위/돈을 태워야 하고,  
아끼면 아이 성장이 늦어진다. **속도와 애정 사이 줄타기.**

## 1. 칸 수 — 40 추천(1차)

모노카피 스스로: **Mono 뼈대 40 + Cap 전용 24 = 64**.

| 안 | 내용 | 득 | 실 |
|----|------|----|----|
| **A. 40칸** | GO 뼈대만. Cap 전투판타지 칸은 보드 밖으로 | 역할 읽기 쉬움 · 덕질 매칭 선명 | 모노카피 1:1 이식 아님 |
| B. 64칸 | Cap 특수까지 다 매핑 | 익숙한 밀도 | 시안이 다시 복잡해짐 · 정체성 흐림 |

**권고 A.** 보내기·콘서트 한판·생카 총대는 보드 **옆/위 이벤트**(모노카피 [여정](삼중AI_공용_20260929/산출/개발진행기획_v01/콘텐츠별_v03/라포AI탐험_기획서.html)처럼 얇게).

## 3. 대지 vs 영지 — 가장 중요한 구분

| | **대지 LAND** | **영지 TERRITORY** |
|---|---------------|-------------------|
| 모노카피 감각 | 싸워서 **돈** | 도착해서 **성장 선택** |
| 덕질 감각 | “오늘도 **일**했다” (스밍·투표·차트) | “사람을 **만났다/골랐다**” (관계·계정·휴식) |
| 감정 | 노동·성취·지침 | 따뜻함·선택·가끔 위험(해적≈악플/사기 주의) |
| 보드에서 비중 | 주수입 → **많아야** 함 (GO처럼) | 숨구멍 → LAND보다 적게 |
| 사다리 연결 | 재화→TAX·서포트 가능 | 직함 3·4·5의 관계/총대 씨앗 |

잘못하면: 모든 칸이 “미션 이름”만 되어 LAND/영지 차이가 안 난다.  
**칸 위 설명에 역할 단어를 박아야 한다.** (예: `[노동]` `[관계]` `[운]` `[지출]`)

## 4. 보드 클리어 ↔ 키우기·사다리

한 보드 안에서:
1. 주사위로 LAND 등 돌며 **재화·스킬·관계** 축적  
2. 옆 슬롯(랜드마크 자리) = **이 시절 덕질 목표** 예: 첫 음방 사수, 생카 열기, 팬매 입문… (짓기)  
3. 슬롯 다 채우면 → 「다음 보드 생성」+ 아이돌 호흡 한 칸↑ 가능 + 직함 스탬프 기회  

020 사다리는 **보드 번호와 1:1이 아님.**  
보드 10장을 깨도 총대를 안 하면 직함 4가 안 열릴 수 있음 (스탬프·분기).
