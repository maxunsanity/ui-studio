| **① 상단 디오라마** | 장소·도시 실루엣·밴/군집·구역색/POI 하이라이트 | 판정 배너·대사 본문·자원 수치 | HUD ① · 착지브리지 |

## D. 착지 시퀀스 (가안·미잠금)

```
주사위 → 칸확정 → 상단 하이라이트(브리지) → 디오라마 동작(유형) → 필러 알림/대사 → (선택) 대중운 레이어
```

1. 주사위 → 칸확정 — Board40 칸 ID
2. 상단 하이라이트 — 착지브리지 파이프 · 옵션 단서 착지시안
3. 디오라마 동작 — C 유형
4. 필러 알림/대사 — 필러대사 링크 · 본문 미재작성
5. (선택) 대중운 레이어 — 필러도착 ② 링크만

**초·프레임·타이밍 숫자 = 전부 금지(미잠금).**
