## B. 정령 탐험 (시즌)

### B.1 한바퀴 흐름

```
도감(악마/도깨비) → 던전 파견 → 공연 공명 게이지 → 수호 전환 → 멤버 1:1 연결
```

| 단계 | 플레이어가 느끼는 것 | 잠금 |
|---|---|---|
| 도감 등록 | 「악마/도깨비가 도감에 들어왔다」 | 드롭 경로(봉합전·보드 등) = 인접 · G6은 서랍 |
| 던전 파견 | 슬롯에 아이돌 무대를 세우고 도깨비 파견 | 슬롯 수 = **원안참고·미잠금** |
| 공명 | 공연을 들으며 게이지가 찬다(안A) 또는 전투로 정화(안B) | %·시간·배율 = **원안참고·미잠금** |
| 수호 전환 | 같은 개체가 아묾 · 새 카드가 아님(원안 감각) | 연출 유형만 |
| 멤버 연결 | 1:1 연결 → 덱14 드롭 조건 후보 | 배율·쿨 = **원안참고·미잠금** |

### B.2 복수안 미잠금 (탐험 본체)

승자를 고르지 않는다. 검수·조율 재료.

| 안 | 이름 | 요지 | 근거 | 잠금 |
|---|---|---|---|---|
| **안A** | 공연 공명형 | 던전=전투가 아니라 **공연/공명**. 객석 도깨비↔아이돌 무대 | GDD §14 원안 | **미잠금** |
| **안B** | 전투형 정화 | 탐험에서 **전투**로 정화. 푸더덕 보드전투와 **≠**(시즌 탐험 레이어) | Meeting 260928 대체 | **미잠금** |
| **안C** | WF 사건층만 | 시즌 전용 탐험 없음. 탐험·빙의·정화=WF 공연 **안** 사건층(WF-4)만 | WF v0.1 축소 | **미잠금** |

### B.3 레이어 분리

| 레이어 | 역할 | 관계 |
|---|---|---|
| **시즌 정령 탐험** | 도깨비→수호 시즌 루프 | **본팩 중심** |
| **WF 공연 안 사건층** | 탐험·빙의·정화 (WF-4) | ≠ 시즌 탐험 · 링크만 · 세부 미작성(WF) |
| **푸더덕 보드전투** | 배치→진행→클리어 감 | ≠ 정령탐험 · ≠ WF |

### B.4 슬롯·운영 유형만

| 유형 | 감각 | GDD 원안참고(미잠금) |
|---|---|---|
| 던전 무대 슬롯 | 아이돌 지정 · 같은 아이돌 중복 불가 유형 | 기본1 · 콘서트홀 레벨=슬롯 · 덱14 완성+1 — **수치 미잠금** |
| 공명 게이지 단계 | 0→34→67→100% 연출 유형(끊김·바늘땀·봉합·수호) | % 구간 = **원안참고만** |
| 공명 속도 | ★·친화·완성체·스태프 버프 유형 | 시간표·배율 = **원안참고·미잠금** |
| 파견 중 잠김 | 파견 중 도깨비는 다른 용도 잠김 · 취소 시 게이지 유지(패널티 없음 유형) | 유형만 |
| 멤버 1:1 연결 | 아이돌1:정령1 · 연결 변경 자유 후보 | 공명/봉합전 배율 = **원안참고·미잠금** |

BG/보드 가벼운 연결: 콘서트홀·무대 칸이 「파견 무대」 감각 — [#BG](./산출_기획서_건물성장_간략_v0_클로드.html) 링크만.

G6(명성·그림자·봉합전): [미사용정리](./산출_기획서_미사용콘텐츠정리_v1_클로드.html) 서랍. 도깨비 드롭 상류가 봉합전과 겹칠 때만 링크 · **본편 필수 아님**.

## C. 앨범 제작

### C.1 위치

**#MS 판매의 상류** — 「무엇을 만드나」. 제작 완료 → 발매 이벤트 → #MS T3(판매 개시). **#MS 본문 재작성 금지.**

### C.2 레시피 골격 (§16.2 · 원안참고)

| 골격 | 유형 | 잠금 |
|---|---|---|
| 곡 1 레시피 | 멤버1(보컬·곡 속성) + 작곡1 + 작사1 + PD1 + 세션1 + 비주얼0~1(MV 선택) | 조합 유형만 |
| 곡 ★ | 투입 카드 ★ 평균(반올림) 후보 | **원안참고·미잠금** |
| 제작 시간 | ★1 6h / ★2 12h / ★3 24h / ★4 36h / ★5 48h | **원안참고·미잠금** · 잠금 금지 |
| 제작 중 잠김 | 투입 카드는 편성·대결·파견에서 빠짐(한곳 원칙) | 유형 · **원안참고** |
| 곡 효과 유형 | ①던전 세트리스트 동속성 공명 가산 후보 ②타이틀곡 시너지 후보 ③무대칸 명성 가산 후보 | 수치 open |
| 앨범 발매 | 곡 복수(원안 4+) + 비주얼1 → 발매 이벤트 | 장수·보상(명성+30·현금大·콘서트팩×3) = **원안참고·미잠금** |
| 시즌 상한·목표 | 시즌 최대 앨범 수 · 앨범1=데뷔 최소조건 후보 | **채택 open** |

### C.3 실유통 · MV · 채택 open

Meeting 「음방1위·앨범(실제 유통 가능)·MV는 과함」:
- **실유통 깊이** = 채택 open (안A 가상만 / 안B 연출만 / 안C 하이브리드는 #MS 복수안과 조율)
- **MV 제작 깊이** = 채택 open (비주얼 카드 1장 수준 vs 별도 MV 미니게임)
- 본팩은 레시피·발매 **골격**만 · 깊이 승자 판결 없음

## D. 음방 1위

### D.1 위치

판매/차트 **인접** 비동기 대결. #MS의 「음방 연동 티커」와 구분 — 본팩은 **대결 골격**, #MS는 판매 창구만.

### D.2 골격 유형 (§16.3 · 원안참고·미잠금)

| 유형 | 감각 | GDD 원안참고(미잠금) |
|---|---|---|
| 리그 분리 | 시즌 진행도별(초반/중반/후반) · 과금·헤비와 초반 분리 감각 | 1–20 / 21–45 / 46–60일 — **일수 미잠금** |
| 매치 | 하루 비동기 + 친구 지명전 유형 | 하루 5회 등 — **횟수 미잠금** |
| 판정 | 무대력 + 팬응원 유형 | 70%+30% — **% 미잠금** |
| 연출 | 짧은 대결 컷 · 좌우 무대 · 응원 게이지 | 15초 — **원안참고·미잠금** |
| 결산 | 주1회 · 트로피/상위선택권/참가보상 유형 | 보상 수치 open |
| **패배 손실 없음** | 가산형 대결 · 손실형 소셜(역공명)과 분리 | **유형** 채택 후보 (숫자 없음) |
| 편성 잠금 | 결산 직전 편성 잠금 유형 | 6h — **원안참고·미잠금** |

### D.3 채택 open

- 음방1위 **본규칙**을 시즌1에 넣을지
- 깊이: 풀 비동기 PvP vs 무대 칸 티커/배너만(#MS 인접)
- 회의 「과함」메모 유지 · 승자 판결 없음 · 풀 PvP 밸런스 시트 **작성 안 함**

## E. 관계도 (세부)

```
카드북/도감 ──┬──► 시즌 정령 탐험 ──► 멤버 연결
              ├──► 앨범 제작 ────────► 발매 ──► #MS 판매
              └──► 음방 1위(채택 open) ──► 차트 감각(#MS 티커와 인접)
                    ↕
              WF 공연/사건층 (≠ 시즌 탐험)
                    ↕
              푸더덕 보드전투 (≠ 정령탐험)
```

| 노드 | 관계 | 문서 |
|---|---|---|
| 카드북/도감 | 도깨비·멤버·스태프 공급 | 카드획득 · §13–14 |
| 시즌 정령 탐험 | 본팩 B | 본 문서 |
| 앨범 제작 | 본팩 C · #MS 상류 | 본 문서 |
| 음방 1위 | 본팩 D · 채택 open | 본 문서 |
| #MS 판매 | 발매 후 「어떻게 팔리나」 | [음원판매](./산출_기획서_음원판매_경로_간략_v0_클로드.html) |
| WF 사건/공연 | 공연 안 사건층 ≠ 시즌 탐험 | [WF v0.1](./산출_기획서_월드페스티벌_공연중심_v0.1_클로드.html) |
| 푸더덕 | 보드전투 ≠ 정령탐험 | [푸더덕](./산출_기획서_전투_푸더덕형_컨셉스케치_v0_클로드.html) |

**카드 한곳 원칙**(GDD §16 전제 · **원안참고·미잠금**): 한 카드는 한 곳에만. 무대 편성(16.1)에 넣은 카드는 앨범 제작(16.2)에 못 넣고, 제작 중 카드는 편성·대결·파견에서 빠짐. 본팩에서 배분 수치·쿨다운 **잠금 안 함**.
