<p><b>이 문서는</b> P195의 G1~G9를 제안(검수 대기)으로 요약하고, 게릴라 공연의 관객석·팬·돈 흐름을 설명하는 대표 개발 기획서입니다. 기존 상세 기획 P102와 현재 출연권 대전의 코드·실행 범위는 구분합니다.</p>

<p><b>보는 법</b> 1장 그림 → 4장 「한 판 순서」 → 하단 「관객석 시뮬레이터」 순서로 읽습니다. 세부 결정과 근거는 책갈피 <a href="/docs/planning/%EC%82%BC%EC%A4%91AI_%EA%B3%B5%EC%9A%A9_20260929/%EC%82%B0%EC%B6%9C/%EA%B8%B0%ED%9A%8D%EC%84%9C/%EC%82%B0%EC%B6%9C_%EA%B8%B0%ED%9A%8D%EC%84%9C_%EA%B2%8C%EB%A6%B4%EB%9D%BC%EA%B3%B5%EC%97%B0_%EB%B3%B4%EC%99%84%ED%8C%90_v1_%ED%81%B4%EB%A1%9C%EB%93%9C.html" data-paper-path="docs/planning/%EC%82%BC%EC%A4%91AI_%EA%B3%B5%EC%9A%A9_20260929/%EC%82%B0%EC%B6%9C/%EA%B8%B0%ED%9A%8D%EC%84%9C/%EC%82%B0%EC%B6%9C_%EA%B8%B0%ED%9A%8D%EC%84%9C_%EA%B2%8C%EB%A6%B4%EB%9D%BC%EA%B3%B5%EC%97%B0_%EB%B3%B4%EC%99%84%ED%8C%90_v1_%ED%81%B4%EB%A1%9C%EB%93%9C.html">P195 게릴라 공연 보완판</a>에 있습니다. 1·4장의 진행·보상안은 P195 제안이며, 6·7장은 원표·코드 확인 범위와 대기를 함께 봅니다.</p>

<h3 id="현재-기준과-목표">현재 기준과 목표</h3>

<p>이 절은 P195 G1~G9 결정안의 목표를 요약합니다. 현재 쟁탈 도착의 출연권 대전 실행과 같은 기능으로 읽지 않습니다.</p>

<div class="table-scroll"><table><thead><tr><th>모은 셋</th><th>결과</th><th>팬 이동</th></tr></thead><tbody><tr><td>라이트팬 셋</td><td>소</td><td>상대 라이트팬 일부</td></tr><tr><td>코어 셋</td><td>대</td><td>라이트팬 · 코어 일부</td></tr><tr><td>콘크리트 셋</td><td>대박</td><td>라이트팬 · 코어 일부 · 콘크리트 이동 없음</td></tr></tbody></table></div>

<p>위 팬 이동은 P195 2장의 제안 요약입니다. 현재 팬 원표와 공개 이동 함수는 라이트팬만 옮기므로 코어 이동과의 정합은 결정 대기입니다. 콘크리트 팬 자체를 옮기지 않는다는 제안과, 대박 때 라이트팬·코어 일부를 옮긴다는 제안을 구분합니다.</p>

<ul>
<li>결정안은 같은 부문 안 무작위 상대 · 최근에 당한 유저 잠시 제외 · 봇 상대 허용을 제안합니다. 현재 매칭 연결을 확인한 규칙은 아닙니다.</li>
<li>서버 선결정은 기획입니다. 현재 관객석 표시 시안은 메모리에서 좌석을 섞고 공개 결과를 계산하며 서버 결과를 받지 않습니다.</li>
<li>결정안은 데뷔 이후 게릴라 직캠 피드와 페스티벌 점수 직접 제외를 제안합니다. 이 표시 시안에서 해당 운영 연결을 확인한 것은 아닙니다.</li>
</ul>

</section><section class="part" id="part-3"><h2>3. 구동 방법·시뮬레이션</h2>

<p>기획 흐름: 보드 쟁탈전 칸 → 무작위 → 관객석 → 결과 → 다음 접속 상대 알림 · 스샷 미완 · 이식 비교 해당 없음</p>

<ul>
<li>실행 등록: <code>data/simulator/catalog.csv</code>의 게릴라는 문서로 등록되어 전용 게임 실행 모듈 연결 대기입니다. 현재 출연권 대전의 실행과 구분합니다.</li>
<li>이 문서 하단 <b>관객석 시뮬레이터</b>는 메모리에서 좌석을 무작위로 섞고 같은 팬 셋의 등급 문구를 표시합니다. 좌석 수·배치는 임시 시안이며 서버 선결정이나 운영 분포를 재현하지 않습니다.</li>
<li>이 시안 파일에는 CSV/API 호출과 돈·팬 writer·알림·저장 처리가 없습니다. 결과의 돈·팬·맞불·피드 문구를 실제 지급·저장 완료로 읽지 않습니다.</li>
</ul>
