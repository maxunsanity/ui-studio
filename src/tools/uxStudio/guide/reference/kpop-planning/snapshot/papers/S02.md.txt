# S02 · 발란스 툴 — 시즌 경제가 표와 맞나 (이식)

**이 문서는** 시즌 경제·성장 기획의 원표와 시험 입력을 대조하는 발란스 툴의 역할·입력·저장 경계를 설명합니다. 기존 이식 방향과 작성 시점 자료를 함께 보존합니다.

**보는 법** 목차 → 현재 도구 → 기획 방향 → 확인 항목 순서로 읽습니다. [발란스 툴](/docs/planning/balance-tool.html)과 [발란스 시뮬레이터](/docs/planning/idle-sim.html)는 다른 입구입니다.

**지금 상태** 개발됨(주제 목록·표 조회·기존 시즌 계산·시험 입력의 코드 경로 기준). 안내 틀·부분 구현·실제 사용·화면 연결·미검수 범위와 표별 공급 상태를 구분합니다. 실제 실행·저장·플레이와 최신 다른 담당 기능은 이번 문서 대조로 검수 완료 처리하지 않습니다.

## 현재 도구

발란스 툴은 왼쪽 주제 목록에서 질문·관련 문서·표 키를 보고 연결된 계산 화면이나 별도 도구를 엽니다. 자료 안내만 있는 주제와 계산 경로가 있는 주제를 구분합니다.

| 구분 | 현재 코드에서 확인한 범위 |
|---|---|
| 입력 | 시즌 화면은 배수·건설비 배율·반복수를 바꿔 봅니다. 주사위 화면의 소비·배수·팬 입력과 6각형의 시험 모양 입력은 각각 따로입니다. 비교 손잡이는 원표를 바꾸지 않습니다. |
| 기존 시즌 계산 | 현재 시즌 설정의 일수로 건설률을 점검하고 별도 한도까지 완공일을 찾습니다. 충전분을 받아 굴리고 증설하는 계산 가정이며 무료·평균·헤비 자동 성장 관측과 같은 입력이라고 묶지 않습니다. |
| 원표 | `tool_balance_source.csv` 등록 목록과 `data.ts`의 명시 참조를 함께 확인합니다. 시설 성장 단계와 팬·보드 보상·건물·성장 단계/계수 등의 직접 CSV 읽기도 있습니다. 등록 개수만으로 실제 읽기 범위를 대신하지 않습니다. |
| 상태 | 비용 묶음 연결 여부, 실제 값·단위·미공급·표별 임시/검수 상태를 나누어 확인합니다. 원표나 계산의 존재를 정책·사용자 승인으로 바꾸지 않습니다. |
| 저장 | 주제 선택은 표시 설정으로 저장합니다. 기존 시즌 계산은 공용 경제 함수의 팬 기록 writer에 도달할 수 있어 실행 주소의 `testPage`/기본 저장 범위와 실제 저장 결과는 별도로 확인합니다. 실제 저장은 이번 문서 대조에서 미검수입니다. |

카드·이벤트의 표시/계산 경로와 모험의 연결 경로가 있고, 스킬 공급에는 안내 틀이 남아 있습니다. 코드 경로와 실제 사용·화면 연결·검수 완료는 구분합니다. 최신 음악·달력·현황판 작업의 완료는 이 설명으로 대신하지 않습니다.

굴림 배수·능력 점수 표시 배율·성장량 효과는 다른 입력입니다. 6각형의 시험 모양을 실제 성장량·팬 효과로 취급하지 않고, 해당 성장 기획과 실제 로더·쓰기 주체를 대조합니다.

<a id="planning-direction"></a>

## 기획 방향

시즌 경제가 기획 목적과 원표의 값·흐름에 맞는지 비교하고, 어긋난 표와 줄 열쇠를 찾는 개발용 도구입니다. 게임 수치나 운영 정책을 이 문서에서 새로 정하지 않습니다. 전투 발란스나 게임 플레이 화면을 대신하지 않습니다.

```mermaid
flowchart LR
  T[원표 등록 목록 · 명시 참조] --> V[주제별 표 · 계산 · 시험 입력]
  P[시즌 경제 기획 목적 · 원결정] --> V
  V --> D[차이와 확인 범위 기록]
```

현재 코드와 기획이 다르면 입력·모드·계산·실제 사용을 나누어 기록합니다. 기획 목적·원결정과 표시 시안·운영을 구분하고 불명확한 수치·의도를 억지로 맞추지 않습니다.

시즌 경제 기획은 [P110](../개발진행기획_v01/발란스/핵심제안_발란스구조_기획서.md), 도구별 역할·저장 경계는 [S17](S17_기획서툴_제작기본양식_v02.md#current-tool-boundaries)에서 함께 봅니다. 원래 R-S02/V-S02 식별자와 세부 기획 방향은 아래 이전 자료와 짝 로그에 보존합니다.

## 확인 항목

- 이 페이지의 기존 시즌 입력과 연결된 자동 성장 관측의 입력·실행 입구를 구분합니다. 현재 보이는 ‘준비중’이나 안내 틀도 실제 사용과 따로 확인합니다.

- 엔터파워/보유 주사위 문턱 판정과 기존 시즌 화면의 팬 기준 열린 날 기록, 일차 상한 적용 범위를 따로 대조합니다.

- 기존 시즌 계산의 공용 팬 writer 도달 조건과 `testPage`/기본 저장 범위를 확인해야 합니다. 실제 저장 성공·키 변화·영향은 미검수입니다.

- 기획·원표·계산 구현·실제 사용·화면 연결을 나누어 보고, 미공급·발란스 대기·후보·제작전·미검수 범위를 근거와 함께 설명합니다. 새 상태 코드나 값은 추가하지 않습니다.

- 날짜별 후보·측정·보류는 당시 기록입니다. 최신 음악·달력·현황판 및 공용 수치의 동기화는 담당 결과와 연결하며 아래 옛 목록을 현재 결론으로 대신하지 않습니다.

하루 무료 주사위 검사(`audit-game-economy.mjs` 2-5 · 툴 하단 30칸): 하루 무료 주사위 = 모든 무료 일일 보상 합 = 자동 충전 + 일일·주간 미션 + 「미개발 이벤트 보상」 칸(출석 · 8시간 선물 · 준비중 몫) + 보드·잭팟·미니게임·원정. 통째 지급은 없다. 기준 범위 800~900: 800보다 적거나 900보다 많으면 WARN · 목표가 비면 NOTE. 60일(시드 20261029 · 무료) 평균: 자동 충전 113.5 · 이벤트 칸 493.25 · 미션 142.4 · 보드 등 86.4 · 합 835.6(하루 533~1900). 모자란 몫은 상점 유료. 팬 마일스톤 · 완공 덤은 게임에선 「수령」 버튼이지만 시뮬레이션은 바로 받음으로 센다. 검사기 결과에 배수마다 열린 날(`fanUnlockDay`) · 무료 주사위 차이(`freeDiceGap`)를 남긴다.
