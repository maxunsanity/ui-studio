<p><strong>이 문서는</strong> 왼쪽 모바일 화면과 오른쪽 시험 입력으로 인기 기여·곡 등급·월드 순위를 비교하고, 단독 예시와 현재 연결 데이터를 구분하는 기획서입니다.</p>
<p><strong>보는 법</strong> 1장 흐름 → 3장 <a href="/docs/planning/game-simulator.html?module=simulator_module_world_popularity_trial">시뮬레이터 실행</a> → 4장 계산 → 7장 검증 순서입니다. 기존 <a href="%EC%9B%94%EB%93%9C%ED%8E%98%EC%8A%A4%ED%8B%B0%EB%B2%8C_%ED%95%B5%EC%8B%AC%EC%A0%9C%EC%95%88%EC%84%9C.html#world-popularity-first">월드 기획 P207</a>과 <a href="../../%EA%B8%B0%ED%9A%8D%EC%84%9C/%EC%82%B0%EC%B6%9C_%EA%B8%B0%ED%9A%8D%EC%84%9C_%EC%9D%8C%EC%9B%90%C3%97%ED%8E%98%EC%8A%A4%ED%8B%B0%EB%B2%8C_v1_%ED%81%B4%EB%A1%9C%EB%93%9C.html#festival-popularity-first">상세 P191</a>을 함께 봅니다.</p>
<p><strong>지금 상태</strong> 개발됨(공용 모바일 미리보기·오른쪽 입력·단독 시험·현재 세션의 팀/발매곡 읽기). 발란스 전송은 기존 전용 세션을 읽으며, 원본에 없는 인기·추천·찜 집계는 입력 대기입니다. 실제 인기 원장·회원 집계·최종 정책·게임 저장 연결은 현재 개발되지 않음, 진행 중입니다.</p>

<h3>단독 테스트</h3>
<ol>
<li>오른쪽 「단독 테스트 · CSV 예시」를 선택합니다. 예시 개인·크루·곡·시작값으로 바로 비교합니다.</li>
<li>오른쪽 시험 활동으로 인기를 모으고, 왼쪽에서 곡에 기여합니다. 보유량·등급·점수가 즉시 바뀝니다.</li>
<li>왼쪽 하단 「월드 순위」로 순위를 확인하고 곡을 눌러 돌아옵니다.</li>
<li>출전곡과 시작값·규칙을 바꿔 비교하고, 오른쪽에서 마감 결과를 고정합니다.</li>
</ol>
