## 0. 한 줄 · 이게 아닌 것

**1~8주는 비슷한 100명과 매주 겨루고, 9주차에는 그 성적대로 리그를 나눠 모두가 동시에 차트에 오르며 파이널 1,000으로 간다.**

- 이게 아닌 것: 100명 중 1등만 올라가는 토너먼트, 오리지널 16 입구 · 공연형 대결 3종 · 던전 정화, 시즌 끝 공동 축제 한 번, 상위자 전용 입장.

## 3. 시스템 규칙 R-08

### 3-1. 주간 페스티벌 (1~8주)

| 규칙 | 내용 (현재 세팅값) |
|---|---|
| R-08-1 100명 구역 | 친구 먼저 → 빈자리는 비슷한 엔터파워 등급으로 100명 |
| R-08-2 영상 필수 | 음원 단독 출품 불가. 영상이 없으면 아이돌 이미지 연속 **자동 컷씬**, 직접 편집(음악 박자 맞춤) · 모션샷 가능 |
| R-08-3 창작곡 | 출전 허용, 내부곡과 **같은 순위표**(전용 탭 · 큰 가산점 · 외부 영상 업로드 없음) |
| R-08-4 출전 단위 | 팀 칸 멤버 전원(정규 앨범 팀 고정 #35). 솔로 · 유닛은 뮤비 제작 때만 고르고 뮤비 크레딧에 표시 |
| R-08-5 미니게임 | 개인전 · 크루전 미니게임, 보상 수치는 비어 있음(0으로 동작) |
| R-08-6 바퀴 보상 | 매주 7일째 START 통과 때 5명 무리 순위대로 돈 500~100 · 팬 20~4 · 능력 0.25~0.05 |
| R-08-7 연료 레이스 | 7일째 연료 드랍(주 끝 소멸) → 5인 매칭 레이스, 순위 없음 |
| R-08-8 월드 가산점 | 100명 구역 등수 기준, 1~8주 합으로 월드 순번. 등수별 가산점은 비어 있음(0으로 동작) |

### 3-2. 크루 협업 (주간 · 월드 공통)

| 규칙 | 내용 |
|---|---|
| R-08-9 음악 공유 | 창작 음원을 크루에 「음악만」 공유(원소유자 동의) |
| R-08-10 각자 뮤비 | 크루원 각자(원작자 포함)가 **자기 캐릭터로** 뮤비 제작 |
| R-08-11 투표 · 확정 | 크루 내 투표 → 크루장이 회차당 **대표작 1편** 확정(1편은 설정값으로 분리) |
| R-08-12 개인 출품과 별개 | 크루 출품과 개인 출품은 서로 잠그지 않음 |
| R-08-13 공유 철회 | 철회 즉시 새 뮤비 · 새 출품은 막고, 이미 낸 출품본은 그 회차 끝까지 유지한 뒤 비공개. 확정된 순위 · 보상 기록은 남김 |

### 3-3. 9주차 월드 페스티벌

| 규칙 | 내용 (현재 세팅값) |
|---|---|
| R-08-14 전원 참가 | 9주차 전원 참가. 기준 점수 이하는 참여해도 등수 없음 |
| R-08-15 실력별 리그 | 1~8주 성적 · 가산점 순번대로 1위 리그 · 2위 리그 · …, 리그마다 100명 그룹 · 리그별 순위 보상 |
| R-08-16 동시 차트 인 | 라운드마다 그룹당 상위 4~10%가 동시에 차트 인 → 파이널 1,000, 마지막 라운드 차순위 와일드카드로 정확히 1,000명 |
| R-08-17 5탭 | **전체 · 국가 · 친구 · 크루 · 인기**. 탭마다 1,000등까지 계산, 화면은 상위 50명 + 내 등수, 1~5분 주기 준실시간 스냅샷 · 갱신 시각 표시 |
| R-08-18 월드 출전 | 월드는 내부곡 영상끼리만 겨룬다(현중 11/24 18:02). 11/13 결정을 대체한다 |
| R-08-19 외부 영상 | 월드에서 뺀다(현중 11/24 18:02). 11/13 10:14 결정을 대체한다 |
| R-08-20 인기 재화 | 9주차에만 드랍, 인기 탭 크루 총공에 사용 |
| R-08-21 월드 보드 | 9주차 40칸 보드가 월드로 변신. 칸 돈 · 능력 배율은 비어 있음(×1로 동작) |

| 참가 규모 | 100명 그룹 수 | 라운드별 동시 차트 인 | 파이널 |
|---|---|---|---|
| 1,000명 이하 | 1~10 | 단계 없이 전원 파이널 | 전원 |
| 1만 | 100 | 예선 그룹당 상위 10명(10%) | 1,000 |
| 10만 | 1,000 | 1차 10명 → 2차 10명 | 1,000 |
| 100만 | 10,000 | 1차 10명 → 2차 10명 → 3차 10명 | 1,000 |
| 1,000만 | 100,000 | 1차 5명 → 2차 5명 → 3차 4명(4%) | 1,000 |
| 임의 인원 | 참가자/100 올림 | 그룹당 최소 상위 4명 + 와일드카드 | 1,000 |
