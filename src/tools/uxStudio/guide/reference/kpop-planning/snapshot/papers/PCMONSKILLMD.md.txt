# 몬스 스킬 · 출전 명단과 실제 배분 범위를 구분합니다

**이 문서는** 디펜스 한 판 안의 자동 스킬 배분·강화와 팀 피니시를 설명합니다.

**보는 법** 출전 명단 → 자동 스킬과 후보 카드 → 피니시 → 초기화·구현 차이 순서로 읽습니다. [대표 기획서](/docs/planning/삼중AI_공용_20260929/산출/개발진행기획_v01/콘텐츠별_v03/몬스_기획서.html#mons-three-uses)를 함께 봅니다.

**지금 상태** 실제 전투 코드와 원표를 대조했으며, 출전 정원10과 스킬 종류 상한5·명단 제한의 차이를 남겼습니다. 실제 화면 검수는 별도입니다.

## 1. 한 판 안에서 배우고 강화합니다

디펜스 전투 중 배운 자동 스킬과 팀 피니시는 한 판의 전투 기록입니다. 기획사 몬스 보유·종별 합성 횟수·공용 행복 지갑과 전투 스킬 단계를 같은 값으로 쓰지 않습니다.

## 2. 고정 다섯 파트너가 아닌 출전 명단

보유 종 중 실제 선택한0~10마리를 전투로 넘깁니다. 소유하지 않은 종을 더하지 않으며, 출전 명단에 몬스가 없으면 코드도 스킬 기회를 만들지 않습니다.

## 3. 스킬 종류 상한과 명단 제한

자동 스킬 정의는10종이고 현재 활성 종류 상한은5입니다. growthRoster는 출전 명단을 이 상한으로 자른 뒤 아직 스킬을 못 받은 대상을 찾습니다. 출전 정원10 전체와 이 배분 명단이 같은 범위라고 쓰지 않습니다.

## 4. 받은 기술을 강화합니다

초기 배분에서는 아직 받지 못한 대상에게 사용하지 않은 자동 스킬 한 종류를 배분합니다. 이후에는 이미 가진 스킬만 강화하며 최고 단계는 각 스킬의 원표를 읽습니다. 색별 고정 다섯 역할은 이전 콘셉트입니다.

## 5. 후보 풀에서 최대 세 장

현재 offer_choices는3이며 실제 남은 스킬·피니시 후보 풀에서 그 수 이내로 고릅니다. 다섯 몬스 중 반드시 서로 다른 세 마리가 나온다는 뜻이 아닙니다. 후보가 적으면 카드도 적고, 후보가 없으면 기회가 열리지 않습니다.

## 6. 초기 배분의 시간 만료

현재 설정은 초기 자동 스킬 배분과 첫 피니시 기회에서 제한시간이 끝나면 첫 후보를 자동 선택합니다. 처음부터 즉시 강제 선택한다는 뜻은 아닙니다. 이후 기회의 선택·만료와 전투 진행은 실제 엔진의 규칙을 따릅니다.

## 7. 피니시는 팀이 함께 씁니다

초기 자동 배분을 마친 뒤 팀 피니시를 배우는 후보가 열립니다. 내려찍기·빙결·전격·보호막·360도 미사일의 정의와 단계·재사용은 원표와 공유 피니시 코드를 따릅니다. 카드로 습득하는 일과 버튼으로 발동하는 일을 구분합니다.

## 8. 한 판 뒤 전투 습득은 초기화

자동 스킬과 피니시의 습득·강화는 다음 디펜스 판으로 넘기지 않는 기획입니다. 기획사 보유 종·합성·행복 저장을 전투 스킬 초기화와 함께 지우지 않습니다. 실제 재시작과 저장 조합 검수는 따로 확인합니다.

## 9. 기획·코드·미확인을 나눕니다

기획사 실제 보유 출전과 현재 스킬 종류 상한5·앞쪽 명단 제한은 서로 다른 근거입니다. 이 문서 정리가 종류 상한이나 운영값을 바꾼 것은 아닙니다. 출전6~10명 스킬 배분·전체 전투·화면·모바일 검수는 후속 확인 대상입니다.
