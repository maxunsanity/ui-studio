# D05 · 3인 대화·제삼자·관계 배치

문서 버전: 1.0 · 갱신: 2026-09-22 · 상태: 제작 참조 초안 / 실제 씬 검수 전

## 근거와 적용 범위

배우 배치와 카메라는 함께 관계를 전달하며, 여러 사람이면 방향 관계 관리가 복잡해진다. [StudioBinder 배우 배치](https://www.studiobinder.com/blog/blocking-and-staging-scenes/), [대화 축](https://www.studiobinder.com/blog/what-is-the-180-degree-rule-film/). 아래의 역할 모델과 3인 콘티는 자체 설계다. 기존 2인 시제품에서 검증된 것으로 간주하지 않는다.

## 2인 패턴을 세 번 반복하면 안 되는 이유

A–B 얼굴, B–C 얼굴, C–A 얼굴만 연속 배치하면 관객은 C가 어느 쪽에 있는지 놓칠 수 있다. 발언자와 수신자의 쌍이 바뀔 때 전체 공간 정보가 필요하다. 세 사람을 항상 같은 크기로 보여야 한다는 뜻도 아니다. 이번 비트에서 중요한 관계를 고르고 나머지 배우의 위치와 반응을 유지한다.

## 입력 데이터

| 필드 | 예시 | 필요 이유 |
|---|---|---|
| speaker | A | 현재 대사 주체 |
| addressees | B | C에게 하는 말인지 구별 |
| reactionSubjects | B, C | 듣는 둘의 반응 중요도 |
| alliance | A와 C가 동의 | 두 명을 묶는 구도 후보 |
| activePair | A–B | 컷 간 축 판단 기준 |
| layoutEpoch | layout-01 | 자리 변경 전후 구별 |

역할이 없는 배우도 대기·시선 트랙을 가진다. AI가 C를 화면 밖으로 뺀다고 C의 시간과 행동을 멈추지 않는다. 턴마다 모두 동시에 말하는 사람을 향해 고개를 돌리는 자동 동기화는 피하고 실제 반응 시점을 정한다.

## 배치 후보와 선택

삼각형 배치는 각 인물의 관계를 나눠 보여줄 후보가 된다. 둘과 하나의 배치는 합의나 대립을 보여주는 후보이며 줄 세우기 자체를 감정의 증거로 삼지 않는다. 한 사람이 뒤에 있으면 키·거리 차이로 얼굴이 가려지지 않는지 확인한다.

3인 전체 구도에서 배우 ID와 화면 순서를 기록한다. 새로운 쌍으로 촬영할 때 기존 전체 구도를 기준으로 공간을 판단한다. 카메라가 세 쌍의 모든 반평면을 동시에 만족해야 한다고 강제하면 해가 없을 수 있다. 현재 비트의 활성 쌍과 관계 재소개 컷을 사용한다.

## 30초 예시: 질문에 중재자가 끼어든다

| 구간 | 의미 | 화면 | 반응 |
|---|---|---|---|
| 0~4초 | 셋의 관계 제시 | 세 사람 전체 | A와 B 마주봄, C가 옆에서 들음 |
| 4~10초 | A: ‘왜 말하지 않았어?’ | A와 B 관계를 남긴 A 구도 | B가 답을 망설임 |
| 10~15초 | B: ‘먼저 확인하고 싶었어.’ | B 미디엄 | C가 개입할 준비 |
| 15~21초 | C: ‘잠깐, B 얘기를 끝까지 들어보자.’ | C 중심으로 관계 확인 | A가 C를 향함 |
| 21~26초 | A가 듣기로 함 | A 반응 | 큰 제스처 없이 시선 변화 |
| 26~30초 | 새 대화 관계 정착 | 3인 전체 | B가 말을 이어갈 준비 |

C가 개입하는 컷을 만들기 위해 C의 새로운 걷기 동작을 반드시 넣을 필요는 없다. 시선과 작은 손짓으로 목적을 달성할 수 있는지 먼저 검토한다. 위치 변경이 핵심이면 해당 이동 모션과 충돌 경로를 별도로 요구한다.

## 실패 사례와 복구

C가 사라졌다가 반대편에서 갑자기 나타나면 배우 위치가 바뀐 것인지, 축이 뒤집힌 것인지 먼저 확인한다. 두 사람 대화 때 쓰던 축 검사 하나를 모든 컷에 강제로 적용하지 않는다. 얼굴 세 개를 작은 프레임에 억지로 담아 표정이 읽히지 않으면 관계 컷과 개별 반응 컷을 나눈다.

## AI 제작 지시

```text
세 배우의 발언자·수신자·반응 중요도와 현재 배치를 먼저 표로 작성하라.
전체 관계를 알려주는 컷을 확보하고 발언권 변화 때 활성 대화 쌍을 갱신하라.
제삼자의 시선·대기 트랙을 유지하며 필요한 반응만 강조하라.
각 컷의 공간 연결 근거와 얼굴 가림 결과를 반환하라.
```
