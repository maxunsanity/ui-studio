## 이게 뭐냐

카드북이 「완성」되어 월드페스티벌 문 앞까지 가는 **시각 플로우 목업**. 규칙·장수·★·드롭은 쓰지 않고, Q-001 층위만 읽히게 그린다.

## 한 줄

> **풀 → 슬롯5 → 활성1~5 → 비멤버·역할 → ~20덱 채움 → 완성 → WF(입장 미잠금).**

## 화면 구성

| # | 블록 | 내용 |
|---|---|---|
| 1 | 플로우 띠 | 풀→슬롯5→활성→비멤버·역할→완성→WF |
| 2 | 층위 4카드 | 풀 / slot_cap / active / 슬롯밖 |
| 3 | ~20덱 그리드 | 멤버(분홍)·비멤버(주황)·역할(파랑) · 채움 게이지 목업 |
| 4 | 데모 A/B | active=1 · active=5 |
| 5 | 완성→WF | 게이트 UI · 입장 조건=**미잠금** |

## Q-001 용어 (필수)

| 용어 | 값 |
|---|---|
| `member_slot_cap` | **5** |
| `active_member_count` | **1~5** 가변 (≤ cap) |
| 풀 / 슬롯 / 활성 | **분리** |
| 슬롯 밖 | 비멤버 덱 쪽 |
| 역할 덱 | 홍보·정령 등 **유지** |
| ~20덱 | 카드북 맥락 유지 |
| A/B/C | **폐기** |
