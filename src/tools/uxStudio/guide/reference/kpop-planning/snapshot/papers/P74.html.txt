<section class="part" id="part-1"><h2>1. 개요</h2>

<h3 id="콘텐츠-경계">콘텐츠 경계</h3>

<p>배수를 먼저 선택하고 주사위를 굴리면 도착 위치가 정해집니다. 도착 칸이 무엇인지에 따라 해당 콘텐츠로 이어지고, 칸 수익을 계산할 때 선택한 배수를 사용합니다. 건설은 주사위를 직접 쓰는 행동이 아니라 별도의 돈과 건물 규칙을 따릅니다.</p>

<p>현재 공용 시뮬레이터는 보드 이동과 경제 계산을 시험하는 경로입니다. 개발된 시뮬레이터와 표의 임시값이 본게임의 계정 저장이나 최종 발란스까지 완성됐다는 뜻은 아닙니다.</p>

</section><section class="part" id="part-3"><h2>3. 구동 방법·시뮬레이션</h2>

<p>화면 흐름: 공용 시뮬레이터 로비 허브 → 배수 선택·굴림 → 도착 콘텐츠 → 메인 복귀 · 이번 문서의 새 화면 캡처는 미완 · 이식 비교는 해당 없음.</p>

<p><a href="/docs/planning/game-simulator.html?module=simulator_module_dice" data-paper-path="docs/planning/game-simulator.html">눌러서 메인 보드와 주사위 실행</a></p>

<ol>
<li>공용 시뮬레이터의 로비 허브를 엽니다. 현재 팀과 저장된 진행이 있다면 같은 진행을 확인합니다.</li>
<li>열려 있는 배수를 고르고 굴립니다. 현재 수동 허브는 보유 주사위와 엔터파워 문턱을 검사합니다. 일차 상한 표·별도 계산 함수와 이 허브의 연결 차이는 4장에서 구분합니다.</li>
<li>이동 경로와 도착 칸을 보고 해당 칸의 콘텐츠를 확인합니다. 건물 칸의 표시용 룰렛은 <a href="/docs/planning/%EC%82%BC%EC%A4%91AI_%EA%B3%B5%EC%9A%A9_20260929/%EC%82%B0%EC%B6%9C/%EA%B0%9C%EB%B0%9C%EC%A7%84%ED%96%89%EA%B8%B0%ED%9A%8D_v01/%ED%95%84%EB%9F%AC%EB%A3%B0%EB%A0%9B_v01/%ED%95%84%EB%9F%AC%EB%A3%B0%EB%A0%9B_%EA%B8%B0%ED%9A%8D%EC%84%9C.html" data-paper-path="docs/planning/%EC%82%BC%EC%A4%91AI_%EA%B3%B5%EC%9A%A9_20260929/%EC%82%B0%EC%B6%9C/%EA%B0%9C%EB%B0%9C%EC%A7%84%ED%96%89%EA%B8%B0%ED%9A%8D_v01/%ED%95%84%EB%9F%AC%EB%A3%B0%EB%A0%9B_v01/%ED%95%84%EB%9F%AC%EB%A3%B0%EB%A0%9B_%EA%B8%B0%ED%9A%8D%EC%84%9C.html">P72</a>, 실제 수익 계산은 경제 시스템이 맡습니다.</li>
<li>콘텐츠를 마치고 같은 메인으로 돌아가 다음 굴림을 이어갑니다. 문서를 여는 것만으로 무거운 시뮬레이터를 자동 실행하지 않습니다.</li>

<h3 id="배수-선택과-열림">배수 선택과 열림</h3>

<p>현재 <code>item_master_dice_mult.csv</code>는 배수와 최소 보유량을, <code>dice_mult_unlock_rule.csv</code>는 엔터파워 문턱을, <code>dice_mult_day_cap.csv</code>는 일차별 최대 배수를 담습니다. 코드의 현재 배수 문턱은 <code>enter_power_level</code>이 아니라 <code>dice_mult_unlock_rule</code>을 읽습니다. 표 값은 임시 시안이며 최종 발란스는 대기입니다.</p>
<p>공급원을 구분합니다. 공통 경제는 시작 50·12분당 1·기본 충전 상한 30 설정을 읽습니다. 성장 허브에서 real 스위치를 켠 시험은 <code>idol_growth_sim_config</code>의 <code>REAL_DAILY</code> 120·<code>REAL_STORE</code> 360을 읽으며, 끈 시험은 보유량 소비 제한을 분리합니다. balance import로 전달된 같은 진행의 경제 상태는 별도로 읽습니다. 서로 다른 시험의 수치를 무료 하루 총량이나 최종 운영 지급으로 합치지 않습니다.</p>
