# 유료화 — 돈은 아이돌을 키우고, 보여 주고, 손에 쥐게 합니다 (신규)

**이 문서는** 판매 방향과 현재 공통 상점의 부분 연결을 구분하는 유료화 제안서입니다.

**보는 법** 현재 부분 경로는 P217을 먼저 읽고, 아래 10장 컨셉과 이전 질문은 계획·시안으로 구분합니다.

**지금 상태** 상품 조회·보석 차감·팩 보관·같은 진행 저장 코드가 있습니다. 실제 UI 정상·운영 결제·확률 공개·패스·꾸밈은 검수 전 또는 준비 중입니다.

## 현재 공통 상점과 독립 판매 시안

현재 공통 상점은 상품 하위 표와 비용·보상 묶음을 읽는 부분 경로입니다. 실제 보석 구매는 항상 성공하는 프로토 결제이며 운영 결제 연동의 증거가 아닙니다. P217의 독립 판매 판정 시안은 자체 항목을 분류할 뿐 현재 상품·지갑·운영 결제를 읽지 않습니다.

<a id="read-2"></a>

## 준비 중과 소유 원본

패스·꾸밈은 현재 상점 표에서 꺼져 준비 중으로 표시하는 코드가 있습니다. 상품·등급팩·몬스팩의 임시 수치와 정책은 P168·P223 등 소유 원본을 따릅니다. 이 정정은 상품·확률·가격·시안 항목을 바꾸거나 운영 정책을 승인하는 작업이 아닙니다.

## 0. 한 줄 (신규)

> **돈은 아이돌을 더 빨리 키우고, 더 멋지게 보여 주고, 손에 쥐게 하는 데 씁니다. 순위는 팔지 않습니다.**

- 안 사도 같은 시즌 · 같은 대회에 나갑니다. 돈을 쓴 사람과의 차이는 **속도 · 꾸밈 · 소장**이다. [이전안 · 유지]
- 시즌 마지막 대회(월드 페스티벌)의 **점수 · 순위는 직접 팔지 않는 방향입니다. 카드 보관함은 별도의 유료 소장 기능입니다.** [제안 · 새로 추가]

## 1. 지금 게임에서 돈이 들어갈 자리 (신규)

지금 제안서들이 정한 게임 한 바퀴에, 돈이 들어갈 수 있는 자리만 표시했다.

| 게임 흐름 | 유저가 하는 일 | 돈이 들어갈 자리 | 근거 |
|---|---|---|---|
| 오디션 | 아이돌 캐스팅에서 마지막 한 장 선택 | 오디션 티켓·재오픈 결제 여부는 결정 대기 | 오디션 덱 |
| 주사위 | 굴려서 칸에 도착 · 많이 걸수록 판이 커짐 | **주사위 채우기** | [확정] 주사위 = 유료 결제 + 이벤트 지급 + 자동 지급(10/02 현중) |

### 게임 안 수익 구조 (신규)

게임 안 수익은 다음 네 가지로만 구성합니다.

| 게임 안 수익 | 설명 |
|---|---|
| 도착한 칸의 팬 | 보드에서 도착한 칸에 따라 받습니다. |
| 랩 스튜디오·방송 칸 잭팟 | 랩 스튜디오 칸과 방송 칸에서 발생합니다(10/02 현중). |
| 음원 | 게임 안에서 음원 수입으로 받습니다. |
| 출연권과 게릴라 공연 | 출연권과 게릴라 공연에서 발생합니다. |

게임 밖 · 실물 상품은 위 수익 구조에 포함하지 않습니다.

## 2. 유료 상품 구조 — 여섯 가지 (신규)

| # | 줄기 | 무엇을 파나 | 왜 사나 | 성격 |
|---|---|---|---|---|
| 1 | **주사위** | 유료 재화로 주사위 채우기 | 더 많이 걸고, 더 빨리 도시를 키우고 싶어서 | 매일 쓰는 돈 · 주력 |
| 2 | **카드 팩** | 카드북을 채우는 팩 | 원하는 카드 · 마지막 칸 · 대회 편성 | 매일 쓰는 돈 · 주력 |
| 3 | **시즌 패스 · 보관함** | 시즌 추가 보상 · 다음 시즌까지 카드 보관 | 가볍게 한 번 사면 시즌 내내 이득 | 시즌마다 한 번 |
| 4 | **꾸밈** | 무대 의상 · 건물 · 도시 겉모습 | 내 그룹 · 내 도시를 멋지게 보여 주려고 | 성능 없음 |
| 5 | **게임 밖 · 실물 상품** | 축제 음원 · 굿즈(앨범 · 건물 미니어처 · 실물 카드) | 손에 쥐고 싶어서 | 회사 매출 · 게임 밖 |
| 6 | **리드젠** | 파트너 홍보 미션 | 유저는 보상, 회사는 파트너 돈 | 곁 줄기 · 동의한 사람만 |

- 1 · 2가 매일 판매되고, 3이 받침이 되며, 4가 꾸밈을 담당합니다. 5는 게임 밖 · 실물 상품, 6은 곁 줄기입니다. [이전안 순서 유지 · 결정 대기]
- 게임 안 수익은 **도착한 칸의 팬 · 랩 스튜디오·방송 칸 잭팟 · 음원 · 출연권과 게릴라 공연**으로만 구성합니다. 게임 밖 · 실물 상품은 포함하지 않습니다.
- 게임 속 음원 수입(녹음실 도착한 칸)은 게임 재화이고, 축제 음원과 굿즈 판매는 게임 밖 · 실물 상품입니다. 둘을 섞지 않습니다. [이전안 + 확정]

## 3. 시즌 60일 동안 지갑이 열리는 순간 [제안] (신규)

```
오디션 직후 → 초반 → 중반 → 후반 → 대회 직전 → 대회 뒤
  패스          주사위    건물 문턱   카드북      무대 꾸밈     축제 음원
  시작 묶음     부족할 때  장소 카드   마지막 칸               게임 밖 · 실물 상품
```

| 때 | 이런 순간 | 사는 것 |
|---|---|---|
| 오디션 직후 | 새 주인공들과 새 시즌 시작 | 시즌 패스 · 작은 시작 묶음 |
| 초반 | 주사위가 떨어졌을 때 | 주사위 |
| 중반 | 조금만 더 업그레이드하면 건물이 바뀔 때 · 장소 한정 카드가 보일 때 | 주사위 · 카드 팩 |
| 후반 | 카드북이 몇 칸 남았을 때 | 카드 팩 |
| 대회 직전 | 내 그룹을 무대에 세울 때 | 무대 꾸밈(점수 영향 없음) |
| 대회 뒤 | 내가 만든 축제 음원이 나온 뒤 | 게임 밖 · 실물 상품 |

- 사는 이유는 늘 「막혀서」가 아니라 「조금만 더 하면 보여서」. [이전안]

## 4. 팔지 않는 것 (금지선) (신규)

1. **대회 점수 · 순위 · 부문상** — 돈으로 사지 않습니다. [제안 · 새로]
2. **카드 보관함과 대회 성적은 분리** — 남길 카드는 돈을 더 내고 보관합니다. 보관 가격·장수·기간·규칙은 결정 대기입니다(10/02 회의 현중 20:16).
3. **오디션 결과 · 아이돌 능력치** — 팔지 않습니다. [제안]
4. **칸 · 잭팟 확률 · 캐스팅 결과** — 팔지 않습니다. [이전안]
5. **별(희귀도) 합성** — 없습니다. 별은 얻을 때 정해집니다. [이전안 · 카드 덱]
6. **숨긴 확률** — 팩 확률은 공개합니다. [이전안]
7. **곡 뽑기** — 곡은 카드 조합으로 만듭니다. [이전안]

## 5. 먼저 정해야 할 것 — 결제와 유저 채점의 관계 [결정 대기] (신규)

현재 페스티벌은 유저가 만든 음원·영상을 다른 유저가 평가하는 안을 검토하며, 채점 방식은 결정 대기입니다. 레벨별 출전권은 4등급이며, 제작 가이드·툴은 운영사가 제공합니다. 옛 「무대 점수+시즌 점수」 자동 합산식과 이를 전제로 한 A/B/C안은 현행 대회 기준에서 제외합니다.

- 결제로 얻은 카드·성장이 출전 작품에 어떤 영향을 주는지.
- 유저 채점 방식과 몰아주기 방지.
- 출전권 등급 기준과 보관함 카드의 다음 시즌 역할.
- 카드 보관함은 소장 기능이며, 보관했다는 이유로 대회 점수·순위를 직접 지급하지 않는 방향입니다.

## 6. 유저층별로 — 누가 무엇을 하나 (신규)
