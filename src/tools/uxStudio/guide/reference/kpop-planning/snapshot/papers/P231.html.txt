</section><section class="part" id="part-3"><h2>3. 구동 방법·시뮬레이션</h2><p><strong><a href="/docs/planning/game-simulator.html?module=simulator_module_album_release">게임 시뮬레이터 앨범</a> → 발매한 앨범 선택 → 시티 투어 참가 → 차량 선택</strong>로 들어갑니다. 진행 중이면 같은 경기 이어하기입니다. 같은 음악 인스턴스/현재 저장 범위와 albumId를 유지하고 새 팀을 만들지 않습니다.</p>
<p>앨범 경로는 현재 보유 재화·앨범 참여 멤버·차트 리그를 사용합니다. 추가 입장비는 없고 급유할 때만 재화를 차감합니다. 자료가 없으면 대기 사유, 재화가0이면 보드에서 모으기를 표시합니다. 보상을 수령하면 유효한 현재 성장/카드 원장으로 연결합니다.</p>
<p><a href="/event/cityTour/racing3d.html">직접 독립3D</a>와 미니게임 목록은 비교용 명시 로컬 봇 시험입니다. 그 경로의80재화/24시간/시험 수령은 앨범 지갑으로 옮기지 않습니다. 레이싱2d는 기존 비교 실행으로 보존합니다. 명시 시티 단독 실행은 발매 시험곡·같은 로컬 리그·급유 재화80개를 처음 한 번 준비하여 앨범을 직접 만들기 전에도 시험할 수 있습니다. 기존 초안·발매곡·소모한 재화는 보존합니다.</p>

<p><strong>구현 구분:</strong> 앨범 재화 급유와 보드 START 적립/정산 경로는 소스에 있습니다. 속도 50%는 기본 랩 시간 12000ms로 설정에 반영했습니다. 새 설정을 불러와 만든 경기부터 적용하고 기존 경기는 저장된 원래 속도를 유지합니다. 실제 목표는 10바퀴이며 기획의 5바퀴 전환은 별도 후속입니다. 보드 획득→급유 전체 검증은 남아 있습니다. 저장된 기존 경기는 원래 목표·속도·영수증으로 복원하고, 새 경기에서 최신 규칙을 채택합니다. 검증을 끄거나 기존 저장을 새 규칙으로 덮어쓰지 않습니다.</p>

<p>앨범 경로에서 유효한 full checkpoint·현재 세션/팀·카드 보유 원천을 확인하면 <strong>기존 held 주사위와 아이돌 카드 효과/보유 원장</strong>에 수령을 반영합니다. 수령 영수증이 확정되기 전 실제 지급 완료를 표시하지 않습니다. 메타데이터/보유 원천 미확인은 경기 참가와 수령 가용성을 구분해 안내합니다. 직접 독립URL은 기존 로컬 시험 수령으로 남아 본편 보유량을 바꾸지 않습니다.</p>

<h3>추가 기획 체크 · 차량 고유 능력</h3>
<p><strong>제안(검수 대기): 차량의 성능·보유·장착과 아이돌의 주행 능력을 연결하는 기획이 필요합니다.</strong> 현재 코랄·골드·민트는 동등 성능의 시험 외형입니다.</p>
<ul>
<li>차량 정의의 performanceProfileId와 별도 버전 있는 성능 정의를 연결합니다. 최고속도·가속·주행 안정·지속 주행은 후보이며 채택 항목·수치·결합 가중치·상한은 발란스 대기입니다.</li>
<li>구매 거래, 보유 차량 인스턴스, 장착은 각각 구분합니다. 보유 대수·외형·가격을 곧바로 속도에 더하지 않습니다.</li>
<li>현재 아이돌 평균 능력과 차량 성능을 구분한 뒤 공통 구간 속도 규칙에서 결합합니다. 같은 아이돌 평균·같은 차량이면 솔로·유닛·팀의 속도가 같습니다.</li>
<li>재화1개=¼바퀴는 유지합니다. 연비·할인·추가 보상은 별도 경제 기획으로 검토합니다.</li>
<li>경기 생성 때 소유·장착·성능 버전과 계산 결과를 고정하고, 경기 중 교체·재접속으로 재계산 이득을 얻지 못하게 합니다.</li>

<h3>이벤트 시간과 저장</h3>
<p>24시간 마감과 한 경기 시계를 별도로 표시합니다. 차고는 남은 이벤트 시간, 주행은 내 순위·소수점 바퀴/5·남은 연료·현재 구간 속도를 보여줍니다. 작은 내 차 말풍선으로 내 위치를 구분합니다.</p>
<p>리셋은 현재 독립 시험만 새로 준비하고, 다음 경기는 같은 이벤트를 이어갑니다. 시험 저장은 고정 체크포인트1개를 사용합니다. 저장 공간이 부족하면 해당 탭의 메모리 시험으로 이어가며 새로고침 후 미저장 진행이 복원되지 않음을 작은 상태 줄로 알립니다. 메인 기록이나 다른 게임을 자동 삭제하지 않습니다.</p>
<h3>단독으로 바로 참가하기</h3>
<p>**<a href="/docs/planning/game-simulator.html?module=simulator_module_music_city&testPage=simulator_module_music_city">게임 시뮬레이터 시티 투어 단독</a>**을 열면, 현재 시험 팀으로 <strong>참여 멤버 → 시험 싱글 발매 → 100명 차트 리그 → 급유 재화 → 차고</strong>를 한 번 준비합니다. 실제 음악을 생성하거나 제작비를 청구하는 과정은 생략합니다. 보컬 성별이 확인된 멤버는 보컬, 확인되지 않은 멤버는 제작 역할로 명시한 음원 미연결 시험곡입니다.</p>
<p>새 시험의 급유 재화는 <a href="/event/cityTour/data/racing3d.json">3D 연료 설정</a>의 trialCurrency=80개입니다. 재화20개가5바퀴분이므로 네 경기 완주분을 시험할 수 있습니다. 재접속·메뉴 이동·다음 경기로 다시 지급하지 않습니다. 이전 시험 지원 영수증은 보존합니다.</p>
<p>기존 발매곡에 유효한 참여자·리그가 있으면 재사용합니다. 사용자 초안과 편집 내용, 종료된 리그는 바꾸지 않습니다. 만료된 이벤트를 새24시간으로 연장하지 않으며, 남은 경기·미수령 보상은 기존 이어하기로 봅니다. 이 자동 준비는 명시 city 단독 범위만 대상으로 하며 오디션·발란스 전송·메인 연계 자료에 시험 앨범/지원금을 넣지 않습니다.</p>
<h3>단독 시험 진행의 멤버 상태 보존</h3>
<p>단독 시험 준비는 현재 멤버의 능력과 컨디션·배정 상태를 함께 보존한 전체 시험 진행을 먼저 만들고, 그다음 앨범·리그·급유 재화를 준비합니다. 멤버 요약만 있는 상태를 참가 준비 완료로 표시하지 않습니다.</p>
