4. **도착 컷씬/필러·희귀 드롭** — 아레나홀 한 줄 → 보드 맛 보강 → **#2b**.

## 회의260928에서 뽑은 구체 기획 항목 (발췌)

- 3단계: 캐스팅16(≈15분) → 카드북 개방·멤버 선택 → 월드페스티벌.
- 완성자 전용 WF는 위험 → 등급별 + 시즌 끝 공동 축제.
- ★=획득 · 레벨=원정(모노카피바라).
- 카드는 모든 시스템 · 성장 보드 특정 장소 도착 시 희귀.
- 보드 찬스 내용 ≈ 카드 내용 매칭.
- 정령=악당→탐험에서 전투 또는 콘서트 정화.
- 홍보덱=Lead gen · 기본보상+추가보상.
- 음방1위·앨범(실제 유통 가능)·MV는 과함.
- 경제: 투자(주사위)→착지(준비비)→체급→도시.
- 이월=하나 남김(블록 커스텀). 사진 업로드 위험.
- 보상 숫자는 라이브 QA (지금 잠금 금지).
