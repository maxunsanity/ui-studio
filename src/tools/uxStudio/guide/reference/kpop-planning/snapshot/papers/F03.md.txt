## 연출 비트 / 포인트

### A. 밴 이동 · 착지

1. 주사위 결과 → `boardCellId`
2. 검은 밴이 도로망 최단(또는 순환도로)으로 POI 이동
3. 착지 → **도착 컷씬** (그 칸·그 판 버전)
4. 판정 카드 (대박/중박/운망) — 성장 칸만 급 관련 UI

### B. 바쁨 · dots

- 상단 뷰: 팬·보행 = **점**. 군중 메시 그림 금지 (제나 NavMesh 규칙).
- 밀도 소스: 응원봉/물결 · 성장 칸 급 · 당일 대박 여부 · MAX 근접도.
- 노랑·초록 구역이 먼저 밝아지고 점이 몰린다.

### C. 급 상승 (작지만 하이라이트) — 063

```
① 색 칩 10개 한 줄    ② 칸으로 흡수
③ 옛 이름에 줄        ④ 새 이름 찍힘
⑤ 급 배지 +1          ⑥ 빠순이/팬 한 줄 카피
```

핵심 = **③④ 이름 교체**. 「거리 버스킹」→「소클럽 오프닝」이 성장의 얼굴.

### D. 도착 컷씬 스왑 (판 전환 표현)

- Board1 컷씬 세트 / Board2 컷씬 세트 …  
- 판이 넘어가면 **같은 boardCellId라도 도착 영상이 교체**된다.
- 맵 텍스처 교체는 보조. **컷씬 스왑이 1순위 표현** (잠금 합의).

### E. 판 전환 (큰 연출) — 063

```
① 여섯 칸 순차 점등 → ② 카메라 풀백 → ③ 배너「○○ 보드가 생성되었습니다」
→ ④ 판 넘김 → ⑤ 22칸 이름 차례 찍힘 → ⑥ 판 이름 홍대→국내…
→ ⑦ 「우리 동네를 졸업했네」
```

지나온 동네 = **이력으로 남김** (지우지 않음).

### F. MAX 밀도 룩 (Board1 상한)

- 트리거: 노랑3+초록3이 **클럽/온라인 상한**에 전부 도달한 상태의 **상시 도시 룩** (판 전환 직전 최고조).
- 레퍼런스:  
  - `…/지시_성장맥스40칸_20260928/images/SSoT_성장맥스_컨셉아트.png`  
  - `…/블록컨셉아트_40칸_20260928/최종최고상태_컨셉아트.png`
- 읽힐 것: 나이트·창빛·네온·점이 붐빔 · 초록=클럽급 거리/라이브 · 노랑=온라인 송출 타워.  
- **읽히면 안 될 것:** 고척·돔·해외 아레나 · 공중파 사옥화.

### G. 시즌 엔드 (063)

지나온 판을 넘겨 마지막 판에서 정지 → 「여기까지 왔다」= 그 시즌 성적.
