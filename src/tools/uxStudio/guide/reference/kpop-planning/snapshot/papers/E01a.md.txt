## 0. 한 줄 요약

특정 레벨 이상 플레이어가 매주 뮤직·이미지·영상 창작물을 올리고, 조회·투표·공유·좋아요·후원을 합산한 점수로 순위를 매겨 Top 50에게 카드팩·주사위·골드를 지급하는 **주간 서바이벌형 창작 리그**.

설계 목표 셋
1. **창작자에게 무대를** — 게임 밖 바이럴(공유)을 게임 안 보상으로 연결
2. **관람자에게도 할 일을** — 투표·응원 자체가 일일 루틴이 되도록 투표자 보상
3. **돈·봇이 이기지 않게** — 로그 정규화 + 지표 상한 + 어뷰징 필터

## 1. 참여 자격 (레벨 게이트)

| 행동 | 조건(가안) | 이유 |
|---|---|---|
| 열람·좋아요 | 전 레벨 | 유입 장벽 최소화 |
| 투표 | Lv.5 이상 + 가입 3일 경과 | 부계정 1차 방어 |
| 공유 | 전 레벨 (점수는 유효 유입만) | 외부 바이럴 |
| 후원 | Lv.10 이상 | 자전 후원 차단 |
| **작품 제출** | **Lv.20 이상** + 휴대폰 본인인증 1회 | 1인 1계정 · 제재 실효 |

참가 레벨 ≈ 1~2주 플레이 지점 권장. 레벨 도달 시 **「리그 초대장」 연출**(우편+팝업).

## 2. 주간 사이클 (KST)

| 시점 | 이벤트 |
|---|---|
| 월 00:00 | 리그 오픈 · 주간 테마 공개 (테마는 선택 가점) |
| 월~금 23:59 | 작품 제출 (자동 검수 후 6시간 내 게시) |
| 월~일 20:59 | 반응 집계 |
| 토 00:00~ | 제출 마감 · 막판 투표 레이스 |
| **일 18:00~20:59** | **블라인드 타임** — 순위·점수 비공개 |
| 일 21:00 | 집계 락 |
| 일 21:00~월 11:00 | Top 50 정밀 검수 |
| 월 12:00 | 결과 발표 · 보상 우편 · 명예의 전당 |

**늦은 제출 불리 해소** — 게시 후 첫 12시간 「신작」 탭 상단 보장 + 로그 정규화.
**블라인드 이유** — 서바이벌 예능의 「최종 발표 전 순위 공개 중단」 문법. 막판 투표 독려 + 순위 조작 가시성 저하.

## 3. 제출 규정

### 3.1 부문

| 부문 | 예시 | 스펙(가안) |
|---|---|---|
| 뮤직 | 커버·리믹스·오리지널·응원가 | mp3/wav · 4분 · 30MB |
| 이미지 | 팬아트·포토카드·굿즈 시안·4컷 | png/jpg · 장변 4096 · 10MB · 최대 4장 |
| 영상 | 댄스 커버·팬 MV·숏폼·무대 재해석 | mp4 · 9:16/16:9 · 3분 · 300MB |

1인 주당 **부문별 1작·최대 3작**. 순위는 작품 단위, **보상은 1인 최고 순위 1개만**.
필수 입력: 제목·부문·설명(200자)·소스 표기·**AI 사용 여부**.

### 3.2 검수·권리

- **공식 크리에이터 키트** 제공 권장 (일러스트·로고·MR·스템). 검수 빠르고 IP 노출 큼
- 자동 필터: 선정성/폭력 분류 · 오디오 핑거프린트 · 중복 해시
- 금지: 타사 IP·실존 아이돌 초상 무단, 도용, 혐오·비방
- 약관에 **홍보용 2차 이용 동의** 포함, **저작권은 창작자 보유**

## 4. 점수 산정

### 4.1 유효 지표

| 지표 | 유효 기준 | 1인 제한 |
|---|---|---|
| 조회 | 영상·음원 5초+ / 이미지 3초+ | 작품별 1일 1회 |
| 좋아요 | 로그인 좋아요 | 작품별 1회 |
| 공유 | 공유 링크 **유니크 유입** (클릭만 X) | 기기 1회 |
| 투표 | 무료 1일 3표 (Lv.30+ 4표) | 동일 작품 1일 1표 |
| 후원 | **응원 아이템 「응원봉」** (골드·유료) | 작품별 1일 상한 |

### 4.2 정규화 + 가중합

```
N(지표) = ln(1 + 값) ÷ ln(1 + 부문 주간 최댓값) × 100

점수 = (조회N×0.10 + 좋아요N×0.15 + 공유N×0.20
        + 투표N×0.35 + 후원N×0.20) × 10      → 만점 1,000
```

| 지표 | 가중 | 의도 |
|---|---|---|
| 투표 | **35%** | 어뷰징 통제가 가장 쉬운 의사 표현 |
| 공유 | 20% | 신규 유입 기여 보상 |
| 후원 | 20% | 과금 동기는 살리되 독주 차단 |
| 좋아요 | 15% | 가벼운 호감 |
| 조회 | 10% | 부풀리기 쉬워 최저 |

**후원 폭주 이중 장치** ① 로그 정규화 ② 1인 후원은 그 작품 총 후원의 **30%까지만** 반영

### 4.3 계산 예시 (영상 부문)

| 지표 | 부문 최댓값 | 작품 A | N | 가중 |
|---|---|---|---|---|
| 조회 | 50,000 | 12,000 | 86.8 | 8.7 |
| 좋아요 | 8,000 | 2,500 | 87.1 | 13.1 |
| 공유 | 1,200 | 400 | 84.5 | 16.9 |
| 투표 | 3,000 | 1,800 | 93.6 | 32.8 |
| 후원 | 20,000 | 1,000 | 69.8 | 14.0 |
| **합계** | | | | **85.4 → 854점** |

→ 후원이 부문 최고의 1/20인데도 투표가 강하면 상위권 유지. **많이 사랑받은 작품이 이기는 구조.**

### 4.4 동점
① 투표 → ② 공유 유입 → ③ 선제출

### 4.5 통합 Top 50
세 부문 합산 통합 순위. 부문 내 정규화라 영상 독식 완화. 쏠림 지속 시 **부문별 최소 10석 쿼터** 옵션.

## 5. 보상 테이블 (가안)

| 순위 | 카드팩 | 주사위 | 골드 | 명예 |
|---|---|---|---|---|
| 1 | 레전드×3 | ×30 | 300,000 | 챔피언 · **로비 전광판 1주** · 전당 |
| 2 | 레전드×2 | ×25 | 200,000 | 준우승 · 전당 |
| 3 | 레전드×1 + 에픽×2 | ×20 | 150,000 | 3위 · 전당 |
| 4–10 | 에픽×2 | ×15 | 80,000 | Top10 배지 |
| 11–20 | 에픽×1 + 레어×1 | ×10 | 50,000 | Top20 |
| 21–30 | 레어×2 | ×7 | 30,000 | Top50 |
| 31–50 | 레어×1 | ×5 | 15,000 | Top50 |

### 5.1 Top 50 밖을 붙잡는 보조 보상 (이탈 방지 핵심)

| 대상 | 조건 | 보상 |
|---|---|---|
| 참가상 | 검수 통과 제출 | 일반 팩×1 + 주사위×1 |
| 도약상 | 전주 대비 30계단↑ | 주사위×3 |
| 개근 투표자 | 주 7일 투표 | 주사위×2 |
| **팬 픽 추첨** | 1위 작품에 투표한 유저 중 100명 | 에픽 팩×1 |
| 후원 환원 | 내 작품이 받은 후원 | 일정 %를 골드로 창작자에게 |

→ **「50위 못 들어도 매주 뭔가 받는다」가 참가 유지율을 결정.**
팬 픽 추첨은 관람자의 **「될 작품을 알아보는 눈」**을 게임화.

### 5.2 경제 체크포인트
- 주간 총 방출량이 일반 유저 주간 골드 수급의 몇 %인지 산출 후 조정
- 1위 골드 ≈ 일반 유저 **2~3주 치 수급**이 체감 적정 출발점
- 레전드 팩은 1~3위 한정 (희소성)
- **돈으로 못 사는 명예 보상**(전광판)이 창작자에겐 재화보다 강한 동기

## 6. 어뷰징 방지 — 「역공명 필터」

| 유형 | 탐지 | 대응 |
|---|---|---|
| 부계정 투표 | 기기 ID·IP 대역·가입 시점 클러스터링 | 표 무효 |
| 봇 조회 | 재생 패턴(동일 초 종료·비정상 반복) | 조회 무효 |
| 품앗이 투표 | 계정군이 서로 작품에만 반복 투표하는 그래프 | 가중 하향 → 무효 |
| 자전 후원 | 기기·결제수단·IP 유사도 | 후원 점수 무효 |
| 작품 도용 | 이미지 해시·오디오 핑거프린트·신고 | 즉시 비공개 + 심사 |

**단계 제재** 경고+지표 무효 → 주 순위 박탈 → 4주 정지 → 영구 정지
**Top 50 정밀 검수** 집계 락 후 자동 재검 + 운영자 확인 후 보상 확정. 박탈 시 51위부터 승계.

## 7. 화면 구성

**리그 메인** — 테마·마감 카운트다운·내 투표권 / 부문 탭 / 정렬(실시간 1시간 스냅샷·신작·추천·팔로우) / 작품 카드(썸네일·제목·창작자·순위·변동 화살표)
**작품 상세** — 플레이어 + 액션바(좋아요·투표·공유·후원) · 프로필 · 댓글 · 신고
**내 리그 대시보드** — 실시간 순위 · 지표별 기여 그래프 · **50위 경계까지 필요 점수 추정** · 공유 링크 원탭
**명예의 전당** — 주차별 1~3 아카이브 · 누적 Top10 크리에이터

## 8. 세계관 연동안 (**우동 IP** 적용 시 선택) ★

- **주간 테마 = 5감정 로테이션** — 사랑 → 용기 → 희망 → 공감 → 자유. 테마 부합 작품에 **멤버 감정 컬러 프레임**
- **「팬덤이 클수록 천음이 강해진다」** 본편 설정을 리그 명분으로. 리그 총 투표 수가 목표를 넘으면 **전 서버 보상(주사위 ×1)** 을 여는 **「천음 게이지」 공동 목표** → 경쟁 리그에 **협동 레이어**
- 어뷰징 필터를 본편의 **역공명**(증오로 모인 군중이 보스의 힘을 키움) 개념으로 네이밍 → 운영 공지가 세계관 콘텐츠가 됨

## 10. 법무·운영 체크리스트

- [ ] **확률형 아이템 표시** — 보상 카드팩도 확률 정보 게임 내 공개 (게임산업법, 2024.3 시행)
- [ ] **후원의 성격** — 게임 내 재화로만, **현금 환전 금지** (사행성·전자금융 이슈). 창작자 환원도 게임 재화 권장
- [ ] **미성년자** — 유료 후원 월 결제 한도, 미성년 창작자 초상 노출 보호자 동의 검토
- [ ] **저작권·초상권** — 외부 음원·실존 인물 금지, 신고 후 24시간 처리 SLA
- [ ] **AI 생성물** — 사용 여부 표기 의무화, 필요 시 별도 부문 분리 검토
- [ ] 출시 국가별 상이 → 적용 전 법무 검토
