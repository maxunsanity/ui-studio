## 이게 뭐냐

**아직 안 정한 칸·룰들을, 모노폴리 GO와 모노카피바라가 그 자리에서 뭘 했는지 보고 우리 말로 옮긴 답안.**
수치가 아니라 **컨셉**만 채운다.

## 언제 나오냐

지금은 문서. 채택되면 각 칸 문서(033·039·040·041·043·044·038·047)로 흩어져 들어간다.

## ★ 먼저 — 우리 기획이 GO·모노와 어긋나는 곳

### 덕질은 **칸에 떨어져야 하는 게 아니다**

| | 모노폴리 GO | 모노카피바라 | 우리 (지금 문서) |
|--|-------------|--------------|------------------|
| 건설 진입 | **화면에 상시 있는 건설 버튼** | **HUD 「짓기」 상시** — 칸 착지 아님 | "칸에 착지해서 덕질" |
| 정거장 | **약탈만** | 「정거장에서 건설」 구안은 **폐기** | 게이트에서 쌓기(이미 정정됨) |

모노카피바라는 **「정거장 도착 시 건설」을 명시적으로 폐기**했다. 착지 운에 성장이 막히면 답답해서다.

**제안:** 덕질도 **상시 버튼**으로 한다.
- **덕질 대상** = 아이돌 일정 22칸 (유저 확정 그대로)
- **진입** = 화면에 늘 있는 「덕질」 버튼. 어느 칸에 있든 코인만 있으면 한다
- **착지는 코인을 버는 쪽**, **덕질은 쓰는 쪽** — 두 행동이 갈린다

이러면 "덕질은 다 할 수 있어"가 룰로 깔끔해진다.

## 1. 팬덤 게이트 — 약탈 2종

> **이 절은 지났다. 2026-09-17 확정 → [064 딱지](./064_팬덤게이트_딱지.md).**
> 아래는 그때 낸 초안이고, 실제로는 **아무것도 안 뺏는 쪽**으로 갔다.

GO·모노는 정거장에서 **이중 롤**을 굴린다.

| 롤 | 내용 |
|----|------|
| ① 등급 | 중박 60 / 대박 25 / 운빨망함 15 |
| ② 방식 | **공성 60 / 금고 40** (①과 독립) |

**우리 말로**

| 모노·GO | 우리 (제안) | 뭘 하나 |
|---------|-------------|---------|
| Shutdown (공성) | **덮기** | 남이 쌓은 **서사 조각 하나를 가린다.** 우리 팀 이슈로 묻어버리는 감각 |
| Bank Heist (금고) | **가로채기** | 남의 **코인**을 턴다 |
| 쉴드·펫 (방어) | **고정팬** | 막으면 피해가 확 준다 |

**왜 「부수기」가 아니라 「덮기」냐** — 팬덤 육성 톤과 부딪힌다. 남이 키운 걸 부수면 이 게임의 얼굴이 깨진다.
**가린다**는 실제 팬덤에 있는 감각이고(다른 이슈에 묻힘), 되돌릴 수 있어서 덜 잔인하다.

> 금고 3매치는 **연출 전용**이다 (모노 39). 결과는 롤에서 이미 정해져 있고, 여는 순서가 결과를 안 바꾼다. 우리도 같게.

## 2. 사옥 — 한 바퀴 보너스

| | GO | 모노 | **우리 (제안)** |
|--|----|----|------|
| 주는 것 | 현금 +200 × 배수 | 골드 + **하루 +1** | **코인 + 하루가 넘어간다** |

사옥은 "출근"이다. 한 바퀴 돌면 **아이돌의 하루가 하루 지난다** — 스케줄 게임이니 날짜가 도는 게 맞다.
(모노는 100일 안에 클리어 못 하면 실패. 우리도 시즌 길이와 붙을 수 있다.)

## 3. 정산 · 대형 정산

모노 TAX는 **등급롤 네 가지가 전부 마이너스**다. 대박이어도 잃고, 운망이면 크게 잃는다.

**제안:** 우리도 같게. **부호만 반대인 판정.**

| 판정 | 정산 |
|------|------|
| 대박 | 적게 나간다 ("이번 달은 선방") |
| 중박 | 보통 |
| 운빨망빨 | 많이 뜯긴다 |

대형 정산(40)은 정산(5)보다 세다. 액수는 밸런스.

## 4. 병가 — 탈출

모노 JAIL: 수감 중 **등급롤 전부 마이너스** + **3회 탈출 실패 시 벌금**. GO는 더블이면 탈출.

**제안**

| | |
|--|--|
| 들어가면 | 몇 턴 못 움직인다 |
| 나오는 법 | ① 더블(같은 눈) ② 탈출권 ③ 코인 내고 조기 복귀 |
| 있는 동안 | 스케줄이 비어서 **잃기만 한다** |
| 내 쪽 한 줄 | 재촉 안 한다. 마음만 보낸다 |

## 5. A&R · 매니지먼트 — 유틸 요금

GO 전기·수도는 **주사위 눈 × 배수**를 낸다. 후반엔 순자산 업그레이드로 **수입으로 뒤집힌다**.

**제안**

| | |
|--|--|
| 지금 | 회의 들어가면 **주사위 눈 × 배수**만큼 코인이 나간다 |
| 나중에 | 덕력이 높아지면 이 칸이 **수입으로 뒤집힌다** — "회사가 이제 내 말도 듣는다" |

두 칸이 **덕질 불가**인 건 그대로.

## 6. 공동기금 → **총공으로 확정** (2026-09-17 · [039](./039_공동기금_GO표기.md))

모노: 착지마다 적립 → **3단계 목표** 달성 시 보상. GO: 친구 2명과 주간 팀 → 열쇠 → 상자 3단 → **매주 리셋**.

**제안:** GO 구조 그대로. 이름만 덕질로.

| GO | 우리 |
|----|------|
| 주간 팀 (친구 2명) | **총공 팀** |
| 열쇠 | 총공 인증 |
| 상자 3단 | 화력 3단 |
| 파트너 미배정 → 현금 | 팀 없으면 코인 |

## 7. 스탠바이 · 온에어

모노: VISIT = 가벼운 회복, PARK = 안전 보너스. **둘 다 작지만 뭔가는 준다.**
우리는 지금 **기본 무효과**로 잠갔다 ([044](./044_코너_스탠바이_온에어.md)).

**제안:** 무효과 유지. 대신 **시즌 이벤트가 꽂히는 유일한 자리**로 쓴다.
판에 "평소엔 조용한데 특집 때만 켜지는 칸"이 둘 있는 게 리듬에 좋다.

## 8. 덕질 한 번에 얼마 · 판 클리어

모노: **6자리 × 6단 = 36 완공 = 판 클리어.** 건설이 코인의 최대 소비처.
GO: 랜드마크 다 지으면 다음 보드.

**제안**

| | |
|--|--|
| 덕질 자리 | 아이돌 일정 **22칸** |
| 판 클리어 | 22칸이 전부 만단 |
| 단 수 | 밸런스 (모노 6단 참고) |
| 덕질 1회 | **서사 조각 +1 · 덕력 +1** |
| 세트 완성 | 덕력 보너스 (모노 +3) |
| 판 클리어 | 덕력 보너스 (모노 +5) |

## 9. 주사위 통 (덕력 마일스톤)

모노 실측 앵커: **시작 cap 30 → 번영도 500에서 cap 90 → 천장 200.** 재생 시간당 5~10. 매 +1이 아니라 **지정 구간에서만** 열린다.

**제안:** 덕력도 **마일스톤 해금**. 덕력이 1 오를 때마다가 아니라, 정해진 구간에서 통이 커진다.
"어제보다 조금"이 아니라 **"오늘부터 다르게 굴린다"**가 되어야 체감이 산다.

## 안 정한 채로 두는 것

- 모든 수치 (액수·단 수·확률·cap 값)
- 덮기가 **몇 개**를 가리나 · 되돌아오나
- 유틸이 수입으로 뒤집히는 덕력 기준
- 시즌 길이와 「하루」의 관계
