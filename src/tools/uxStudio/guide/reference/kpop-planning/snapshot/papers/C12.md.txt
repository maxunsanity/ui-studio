# D08 · 카메라 계산·초점·웹/Blender 교환

문서 버전: 1.0 · 갱신: 2026-09-22 · 상태: 제작 참조 초안 / 실제 씬 검수 전

## 확인된 기능과 범위

Cine Camera Actor는 필름백·렌즈·초점 등을 설정하는 가상 카메라다. [Epic 공식 문서](https://dev.epicgames.com/documentation/en-us/unreal-engine/cinematic-cameras-in-unreal-engine). Blender 공식 개발 문서의 검색 본문에서는 원근·직교와 초점 대상 기능을 확인했다. [Blender 카메라](https://docs.blender.org/UATEST/manual/en/dev/render/cameras.html). stable 문서 조회는 실패했으므로 설치 버전별 API 확인은 남아 있다.

이하 계산은 표준 핀홀 투영의 수학적 유도와 우리 교환 규격 제안이다. 특정 엔진에서 실행 검증한 코드가 아니다. Three.js 클래스 문서는 이번 조회에서 상세 본문을 확보하지 못했으므로 API 이름별 동작을 새로 확인했다고 주장하지 않는다.

## 원근 카메라 거리의 초기값

수직 화각을 fovY, 화면비를 a=width/height로 두면 수평 화각은 fovX=2*atan(tan(fovY/2)*a)다. 카메라와 평행한 평면 위 대상 높이 H가 화면 높이의 q를 차지하도록 하는 초기 거리는 d=H/(2*q*tan(fovY/2))다.

예: H=1.6m, q=0.8, fovY=40도이면 d는 약 2.75m다. 기울어진 몸이나 깊이가 있는 배우 묶음에는 근사값이다. 최종 구도는 대상 바운딩 포인트를 실제로 투영해 확인한다. 가로 폭 W의 조건도 계산하고 세로·가로 중 더 큰 거리를 초기값으로 삼는다.

이 계산의 H는 전신 컷이면 전신, 얼굴 컷이면 얼굴 영역이다. 항상 모델 전체 높이를 넣으면 얼굴 클로즈 요청이 반영되지 않는다. 수직 화각과 수평 화각, 라디안과 도를 혼용하지 않는다.

## 직교 카메라

직교에서 보이는 세로 범위를 S라고 정의하면 높이 H의 화면 점유율은 q=H/S다. 목표 q를 얻기 위한 S=H/q를 구한다. 가로 범위는 S*a다. 여기서 S는 공통 규격의 수직 범위이며 각 엔진의 `scale` 속성과 직접 동일하다고 가정하지 않는다. 어댑터가 화면비·fit 설정을 고려해 변환한다.

직교 카메라를 앞뒤로 움직여도 원근 카메라처럼 대상 크기가 바뀌지 않는다. 접근 효과는 스케일 변화나 원근 카메라 전환을 검토한다. 중간에 투영 방식을 바꾸면 배경과 인물 비율이 튈 수 있어 컷 경계 또는 별도 전환 설계가 필요하다.

## 얼굴 가림과 초점

카메라에서 양눈·코·입 등의 표본점으로 향하는 가시성을 확인한다. 하나의 중앙 광선만으로 얼굴 전체를 보았다고 판정하지 않는다. 머리카락·반투명 재질·옷자락은 렌더 결과와 충돌 지오메트리가 다를 수 있어 실제 프레임도 검사한다.

초점 대상 전환은 카메라 방향 회전과 다르다. 방향은 유지한 채 전경에서 후경으로 초점을 바꾸는 설계도 가능하다. 렌더러가 심도를 지원하지 않으면 초점값만 바꿔 효과가 생겼다고 하지 않는다. 해당 효과를 미지원으로 표시하고 구도 전환 대안을 제시한다.

## 공통 교환 데이터

| 항목 | 기록 방식 |
|---|---|
| 좌표 | 월드 단위·업 축·카메라 전방 축·좌표계 설명 |
| 시간 | fps·정수 프레임 범위·시간 기준 |
| 투영 | perspective/orthographic |
| 렌즈 | 수직 화각 또는 센서+초점거리, 기준 축 명시 |
| 직교 | 공통 세로 범위, 엔진별 변환 방식 |
| 방향 | 위치·회전·타깃의 우선권, 회전 연속성 |
| 초점 | 대상 ID 또는 거리와 단위, 심도 지원 상태 |
| 출력 | 해상도·화면비·crop/fit·near/far |

## Blender 왕복 절차

원본 씬과 리그를 복제해 작업한다. 카메라와 배우를 공통 월드 기준으로 변환하고 시작·중간·끝의 기준 프레임을 렌더한다. 카메라 애니메이션에 제약이 있으면 교환용으로 평가된 결과를 베이크하는 안을 사용한다. 가져온 뒤 배우 머리·발·카메라 위치와 동일 화면비의 이미지 비교를 수행한다.

VRM/GLTF 또는 Blender 파일에서 좌표 변환이 이미 적용됐는지 확인해 두 번 변환하지 않는다. 모델 스케일 차이가 카메라 거리 차이로 보이면 렌즈부터 고치지 않는다. 웹 카툰 재질과 Blender 재질의 일치 여부는 카메라 교환과 별도로 검증한다.
