### 1-2. 중심 = 메인 보드(허브)
- 첫 바퀴 뒤 메인 보드가 모든 콘텐츠의 출발점이자 돌아오는 곳이에요. 지금 허브도 보드 화면을 「메인」으로 써요(`data/simulator/simulator_module.csv:3`).
- 왜: 매 턴 보는 곳이 보드라서 기준점을 하나로. 막는 문제: 길 잃음, 콘텐츠끼리 서로 불러 생기는 되돌이 고리.
- 연결: 모든 「돌아가기」는 메인으로(`hub-flow.mjs:16` returnModuleId = mainModule).

### 1-5. 공통 이동 규칙
1. **들어가기**: 보드가 판정·보상 패킷을 먼저 확정·저장한 뒤 이동. 저장 실패면 넘기지 않음(`play.html:452`). 왜: 꺼져도 결과가 남게. 막는 문제: 결과 유실·다시 굴려 고르기.
2. **결과 넘기기**: 요청 하나(requestId)와 패킷만. 같은 requestId는 다시 만들지 않음(`hub-flow.mjs:15`). 막는 문제: 중복 지급.
3. **돌아오기**: 모든 콘텐츠 같은 자리 「메인으로 돌아가기」(`simulator_ui_text.csv:32`). 연출 화면은 지급 없이 「봤음」만(`events.mjs:159` presentationOnly). 막는 문제: 연출 화면 지급으로 두 번 받기.
4. **끊김·이어하기**: 열린 요청은 팀마다 하나(`hub-flow.mjs:15`). 다시 들어오면 그 요청으로 바로 안내(`idol_growth.mjs:36`). 첫 바퀴 중 끊기면 첫 바퀴 그 칸부터. 막는 문제: 길 잃음, 연출 중단으로 보상 누락.
5. **끼어들기 순서**: 디펜스 → 원래 칸 콘텐츠 → 2차 룰렛 → (턴 끝) 찜 오디션 알림. 한 번에 하나만. 막는 문제: 화면이 겹쳐 무엇을 받았는지 모름.
