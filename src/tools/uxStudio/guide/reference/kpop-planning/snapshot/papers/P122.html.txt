</section><section class="part hist"><h4>스킬 카드 3장 선택 창</h4>
<ul>
<li>뜨는 때: 성장 기회 시각에 화면 아래쪽에서 카드 3장이 올라옵니다. 기회 횟수는 「확인 필요 1」을 따릅니다. (v03 06장, mons-skill.md:136) (제나 초안 15:10)</li>
<li>머리말: 「스킬을 배울 기회 · 키울 몬스 하나를 고르세요」 (mons-skill.md:40) (제나 초안 15:10)</li>
<li>카드 한 장(위에서 아래로): 몬스 얼굴(실제 담당 몬스 얼굴 카드 그림) → 몬스 이름 → 스킬 이름 + 발사체 그림 → 「신규」 또는 「n단계 → n+1단계」 → 한 줄 설명. (v03 06장, mons-skill.md:41~43) (제나 초안 15:10)</li>
<li>남은 시간: 카드 줄 위에 줄어드는 막대 하나. 제한 시간(v03 8초)은 (신규) 임시 시안. 시간이 다 되면 카드가 내려가고 기회를 건너뜁니다. (v03 06장) (제나 초안 15:10)</li>
<li>후보가 3장 미만이면 있는 장수만 가운데 정렬로 보이고, 후보 0이면 창을 띄우지 않습니다. (v03 06장) (제나 초안 15:10)</li>
<li>고른 뒤: 고른 카드가 위로 커지며 사라지고, 담당 몬스 머리 위에 단계 숫자가 잠깐 뜹니다. 그 몬스가 말버릇대로 한마디 합니다. (mons-skill.md:139) (제나 초안 15:10)</li>
<li>창 크기는 「확인 필요 8」에 따릅니다. (제나 초안 15:10)</li>
</ul>
</section><section class="part hist"><h4>몬스 표시 크기 50%와 얼굴 카드 자리</h4>
<ul>
<li>필드 위 몬스는 이전의 절반(배율 1.6 → 0.8, (신규) 임시 시안)으로 작아지므로, 누가 누구인지는 얼굴 카드로 알려 줍니다. 악귀 0.72, 보스 1.35 별도 배율((신규) 임시 시안). (v03 04장) (제나 초안 15:10)</li>
<li>얼굴 카드 줄: 화면 아래 왼쪽, 편성한 몬스 수만큼 가로로(최대 5칸, (신규) 임시 시안). 칸마다 얼굴 + 가진 스킬 아이콘 + 단계 숫자 + 쿨타임 원형 게이지. (제나 초안 15:10) (신규) 확인 필요</li>
<li>필드 몬스 머리 위에는 작은 색 점만 두고, 얼굴 카드 칸 테두리 색과 맞춰 짝을 알 수 있게 합니다. (제나 초안 15:10) (신규) 확인 필요</li>
<li>스킬 카드 창이 뜰 때 얼굴 카드 줄은 가리지 않는 자리(카드 창 위쪽 또는 옆)에 둡니다. (제나 초안 15:10)</li>
<li>편성 몬스 1~4마리일 때 빈 칸을 보일지 숨길지는 「확인 필요 7」과 같이 정합니다. (제나 초안 15:10)</li>
</ul>
