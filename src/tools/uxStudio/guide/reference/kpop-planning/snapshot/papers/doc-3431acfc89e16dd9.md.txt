## 이게 뭐냐 (신규)

**아이돌이 노랑·초록 6칸에 떨어졌을 때 나오는 그날 결과.**
칸 이름이 아니라 **판정**이다 — 잘 됐나 그저 그런가 망했나.

## 언제 나오냐 (신규)

주사위 → **노랑(방송)·초록(공연) 칸 착지** → **판정** → 대박 / 중박 / 운빨망빨 중 하나

> **정정 2026-09-17 (유저).** 전에는 「대박 = 수준 +1 (영구)」였는데 **아니다.**
> **대박은 그날 한 번 위 급 무대에 서는 것**이고, 다음엔 원래 급으로 돌아온다.
> **칸 급이 진짜로 바뀌는 건 덕질(색 10개)뿐이다.** → [062](./062_보드성장.md)

| | 뭐가 되나 | 얼마나 가나 |
|--|-----------|-------------|
| **대박** | 한 급 위 무대에 선다 · 코인 크게 | **그날만** |
| 중박 | 같은 급에서 잘함 | — |
| 운빨망빨 | 제자리 (하락 없음) | — |
| **덕질 10개** | 칸 급이 **바뀐다** | **영구** |

한 번 좋은 무대 섰다고 그 급이 되는 게 아니다. 게릴라로 클럽 한 번 서는 것과 클럽에서 계속 부르는 것은 다르다.

## 규칙 (일관) (신규)

| 판정 | 수준변화 | 다음 종류 | 지역명 | 돈 |
|------|----------|-----------|--------|----|
| **대박** | 공유 사다리 **+1** | 다음 수준의 **구체 종류명**(지금 칸명과 다름) | `룰렛(대·소분류)` | 큼 |
| **중박** | **수준 유지** | 같은 수준·더 좋은 종류 / 보너스 | 약하게 가능(소분류 힌트) | 중간 |
| **운빨망빨** | **제자리**(하락 없음) | 낮은 노출·재시도 연출 | 없음 / 실패 연출 | 적음·실패 |

시상식은 **방송 사다리에서 제외**.

### 공유 사다리 (신규)

- **공연(초록):** 버스킹 → 클럽 → 소극장 → 중극장·홀 → 아레나·대형홀
- **방송(노랑):** 온라인 → 라디오 → 케이블TV → 공중파TV → 해외방송

### 대박 다음 예시 (Board1 → +1) (신규)

- 버스킹 종류 → 클럽 종류: 소클럽 오프닝 / 라이브하우스 / 댄스클럽 쇼케이스
- 온라인 종류 → 라디오 종류: 심야 / 로컬 / 메인 게스트
