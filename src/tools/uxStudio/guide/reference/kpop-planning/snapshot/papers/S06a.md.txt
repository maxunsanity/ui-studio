**이 문서는** 장면·화면·연출·소리의 구조를 읽는 이식 부록입니다. 원형 표·규칙·당시 규모와 모노 근거를 보존해 봅니다.

**보는 법** 아래 현재 읽기 범위를 확인하고 간략에서 세부로 내려갑니다. 기존 S06·S06b 연결과 [S14 구현 구조](S14_구현구조.md)를 함께 읽습니다.

**지금 상태** 이식 기획과 포트의 일부 코드·현재 등록 허브의 계약을 정적으로 대조한 제안(검수 대기) 문서입니다. 상위 연결과 실제 화면·소리·저장 동작은 미검수입니다.

**현재 읽기 범위 — 정적 대조**

- **장면·허브** — 포트의 `enter/exit/afterEnter`와 현재 등록 허브의 `mount/activate/deactivate/serialize/dispose`는 서로 다른 계약입니다. 포트 장면 전체가 현재 허브에 연결됐다는 뜻은 아닙니다.

- **연출 값·저장** — 점 전환에는 코드 상수가 있고, FX 설정에는 코드 기본값·툴의 로컬 저장 묶음·CSV 덮기 경로가 있습니다. 각 reader가 무엇을 읽는지는 나눠 확인합니다. 저장 helper의 존재와 실제 저장 성공을 구분합니다.

- **소리 연결** — cue·bind·asset과 대체음 코드는 있으나 읽은 포트 runtime은 `action_type` 중심입니다. `scene.enter/exit`가 현재 배경음까지 이어지는 연결·실제 재생은 미확인입니다.

- **배치·원표** — `pageLayout`은 배치·글자·초상 크기를 적용하는 코드이며, `scene_*` 대표행은 도시 공간 시안, `text_ko`는 표·개체·필드별 표시 문구 연결입니다. 이름만으로 모든 화면의 동일 원천으로 합치지 않습니다.

- **주소·공급** — 상대 CSV 주소·`csvRoot`·번들 조회와 실행 페이지의 상위 연결은 미확인입니다. 확인한 기본 경로의 부재를 원표 전역 부재나 현재 실행 오류로 확대하지 않습니다.

- **당시 기록** — 아래 규모·표·도식·키·원값과 기획의 미정·제외 범위는 당시 기록으로 보존합니다. 현재 부분 코드 확인을 새 정책·운영값 확정이나 모든 기능의 구현 완료로 쓰지 않습니다.

## 간략

**머리표** 시스템 기획 · S06a · 화면 구조 · 모노 장면 15 · 화면 61 · UI 연출 58 · 연출 표 30 · 소리 3단 · 글자 · 아이콘 · 구역 배치 이식(바꿔서 옮김)

**제목** 화면 구조 — 장면은 조립만, 박자 · 소리 · 글자 · 자리는 모두 표가 정한다

**훅** 코드는 「무슨 일이 났다」만 알리고, 어떻게 보이고 들릴지는 표 한 줄을 바꿔서 고친다.

**두 줄 요약**
- 화면은 네 겹이다: **장면**(통째로 바뀜 · 로비 ↔ 인게임 · 이벤트는 얹기) → **화면**(장면 안 부품) → **연출**(표가 정한 박자) → **소리**(신호 → 연결 → 파일).
- 연출 · 소리 · 글자 · 아이콘 · 구역 배치 값은 모두 `data/game/`의 `ui_fx_*` · `sfx_*` · `text_ko` · `tool_icon_source` 표에 두고, 코드는 키만 부른다. 값은 임시 시안 · 전투 줄은 뺀다.

```mermaid
flowchart LR
  S[장면 · 들어가기 / 나가기 / 들어간 뒤] -->|scene.enter · exit 신호| SFX[소리 3단 · 신호 → 연결 → 파일]
  S --> V[화면 · 장면 안 부품]
  V --> FX[연출 · 표 값을 읽어 박자대로]
  FX --> T1[ui_fx_* key 표 · 줄 표]
  V --> TX[글자 text_ko · 아이콘 icon 칸 · 구역 ui_fx_page_layout]
  SFX --> T2[sfx_cue · sfx_bind · sfx_asset]
```

1. **바꾼다** — 로비 ↔ 인게임은 완전 교체(점 연출 닫힘 → 나가기 → 들어가기 → 열림 → 인트로). 이벤트 · 창은 위에 얹고 닫는다.
2. **그린다** — 장면은 화면 부품을 조립만 한다. 게임 규칙은 장면에 넣지 않는다.
3. **움직인다** — 연출은 `ui_fx_*` 표 값을 박자대로 읽는다. 코드에 시간 · 크기를 박지 않는다.
4. **울린다** — 신호가 나면 `sfx_bind` → `sfx_cue` → `sfx_asset` 순으로 소리를 고르고, 파일이 없으면 대체 삐.

| 왜 지금 | 이게 핵심 | 이게 아닌 것 |
|---|---|---|
| 케이팝 프로토에는 장면 전환 · 결과창 · 연출 표 · 소리 표가 없고 기획서도 없어, 모노 원본 없이 화면을 다시 만들 수 있게 구조를 옮겨 둬야 한다 | 장면 3박자 · 바꾸기 둘 · 표가 값을 정함 · 소리 3단 · 키 이름은 모노와 같게 | 인게임 화면 층 설계가 아니다(→ S06) · 모노 숫자 · 색 복사가 아니다 · 전투 연출이 아니다 |
