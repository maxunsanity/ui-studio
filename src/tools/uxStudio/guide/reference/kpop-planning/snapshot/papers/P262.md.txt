# HUD · 포토카드 UI 통합 기획서 v1

**이 문서는** 보드 화면(HUD)부터 포토카드 · 명함집 · 카드 · 획득 연출까지, 지금 기준 UI를 한 곳에 모은 UI 기획서입니다. HUD 상세 기획서 v1.6 본문과 화면 깊이표, 11/20 와이어프레임 4장(HUD 한 장 · 포토카드 · 카드 디자인 가이드 · 획득 연출)을 합쳤습니다.

**보는 법** 1장(원칙) → 4-2절 HUD 메뉴 표 → 4-11절 화면 깊이 → 4-12절 포토카드 → 4-13절 카드 디자인 → 4-14절 획득 연출 → 4-15절 남은 결정 순서로 읽습니다. 화면은 각 절의 회색 와이어프레임(390×844)으로 봅니다.

**지금 상태** 현재 개발되지 않음, 진행 중. HUD 쪽 시뮬레이터 상태는 7장에 있습니다. 포토카드 · 명함집 · 카드 앞면 · 획득 연출은 와이어프레임 1차까지이고, 게임 시뮬레이터 화면은 아직 이 구조가 아닙니다.

## 1. 개요

### 콘텐츠 경계

- 맡는 것: 보드 화면 HUD의 자리 · 버튼 · 누르면 열리는 화면 · 칸 도착 버튼 · 글자 수, 화면 깊이와 뒤로 가기, 포토카드 탭 화면(목록 · 사람 보기 · 카드 · 팩 · 명함집 · 스카우트 · 교체), 카드 앞면 틀, 획득 연출 단계.
- 맡지 않는 것: 각 콘텐츠 화면의 안쪽 구성(이름과 입구만), 수치 · 보상 · 확률 값(카드 기획서 · 각 시스템 기획서 · 비앙카 산정), 연출 영상 자체.

### 원칙

| 원칙 | 내용 |
|---|---|
| HUD에 두는 것 | 보드 플레이와 관계된 것만 둡니다. 나머지는 눌러서 들어간 콘텐츠 화면에서 보여 줍니다 |
| 버튼 모양 | 버튼, 이미지, 누를 수 없는 표시를 모양으로 구분합니다. 입체(3D) 효과는 넣지 않습니다 |
| 펼침 표시 | 펼침 메뉴(정보 · 몬스 기분 게이지 · 설정)에만 작은 화살표를 붙입니다 |
| 빨간 점 | 지금 받을 수 있는 보상이 있을 때만 답니다 |
| 새 창 | HUD를 위해 새 화면을 늘리지 않습니다. 기존 콘텐츠 화면으로 바로 갑니다 |
| 화면 동작 버튼 자리 | 화면 동작은 아래 메뉴 바로 위 버튼 줄에만 둡니다. 화면을 바꿔 보는 것(책갈피)은 위쪽, 그 대상에게 하는 동작은 아래쪽입니다 |
| 창 버튼 자리 | 창은 제목 왼쪽 위 · ✕ 오른쪽 위 · 동작 버튼은 창 맨 아래 |
| 화면 깊이 | 깊이는 2까지. 더 들어가야 하면 창으로 띄웁니다(4-11절) |
| 사람 단위 | 포토카드 · 명함집은 사람 한 명이 한 칸입니다. 카드는 그 사람의 12장입니다 |
| 등급 표기 | 아이돌 · 팀은 단계 이름(연습생 · 데뷔조 · 라이징 스타 · 톱스타 · 월드스타), 스태프 · 회장은 ★만 |
| 와이어 수준 | 회색 와이어프레임 1차 · 글자 11px 이상 · 이름표는 칸 안 |

### 확정한 결정

- 방패는 따로 두지 않고, 이어지는 하나의 **몬스 기분 게이지**로 보여 줍니다(칸을 나누지 않음, 빈 게이지 → 가득 = 방패 3).
- 돈, 엔터파워, 팬은 줄이지 않고 모든 자릿수를 보여 줍니다. 자리가 늘면 그 숫자 글자만 작아집니다.
- 주사위는 **가진 개수/상한**으로 보여 줍니다. 1,000개부터 1.2K처럼 줄입니다.
- 앨범 상자는 화살표·드롭다운 없이 **두 칸**으로 바로 이동합니다.
- 음악 앱은 이번 구조에서 뺍니다. 기록장·소식은 HUD에 두지 않습니다.
- 이름: 위쪽 재화는 **루비**, 아래 메뉴는 **포토카드**, 정보 펼침의 공동체는 **크루**, 오른쪽 상자는 **앨범**입니다.
- 포토카드 상세는 **사람 보기** 한 화면입니다. 큰 캐릭터 위에 능력 줄을 겹치고, 위쪽 책갈피 「능력 · 카드」로 바꿔 봅니다. 아래 버튼은 그 사람에게 하는 동작 하나(스태프 교체 · 아이돌 캐릭터 정보)입니다.
- 팀 보기는 포토카드 안에서 팀 등급 · 팀 능력 합 · 팀 6축 · 멤버를 한 화면에 보여 줍니다. 팀 등급 문턱은 루키 0 · 대세 1,100 · 톱티어 2,400 · 국민돌 8,300 · 글로벌 아이콘 8,600입니다.
- 아이돌 사람 보기에서 가장 중요한 값은 **지금 단계 · 재능선 · 지금 6축 값**입니다. 세부는 현황판 · 캐릭터 정보창에서 봅니다.
- **명함집**은 스태프 · 팬클럽 회장만 담는 페이지입니다(아이돌은 캐스팅). 스카우트 팩 열기 · 보관 · 교체를 한 기능으로 묶습니다. 명함에는 주요 능력(가장 큰 축)과 카드 n/12를 적습니다.
- 진행은 게이지 대신 **n/12 글자**로 적습니다. 6축은 작게 접어 두며 나중에 뺄 수 있습니다.
- 카드 앞면은 **그림이 카드 전체**를 채우고, 이름 · ★ · 능력은 그 위에 반투명 판으로 겹칩니다.
- 아이돌 캐스팅 · 스태프 획득 · 팬클럽 회장 선출은 **같은 5단계 연출**이고 영상만 다릅니다. ④ 공개는 사람 보기 화면을 그대로 씁니다.
- 화면 깊이 · 뒤로 · 바로 가기 · 팀 얼굴 · 상점 처음 책갈피 규칙(4-11절)을 확정했습니다. 크루는 이번 범위 밖입니다.

## 4. 상세 기획

### 4-1. 한 판 순서

평소 화면에서 굴리기를 누름 → 말이 이동하는 동안 필러 박스는 카드 한 장 높이 → 칸 도착 → 필러 결과·대사 → 가운데 줄이 그 칸 버튼(1~3개)으로 바뀜 → 칸 버튼을 누르거나 콘텐츠를 마치고 돌아옴 → 다시 굴리기.

| 점검 | 내용 |
|---|---|
| 시작·종료 | 로비에 들어오면 HUD. 다른 전체 화면이 열려 있으면 그 화면을 닫고 HUD로 |
| 입력·출력 | 굴리기 탭(한 번) · 꾹 1초(자동) / 이동, 칸 도착 |
| 상태와 전이 | 평소 → 이동 중 → 칸 도착 → (콘텐츠) → 평소. 자동 중에는 굴리기 버튼이 「자동」 모양 |
| 판정 | 칸 도착 판정과 필러 결과는 도착 때 정해 둠 |
| 오류·예외 | 주사위가 배수보다 모자라면 굴리기 막힘. 0개면 다음 충전 시간만 보이고 자동도 멈춤 |
| 저장·복원 | 해당 없음(각 콘텐츠의 저장을 따름) |
| 다른 모듈 연결 | 4-2절 HUD 메뉴 표의 「주 메뉴」 |

### 4-2. HUD 메뉴 표 · 확정

게임 시뮬레이터 · 현황판 · 발란스 시뮬레이터 · 원본 기획서와 줄마다 대조했습니다. **(추가)**는 지금 어느 도구에도 없고 이 문서에서 새로 넣는 것입니다.

| HUD 메뉴 | 하위 메뉴 | 주 메뉴 | 기능 |
|---|---|---|---|

### 4-4. 앨범·페스티벌 상자

![앨범·페스티벌 칸 세 상태](산출_기획서_20261119_로비메뉴_프로필정보_상세기획서_그림/01_앨범페스티벌칸_3상태.png)

**01.** 위부터 ① 페스티벌 아닌 기간 ② 주간 페스티벌 ③ 월드 페스티벌

버튼 모양의 상자 하나에 두 칸이 있습니다. 자리만 함께 쓰고 기능과 설명은 칸마다 따로입니다. 화살표·드롭다운은 없습니다.

**앨범 칸** (세 상태 공통)

| 보이는 것 | 데이터 이름 |
|---|---|
| 내 앨범 재킷 | 내 앨범 목록의 대표 앨범 |
| 「내 앨범 n/8」(이번 시즌 발매 수, 시즌 최대 8곡) | `count` |
| 차트 순위 | `league.playerRank` |
| 남은 시간 | `league.remainingMs` |
| 한 바퀴 보상 돈·팬·능력 아이콘 3칸. 3개를 넘으면 「보상 보기」(작은 창) | 값은 차트 보상 표를 따름 |

누르면: 차트 중이면 그 곡의 차트, 아니면 내 앨범 화면. 게이지는 이 칸에 두지 않고 내 앨범 화면과 차트에서 보여 줍니다.

**페스티벌 칸** (항상 있고 버튼은 항상 켜짐)

| 기간 | 이름 | 시간 | 재화 수 | 버튼 |
|---|---|---|---|---|
| 페스티벌 아닌 기간(시즌 사이 쉬는 3일 포함) | 주간 페스티벌 | 시작까지 0일 00:00:00 | 연료 수 | 레이스 |
| 주간 페스티벌(1~8주) | 주간 페스티벌 | 남은 기간 0일 00:00:00 | 연료 수 | 레이스 |
| 월드 페스티벌(9주) | 월드 페스티벌 | 남은 기간 0일 00:00:00 | 인기 재화 수 | 추천 |

- 칸 본체를 누르면 주간 또는 월드 페스티벌 화면, 「레이스」는 레이스 입장, 「추천」은 모은 인기 재화를 내 월드 출전곡에 씁니다.
- 연료 수 데이터: `musicCareer.journey.balanceFestival.fuel`.
- 무리 순위 · 구역 등수 · 월드 리그 · 크루 총공은 HUD에 두지 않고 각 페스티벌 화면에서 보여 줍니다. 크루 월드 신청은 크루 화면에서 크루장만 합니다.

### 4-5. 가운데 줄 · 굴리기

![가운데 굴리기 줄](산출_기획서_20261119_로비메뉴_프로필정보_상세기획서_그림/02_가운데굴리기줄.png)

**02.** 가운데 줄 구성(① 기본 굴리기 ② 자동으로 굴러가는 중 ③~⑤ 칸 도착 버튼 1~3개 ⑥ 복귀 굴리기 · 디펜스)

![굴리기 버튼 상태 다섯 가지](산출_기획서_20261119_로비메뉴_프로필정보_상세기획서_그림/03_굴리기버튼상태.png)

**03.** 굴리기 버튼 상태(① 기본 ② 손가락 닿음 ③ 이동 중 ④ 자동 이동 중 ⑤ 주사위 모자람)

- 평소: 왼쪽 배수 + 넓은 굴리기 버튼(안에 남은 주사위 수 · 다음 충전 시간). 오른쪽은 비우고, 자동 버튼은 따로 두지 않습니다.
- 꾹 누르기: 손가락이 닿으면 버튼 아래 막대가 1초 동안 차오릅니다. 다 차기 전에 떼면 한 번 굴리고 글자는 「이동 중」, 다 차면 자동 이동(슬롯머신 불빛이 빠르게 도는 느낌, 몇 번째 굴림인지 표시).
- 나온 눈은 「주사위 0 + 0 = 00칸」 형식으로 보여 줍니다.
- 배수를 누르면 다음 열린 배수로 바뀝니다. 가진 주사위가 지금 배수보다 모자라면 굴리기가 막힙니다.

**칸 도착 버튼** (주 행동은 오른쪽 끝, 1개는 전체 폭 · 2개는 반반 · 3개는 3등분)

| 상황 · 칸 | 버튼 |
|---|---|
| 평소 · 도착 연출이 끝난 뒤 | 굴리기 (+ 왼쪽 배수) |
| 건물 · 출발 · 사옥 · 팬 반응 · 찬스 — 대사가 남았을 때 | 넘기기 · 건너뛰기 |
| 건물 — 파손됐을 때 | 수리 · 굴리기 |
| 출연권 대전 6 · 16 · 26 · 36 | 도전 |
| 감옥 31 | 복귀 굴리기 |
| 나쁜 기운 가득(칸 상관없음) | 디펜스 |
| 정산 · 큰 정산 · 기숙사 · 본가 | 굴리기만 |

- 짓기 · 증축은 칸 도착이 아니라 아래 메뉴 「건설」에서 합니다. 건물은 번 돈을 투자해야만 자랍니다.
- 자동 중에 나쁜 기운 가득 · 출연권 대전 · 허브 도착이 오면 자동을 멈춥니다(제안, 남은 결정 8번).

### 4-6. 필러 박스

**05.** 칸 도착 필러 세 단계(① 이동 중 카드 한 장 ② 결과 멈춤 ③ 대사만큼 위로 늘어남)

![2차 필러 박스 카드 디자인 목록](산출_기획서_20261119_로비메뉴_프로필정보_상세기획서_그림/06_필러모음.png)

**06.** 필러 카드 디자인 목록(가 1~15 케이팝 게임 시뮬레이터에 있는 카드 · 나 16~24 모노에만 있는 카드)

| 단계 | 모습 |
|---|---|
| ① 이동 중 | 박스는 카드 한 장 높이. 도착 카드와 대박·중박·운망 글자 슬롯 하나만. 결과 문장은 미리 넣지 않음 |
| ② 결과 멈춤 | 글자가 돌다가 결과에서 멈춤. 이어서 보상 칩이 하나씩 |
| ③ 대사 | 대사·지문·보상 카드가 붙는 만큼 위로 늘어남. 최대 170, 넘치면 위쪽 줄이 박스 안에서 밀려 올라감 |

- 박스 안에는 버튼을 두지 않습니다. 넘기기 · 건너뛰기 · 굴리기는 가운데 줄에 있습니다.
- 도착 카드 한 줄 = 도착 이름표 · 칸 이름 · 판정 이름표. 장면 카드 한 줄 = 장면 제목 · 장소 · 인물. 카드 높이는 기존보다 줄입니다.
- 자동 굴림일 때만 대사를 1.1초마다 자동으로 넘깁니다.
- 카드 디자인: 케이팝 게임 시뮬레이터 15종(도착 1 · 장면 리본 4색 · 바퀴 띠 1 · 캐릭터 말풍선 1 · 리액션 말풍선 2 · 판정 카드 4 · 보상 칩 2), 모노에만 있는 것 8종.

|---|---|---|
| 포토카드 | 포토카드 화면(처음은 배치) | 가진 카드팩 수 |

| 미션 | 미션 화면 | 받을 수 있는 미션 |
| 상점 | 상점 화면 | 선물 받기 가능 |

- 알림: 숫자 0~99는 그대로, 100부터 「99+」. 숫자가 아닌 알림은 빨간 점.
- 아래 메뉴는 다시 누르면 닫힙니다. 정보 펼침도 같습니다. 펼친 메뉴 바깥을 누르면 접힙니다.
- 정보 펼침 순서: 팀(팀이 있을 때만) · 아이돌 · 관계 · 크루 · 몬스. 팀과 아이돌은 같은 캐릭터 정보창이고, 팀은 팀 책갈피, 아이돌은 개별 책갈피로 엽니다. 창 안에서 책갈피로 오갈 수 있습니다.
- 팀은 멤버가 2명이 되면 결성됩니다. 팀이 없으면 정보 펼침은 아이돌부터 시작합니다.

왼쪽은 특가·세일, 오른쪽은 경쟁·미니게임만 둡니다. 원래 가운데 1칸은 앨범·페스티벌 상자에 내주었습니다.

|---|---|
| 왼쪽 1 | 사다리 특가 (고정) |
| 왼쪽 2 | 황금 바자 |
| 왼쪽 3 | 세일 · 행운 상자 |
| 왼쪽 4 | 골라담기 |
| 왼쪽 5 | 오늘의 3종 |

- 넣지 않는 것: 버프(위쪽 시간 버프 칩) · 출석(입장 때 창) · 전투 계열 이벤트.

#### 화면 깊이 · 들어오는 길 · 뒤로 (확정 2026-11-19~20)

깊이 0 = HUD, 1 = HUD에서 한 번 눌러 여는 화면, 2 = 그 안의 버튼으로 들어가는 안쪽 화면입니다. 책갈피는 같은 깊이 안에서 바꿔 보는 것이라 깊이를 늘리지 않습니다.

1. **깊이는 2까지만** 둡니다. 더 들어가야 하면 창으로 띄웁니다. 창은 깊이를 늘리지 않습니다(현중 11/19 「2까지·창으로」).
2. ← 뒤로는 한 칸 위로 갑니다. 깊이 2 → 깊이 1(보던 책갈피 그대로) → HUD.
3. 창은 닫기 · 바깥 누름 · Escape로 닫고, 연 자리로 돌아갑니다.
4. 아래 메뉴는 전체 화면 위에서도 보입니다. 다른 칸을 누르면 화면을 쌓지 않고 바로 바뀌고, 같은 칸을 다시 누르면 HUD로 돌아갑니다.
5. **바로 가기**(다른 메뉴의 화면으로 건너뜀)로 들어간 화면의 ← 뒤로는 **온 화면**으로 한 번 돌아갑니다(현중 11/19 「온 화면으로」).
6. **팀 얼굴**을 누를 때 다른 전체 화면이 열려 있으면, 그 화면을 닫고 캐릭터 정보창을 바로 엽니다. 로비 원본 R-S12-14 「초상을 누르면 전체 화면이 닫힘」을 이렇게 바꿉니다(현중 11/19 「닫고 바로 열기」).
7. **상점 처음 책갈피**: 돈으로 열면 특가, 루비로 열면 루비 책갈피(현중 11/20 「그렇게 열기」).
8. 칸 도착 콘텐츠(도전 · 디펜스)는 HUD 위로 장면이 바뀌고, 끝나면 그 칸으로 돌아옵니다. 도중에 ← 는 없습니다(포기 버튼만).

**구분:** 확정 = 원본·시뮬에 있음 · 제안 = 이번에 정하는 것

### 4-12. 포토카드 · 명함집

아래 메뉴 「포토카드」를 누르면 ① 목록이 열립니다. 모든 칸은 사람 한 명입니다.

### 4-13. 카드 디자인 가이드

카드 한 장 = 꽉 찬 그림 한 장 + 그 위에 겹치는 이름 · 능력 판입니다. 그림에는 글자 · 별 · 번호 · 테두리를 넣지 않습니다(카드 기획서 5장).

| 자리 | 내용 |
|---|---|
| 테두리 | ★ 색: ★1 회색 · ★2 하늘 · ★3 초록 · ★4 보라 · ★5 금색 + 반짝 바탕 |
| 위 판 | 카드 이름 · ★ |
| 그림 | 카드 전체. 얼굴 · 주요 동작은 위 판과 아래 판 사이, 카드 위쪽 절반 안 |
| 누구 판 | 종류 아이콘 · 「예명 · 아이돌」 / 「이름 · 직업」 |
| 능력 판 | 종류마다 다름(아래 표) |
| 아래 판 | 번호 n/12 · 한 줄 글 · 얻는 팩 아이콘 |

| 카드 종류 | 능력 판 | 예 |
|---|---|---|
| 아이돌 | 올리는 세부 능력 + 값 | 보컬 기초 ★1 · 음정 +1,000 · 발성 +1,000 |
| 스태프 · 능력 6자리 | 그 자리가 맡은 세부 + 값(세부 하나 900을 ★ 배수로 나눔) | 보컬·랩 · 딕션 · 발성 · 플로우 +00 |
| 스태프 · 기획사 3자리 | 효과 % · 앞으로 얻는 양에만 | 컨디션 케어 ★2 · 컨디션 회복 +2.00% · 라포 획득 +2.82% |
| 팬클럽 회장 | 팬 증가 · 팬 돈 · 악개 감소 · 팬 상한 % | 레전드 팬덤 ★5 · 팬 증가 +3.77% · 팬 돈 +2.85% · 팬 상한 +12.00% |

그림 가이드: 아이돌은 단계가 오를수록 무대가 커집니다(연습실 → 쇼케이스 → 음방 → 콘서트 → 월드 투어). 스태프는 일하는 장면이고 얼굴은 명함과 같은 사람입니다. 회장은 등급이 오를수록 팬이 많아집니다. 한 사람의 12장은 색감을 맞춰 한 벌로 보이게 하고, 없는 카드는 같은 틀에 그림만 흐립니다.

### 4-14. 획득 연출 구조

아이돌 캐스팅 · 스태프 획득 · 팬클럽 회장 선출은 같은 5단계이고 영상만 다릅니다. 스킵은 처음부터 끝까지 오른쪽 아래에 있습니다.

1. **시작** — 그 종류의 장소 영상과 「열기」.
2. **기대** — 문 · 무대 · 응원봉이 빛나고 빛 색으로 등급을 미리 알려 줍니다.
3. **숨김** — 흰 번쩍 뒤 실루엣.
4. **공개** — 포토카드 「사람 보기 · 능력」 화면 그대로(책갈피와 아래 버튼만 숨김) · NEW. 처음 만난 사람만, 중복은 건너뜁니다.
5. **결과** — 얻은 사람 · 영상 스킵 체크 · 한 번 더 · 확인.

| 종류 | ① 장소 영상 | ② 빛나는 것 | ④ 능력 줄 · 가운데 띠 | ⑤ 뒤 가는 곳 |
|---|---|---|---|---|
| 아이돌 캐스팅 | 오디션 무대 | 무대 조명 | 특기 · 재능선 % / 띠 단계 · 6축 평균 / 6축 지금 값 ━ ◆재능선 | 팀 |
| 스태프 획득 | 기획사 사무실 | 문 | ★ · 고정 능력 · 맡는 세부 · 스케줄 / 띠 주요 능력 | 명함집 |
| 팬클럽 회장 선출 | 팬 모임 · 응원봉 | 응원봉 물결 | ★ · 팬 수 문턱 / 띠 팬 효과 % | 명함집 |

### 4-15. 남은 결정

1. 친구 메뉴(친구 목록 · 파트너 이벤트 · 선물 · 카드 트레이드)를 정보 펼침 안에 둘지, HUD에 따로 둘지.
2. 상점 「이벤트 보상」 입구를 둘지. 원본의 이벤트 보상은 상점 책갈피가 아니라 무료 주사위 계산 항목입니다. 이 문서에서는 뺐습니다.
3. 3일 마일스톤을 오른쪽 5번으로 옮길지(안 A), 오른쪽 한 칸을 넘겨 보는 칸으로 묶을지(안 B).
4. 관계 화면에 팀 케미 · 어색한 쌍을 더할지. 지금 케미는 「처음 케미 미리보기」에만 있습니다.
5. 주사위 상한: 자동 충전 상한(엔터파워 단계별 30~120)을 보여 줄지. (제안: 자동 충전 상한)
6. 글자 수 제안: 팀 이름 12자 · 앨범 이름 16자 · 차트 순위 「100위」 4자 · 앨범 남은 시간 「1일 00:00:00」 · 이벤트 문구 한 줄 7자 · 아래 메뉴 이름 4자 · 펼침 항목 이름 8자 · 대사 한 줄 38자. 넘치면 글자를 줄인 뒤 「…」.
7. 차트 밖일 때 앨범 칸: 순위 「차트 밖」, 보상 칸은 그대로. (제안)
8. 자동 중 멈춤: 나쁜 기운 가득 · 출연권 대전 · 허브 도착에서만 멈춤. (제안)
9. 자동 이동 중 색: 회색은 주사위가 모자랄 때만, 자동은 슬롯머신 불빛. (제안)
10. 필러 룰렛을 건물·창구 포함 28칸에서 열지, 건물에서만 열지. (제안: 28칸)
11. 1차 대박 뒤 2차 룰렛 연출을 넣을지. (제안: 결과에서 멈추고 2차는 돌리지 않음)
12. 필러 판정 카드에 팬·능력도 붙일지. (제안: 돈만)
13. 말하는 사람 자리: 그림을 둘지, 이름 첫 글자 배지를 둘지. (제안: 첫 글자 배지)
14. 판정 이름: 대박 · 중박 · 운망(제안) / 올킬 · 차트인 · 광탈.
15. 주간 페스티벌: 순위가 월드로 이어지는지, 주간 보상, 주간에 크루 출전이 되는지. 원본끼리 서로 다릅니다. HUD에는 두지 않고 페스티벌 화면에서 다룹니다.
16. 명함집 보관 칸 수. (현중 결정)
17. 스카우트 팩 등급 확률 · 지급 수 · ★5 천장 횟수. (비앙카 산정)
18. ④-1 팩 안 카드: 사람별 12칸 대신 「나올 수 있는 카드 00장 · 아직 없는 카드 00장」 숫자 두 줄로 줄일지. (제안: 숫자 두 줄)
19. 6축 접기 줄을 스태프 사람 보기에서 뺄지. (나중에 결정)
