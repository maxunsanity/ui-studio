# D10 · 자동 촬영 연구를 우리 구조로 옮기기

문서 버전: 1.0 · 갱신: 2026-09-22 · 상태: 제작 참조 초안 / 실제 씬 검수 전

## 연구에서 확인한 내용

Cine-AI는 기법 데이터를 바탕으로 후보를 거르고, 카메라 배치와 가시성·충돌을 확인하며 콘티에서 수정할 수 있는 구조를 다룬다. 본문의 데이터 주석, 기법 선택, 배치 검증, 한계 절을 확인했다. 감독 스타일의 구별은 장면 종류와 표본에 영향을 받고 주석 작성자의 판단에도 의존한다. [Cine-AI 본문 3·4·7절](https://arxiv.org/html/2208.05701v1).

FilmAgent의 연구팀 개요는 준비된 가상 공간에서 대본·연기·촬영 역할을 나누고 중간 결과를 피드백으로 검토하는 접근을 설명한다. 이번에 확인한 것은 프로젝트 개요이며 전체 코드·실험의 재현은 아니다. [FilmAgent 연구팀](https://filmagent.github.io/).

아래는 이 연구를 그대로 복제한 구현이 아니라 우리 도구를 위한 설계 판단이다.

## 우리에게 필요한 네 단계

1. 의미 계획: 대사의 목적과 감정 변화를 정하고 화자·청자·반응 대상을 적는다.
2. 기법 선택: 관련 영상과 이론 문서를 읽고 자산·인원·공간 조건으로 후보를 거른다.
3. 장면 조립: 선택한 기법의 카메라 좌표·시간·모션 연결을 계산한다.
4. 검사·수정: 장면 데이터와 연속 재생을 보고 문제 구간만 다시 구성한다.

자연어 AI가 모든 뼈 좌표와 카메라 키를 즉석에서 직접 작성하도록 맡기지 않는다. AI는 의도와 후보 선택을 담당하고 좌표·타임라인은 검증 가능한 조립 명령으로 계산한다. 이것이 프롬프트를 길게 쓰는 것만으로 해결되지 않는 부분이다.

## 실제 연결할 입력과 출력

| 모듈 | 입력 | 출력 | 실패 시 |
|---|---|---|---|
| 자료 조회 | 지시·인원·자산 조건 | 문서 ID·절·근거 카드 | 근거 부족 표시 |
| 연출 계획 | 대본·자료·잠금 | 비트·컷·선택 이유 | 모순 또는 자산 누락 |
| 장면 조립 | 검증된 ID·파라미터 | 편집 패치 | 유효성 실패 |
| 배치 검사 | 배우·공간·카메라 | 가림·충돌 후보 | 다른 배치 제안 |
| 재생 검사 | 전체 시퀀스 | 문제 시간·판정 | 부분 재구성 |
| 저장 | 기준 버전·변경 | 새 리비전·실행 기록 | 충돌 시 기존 유지 |

## 연구의 채택과 보류

스타일을 데이터로 관리하고, 후보를 조건으로 거르고, 카메라 검사를 거치고, 결과를 사람이 수정할 수 있게 하는 방향을 채택 제안한다. 특정 감독의 기법 빈도만 그대로 재현하거나 연구의 품질 점수를 우리 도구의 성능으로 가져오지 않는다. 감독 이름 대신 ‘반응을 오래 유지’, ‘주로 고정 구도’, ‘강조에만 접근’처럼 관찰 가능한 속성을 저장한다.

다중 에이전트 실행은 여기서 자동 도입하지 않는다. 역할 분리된 단계는 하나의 AI와 명령 인터페이스로도 먼저 검증할 수 있다. 필요한 경우에만 비용·지연·개선 효과를 비교한 뒤 확장한다.

## 첫 검증 실험

같은 2인 대본에 A안은 화자 중심, B안은 청자 반응 중심으로 만든다. 동일 자산·길이·배경을 유지하고 어떤 순간 감정이 더 잘 읽히는지 비교한다. 평가 기록에는 사용 문서 버전·콘티·카메라·모션·사용자 의견을 남긴다. 비교 결과 한 번으로 모든 씬의 기본값을 바꾸지 않는다.

## 실험 완료 조건

지시의 근거를 원문 URL만이 아니라 우리 MD의 문서/절로 추적할 수 있어야 한다. 선택된 모션은 실제 등록된 ID여야 한다. 부분 수정 시 잠금과 기존 씬을 보존해야 한다. 재생 검사를 하지 않았다면 데이터 검사만 완료했다고 표시한다.
