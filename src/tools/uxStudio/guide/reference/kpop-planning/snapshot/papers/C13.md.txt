# D09 · 카메라와 연기 연결·접지·실패 복구

문서 버전: 1.0 · 갱신: 2026-09-22 · 상태: 제작 참조 초안 / 실제 씬 검수 전

## 근거와 상태

이 문서는 외부 교육 자료 요약이 아니라 기존 컷씬 시제품의 실패 기록을 바탕으로 한 우리 제작 규칙이다. 공식 모션 7종 중 인사 모션의 시작이 웅크림이었다는 기존 검사, 골반 이동 누락과 상체 부분 적용 실험을 출발점으로 삼는다. 이번 상세 문서 작성 중 모션을 새로 재검수한 것은 아니다.

## 왜 카메라만 고쳐서는 해결되지 않는가

다리가 들려 있거나 골반과 상체가 어긋난 동작을 얼굴 컷으로 가리면 원인이 남는다. 전신으로 돌아오는 순간 같은 오류가 드러난다. 모션의 시작·핵심·복귀가 안정된 뒤 연출 구도를 선택한다. 카메라 검수와 애니메이션 검수는 각각 통과해야 한다.

## 모션 세그먼트의 필수 기록

원본 파일 ID와 해시, 리그 버전, 실제 사용 구간, 시작/끝 자세, 이동량, 접지 구간, 전신/부분 적용 방식, 시선·표정 충돌, 재생 속도 범위, 검수 모델과 검수 날짜를 저장한다. ‘인사’라는 파일 이름만으로 서 있는 가벼운 인사라고 분류하지 않는다.

모션 전체 검수와 잘라낸 구간 검수는 다르다. 3초 이후가 서 있는 자세라 해도 그 구간으로 들어갈 때 팔이 튈 수 있으므로 대기→선택 구간→대기 전체 연결을 재생한다. 구간을 검수했다는 것은 모든 모델과 모든 속도로 검수했다는 뜻이 아니다.

## 연결 설계

전신 클립은 관절 회전과 필요한 루트·골반 위치를 함께 고려한다. 하체 회전만 복사하고 골반 이동을 누락하지 않는다. 부분 클립은 안정된 기본 대기 위에 검수된 관절만 혼합한다. 흉곽·어깨·목의 연결을 보지 않고 팔만 강하게 돌리지 않는다.

블렌드 가중치 0에서는 기본 포즈, 1에서는 선택 방식의 목표 포즈가 되어야 한다. 위치·회전·표정별 혼합 의미를 명시한다. 카메라 컷 때 블렌드 시간을 초기화하지 않는다. 역방향 스크럽과 특정 시간으로 점프했을 때도 같은 자세가 나오는지 확인한다.

## 검사 항목

| 검사 | 데이터 검사 | 화면 검사 |
|---|---|---|
| 발 접지 | 접지 구간의 발 월드 위치 변화 | 바닥 미끄러짐·뜀 |
| 골반 연결 | 골반 높이와 다리 변환 | 무릎과 몸통 분리 |
| 제스처 | 손·어깨 이동량과 관절 범위 | 과장·팔 교차·옷 충돌 |
| 시선 | 타깃과 눈·머리 방향 | 허공 응시·사시처럼 보임 |
| 얼굴 | 표정/입 모양 트랙 혼합 | 눈동자·깜빡임·입 표현 |
| 끝 자세 | 클립 끝과 대기 차이 | 복귀 순간 튐 |

위치 오차 허용치는 캐릭터 신장과 프로젝트 단위로 정한다. 고정 수치를 전 모델에 적용하지 않는다. 의도적으로 발을 떼는 구간은 접지 검사에서 구별한다. 카메라에 안 보이는 발도 장면 연속성에 필요하므로 검사한다.

## 실패 복구 순서

원본 정상 여부 → 리타기팅·축·스케일 → 골반/루트 누락 → 부분 마스크 → 블렌드 → 시선·표정 → 카메라 순서로 원인을 좁힌다. 모델 눈이 안 보이면 카메라 각도 문제인지 재질·텍스처 문제인지 분리한다. 없는 제스처를 임의 뼈 회전으로 만든 결과는 검수된 모션과 같은 등급으로 등록하지 않는다.
