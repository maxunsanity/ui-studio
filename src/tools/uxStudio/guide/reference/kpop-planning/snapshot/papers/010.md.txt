# 010 · 미션풀 — 매일 덕질

**이 문서는** 초기(9월 말) 기획 때 쓴 **옛 컨셉 기록**이에요. 요약: 매일 덕질 [미션](삼중AI_공용_20260929/산출/시스템기획/S11_미션.md) 풀. 지금 게임의 미션은 [S11 미션](삼중AI_공용_20260929/산출/시스템기획/S11_미션.md)과 미션 표를 따르고, 이 문서는 아이디어 재료로만 남겨 둬요.

**보는 법** 지금 규칙이 궁금하면 [S11 미션](삼중AI_공용_20260929/산출/시스템기획/S11_미션.md)을 먼저 보세요. 이 문서는 덕질 행동 예시나 표현을 찾을 때만 읽어요. 같이 여는 시뮬레이터: [미션 시뮬레이터](/docs/planning/game-simulator.html?module=simulator_module_mission).

**지금 상태** 이 문서 내용은 게임에 그대로 들어가지 않았어요. 미션 기능 자체는 개발됐어요(미션 시뮬레이터). 여기 적힌 덕질 미션 풀을 쓰는 것은 현재 개발되지 않음, 진행 중이에요.

폰이 현장이다. 출석·새로고침·스밍·짤·라이브처럼 **매일 돌아오는 ○ 바닥**이 이 풀의 본체다.  
**키우기 렌즈:** 신인초에는 같은 ○도 “내가 키운다”로 크게 느껴지고, 성장후로 갈수록 습관·바닥으로 내려간다. 이미 뜬 아이돌 체크리스트가 아니라, **아직 작은 무대를 같이 지키는 호흡**으로 깐다.

## 보드 힌트

- 이 풀은 **바닥의 뼈대**. 칸 수 고정 [보드](삼중AI_공용_20260929/산출/개발진행기획_v01/콘텐츠별_v03/P74_설명.html)에서 절반 가까이를 ○로 채워도 어색하지 않다.
- 신인초 보드에서는 출석·새로고침·D-day의 **감정 가중**을 살짝 올려 “키운다” 감각을 살린다.
- 성장후·사장근처로 갈수록 같은 미션은 자동·습관 칸으로 내려가고, 시즌 ●가 위에 얹힌다.
- 일코·가계부·구독 점검은 “가벼운 현실” 칸으로, 무거운 돈 미션(015)과 톤을 나눈다.
- 플랫폼 브랜드명 대신 **팬앱 출석 / 팬플 라이브**처럼 상황어로 표기한다.
