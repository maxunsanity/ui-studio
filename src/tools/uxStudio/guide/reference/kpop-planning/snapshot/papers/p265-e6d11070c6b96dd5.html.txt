<p class="flow"><b>메인은 단순하게</b>: 정보창 = 모습 · 이름 · 등급 · 중요 능력 한 줄 · 의상 스킬 요약. 자세한 능력은 「능력 자세히」(포토카드 기존 화면)로 넘김. 꾸미기 · 의상은 하위 화면.</p>

  · <b>의상 = 모습 + 스킬.</b> 부분 조각 = 작은 스킬 1개(축 하나) · 세트 = 세트 스킬 1개 + 같은 세트 조각을 다 입으면 세트 보너스. 효과 종류는 기존 멤버 스킬 표를 그대로 씀. 내 보드에만 · 대전 영향 없음(10/28).<br>
  · <b>적용 과정</b>: 고르면 바로 입어 보기(전신이 바뀜 · 저장 안 됨) → 바뀌는 스킬을 아래 줄에 미리 보여 줌 → 「적용」 → 확인 창(바뀌는 스킬 · 판정 상한) → 저장 · 정보창과 HUD 얼굴이 바뀜. 적용 안 하고 나가면 확인 창.<br>
