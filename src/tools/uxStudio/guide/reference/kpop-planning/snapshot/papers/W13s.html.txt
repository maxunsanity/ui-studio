<h2>0. 한 줄</h2>
<p><strong>안 사도 같은 무대에 서고, 사면 더 빨리 가고 더 많이 간직합니다.</strong> 매일은 카드팩, 시즌마다 패스, 굿즈는 게임 밖 상품입니다.</p>
<ul>
<li>이게 아닌 것: 사야만 열리는 진행, 확률형 곡 뽑기, 굿즈를 게임 속 보상으로 주기, 아이돌 카드 ★ 합성 판매, 시즌이 끝나면 산 것이 사라지는 구조.</li>
</ul>
