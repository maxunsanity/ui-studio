# D01 · 구도·샷 크기·시점 결정

문서 버전: 1.0 · 갱신: 2026-09-22 · 상태: 제작 참조 초안 / 실제 씬 검수 전

## 원리와 근거

샷 크기는 대상을 얼마나 담는가, 각도는 어느 방향에서 보는가, 카메라 높이는 어디서 보는가에 해당한다. 세 값은 따로 결정해야 한다. 근접 구도는 표정을 읽기 좋지만 주변 관계를 덜 보여준다. 높은/낮은 시점의 감정적 의미는 맥락에 따라 달라진다. [Adobe 촬영 구도](https://www.adobe.com/creativecloud/video/production/cinematography/camera-shots-and-angles.html), [Yale 촬영 분석](https://filmanalysis.yale.edu/cinematography/).

이하 순서와 수치는 우리 카툰 캐릭터를 위한 설계안이다. 영화 교재의 고정 규칙으로 사용하지 않는다.

## 카메라를 고르기 전 필요한 정보

장면이 전달할 정보 한 가지, 주목 대상, 동작 범위, 얼굴 리그의 표현 범위, 화면비, 자막 영역을 먼저 기록한다. ‘예쁘게’라는 지시만 있으면 눈·얼굴을 읽기 쉬운 안정된 구도를 첫 후보로 하고 극단적인 렌즈나 기울기는 별도 후보로 둔다.

| 구도 | 우리 씬에서 필요한 이유 | 설정할 기준점 | 실패하기 쉬운 부분 |
|---|---|---|---|
| 공간 소개 | 두 배우의 거리와 방 구조 설명 | 배우 묶음과 주요 배경 | 너무 멀어 배우를 구분 못함 |
| 전신 | 발부터 손끝까지 행동 확인 | 전체 몸과 동작 범위 | 기본 자세만 맞추고 손짓 때 잘림 |
| 미디엄 | 얼굴과 작은 손짓 동시 확인 | 머리·가슴·손 움직임 | 손이 하단 자막 뒤로 사라짐 |
| 얼굴 근접 | 감정 변화 읽기 | 눈 중간·턱·머리 장식 | 코 과장·머리카락/눈 가림 |
| 주관 시점 | 특정 인물이 보는 대상 공개 | 관찰자 눈 위치·대상 | 누가 보는 화면인지 모름 |

머리의 최상단이 모자나 장식이면 얼굴 영역과 장식 영역을 따로 측정한다. 장식을 포함하는 컷과 눈을 강조하는 컷에 같은 바운딩 박스를 강요하지 않는다. 모델 전체 박스 중심을 얼굴 타깃으로 삼지 않는다.

## ‘얼굴 클로즈’ 지시의 처리 순서

1. 사용자가 지정한 컷의 촬영 대상과 해당 시점의 머리 뼈 위치를 읽는다.
2. 현재 화면비에서 머리·눈·턱의 화면 좌표를 계산한다. 입·눈 표현을 확인한다.
3. 카메라 거리 후보를 줄이되 얼굴이 왜곡되거나 앞머리에 가려지면 거리와 화각을 함께 조정한다.
4. 시선 방향에 여백을 남길지 정면 구도로 할지 대사 의도에 따라 선택한다.
5. 컷 시작·중간·끝을 검사한다. 고개를 숙일 때 턱이 잘리면 타깃 또는 구도를 조정한다.
6. 배우 모션·대사·다른 컷은 그대로 두고 선택 카메라의 변경만 기록한다.

## 프로젝트용 예시 콘티

A가 B를 기다렸다는 장면이라면 첫 컷은 두 사람의 거리를 보여준다. ‘조금 기다렸어’는 작은 손짓을 담는 미디엄, B의 놀람은 얼굴 근접이 후보가 된다. 모든 대사를 얼굴 컷으로 바꾸면 가까워진 이유가 사라지므로 감정 변화 지점을 먼저 정한다.

카메라 높이를 바꾸는 경우 ‘B가 압박을 느낀다’라는 의도와 낮은 시점 후보를 연결하되, 기본 눈높이와 비교한다. 낮은 시점이 무조건 권력을 뜻한다고 해석하지 않는다. 얼굴 형태가 어색해지면 각도 강도를 줄인다.

## 실패 진단과 수정

| 관찰한 문제 | 먼저 확인 | 수정 후보 |
|---|---|---|
| 얼굴이 작다 | 대상이 배우 전체 박스로 잡혔는가 | 얼굴 기준점으로 다시 구성 |
| 눈이 안 보인다 | 재질·앞머리·표정·카메라 가림 | 모델 문제와 촬영 문제를 분리 |
| 코가 과장된다 | 가까운 거리와 넓은 화각 | 거리 확보 후 화각으로 크기 조정 |
| 말하는 사람이 헷갈린다 | 자막 화자와 화면 대상 | 청자 반응 의도를 표시하고 대사 유지 |
| 구도가 갑자기 튄다 | 이전 컷과 크기·위치 변화 | 중간 컷 또는 더 명확한 차이 검토 |
