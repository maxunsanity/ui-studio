# 케이팝몬스터즈 기획서
UI 스튜디오 서버의 `/ui-studio/source/guide/reference/kpop-planning/index.html`에서 엽니다. 각 문서는 `?doc=문서키`로 바로 열거나 원본 파일을 내려받을 수 있습니다.

전달 시 이 디렉터리 전체와 바로 옆의 `kpop-lobby/`를 UI 스튜디오 도구에 포함합니다. `snapshot/`에는 등록 원본, HTML의 짝 Markdown, 문서에 직접 포함된 로컬 첨부를 동봉합니다. 실제 설계를 함께 전달할 때는 케이팝몬스터즈의 별도 `ui-studio/` 작업 폴더(설계·자산)도 필요합니다. 전달받은 환경에서 UI 스튜디오로 그 작업 폴더를 열어 등록합니다.

정리 기준은 케이팝몬스터즈 기획서 툴의 `data/planning_doc_catalog.csv`입니다. 스냅샷 시각은 목록에 표시합니다. 이력과 보관본은 문서 범위에서 볼 수 있습니다. 실행 시뮬레이터와 코드 연결은 경로가 표시되는 참조 항목입니다. HTML의 자체 실행 코드는 읽기 전용 열람에서 동작하지 않으며 원본 그대로 내려받을 수 있습니다.

최신 원본으로 갱신할 때 UI 스튜디오 루트의 `python3 scripts/snapshot-kpop-planning.py <케이팝몬스터즈_루트> <새_빈_스냅샷_경로>`를 실행하여 새 사본을 만듭니다. 원본·누락·첨부 수를 확인한 뒤 기존 `snapshot/`을 백업하고 교체합니다.
