제작비는 기존 지갑과 발매 원장을 읽습니다. 재킷과 앨범 소개를 확인하는 단계에서 제작비를 다시 차감하지 않습니다. 준비 실패 시 같은 초안을 유지합니다. 현재 시뮬레이터 첫 제작비 예시 5,000원은 운영 확정값과 구분합니다.

발매 전에도 홍보·버스킹과 기본 보드 판정을 유지합니다. 첫 정상 발매 뒤 같은 6개 칸의 간판·조명과 곡별 활동 연결이 달라집니다. 콘서트장에 도착하면 내 공연을 음악 앱에 보냅니다. 송출 요청은 도착 사건·내 팀·발매곡·채널과 확정 견적을 사용한다. 송출 후 잔액 = 보유 돈 − 확정 송출비. 부족액 = max(0, 확정 송출비 − 보유 돈). 견적 미확정 또는 잔액 부족 시 송출을 막는다. 운영 요율·재화 계약은 발란스 대기. 음악 앱 수신과 비용 차감은 같은 요청으로 한 번만 확정하고 실패하면 비용을 돌려주거나 청구하지 않는다. 시연 숫자는 운영값과 구분한다. 1번 START 통과 후 누적 보상을 지급하고 보드 HUD에서 알립니다.
