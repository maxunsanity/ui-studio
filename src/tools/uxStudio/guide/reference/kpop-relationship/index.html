3. 포토카드와 선택 상태

카드는 포토카드의 얼굴과 하단 이름 배치를 재사용한다. 3열·최대 2줄, 한 페이지 최대 6장이다. 10명은 6장과 4장으로 나뉜다. 좌우 버튼과 스와이프로 이동하고 현재 페이지를 표시한다.

아이돌 탭은 현재 팀원, 스태프 탭은 배치된 스태프 카드만 표시한다. 한 장을 누르면 같은 높이 안에서 왼쪽은 선택한 인물, 오른쪽은 가까운 상대 최대 3명과 라포를 표시한다. 아이돌을 고르면 다른 팀원, 스태프를 고르면 현재 팀 아이돌이 상대다. 가까운 관계에 기록이 없으면 빈 상태를 표시한다. 아래 관계 목록은 선택 전후에 같은 범위를 유지한다.

스태프 관계 행에는 아이돌과 스태프의 이름, 직무, 현재 보너스와 다음 단계까지 남은 값을 표시한다. 역할별 상세에서는 라포 값과 직무에 맞는 스케줄을 볼 수 있다. 팬클럽 회장 짝과 덱 효과는 기존 별도 행을 유지한다.

4. 하단 관계 목록 · 함께 보내기
항목동작
표시 범위팀원의 관계를 한 쌍당 한 줄로 표시한다. 2명은 1쌍, 5명은 10쌍, 10명은 45쌍이다. 항목은 스크롤하며 위 카드 페이지와 독립적으로 동작한다.
정렬기본은 「관계 안 좋은 순」이다. 「관계 좋은 순」으로 전환할 수 있다. 양쪽 모두 관계 화면의 가까움 값으로 정렬한다. 동점은 쌍의 순서를 유지하고, 가까움 값이 없는 관계는 끝에 둔다.
한 줄 구성두 얼굴과 이름 → 관계 단계와 긴장 상태 → 다음 단계에 필요한 값 → 함께 보내기. 최고 단계와 처음 봄을 해당 상태 그대로 표시한다. 행 본문은 둘 사이 모달을 열고, 함께 보내기는 해당 두 사람을 전달한다.
함께 보낼 스케줄시트 상단에 두 이름을 고정한다. 스케줄 시스템에서 현재 이용 가능한 모험 중 추천 인원이 2명인 항목을 먼저 보여준다. 행은 장소 썸네일, 제목, 시간, 추천 인원, 편성하기로 구성한다. 시안 예시는 지방 행사 가는 길 25분, 숙소 작은 방 30분, 연습실 복도 35분이다.
추천 없음 · 전체 보기추천할 스케줄이 없으면 빈 상태를 표시한다. 「스케줄 전체 보기」에서 두 사람을 유지한 채 스케줄 목록으로 이동한다. 선택 가능 여부와 참가 조건은 스케줄의 기존 기준을 사용한다.
편성과 출발추천 항목의 「편성하기」는 해당 스케줄 편성 화면을 연다. 두 참가자는 채워진 상태이며 남은 자리는 기존 편성 화면에서 확인하거나 바꾼다. 티켓과 참가 조건은 출발 버튼을 누를 때 스케줄에서 검증한다.
전달과 복귀기존 스케줄 모듈 요청의 참가자 두 키와 스케줄 식별자를 사용한다. 전체 보기에서는 참가자 두 키를 유지한 채 목록을 연다. 스케줄에서 돌아오면 관계 탭, 카드 페이지, 선택 인물, 정렬, 목록 스크롤을 복원한다. 실제 게임의 데이터 수신과 복원 검수는 연동 항목이다.
5. 관계도

상단 「관계도」는 팀원을 표시하는 바텀시트다. 2명은 마주 보는 두 노드와 한 연결선, 5명과 10명은 원형 배치다. 첫 진입은 현재 팀 인원으로 열린다. 2명·5명·10명 전환은 검수 시안에서 배치를 확인하는 기능이다.

전체 · 가까운 사이 · 긴장 중 · 처음 봄으로 선을 거른다. 얼굴을 누르면 해당 인물의 연결로 좁히고, 선을 누르면 아래에 해당 쌍의 상태와 「함께 보내기」를 표시한다. 관찰되지 않은 값은 공란 상태로 둔다.

관계 효과 · 현재 적용과 다음 단계

기존 둘 사이 / 스태프 짝 / 팬클럽 회장 짝 모달에서 이름과 단계 바로 아래에 「관계 효과」를 표시한다. 표시 순서는 적용 대상 → 현재 효과 → 다음 단계나 적용 조건이다. 라포 게이지와 추천 스케줄은 그 아래에 둔다.

시각화 규칙. 아이돌은 신뢰·이해 평균 37.5와 긴장 48을 같은 축의 막대로 비교한다. 스태프는 현재 +10%와 라포 +2일 때 +15%를 나란히 놓고, 기본 100의 예시 결과 110 → 115를 붙인다. 회장은 기본 팬 획득 +10%에 짝 보너스 +5%를 적용한 +10.5% 예시를 세 칸으로 보여준다.

화면현재 효과다음 변화와 사용자 행동
아이돌 둘 사이선택 쌍의 신뢰·이해·긴장이 알려지면 클릭 성장 감소 요인을 표시한다. A–D 예시는 긴장 48이 신뢰 34와 이해 41의 평균보다 높다. 멤버별 실제 감소율은 각자가 속한 전체 쌍의 축 평균을 성장 계산에 넣은 결과를 별도 표기한다.다음 단계에 필요한 축과 값은 라포 진척으로 표시한다. 단계가 오른 뒤의 성장률은 결과를 계산할 수 있을 때 보인다. 긴장 관계를 함께 보낼 때는 기존 스케줄 입구를 쓴다.
스태프 짝선택한 아이돌이 해당 직무의 스태프 카드로 능력을 얻을 때 적용되는 보너스를 직무명과 함께 표시한다. 보컬·랩 예시의 현재 단계는 2, 카드 효과는 +10%다.예시는 라포 18에서 2가 더 오르면 3단계의 +15%다. 최고 단계에는 「최고 단계」를 표시하고, 해당 직무의 추천 스케줄은 기존 버튼으로 연다.
팬클럽 회장 짝회장 덱의 실제 보유 효과명과 적용값을 표시한다. 가능한 항목은 팬 획득, 팬 돈 획득, 악개 감소, 건물 팬 상한이다. 팀 최고 단계가 데뷔조 이상이면 합류한 아이돌의 회장 짝 보너스 중 가장 높은 값 하나로 기존 덱 효과를 강화한다. 완성 조건이 붙는 효과는 덱의 조건을 따른다.선택 짝의 다음 보너스와 팀 실제 적용값을 따로 보여준다. 다음 단계에서도 다른 짝이 더 높으면 적용값을 유지한다. +5%에서 +10%는 현재 세팅 검수 예시이며 최종 발란스 결정 대기다.

값과 상태 표기

  • 기록 대기는 「—」를 사용한다. 필요한 기록이 있어 계산 결과가 0이면 「성장 감소 없음」 또는 「카드 효과 보너스 없음」을 표시한다.
  • 회장 짝은 데뷔 전이면 「데뷔조부터 적용」을 표시한다. 해금 뒤에는 「현재 적용 중」 또는 「다른 짝 적용 중」을 표시한다. 같은 최고값을 가진 짝이 여럿이면 팀 적용값 한 건만 표시하고 특정 짝을 임의로 선정하지 않는다.
  • 하단 목록은 해당 쌍의 효과를 한 줄로 요약한다. 아이돌은 「클릭 성장 감소 요인」, 스태프는 「카드 효과 +n%」, 회장 행은 「덱 효과 보기」로 상세에 진입한다. 실제 효과는 상세창에서 동일한 원본으로 계산해 표시한다.

데이터 근거는 rapport_effect_map.csv와 멤버별 성장 계산, staff_rapport_bonus.csv와 카드 효과 계산, president_rapport_bonus.csv·skill_effect_rule.csv와 회장 덱 계산이다. r11 세부 와이어프레임은 대표 예시와 기록 대기를 보여준다. 잠금과 실제 적용 상태 및 보유 덱 수치는 게임 데이터가 연결되면 표시한다.

관계 아이템 사용 · 상세에서 적용

아이돌 둘 사이, 스태프 짝, 팬클럽 회장 짝 상세창의 하단에 아이템 사용을 둔다. 상세에서 고른 짝이 그대로 전달된다. 스케줄은 기존 버튼에서 열고, 보유한 관계 아이템은 바텀시트에서 사용할 수 있다.

상태표시와 조작
아이템 선택 · 바텀시트 374×748적용 대상, 사용 가능한 관계 아이템, 보유 수량, 상승할 라포 항목과 예상값을 표시한다. 아이돌 쌍은 아이템이 지정한 축으로, 스태프와 회장 짝은 해당 짝 라포로 연결한다. 아이템 행을 선택하면 사용 전후 및 달라지는 관계 효과를 확인한다.
1개 적용하기대상 짝과 선택한 아이템의 보유량 및 적용 가능 여부를 다시 확인한다. 조건을 충족하면 한 번만 차감하고 라포를 바로 갱신한다. 처리 중에는 버튼을 잠그고, 보유량이 바뀌거나 적용할 수 없으면 사유를 표시한다.
결과 · 모달 팝업 374×748대상 짝, 오른 축이나 라포, 적용 전후 값, 바뀐 단계와 보너스, 남은 수량을 표시한다. 단계 변화가 없으면 오른 라포를 표시한다. 와이어프레임의 확인 → 아이템 시트 → 닫기 순서로 기존 상세창에 돌아간다. 게임 연동 시 효과와 수량을 새 기록에서 다시 읽는다.
보유 없음 · 확인 대기보유 0이면 「사용 가능한 관계 아이템이 없어요」를 표시한다. 아이템이나 적용값을 확인할 수 없으면 「기록 대기」와 비활성 버튼을 표시한다. 수치가 비어 있으면 「—」로 표시한다.

r11이 시연하는 적용 전후는 검수용이다. 아이돌 A–D 신뢰 34 → 40, 보컬·랩 짝 라포 18 → 20, 회장 짝 1 → 2단계는 동작 확인 예시다. 제품 아이템의 이름·획득처·대상 축·상승량·보유 수량과 실제 차감은 아이템과 라포 데이터 계약으로 연결한다.

6. 리소스 · 데이터

카드와 초상은 포토카드 검수용 자산, 장소 썸네일은 스케줄 장소 자산을 재사용한다. 쌍의 단계·수치·효과는 라포 기록, 스태프 단계와 보너스는 스태프 라포 표, 추천·시간·참가 조건은 adventure_route의 현행 값을 읽는다. 샘플의 자리와 미기록 값은 제품 수치로 옮기지 않는다.

7. 남은 검수

엔진 연동 후 실제 참가 가능 여부, 편성 복원, 라포 상승과 게임 리소스를 검수한다. 7018 편집판에서는 페이지 버튼으로 카드 페이지를 바꾼다. 손가락 스와이프와 실제 게임의 편성 데이터 연동은 후속 검수 대상이다.
