# 킹샷 샘플 작업 진입점

현재 직접 지시와 상위 지침이 우선입니다. samples/kingshot만 담당하며 7018에서 독립 UI를 제작합니다.

1. README.md→docs/ui/PRODUCTION_GUIDE.md→ui-inventory.json→sample-data.json→ui-tokens.json→최신 보고 순으로 읽습니다. 원본 캡처와 제작 화면을 비교합니다.
2. ui-studio/guide/는 공통 가이드 사본입니다. PROGRESS.md에 다른 샘플의 과거 이력이 섞여 있으므로 킹샷의 진행·완료 근거로 사용하지 않습니다. 킹샷 정본은 전용 보고·inventory·저장 설계입니다.
3. 모든 화면·부품·부모·입력·상태·연결 변경은 실제 Studio UI로 합니다. 외부 설계 JSON 작성·API 주입·숨은 모델/DOM 변경을 금지합니다. 저장 JSON은 읽기 전용 감사만 허용합니다.
4. 그림은 새로 만듭니다. 캡처 잘라 붙이기 금지. 게임 장면만 새 정지 그림으로 처리하고 글자·수량·타이머·버튼·입력은 native 요소로 분리합니다.
5. 원본 영상/PNG와 원화는 보존합니다. 자신의 문서도 수정 전 백업하고, 변경 원화는 버전을 올립니다. 자체 임시는 _작업/codex/만 사용합니다.
6. 자동 진입과 없는 페이지를 만들지 않습니다. 다른 건물이나 시대가 다른 마을을 정확한 대체 대상으로 연결하지 않습니다. 승인·원본 동등·전체 클릭 검수를 자칭하지 않습니다.
7. 같은 역할은 공통 규격을 따릅니다. native 복제 후 부모/로컬 좌표/이름/상태 참조를 확인하고 저장·재열기·실화면 검수를 거칩니다. 네비는 클릭한 한 항목만 확대하고 배지보다 앞에 표시합니다.
8. 공통 소스·다른 샘플·7007·서버/LSB·예약은 수정하지 않습니다. 다른 담당과 필요한 협의는 현재 사용자가 허용한 범위만 따릅니다.
