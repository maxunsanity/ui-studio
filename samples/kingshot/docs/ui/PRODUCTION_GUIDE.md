## 실제 실수와 재발 방지

- 이름/문구에 DOM fill만 쓰면 미반영될 수 있습니다. native AX 입력→Tab→재표시/저장값을 확인합니다. 빈 글자는 Backspace로 삭제 확인합니다.
- 긴 조작 중단 뒤 부분 반영을 먼저 확인하고 재생성하지 않습니다. 저장 후 다시 열어 도구 응답을 회복했으며 단일 버튼/짧은 묶음으로 조립합니다.
- 실제 옵션 ‘겹쳐 열기’/‘전체 맞춤’ 등 목록을 보고 고릅니다. 존재하지 않는 명칭을 추측하지 않습니다.
- 체크박스 변경 후 패널 재그리기로 도구가 실패를 보고할 수 있습니다. checked를 읽고 중복 클릭하지 않습니다.
- 숨긴 DOM의 존재를 표시 여부로 시험하지 않습니다. 궁수 설명은 DOM에 남아 있어도 실제 rect/display를 확인하면 숨겨져 있습니다.
- 주방 업그레이드를 도시 센터로 연결했던 오류를 제거했습니다. 판틀이 비슷해도 건물/내용이 다르면 정확한 대상이 아닙니다.
- 헤더의 따뜻한 탄색·청록 버튼 림/명도/두께, 인물 배너2남1여, 궁수 세로 비율을 원본 재대조 후 v002로 고쳤습니다. v001은 보존합니다.
- 버튼이 뒤에 가려지지 않도록 바탕 뒤/글자 앞/CTA 앞 순서를 실제 화면에서 봅니다. 대화창의 이름과 다음 표시는 대화창 부모 안으로 옮겼습니다.
