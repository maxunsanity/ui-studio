이 폴더는 현중이 직접 제작을 요청한 Royal Match 참고 샘플 정본입니다. 일반 사용자 신규 제작은 이 샘플을 다른 작업 폴더로 native 사본 준비 후 편집합니다. 이 배정은 다른 샘플·공통 툴 소스·서버를 수정하는 권한이 아닙니다.

1. README와 docs/ui/research.html, ui-inventory.json, sample-reference-data.json, sample-data.json, ui-tokens.json, connections.json을 읽습니다. 조사·계획·실제 저장·실화면 검수를 구분합니다.
2. 제공 영상은 reference/video-analysis-20261118/source.json 기준 원본입니다. 캡처는 분석 전용이며 제품 이미지에 쓰지 않습니다. 게임은 새로 그린 스틸, UI는 native 입력·글자·자원·프레임으로 분리합니다.
3. 제공 화면 분석 → 유사 샘플 실제 계층·규격·상태·연결 데이터 제시 → 대상 차이 정리 → native 조립 순서를 지킵니다. 504×894는 이 영상의 제작 기준이며 다른 게임에 강제하지 않습니다.
4. samples/royal-match/ui-studio/project.json의 workspace와 ux-9f500ab8 실제 revision을 매번 확인합니다. native 상세/디자인 가이드의 조작으로만 설계를 만들고, 저장 JSON을 외부에서 수정/주입하지 않습니다.
5. 정상/눌림 원화는 공통 캔버스와 기준점 유지. 상태 원화는 contain 비율 때문에 입력 크기와 다르면 얇아 보일 수 있습니다. 메인은 전용214×100, 일반 버튼240×80. 상태별 개별 alpha crop 금지입니다.
6. AX 현재 선택 → setValue → Tab → 재표시 → 파일 저장 → 읽기 대조. 이번 환경에서 locator.fill로 이름/문구/이미지 경로를 넣은 뒤 실제 값이 안 남는 경우가 있었으므로 성공 판정하지 않습니다. 그림은 native 파일 선택으로 등록합니다.
7. UI 복사 버퍼는 재진입/페이지 갱신 후 비어 있을 수 있습니다. 먼저 현재 레이어/미저장 여부를 확인하고 저장 원본 버튼을 다시 복사합니다. 복제 중 시간이 끊겼으면 새 이름이 적용되지 않은 ‘복사’ 부품을 확인합니다. 중복 생성으로 덮지 않습니다.
8. 빈 프로젝트는 native 폴더 등록 전에 ui-studio/를 임의 생성하지 않습니다. project.json 없는 보관영역을 만들어 놓으면 잘못된 폴더로 거절됩니다. 이번 자기 빈 폴더는 _작업/codex/video01/asset-staging/으로 이동 보존했습니다.
9. 생성 그림의 의미·추가 소품·투명 여백을 확대해서 검사합니다. 방 v001의 사다리/천은 v002에서 제거, 아바타 v001의 왕관/망토는 v002에서 제거했습니다. 실패판을 삭제하지 않습니다. AI 생성 원본과 생산 WebP, SHA/프롬프트/교체 이유를 보존합니다.
