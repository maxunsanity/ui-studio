# AI 진입점

1. 상위 게임 프로젝트의 AGENTS.md와 최신 직접 지시를 먼저 따릅니다. 이 문서는 상위 지침을 변경하지 않습니다.
2. README.md → guide/AI_GUIDE.md → guide/EXISTING_GAME.md → integration.md → project.json 순으로 읽습니다.
3. conversionDecision=pending이면 설계 저장 전 사용자 선택이 필요합니다. independent이면 기존 게임 파일을 변경하지 않고 ui-studio 안에서만 독립 UI를 만듭니다.
4. convert는 변환·연결 요청 기록이며 완료가 아닙니다. 별도 실제 게임 조사·백업·구현·회귀 검수 없이 전체 변환 완료를 주장하지 않습니다.
5. 가이드 사본과 원본·설계·자원을 임의로 덮어쓰거나 삭제하지 않습니다. 현재 미완료 범위는 guide/PROGRESS.md를 확인합니다.
