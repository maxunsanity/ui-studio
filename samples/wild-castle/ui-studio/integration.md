# 기존 게임 연결·변환 기록

현재 선택은 project.json의 conversionDecision·conversionDecidedAt·conversionStatus가 정본입니다. 폴더 열기는 게임 루트 AGENTS.md·소스·저장파일을 읽거나 변경하지 않습니다.

- pending: 사용자 선택 대기. 설계 읽기만 허용합니다.
- independent: 기존 게임 UI를 변경하지 않고 ui-studio 내부에 독립 UI 소스를 저장합니다.
- convert / requested: 사용자 변환·연결 요청만 기록했습니다. 자동 변환은 미구현이며 기존 게임 UI 조사·백업·연결 변경·회귀 검수를 거친 후 별도 결과를 남겨야 합니다.

전체 변환 완료: 미실행·미검수. 기존 UI 목록·게임 연결·누락·미지원 화면: 아직 조사하지 않았습니다.
