# 와일드 캐슬 독립 UI 샘플 설계

현중이 요청한 기존 영상 샘플 방식의 연속 작업입니다. 공식 게임명은 와일드 캐슬 TD - 왕국 건설 타워 디펜스/Funovus이며 공식스토어/개발사 자료와 영상의 구조·아바타를 대조했습니다. 원게임 실행/변환이 아니라 독립 UI 샘플입니다.

접근: 새 standalone 웹앱/외부 설계JSON 대신 기존7018 native Studio로 제작합니다. 캡처를 직접 제품 그림으로 쓰지 않고 새 그림과 native 글자/입력/상태를 조립합니다. 사용자에게 이미 정해진 제작 방법으로 진행하며 새 기능·게임 수치를 만들지 않습니다.

6대표뷰/5판틀: 로비, 골드부족안내, 연속상점, 전투표시, 재능, 프로필. 같은 목록의 스크롤이나 숫자 변형은 추가페이지로 세지 않습니다. native logical390×780, 상단66/하단60. 원본의 검은padding/녹화표시 제외. 기존샘플의 실제값은 sample-reference-data.json에 보존합니다.

W에서 동일ID의 구조와 확인된연결을 먼저 보존, P에서 입력·탭·닫기/복귀, U에서새스틸/아이콘·팝업/버튼재질을 적용합니다. Store원본스크롤탭 자동spy/특정구간자동점프는현재툴의지원여부를확인하고미지원이면연속스크롤을유지하며미확인으로남깁니다. 별도허구의페이지/결제/승리/설정/이름변경창을만들지않습니다. 실제전투는UI상태와새정지그림으로만표시합니다.
