## 지시와 출처

현중 「같은 마을 맵에서」, 「한 화면에 안 보이는 게 단점」, 「그림을 더 키울 수 있잖아」, 「그럼 이렇게 해서 UI 스튜디오에 적용」. 흑백 9개 건물 확대 시안, P81 및 P106, 7007 건설 기획 목록, 11/24 디펜스 수리비 정리, 기존 7018 건설 r4·HUD r17·작업 명세를 읽었다.

## 반영

- 건설 r6 · 30개 편집 보드 · 163개 연결. 390×844 화면 안에 9시설. 카드 121×188 안에 흑백 외관 117×144, 배지·이름·0~30단계 별도 레이어. 선택은 시설별 같은 마을 확대 보드로 이동한다.
- HUD r19 · 25개 편집 보드 · 137개 연결. 메인·솔로·도착·게이지 가득 보드에 동일 마을과 9건물 터치 영역. 지붕 위 증설·수리 상태 예시. 기존 디펜스 전투 보드 데이터 보존. 디펜스 결과의 수리 버튼은 같은 마을의 해당 연습실로 연결한다.
- +1·최대 증설 견적, 0단계 짓기, 재화 부족, 완공, 대전·디펜스 파손 및 수리 완료. 시안 상태에서 증설 후 25/30, 첫 건설 후 1/30, 수리 후 단계 유지 및 파손 해제 갱신 예시를 표시한다. 수리비는 마지막 건설비의 50%.
- 7018 P265 건설·HUD, 건설 작업 명세와 HUD 작업 명세를 갱신했다. preview.mjs에 등록된 직접 진입 화면의 닫기·돌아가기만 원래 화면에 돌아가는 분기를 추가했다. 기존 7018 작업에서 사용하는 복귀는 그대로 보존했다.
