# 7018 스케줄 편성 수정과 몬스 출동

작성자 codex(단이) · 2026-11-23 10:31 KST · 제안(검수 대기)

현중의 기획 근거 확인, 직접 수정, 몬스 출동 진입, 서로 다른 콘텐츠 연출 설명 요청을 반영했습니다.

- P265 스케줄의 목적·범위와 ② 편성, 규칙서 P241의 편성 조건을 확인했습니다. 조건 충족은 현재 후보를 바탕으로 판정합니다. 자동 편성은 버튼 입력입니다.
- r16 · 56개 화면 · 192개 연결. 아이돌 편성에서 「편성 수정」 또는 인원 조건 줄로 후보를 바꿉니다. 새 후보에 따라 케미 예시가 바뀝니다. 몬스 탭에서 출동 목록과 편성으로 이어집니다. 토끼 선택 해제 상태에서는 목 속성·3단 필수 조건과 출동 버튼을 함께 확인할 수 있습니다. 「자동 편성」을 누르면 준비 상태로 돌아갑니다.
- 아이돌 탐험의 장소 배경·대사 4장면과 몬스의 기존 3D 전투 연결을 각각의 편성 화면과 명세에 표시했습니다. 홈의 공동 샘플 카드가 몬스 편성으로 이어지던 연결도 제거했습니다.
- 검수는 저장·재열기, 1440px 실제 마우스로 아이돌 편성 수정 → 후보 → 자동 편성 → 배경과 대사, 430px 실제 마우스로 몬스 탭 → 편성 → 조건 부족 → 자동 편성 → 진행 → 3D 전투 연결 → 결과를 확인했습니다. 소비자 모델에서 필수 조건 부족 시 출동 차단과 결과 검수도 통과했습니다.
- 실제 보유 후보 전체, 자동 추천식, 출동 조건 재평가 엔진, 전투 실행은 게임 연결 항목입니다. 2차 시안은 대표 후보와 상태를 보여 줍니다. 7018만 갱신했으며 커밋하지 않았습니다.
