현중 직접 요청. 전체 미리보기 마무리, 로비 컬러 3D 아이돌과 수령 가능한 팬 선물 표현, 시설별 팬 100명 묶음 표기, 보드 성장과 시설별 콘셉트를 세부 와이어프레임 부품·추가 UI 기획서에 반영, HUD 페이지 분리.

- `src/tools/uxStudio/overview.mjs`, `overview-layout.mjs`, `grapes-pilot.html`, `planning-documents.json`에 캔버스 5구역, 구역별 보기 설정, 기존 화면 직링크 자동 분류를 적용했습니다.
- `src/tools/uxStudio/guide/reference/kpop-planning/common-ui-finish/`에 전체 미리보기, 보드 성장·대표 팬 기획서, 굴리기에서 새 기획서로 잇는 경로, 검수 기록을 저장했습니다.
- 주요 저장판은 HUD r84, 새 도시 r12, 주간 페스티벌 r6, 건설 r18, 앨범 r9, 스케줄 r28, 오디션 r12, 인트로 r6, 프로필 r25, 굴리기·도착 부품 r4입니다.

## 전체 미리보기와 HUD 구역 검수 · 2026-11-27

- UI 스튜디오 현행 설계 22개, 767개 화면을 브라우저의 430px·1440px에서 각각 열었습니다. 1,534회에서 선택 대상 불일치, 빈 화면, 확인된 이미지 수신 실패, 화면 전체 가로 넘침은 각각 0건입니다. 화면 표시 검사와 각 버튼의 기능 검사는 범위가 다릅니다.
- HUD r84의 캔버스는 로비 15개, 주사위·보드 16개, 도착·찬스 16개, 출석·광장 선물 13개, 새 도시 4개로 나뉩니다. 다섯 구역 전환, 기존 01번 주소의 자동 구역 선택, 로비 미리보기 연결을 확인했습니다. 새 도시 저장판은 새 도시 구역에서 불러옵니다. 기본 진입의 카드 수를 비교했으며, 최초 네트워크 응답 시간은 계측하지 않았습니다.
- 시설별 팬 지도 → 댄스 100명 1개 말풍선, 콘서트장 430명 4개 말풍선 + 30명, 콘서트장 무대 앞, 건설 상세 → 보드 칸 4·24·25 강조를 확인했습니다. 로비 컬러 3D 5인, 음료 카트 수령 전후 교체, 주간 페스티벌 HUD 종료 → 종료 화면을 확인했습니다.
- 창작곡 선택/부족, 스태프 선택/친구 확정, 오디션 이어하기, 팀 리더 선택·변경, 크루 개인 미션 수령 경로는 대표 화면에서 직접 조작했습니다. 보드 성장 부품 → 첫 앨범 발매 전후 화면을 눌러 확인했습니다.
- 캔버스·미리보기 회귀 42개 통과. 기획 패널을 포함한 시험에서는 52개 중 51개 통과했습니다. 기존 실패 1개는 등록표 첫 항목을 HUD로 가정합니다. 작업 전 백업과 현재 모두 첫 항목은 새 도시입니다. 시설·앨범·스케줄·오디션·리더·프로필 저장 연결 6개를 재검사했습니다.
- 남은 제품 확인은 시설별 팬 실집계와 실제 증감, 멤버 능력에 따라 보드 외형을 바꾸는 조건, 수령 보상과 활동 결과의 게임 저장 연동입니다. 화면의 100명, 430명과 최대 인물 네 명은 검수 시안입니다.
