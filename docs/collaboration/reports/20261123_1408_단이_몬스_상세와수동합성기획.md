# 몬스 상세와 수동 합성 UI 기획

작성자 codex(단이) · 2026-11-23 14:08 KST · 제안(검수 대기)

현중 직접 요청 「상단에 합성을 누르는게 좀 그러네..그냥 버튼만」, 「그럼 기획서를 제작해봐」. 몬스 정보는 단계·희귀도·모은 수만 표시. 합성 공식은 화면에서 숨긴다.

## 반영

- 7018 P265의 몬스 탭을 목적, 흐름, 뒤로, 상세, 규칙, 데이터, 남은 결정, 이력, 그림 발주의 9항목으로 정리했다. HUD의 방패 게이지 경로와 보관함 진입을 구분했다.
- 보관함은 높은 단 정렬, 속성 복수 선택과 하단 바로가기 3종이다. 상세는 단계·희귀도·모은 수와 하단 「합성하기」「컨디션 게임」만 둔다. 기분 아이템은 기분 화면에서 쓴다.
- 같은 종과 같은 단계의 두 마리가 있을 때 하단 합성하기를 켠다. 사용 후 결과, 보유 수, 다음 버튼 상태를 갱신한다. 최신 작업 명세와 편집 저장판 r4를 문서에서 구분했다.
- 시안에서 모은 수는 현재 보유량이고, 후보가 여러 단계면 높은 단계부터 처리하도록 그렸다. 기존의 10단 행복 전환 처리 시점, 배치 충돌 우선순위, 간식 발란스는 확인이 필요하다.

## 확인

- Chromium에서 상세 정보 3가지, 상단 탭 제거, 하단 합성 가능·사용 뒤 비활성, 컨디션 게임 복귀와 360px 가로 범위를 확인했다.
- 7018에서 P265 몬스 탭과 작업 명세를 열어 9개 항목, 상세 전후 이미지, 간식 아이콘이 표시되는 것을 확인했다. 관련 기획 패널·기획서 모음 시험 12개 통과.
- 기존 7018 편집 저장판 r4와 7007 원본에 대한 변경은 이번 문서 작업 범위 밖이다. 실제 기분 아이템과 합성 트랜잭션 연동은 대기다.
