# 크루 누락 화면 보완과 재검수

codex(단이) · 현중 직접 요청 · 7018

P265 크루 탭과 작업 명세 r6, 클로드 크루 와이어 원안, 게임 시뮬레이터 크루 커뮤니티 소스의 관리·파일 정책을 비교했습니다. r6은 대표 이미지를 보여 주지만 교체 편집 화면을 담지 않았고, 관리 메뉴와 크루 만들기가 시뮬레이터 연결에서 끝났습니다.

## 결과 · 제안(검수 대기)

- 7018 크루 세부 와이어프레임 r7, 52개 보드·190개 연결. r6의 20개에서 32개 화면과 상태를 보완했습니다.
- 크루 관리 → 크루 정보 → 대표 이미지 교체 바텀시트 → 교체 후 정보·공개 프로필. 형식·용량 오류는 가운데 모달에서 이전 그림을 유지하도록 안내합니다. 크루 정보에는 공개 소개 편집을 배치했습니다.
- 관리의 다섯 메뉴를 각 화면에 연결했습니다. 가입 신청 목록·수락·거절, 크루원과 운영진 권한 바텀시트, 내보내기·위임·탈퇴 확인, 공지 작성·공개 범위와 고정, 모집 여부와 글을 포함했습니다.
- 발매 앨범을 확인하는 크루 만들기와 제한 상태, 정원 도달 상태, 음악 공유 완료·거두기, 음원·뮤비가 비어 있는 출품판, 크루 알림 목록을 추가했습니다. 투표가 열려 있는 크루장 메인에서 대표작 선정을 잠그고, 투표 마감 검수 상태에서 열었습니다. 크루장에게는 위임 전 일반 탈퇴를 열지 않습니다.
- [7018 P265 크루 탭](http://127.0.0.1:7018/ui-studio/source/guide/reference/kpop-planning/index.html?doc=P265#crew)과 [작업 명세](http://127.0.0.1:7018/ui-studio/source/guide/reference/kpop-crew/index.html#crew-audit-r7)의 화면 수·상태 순서·창 유형·갤러리 및 보드별 등록 자료를 갱신했습니다.
- 근거는 P265 크루 3~6장, 클로드 크루 와이어 원안, 케이팝몬스터즈 src/simulator/music-career/crew-community-panel.mjs 123~135, 168~203줄과 data/music_career/crew_community.json 233~243줄입니다. PNG·JPG·WebP 최대 2MB와 브라우저 내부 저장은 시뮬레이터 기준입니다.

## 검수

- Chromium 1440px·430px에서 52개 화면의 390×844 논리 크기·이미지 로드·가로 넘침을 확인했습니다. 모달의 중앙 및 바텀시트의 하단 좌표와 모든 연결 대상도 검사했습니다.
