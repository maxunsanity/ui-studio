## 제작판 · 2026-11-23 16:20 KST

- 프로필·의상 r9, HUD r15, 포토카드 r33, 관계 r12, 스케줄 r20, 상점 r10, 미션 r12, 크루 r8. 저장 후 API 재열기로 일치 여부 확인.
- 팀·아이돌 정보는 HUD와 포토카드가 동일 화면을 열고, 포토카드 수집과 능력은 하위 화면으로 연결. 아이돌 필터 탭과 출발 HUD를 돌아가기로 복원. 솔로·판 중 열람과 적용 제한은 같은 정보 구조의 상태 시안.
- 오시온은 개인 의상 전환, 한서아는 단체복 전환을 시각화. 한서아 전용 개별 장비 교체 품목은 검수 예시 추가가 필요한 범위.
- 착용 시안의 현재 외형은 HUD·포토카드 인물 목록·관계·관계 경유 스케줄 편성·공연에 전달. 수집 카드 그림과 스케줄의 엽서·탐험 결과는 고정된 기록 시안 사용. 스케줄의 장소·이야기 배경은 기존 연출 방식 유지.
- 상점 꾸밈은 공개 준비판으로 추가. 이벤트·시즌 패스에 의상 카드와 수령·착용 대상 선택을 추가. 판 진행 중 구매 후 확인·보상 수령은 가능하고 바로 입기는 비활성 상태 시안.
- 크루원과 월드 카드의 팀 마크·이름은 팀 꾸미기 검수 데이터와 같게 표시. P100 첫 팀 이름 무료와 이후 유료 안내는 P100 HTML과 기본 MD 모두에서 7018 확인 화면으로 연결.
- 기획·명세는 7018 P265 K-01~14와 변경 대상 8개 작업 명세에 기록. 문서에서 누르면 7018 내부의 검수 화면을 여는 경로를 제한적으로 허용. 다른 서비스 주소나 등록되지 않은 쿼리 입력은 기존 제한을 적용.
