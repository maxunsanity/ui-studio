# 몬스 모달과 바텀시트 정리

codex(단이) · 현중 직접 요청 · 7018

첨부 4장과 r11 저장판의 좌표·연결을 비교했습니다. 입장 대상 이름과 컨디션 숫자의 세로 영역이 겹치고, 단문 확인과 팩 관리가 모두 높이 748 프레임을 사용하고 있었습니다. 팩 흐름에는 보관함 숫자와 시험 상황이 충돌하는 표시와 확인창을 건너뛰는 연결이 있었습니다.

## 결과

- 7018 몬스 r12, 48개 보드·197개 연결. 390 × 844 기준 화면에서 가운데 모달은 폭 342, 하단 시트는 폭 374를 사용합니다. 입장은 354, 일시정지는 176, 종료는 208, 팩 열기는 308, 행복 교환 확인은 212, 팩 결과는 270 높이로 정리했습니다. 팩 시트는 높이 320, 수호 몬스 선택은 478입니다.
- 입장 확인에서 아이돌·수호 몬스, 컨디션, 전투 정보를 순서대로 정렬했습니다. 일시정지와 종료는 같은 전투 위에 띄웁니다. 공통 부품에는 중앙·하단 창의 형태를 붙였습니다.
- 팩 수는 시트에 표시합니다. 첫 등록/보유 종 결과는 같은 팩 확인을 거치며, 결과 확인은 보관함으로 돌아갑니다. 공용 행복 차감 전 별도 교환 확인을 추가했습니다. 수량 0·행복 부족·취소·복귀를 포함한 시퀀스를 P265 몬스 탭과 작업 명세에 기록했습니다.
- 기획 근거는 P243 몬스 규칙서 3장·4장과 P223 몬스 보유 구조 3장·4장, 7018 P265입니다. 7018 수동 열기·교환 흐름과 P223 시뮬레이터 자동 개봉의 운영 정책 차이를 명세에 기록했습니다. 시뮬레이터 데이터와 저장 동작은 이번 작업 범위 밖입니다.
- 백업은 docs/planning/_backup/20261123_단이/몬스창정리의 r11 설계와 P265·작업 명세·등록 원문입니다.
