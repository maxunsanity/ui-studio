# 오디션·앨범 송출·HUD 검수와 기획 전달

작성자 codex(단이) · 2026-11-25 10:30 KST · 제안(검수 대기). 수신은 총괄(이스라트)이며 아래 삭제·이관 사유는 기획 정의(클로드) 전달용입니다.

## 현중 직접 지시

오디션은 기존 시안의 전신과 버튼으로 수정하며 선택 이후 탈락 카드가 움직이는 순서를 설명합니다. 스태프는 획득 시 미배치로 명함집에 들어가고 아이돌은 확정 시 즉시 팀에 합류합니다. 보드 도착 시 내 공연을 음악 앱에 송출하고 비용을 계산합니다. 한 바퀴 정산 모달과 앨범의 불필요한 화면을 정리합니다. 정보 후속과 출석·복귀·팬 선물의 필요한 UI는 실제 메뉴와 HUD에 연결합니다.

## 삭제·이관 이유

| 기존 화면·항목 | 처리 | 이유와 남은 기능 |
|---|---|---|
| 공연 관람형 ‘같은 공연 보기’ | 보드 위 ‘내 공연 송출’ 바텀시트로 교체 | 현재 도착 사건의 내 팀·내 발매곡을 음악 앱에 보냅니다. 공연 이미지와 제목을 확인하고 송출비·보유금·차감 후 잔액을 한 화면에 표시합니다. 별도 관람 진입은 이 흐름에서 제외합니다. |
| 한 바퀴 정산 영수증 모달 | 세부 와이어프레임과 연결에서 제거 | 1번 START 통과 시 보상이 보드에 자동 반영됩니다. 안내는 HUD의 도착 띠를 쓰며 곡별 내역은 기존 내 앨범 상세에 남습니다. |
| 스카우트 결과의 ‘바로 앉히기’와 확인창 | 기존 개봉 결과에서 제거 | 스태프 영입은 명함 보유와 배치를 나눕니다. 결과에서 미배치 상태를 표시하고 ‘명함집 보기’로 기존 목록을 엽니다. 기존 명함 상세와 배치 조건·교체 확인이 배치를 맡습니다. |
| UI 스튜디오 홈의 독립 ‘정보 후속’ 카드와 검수용 정보 첫 화면들 | 독립 메뉴에서 제외하고 기존 화면에서 진입 | 로비와 포토카드의 같은 아이돌 정보에서 상태·서사에 접근합니다. 포토카드 개봉 결과에서 카드 획득 영수증으로 들어갑니다. 컨디션에서 배정을 건너뛰는 검수용 행도 제거했습니다. |
| 독립 ‘출석·복귀·팬 선물’ 홈과 광장 버튼 목록 | 새 HUD 진입으로 대체하고 옛 설계를 보존 | 설정에서 출석·복귀에 접근합니다. 광장의 물체 자체가 입력이므로 별도 목록을 거칠 이유가 없습니다. 복귀 결과 안의 중복 요약 행도 제거했습니다. |
| 대진의 반복 화면 | 캔버스에는 대표 순서만 배치 | 실제 선택 분기는 모두 작동합니다. 왼쪽과 오른쪽 어느 쪽을 선택해도 살아남은 후보가 같은 자리에 남습니다. |
