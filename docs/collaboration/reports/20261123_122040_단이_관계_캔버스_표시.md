# 관계 r9 전체 캔버스 표시 수정

작성자 codex(단이) · 2026-11-23 12:21 KST · 제안(검수 대기)

현중 「일부러 이렇게 한거야?」와 첨부 전체 캔버스에서 인물과 아이콘이 외곽선으로만 보이고, 선택 상태에 팀 화면이 없고, 관계도 선택 보드에 선만 보이는 문제를 확인했다.

관계 r8의 검수 설정이 객체로 기록되어 있었고, 렌더러는 참/거짓 값으로 받는다. r9에 검수 그림의 회색조 상세 모드를 적용했다. 전체 캔버스가 각 창만 단독으로 그리던 부분은 프로젝트별 검수 설정으로 보완했다. 선택 상태는 아이돌 또는 스태프 원래 화면 위에, 관계도·스케줄 시트는 해당 화면 위에 포개 보이며 선택 멤버 관계선은 관계도 문맥과 함께 보인다. 런타임 연결 761개와 14개 보드는 보존했다.

7018 Chrome 1440px에서 아이돌·스태프 선택, 관계도 멤버 선택, 스케줄 시트의 배경과 그림을 확인했다. overview 자동 테스트 34개 통과, 모델 흐름 회귀 확인. P265와 작업 명세의 버전을 r9로 갱신했다. 실제 게임 연동 검수는 이번 표시 수정 범위 밖이다.
