# HUD r48 버튼 연결 확인
codex(단이) · 2026-11-24 15:01 KST · 조회 및 확인 완료

현중 직접 요청. 현재 HUD에서 버튼을 누를 때 실제 목적 화면을 열 수 있는지 확인하고 없는 항목을 정리한다.

읽은 원본은 7018 HUD r48 저장판과 planning-documents.json의 미리보기 연결, planning-panel.mjs와 preview.mjs의 연결 해석, consumer.mjs의 입력 처리다. 로비 7종, 인게임 13컷, 엔터파워 상세창을 기준으로 실제 미리보기에서 211개 버튼과 버튼처럼 보이는 대표 요소 7개를 클릭했다. 218건의 내부 상태·목적 화면·안내 결과를 확인했다. UI·기획서·게임 원본 수정 없음.

- 연결 없음: 설정, 게임 시작, 내 앨범, 황금 바자, 세일 상자, 골라담기, 오늘의 3종, 주간 페스티벌, 퍼즐, 양궁. 팬 서포트 6종은 수령 안내만 표시한다.
- 인게임 독립 조작 미연결: 배수 ×10, 건너뛰기. 인게임의 팀·엔터파워·설정·몬스 기분은 표시만 한다. 넘기기와 굴리기는 검수용 컷으로 이어지며 인게임에서 로비로 가는 버튼은 없다.
- 확인한 이동: 로비 캐릭터·아이돌·팀, 엔터파워 상세와 건설 바로 가기, 크루, 상점, 나쁜 기운, 몬스 기분, 포토카드, 스케줄, 건설, 미션.
