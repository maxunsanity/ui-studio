# 도시 습격 디펜스 · 나쁜 기운 9단계

작성 codex(단이) · 2026-11-25 13:41 KST · 진행

현중 직접 지시. 첫 게이지보다 2번째가 빠르고 이후 9번째까지 순차 가속. 단계별 습격과 관련 UI를 기획하여 7018에 추가한다.

## 적용 · 2026-11-25 13:46 KST · 제안(검수 대기)

- 기존 디펜스 r16에서 r18로 갱신했다. 기존 11개에서 26개를 추가하여 37개 저장 화면, 연결 74개다. 추가 화면에는 1차 3컷, 위험 1~9단계, 가속 자동 시연 9컷, 로비 8/9, 편성·전투·결과와 부품판이 있다. 수동 9단계를 캔버스 한 행에 배치했다.
- 엔터파워 최고 도달 500 이상에서 첫 만충을 방어하지 않고 플레이를 계속할 때 붉은 게이지가 오른다. 5분 경과로 위험 수가 자동 상승하지 않는다. 2~8단계는 서로 다른 시설의 위험 예고이며 기존 선두 시설 방어로 누적을 끊을 수 있다. 9에서 3구역 도시 방어를 연다. 구역 방어의 결과에서 실제 피해 시설만 표시한다.
- HUD의 기존 나쁜 기운 정보에서 도시 습격 시연에 접근한다. 1단계 기본색, 붉은 단계·구역·표적은 색과 숫자를 함께 쓴다. 재사용한 도시 3D 원화는 컬러, 공통 2D 프레임은 기존 9슬라이스다. 안개·공중 보스 원본은 부품판에서 열 수 있다. 기존 방어 준비·건설 복귀를 확인했다.
- 기획 근거는 P88R01 지도 엔트리, P171/P172의 엔터파워 문턱·현행 CSV와 저장판 HUD r73, 디펜스 r16·건설 r13이다. 7018 문서 `guide/reference/kpop-planning/snapshot/papers/P265.html.txt:2262`, 디펜스 명세 `guide/reference/kpop-defense/index.html:6`, 위험색 예외 `presentation.css:121`, 저장 설계 kpop-defense-ui r18.

## 검수

- 스키마 및 저장 후 API 재조회 일치. 단계별 표적 수 1~9와 시연 시간의 단조 감소, 기존 만충 방어 대상 연결을 확인했다. 7018 1440px·430px에서 HUD 나쁜 기운 → 도시 시연 → 9단계 → 편성 → 3구역 전투 → 결과 → 건설 → 시연 복귀를 실행했다. 대표 화면 가로 넘침·전투 이미지 오류 0.
