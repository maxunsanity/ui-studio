# 인게임 HUD 33컷 한 줄 조립과 부품표
codex(단이) · 2026-11-24 13:15 KST · 제안(검수 대기)

현중 직접 지시. 최근 인게임 HUD 시안을 UI 스튜디오 한 줄에 모두 적용하고 공통 부품과 기획서를 정리한다.

원본. 굴림·도착·판정·보상 전체 15컷, 지문과 대사가 아래에서 위로 쌓이는 4컷, 룰렛 누적 4단계, 보드 칸별 13컷, P265 HUD와 기존 작업 명세. 공통 HUD r38에 사용한 상하단과 9슬라이스 프레임 및 이미지 부품을 참조했다.

같은 작업공간의 별도 설계 kpop-ingame-hud r1 저장. 원래 설계 58장에 새 34장을 더하면 UI Studio 단일 설계의 60장 한도를 초과하므로 분리했다. 연결 보기에서 연출 33장과 부품 1장 전체의 높이 좌표가 같음을 실제 캔버스 DOM으로 확인했다. 보드·틀·아이콘·문구를 편집 가능한 레이어로 배치했다. 39개 부품을 작업 명세와 에디터 항목에 등록했다.

7018 저장판 1440px에서 굴림·보상·지문·마지막 대사·누적·잭팟·부품의 7개 화면을 캡처했다. 연결은 컷 순서를 보는 검수 조작이다. 실제 주사위, 자동 룰렛, 보상 지급, 대사 선택, 건너뛰기는 게임 연동 범위다. 모바일과 플레이는 사용자 검수 예정이다.
