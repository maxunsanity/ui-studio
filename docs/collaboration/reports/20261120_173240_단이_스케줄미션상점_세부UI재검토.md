## 변경

- 스케줄 r6 · 29보드. 현장 사진처럼 투시가 있는 배경을 카드에서 쓰고, 진행·이야기에는 화면 폭을 채웁니다. 탐험 4·출동 3장면과 별도 인물·몬스 레이어, 순차 탐색, 건너뛰기, 각 결과, 공격 미리보기, 전체 폭 하단 조작을 연결했습니다. 출동·탐험 상태를 분리했고 캔버스는 좌→우에 편성과 두 장면 분기, 다음 행에 도감·기록·소식·부품을 배치했습니다.
- 미션 r10 · 11보드. HUD 재화 이미지·같은 탭 격자·버튼 규격, 5개째 체크포인트와 전체 받기 충돌 해소, 차트 1위 확대 연출과 주간 보상 안내 분리. 이벤트 마일스톤과 종류별 아이콘을 유지하며 두 단계표와 신규 화면을 작업 명세에 보였습니다.
- 상점 r9 · 10보드. 재화 아이콘이 있는 가격·헤더, 성장 5단계별 팩 외형, 예시가 들어간 캔버스 확인창, 선택한 상품과 일치하는 구매 확인·완료 및 부족 분기. 캔버스를 특가·상품·확인·완료 행과 채움·부족·루비 행으로 정렬했습니다.
- UI 스튜디오 `src/tools/uxStudio/bindings.mjs`의 정적 예시 표시를 `overview.mjs`·`sample-preview.mjs`에서 사용. `model.mjs`의 시험 구매 성공 대상과 `preview.mjs`의 명시적인 시험 처리 모드를 추가했습니다. 실제 지급이나 원화 결제는 게임 연결 대상입니다.
