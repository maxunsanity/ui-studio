현중 직접 지시. 출발·이동·도착 세 장을 먼저 그린 뒤 첫 컷을 제외하고 굴림과 결과의 배경에 반영한다.

- HUD `import-6604270d` r52 → r53. 첫 굴리기 입력과 로비를 보존하고 회전·눈 확정·이동·도착·판정·보상·지문·대사 12컷에 기존 월드와 타일을 사용하는 1.9배 카메라 영역을 추가했다. 전체 화면이 이동하지 않으며 상하단과 안내 부품은 화면에 고정된다. 예시 위치 1번 → 3번 → 4번. 14~15칸은 영역 안에 들어온 타일 중심 기준이다.
- 7018 r53 저장 재조회. 브라우저에서 12컷을 열었다. 대표 이동 및 결과 화면 1440px·430px 맞춤·오류 이미지 0. 비교 검사에서 첫 컷과 기존 상하단 HUD·연결 일치. 자동 카메라 추적 애니메이션과 실제 게임 연동은 미실행이다.
