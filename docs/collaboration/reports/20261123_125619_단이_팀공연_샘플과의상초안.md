# 팀 보기 5명·10명 공연 배치와 의상 영향 초안

작성자 codex(단이) · 2026-11-23 12:56 KST · 제안(검수 대기)

현중 「5명 10명 샘플」, 「모자른 그림은 중복」, 「리소스 늘리지 말고」, 「같은 이미지 인데 연출된 공간에서 공연하는 듯한 위치」.

포토카드 팀 보기 2인 원본과 관계 프로젝트의 기존 전신 자산을 확인했다. r30에 5명 V자, 10명 앞뒤·좌우 공연 포메이션을 추가했다. 공연 공간은 편집 가능한 LED 배경, 조명 빔, 무대 바닥과 돌출 무대 레이어로 구성했다. 기존 전신 자원 5종만 재사용했고 자원 업로드는 0건이다. 기존 팀 화면은 유지했다. r30 전체 58개 화면, 275개 연결이며 샘플 자체는 2개와 6개 연결이다.

P265와 포토카드 작업 명세에 5명·10명 샘플을 반영하고 의상 갈아입기의 기존 콘텐츠 영향 초안을 넣었다. 대상은 HUD·아이돌과 팀 정보, 포토카드, 관계, 스케줄과 공연이다. 실제 의상 시스템과 다른 콘텐츠 UI 수정은 기획 검수 범위로 남아 있다.

모델에서 인원 수와 기존 자원 참조, 상호 전환, 팀 상세 연결을 검증했다. 7018 브라우저에서 두 샘플의 전신 5개·10개 디코딩을 확인하고 캡처를 보존했다. 7007 및 게임 구현은 변경하지 않았다.
