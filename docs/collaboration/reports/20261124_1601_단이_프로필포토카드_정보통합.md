# 프로필·포토카드 정보 통합

## 작업

- 시작 홈의 두 작업 진입을 **정보** 한 항목으로 합쳤다. 케이팝몬스터즈의 프로필과 포토카드 저장본을 연결하는 작업 순서 페이지에서 8개 흐름과 30개 대표 화면을 열 수 있다. 각 화면에 실행·편집 링크를 연결했다.
- 포토카드 저장본에서 유입 연결을 모두 확인한 뒤 미사용 복제 화면 두 개를 정리했다. 오시온 공통 아이돌 정보 복제판(원본은 프로필 `idol-info`)과 팀 선택 닫힘 복제판(공통 팀 정보와 열림 화면 사용)이다. 포토카드 r42 58화면, 프로필 r16 60화면. 실행과 편집은 각 저장 설계를 직접 참조한다.
- 원본 및 변경 대상은 `home-data.mjs`, `home.mjs`, `planning-documents.json`, `guide/reference/kpop-information/`, 프로필·포토카드 가이드, 포토카드 저장 설계. 7018 공식 저장 API를 사용했다.

## 확인

- 시작 홈의 케이팝몬스터즈 → 정보, 순서 8개, 썸네일 30개 표시와 이미지 오류 0 확인. 아이템 상세, 포토카드 능력, 팀 세트 선택 실행 팝업과 편집 URL을 확인했다. CSS 1600px에서 가로 넘침 없음. 모바일 브라우저 크기 변경이 이 탭에서 반영되지 않아 430px 실측은 미확인.
- 홈 관련 자동 시험 20/20 및 메뉴 링크 계약 확인. 전체 회귀 739개 중 728 통과, 11 실패. 11개는 통합 전 백업을 적용한 격리본에서도 동일 재현했다.
