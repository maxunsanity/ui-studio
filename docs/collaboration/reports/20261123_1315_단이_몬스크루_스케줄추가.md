# 7018 몬스·크루 세부 와이어프레임과 스케줄 추가 기획

codex(단이) · 2026-11-23 13:15 KST · 진행

현중 직접 요청 「추가된 기획에 따라 추가 ui 넣고..추가 기획인 몬스와 크루도 진행」.

7007 P265와 몬스·크루 초안, 스케줄 와이어프레임 4차와 P241을 확인했다. 7018 HUD r9, 스케줄 r18, 포토카드 r30, 관계 r11을 원본으로 대조했다. 스케줄은 목표 지정·변경과 등급 상태를 추가하고, 몬스와 크루는 HUD에서 접근하는 별도 2차 편집 화면으로 만든다. 기존 HUD·스케줄 설계는 API로 저장 전 revision을 백업한다.

## 결과 · 제안(검수 대기)

- HUD r11 · 정보 메뉴 다섯 항목의 순서를 정본과 맞췄다. 「크루」와 「몬스」에 새 저장 설계를 연결했다. 몬스 기분 메뉴의 「몬스 정보」도 보관함으로 연결했다.
- 스케줄 r19 · 기존 56개 화면에 열림 문턱 잠김, 목표 그림 지정·변경, 도감 상태, 출처 화면의 「목표 조각」을 추가했다. 동쪽 나쁜 기운 입구의 6,731은 `data/game/adventure_route.csv`의 열림 엔터파워다. 지난 등급은 선택 목록에서 제외하고 기존 출동 기록은 유지하는 규칙을 P241과 명세에 반영했다.
- 몬스 r4 · 54개 화면·상태, 305개 연결. 보관함 27종의 속성과 보유 상태, 보유·미보유 상세, 지킴이·수호·출동, 배치 바꾸기, 합성, 팩과 행복 교환을 편집 가능한 요소로 조립했다. 지킴이 상태 등은 원안의 검수 샘플이다. 9슬라이스와 기존 몬스·보스 그림을 재사용했다.
- 크루 r3 · 20개 화면·상태, 99개 연결. 크루원·크루장·9주차·미가입 검수 입구, 출품판·음악 공유 동의·뮤비 단일 투표·대표작 선정·멤버 관리·월드 총공·가입 신청과 취소를 조립했다. 검수 입구별 시점은 실제 권한이나 회차 정보를 대신하는 샘플이다. 크루 재화·레벨·미션·홍보는 P192 최신 규칙을 따른다.
- 두 신규 설계의 창은 374×748로 통일했다. 모달은 중앙(Y=48), 바텀 시트는 하단(Y=96)이다. 크루 공유 모달을 가리던 선택 상태 레이어의 영역을 적용 버튼으로 줄였다. 토글의 시각 레이블은 카드 제목을 사용하고 접근성 이름은 유지했다.
- 7018의 P265에 HUD·스케줄 갱신과 몬스·크루 탭을 추가했다. P192의 11/23 우선 규칙과 P241의 등급 구간을 가져왔다. P265에서 클로드 원안, 편집 캔버스, 화면별 작업 명세, 캡처로 연결했다. 몬스와 크루는 내 작업에 표시된다.

## 확인

- 저장 API의 revision 검사를 통과하고 4개 최종 설계를 다시 읽어 저장 응답과 비교했다.
- Chromium 실제 클릭으로 HUD 정보 → 몬스 보관함 → 상세·배치 모달 → 보관함 → 지킴이·수호·출동 → HUD, 기분 메뉴 → 몬스 정보 → HUD, HUD 정보 → 크루 → 출품판·공유 창 및 투표 확인 → HUD를 확인했다. 스케줄 도감에서 목표를 바꾸고 편성 화면의 목표 조각 표시도 확인했다.
- 데스크톱 폭 1440과 모바일 폭 430에서 대표 12개 화면씩 확인했다. 논리 화면은 390×844이며 검수 캡처는 미리보기 표시 영역을 잘라 보존했다. 대표 화면의 가로 넘침 및 표시 이미지 로딩 오류가 없었다.
- P265의 몬스·크루·스케줄 탭과 작업 명세 3개가 실제 로딩되었다. 계획 문서·미리보기 관련 25개 시험을 통과했고, 워크스페이스 범위별 미리보기 연결 검사를 4건 통과했다. 전체 `npm test`는 734개 중 724개 통과, 기존 보고에 기록된 10개 실패가 재현됐다.
- 캡처 17개는 `docs/planning/_검수캡쳐/20261123_1315_단이_몬스크루_스케줄추가/`에 있다. 이전 설계 및 문서 백업은 `docs/planning/_backup/20261123_단이/1315_몬스크루스케줄/`에 있다.

## 남은 검수와 연동

게임 데이터에 따른 스케줄 등급·드랍·자동 목표 변경, 몬스 배치·재화·팩 지급 및 3D 전투, 크루 권한·공유·투표·출품 원장과 콘텐츠 실행은 게임 연동 항목이다. UI 스튜디오 미리보기는 샘플 흐름과 메뉴 연결을 검수한다. 7007과 게임 데이터의 실제 적용은 별도 동기화 범위다.
