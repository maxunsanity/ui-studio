# 관계 효과 UI 기획과 7018 r10

작성자 codex(단이) · 2026-11-23 12:36 KST · 제안(검수 대기)

현중 「그거에 대한 ui 기획을 만들어봐」, 「관련 ui도 추가하고」. 아이돌 둘 사이, 스태프 짝, 팬클럽 회장 짝 세 상세를 포함한다.

7018 P265와 관계 작업 명세에 적용 대상·효과·다음 단계·기록 대기·회장 덱 적용 상태를 기록했다. 관계 r10에서 세 상세창의 효과 카드, 기록 대기, 목록 요약과 공통 부품 보드를 편집 가능 요소로 반영했다. 화면 14개와 연결 761개는 유지했다. 원본은 클릭 성장의 멤버별 라포 평균, 카드 효과 계산 및 스태프 보너스 표, 회장 덱 계산 및 회장 보너스·스킬 효과 표다.

7018 Chrome 1440px에서 효과 카드 다음에 이어지는 정보와 위치 중첩을 확인했다. 430px에서 회장 창의 너비를 확인했다. 관계 모델 기존 흐름을 검증한 뒤 저장 API로 r10 재열기를 확인했다. 아이돌 실제 적용값과 회장 잠금·적용 짝 상태, 보유 덱 값은 게임 연동 대상이다. 회장 +5%/+10%는 검수 예시다.
