# 관계 효과 시각화와 아이템 사용 · r11

codex(단이) · 2026-11-23 12:44 KST · 제안(검수 대기)

## 지시
현중 「좀더 디테일 하고 시각화」, 「아이템으로 올릴 수 있다고」, 「기획서부터 작업 명세까지 모두 동기화」.

## 반영
관계 상세 r10, 클릭 성장의 멤버별 관계 평균, 스태프 카드 효과와 회장 덱 효과 계산을 대조했다. r11에 아이돌 긴장과 신뢰·이해 평균, 스태프 현재와 다음 단계, 회장 덱 적용 전후 계산을 편집 요소로 배치했다. 아이돌·스태프·회장 상세에서 선택 짝을 넘기는 아이템 바텀시트와 적용 결과 모달을 만들고 부품 보드를 보완했다. 16개 화면과 839개 연결을 저장했다. P265 관계 탭, 작업 명세, 편집 화면 설명과 캔버스 순서를 r11에 맞췄다.

## 확인
모델 검증과 2MB 이하 내보내기, 저장 API 재열기, 아이돌·스태프·회장 아이템 경로와 기록 대기 비활성 상태를 검증했다. Chrome 7018 미리보기에서 1440px 세 관계 효과와 스태프 아이템 전후 → 적용 결과 → 복귀를 검수하고 430px 화면 폭을 확인했다. 캡처는 docs/planning/_검수캡쳐/20261123_124458_단이_관계효과시각화와아이템.

## 남은 범위
검수용 아이템의 상승량·수량은 예시다. 실제 상품 표, 인벤토리 차감, 적용 후 라포 저장과 실제 덱 효과 갱신은 게임 엔진 연결 범위다. 7007은 기존 역할 분담에 따라 이번 7018 작업에서 다루지 않았다.
