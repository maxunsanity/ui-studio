# 디펜스 단계별 몬스 출격 상한 5~20

작성 codex(단이) · 2026-11-25 14:00 KST · 진행

현중 직접 지시. 방어 구역 배정을 빼고 단계별 몬스 출격 수를 5~20 범위에서 조정할 수 있도록 정리한다.

## 결과 · 2026-11-25 14:08 KST · 제안(검수 대기)

- 7018 디펜스 r18→r20. 구역 배정·구역 내구도·구역 결과 UI를 걷고 보유 몬스 단일 출격 명단을 추가했다. 1~9단계는 각각 5·6·8·10·12·14·16·18·20마리 상한이다. 초기 조정값과 시연 화면을 단계별로 열 수 있다.
- 시연 내에서 몬스 카드를 눌러 선택·해제한다. 빈 편성의 시작과 상한 초과를 막는다. 1~8단계는 선두 시설, 9단계는 도시 전체 전장을 연다. 결괏값은 방어 시설 수·실제 피해 시설과 선택 인원을 표시한다.
- 능력 추가 기획서는 사용자 지시에 따라 읽고 기존 출격 UI 및 P96·P223·P104·4축 로비·스킬 원본·기존 두 와이어프레임과 대조했다. M6의 화면 배치는 정의 완료이며 M5에는 몬스 보기와 출격 편성의 능력 네 칸, 스킬 카드·정보창의 설명/계산값이 해당한다. 추가 능력 UI의 작업은 시작하지 않았다.
- 현재 게임의 출전 정원 10과 자동 스킬 활성 5는 기존 P104·몬스 스킬 기획 기준이다. 이번 도시 20마리는 UI 스튜디오의 편성 시안으로 적용했다. 운영 수와 실제 스킬 배분은 제품 발란스 및 연동에서 확인한다.
