# 7018 관계 r8 2차 세부 와이어프레임

codex(단이) · 2026-11-23 12:17 KST · 제안(검수 대기)

## 지시
현중 「그럼 이제 ui 스튜디오 세부 와이어 프레임 작업해」, 「나중에 좀더 디테일 하게는 마우스로 직접 컨트롤 해서 보면서 해」, 「지금은 그냥 해」.

## 반영
승인된 관계 미리보기와 P265, r6, 스케줄 r18의 편성·장소를 읽고 실제 7018 workspace 설계 kpop-relationship-ui를 r8로 저장 후 다시 열었다. 화면·상태 14개, 연결 761개다. 아이돌과 스태프의 3열 2줄 카드와 페이지 전환, 같은 자리의 선택 인물·가까운 관계, 팀 45쌍의 양방향 정렬, 2·5·10명 관계도와 멤버별 선, 함께 보낼 스케줄, 기록 대기 공통 창과 부품 보드를 편집 요소로 구성했다. 공통 프레임은 9슬라이스다. P265/작업 명세/캔버스 화면 설명을 같은 저장판에 맞췄다.

추천 경로 키와 참가자 둘은 저장 데이터에 명세했다. UI 스튜디오 모듈 요청 시연에서 시뮬레이터 ID가 나오는 것까지 검수했다. 실제 게임으로 스케줄 데이터가 인계되는지와 라포 갱신은 별도 연동 검수다. 검수용 인물 이미지가 없는 슬롯과 원본 수치가 없는 쌍은 기록 대기 예시다.

## 확인
모델 검증, 2MB 이하 직렬화 확인, 저장 API 재열기, 1440/430px Chrome 자동 검수를 했다. 카드 페이지와 정렬의 독립, 선택→같은 페이지 복귀, 관계도 인원·분류·멤버별 선, 스태프 선택, 추천 및 전체 목록 참가자 명세를 확인했다. r7 확인 중 탭 대비와 선택용 버튼 노출을 발견하여 r8에서 스킨을 보완하고 재확인했다.

## 미확인
직접 마우스 정밀 조정은 현중 요청에 따라 후속 검수로 남겼다. UI 스튜디오 편집판의 캐러셀은 페이지 버튼으로 조작한다. 손가락 스와이프는 검토용 인터랙션 시안에서 쓴 동작이며 편집판에는 추가 검수가 필요하다. 7007 동기화 및 커밋을 하지 않았다.
