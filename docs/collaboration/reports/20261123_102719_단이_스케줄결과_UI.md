## 지시와 결과

현중의 결과창 재작업, 화면 요소 크기 통일, 스케줄 결과와 관계 라포 기획 확인 요청을 반영했습니다. 스케줄 r15 · 53개 화면 · 170개 연결입니다.

- 결과 5종의 화면 390×844, 장소 배경 390×170, 별점 카드 304×122, 보상 첫 줄과 하단 버튼을 같은 위치로 맞췄습니다.
- 완벽 ★3 검수 상태를 추가했습니다. 부분 성공은 기존 카드팩 ×1 · 주사위 ×5 · 돈 ×500 아래 「받기」, 실패는 빈 보상 상태와 「스케줄로 돌아가기」가 표시됩니다. 몬스 성공의 도감 카드는 보상 바로 아래에 놓았습니다.
- 실제로 오른 동행 관계를 이전 → 현재와 증가량으로 표시합니다. 시안의 아이돌·스태프 값은 이전에 사용하던 예시입니다. 아이돌의 축별 결과값, 해당하는 스태프·회장 기록, 단계 변화는 게임 데이터 연동 항목입니다.
- 관계 기획의 ⑥ 팝업은 단계 상승 때만 표시하며, 여러 짝은 한 장씩 확인한 뒤 원래 결과로 복귀합니다. 7018의 관계 r2에 검수용 ⑥이 이미 있습니다. 실제 결과로부터 자동 호출하는 연결은 게임 연동 항목입니다.
