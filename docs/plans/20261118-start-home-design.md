# UI 스튜디오 시작 화면 설계
상태: 제안(검수 대기). 현중의 '해봐' 및 작업/샘플 구분·새작업 가이드 요청에 따라 실행합니다.

의도: 첫 접속에서 제작을 시작하고 현재 작업을 이어가며 참고 샘플과 사용법을 구분합니다. 기존 독립7018·경량캔버스·상세편집·저장 계약을 재사용합니다.

접근 비교: 기존 샘플 자동진입은 제작과 참고를 혼동시킵니다. 별도 서버나 다른 저장체계는 필요 없습니다. bare /ui-studio/만 가벼운 홈으로 바꾸고 명시 workspace/project·canvas.html·editor=detail 주소는 보존하는 방식을 채택합니다. 제작하기/샘플보기/가이드 세 입구, 내작업과 샘플 별도 목록을 제공합니다.

폴더 분류: 정본 samples/ 바로 아래의 실제 등록 게임 폴더는 참고 샘플입니다. folder-check 및 중첩 ui-studio 등록은 내부 시험/중첩으로 홈에서 제외하며 삭제하지 않습니다. 기타 사용자가 선택한 프로젝트 폴더는 내작업입니다. 이름·revision·independent 여부로 분류하지 않습니다. 새 게임명이 추가되어도 등록 목록으로 표시합니다. 샘플도 제작중일 수 있으며 완성/최종동등을 주장하지 않습니다.

제작: 기존 프로젝트 폴더 관리자와 변환 사전선택을 재사용합니다. 빈 작업은 상세의 빈 설계로, 저장 설계가 있으면 전체캔버스로 이동합니다. 샘플 보기는 저장판 단독 뷰어이고 사본으로 제작은 다른 내작업 폴더에 새 설계ID와 자원을 복사합니다. 원본 샘플/원게임은 수정하지 않습니다. 폴더 열기는 변환 동의가 아닙니다.

성능: 홈에서는 캔버스/Grapes/샘플 그림 전체를 그리지 않습니다. 등록 메타/설계 목록만 읽고 개별 실패를 표시합니다. 임의 HTML/외부 경로 실행/새 패키지/서버 재시작은 하지 않습니다.

증거: 자동회귀와 실제7018 CSS1440/430 홈/가이드/이동을 구분하고 내장 .35 가이드에 새작업 순서·네이밍/규격/리소스 전문 가이드 링크를 연결합니다. 샘플 저장JSON/프로젝트 .4 가이드 자동덮기 금지. 2차 Royal Match 작업은 보존하고 HMR은 저장 안전 시점에만 반영합니다.
