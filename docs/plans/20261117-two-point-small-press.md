# 2점 투시 / 작은 눌림 보완
현중 최신: 먼 윗부분이 짧아져야 함 / 큰 눌림 불필요 / 눈높이선과 소실점 참고.
1. 유저 참고/실패시안 보존. 일반 이론 설명으로 완료하지 않고 실제 점의 소실점 수렴/먼변<가까운변/눌림2논리px를 검증한다.
2. 같은 pinhole camera의 두 소실점과 수평선, 밑면z=0/윗면z=h/눌림z=h-p로 하나의 투영을 계산한다. 카메라 tilt 없이 높이+frame shift로2점투시를 유지한다. 광택보다 기하를 먼저 본다.
3. 네 점의 수렴을 독립 외적으로 검사하고 밑면불변/전상태동일캔버스/모든윗면점이2px이내만이동하는지 확인한다. 수치는 제작 제안이며 원본 카메라/눌림을 관찰한 값이 아니다.
4. 기존 SVG UI 자원 방식을 사용해 계산된 원형에서 입체 전체 Normal/Pressed를 각각 출력한다. 제품3D엔진/새패키지0. 텍스트/외부그림자는 분리한다.
5. 실제 native에서 전체상태graphic과 텍스트그룹을 나누고 이중이동을 없앤다. 저장/held mouse·Space/복원/기기 확인, 원본 r299와타11화면/20edges 보존을 확인한다.
6. 가이드에2점투시 그림/계산결과/작은눌림을 연결하고 실패와미확인을 보고한다. 시각동등/최종승인은 별도다.
