# UI 스튜디오 가벼운 전체 캔버스·제작 3모드 설계

2026-11-18 · codex(단이) · 제안(검수 대기). 현중의 10가지 UX 지시, 3모드 정의, “전체 캔버스는 최대한 가볍게…피그마처럼…오른쪽은 설명…있는 요소만”, 이후 “진행해”를 실행 근거로 합니다.

## 목표와 선택
메인은 화면 관리/전체 선택, 상세는 부모·자식 개별 조립, 가이드는 단위 정밀 배치로 분리합니다. 상단 프로젝트/현재 화면/현재 단계/표현/미리보기 위치를 일관되게 만들고 같은 선택과 workspace를 넘깁니다. 첫 샘플은 기존 한 화면을 세 표현으로 보여 주어 시각 확인을 받습니다.
단이는 기존 엔진에 모든 부품 모델을 계속 싣고 메뉴만 감추는 안과, 기존 renderer를 재사용하는 가벼운 overview를 비교했습니다. 후자를 선택합니다. 새 UI 엔진/새 패키지를 만들지 않고 overview에서 편집 엔진 자체를 초기화하지 않아 화면 전체 선택이 명확해집니다. 기존 GrapesJS 소스/브리지/시험/원본과 상세 편집 엔진은 보존합니다.

## 전체 캔버스
상단은 프로젝트·설계/현재 단계, 구역선/세부 와이어/본UI, 정렬/연결 보기, 확대/맞춤, 미리보기·상세 진입만 핵심으로 둡니다. 프로젝트/설계 선택·가이드는 한 관리 메뉴에 둡니다. Undo/Redo는 메인 화면에 노출하지 않고 내부 복구 수단은 보존합니다.
왼쪽은 실제 저장 설계의 화면 목록만, 가운데는 실제 화면 보드만, 오른쪽은 선택 화면 설명/종류/크기/출입 연결 요약만 둡니다. 메인에서 부분 선택·속성 수정·임의 새 화면/게임 기능 생성은 하지 않습니다.
정렬은 5개씩 행을 내려 배치합니다. 연결은 entryScreen을 기준으로 저장된 명시 target 연결을 SVG로 보여 주고 자유롭게 보드를 배치합니다. 미연결 화면은 별도로 놓고 가짜 링크를 생성하지 않습니다. 두 보기의 위치/확대/선택은 workspace+project별 로컬 보기 설정으로 보존하며 저장 게임 좌표와 분리합니다.
보드는 화면 전체를 하나의 선택 대상으로 쓰고 하위 부품 pointer를 막습니다. 목록 클릭과 보드 클릭은 같은 selection을 사용합니다. 상세 편집/가이드/샘플에 project/workspace/screen과 표현 모드를 넘깁니다.
메인에서는 editor model/iframe/부품별 편집 이벤트를 만들지 않습니다. 보이는 보드부터 렌더하고 밖으로 멀어진 보드는 해제합니다. 기본 본UI 표시는 기존과 이어 가고 표현 선택은 보기 설정으로 기억합니다. 실제 초기 DOM/렌더 수·Grapes 미초기화·이미지 실패·넘침을 기록하며 측정하지 않은 속도 배수를 주장하지 않습니다.

## 세 표현
wireframe: 큰 배치 구역만 선으로 보여 줍니다. 게임 그림/텍스처를 요청하지 않고 제품 텍스트는 숨깁니다. 구역 이름은 편집 안내로만 구분합니다.
detailed-wireframe: 같은 계층/배치/반응형·텍스트를 유지하고 실제 그림의 알파 형태를 단색/외곽과 얕은 그림자로 표시합니다. native 텍스트 정보는 정확히 유지합니다.
ui: 현재 정식 이미지/색/효과를 표시합니다.
표현 전환은 저장 문서의 변환/이미지 교체/사본 생성이 아니라 공통 renderer의 보기 옵션입니다. UI 제작은 계속 실제 툴에서 조립하며 특정 샘플 이름·ID를 JS에 넣지 않습니다.

## 상세와 가이드·미리보기
상세 상단에 전체 캔버스→상세 편집→디자인 가이드의 동일한 길과 현재 화면을 표시합니다. 저장/필수 단계 이동·표현·미리보기만 전면에 두고 기술/공유/진단/기기·편집 보조는 접는 메뉴로 정리합니다. Undo/Redo 전면 버튼은 빼되 키보드/엔진 이력은 보존합니다.
가이드에도 현재 project/screen/선택 부모·자식 경로와 같은 표현·미리보기 진입을 둡니다. 기존 가이드 위치/크기/선/이미지 편집 기능은 보존합니다.
저장 샘플 viewer는 3표현을 받고 어느 화면이나 선택해 단독 표시합니다. 미저장 상세 미리보기는 현재 설계를 그대로 보는 기존 동작 시험을 활용하고, 저장 샘플과 명확히 구분합니다. 미리보기를 위해 임시 게임 연결을 추가하지 않습니다.

## 경계와 검수
샘플 저장 JSON/자원 외부 수정0, source 변경 전 백업, 후보는 scratch. 2차는 카피바라 샘플을 계속 제작하며 HMR 직전 저장 안전 상태를 조율합니다. 7007/서버 재시작/빌드/새 예약/보호파일/다른 게임을 건드리지 않습니다.
단독/공통 parser·선택·grid/graph·분기·주소/격리·서로 다른 논리 크기·empty/invalid 연결/다국어 텍스트를 시험합니다. 소스 자동 시험과 실제 1440/430 화면·링크/자원·키보드/휠·스크롤·UI 저장/재열기를 구분합니다. 새 기능을 W/P/U/S나 원본 시각 동등 완료로 세지 않습니다.
