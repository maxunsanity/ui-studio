보드 성장 부품 첫 앨범 발매 전후 콘서트장 대표 팬

능력 성장과 시설 외형

본진의 시설 타일은 8개 시설군마다 3칸씩 배치합니다. 도착 칸은 성장 대상 능력을 정하고, 도착 결과에는 해당 이동에서 바뀐 멤버 이름과 세부 능력의 전후 값을 표시합니다. 팬샵 12·14·15는 굿즈 수익과 팬 활동을 안내합니다. 시설 외형은 건설에서 본관과 부속 두 동을 증설할 때 달라집니다.

시설별 기존 바닥색과 지붕 각인은 평소에도 보입니다. 이동 중 잠깐 밟으면 얇은 외곽선, 최종 도착하면 두 겹 외곽선과 위치 핀을 표시합니다. 시설별 도착 연출은 핀 주변에 붙여서 이동 경로가 읽히게 합니다.

시설연결 칸연출과 정보
댄스 연습실4·24·25연보라 바닥과 댄서 각인. 도착 결과에 해당 칸의 성장 능력을 표시합니다.
예능 방송국27·28·30연두 바닥과 방송 카메라 각인. 직선 프레임과 ON AIR로 송출을 표현합니다.
콘서트장32·33·35페리윙클 바닥과 왕관 돔 각인. 둥근 무대 아치와 스포트라이트로 공연을 표현합니다.

첫 앨범 발매 전후에는 같은 칸의 장소명과 활동 외형을 바꿉니다. 멤버 성장에 따라 추가로 외형을 바꾸는 조건은 시안 검수 항목입니다. 게임 조건과 능력 문턱은 확정 데이터가 필요합니다.

서 있는 대표 팬과 실제 인원

건설 → 시설 상세 → 모인 팬 보기에서 컬러 3D 인물 머리 위에 공통 테두리의 ×100 말풍선을 표시합니다. 아래에는 총인원과 나머지를 표시합니다. 인물은 최대 네 명을 보여 주고, 그 밖의 인원은 숫자로 이어서 표시합니다.

총 430명×100×100×100×100+30명
  • 팬 100명은 인물 한 명과 ×100. 팬 99명은 총 99명 텍스트.
  • 팬 0명은 인물 없이 총 0명. 집계 대기는 합계 자리에 대기 문구.
  • 무대 앞 배경 관객은 분위기를 연출합니다. 인원을 나타내는 인물에는 항상 ×100 말풍선을 붙입니다.

100명과 430명은 미리보기 시연 값입니다. 능력 성장 원본은 P87·P106·P107·P265와 board_tile.csv, growth_source.csv를 따릅니다.
