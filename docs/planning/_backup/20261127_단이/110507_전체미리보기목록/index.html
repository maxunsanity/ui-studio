전체 화면 표시와 공통화 검수

등록된 현행·연동 721개 화면을 430px와 1440px에서 각각 열었습니다. 총 1,442회 표시 중 브라우저의 이미지 미수신과 화면 전체 가로 넘침은 0건입니다. 동작 시험은 대표 경로를 직접 조작해 확인했습니다.

화면별 공통화 검수표 · 실제 동작 결과와 증거

  • 스크롤 · 본문만 움직이고 제목, 탭과 하단 행동은 고정합니다. 엔터파워 두 시트에서 목록의 휠 입력을 복구했습니다. 71개 후보는 실제 재현 여부를 더 확인합니다.
  • 닫기·복귀 · 닫는 창의 바로 아래 창과 진입 버튼에 초점을 돌립니다. 카드 효과에서 영수증과 호출 버튼으로 돌아가는 흐름을 확인했습니다.
  • 결정창 외부 탭 · 구매 및 변경 취소처럼 중요한 결정을 받는 창의 닫기 정책을 공통화합니다. 구매 확인은 현재 배경 탭으로 닫힙니다. 이 유형의 후보는 5개입니다.
  • 모달·시트 외곽 · 모달 177개 중 119개, 시트 143개 중 103개에서 현재 공통 원본과 일치하는 외곽 후보를 찾았습니다. 나머지는 애니메이션 전용 화면과 실제 창을 확인합니다.

스크롤 후속 검수와 모달 닫기 제안

71개 화면의 73개 스크롤 영역에 휠을 입력했습니다. 입력이 막힌 7곳을 수정했고, 430px와 1440px에서 14회 다시 시험했습니다. 나머지 66곳은 시험한 본문 위치에서 이동했습니다.

결정창은 배경 탭을 받아도 열린 상태를 유지하는 안을 검수 대기로 올립니다. 취소와 확인 버튼을 제공하고, Escape는 명시 취소와 같은 결과를 내는 경우에만 허용합니다. 닫힌 뒤에는 호출 버튼으로 초점을 돌립니다.

의상 결정창과 공통 외곽 후속 검수

새 의상과 한서아 시착의 실제 뒤로 조작에서 의상 결정창을 열었습니다. 배경 탭, Escape, ×에서 닫히고 호출한 뒤로 버튼에 초점이 돌아왔습니다. 일반·세트 변형은 단독 표시를 확인했습니다. 현재 저장판의 진입 연결은 두 변형에서 모두 확인되지 않습니다.

온보딩 일반 모달 8개와 HUD 정보 시트 4개의 9슬라이스를 공통 원본으로 맞췄습니다. 고정 테두리 7px와 분할 11px를 430·1440px에서 확인했습니다.
