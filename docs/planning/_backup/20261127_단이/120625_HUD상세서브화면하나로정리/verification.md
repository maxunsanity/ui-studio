### 검수 대기 중 계속 적용한 화면

정보 후속 r11에서 카드 획득 영수증, 이번 획득 효과, 두 아이돌의 스토리 시트에도 적용했습니다. 판의 9슬라이스를 유지하고 닫기 입력 44×44px, 고정 하단 버튼 높이 54px를 사용했습니다. 영수증 → 이번 효과 → 영수증 복귀, 오시온·한서아의 스토리 상세 진입을 실행기로 확인했습니다. 영수증 표시를 1440·430px에서 확인했습니다.

### 버튼 테두리 수정과 뒤로 공통 적용

부품 보드 r12에 주·보조·닫기·뒤로 버튼 5개를 실제 9슬라이스로 적용했습니다. 1440·430px 렌더에서 분할값, 고정 테두리, 가로 넘침을 확인했습니다. 보조 버튼과 창 크기 비교에는 공통 모달 이미지(분할 11px, 고정 7px)를 사용합니다.

기존 작업의 건설 r15·상점 r15·스케줄 r27·HUD r76·정보 r13에 주 버튼 7개를 적용했습니다. 정보 r13의 오시온·한서아·포토카드 결과에서 뒤로 44×44를 적용했고, 기존 back 연결과 9슬라이스 표시를 확인했습니다. 대표 모달 2개의 저장판 미리보기에서 동일한 외곽 이미지를 확인했습니다. 전체 모달 표준 적용 검수는 진행 중입니다.

## 스크롤 후속 검수 · 2026-11-26

71개 화면의 본문 영역 73곳에서 지정 위치에 실제 휠을 입력했습니다. 숨겨진 팬 등급 및 팬 반응 탭 3곳은 탭을 열어 검사했습니다. 66곳이 움직였고 7곳에서 입력이 본문에 닿지 않았습니다. 7곳의 입력을 수정하고 저장판을 다시 읽어 430px와 1440px 양쪽에서 총 14회 본문 이동을 확인했습니다. 오시온 몬스 선택 → 확인 → 취소 후 원래 몬스 카드에 초점이 돌아옵니다.

수정 화면은 HUD 복귀 주사위, 오디션 임태이 후보 상세, 오시온·한서아 몬스 배정, 카드 획득 효과, 로비 보상 오늘 출석·복귀 주사위입니다.

### 결정창 닫기 · 검수 대기

구매 확인 1개와 의상 변경 취소 4개가 외부 탭으로 닫히는 설정 후보입니다. 실제 외부 탭으로 닫히는 동작을 확인한 예시는 상점 구매 확인입니다. 결정창의 배경 입력은 창을 열린 상태로 두고, 취소와 확인 버튼을 사용합니다. Escape와 명시 취소의 효과가 같은 경우 Escape를 허용하고 호출 버튼으로 초점을 복귀시키는 안입니다. 의상 변형 네 개는 실제 진입과 입력을 추가 검수합니다.

## 의상 결정창과 공통 9슬라이스 · 2026-11-26

- 의상 결정창: 새 의상 시착과 한서아 시착에서 뒤로를 눌러 모달에 들어갔습니다. 배경 탭, Escape, × 모두 닫힌 뒤 호출 버튼에 초점이 돌아왔습니다. 일반·세트 변형은 저장판에서 표시를 확인했고 현재 등록된 진입 연결은 없습니다. 결정창의 배경 탭 금지안은 검수 대기입니다.
- 외곽: 온보딩 r5의 일반 모달 8개와 HUD r80의 엔터파워·팬 정보 시트 4개에 공통 원본과 분할 11px, 네 변 고정 7px를 적용했습니다. 430·1440 총 24회 렌더 확인, 가로 넘침 및 표시 이미지 오류 0건.
- 실제 조작: 캐스팅에서 예명 입력 진입, 로비에서 엔터파워와 팬 정보를 열어 탭을 누른 후 Escape로 나와 원래 입력에 초점이 복귀했습니다.
- 최신 외곽 대조: 모달 177개 중 공통 원본 127개, 시트 143개 중 107개. 별도 메뉴 시트와 연출 전용 창은 용도를 보면서 대조합니다.
