3. 화면 깊이 · 뒤로

깊이 0 = HUD, 1 = HUD에서 한 번 눌러 여는 화면, 2 = 그 안의 버튼으로 들어가는 안쪽 화면. 책갈피는 같은 깊이 안에서 바꿔 보는 것이라 깊이를 늘리지 않습니다.

#규칙출처
1깊이는 2까지. 더 들어가야 하면 창으로 띄움. 창은 깊이를 늘리지 않음현중 11/19
2← 뒤로는 한 칸 위로. 깊이 2 → 깊이 1(보던 책갈피 그대로) → HUD확정
3창은 닫기 · 바깥 누름 · Escape로 닫고 연 자리로 돌아감확정
4아래 메뉴는 전체 화면 위에서도 보임. 다른 칸 = 바로 바뀜(쌓지 않음), 같은 칸 다시 = HUD확정
5바로 가기(다른 메뉴의 화면으로 건너뜀)로 들어간 화면의 ← 는 온 화면으로 한 번 돌아감현중 11/19

사람마다 카드 12장을 모으고, 아이돌 · 팀 · 스태프 능력을 보고, 스태프 · 회장 명함을 바꾸고, 팩을 여는 화면입니다.

v1 · 2026-11-20 클로드 · 기준 순서: 현중 직접 조정 → 카드 기획서 P168 → 와이어 1차 · 양식: UI 기획 문서 규칙

핵심

  • 모든 칸은 사람 한 명입니다. 카드는 그 사람의 12장이고 사람마다 따로입니다.
  • 사람 보기 = 큰 캐릭터 위에 능력 줄을 겹친 한 화면. 위쪽 책갈피 「능력 · 카드」로 바꿔 봄. 아래 버튼은 그 사람에게 하는 동작 하나.
  • 아이돌에서 가장 중요한 값 = 지금 단계 · 재능선 · 지금 6축 값. 세부는 현황판 · 캐릭터 정보창.
  • 팀 보기 = 팀 등급 · 팀 능력 합 · 다음 등급까지 · 팀 6축 · 멤버. 3팀까지 넘겨 봄.
  • 명함집 = 스태프 · 회장만(아이돌은 캐스팅). 스카우트 팩 열기 · 보관 · 교체를 한 곳에서.
  • 진행은 게이지 대신 n/12 글자. 카드 앞면은 그림이 전체, 능력은 반투명 판으로 겹침.

스케줄 UI 기획서

아이돌을 탐험에, 몬스를 출동에 보내고, 다녀오면 이야기와 보상을 받는 화면입니다. 도감 · 기록장 · 소식이 같이 붙어 있습니다.

v1 · 2026-11-20 클로드 · 기준 순서: 현중 직접 조정 → 스케줄 규칙서 P241 · 탐험 통합 기획 P206 → 게임 시뮬레이터 스케줄 · 와이어 원본: 스케줄 와이어프레임 · 양식: UI 기획 문서 규칙

핵심

  • 화면은 4장: 홈 → 보내기 → 진행 중 → 결과. 나머지는 모두 창입니다.
  • 홈 카드 한 장 = 스케줄 하나. 카드가 상태(결과 받기 · 진행 중 · 보내기 · 못 보냄 · 잠김)를 들고 있어서 따로 진행 목록이 없습니다. 순서는 열리는 엔터파워 순으로 고정합니다.
  • 아이돌 탐험과 몬스 출동은 같은 틀입니다. 위에 큰 대표 이미지, 그 아래 조건 줄 = 보낼 팀(줄 안에 얼굴이 쌓임), 누른 줄에 넣을 수 있는 사람만 아래에 나옵니다.
  • 아이돌 · 스태프 · 몬스는 배지로 구분합니다. 진한 칩은 꼭 필요, 테두리 칩은 넣으면 좋음, 안 가는 것은 숨깁니다.
  • 결과는 이야기를 먼저 보고, 그다음 한 장으로 ★ · 받은 것 · 좋아진 것(전 → 후 ▲)을 보여줍니다. 카드팩은 받은 뒤에 엽니다.
  • 도감 조각 3개로 항목을 완성하고, 남는 조각은 반복 퍼즐에 씁니다. 다녀온 스케줄은 엽서가 되어 기록장 · 소식으로 친구와 나눕니다.

핵심

  • 미션은 새 놀이가 아니라 보드에서 하는 일(굴림 · 칸 도착 · 증설 · 카드 열기 · 스케줄 · 미니게임)의 횟수 장부입니다. 다 되면 목록에서 바로 받고, 받을 때 창은 뜨지 않습니다.

  • 일일은 오늘 받은 수를 차트 순위(1개 100위 → 5개 1위)로, 주간은 음방 트로피(4개)로 보여 줍니다. 1위 칸이 기존 묶음 보상(오늘 5개 · 이번 주 4개 완료)입니다.
  • 미션 카드 = 팬 한 명의 부탁. 큰 글은 부탁 말투, 아래 회색 글은 실제 할 일과 진행 막대. 카드 아래 줄에 받을 보상을 아이콘 + 수량으로 바로 보여 줍니다. 버튼은 「받기」 또는 「바로 가기 ›」.
  • 순서는 받기 → 진행 중 → 잠김 → 받음(✓ 흐리게 · 접지 않음). 맨 아래 「전체 받기 · n건」(0건이면 꺼짐).
  • 게이지 칸 · 보상 칸을 누르면 말풍선으로 조건 · 내용을 봅니다. 팩은 「팩 안 보기 ›」로 포토카드 팩 안 카드 창을 엽니다.
