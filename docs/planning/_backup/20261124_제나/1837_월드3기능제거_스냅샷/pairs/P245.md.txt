# P245 · 독립 음악 앱 · 대표 개발 기획서

**이 문서는** 게임에서 키운 내 아이돌의 곡과 영상을 청취자 · 팬이 보고 · 듣고 · 찜하고 · 투표하는 독립 음악 앱의 화면 컨셉과 구동 순서(라이브 실황 · 게임 유저 · 크루 · 게임 안 하는 사람)를 그림과 함께 정리한 대표 개발 기획서입니다.

**보는 법** 1장 「일반 음악 앱과 다른 점」 → 3장 화면 12장 그림 설명 → 4장 네 가지 구동 순서와 데이터 → 5장 그림 목록 → 7장 진행 순서로 읽습니다. 발표용 화면은 짝 [웹 발표판](독립음악앱_기획서.html), 화면 원본은 [UI 컨셉 시안](../../기획서/음악앱_UI컨셉_v1/음악앱_UI컨셉_시안_v1.html), 눌러 보는 구동판은 [음악 앱](/docs/planning/music-app.html)입니다. 시뮬레이터 없음.

**지금 상태** 현재 개발되지 않음, 진행 중. 남은 결정 3건은 현중 11/14에 정했습니다(응원 문구만 · 앱 전용 팬 투표도 게임 순위에 · 팀 채널 · 프리미어는 다음 범위). 구동판(`music-app.html`)은 화면 M1~M9에 비로그인 첫 화면 · 로그인 시트 · 앱 계정 투표 · 관람방 응원 문구를 더했고, 여러 상황을 바로 열어 보는 [시험 데이터 묶음](/docs/planning/music-app-samples.html)이 있습니다. 실서버 · 실원장 · 실제 공연 공급은 미개발입니다.

## 1. 개요

### 한 줄 (확정 · 콘텐츠 규칙서 0장)

**게임에서 키운 내 아이돌의 곡과 영상이, 청취자와 팬이 듣고 찜하고 투표하는 진짜 음악 앱으로 나간다.** 게임은 아티스트 쪽(팀 육성 · 앨범 발매 · 페스티벌 신청 · 보드 공연), 앱은 팬 쪽(감상 · 발견 · 차트 · 관람 · 숏츠 · 찜 · 투표 · 인기 응원 · 업로드)입니다.

![게임과 앱의 연동 지도](_assets/독립음악앱_v01/00_연동지도.jpg)

*그림 0 · 게임 ↔ 앱 연동 지도. 왼쪽 게임 사건(팀 · 보드 공연 · 발매 · 영상 · 페스티벌 · 인기 재화)이 가운데 연동 번호(#1~#8)를 거쳐 오른쪽 앱 화면에 나타난다. 앱이 없어도 게임은 끝까지 진행되고, 시즌이 끝나도 앱 기록은 이월된다.*

### 일반 음악 앱과 다른 점 (신규)

일반 음악 앱은 멜론 · 스포티파이 · 유튜브 뮤직 · 유튜브 같은 상용 서비스를 말합니다.

| 항목 | 일반 음악 앱 | 우리 음악 앱 |
|---|---|---|
| 곡이 어디서 오나 | 기획사 · 유통사가 넣은 실제 음원 | 게임에서 키운 **내 아이돌**의 곡. 내부 발주곡(4장르 × 8곡) 또는 직접 올린 창작곡(`mp3` 180초, 검수) |
| 가수 | 실존 아티스트 | 게임 팀 · 멤버 예명. 크레딧은 반드시 내 팀 아이돌 |
| 듣는 사람 | 감상자 | 감상자이면서 다른 팀의 **경쟁자 · 기획사 대표**. 같은 사람이 아티스트 쪽(게임)과 팬 쪽(앱)을 오간다 |
| 차트 | 재생 · 다운로드 수 집계 차트 하나 | 게임 페스티벌과 같은 차트 3종: 앨범(발매 직후 더미 100명) · 주간(1~8주, 같은 수준 100명 구역) · 월드(9주, 리그 · 1,000등 · 6탭) |
| 투표 | 음악방송 사전투표처럼 다른 앱에서 따로 | 앱 안에서, 감상 → 찜 → 곡 상세 · 보관함 → 확정. **목록 1클릭 투표 없음 · 확정 후 취소 불가**. 결과가 게임 페스티벌 점수(팬 평가)로 들어간다 |
| 찜 | 좋아요 · 플레이리스트 | 곡 찜과 숏츠 찜을 따로. 찜은 투표 대상을 모아 두는 주머니 |
| 영상 | 실제 촬영 MV | 자동 연출 영상 · 내 아이돌 모션샷 + 컷씬 편집 MV · 외부 `mp4`(월드만). 실사 사진 · AI 얼굴 없음 |
| 라이브 | 기획사가 정한 시각의 생방송 | 게임 보드 방송 · 공연 칸에 **도착한 순간 시작되는 실황**. 내 관람 명단(100명 고정)의 무대만 보인다 |
| 팬 모임 | 팬카페 · 커뮤니티 앱 따로 | 게임 크루가 그대로 앱 크루. 음악 공유 → 크루원 각자 MV → 크루장이 대표작 1편 출품 |
| 응원 재화 | 유료 투표권 · 하트 | 인기 재화는 9주차에만 생기고 월드 인기 탭 크루 총공에만 쓴다. 투표 · 찜 · 연료와 섞지 않는다 |
| 기록 | 계정에 계속 | 시즌이 끝나 건물이 초기화돼도 곡 · 숏츠 · 채널 · 구독 · 보관함은 모두 이월 |
| 게임과의 관계 | 없음 | 앱은 선택. 앱이 없어도 게임은 끝까지 진행되고 기본 보상을 막지 않는다 |

### 지금 기획과 이 문서가 더한 것

지금 기획 = [콘텐츠 규칙서 P244](../../기획서/산출_기획서_20261113_독립음악앱_콘텐츠규칙.md)와 구동판(M1~M9). 이 문서는 규칙을 바꾸지 않고 **화면 컨셉 · 배치 · 구동 순서**를 더합니다.

| 항목 | 지금 기획 | 이 문서가 더한 것 | 꼬리표 |
|---|---|---|---|
| 화면 컨셉 | 5탭 · 블록 나열 | 「플레이스토어 랭킹 + 유튜브 콘텐츠 보기」 · 아이돌 공식 채널 구조 | (신규) |
| 홈 | 내 발매곡 · 크루 신곡 · 페스티벌 배너 · 추천 차트 | 맨 위 **내 팀 페스티벌 카드**(게임 연동) → 프리미어 MV → 무대 실황 → 구독 영상 → 숏츠 | (합침) |
| 차트 행 | 듣기 · 찜 · 투표 버튼 | 플레이스토어처럼 버튼 하나(찜). 투표는 곡 상세 · 보관함으로 | (합침) |
| 곡 상세 | 곡 정보 카드 + 투표 시트 | 플레이스토어 앱 상세형: 큰 커버 · 지표 3칸 · 큰 「투표하기」 · 영상 줄 · 평점 막대 · 게임 발매 줄 | (신규) |
| 팀 채널 | 없음 | 게임 팀 = 공식 채널(배너 · 구독 · 무대/MV/숏츠/앨범 탭) | (신규 · 다음 범위 · 현중 11/14) |
| 프리미어 | 없음 | 발매 컷씬 MV 공개 카운트다운 + 알림 | (신규 · 다음 범위 · 현중 11/14) |
| 실황 화면 | 16:9 플레이어 · 댓글 | 방송 · 공연 6채널 목록 · 실황 상태 표시 · **관람방 응원 문구**(정해진 문구만 · 자유 채팅 없음 · 현중 11/14) | (합침) |
| 비로그인 | 규칙만 | 로그인 시트(누른 곡을 다시 보여 줌) · 비로그인 홈 | (신규) |
| 앱 전용 팬 | 결정 없음 | 게임 없이 앱 계정만 있는 팬의 투표도 게임 페스티벌 순위에 들어간다(현중 11/14) · 표 조작 막기 규칙 4-6 | (신규) |
| 만들기 | 상단 `+ 만들기` 버튼 | 4갈래 시트(숏츠 · 컷씬 MV · 창작곡 · 무대 영상) | (합침) |
| 그림 · 표기 | 빈 칸 · 아이콘 | 기존 복셀 이미지, 영상 자리에만 「▶ 영상」 표기 | (신규) |

## 3. 구동 방법·시뮬레이션

화면 흐름: [게임 보드 · 발매 · 페스티벌] → [음악 앱 홈 · 실황 · 차트 · 곡 상세 · 보관함] → [투표 확정 · 게임 페스티벌 점수] · 스샷 [UI 컨셉 시안 12장](../../기획서/음악앱_UI컨셉_v1/음악앱_UI컨셉_시안_v1.html) · 이식 비교 해당 없음

- 구동판: [음악 앱 `music-app.html`](/docs/planning/music-app.html) — 5탭 · 곡 상세 · 투표 시트 · 보관함 · 관람 · 숏츠를 가짜 데이터로 눌러 볼 수 있음(개발됨, 시험 49개 통과).
- 아래 12장은 이 문서가 제안하는 새 화면 배치입니다(배치 시안). 숫자는 모두 예시 값이고, 실제 화면은 서버가 준 값만 씁니다.
- 그림 표기 규칙: 영상 자리(16:9 썸네일 · 숏츠 · 플레이어)에는 「▶ 영상」, 표기가 없는 커버 · 프로필 · 배너는 이미지입니다. 분홍 원 번호는 설명 번호입니다.

### 3-1. 홈 피드 — 유튜브 홈 (배치 시안)

![홈 피드](_assets/독립음악앱_v01/01_홈피드.jpg)

| 번호 | 무엇 | 설명 |
|---|---|---|
| 1 | 내 팀 페스티벌 카드 | 게임에서 발매 · 출전한 곡의 주차 · 구역 순위 · 마감 · 남은 투표. 출전곡이 없으면 「게임에서 앨범을 발매하면 여기서 순위를 볼 수 있어요」. 9주차엔 월드 리그 카드 |
| 2 | 프리미어 카드 | 발매 컷씬 MV 공개까지 카운트다운, 「알림」은 공개 순간 푸시 |
| 3 | 무대 실황 카드 | 보드 공연 · 방송 칸 실황 + 관람방 인원. 누르면 실황 화면 |
| 위 | 「게임으로」 칩 · `+` · 알림 | 모든 화면 같은 자리. 게임 쪽엔 「음악 앱 열기」(#8) |

## 4. 상세 기획

### 한 판 순서

**게임에서 곡이 생긴다 → 앱에 채널 · 곡 · 영상이 올라온다 → 보드 공연이 실황으로 퍼진다 → 팬이 보고 찜한다 → 곡 상세 · 보관함에서 확정 투표 → 게임 페스티벌 점수 · 차트 → 시즌 끝 이월.**

| 점검 | 내용 |
|---|---|
| 시작 · 종료 | 시작 = 게임 팀 생성(채널) · 앨범 발매(곡) · 보드 공연 시작(실황). 회차 종료 = 주간 7일째 마감 · 9주차 월드 마감. 시즌 종료 = 앱 기록 이월 |
| 입력 · 출력 | 입력 = 게임 꾸러미(신원 · 예명 · 발매 · 공연 · 차트 · 인기 획득). 출력 = 투표 · 찜 · 인기 사용 영수증, 업로드 검수 결과, 관람 상태 |
| 상태와 전이 | 곡: 검수 중 → 등록 완료 / 반려됨. 공연: 공연 중 → 다시보기. 투표: 확인 → 확정(취소 없음) |
| 판정 | 앱은 점수를 계산하지 않는다. 투표 · 인기 사용은 게임 페스티벌 점수 A(팬 평가) · C(인기 응원)로 들어간다 |
| 오류 · 예외 | 통신 실패 = 차감 없음. 같은 요청 두 번 = 한 표. 빈 값 = 「아직 기록이 없어요」(숫자를 지어내지 않음) |
| 저장 · 복원 | 찜 · 투표 내역 · 업로드 · 구독 · 채널은 계정에 저장, 시즌 이월. 화면 이동 · 새로고침으로 사라지지 않음 |
| 다른 모듈 연결 | 앨범 발매 · 보드 공연 · 페스티벌 · 크루 · 숏츠 · 인기 재화(연동 #1~#8) |

### 4-1. 라이브(실황) 시퀀스 (확정 · P234 / 응원 문구 현중 11/14)

실황은 정해진 방송 시각이 없습니다. **게임에서 누군가 보드 방송 · 공연 칸에 도착해 공연이 시작되는 순간**이 실황 시작입니다. 그래서 「언제 몇 시에 방송하나」가 아니라 「내 관람 명단 안에서 지금 누가 공연 중인가」를 보여 줍니다.

```mermaid
sequenceDiagram
  participant B as 게임 보드(공연한 사람)
  participant P as 공연 상태
  participant G as 게임 PIP(본인)
  participant A as 음악 앱(관람 명단 100명)
  participant F as 페스티벌
  B->>P: 방송·공연 칸 도착 → 공연 시작(performanceId)
  P-->>G: 내 공연 오른쪽 PIP(음소거로 시작)
  P-->>A: 명단에 이 사람이 있는 관객: 홈 실황 카드 · 채널 「공연 중」
  A->>P: 관람 → 지금 지점에 합류
  A->>A: 하트 · 찜 · 곡 보기(투표는 곡 상세)
  B->>P: 공연 종료 · 검증
  P-->>A: 「다시보기」로 바뀜 → 팀 채널 「무대」 탭
  P->>F: 인정된 공식 결과만 페스티벌에(중복 · 기간 확인)
```

| 순서 | 게임 쪽 | 앱 쪽 | 데이터 |
|---|---|---|---|
| 1 | 앨범 발매로 보드 6칸이 켜짐(방송27 · 28 · 30, 공연32 · 33 · 35) | 채널 이름이 예능 · 라디오 · 음악 방송국 등으로 바뀜 | 칸 번호 · 발매 여부 |
| 2 | 내 말이 칸에 도착 → 공연 시작 | — | `performanceId` · `sourceEventId` · `boardPos` · 팀 · 앨범 · 출전 건 · 시작 시각 · `status` |
| 3 | 오른쪽 PIP(줄이기 · 닫기는 공연 취소 아님) | — | PIP 상태(줄임 · 닫음) |
| 4 | — | 내 관람 명단에 그 사람이 있으면 홈 실황 카드 · 채널 「공연 중」 | 관람 명단 `groupId` · `rosterRevision` · 포함 사유(친구 · 크루 · 일반 · 주간) |
| 5 | — | 관람: 지금 지점에 합류. 영상 지연이면 「영상 연결 중」 | `mediaRef` · 실황 상태 5종 |
| 6 | — | 하트(무료) · 찜 · 곡 보기 → 곡 상세에서 투표 | 찜 영수증 · 투표 영수증(계정 · 회차 · 곡) |
| 7 | 공연 종료 | 「다시보기」로, 팀 채널 「무대」 탭에 쌓임 | 종료 시각 · 재생 가능 자료 |
| 8 | 인정된 공식 무대만 페스티벌 점수 G | 차트 잠정 순위 · 기준 시각 갱신 | 공식 결과 · 회차 · 기준 시각 |

- **관람 명단(확정 · P234):** 내 그룹 `N = S ∪ T` — 친구 · 크루 S 전원 + 같은 등급 일반 T로 100명까지(친구 · 크루가 100명을 넘으면 넘는 대로). 주간 대회 모드 `V = W ∪ S`(경쟁 상대 전원 + 친구 · 크루). 월드 상위권은 관람 키로만.
- **실황 상태 5종(확정 · P234):** 공연 중(지금 지점 합류) · 공연 중 + 영상 연결 중 · 다시보기 · 상태 확인 중 · 영상 없음(공연 정보만). 끝난 영상을 처음부터 틀며 실황이라고 쓰지 않는다.
- **소리(확정):** 한 번에 하나. 실황을 켜면 음악은 멈추고, 닫으면 이어 듣기.
- **점수(확정):** 시청 · 재생 · 관람 키 사용만으로는 점수를 주지 않는다. 관람 명단이 커져도 투표 수는 늘지 않는다.
- **관람방 응원(확정 · 현중 11/14):** 자유 채팅은 넣지 않는다(P234 범위 유지). 대신 **정해진 응원 문구 6개**를 누른다. 문구는 서버가 id로 내려 주고 화면 글자는 앱 문구 표에서 고른다(지금 문구: 「최고예요」 · 「무대 찢었다」 · 「목소리 너무 좋아」 · 「다음 무대도 기다릴게」 · 「같이 응원해요」 · 「앵콜!」 — 클로드가 쓴 현재 문구, 카피 담당 확정 전). 한 무대에서 같은 문구는 한 사람이 한 번만 센다. 비로그인은 로그인 시트를 연다.

### 4-3. 크루 시퀀스 (확정 · P244 M6 · R-MA-61)

```mermaid

  participant C as 크루
  participant M as 크루원 각자
  participant L as 크루장
  participant F as 페스티벌
  O->>C: 창작곡 「음악만」 공유(동의 체크)
```

| 순서 | 무엇 | 규칙 | 데이터 |
|---|---|---|---|
| 1 | 크루 가입 | 게임 크루 그대로. 이름 40자 · 소개 300자 · 정원 현재 세팅 0(제한 없음) | 크루 id · 크루장 |
| 2 | 음악 공유 | 원작자가 창작곡을 「음악만」 공유. 검수 중이어도 크루 안에서는 보임 | 공유 id · 동의 영수증 |
| 3 | 각자 MV | 크루원 각자(원작자 포함) **자기 아이돌**로 MV. 다른 팀 아이돌은 못 넣음 | MV id · 곡 id · 내 팀 크레딧 |
| 4 | 크루 투표 | 1인 1표, 참고 지표 | 크루 투표 기록 |
| 5 | 대표 확정 | 크루장이 회차당 1편(설정값 1). 개인 출품과 서로 막지 않음 | 대표 확정 · 출품 건 |
| 6 | 관람 | 크루원은 관람 명단 S에 전원 | 포함 사유 = 크루 |
| 7 | 인기 총공 | 9주차 월드 인기 탭에서만 | 인기 사용 영수증 |

### 4-4. 게임 안 하는 사람 시퀀스 (로그인 경계 확정 · 앱 전용 팬 투표 현중 11/14)

```mermaid
flowchart LR
  I[앱 설치] --> H[비로그인 홈<br/>보기 · 듣기 자유]
  H --> W[실황 · 숏츠 · 차트 보기]
  W --> T{찜 · 투표 · 하트 · 크루 누름}
  T --> S[로그인 시트]
  S -->|둘러보기| W
  S -->|로그인| L[로그인한 팬]
  L --> K[찜 → 보관함 → 확정 투표]
  L --> X[게임 없이 앱 계정만인 팬도<br/>같은 회차 표 수로 투표 → 게임 순위]
```

| 순서 | 무엇 | 규칙 |
|---|---|---|
| 1 | 앱만 설치 | 비로그인 = 감상 · 둘러보기만(확정 · P244 M1) |
| 2 | 비로그인 홈 | 「게임으로」 · `+` · 알림 대신 「로그인」, 내 팀 카드 대신 페스티벌 안내. 실황 시청 가능 |
| 3 | 반응하려 함 | 찜 · 투표 · 하트 · 채팅 · 업로드 · 크루 · 보관함을 누르면 로그인 시트(누른 곡 다시 보여 줌) |
| 4 | 로그인 | 그 찜을 바로 마친다. 로그인 = 찜 · 투표 · 인기 응원 · 업로드 · 크루(확정) |
| 5 | 앱 전용 팬 | **게임 없이 만든 앱 계정의 투표도 게임 페스티벌 순위(점수 A · 팬 평가)에 들어간다(현중 11/14 확정).** 게임 계정 표와 같은 무게(설정값, 지금 1)로 센다. 표 조작은 4-6 규칙으로 막는다. 관람 명단 등급은 앱 계정이면 「일반」(친구 · 크루 없음)으로 넣는다(신규 제안) |

### 4-6. 앱 전용 팬 표 조작 막기 (신규 제안 · 현중 11/14 결정에 따름)

| 번호 | 규칙 | 화면 · 데이터 |
|---|---|---|
| 1 | **한 사람 한 계정.** 앱 계정은 본인 확인을 마쳐야 투표할 수 있다. 확인 전에는 찜 · 감상만 | 계정 `verified` · 투표 시트 「본인 확인 뒤 투표할 수 있어요」 |
| 2 | **표 수는 같다.** 앱 계정도 게임 계정과 같은 회차 표 수(서버 값)를 쓴다. 계정 종류로 표가 늘지 않는다 | 원장 회차 표 수 · `votesPerRound` |
| 3 | **두 계정은 한 사람.** 게임 계정과 앱 계정을 연결하면 회차 표 수를 함께 쓴다(합쳐서 두 배 아님) | 연결 id · 회차 사용 수 합산 |
| 4 | **투표 순서 그대로.** 감상 → 찜 → 곡 상세 · 보관함 → 2단계 확정. 목록 1클릭 투표 없음(R-MA-90) | 기존 투표 시트 |
| 5 | **이상 표는 무효.** 같은 기기 · 짧은 시간 몰림 같은 이상 표는 서버 검사 뒤 무효로 돌리고 영수증에 「무효」를 단다. 무효 기준 수치는 비어 있음(0으로 동작) = 지금은 무효 처리 안 함 | 영수증 `status` · `voterKind`(게임 · 앱) |
| 6 | **영수증에 계정 종류를 남긴다.** 순위에는 같은 무게로 들어가되, 운영이 나눠 볼 수 있게 `voterKind`를 기록한다 | 원장 영수증 |

### 4-5. 찜 · 투표 · 인기 (확정 · R-MA-90 · 91)

- 투표 순서: 감상 → 찜 → 곡 상세 또는 보관함 → 회차 확인 → 「이 곡에 투표하시겠습니까?」 → 확정. 목록 · 숏츠 · 실황에는 투표 버튼이 없다. 확정은 취소할 수 없다.
- 찜 · 투표는 **곡 · 숏츠 단위만**(아이돌 단위 아님 · 확정 세팅 Q3).
- 인기 재화는 9주차에만 생기고 월드 인기 탭 크루 총공에만. 투표 · 찜 · 레이싱 연료와 섞지 않는다.
