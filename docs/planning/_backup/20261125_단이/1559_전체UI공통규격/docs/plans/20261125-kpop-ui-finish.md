# 케이팝몬스터즈 전체 UI 마무리 작업 계획

작성 codex(단이) · 2026-11-25 · 제안(검수 대기)

## 이어갈 때 먼저 읽는 기준

1. 현중의 최신 직접 지시 → 이 계획의 진행표 → P265 원본과 작업 명세 → 비교 샘플의 저장 화면·부품 → 해당 7018 저장판을 읽습니다. 시작할 때 기록한 과거 revision을 최신으로 가정하지 않습니다.
2. 화면마다 먼저 보여야 할 정보와 주 행동을 정합니다. 겹치는 정보, 구획과 과한 테두리를 줄이고 필요한 상세는 열어 볼 수 있게 유지합니다. 기존 편집·진입·복귀의 동작은 각각 확인합니다.
3. 샘플 이름이나 그림만 옮기지 않습니다. 구조가 같은 샘플의 실제 부모·자식, 크기, 간격, 상태, 배치, 동작, 자원을 대조해서 채택·변경 이유를 남깁니다.
4. 대표 2차 화면은 UI 스튜디오 상세 편집과 미리보기에서 번갈아 직접 보며 조립·수정합니다. 스크립트는 저장본 읽기 대조·측정·반복 검증에 사용합니다. 단독 페이지 표시와 실행기 입력 검수는 각각 기록합니다.
5. 2차는 실 UI와 가까운 완성도로 구성합니다. 버튼 표면·두께·그림자·정상/눌림/비활성 상태가 읽히게 합니다. 2D는 명암이 읽히는 흑백, 3D 장면과 모델·건물·지도의 대표 자원은 원본 컬러. 글자, 아이콘, 프레임, 입력 범위는 편집 가능한 별도 부품으로 둡니다.
6. 기존 레이아웃을 바꾸는 제안은 같은 논리 폰 크기로 전후 스크린샷을 만듭니다. 왜 바꾸는지, 어떤 상태인지, 지켜야 할 정보·동작을 캡처와 같이 요약합니다. 제안을 사용자 승인으로 기록하지 않습니다.
7. 실제 게임 연동, 시즌 마감·월드 페스티벌·독립 음악 앱 및 새 미니게임은 현재 마무리 범위에서 보류합니다. 기존 시안은 원본과 변경 이력을 보존합니다. 기존 서버·자동화는 재시작하거나 활성화하지 않습니다.
8. 작업이 길어지거나 담당 단위가 바뀔 때 위 기준을 다시 읽고 시작·변경·미확인·검수 범위를 대조합니다.

## 11개 요청의 완료 기준

| 번호 | 산출과 확인 |
| --- | --- |
| 1 | 버튼 부품 보드와 규격서. 주 행동, 보조 행동, 아이콘 버튼에 대해 외곽, 높이, 입력 범위, 글자·아이콘, 상태를 명시 |
| 2 | 중앙 모달 공통 규격. 확인·결과를 구분하고, 너비·최대 높이·딤·닫기·초점 및 복귀 확인 |
| 3 | 바텀시트 공통 규격. 하단 정렬·안전영역·제목/본문/고정 버튼의 책임, 스크롤과 계층 복귀 확인 |
| 4 | 아이콘 공통 부품서. 원본 크기와 실제 표시 크기, 역할별 입력 크기, 정렬·투명 여백 명시 |

| 6 | 2차 버튼 외곽·앞면·눌림·그림자·잠김을 실제 미리보기로 비교 |
| 7 | 이미지별 3D 컬러와 2D 흑백을 확인하고 용도가 애매한 것은 사람이 분류 |
| 8 | 7018에 연결된 설계·화면 전수 장부와 공통 규격 대조. 1440/430 CSS 화면, 390×844 설계, 실사용 경로 확인 범위를 각각 기록 |

| 10 | 연출을 화면 상태에 연결. 진입·진행·종료·입력 차단과 다음 화면을 기록하고 대표 전환을 실행기에서 확인 |
| 11 | 활용 이미지 원본·등록 참조·사용 위치·중복·3D/2D·누락을 정리. 보존판은 현행 분모에서 구분 |

## 실행 순서와 검증

- [ ] P265 문서·7018 등록과 공용 가이드의 현행 상태를 읽고 저장본·그림·부품·상태·연결을 목록화합니다. 샘플에서 검증된 제작 노하우의 대응표를 작성합니다.
- [ ] 공통 부품 기준안과 자료표를 만들고 대표 4종(HUD, 목록, 모달, 바텀시트)의 기존 역할과 치수를 대조합니다.
- [ ] 같은 역할의 구조를 참고해 대표 화면을 상세 편집에서 보정합니다. 화면 배치 제안은 전후 실제 미리보기 스크린샷으로 보여 줍니다.
- [ ] 건설·상점·정보·스케줄부터 적용 사례를 만들고, 기능별 저장판을 범위별로 조립·저장·재열기합니다. 나머지는 등록 작업 목록을 따라 같은 검사표로 마무리합니다.
- [ ] 화면별 동작·연출·이미지·부품을 확인합니다. 같은 상태를 각각의 새 화면 취급하지 않되 제작된 변형에서는 눌림/닫기/복귀를 검수합니다.
- [ ] 7018 UI 기획서·작업 명세·부품서를 실제 저장판과 맞추고, 완료 범위/보류/미검증을 항목별로 남깁니다.
