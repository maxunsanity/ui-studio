# 케이팝몬스터즈 전체 UI 마무리 작업 계획

작성 codex(단이) · 2026-11-25 · 제안(검수 대기)

## 이어갈 때 먼저 읽는 기준

1. 현중의 최신 직접 지시 → 이 계획의 진행표 → P265 원본과 작업 명세 → 비교 샘플의 저장 화면·부품 → 해당 7018 저장판을 읽습니다. 시작할 때 기록한 과거 revision을 최신으로 가정하지 않습니다.
2. 화면마다 먼저 보여야 할 정보와 주 행동을 정합니다. 겹치는 정보, 구획과 과한 테두리를 줄이고 필요한 상세는 열어 볼 수 있게 유지합니다. 기존 편집·진입·복귀의 동작은 각각 확인합니다.
3. 샘플 이름이나 그림만 옮기지 않습니다. 구조가 같은 샘플의 실제 부모·자식, 크기, 간격, 상태, 배치, 동작, 자원을 대조해서 채택·변경 이유를 남깁니다.
4. 대표 2차 화면은 UI 스튜디오 상세 편집과 미리보기에서 번갈아 직접 보며 조립·수정합니다. 스크립트는 저장본 읽기 대조·측정·반복 검증에 사용합니다. 단독 페이지 표시와 실행기 입력 검수는 각각 기록합니다.
5. 2차는 실 UI와 가까운 완성도로 구성합니다. 버튼 표면·두께·그림자·정상/눌림/비활성 상태가 읽히게 합니다. 2D는 명암이 읽히는 흑백, 3D 장면과 모델·건물·지도의 대표 자원은 원본 컬러. 글자, 아이콘, 프레임, 입력 범위는 편집 가능한 별도 부품으로 둡니다.
6. 기존 레이아웃을 바꾸는 제안은 같은 논리 폰 크기로 전후 스크린샷을 만듭니다. 왜 바꾸는지, 어떤 상태인지, 지켜야 할 정보·동작을 캡처와 같이 요약합니다. 제안을 사용자 승인으로 기록하지 않습니다.
7. 실제 게임 연동, 시즌 마감·월드 페스티벌·독립 음악 앱 및 새 미니게임은 현재 마무리 범위에서 보류합니다. 기존 시안은 원본과 변경 이력을 보존합니다. 기존 서버·자동화는 재시작하거나 활성화하지 않습니다.
8. 작업이 길어지거나 담당 단위가 바뀔 때 위 기준을 다시 읽고 시작·변경·미확인·검수 범위를 대조합니다.

## 진행 기록

- 시작 · 현중 직접 요청에 따라 대표 샘플 방식과 전체 마무리 계획을 고정합니다. 레이아웃 변경은 비교 캡처로 제시합니다.

- 1차 적용 · 건설 r14의 시설 상세 한 화면. Studio에서 효과 3개를 한 영역에 묶고 주·보조 버튼은 54px 높이로 맞춘 뒤 강조 단계를 적용했습니다. 눌림 3px는 저장 데이터로 확인했습니다. 1440·430 표시, 건설 현황 복귀, 한 단계·최대 증설 진입을 실행기에서 확인했습니다.
- 저장 데이터 점검 · 등록 설계 23개 모두 기본 스키마를 통과했습니다. 현행·연동 대상 21개에 720개 화면 레코드가 있습니다. 표시 유형은 389 페이지, 177 모달, 143 시트, 7 팝오버, 4 토스트입니다. 39개 보관 레코드는 작업 범위와 분리했습니다.
- 이어갈 실제 작업 · 상점 구매 확인 모달, 스케줄 이야기 변경과 정보 바텀시트, HUD 주사위·새 도시부터 실제 화면과 조작을 점검합니다. 기능 전용 치수의 예외를 먼저 명세하고 같은 역할의 재사용 가능한 부품을 보드로 모읍니다.

- 직접 적용 2차 · 상점 r14 구매 확인, 스케줄 r26 이야기 바꾸기, HUD r75 엔터파워 해금, 새 도시 r8의 0·49·50바퀴 상태를 UI 스튜디오에서 편집하고 저장했습니다. 실제 진입과 닫기·탭을 검수했습니다. 새 도시 세 상태는 정적 표시 검수입니다.
- 가이드 · 계획·부품서·화면 및 입력 검수표·이미지 목록·화면 비교를 UI 스튜디오의 가이드에 연결했습니다.
- 진행 중 · 기능별 상태 변형의 적용과 편집 가능한 전체 공통 부품 보드는 계속 검수합니다.

- 직접 적용 3차 · 공통 부품 보드 r9를 Studio에서 제작하고 가이드에 검수 대기로 올렸습니다. 기존 판·창 9슬라이스 규칙을 저장 전 검사에 연결하고 확대·축소 대조를 추가했습니다.
- 병행 적용 · 정보 후속 r7에서 두 멤버의 컨디션 시트와 배정 확인 모달을 적용하고 기존 동선을 실행기로 확인했습니다. 다른 정보 시트와 결과 창은 계속 검수합니다.

- 검수 게시 후 병행 · 정보 후속 r11의 카드 영수증·획득 효과·두 스토리 시트를 조정했습니다. 영수증 복귀와 스토리 상세 진입을 확인했습니다. 공통 부품 보드 검수 상태는 대기로 유지합니다.
