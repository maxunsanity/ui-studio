UI 스튜디오 보드 캔버스

인게임 굴리기 HUD와 50바퀴 표시

새 도시에서 기존 굴리기 대기 화면의 팀·엔터파워·팬·설정, 하단 재화 띠, 배수 선택과 주사위 굴리기 버튼을 같은 규격으로 씁니다. 3D 도시 보드는 컬러, 2D HUD는 흑백입니다.

상단에 「한 번 입장에 최대 50바퀴」와 「완료 0 / 50」를 별도 텍스트로 표시합니다. 입장 직후 0이며, 01번 출발점을 돌아오거나 통과하면 완료 수를 1 올립니다. 50 / 50에서는 하단 굴리기를 잠그고 방문 정산으로 이어집니다.

기준은 390×844입니다. 굴리기 HUD r73의 flow-01을 참고했습니다. 하단 재화 띠 386×37, 배수 버튼 93×43, 굴리기 버튼 275×61입니다. 바퀴 표시 297×46은 이 화면의 검수용 배치입니다.

첫 굴리기 · 0 / 50 · 마지막 바퀴 · 49 / 50 · 방문 완료 · 50 / 50

49 / 50 페이지에서 굴리기 버튼을 누르는 동작 시험은 01번을 지나는 고정 검수 사례입니다. 실제 굴림, 주사위 차감, 정산 지급과 로비 이벤트 복귀는 게임 연동 범위입니다.

입장과 한 바퀴

방송 출연으로 입장 게이지를 채웁니다. 가득 찬 게이지는 입장 전까지 더 차지 않습니다. 로비 이벤트에서 열며, 앨범 보유와 팀 능력은 각각 확인합니다. 게이지 이름과 로비 내 정확한 위치는 결정 대기입니다.

보유 주사위로 움직이고 최대 50바퀴 방문합니다. 정상 완료는 출발점으로 돌아와 50번째 바퀴가 완성될 때입니다. 정산 안내 칸에서 방문 중간 결과를 확인하고 방문을 마칠 때 결과를 정산합니다. 초과 이동 처리와 중도 귀환은 결정 대기입니다.

혜택과 원본

공연 수익, 현지 팬, 카드 보상은 기존 방문안보다 혜택을 늘리는 방향입니다. 칸별 지급량, 배수, 바퀴별 보상과 최종 보상은 발란스 대기입니다.
