# 출연권 대전 · 전체 공격 기획 v01

2026-11-25 · 단이 · 제안(검수 대기)

## 1. 기능과 진입

보드 쟁탈 칸 도착 → 타이틀·상대 매칭 → 상대 마을 → **전체 공격** → 출격 확인 → 몬스 출격·교대 사격 → 전체 공격 결과 → 같은 보드 칸 복귀.

상대 마을의 9개 시설 과녁은 그대로 사용한다. 과녁을 눌러 한 시설을 공격할 수도 있고, 하단 **전체 공격**을 누르면 현재 상대의 공격 가능한 시설이 자동으로 잡힌다. 이미 피격된 시설도 외형 단계가 남아 있으면 대상에 포함한다. 미건설·잔재·현재 공격 불가 시설은 제외하고 확인창에 이유를 표시한다. 대상이 0곳이면 버튼을 비활성화한다. 전투 전 취소는 같은 마을로 돌아간다.

## 2. 한 판의 판정

| 순서 | 제안 규칙 |
| --- | --- |
| 출격 확정 | 동일 상대의 최신 시설과 방어 상태를 확인해 1회 요청으로 대상 목록을 고정한다. 화면을 연 뒤 목록이나 비용이 달라졌으면 확인 화면을 갱신한다. 같은 도착에서 단일·전체 공격은 하나만 확정할 수 있다. |
| 공용 방어 | 기존 공용 방패가 공격 전 판정에서 발동하면 이번 전체 공격을 막고 기존 규칙에 따라 한 번만 소모한다. 공용 몬스 수비가 판 전체를 막는 분기도 같은 기준을 쓴다. 마지막 수비를 소진한 판도 방어 처리한다. |
| 시설 판정 | 공용 방어를 넘긴 경우 대상 시설마다 적중·방어·빗나감 결과를 기록한다. 시설별 보호가 있는 경우에만 개별 방어 결과를 쓰며, 현재 지원하지 않는 방어 종류는 추가로 가정하지 않는다. 현재 피해는 적중한 시설에만 반영한다. |
| 피해 | 시설당 피해 최대 1단계를 제안한다. 잔재는 추가 피해를 받지 않는다. 판 전체 피해 상한과 공격·수비 기분 소모는 발란스 대기다. |
| 확정·복귀 | 방패·기분·시설 피해·소득은 한 결과로 한 번만 확정한다. 새로고침·재접속·다시 보기에는 같은 결과를 보여 준다. 연출 도중 끊겨도 결과를 다시 뽑거나 소득을 다시 지급하지 않는다. |

## 3. 혜택과 소득 편차

**최종 획득 = 기본 소득 + 적중 소득 합계**로 제안한다. 적중 소득은 각 적중 시설의 승인 계수와 현재 단계에 따라 계산하고 한 판 소득 상한을 적용한다. 전체 공격 출격을 정상 완료하면 공용 방어에 막히거나 전부 빗나가도 기본 소득을 받는다. 취소·매칭 실패·확정 전 오류는 완료 수입이 없다.

| 결과 | 공격자에게 보이는 수입 | 시설 변화 |
| --- | --- | --- |
| 최소 | 기본 소득만 | 적중 0곳 |
| 일부 적중 | 기본 소득 + 해당 시설 적중 소득 | 적중한 시설만 손상 |
| 큰 소득 | 기본 소득 + 여러 시설의 적중 소득, 한 판 상한 적용 | 여러 시설에 손상 |

- 기본 소득, 시설별 적중률·계수, 상한, 출격 비용과 주사위 배수 연동은 발란스 대기다. 비용을 도입한다면 확인창에 비용을 따로 표시하고, 결과에는 획득·비용·순증감을 구분해 기본 소득과 순이익을 혼동하지 않도록 한다.
- 이 혜택은 기존 ‘출연권 대전은 보상 없음’ 기준에 대한 **전체 공격 전용 신설 제안**이다. 기존 보드 도착 수입과 단일 공격을 재정산하지 않는다. 공격자 소득과 상대 잔액 차감의 관계는 별도 결정한다. 시안의 8개 대상과 적중 0·3·7곳은 화면 검수 사례다.
- 발란스 검수는 방패가 많은 상대의 최저, 중간 적중, 방어가 약한 상대의 최고, 낮은 단계 시설이 많은 경우, 출격 비용 대비 순증감과 부계정·동일 상대 반복 시 소득 편차를 비교한다.

## 4. UI 작업 명세

| 화면 | 정보 우선순위 | 연결 |
| --- | --- | --- |
| 상대 마을 · 전체 공격 진입 | 정상·피격 흔적이 있는 기존 9개 시설, 하단 전체 공격과 다른 상대 | 전체 공격 → 확인 모달. 시설 과녁 → 기존 단일 공격 확인. |
| 전체 공격 확인 모달 | 상대 이름, 공격 가능 범위와 제외 수, 최소~최대 예상 소득, 방패·수비에 따른 변화, 확정된 비용이 있다면 비용 | 취소 → 해당 마을. 출격 → 전체 공격 장면. |
| 전체 화면 교대 사격 | 3D 마을 전체 구도, 방패 발동·시설별 적중 표시, 몬스 교대 사격 | 처리 종료 → 결과 모달 자동 진입. 검수판의 결과 버튼은 경로 확인용이다. |
| 결과 모달 | 획득 총액, 기본·적중 소득, 적중·방어·빗나감·제외 시설, 변경 단계 | 결과 모달 → 보드로. 시설별 목록은 필요 시 내부 스크롤. |

기존 방패·과녁·시설 썸네일·전투 컷·9슬라이스 프레임을 재사용한다. 3D 컷은 컬러, 2D 정보·아이콘은 흑백, 설명·표·버튼은 편집 가능한 시스템 폰트로 표현한다. 마을 전체 구도 및 다중 피격 효과는 실제 게임 연출 작업 항목이다.

## 5. 수락 기준

- 양쪽 상대 마을에서 건물을 한 번도 고르지 않고 전체 공격으로 진입하고, 취소 시 그 상대 화면을 다시 본다.
- 기존 시설 과녁과 다른 상대 선택이 함께 동작한다. 대상 0곳에서는 출격하지 않는다.
- 공용 방어가 발동한 판에서는 모든 시설이 그대로이고 기본 소득 한 번이 기록된다. 일부 적중·다수 적중은 각 시설 결과와 소득 합계가 일치한다.
- 공격 확인 이후 재시작·재접속·중복 완료에도 상태 변경과 소득이 각각 한 번만 기록된다. 출격 취소 시 피해·차감·수입 변화가 없다.
- UI 시안에서 최소·일부 적중·큰 소득 3개를 확인하고 모두 같은 보드 복귀 경로를 사용한다.
