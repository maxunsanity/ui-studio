- Studio의 배치 함수로 논리 화면의 버튼 4,148개를 계산했습니다. 이름·ID가 닫기 또는 뒤로에 해당하는 539개 중 479개가 검수안 44px보다 작습니다. 실제 입력 보정, 겹침과 흐름은 화면별로 확인할 후보입니다. 건설 상세의 기존 닫기도 42×41px에 해당하므로 공통 닫기 부품 적용 단계에서 검수합니다.
