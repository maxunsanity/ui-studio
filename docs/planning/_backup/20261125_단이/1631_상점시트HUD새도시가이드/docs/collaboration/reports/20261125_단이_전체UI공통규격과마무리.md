## 전체 저장판 입력 점검과 회귀 시험

- Studio의 배치 함수로 논리 화면의 버튼 4,148개를 계산했습니다. 이름·ID가 닫기 또는 뒤로에 해당하는 539개 중 479개가 검수안 44px보다 작습니다. 실제 입력 보정, 겹침과 흐름은 화면별로 확인할 후보입니다. 건설 상세의 기존 닫기도 42×41px에 해당하므로 공통 닫기 부품 적용 단계에서 검수합니다.
- 저장 종류와 별도의 연출 창 유형을 함께 기록했습니다. 31개는 창 표시가 저장 종류와 다릅니다. 건설 현황처럼 페이지 데이터를 시트로 띄우는 디자인도 포함되므로 표시 차이 자체를 결함으로 처리하지 않습니다.
- 공통 버튼·눌림·프레임·오버레이 단위 시험 37건이 통과했습니다. 전체 `npm test`는 741건 중 730건 통과, 11건 실패입니다. 실패 범위는 공통 미리보기 치수·스크롤, 도구 헤더 테스트의 함수 정의, 로비 부품 연결, 상점 모의 구매입니다. 대표 건설 저장판과 별도의 테스트 결과이며 이번 작업에서 Studio 공통 엔진 소스는 수정하지 않았습니다.
