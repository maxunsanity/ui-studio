대표 화면

프로필·의상 기존 화면 적용

프로필·의상 r9 · HUD r15 · 포토카드 r33 · 관계 r12 · 스케줄 r20 · 상점 r10 · 미션 r12 · 크루 r8

  • K-01 HUD 프로필　HUD와 판 진행 중 HUD에서 공통 팀 정보로 진입합니다. 정보 메뉴의 아이돌과 팀도 같은 정보로 열립니다. 솔로 HUD는 솔로 아이돌 정보를 엽니다.
  • K-02 팀 보기　포토카드 팀 보기와 HUD가 같은 팀 정보를 엽니다.
  • K-03 캐릭터 정보　포토카드 인물과 프로필 멤버에서 오시온·한서아의 공통 화면을 사용합니다. 능력·포토카드 수집·옷장은 공통 화면의 버튼으로 엽니다.
  • K-04 포토카드 명세　정보 화면과 카드 수집 화면의 역할을 연결했습니다. 개인 착용과 팀 단체 의상 규칙을 반영했습니다.
  • K-05 현재 외형　포토카드 인물 목록·HUD·공통 정보의 초상과 전신이 미리보기에서 적용한 외형을 읽습니다. 수집 카드의 전용 그림은 계속 사용합니다.
  • K-06 상점 꾸밈　기존 상점에 꾸밈 판매 준비 화면과 획득·착용 선택을 추가했습니다. 탭 공개 시점과 가격은 대기 중입니다. 판매 준비 상태에서 검수용 획득 흐름을 열 수 있습니다.
  • K-07 시즌 패스·이벤트　미션 이벤트와 시즌 패스 보상에서 의상 아이콘이 있는 보상 카드를 확인하고, 수령 → 새 의상 → 착용 대상 선택 → 옷장으로 이동합니다.
  • K-08 기록 당시 외형　실제 7018 스케줄의 기록장·엽서·탐험 결과에 기록 초상과 당시 표시를 넣었습니다. 게임 저장 계약은 S17에서 확인합니다.
  • K-09 인물과 공연　관계, 관계에서 이어진 스케줄 편성, 공연 무대에서 검수용 현재 착용을 공유합니다. 스케줄 장소·이야기 배경 연출은 기존 방식을 따릅니다. 상황별 무대복·사복 규칙은 미정입니다.
  • K-10 판 진행 중　판 진행 중 HUD에서 보기 상태의 팀 정보를 열고, 개인·단체 적용과 수령 후 바로 입기를 제한합니다. 게임 상태 공급원은 개발 연결 범위입니다.
  • K-11 첫 팀 이름　P100 첫 팀 이름 검수 보드에 두 번째 합류 후 팀 이름과 무료 변경 안내를 연결했습니다.
  • K-12 공개 팀 정체성　팀 꾸미기 미리보기에서 크루원 카드·월드 카드로 이어집니다. 공통 팀 마크와 이름을 표시하고, 다른 유저의 의상 표시 범위는 기획 결정 대기입니다.
  • K-13 7007 시뮬레이터　별도 게임 시뮬레이터 개발 항목. S17 연결 계약과 함께 확인합니다.
  • K-14 효과 데이터　게임 효과와 수치는 승인된 의상·세트 표 및 발란스 장부에서 가져옵니다. 7018 수치와 외형 변화는 검수용입니다.
