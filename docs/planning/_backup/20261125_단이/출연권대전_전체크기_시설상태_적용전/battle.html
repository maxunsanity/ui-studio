출연권 대전

2차 세부 와이어프레임 r11 · 검수 대기

도착에서 보드 복귀까지

  1. 6번 쟁탈 칸 도착

    확대 보드에서 말이 티켓 칸에 멈춥니다.

  2. 하단 도착 안내

    도착 칸과 콘텐츠를 안내합니다.

  3. 출연권 대전 · 매칭

    보드 배경을 걷고 타이틀과 매칭 상태를 중앙에 표시합니다.

  4. 상대 기획사 공개

    같은 타이틀 카드에 상대 이름과 엠블럼이 나타납니다.

  5. 상대 마을과 과녁

    정상과 파손을 구분하며 공격 가능한 시설은 과녁이나 카드 전체를 누릅니다.

  6. 공격할 시설 확인

    선택한 건물과 출격을 확인합니다.

  7. 몬스 출격

    기존 시뮬레이터의 몬스 준비 동선을 사용합니다.

  8. 10초 교대 사격

    기존 시뮬레이터에서 직접 캡처한 사격 컷입니다.

  9. 시설 피격 또는 방패 방어

    기존 시뮬레이터의 분기 장면을 재사용합니다.

  10. 중앙 결과 모달

    파손과 방어에 맞는 내용을 표시하고 보드로 돌아갑니다.

  11. 같은 보드 복귀

    도착 칸과 기존 확대 시점을 유지합니다.

건물 상태와 공격 입력

멀쩡한 시설과 피해 입은 시설을 색과 상태 문구로 구분합니다. 시설당 과녁 1개. 과녁과 카드 전체를 같은 터치 영역으로 처리합니다. 파손된 시설도 남아 있는 외형 단계가 있으면 공격할 수 있습니다. 잔재 단계0은 정식 선택에서 비활성입니다.

상대 교체는 다른 상대 고르기에서 합니다. 처음 들어올 때만 타이틀과 상대 공개를 보여 줍니다.

기존 공격 연출

출격 준비 → 10초 교대 사격 → 방패 또는 건물 피격 → 기분과 수비 수 정산. 캔버스는 기존 시뮬레이터의 네 대표 장면을 순서대로 엽니다. 캡처는 결과 계산을 실행하지 않습니다.

시뮬레이터에서 기존 공격 연출 재생

결과 모달과 복귀

피격 화면 위에 건물 적중 또는 방어 성공 결과를 보여 줍니다. 확인 후 같은 보드와 도착 위치로 돌아갑니다. 확정된 결과에서 필요한 값만 읽으며, 화면을 다시 열어 결과를 재계산하지 않습니다.

검수 경로는 로딩 카드와 상대 공개 카드를 눌러 진행합니다. 게임은 각각의 준비 완료 상태를 확인한 뒤 자동 진행하는 기획입니다.
