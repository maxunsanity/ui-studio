구분발동과 처리
해금엔터파워 최고 도달 수치가 500 이상인 계정에 도시 습격을 해금한다. 500 미만은 기존 단일 시설 방어를 사용한다.
충전첫 게이지 만충으로 한 곳을 기록한다. 방어하지 않고 직접 진행하면 같은 입력에서 두 번째 게이지가 첫 번째보다 더 많이 오른다. 이후에도 단계마다 충전량이 커지고, 9번째의 증가량이 가장 크다. 첫 만충의 자동 굴리기 중단을 유지한다. 붉은 단계는 직접 주사위 굴림과 해당 플레이 이벤트만 누적한다. 접속 공백·유휴 시간만으로 단계가 오르지 않는다. 해금 조건에서는 5분이 지나도 위험 1곳을 유지한다. 그 뒤 첫 수동 진행부터 붉은 게이지가 오른다. 500 미만은 기존 단일 습격 정책을 따른다.
위험과 피해1~8곳은 사건의 서로 다른 시설을 순차 지정한다. 위험 번호와 시설을 재접속 뒤에도 유지한다. 2~8단계의 접근·포위는 지도 연출이며 시설 내구도와 외형은 전투 결과로 적용한다. 8에서 9로 넘어갈 때 같은 습격 ID로 한 번만 도시 전투를 연다.
중간 방어9곳 전에는 기존 선두 시설 방어에 들어갈 수 있다. 기존 5분·자동 굴림·단일 시설 무대 자산을 재사용한다. 방어를 선언하면 현재 충전을 멈추고, 성공 시 사건의 위험을 모두 해제한다. 단일 시설 방어 실패 피해는 해당 시설에만 적용한다.
몬스 출격 편성보유 몬스를 하나의 출격 명단에 편성한다. 1단계부터 9단계까지의 출격 상한은 조정표에서 각각 관리한다. 보유 몬스 범위에서 선택하며 같은 개체는 한 번만 출격한다. 5마리는 1단계 상한이다. 해제 시 남은 칸 수를 갱신한다.
도시 전투와 결과1~8단계는 선두 시설을 기존 방식으로 방어하고 9단계는 도시 전체를 방어한다. 전투 중 하나의 출격 수를 표시한다. 결과에서 방어 시설 수와 실제 피해 시설을 보여 주며 같은 습격 ID의 피해를 한 번만 반영한다.
발란스 조정 항목단계별 출격 상한은 5→20마리의 검수용 초기안이다. 실제 조정 항목은 단계별 출격 상한, 충전 배율, 시설 피해 상한, 도시 습격 미참여, 보상이다.

전체 전투 화면 · 스킬 오버레이

전장이 화면 전체를 채웁니다. 상단은 시설 내구도·웨이브·시간, 하단은 출격 몬스·처치·보상 정보와 공통 스킬 버튼입니다. 미습득이나 재사용 대기 중에는 시뮬레이터 상태를 따릅니다. 스킬 후보 3장은 전장 하단에 자동으로 겹쳐 뜹니다. 성공·실패 결과도 전장이 보이는 상태에서 모달 오버레이로 표시합니다. 7018 미리보기는 전투 진입 8초 뒤 스킬 오버레이를 확인할 수 있습니다.

몬스와 시설 결과 연출

수리비 표시 조건 방어 성공 시 연습실은 정상 이용 상태이며 수리비가 없습니다. 방어 실패나 습격을 그냥 두어 시설이 파손된 경우에만 수리비와 수리하기를 표시합니다. 실패 제목은 「방어에 실패해 연습실이 파손됐어요」입니다.

획득한 보상은 스케줄 결과와 같은 아이콘·이름·수량 타일로 표시합니다. 성공은 처치 보상과 지킴 덤이 포함된 돈을, 패배는 처치로 얻은 돈을 보여 줍니다. 보상이 없는 상태는 빈 보상 타일을 표시합니다. 수량은 검수용 예시입니다.

같은 카메라 구도에서 결과를 보여 줍니다. 성공하면 건물에 빛이 돌고, 앞에 모인 방어 몬스가 기뻐합니다. 실패하면 한 단계 전 외형의 건물에 균열이 드러나고, 참가 몬스가 건물 앞에 남습니다. 세부 와이어프레임은 두 연출의 마지막 장면을 보여 줍니다. 기존 시설 단계는 유지하고 수리하면 파손 표시를 지웁니다. 수리는 건설의 같은 시설로 연결하며 수리비는 마지막 건설비의 50%입니다.
