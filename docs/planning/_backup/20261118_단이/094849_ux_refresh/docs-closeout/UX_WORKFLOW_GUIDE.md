# 전체 캔버스·상세 편집·디자인 가이드

## 화면 전체를 고르기

1. 7018 UI 스튜디오의 전체 캔버스에서 프로젝트와 저장 설계 이름을 확인하세요.
2. 왼쪽 목록이나 가운데 보드를 눌러 화면을 고르세요. 오른쪽에서 설명·종류·논리 크기·출입 연결을 읽을 수 있습니다.
3. 정렬 보기에서는 화면을 다섯 개씩 한 줄에 봅니다. 연결 보기에서는 저장된 목적지 사이의 선을 확인하고 보드를 끌어 위치를 바꿀 수 있습니다. 보드에 초점을 둔 뒤 방향키로도 옮길 수 있습니다. 확대·맞춤은 캔버스를 보는 배율을 조절합니다.

## 같은 화면을 세 표현으로 보기

| 표현 | 확인할 내용 |
| --- | --- |
| 와이어프레임 | 큰 구역의 상대 배치. 게임 그림과 제품 문구를 숨깁니다. |
| 세부 와이어프레임 | 실제 그림의 투명 윤곽·단색 면·얕은 그림자, 원래 글자와 부품 간격. 3슬라이스 버튼의 양끝과 늘어나는 중앙도 같은 크기 체계를 따릅니다. |
| 본 UI | 최종 이미지·색·효과가 적용된 화면. |

표현을 바꾸어도 편집할 화면과 파일은 같습니다. 기본 와이어에 버튼·아이콘 자리·텍스트 행 도형을 더하는 보강판은 실화면 확인 중입니다.

## 한 부품을 고쳐 확인하기

1. 선택한 화면에서 ‘상세 편집’을 열고 부모나 자식을 고릅니다.
2. ‘디자인 가이드’를 열어 화면 이름과 부모·자식 경로를 확인합니다. 위치·크기·선·이미지 등 필요한 항목을 조절합니다.
3. ‘미리보기’에서 선택 화면 하나를 확인합니다. 상세 편집의 미저장 변경도 포함됩니다. 모달을 고르면 해당 모달을 단독으로 봅니다.
4. 저장한 결과를 다시 볼 때는 상세 편집에서 파일에 저장한 뒤 ‘저장 샘플 보기’를 엽니다. 다른 페이지나 모달은 샘플의 화면 선택에서 고릅니다. 실제 게임 연결을 따라가는 검사는 별도의 동작 시험에서 합니다.
