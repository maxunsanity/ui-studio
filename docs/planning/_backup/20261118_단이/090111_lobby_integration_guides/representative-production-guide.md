## 이번 실수와 재발 방지

- 여러 부모의 부품을 Meta 선택해도 실제 복사는 마지막 부품만 남을 수 있었다. 붙여넣기 후 ID/개수를 읽고 누락 부품만 별도 native 복사했다.
- 이미지 분해 기본값은 그림84%×65%/라벨Y76%여서 뽑기 밑판은 얇아지고 글자가 밑으로 내려갔다. 그림/라벨100% 보정 후 모바일에서 자식4개의 실제 bounds가 입력과 같음을 확인했다.
- 자동 라벨에 내부 Btn_* 이름이 노출됐다. 아이콘 버튼도 빈 문자열을 명시해 지운다. 복제된 Close 행동 이름에 옛 골드/펀드가 남아 있어 각 화면 이름으로 정정했다.
- 자원 등록 도중 실패한 뒤 이미 만들어진 교환 부품을 다시 생성하지 않았다. 선택 ID부터 읽고 그 부품의 빠진 자원 적용 단계만 완료했다.
- 같은 녹색 구슬로 처리했던 달력의 금빛 원형 아이콘은 확대 비교 후 별도 새 그림으로 고쳤다. 색 이름·작은 썸네일만 보고 넘기지 않는다.
- PNG 자원도 있어 SHA 파일명을 .webp로 단정하면 안 됐다. 실제 선택된 SHA와 확장자를 확인한다.
- 클릭 직후 fade 중 캡처는 색이 연해지거나 두 팝업이 겹쳐 보였다. opacity1/로딩 완료를 확인하고 최종 캡처한다. 불투명도 문제를 자원 색상 문제로 단정하지 않는다.
- DOM 래퍼에서 inert 속성이 undefined로 보인 것을 false로 단정하지 않는다. hasAttribute('inert')와 실제 Tab 가두기·초점 복귀로 확인한다.
