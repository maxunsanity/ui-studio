## 1. 원본과 비교할 샘플부터 읽기

1. `reference/video-analysis-20261118/source.json`의 영상 경로·SHA·56.95초·504×894를 확인합니다. 영상은 수정하지 않습니다.
2. 2fps 114장과 scene-cut 36장을 훑고 대표14장을 확대합니다. 스크롤 위치·로딩·숫자 애니메이션은 새 페이지로 세지 않습니다. 온보딩 A01은 분석 전용입니다.
3. `ui-inventory.json`으로 UI 유형/관찰 시각을 찾고, `sample-reference-data.json`의 카피바라고 r90 실제 부품 데이터를 먼저 봅니다. 요약 그림만 보고 ‘비슷하다’고 판단하지 않습니다.
4. 공통 구조를 재사용합니다. HUD의 자원 입력 부모와 표시 자식, 5개 하단 메뉴, 정상/눌림 이미지 슬롯, 팝업의 닫기/연결 구조는 비교 가능합니다. 로얄매치의 파랑·금색 바탕, 두 개 메인 버튼, 선택 메뉴 확대, 화면 문구·배열은 새 규격과 그림으로 바꿉니다. 카피바라고 원본을 수정하지 않습니다.

## 2. 샘플과 내 작업을 분리하기

스튜디오는 7018입니다. 샘플 정본은 `samples/royal-match`, workspace `workspace-fd5ecb11-2d17-4d9f-b610-f8989abc9fd4`, 설계 `ux-9f500ab8`입니다. 신규 프로젝트에는 native ‘사본 준비’로 복사해 작업합니다. 샘플 정본·기존 Mono/Capy·공통 서버를 임의 변경하지 않습니다.

빈 폴더를 native 등록하기 전에 `ui-studio/`와 가짜 `project.json`을 만들지 않습니다. 등록은 스튜디오가 합니다. 자원·조사서는 별도 폴더에서 준비한 후 등록된 작업공간에 넣습니다. 모든 화면/부품/연결은 실제 편집기의 native 조작으로 만듭니다. 저장 JSON의 외부 수정·주입은 금지합니다. JSON 읽기는 저장 결과 감사와 실제 계층 비교용입니다.

## 3. 잘라 붙이지 않고 새 그림 만들기

분석 캡처를 생산 이미지로 사용하지 않습니다. 방·왕·아바타·배지·아이콘은 새로 그리고, 글자·가격·수량·진행도·입력은 native 부품으로 분리합니다. 퍼즐은 새로 그린 정지 장면입니다. 원화는 `ui-studio/assets/authoring/v001`, 생산 WebP는 `production/v001`, 실제 native 등록본은 `assets/sha256-…webp`입니다. 자원 근거/SHA/크기는 `_작업/codex/video01/assets.json`을 따릅니다.

형태가 단순한 밑판·프레임은 새 기하 형태와 연속 그라데이션으로 제작합니다. 반으로 나뉜 단색 띠·검은 부분 백판으로 대충 때우지 않습니다. 확대해 상단 하이라이트, 테두리, 눌린 앞면 위치, 바닥 그림자, 모서리 반경, 투명 여백을 확인합니다. 실패 원화는 삭제하지 않고 미사용으로 보존합니다.

## 5. 버튼과 연결

기본/눌림 원화는 같은 캔버스·기준점으로 저장합니다. 원화 비율과 입력 영역 비율이 다르면 contain에서 두께가 바뀌므로 메인214×100에는 전용 원화를 사용합니다. 상태별 독립 alpha crop은 하지 않습니다. hover/disabled 전용 원화가 없는 것은 없는 상태로 기록합니다.

하단 5메뉴는 실제 저장 화면으로 연결하며 각 페이지의 선택 메뉴 그림만 크게 합니다. 레벨25 → 준비 팝업 → 플레이 → 퍼즐 스틸, 로비 자원/프로필/설정/이벤트 → 관련 팝업, 닫기/계속을 연결합니다. 복귀 선물 ‘탭해서 받기’는 로비 이동만 합니다. 실제 지급은 없습니다.

영상에서 누르지 않은 현재 장소·킹스컵 플레이·상점 구매·친구 수락/거절·팀 돕기/메시지/요청·외부 지원/약관은 눌림 표시만 둡니다. 목적지나 결과를 창작하지 않습니다. 자동 복귀 팝업 진입은 별도 연결하지 않았다면 미연결로 기록합니다. `connections.json`의 계획과 `saved-data-audit.json`의 실제 저장 전이를 구분합니다.

설정 4개는 선택 가능한 이미지 버튼입니다. 기본/눌림은 꺼짐, 선택은 켜짐 그림을 씁니다. 빈 native 토글을 쓰면 체크박스와 기술 이름이 표시되는 문제가 있어 사용하지 않았습니다. 실제 음향/알림 설정을 변경하지 않습니다.

## 6. 이번 실수와 재발 방지

- 작은 목표를 우체통으로 오독했습니다. 세 번째 목표는 **하트 편지봉투**입니다. goal-mail은 미사용, goal-envelope가 정본입니다.
- 프로필 완료 공간은3이 아니라 **2**입니다. 상품명은 **왕자의 보물**입니다. 표본값은 화면 확대 확인 후 `sample-data.json`에 기록합니다.
- 아바타는 털/왕관이 아니라 매끈한 보라 괴물과 녹색 배경입니다. v003을 사용합니다. 왕 컵 그림은 회색 수염·보라 옷입니다. 퍼즐 초상과 억지로 빨강 옷으로 통일한 v002는 미사용입니다.
- 원화의 추가 사다리·천·왕관·망토는 제거한 판을 사용합니다. 같은 색이라도 형태가 다르면 통과시키지 않습니다.
- native 복제한 루트의 부모가 화면 최상위로 바뀝니다. 내부 카드 복제 후 부모를 다시 지정하고 로컬 좌표를 넣습니다. 상점 두 상품/골드 카드가 틀어졌던 것을 이 순서로 고쳤습니다.
- 뒤에 추가한 하단 밑판이 모든 아이콘을 덮었습니다. 5화면 모두 밑판을 맨 뒤로 옮기고 모든 메뉴를 재확인했습니다.
- 이미지 경로 칸은 일반 파일 경로를 직접 받아 주지 않습니다. 실제 파일 선택으로 등록하고 저장된 이미지 목록/SHA를 확인합니다.
- locator.fill만으로 이름·숫자 입력이 저장됐다고 판정하지 않습니다. 정상 AX에서는 setValue→Tab→재표시. AX 관찰이 unreachable이면 DOM snapshot과 실제 키 입력으로 복구합니다. 텍스트는 전체선택→키입력→Tab, 숫자는 펼친 입력에서 값/화살표 조작 후 다시 펼쳐 확인합니다. 세부패널이 렌더 뒤 닫힐 수 있습니다. 반드시 파일 저장 후 읽기 대조합니다.
- 실패한 AX 관찰이 탭 생성 자체 실패를 뜻하지 않습니다. 탭 목록 확인 후 기존 탭의 DOM 지원 여부를 확인하고 중복 탭 생성을 피합니다. 보안/잠금 문제로 단정하지 않습니다.
- 긴 CUA 호출 시간초과 후 중복 복제하지 않습니다. 레이어 ID/미저장 상태부터 확인합니다. 파일 저장 revision 백업과 별도 기준 백업을 보존합니다.
- 이전 생성 스크립트가 전체 manifest를 덮어쓸 수 있습니다. `prepare_assets.py`를 무작정 재실행하지 말고 현 manifest와 병합하는 작업만 합니다.
