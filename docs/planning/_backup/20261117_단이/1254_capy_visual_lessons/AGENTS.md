# 카피바라고 샘플 UI 작업 지침

최신 사용자 직접 지시와 상위 UI Studio AGENTS.md가 우선합니다. 이 폴더는 2차 채팅의 독립 카피바라고 샘플입니다. 1차 모노폴리 GO의 제작·설계·공용 수신을 중복 수행하지 않습니다.

1. README.md → reference/video-analysis-20261117/분석보고.md → ui-inventory.json → ui-connections.json과 해당 원본 캡처를 읽습니다. 원본 보존 영상과 source.json SHA도 대조합니다.
2. 사용자 지시: 게임 장면은 스틸샷으로만, UI 관련 작업만 합니다. 모든 관찰 UI는 로비를 출발점으로 미리보기에서 입구/닫기/복귀가 연결되어야 합니다.
3. 영상 분석 단계입니다. 캡처 전체를 완성 UI로 등록하거나 목록 JSON을 설계 JSON이라고 부르지 않습니다. UI Studio 등록/조립은 정식 UI 조작과 기존 저장 계약을 사용합니다. 외부 설계 JSON 편집으로 우회하지 않습니다.
4. 기존 게임 소스가 제공된 것이 아닙니다. 독립 샘플 UI만 만들고 실제 결제·계정 연동·서버 변경·문의 전송·게임 상태 쓰기를 하지 않습니다. Chrome 온보딩은 제작 제외입니다.
5. 원본 504×894 px, 설계 논리 px/부모 %, CSS viewport·확대율을 구분합니다. 그림/텍스트/입력/BG/Frame을 분리하고 이름을 바꾸며 stable ID·parentId·연결을 재발급하지 않습니다. 수치는 원본 관찰 fixture이며 게임 정책 확정값이 아닙니다.
6. 원본 영상/캡처/이전 시안은 보존하고 수정 전 백업합니다. 자기 임시는 이 샘플의 _작업/codex/에 둡니다. 이 샘플의 보고는 docs/collaboration/에 남깁니다. 다른 프로젝트 파일/보호 파일을 접근·수정하지 않습니다.
7. 1차 탭/모노폴리 GO 설계/전역 current-review 포인터/서버/가이드/예약은 이 샘플 작업만으로 변경하지 않습니다. 별도 UI workspace와 문서 ID를 확인합니다.
8. 구현·파일 검증·자동 시험·실제 화면 관찰·사용자 승인을 분리하고 모든 산출은 제안(검수 대기)입니다. 영상 밖 하위 목적지/규칙/값은 창작하지 않습니다.

## 최신 직접 지시 · 모든 그림 새 제작 / 로비부터 작업

현중: “다른 AI가 이걸 보고 따라 해야”, “문서도 스튜디오에”, “가이드 서류와 기존 방법을 확인해서 로비부터…1차와 겹치지 않게”, “그림은 잘라 붙이는게 아니라 전부 새로”. 공통 guide/VIDEO_UI_WORKFLOW.md를 필수로 읽습니다. 영상 캡처는 분석 참고용입니다. 실제 UI 일러스트·아이콘·장면 그림은 모두 새 제작하며 게임 장면도 새로 그린 스틸 이미지로 표시합니다. 글자/입력/BG/Frame은 분리 조립합니다. 1차 모노폴리 GO와 별도 workspace·설계·탭·자원으로 로비부터 진행합니다. 이번 공통 가이드 수정은 별도 명시 요청 범위이며 다른 담당의 소스/설계/자원/검수포인터는 수정하지 않습니다.
