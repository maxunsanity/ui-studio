## 앞으로 적용할 판단 순서
1. 이름/이미지부터 바꾸지 말고 기존 frame family의외곽·영역분할·header/footer·고정부/scroll영역을대조한다.
2. 같은부품의크기/행/열/정보/이미지/Close위치차이는명시variant로정리한다. 같은역할의메뉴·icon/text/뱃지는기존공통규격을유지한다.
3. 기존구조로표현할수있는화면은신규프레임제작에서제외한다. 신규보상/장착/구매기능이있어도프레임신규성과혼동하지않는다.
4. 전체구조가다른3후보만먼저세부구조를설계한다. 공통9slice·텍스트·딤·버튼·입체제작법은기존규칙을재사용한다. 모든그림을한장으로굽지않는다.
5. 과거목록·원본·완료/미완료는그대로보존한다. 제외를완료로바꾸지않는다. 관찰되지않은게임입구/동작은targetnull이다.
