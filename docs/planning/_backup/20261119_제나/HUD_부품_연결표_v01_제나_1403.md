## ① HUD 상태 수량표 (38가지 · 들어갈 화면)

**화면 번호**
- 기본 = 기존 기본 HUD 화면(이미 있음)
- 흐름 화면: ① 이동 중 · ② 자동 이동 중 · ③ 결과 뒤 늘어남 · ④ 주사위 0개
- 모음 화면: ⑤ 필러 카드 모음1(시뮬 15종) · ⑥ 필러 카드 모음2(모노 전용 8종·25) · ⑦ 버튼 줄 모음 · ⑧ 페스티벌 이벤트 박스

## ② 현중 님께 물을 질문 (우선순위, 하나씩)

1. 방패는 몇 개로 그릴까요? 설정값은 `board_shield_max`=3 (economy_config.csv:61)이고, 그림 안은 5개예요.
2. 주사위 「보유/상한」의 상한은 어느 값인가요? 자동 충전 상한 `reserve_cap` 30, 보관 상한 `max_dice_cap`(단계별 30부터) 중 하나예요. r50 예시 50/20은 설정값과 맞지 않아요.
3. 칸 버튼 글자는 최대 몇 자인가요? (4 / 5 / 6)
4. 배수 버튼 폭은 얼마로 할까요? 「×1000」 5자가 들어가야 해요.
5. 필러 대사 한 줄은 몇 자까지 넣을까요? 지금은 38자가 제안으로만 있어요.
6. 팀 이름은 최대 몇 자, 등급은 몇 자리로 보일까요?
7. 엔터파워·팬 숫자도 돈처럼 K·M·B로 줄일까요? 줄이지 않으면 몇 자리까지 보일까요?
8. 페스티벌 남은 기간은 게임 일차로 셀까요, 실제 시계로 셀까요? 「아닌 기간」은 주간 본행사 날만 빼고 볼까요, 접수 주중도 페스티벌로 볼까요?
9. 앨범 순위와 한 바퀴 보상 칩 숫자는 몇 자리로 보일까요?
10. 좌우 이벤트 칸 10개는 「보드 플레이 관련만」 기준으로 HUD에 남길까요?
11. 위쪽 줄 오른쪽 끝 설정 버튼은 남길까요?
12. 기록장·소식 탭은 HUD에 둘까요? 시뮬 공통 프레임에만 있고 늘 막혀 있어요. 확정 HUD 영역에는 자리가 없어요.

14. 드롭다운(설정·방패·몬스·정보)은 바깥을 누르면 닫히고, 여는 버튼을 다시 눌러도 닫히게 할까요? 원본에는 하단 탭 「다시 누르면 닫힘」만 있어요.
15. 시뮬에 연결이 없는 버튼(팀 얼굴, 보상 보기, 추천, 방패 팝업, 계정 메뉴, 복귀 굴리기, 꾹 누르기 자동)은 기획서 설명만으로 둘까요?
