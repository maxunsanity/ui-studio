# UX 기획 스튜디오 — 소스 안내

1차 정리 기준: 2026-11-13, 제안(검수 대기). 게임 엔진과 3D 자산을 불러오지 않는 DOM/CSS 편집기입니다.

## 실행과 책임

기존 7007 기획서 툴의 책갈피 → 툴 기획 → T04 → UX 스튜디오 열기로 진입합니다. 서버 빌드나 재시작은 이 소스 점검에 필요하지 않습니다.

- `main.mjs`: 편집 상태·명령·패널과 뷰 조정. 대량 선택 시 도구 재생성은 후속 최적화 대상입니다.
- `model.mjs`: 문서 검증·가져오기 경계. 파일 상한 2,000,000bytes, ID 검증.
- `layers.mjs`, `commands.mjs`: 계층 인덱스·그룹·검색·편집 명령.
- `history.mjs`: undo/redo 기록 삽입. 각각80개/직렬화 UTF-8약8MiB 예산, 최신1개는 보존. JS heap 상한이 아닙니다.
- `graph-view.mjs`: 관계도 지연 로딩·인스턴스와 DOM 재사용·해제.
- `workspace.mjs`: 도킹/분리 패널 배치와 설정 정규화.
- `layout-view.mjs`, `menu-state.mjs`, `bindings.mjs`, `units.mjs`: 가벼운 표시와 메뉴/기능 정의.
- `consumer.mjs`: 편집 라이브러리를 포함하지 않는 소비 경로. 게임 호스트 어댑터는 아직 없습니다.

저장 형식과 API 계약은 T04 및 S17 정본을 우선합니다. UI 편집 데이터가 게임 상태의 writer가 되지 않도록 합니다. 세계/필러 슬롯은 표시 자리이며 실제 콘텐츠 공급은 향후 호스트 책임입니다.
