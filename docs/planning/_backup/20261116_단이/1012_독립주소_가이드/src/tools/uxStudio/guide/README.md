## 무엇을 만드는 도구인가요
게임 UI의 화면, 부품, 배치, 입력, 이동과 연결 행동을 데이터로 만들고 시험하는 가벼운 웹 도구입니다. 완성 게임 그래픽 편집기나 게임 엔진의 대체품은 아닙니다. 디자인을 조립하고 저장한 다음 소비 렌더러에서 같은 설계를 읽는 구조입니다.

도구와 이 안내의 정본은 독립 프로젝트 /Users/max/projest_max/ui-studio/입니다. 소스는 이 루트의 src/tools/uxStudio/, 사용 설명서·툴 기획·제작 구조·AI 규칙은 그 안의 guide/에 있습니다. 케이팝의 옛 src/tools/uxStudio/는 이관 전 보존본이며 추가 편집하지 않습니다.

케이팝은 기획서·시뮬레이터 프로젝트이며 실제 게임이 아닙니다. 모노폴리 GO는 이 도구를 검증하기 위한 samples/monopoly-go/ 샘플입니다. 샘플 한 화면과 도구 전체, 실제 게임 연결의 완성을 서로 구분합니다.

게임마다 도구 전체를 복사하는 대신 선택한 게임 폴더 안의 ui-studio에 설계와 자원, 안내를 보관합니다. 폴더 선택은 게임 변경이나 기존 UI 변환에 대한 동의가 아닙니다.

## 도구를 여는 위치
이 Mac의 7007 기존 /docs/planning/ux-studio.html 진입은 유지하며, 독립 루트의 tools/ux-studio/mount.mjs와 저장 플러그인이 실제 소스·API를 연결합니다. 7007에서 열리더라도 편집 정본은 독립 프로젝트입니다. 이 안내를 읽기 위해 서버 재시작이나 빌드를 할 필요는 없습니다.

별도 실행이 필요하면 루트 README.md의 조건을 확인합니다. npm start는 scripts/start.mjs로 실행하며, 이 Mac에서는 기존 Vite 5.4.21 설치를 재사용합니다. 새 패키지를 설치한 상태로 설명하지 않습니다.

## 처음 할 일
1. 상단 가이드에서 사용 설명서와 기존 게임 변환·독립 작업을 읽습니다.
2. 게임 폴더를 선택합니다. 처음 연결할 때 기존 UI 변환 여부를 먼저 선택합니다.
3. 변환을 원하면 AI가 기존 UI 전체 조사·백업·변환·연결·검증을 수행해야 합니다. 선택만으로 변환이 끝나지 않습니다.
4. 변환을 거절하면 원래 게임을 건드리지 않고 해당 게임의 ui-studio 안에서 독립 UI 소스만 만듭니다.
5. 화면·부품·연결을 편집하고 동작 시험 후 저장합니다. 파일 재열기와 소비 화면도 확인합니다.

게임 폴더를 사용하지 않는 기존 저장공간도 보존합니다. 폴더 기능의 선택·저장·전환 세부 동작은 사용 설명서를 따르세요.
