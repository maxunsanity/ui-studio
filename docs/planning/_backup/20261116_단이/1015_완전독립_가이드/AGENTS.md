먼저 README.md, src/tools/uxStudio/guide/{AI_GUIDE,USER_GUIDE,TOOL_SPEC,ARCHITECTURE,EXISTING_GAME,PROGRESS}.md를 읽습니다. 코드 정본은 이 폴더입니다. 케이팝 중복 도구 101파일은 이 루트의 docs/planning/_backup/20261116_단이/1012_kpop중복정리/로 이동 보존했으며 보존본을 함께 편집하지 않습니다. 케이팝 src/tools/uxStudio/에는 기존 호스트·시험용 model.mjs·consumer.mjs export 연결 두 개와 README만 남습니다. 연결 파일에 도구 구현을 복제하지 않습니다. 케이팝의 기획서·시뮬레이터·공유 기록·옛 설계 데이터는 구분해 보존합니다. 현재 실제 구현과 기획·미확인을 구분합니다.

기존 게임 변환은 반드시 먼저 질문합니다. 폴더 열기를 변환 동의로 취급하지 않습니다. 거절 시 원 게임 소스 무수정, ui-studio 내부 독립 저장을 유지합니다. 허용 시 화면 전체 조사·백업·대응표·회귀와 미완료를 기록합니다. 임의 승인·미정 게임 수치를 만들지 않습니다.

정식 실행 주소는 http://127.0.0.1:7007/ui-studio/이며 preview.html·canvas.html·source/도 이 경로 아래입니다. 7007 프로세스는 케이팝 Vite와 공유합니다. 독립 소스 정본을 완전 독립 서버라고 표현하지 않습니다. 옛 도구 HTML 주소는 호환 진입으로만 취급합니다.

도구의 URL 경로와 게임별 저장공간을 구분합니다. 프로젝트 폴더 ID와 설계 projectId/revision을 함께 확인하고 API·미리보기·저장 통지를 같은 workspace 범위로 유지합니다. 심볼릭 링크·상위 경로 탈출과 저장 충돌 검사를 우회하지 않습니다. 프로젝트 가이드 사본을 자동 덮어쓰지 않습니다.

변경 전 docs/planning/_backup/YYYYMMDD_단이/에 백업하고 자기 임시 작업은 _작업/codex/에 둡니다. 보호 대상과 다른 담당 소스를 수정하지 않습니다. 외부 발송·공개게시·결제·시크릿 접근·원본 삭제·지시 없는 서버 재시작/빌드/감시/예약은 금지합니다.
