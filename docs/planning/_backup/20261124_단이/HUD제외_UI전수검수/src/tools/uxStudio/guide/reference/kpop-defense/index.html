HUD의 나쁜 기운을 누르면 현재 상태의 정보창이 열립니다. 만충 정보창 → 방어 준비 → 습격 시설과 출격 편성. 남은 시간은 열린 정보창과 편성 화면에서 이어집니다.

습격 시설과 몬스 체크 편성

HUD 만충 → 05:00 → 만충 정보창 → 방어 준비 → 시설과 출격 편성.

습격 시설 한 곳과 남은 시간을 확인합니다. 기존 몬스 보관함과 같은 단계순 3열 카드에서 체크하면 하단 출격 칸에 반영됩니다. 최대 5마리까지 선택할 수 있습니다. 카드 하단에 몬스별 기분 게이지를 표시합니다. 보관함 시안의 수치를 연결하고 미연동 값은 대시로 표시합니다.

편성 미리보기

전체 전투 화면 · 스킬 오버레이

전장이 화면 전체를 채웁니다. 상단은 시설 내구도·웨이브·시간, 하단은 출격 몬스·처치·보상 정보와 공통 스킬 버튼입니다. 미습득이나 재사용 대기 중에는 시뮬레이터 상태를 따릅니다. 스킬 후보 3장은 전장 하단에 자동으로 겹쳐 뜹니다. 성공·실패 결과도 전장이 보이는 상태에서 모달 오버레이로 표시합니다. 7018 미리보기는 전투 진입 8초 뒤 스킬 오버레이를 확인할 수 있습니다.

전투 미리보기에 들어가면 8초 뒤 스킬 후보가 떠요. 스킬 오버레이 바로 보기

몬스와 시설 결과 연출

수리비 표시 조건 방어 성공 시 연습실은 정상 이용 상태이며 수리비가 없습니다. 방어 실패나 습격을 그냥 두어 시설이 파손된 경우에만 수리비와 수리하기를 표시합니다. 실패 제목은 「방어에 실패해 연습실이 파손됐어요」입니다.

획득한 보상은 스케줄 결과와 같은 아이콘·이름·수량 타일로 표시합니다. 성공은 처치 보상과 지킴 덤이 포함된 돈을, 패배는 처치로 얻은 돈을 보여 줍니다. 보상이 없는 상태는 빈 보상 타일을 표시합니다. 수량은 검수용 예시입니다.

같은 카메라 구도에서 결과를 보여 줍니다. 성공하면 건물에 빛이 돌고, 앞에 모인 방어 몬스가 기뻐합니다. 실패하면 한 단계 전 외형의 건물에 균열이 드러나고, 참가 몬스가 건물 앞에 남습니다. 세부 와이어프레임은 두 연출의 마지막 장면을 보여 줍니다. 기존 시설 단계는 유지하고 수리하면 파손 표시를 지웁니다. 수리는 건설의 같은 시설로 연결하며 수리비는 마지막 건설비의 50%입니다.

악귀 3D 리소스 부품표

악귀 12종은 지상 10종과 공중 2종입니다. 용형 공중 보스는 별도 모델입니다. 각 이미지는 원본 GLB를 리소스 뷰어에서 열어 캡처했습니다.

실제 크기와 움직임은 3D 리소스 뷰어의 악귀·보스 탭에서 확인합니다. GLB는 게임에 불러오는 파일이며 Blender는 수정용 원본입니다.
