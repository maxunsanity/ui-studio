## 케이팝몬스터즈 기획 동기화와 UI 제작 순서

**제작 범위는 1차 와이어프레임과 2차 세부 와이어프레임까지입니다. 3차 본 UI 원본은 미제작으로 관리합니다.** 검수용 이미지와 조작 예시는 2차 설계 자료로 기록합니다.

현중이 정한 동기화 순서는 클로드 초안 → 클로드가 공통 UI 기획서 양식으로 정리 → 코덱스 검수와 실제 UI 제작 → 코덱스가 7018 UI 기획서와 작업 명세 갱신 → 클로드가 7018 내역을 7007에 동기화입니다.

1. 클로드 원안과 연결 문서, 현재 7018 탭과 저장판을 읽고 충돌 항목을 확인합니다. 화면의 진입·조건·상태·복귀·공통 부품을 목록으로 작성합니다.
2. HUD·포토카드 및 해당 기능에 맞는 내장 참고 샘플의 계층, 배치, 크기, 아이콘과 상태를 확인합니다.
3. 7018 안에서 최신 UI 기획서, 작업 명세, 그림, 검수 목록을 실제 저장판과 맞춥니다. 7007 동기화는 클로드가 수행합니다.
4. 1차 와이어프레임에는 영역과 흐름을 설명합니다. 2차 세부 와이어프레임은 UI 스튜디오에서 텍스트, 버튼, 아이콘, 이미지, 게이지를 각각 편집할 수 있게 만듭니다. 확정 수치가 있으면 화면에 숫자와 단위를 직접 표시하고, 원본 결측은 —로 남깁니다. 텍스트는 시스템 글꼴을 쓰고, 흑백 아이콘은 의미가 읽히도록 강조합니다. 공통 틀과 9슬라이스 상태를 공유하고 필요한 그림만 새로 제작합니다.
5. 기능별로 왼쪽에 메인, 오른쪽에 상세·팝업·상태를 흐름 순으로 펼칩니다. 반복 구성은 실제 부품 보드에 전개합니다. 카드나 팩의 화면은 확인, 연출, 결과를 사용 순서로 잇습니다.
6. 작업 명세에 캔버스와 같은 순서로 화면 ID, 진입·복귀, 입력 조건, 상태 변화, 규격, 출처, 최신 실제 캡처를 적습니다. 이전 그림은 백업에 보존하고 작업 명세에는 최신 캡처를 표시합니다. 작업 명세에서 UI 기획서 원문 탭과 동작 미리보기를 열 수 있게 연결합니다.
7. UI 스튜디오에서 저장한 설계를 다시 열고, 보드·이미지·가로 넘침·시스템 글꼴·화면 이동을 확인합니다. 실제 브라우저 마우스 입력으로 들어가기·선택·닫기·복귀를 확인합니다. 팝업은 편집 캔버스와 동작 미리보기의 좌표 기준이 맞고 제목·버튼이 프레임 안에 있는지 확인합니다. 검수 범위와 연동 대기 항목을 기록합니다. 수정 전 백업을 남깁니다.

이번 제작 순서는 스케줄 → 관계입니다. 작업 명세만 요청받은 회차에는 원본 기획은 확인과 동기화 원본으로 사용합니다.

스케줄 작업 명세에는 화면마다 전체 화면·바텀 시트·모달·부품 보드 유형을 표시합니다. 스케줄 창은 390×844 기준 374×748 공통 외곽을 사용하며, 하단 정렬의 바텀 시트와 가운데 정렬의 모달을 구분해 진입·복귀와 함께 기록합니다.

## 1차·2차 제작 및 기존 화면 재검수 기준 (2026-11-24)

1차 와이어프레임에서는 화면의 목적, 정보의 우선순위, 진입점, 주요 행동과 복귀 경로를 정합니다. **2차 세부 와이어프레임은 최종 그림만 교체하면 되는 수준의 준완성형 UI**로 제작합니다. 그림을 교체할 때도 배치, 문구, 상태, 터치 영역과 화면 연결을 그대로 사용할 수 있어야 합니다.

- **기존 화면과 맞추기.** 제작 전에 공통 UI 가이드와 같은 역할을 하는 최신 저장 화면을 함께 봅니다. 참고한 화면 ID와 재사용할 부품을 명세에 적고, 버튼 크기·간격, 글자 위계, 아이콘 표현, 창의 위치, 닫기와 복귀 동작을 맞춥니다. 같은 캐릭터 정보처럼 여러 메뉴에서 여는 공통 창은 재사용하고, 닫으면 들어온 메뉴와 선택 위치로 돌아가는지 확인합니다.
- **정보를 그림으로 설계하기.** 화면마다 플레이어가 먼저 알아봐야 하는 대상·상태·행동을 정합니다. 기존 화면에서 같은 정보를 어떻게 보여 주는지 살피고 초상, 아이템 그림, 게이지, 배치 등 알맞은 표현을 선택합니다. 이름·수치·단위·행동 문구는 읽을 수 있게 유지합니다. 모든 아이콘 자리에는 뜻을 알아볼 수 있는 그림을 배치합니다. 같은 의미의 아이콘은 기존 그림을 재사용하고, 없는 아이콘은 기존 선 굵기와 크기에 맞춰 그립니다.
- **3D 장면을 대표 이미지로 구현하기.** 캐릭터 전신, 팀 무대처럼 3D로 나올 부분은 해당 장면의 대표 그림을 생성해 실제 표시 영역에 넣습니다. 최종 카메라 구도·인물 크기·앞뒤 관계·UI 가림을 고려합니다. 의상 교체처럼 변화 자체가 기능이면 같은 구도의 전후 그림을 준비해 선택 즉시 차이가 보이게 합니다.
- **3D 리소스는 컬러를 유지합니다.** 3D 전장·맵·건물·캐릭터·오브젝트·효과의 대표 이미지와 부품 보드 썸네일은 원본의 색을 유지합니다. 세부 와이어프레임의 2D UI가 흑백이어도 3D 이미지에 일괄 회색 필터를 적용하지 않습니다. 상세 편집의 이미지 내용에서 「3D 원본 색상 유지」를 선택합니다.
- **겹침과 입력을 함께 검수하기.** 바텀시트와 모달은 기존 UI에서 같은 역할을 하는 창의 배치와 조작을 따릅니다. 배경과 앞창의 경계, 입력을 받는 층, 닫기 위치를 명확히 합니다. 아이콘·문구·버튼을 각각 편집할 수 있게 두고 그림과 실제 터치 영역이 맞는지 확인합니다.
- **저장판에서 확인하기.** 데스크톱 1440px과 모바일 430px(폰 논리 화면 390×844)에서 실제 진입 → 선택·상태 변화 → 닫기·복귀를 확인합니다. 그림 누락, 의도하지 않은 겹침, 잘림과 넘침을 기록합니다. 명세에는 화면 ID, 확인한 동선과 캡처를 남기고, 시안 예시값과 승인된 게임 수치, 실게임 연동 대기를 구분해 표시합니다.

## 창 동작·부품 보드·문서 갱신 (2026-11-24)

- **바텀시트**는 현재 대상을 보면서 상세를 읽거나 후보를 비교·선택할 때 하단에 엽니다. 예를 들어 장비 칸을 누르면 그 장비의 상세가 열립니다. 선택·미리보기·최종 적용이 각각 언제 일어나는지 명세에 쓰고, 닫으면 호출 화면의 탭과 선택 위치로 돌아오게 합니다.
- **모달**은 진행을 잠시 멈추고 사용 여부를 결정하거나 결과를 확인할 때 엽니다. 예를 들어 몬스 간식 사용 확인에서는 대상과 사용 전후 상태를 보여 줍니다. 열린 동안 배후 입력을 막고, 확인은 명세에 정한 동작을 한 번 수행하며 취소는 사용 전 상태로 돌아갑니다. 시트 위에 모달이 열리면 맨 위 창부터 닫히는지 확인합니다. 창마다 진입 조건, 배경 탭·뒤로 가기 처리와 복귀 대상을 기록합니다.
- **부속품은 별도 제작하고 설명합니다.** 카드, 버튼, 탭, 게이지, 아이템 슬롯 등을 편집 가능한 부품으로 만들어 기능별 부품 보드에 배치합니다. 작업 명세에서 부품 ID로 보드와 사용 화면을 연결하고 용도, 구성, 크기·간격, 표시 데이터, 입력·결과, 적용되는 상태를 설명합니다. 예를 들어 장비 슬롯은 빈칸·보유·선택·착용이 어떻게 보이고 눌렀을 때 무엇이 열리는지 보드에서 비교할 수 있어야 합니다.
- **기능별로 제작하면서 7018의 두 문서를 함께 갱신합니다.** 착수할 때 UI 기획서에 목적·진입·화면 유형·플레이어 동선을 확인하고 작업 명세에 대상 화면·부품 ID를 잡습니다. 제작 중 흐름이나 상태가 달라지면 해당 단계에서 기획서와 명세의 관련 절을 실제 저장판에 맞춥니다. 검수 후에는 작업 명세에 같은 저장판의 캡처·미리보기·확인 결과를 연결하고, 기획과 구현 간 남은 차이를 기록합니다.

### HUD 박스와 구역선 제작

- 1차에서 광장·보드의 범위는 직선 면으로 잡고, 배경을 감싸는 이중 테두리를 제거합니다. 도착 필러는 보드 위에 겹치고, 하단 재화 띠와 조작부는 한 기준선에 맞춥니다.
- 크기가 바뀌는 박스·버튼·카드·말풍선의 바탕은 9분할 PNG로 제작합니다. 원본에서 모서리와 직선이 만난 뒤에 분할선을 놓고, 모서리 표시 크기를 고정합니다. 위아래 변은 가로로, 좌우 변은 세로로, 가운데만 양방향으로 늘립니다. 이번 HUD 공통 프레임은 원본 48×48px, 네 변의 분할선 11px, 표시 폭 7px입니다.
- 부품 보드와 실제 캔버스의 축소 보기에서 모서리 잘림·분할선 틈·이중 외곽선을 확인합니다. 반투명 필러는 뒤 장면이 보이는지, 버튼은 문구와 입력 범위가 일치하는지도 확인합니다.

### 로비 신규 부품 등록

UI 부품과 맵에 놓는 3D 오브젝트는 추가하는 회차에 작업 명세의 부품표에도 등록합니다. 3D 대상은 현재 대표 이미지, 장면상의 위치·상대 크기·입력 및 상태를 연결합니다. 보유 아이돌 외형은 재사용 참조로 관리합니다. 캔버스 요약 패널에서는 작업 명세 링크로 세부 내용을 엽니다.

2차 HUD에서 로비 광장, 3D 오브젝트, 인게임 보드 장면은 원본 색으로 표시한다. UI 아이콘과 정보 표기는 흑백으로 표시한다.
