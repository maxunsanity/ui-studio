홈과 편성

390 × 844. 아이돌·몬스 화면은 장소 배경 위에 보상 그림을 놓습니다. 아이돌은 멤버 칩, 참가 인원 슬롯, 케미 표시, 선택 후보 체크를 사용합니다. 편성 조건 줄에는 아이콘, 조건 이름, 확인 상태가 함께 표시됩니다.

편성 수정과 몬스 출동

후보를 바꾸면 필수 조건이 다시 판정됩니다. 「자동 편성」은 눌렀을 때 실행됩니다. 아이돌은 「편성 수정」에서 후보를, 몬스는 카드에서 선택 여부를 바꿉니다. 몬스 검수 예시에서 토끼를 빼면 목 속성과 3단 조건이 부족해 출동이 잠깁니다.

스케줄 홈의 「몬스」 탭에서 출동 목록을 엽니다. 아이돌 탐험은 장소 배경과 대사 4장면을 보며, 몬스 출동은 기존 3D 전투 연결을 거칩니다. 각각의 결과 화면으로 이어집니다.

스케줄 흐름

  • 아이돌은 편성 → 진행 → 장소 배경과 대사 4장면 → 결과 → 받기 순으로 열립니다.
  • 몬스는 출동 편성 → 진행 → 기존 3D 전투 → 결과 순입니다. 전투 전환과 반환 데이터는 실제 게임에 연결할 항목입니다.
  • 공동 순위는 결과의 「공동 순위 보기」에서 열립니다. 검수 캔버스에서는 결과 오른쪽에 배치했습니다.
  • 관계에서 이어지는 추천 3개와 도감에서 나오는 2개는 실제 장소 시안과 함께 별도 상태로 배치했습니다. 조건과 보상 예시는 확인된 값만 표시합니다.

결과와 좋아진 라포

390×844. 모든 결과의 장소 배경은 390×170, 결과 카드는 304×122입니다. 별점과 보상 시작점, 하단 버튼 크기와 기준을 공유합니다. 완벽·좋음은 100%, 부분 성공은 50%, 실패는 0% 예시입니다.

보상 타일을 확인한 뒤 받습니다. 획득한 그림 조각은 도감 카드에서 원화 조각·진행·새 번호를 확인합니다. 관계가 오른 경우엔 보상 아래 「좋아진 라포」에서 함께 간 짝과 이전 → 현재, 증가량을 봅니다. 스태프와 회장 짝은 해당 스케줄에서 실제 증가가 있을 때 각자 표시합니다. 관계 단계 상승 시 열리는 ⑥ 팝업은 관계 작업 명세를 따릅니다. 실제 단계 이벤트 자동 연결은 게임 연동 항목입니다.

그림 조각 도감

  • 도감·상세·맞추기·완성에서 같은 원화를 9등분해 공유합니다. 획득한 조각은 썸네일을, 빈 칸은 자리 번호를 보여 줍니다. 「완성 그림」에서 원화를 읽고 현재 판으로 돌아갑니다.
  • 첫 완성은 기획사 일반 카드팩 1개, 돈, 주사위입니다. 문서에 수량이 없는 돈과 주사위는 —로 보입니다. 2회차 예시는 같은 「녹음 메모」 그림과 주사위 ×27을 사용합니다.
  • 조각은 선택 → 자리 누르기 순입니다. 9자리가 모두 채워지면 「완성하기」가 켜지고 보상 단계로 이어집니다.

목표 그림과 등급 구간

  • 엔터파워가 열림 문턱에 미달하면 자물쇠와 필요한 엔터파워가 표시됩니다. 열렸지만 참가 조건이 부족한 카드에는 부족한 조건을 표시합니다. 닫힘 문턱을 지난 스케줄은 새 편성 목록과 추천에서 빠집니다. 출발한 기록은 결과까지 받습니다.
  • 목표 그림은 한 장입니다. 첫 목표는 미완성 중 조각이 가장 많은 그림입니다. 동률이면 도감 순서를 따릅니다. 도감 상세의 「이 그림 모으기」로 바꾸고, 완성한 그림도 다시 지정할 수 있습니다. 다 모으면 다음 목표를 자동으로 지정합니다.
  • 도감 카드에는 「목표」, 상세에는 「목표로 모으는 중」, 해당 편성에는 「목표 조각」이 표시됩니다. 현재 등급에서 갈 수 있는 출처에 다녀오면 목표 그림의 비어 있는 칸 조각을 먼저 받습니다. 열려 있는 출처가 없으면 그 상태를 표시합니다.
  • 다른 스케줄의 보정은 목표 외 조각이 연속 5번이면 6번째가 목표 조각인 원안 기준입니다. 5회의 수치는 제안입니다. 닫힘 구간 판정과 드랍·자동 변경은 실제 게임 연결 항목입니다.

바텀 시트와 모달 팝업

기준 화면 390×844. 공통 9슬라이스 프레임은 374×748, 좌우 여백은 8px입니다. 바텀 시트는 Y=96의 하단 정렬과 손잡이·슬라이드, 모달은 Y=48의 가운데 정렬과 페이드를 사용합니다. 둘 다 닫으면 열었던 화면으로 돌아갑니다.

편성·기록장·순위·소식·도감 목록·이야기 변경은 바텀 시트입니다. 댓글·받은 엽서·도감 상세 및 맞추기·해금은 모달입니다.
