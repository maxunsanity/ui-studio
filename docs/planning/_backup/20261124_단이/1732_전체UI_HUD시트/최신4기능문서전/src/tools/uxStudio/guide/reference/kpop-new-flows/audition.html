원안의 상태와 규칙 열기
  1. ① 만남 (대지 칸 도착 · 아래 판)
    • 도착 칸 번호 · 시설 · 「찜 n / 5 ›」(누르면 ② 찜 모음) · 보드를 가리지 않는 아래 판
    • 후보: 얼굴 · 이름 · 특기 · 성격(색 점 + 묶음) · 사연 한 칩 · 대사 한 줄 · 이미 찜한 친구면 「명함을 준 친구」 칩
    • 큰 능력 6개 등급만(보컬 · 댄스 · 랩 · 비주얼 · 끼 · 프로듀싱 · P100 R-05-4) · 숫자는 영입 뒤
    • 이야기 n / 5 · 명함을 줄 때마다 한 토막 열림 · 누르면 ①-1
    • 패스 = 그냥 보냄 · 명함 주기 = 찜(5명 차면 ①-2) · 캐스팅 = 바로 영입 → ⑦ (빈 자리가 있을 때만 · 없으면 ①-3)
  2. ①-1 이야기 펼침
    • 소개 2 · 3줄 + 열린 이야기 토막(제목 · 글 · 대사) · 접기
    • 안 열린 토막은 잠김 한 줄 · 열린 이야기는 찜을 바꿔도 남음
  3. ①-2 찜 바꾸기 (5명이 찼을 때)
    • 찜 5명 중 하나를 골라 바꿈 · 바뀐 친구의 열린 이야기는 남음 · 오디션 진행 중에는 찜을 바꿀 수 없음
    • 돌아가기 = 명함 안 줌 · ① 그대로
  4. ①-3 빈 자리 없음 (캐스팅 버튼 숨김)
    • 멤버 자리가 다 찼을 때: 「다음 멤버 자리 · 엔터파워 n」 · 자리는 시작 1 + 문턱 12개(538 ~ 9,000) · 최대 30
    • 캐스팅 대신 명함 주기만 · 찜해 두면 자리가 열릴 때 오디션으로
  5. ② 찜 모음 (제안 · 시뮬은 검토창에만)
    • 찜 n / 5 · 얼굴 · 이름 · 이야기 n / 5 · 특기 · 누르면 능력 등급 창(①과 같은 칸) · 찜 해제(오디션 중에는 꺼짐)
    • 빈 찜 칸
    • 멤버 자리 n / n · 빈 자리 수
    • 오디션 열기 → ③ · 빈 자리 없으면 꺼짐(「다음 멤버 자리 · 엔터파워 n」) · 진행 중이면 「오디션 이어하기」 · 들어오는 곳 = ①의 「찜 n / 5」 · 정보 탭 아이돌 목록 빈 자리
  6. ③ 오디션 준비 · 참가자 4명
    • 참가자 4명 · 출처 「명함을 준 친구」 / 「추가 초대」 · 누르면 등급 창 · 다른 후보가 4명보다 적으면 열리지 않음(「초대할 후보가 부족해요」)
    • 진행 요약(시뮬 하단 「비어 있음」 문구는 뺌)
    • 보드로 = 오디션 안 열고 돌아감(찜 그대로) · 오디션 시작 → ④
  7. ③-1 찜 5명 → 참가할 4명 고르기
    • 누를 때마다 ✓ / + · 고른 칸은 굵은 테
    • 정확히 4명일 때만 켜짐
  8. ④ 첫인상 (원픽 고르기)
    • ✕ = 첫인상 건너뛰기(원픽 없이 대진)
    • 이름 · 특기 · 호감도 표시 · 배경 칩 6개 · 어학 도장(EN · 中 · 日 · 5면 ★5)
    • 스킬 2개 미리보기(첫인상 · 스카우트 · 누르면 설명) · 소개 3줄 · 대사
    • 참가자 4명 썸네일 · 눌러서 바꿔 봄 · 「? 무작위」
    • 고른 친구가 첫 판의 「남아 있는 친구」가 됨 · 3판 모두 12초
  9. ⑤ 대진 (카드 앞면 · 재능 등급)
    • Ⅱ = 멈춤(⑤ 안 「나중에 이어하기」 · 남은 대진 저장) · 라운드 n / 3 · 남은 선택
    • 제한 시간 12초 막대 · 3초부터 굵게 · 첫 판에 남아 있는 친구가 없으면 「첫 대결은 직접 선택」(시간 없음)
    • 카드 라벨: 남아 있는 친구 / 새 도전자 / 첫 후보 · 첫인상 원픽 표시
    • 앞면 = 그림 · 이름 · 성격 · 재능 6각(등급 글자 · 숫자 없음)
    • 뒤집기 → ⑤-1 · 이야기 → ⑤-3 · 이 친구 선택 → ⑤-2
  10. ⑤-1 카드 뒷면 (배경 · 스킬)
    • 뒷면 = 배경 · 숨은 특기 · 스킬 3칸(★ 열림 / ◇ 잠김) · 상세 펼침 · 능력 숫자는 넣지 않음(시뮬 뒷면 6축 막대 · 총합은 영입 뒤 프로필로)
    • 뒤집어도 시간은 계속 흐름
  11. ⑤-2 선택 뒤 (승리 · 탈락)
    • 승자 도장 「승리 · 계속 도전」(시간 종료면 「시간 종료 · 자동 승리」) · 패자 「이번 대결 탈락」 · 승패 연출 1.15초
    • 승자 말풍선 · 스킬 칸 n / 3 · 스킬 획득 · 시간 종료면 「시간 종료! ○○ 친구가 남고 새 도전자가 등장합니다」
  12. ⑤-3 이야기 창 (대진 위 · 시간 흐름)
    • 배경 칩(약점 극복 점)
    • 장 탭: 합격 서사 · 캐스팅 · 성장 단계 장(잠김 = 「○○ 단계에 열립니다」) · 에필로그
    • 넘기기 · 창을 열어도 대진 시간은 계속(✕로 닫음)
  13. ⑥ 최종 확인
    • 고른 카드 한 장(버튼 없음)
    • 몬스 배정 문구 뺌(현중 11/02 「오디션 때 몬스 지급은 다 빼라」) · 영입 뒤 예명 · 능력 공개 안내
    • 다시 비교 = 마지막 비교만 되돌림 · 이 멤버와 시작 → ⑦
  14. ⑦ 영입 연출 (4.2초 · 탭하면 건너뜀)
    • 커튼이 열리며 멤버 등장(시뮬 presentation.mjs 단계: 모음 0.65 → 펼침 1.55 → 지움 2.25 → 공개 2.7 → 이름 3.45초)
    • 「영입 완료」 · 이름 · 몬스 칸 없음
    • 건너뛰기 → 바로 인트로 ⑥ 예명 창 → ⑧
  15. ⑧ 영입 결과 (스킬 · 합격 서사)
    • 예명(본명) · 멤버 n / n · 두 번째 멤버면 이 뒤에 인트로 ⑦ 팀 이름 창
    • 스킬 3칸: 획득 / 미달성 · 얻은 길(첫인상 원픽 유지 · 대진 승리 · 스카우트)
    • 합격 서사 · 합격 다짐
    • 이야기(n / 4 · 끝이면 👑 에필로그) · 능력 자세히 → 프로필 탭 아이돌 정보(18세부 · 재능선이 여기서 처음 열림)
    • 보드 계속하기 → 보드(HUD) · 짝 몬스 칸 없음
