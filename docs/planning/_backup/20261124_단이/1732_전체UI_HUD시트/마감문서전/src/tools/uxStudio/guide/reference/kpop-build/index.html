건설 · 2차 작업 명세

공통 HUD·시트 적용 · r12

건설 현황 6상태는 하단 시트다. 건물 사진은 컬러 3D 대표 그림이며 시설 확대·증설·수리의 전용 화면과 입력은 현황에서 이어진다. 시스템 글꼴을 사용하고 2D 그림은 회색, 3D 대표 그림은 컬러로 표현한다.

현재 캔버스 · 공통 제작 가이드

r11 · 30개 편집 보드 · 제안(검수 대기)

편집 캔버스 · 건설 미리보기 · 로비에서 건물 선택 · UI 기획서

9시설 한 화면

건설 현황은 390×844에서 스크롤 없이 아홉 시설을 표시합니다. 3×3 카드 외곽 121×188, 컬러 건물 사진 117×144, 상태 배지와 이름·전체 단계는 편집 요소입니다. 시설 성장은 0~30단계 하나로 표시합니다.

공통 시설 확대와 상태

로비 지도에서 건물 또는 지붕 배지 선택 → 해당 시설 확대. 건설 현황에서 9개 카드 중 선택 → 같은 시설 확대. 모두 같은 마을의 구도를 유지합니다. 최초 진입점에서 닫는 동작은 해당 진입점으로 복귀합니다.

0단계는 짓기, 일반 시설은 +1 또는 최대, 돈 부족은 부족분 안내, 파손은 수리, 30단계는 완공입니다. 최대 견적은 목표 단계·단계 수·총비용·예상 잔액을 표시합니다. 수리비 기준은 대전과 디펜스 모두 마지막 건설비의 50%입니다.

증설·수리·복귀

증설 성공 후 25/30, 첫 건설 후 1/30, 수리 시 기존 단계 유지 및 파손 표시 해제를 검수 상태로 연결합니다. 연출은 같은 마을의 카메라 컷으로 표시하며 실제 카메라 이동·차감·시설 상태 갱신·저장 연동은 개발 범위입니다.

공통 부품

지도 원화·시설 확대 구도·카드 사진은 같은 검수 원화 기반입니다. 로비 건물 터치 면과 지붕 배지는 각기 독립 레이어입니다. 증설 가능 표시의 게임 조건은 보유금이 +1 견적 이상이고 아직 완공·파손 상태가 아닐 때입니다. 초기 시설은 짓기 가능 상태로 다룹니다.

부품 보드

디펜스 파손 외형

같은 카메라 구도에서 결과를 보여 줍니다. 성공하면 건물에 빛이 돌고, 앞에 모인 방어 몬스가 기뻐합니다. 실패하면 한 단계 전 외형의 건물에 균열이 드러나고, 참가 몬스가 건물 앞에 남습니다. 세부 와이어프레임은 두 연출의 마지막 장면을 보여 줍니다. 기존 시설 단계는 유지하고 수리하면 파손 표시를 지웁니다. 수리는 건설의 같은 시설로 연결하며 수리비는 마지막 건설비의 50%입니다.
