11월 24일 P265 출연권 대전 탭 · 원안 11상태

원안의 상태와 규칙 열기
  1. ① 쟁탈전 도착 · 콘텐츠 결정 (1.8초)
    • 칸 6 · 16 · 26 · 36 도착 · 이벤트 뽑기 연출 → 「출연권 대전」 티켓
    • 게릴라 콘서트(다른 쟁탈 이벤트)는 준비 중 · 지금은 늘 출연권 대전
    • 버튼은 꺼진 채 1.8초 뒤 자동으로 ②(퇴장 0.7초) · 나쁜 기운이 가득이면 디펜스 먼저 · 그다음 쟁탈전
  2. ② 상대 · 시설 고르기 (3D 위에서 봄)
    • 상대: SNS 사진 · 닉네임 · 기획사 이름 · 「봇 소속사」 · 방패 n / 3 · 기분 %(제안 · 고르기 전에 막힐지 가늠) · 다시 뽑기 없음
    • 시설 모두 보기 → ②-1
    • 9시설 이름표 「짧은 이름 n / 30」(건설 단계) · 0단계는 잔재(못 고름) · 고른 건물 굵은 테
    • 선택한 건물 · 고르기 전에는 「지도에서 시설을 눌러 주세요」
    • 건물을 고르기 전엔 「건물을 선택하세요」(꺼짐) · 중단한 판이 있으면 「중단한 전투 이어 보기」 · 자동 굴리기 중에는 손상 안 된 가장 높은 단계 건물을 자동으로 고름(제안)
  3. ②-1 시설 모두 보기 (2열 판)
    • 9시설 · n단계 · 0단계는 「선택 불가」(누르면 「잔재만 남은 건물입니다. 다른 건물을 선택해 주세요」) · 고른 곳 ✓ · 눌러서 고르기
    • 닫기 → ②(고른 건물 유지)
  4. ③ 전투 (10초 · 자동)
    • 시설 이름 · 수비 n명 · 남은 시간
    • 상대 유저 기분 % 미터 · 수비 남은 / 전체 · 몬스 칸(✓ / ×) · 「수비 없음 · 다음 공격은 건물에 적중」
    • 단계: 출격 준비 · 대기조 이동(1.1초) → 10초 교대 사격(스킬 10종) → 방패 깨짐(1.6초) 또는 건물 손상 「n → n−1단계 손상」(1.25초) → 기분 정산 · 수호 몬스 퇴장(0.65초)
    • 출격 = 내 몬스 단 높은 순 최대 10 · 지금 단계 글
    • 멈춤 → 「포기하면 이번 결과는 확정하지 않아요」 · 앱이 꺼지면 다음에 「중단한 전투 이어 보기」
  5. ④ 결과 · 건물 적중
    • 결과 한 줄 · 「건물에 적중했어요!」 · 시설 단계 n → n−1(손상 1단계)
    • 배수 식 연출: 시설 적중 보상 × 주사위 배수 = 최종 획득(메가면 「메가 보상 적용 × 3」) · 소수점 버림
    • 받은 것: 돈 · 팬(시뮬은 결과 화면에 없음) · 주사위 · 카드팩은 P98 지급 조건 작업전이라 회색 칸 · 동전이 HUD 돈으로 날아감 「돈 획득!」
    • 상대 쪽 변화: 잃은 돈(10%) · 방패 · 기분
    • 보드로는 연출이 끝나야 켜짐 · 카드팩이 있으면 「카드팩 열기」 → ⑤
  6. ④-1 결과 · 방패가 막음 / 수비가 막음
    • 판정 순서 1: 상대 방패가 1개 이상이면 1개를 쓰고 막음 · 기분 안 줆 · 방패 깨짐 연출 1.6초
    • 막힌 판 보상 = 기본 × 배수 × 7.5(적중의 절반) · 메가 없음
    • 막히면 팬 · 상대 손실 없음
    • 판정 순서 2: 방패 0이면 수비 기분(남은 수비 = 올림(N × 기분%)) · 수비가 남으면 막힘 · 한 판에 기분 10% 깎임 · 말은 「수비 몬스」로 통일(시뮬 「수호령」 · 「지킴이」 섞임)
  7. ④-2 메가 적중 (적중 때 2%)
    • 메가 도장 연출(적중일 때만 · 2%)
    • 식에 「메가 보상 적용 × 3」 줄이 더해짐 · 계속 → ④와 같은 받은 것 · 보드로
  8. ⑤ 카드팩 열기 (지급 조건 작업전)
    • 봉인 팩 · 탭 → 찢기 · 총 n장
    • 카드마다 「어떤 카드일까요?」 → 뒤집기 → NEW / 중복 표시 · n / n
    • 나머지 한 번에 보기 → ⑤-1 · 지급 여부 · 팩 내용 · 확률은 P98 작업전(지금 실제 도착은 돈만)
  9. ⑤-1 카드팩 요약
    • 이번 팩 최고 카드 · 등급 · NEW
    • 나머지 카드 · NEW / 중복 · 페이지
    • 카드 상세(앞뒤 보기 / 닫기) · 「카드 보관함으로 이동 중 → 이동 완료」
    • 확인 → 「보상 획득 완료」 → ④ 보드로
  10. ⑥ 보드 복귀 · 알림 / 못 여는 상태
    • ① ~ ④가 끝나면 보드로(0.6초 닦아내기) · 위에 한 줄 알림(돈 · 팬) · 그 칸에서 다음 굴림
    • 못 여는 경우는 알림 한 줄만 · 자동 굴리기 중이면 멈추지 않음
  11. ⑦ 자리 비운 동안 공격받음 (제안)
    • 다시 들어올 때 한 번 · 공격한 상대 · 막음 / 적중 · 잃은 돈 · 단계 · 30초 다시 보기 · 복수하기(다음 쟁탈전 상대로 고정 · 제안)
    • 내 방패 n / 3(HUD 띠 게이지와 같은 값) · 부서진 건물 · 수리비 = 마지막 건설비 × 0.5
    • 수리하러 가기 → 건설 탭 ①-4 · 지금 봇 공격 횟수 0(bot_attack_per_day=0) · 켜질 때 쓰는 화면(건설 탭 남은 결정 6 「소식」과 같음)
