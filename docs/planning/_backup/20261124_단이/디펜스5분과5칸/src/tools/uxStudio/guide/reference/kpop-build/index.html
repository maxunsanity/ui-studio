9시설 한 화면

건설 현황은 390×844에서 스크롤 없이 아홉 시설을 표시합니다. 3×3 카드 외곽 121×188, 흑백 건물 사진 117×144, 상태 배지와 이름·전체 단계는 편집 요소입니다. 시설 성장은 0~30단계 하나로 표시합니다.

공통 시설 확대와 상태

로비 지도에서 건물 또는 지붕 배지 선택 → 해당 시설 확대. 건설 현황에서 9개 카드 중 선택 → 같은 시설 확대. 모두 같은 마을의 구도를 유지합니다. 최초 진입점에서 닫는 동작은 해당 진입점으로 복귀합니다.

0단계는 짓기, 일반 시설은 +1 또는 최대, 돈 부족은 부족분 안내, 파손은 수리, 30단계는 완공입니다. 최대 견적은 목표 단계·단계 수·총비용·예상 잔액을 표시합니다. 수리비 기준은 대전과 디펜스 모두 마지막 건설비의 50%입니다.

증설·수리·복귀

증설 성공 후 25/30, 첫 건설 후 1/30, 수리 시 기존 단계 유지 및 파손 표시 해제를 검수 상태로 연결합니다. 연출은 같은 마을의 카메라 컷으로 표시하며 실제 카메라 이동·차감·시설 상태 갱신·저장 연동은 개발 범위입니다.

공통 부품

지도 원화·시설 확대 구도·카드 사진은 같은 검수 원화 기반입니다. 로비 건물 터치 면과 지붕 배지는 각기 독립 레이어입니다. 증설 가능 표시의 게임 조건은 보유금이 +1 견적 이상이고 아직 완공·파손 상태가 아닐 때입니다. 초기 시설은 짓기 가능 상태로 다룹니다.
