진입과 복귀

HUD 하단 건설 또는 엔터파워 상세에서 들어갑니다. 건설 상세 바텀시트를 닫으면 원래 지도나 목록으로 돌아갑니다. 전투 결과의 수리하기는 파손 지도에서 해당 연습실을 강조합니다.

표준 규칙은 P81·P106과 7007 건설 1차를 따릅니다. 표와 연결해야 하는 비용·효과는 —이며 최대 증설 확인 기준·수리 순서는 검수 대기입니다.
