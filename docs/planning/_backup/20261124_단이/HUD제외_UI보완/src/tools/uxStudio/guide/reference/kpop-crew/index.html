진입과 흐름

HUD 하단 정보 → 크루. 크루원과 크루장 메인은 현재 회차, 해야 할 한 가지, 메뉴를 보여 줍니다. 주간 출품과 투표, 대표작 고르기, 크루원과 관리는 하위 화면입니다. 월드 총공은 해당 회차에 열립니다.

배경과 버튼은 기존 HUD·포토카드의 9슬라이스 규격을 사용합니다. 가운데 모달과 하단 바텀시트는 내용에 맞는 크기를 사용합니다. 닫으면 열었던 화면으로 돌아갑니다. 실제 게임 데이터와 발란스 연동은 별도입니다.

대표 이미지와 창 유형

민트 웨이브의 합동 리허설 이미지 한 장을 크루원·크루장 메인, 전체 크루 카드, 공개 프로필에 씁니다. 목록에서는 썸네일, 메인과 프로필에서는 배너로 표시합니다. 다른 크루는 기존 크루별 대표 그림이나 기본 표식을 사용합니다. 크루장이 등록한 이미지가 있으면 그 이미지를 사용합니다.

편집 보드 기준은 390 × 844입니다. 확인과 동의는 화면 중앙에, 뮤비 크게 보기는 손잡이가 있는 하단 시트에 놓습니다.
