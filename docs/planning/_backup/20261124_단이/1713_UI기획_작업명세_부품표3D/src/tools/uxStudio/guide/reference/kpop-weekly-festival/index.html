스케줄 기준 상세 화면

스케줄 r23의 상태 칩·아이콘과 수치·진행 막대·조건 행을 적용했다. 390×844에서 53px 헤더와 62px 하단 동작을 고정하고, 730px 본문을 세로로 스크롤한다. 앨범과 보상 합계는 첫 화면 안에 들어온다.

혜택 날짜와 남은 시간, 참가·활동·굴림·연료, 앨범 재킷·대표곡·팀·순위·점수·바퀴, 다음 순위까지 점수, 상위 3·내 주변 ±1, 앨범 차트와 페스티벌의 보상 별도 값·합계, 참가·혜택일·연료 상한과 마감 규칙을 표시한다.

앨범 선택, 내 발매 앨범, 전체 순위, 네 탭 기록은 바텀시트다. 레이스에서 참가 앨범·지난 경기·차량 3종·드라이빙 프로필·바퀴 구간 배수·차량 이름표·카메라 작은 화면·미니맵·전체 시상 순위와 보상 수량을 표시한다. 페스티벌 순위의 참가자 수는 기획값을 확인한 뒤 연결한다.

표시와 연결 규칙

  • 앨범 한 곡으로 개인 신청한다. 앨범 선택은 바텀시트에서 한다. 신청 이후에도 한 바퀴 보상과 앨범 차트 위치를 유지한다.
  • 한 바퀴 보상은 앨범 차트와 현재 적용 가능한 페스티벌 추가분으로 나눈다. 다음 START 통과 때 자동 정산한다. 화면 수치는 원본 규칙의 예시이며, 지급값은 런타임 견적을 사용한다. 앨범이 없거나 이벤트 종료면 보상 표 대신 상태 안내를 표시한다.
  • 돌아온 바퀴는 상세 화면에 표시하며 로비 HUD에는 표시하지 않는다. 시뮬의 ‘실제 보드 반영 n회’는 view.mjs에서 도착 기록 수를 세므로 START 통과 바퀴로 재사용할 수 없다. 실제 START 패스 ID와 앨범 ID의 귀속이 필요하다.
  • 시뮬레이터의 앨범 리그 현행 코드에 `moneyPerPass`와 카드·하루 상한 미연결이 남아 있다. 능력 단위, 신규 보상 정산과 페스티벌 무리 크기(표 5 / 런타임 100)는 후속 검토한다. 화면의 페스티벌 순위는 분모 없이 표시한다.
  • 앨범 없음과 종료의 제작 입구에서 앨범 발매 준비와 싱글 초안 화면을 미리 볼 수 있다. 발매 상태와 실제 재화는 시뮬레이터에서 관리한다. 급유·주행·완주 보상은 시안 연결을 재생한다.
