5분 카운트와 출격 편성

나쁜 기운이 가득 차면 05:00 카운트 시작 → 게이지를 누르면 건설에 사용한 시설 이미지를 보여 주고, 같은 화면에 출격 슬롯 최대 5마리를 한 줄로 표시 → 방어하기 → 대표 전투 HUD → 결과.

전투 HUD

일반 스킬 10종과 팀 피니시 5종을 서로 다른 이미지로 제작했습니다. 같은 부품 보드에서 각 이름과 핵심 역할을 확인합니다. 전투 HUD는 습격 시설의 내구도 한 줄, 웨이브와 적 수, 스킬 선택, 피니시, 멈춤을 표시합니다.

몬스와 시설 결과 연출

같은 카메라 구도에서 결과를 보여 줍니다. 성공하면 건물에 빛이 돌고, 앞에 모인 방어 몬스가 기뻐합니다. 실패하면 한 단계 전 외형의 건물에 균열이 드러나고, 참가 몬스가 건물 앞에 남습니다. 세부 와이어프레임은 두 연출의 마지막 장면을 보여 줍니다. 기존 시설 단계는 유지하고 수리하면 파손 표시를 지웁니다. 수리는 건설의 같은 시설로 연결하며 수리비는 마지막 건설비의 50%입니다.
