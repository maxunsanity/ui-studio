사옥 광장과 라포적용 팀의 2D 만화 정지 포즈 네 종과 얼굴을 개별 편집한다. 같은 짝이 가까이 선 배치와 각자 떨어진 배치를 비교한다. 표본 팀명·크루명·일정은 검수값이다.
로비 HUD와 부속품상단은 내 팀·엔터파워·팬·설정. 내 앨범은 중앙, 왼쪽은 상점과 판매 이벤트, 오른쪽은 페스티벌·나쁜 기운·퍼즐·양궁. 현수막과 명판, 일정, 서포트 선물의 수령 전후를 구분한다.
순환 보드와 조작게임 시작으로 같은 도시의 보드를 연다. 40개 칸 번호와 시설 입구를 개별 배치한다. 보드의 상단과 하단을 고정하고 상태별 중앙 조작을 교체한다.
주사위 배수배수표의 1·2·5·10·20·50·100·200·500·1,000을 비교한다. 현재 배수와 상한을 분리하고 대사·결과에서도 표시한다. 이동 중 배수는 잠긴다.
필러 장면 그림필러의 맨 뒤에 독립 연습실 그림을 깔고 밝은 카드 표면과 여백을 통해 그림이 보이게 한다. 카드와 배경 그림은 각각 교체할 수 있다.
얼굴·이름표·말풍선발화자 얼굴, 이름표, 대사, 지문을 독립 부품으로 둔다. 카드 폭 기준 378, 전체 필러 높이 170 이하. 대사가 남으면 하단에서 넘기기·건너뛰기를 조작한다.
도착·연습·판정도착 핀, 연습 클랩보드, 지문 책, 대박·중박·운망 도형, 보상 칩을 각각 그림으로 제작한다. 검수 대표 결과는 중박이며 판정별 아이콘은 부품 보드에서 비교한다.

검수용 장면 전환은 버튼으로 확인합니다. 수령 영속 저장·실제 판정·실시간 이동과 카메라·1초 길게 누른 자동 굴림·실제 라포 산출·이벤트 서비스는 게임 연동 범위입니다. 나쁜 기운·건설·몬스의 기존 개별 기획은 해당 탭을 따릅니다.
