진입과 습격 경고

HUD의 가득 찬 게이지 → 디펜스 습격 경고 → 출격 편성 확인 → 전투 → 결과 → 보드. 실패·그냥 두기의 수리는 건설의 해당 연습실로 연결합니다. 가득 찬 채 굴리면 그냥 두기 결과를 표시합니다.

대상은 파손되지 않은 연습실 중 단계가 가장 높은 곳이고 동률이면 무작위입니다. 경고에 대상·연습 중 아이돌·손실과 수리비·출격 몬스를 표시합니다. 방패는 출연권 대전에서 사용합니다.

출격 편성

출격은 최대 10마리입니다. 그 습격에만 편성 수정을 반영하고 다음에는 단 × 기분 능력으로 다시 자동 편성합니다. 기분 70 이상 120%, 35~69는 100%, 35 미만은 70%이며 디펜스에서 기분을 차감하지 않습니다. 출격 몬스가 0마리면 건물 보석만으로 방어하는 상태입니다.

전투·스킬·보스

세로 전장에서 이동·공격·카메라는 자동입니다. 스킬 카드 선택, 팀 피니시, 멈춤을 제공하고 보스는 체력 3구간과 공격 예고를 표시합니다. 가득 찬 상태의 선택 대기에는 제한이 없습니다. 일반 적은 4분에 출현을 멈추고 교전 상한은 5분입니다.

보상·파손·수리

성공 시 처치 보상과 지킴 덤, 실패는 처치 보상만 표시합니다. 실패나 전투 건너뛰기로 연습실이 파손되면 수리비는 마지막 건설비의 50%입니다. 그냥 두기에는 게이지 초기화를 표시합니다.

2차 화면의 전투·편성·보상은 검수 상태 예시입니다. 기분 배율은 최신 기획을 표시하며 실게임 발란스·피해 계산·지급·저장은 연결 대기입니다.
