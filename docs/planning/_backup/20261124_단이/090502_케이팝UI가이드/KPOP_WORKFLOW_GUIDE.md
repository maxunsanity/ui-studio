## 케이팝몬스터즈 기획 동기화와 UI 제작 순서

**제작 범위는 1차 와이어프레임과 2차 세부 와이어프레임까지입니다. 3차 본 UI 원본은 미제작으로 관리합니다.** 검수용 이미지와 조작 예시는 2차 설계 자료로 기록합니다.

현중이 정한 동기화 순서는 클로드 초안 → 클로드가 공통 UI 기획서 양식으로 정리 → 코덱스 검수와 실제 UI 제작 → 코덱스가 7018 UI 기획서와 작업 명세 갱신 → 클로드가 7018 내역을 7007에 동기화입니다.

1. 클로드 원안과 연결 문서, 현재 7018 탭과 저장판을 읽고 충돌 항목을 확인합니다. 화면의 진입·조건·상태·복귀·공통 부품을 목록으로 작성합니다.
2. HUD·포토카드 및 해당 기능에 맞는 내장 참고 샘플의 계층, 배치, 크기, 아이콘과 상태를 확인합니다.
3. 7018 안에서 최신 UI 기획서, 작업 명세, 그림, 검수 목록을 실제 저장판과 맞춥니다. 7007 동기화는 클로드가 수행합니다.
4. 1차 와이어프레임에는 영역과 흐름을 설명합니다. 2차 세부 와이어프레임은 UI 스튜디오에서 텍스트, 버튼, 아이콘, 이미지, 게이지를 각각 편집할 수 있게 만듭니다. 확정 수치가 있으면 화면에 숫자와 단위를 직접 표시하고, 원본 결측은 —로 남깁니다. 텍스트는 시스템 글꼴을 쓰고, 흑백 아이콘은 의미가 읽히도록 강조합니다. 공통 틀과 9슬라이스 상태를 공유하고 필요한 그림만 새로 제작합니다.
5. 기능별로 왼쪽에 메인, 오른쪽에 상세·팝업·상태를 흐름 순으로 펼칩니다. 반복 구성은 실제 부품 보드에 전개합니다. 카드나 팩의 화면은 확인, 연출, 결과를 사용 순서로 잇습니다.
6. 작업 명세에 캔버스와 같은 순서로 화면 ID, 진입·복귀, 입력 조건, 상태 변화, 규격, 출처, 최신 실제 캡처를 적습니다. 이전 그림은 백업에 보존하고 작업 명세에는 최신 캡처를 표시합니다. 작업 명세에서 UI 기획서 원문 탭과 동작 미리보기를 열 수 있게 연결합니다.
7. UI 스튜디오에서 저장한 설계를 다시 열고, 보드·이미지·가로 넘침·시스템 글꼴·화면 이동을 확인합니다. 실제 브라우저 마우스 입력으로 들어가기·선택·닫기·복귀를 확인합니다. 팝업은 편집 캔버스와 동작 미리보기의 좌표 기준이 맞고 제목·버튼이 프레임 안에 있는지 확인합니다. 검수 범위와 연동 대기 항목을 기록합니다. 수정 전 백업을 남깁니다.

이번 제작 순서는 스케줄 → 관계입니다. 작업 명세만 요청받은 회차에는 원본 기획은 확인과 동기화 원본으로 사용합니다.

스케줄 작업 명세에는 화면마다 전체 화면·바텀 시트·모달·부품 보드 유형을 표시합니다. 스케줄 창은 390×844 기준 374×748 공통 외곽을 사용하며, 하단 정렬의 바텀 시트와 가운데 정렬의 모달을 구분해 진입·복귀와 함께 기록합니다.
