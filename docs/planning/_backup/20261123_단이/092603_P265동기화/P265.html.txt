<p class="meta"><strong>UI 스튜디오 2차 저장판 r8</strong>　정보 메뉴 아이돌·팀의 목적 화면과 진입 HUD로 돌아가는 규칙, 몬스 기분 게이지·수량, 필러와 조작 줄, 공통 버튼 9슬라이스 규격을 2차 작업 명세 기준으로 봅니다. 포토카드 화면을 여는 게임 연결은 연동 항목입니다. <a href="http://127.0.0.1:7018/ui-studio/source/guide/reference/kpop-lobby/review-2/index.html#overview">최신 작업 명세</a></p>

<summary>3. 화면 깊이 · 뒤로</summary>
<div>
<p>깊이 0 = HUD, 1 = HUD에서 한 번 눌러 여는 화면, 2 = 그 안의 버튼으로 들어가는 안쪽 화면. 책갈피는 같은 깊이 안에서 바꿔 보는 것이라 깊이를 늘리지 않습니다.</p>
<table>
<tr><th>#</th><th>규칙</th><th>출처</th></tr>
<tr><td>1</td><td>깊이는 2까지. 더 들어가야 하면 창으로 띄움. 창은 깊이를 늘리지 않음</td><td>현중 11/19</td></tr>
<tr><td>2</td><td>← 뒤로는 한 칸 위로. 깊이 2 → 깊이 1(보던 책갈피 그대로) → HUD</td><td>확정</td></tr>
<tr><td>3</td><td>창은 닫기 · 바깥 누름 · Escape로 닫고 연 자리로 돌아감</td><td>확정</td></tr>

<p class="meta"><strong>UI 스튜디오 2차 저장판 r6</strong>　홈·편성의 장소 카드에서 시작해 진행 중 → 이야기 → 결과로 이어집니다. 탐험 4장면과 출동 3장면은 장면마다 화면을 채우는 배경, 인물·몬스, 대사를 별도 층으로 구성합니다. 검수 예시는 새벽 녹음과 안개 낀 숲길입니다. 실제 3D 모델과 애니메이션 연결은 게임 제작에서 진행합니다. <a href="http://127.0.0.1:7018/ui-studio/source/guide/reference/kpop-schedule/index.html#scene">최신 작업 명세</a></p>

  <div class="key">
    <h2>핵심</h2>
    <ul>
      <li>기본 흐름은 <b>홈 → 보내기·출동 → 진행 중 → 이야기 → 결과</b>입니다. 이야기 장면은 탐험 4개, 출동 3개로 이어집니다.</li>
      <li>홈 카드 한 장 = 스케줄 하나. 카드가 상태(결과 받기 · 진행 중 · 보내기 · 못 보냄 · 잠김)를 들고 있어서 따로 진행 목록이 없습니다. 순서는 열리는 엔터파워 순으로 고정합니다.</li>
      <li>아이돌 탐험과 몬스 출동은 <b>같은 틀</b>입니다. 위에 큰 대표 이미지, 그 아래 <b>조건 줄 = 보낼 팀</b>(줄 안에 얼굴이 쌓임), 누른 줄에 넣을 수 있는 사람만 아래에 나옵니다.</li>
      <li>아이돌 · 스태프 · 몬스는 배지로 구분합니다. 진한 칩은 꼭 필요, 테두리 칩은 넣으면 좋음, 안 가는 것은 숨깁니다.</li>
      <li>결과는 이야기를 먼저 보고, 그다음 한 장으로 ★ · 받은 것 · 좋아진 것(전 → 후 ▲)을 보여줍니다. 카드팩은 받은 뒤에 엽니다.</li>
      <li>도감 조각 3개로 항목을 완성하고, 남는 조각은 반복 퍼즐에 씁니다. 다녀온 스케줄은 엽서가 되어 기록장 · 소식으로 친구와 나눕니다.</li>
    </ul>
  </div>

<p class="meta">v1 · 2026-11-20 클로드 · 기준 순서: 현중 직접 조정 → 미션 기획 S11 · 미션 표 → 게임 시뮬레이터 미션 · 와이어 원본: <a href="산출_기획서_20261120_미션_와이어프레임.html">미션 와이어프레임</a> · 양식: <a href="산출_기획서_20261120_UI기획_문서규칙.html">UI 기획 문서 규칙</a></p>


<p class="meta"><strong>UI 스튜디오 2차 저장판 r10</strong>　상단 자원 칩에는 HUD의 흑백 주사위·루비 아이콘을 씁니다. 6개 탭과 상태별 버튼은 같은 규격을 씁니다. 미션 카드 왼쪽에는 출석·굴림·출동처럼 목표 유형을 나타내는 아이콘을, 보상 줄에는 재화 아이콘과 수량을 표시합니다. 주간과 이벤트는 완료·현재·다음 보상 상태를 구분합니다. <a href="http://127.0.0.1:7018/ui-studio/source/guide/reference/kpop-mission/index.html#ui-polish">최신 작업 명세</a></p>

    <h2>핵심</h2>
    <ul>
      <li>미션은 새 놀이가 아니라 보드에서 하는 일(굴림 · 칸 도착 · 증설 · 카드 열기 · 스케줄 · 미니게임)의 <b>횟수 장부</b>입니다. 다 되면 목록에서 바로 받고, 받을 때 창은 뜨지 않습니다.</li>
      <li>탭 6개는 <b>기존 이름 그대로</b>입니다. 카드 · 정렬 · 받기는 모두 같고 <b>위쪽 칸만</b> 탭마다 다릅니다.</li>
      <li>일일은 오늘 받은 수를 <b>차트 순위</b>(1개 100위 → 5개 1위)로, 주간은 <b>음방 트로피</b>(4개)로 보여 줍니다. 1위 칸이 기존 묶음 보상(오늘 5개 · 이번 주 4개 완료)입니다.</li>
      <li>미션 카드는 <b>목표 유형을 나타내는 아이콘과 팬의 부탁</b>을 함께 보여 줍니다. 큰 글은 부탁 말투, 아래 회색 글은 실제 할 일과 진행 막대. 카드 아래 줄에 <b>받을 보상을 아이콘 + 수량</b>으로 바로 보여 줍니다. 버튼은 「받기」 또는 「바로 가기 ›」.</li>
      <li>순서는 받기 → 진행 중 → 잠김 → 받음(✓ 흐리게 · 접지 않음). 맨 아래 「전체 받기 · n건」(0건이면 꺼짐).</li>
      <li>게이지 칸 · 보상 칸을 누르면 <b>말풍선</b>으로 조건 · 내용을 봅니다. 팩은 「팩 안 보기 ›」로 포토카드 팩 안 카드 창을 엽니다.</li>

      <li>모든 탭 맨 위 = <b>무료 선물</b>(6시간마다 주사위 30 · 쌓이지 않음). 받을 수 있으면 아래 「상점」에 빨간 점.</li>
      <li>주사위 · 팩은 <b>루비</b>로, 루비는 <b>원화</b>로 삽니다. 루비 결제는 구성·가격을 확인합니다. 원화 구매는 2차에서 확인 예시를 보이며 실결제는 플랫폼 결제창에서 진행합니다.</li>
      <li>루비가 모자라면 「루비 탭으로 ›」. 보드에서 주사위가 0이면 <b>주사위 채움 창</b>(주사위 탭과 같은 상품 6개)이 뜹니다.</li>
      <li>값은 표 그대로입니다. 팩 가격은 임시값, 첫 구매 두 배는 꺼져 있어 자리만 둡니다.</li>
    </ul>
  </div>
</section>
