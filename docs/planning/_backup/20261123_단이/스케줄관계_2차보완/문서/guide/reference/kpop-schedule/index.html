진행과 결과

그림 조각 도감

  • 스케줄 결과에 획득한 조각과 채운 번호를 표시합니다. 예시로 오래된 악보 4 / 9, 새 칸 5번을 보여줍니다. 도감 보기는 해당 그림 상세로 이동합니다.
  • 홈 도감에는 27장과 6개 분류, 발견 전·모으는 중·완성 상태가 들어갑니다. 9개 미만이면 맞추기 버튼을 비활성화합니다.
  • 같은 그림의 조각 9개를 모아 3×3 판에 맞춥니다. 2차 미리보기에서는 조각 3 → 7 → 8을 차례대로 눌러 빈 칸 3 → 7 → 8을 선택할 수 있습니다. 오답 안내, 완성 그림, 9칸 완성 상태를 확인할 수 있습니다. 실제 조각 끌어 놓기와 자유 순서 배치는 게임 구현에서 연결합니다.
  • 첫 완성은 9조각을 사용해 그림을 등록하고 보상과 이야기를 엽니다. 다시 모으면 2회차 예시와 주사위 ×27 보상을 표시합니다. 분류·전체 완성 보상은 결정 대기입니다. 그림 원화는 와이어프레임에서 칸으로 표시합니다.
