관계 화면

HUD 오른쪽 정보 메뉴에서 「관계」를 선택합니다. 아이돌끼리·스태프와, 서기·관계도로 전환합니다. 친한 순서와 관계도는 클로드 초안의 표와 멤버 예시를 사용합니다.

상세와 연결

  • 멤버 → 둘 사이·스태프 짝·회장 짝 → 함께 보내기. 추천 스케줄, 전체 목록, 닫기를 열 수 있습니다.
  • 실제 게임의 모험·스케줄은 모듈 요청을 받는 쪽에서 대상, 참가자와 복귀 위치를 이어야 합니다. 7018은 요청과 화면 상태를 검수합니다.
  • 스케줄 결과의 좋아진 라포에는 함께 간 짝의 증가분이 표시됩니다. 단계가 상승한 짝은 ⑥을 한 장씩 보여 주고 마지막 확인 뒤 결과로 돌아갑니다.
  • 함께 보낼 스케줄은 전체 화면 좌표 안에 9슬라이스 창을 배치합니다. 430px에서 제목·시간·보내기 버튼의 행 안쪽 포함 여부를 확인했습니다.

공통 부품

관계 단계와 수치, 아이돌·스태프 행, 추천 스케줄 카드, 닫기와 보내기 상태를 관계 공통 부품 보드에서 확인합니다. 원안에 값이 없는 스태프 예시는 데이터 연결 대기로 표시합니다.
