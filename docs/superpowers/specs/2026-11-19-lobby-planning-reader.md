# 로비 기획 읽기 보기
사용자 승인: 이 채팅 「그럼 해봐..작업을..로비창으로..」
프로젝트별 기획 정본 하나를 그림→영역 설명→클릭→상태→검토 질문 순서로 제공한다. 로비 전체와 부품 선택 때 같은 정본의 해당 절을 오른쪽에서 요약하고 문서 뷰어를 연다. 근거·이력은 원문 사본으로 접어 분리. 합의는 로비1차뿐이며 2차와 타 페이지 확정 표현을 승계하지 않는다.
접근 방식: 외부 탭만 연결은 편집과 분리되어 요약 부족. 본문 전체를 속성에 복사하면 중복·긴글 재발. 프로젝트/화면/부품ID의 선언형 연결표와 공통 읽기 패널을 채택.
기존 디자인JSON/게임기획 원본 무수정. 공통 도구 소스만 최소 수정, 정본 보기/등록/요약 데이터는 한 패키지로 관리. 숨은 기획 승인·게임 수치 확정 없음.
