# UI 스튜디오 · 프로젝트 폴더와 내장 설명서
작성자 codex(단이) · 2026-11-16 · 제안(검수 대기)

## 사용자 직접 요구
프로젝트를 폴더로 구분. 폴더 찾기로 열고 선택한 폴더 안에 ui-studio를 생성. 기본 가이드·툴 기획서·제작 구조·활용법·현재 진척과 남은 작업을 툴 안에 포함하고 언제든 보기/프로젝트 전환. 설명서와 기능 함께 작업. 기존 UI가 있으면 전부 스튜디오 관리 구조에 맞추되 변환 전에 반드시 사용자에게 변환 여부를 질문. 거절하면 기존 게임 UI를 건드리지 않고 독립 UI 소스 저장. 현재 UI 미완료이며 대표 W/P/U/S0/4 유지.

## 구현 결정
공용7007 스튜디오와 게임별 ui-studio 데이터 폴더. 툴 전체 복제는 업데이트 분기를 만들므로 사용하지 않음. 게임폴더는 네이티브 macOS 폴더선택기로 명시 선택. 서버가 UI 스튜디오에 포함된 작은 AppKit 선택기를 실행하며 브라우저가 임의 경로를 저장 API에 전달하는 기능은 만들지 않음. 별도 앱 소스/엔진/새 패키지 불필요.

ui-studio/project.json: 폴더 프로젝트ID·이름·가이드판·변환 선택과 시각. designs/: 문서(JSON) 및 기존 방식 backups/baselines. assets/: 독립UI자원. guide/: 공통 설명서 사본. README.md/AGENTS.md: AI 진입점과 상위 프로젝트 지침 우선. integration.md: 기존 게임 연결·변환 현황. exports/: 독립 출력.
게임의 루트 AGENTS·소스·저장파일은 폴더 열기로 수정하지 않음. 파일쓰기 허용범위는 선택게임/ui-studio 내부. 심볼릭 링크/상위경로 탈출/기존폴더 형식불일치 거부. 기존 프로젝트 폴더가 있으면 가이드나문서 덮어쓰기 없이 재열기. 원자적 저장·revision충돌·백업 유지.

## 폴더별 격리
현재 레거시 저장공간은 보존. workspace ID는 브라우저 URL과 매 API에 포함하고 서버 전역 active 변수를 쓰지 않음. 동일문서ID가 서로 다른폴더에 있어도 저장/소비자/최근문서/BroadcastChannel 범위 격리. 미저장 전환은 저장후전환/수정버리고전환/취소, 실패시 원문서 유지.

## 기존 게임 동의
새폴더 첫열기에서 기존UI 변환 여부를 먼저 묻는다: 변환·연결 요청 / 독립UI로 작업 / 취소. 선택과시각을 project.json에 저장. 변환 요청은 작업지시이며 자동변환완료가 아님. AI는 기존 프로젝트 지침→UI 전체목록→부품/상태/입력/이동/저장/자원 대조→백업→스튜디오 구조화→연결 변경→기존동작 회귀 순서. 누락/미지원/동적화면은 명시하고 전체가 검수되기 전 완료 금지. 거절한 프로젝트는 게임코드 변경 금지·ui-studio 안 독립UI소스만 작성. 사용자가 명시적으로 선택을 바꾸기 전 유지. 실제 게임 UI를 이번 구현에서 자동변환하지 않음.

## 내장 설명서
사용 설명서, AI 사용·수정규칙, 툴 기획서, 제작구조, 기존게임 변환·독립저장 규칙, 진척/미완료. 공통정본은 src/tools/uxStudio/guide 안. 상단 항상 보이는 가이드 버튼에서 조회. 선택프로젝트에도 사본을 넣고 프로젝트안내로 읽음. 상위AGENTS를 덮어쓰지 않으며 웹가이드 내용은 실행코드가 아니라 문서로 표시. 구현/계획/관찰/미확인 구분.

## 순서와 검수
1. 폴더저장/격리/변환선택 백엔드 및 테스트. 2. 폴더선택·전환·저장/소비 연결. 3. 공통/프로젝트설명서 실제보기. 4. 프로젝트2개 격리·한글경로·미저장취소·기존파일보존·재열기·실브라우저/로컬앱 검수. 기존게임/보호파일 수정 및 서버 강제종료 없음. 기능과 설명서를 함께 갱신. 미지원 자동변환을 구현됐다고 쓰지 않음.
