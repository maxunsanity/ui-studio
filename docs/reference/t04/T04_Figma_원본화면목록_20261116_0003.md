## 다음 조립 대상과 입력 분리
스티커 보내기 확인(image303)을 원본 기반 모달 샘플 대상으로 삼습니다. 아래는 우리 툴 조립 명세 제안이며 Unity 원본 계층이 아닙니다.

- 화면 루트 → 타임라인 배경(보존) → 딤/입력 차단층 → 모달 전체 → 프레임/바탕/제목/콘텐츠 그룹/안내/횟수/확인 버튼.
- 콘텐츠 그룹 → 카드 이미지/별/수량/이름, 방향 화살표, 대상 아바타. 표시 요소와 확인 버튼 클릭영역을 분리합니다. 그림 등록 후 임시박스는 숨기되 프레임은 별도 유지합니다.
- 전달값은 stickerId/recipientId/ownedCount/dailyUsed/dailyLimit의 시험 데이터 참조로 제안합니다. 원본0/5는 캡처의 관찰값이며 게임 정책으로 하드코딩하지 않습니다.
- 준비/전송중/성공/실패/횟수부족/닫기 상태는 수락시험에 필요하지만, 원본에서 확인된 것은 준비 상태뿐입니다. 다른 상태는 시험용 제안으로 표시해야 합니다.
- 302의 보내기에서303으로 진입하는 것은 내용상 추정입니다. 실제 클릭 영상 또는 프로토타입 근거를 확보할 때까지 확정 연결로 기록하지 않습니다.
- 하단X의 소속/닫기 깊이는 미확인입니다. 원본 UI를 임의로 확정하지 않고 샘플의 임시 닫기 정책을 분리합니다.
- 저장/재열기, 연타, 뒤 화면 차단, 닫기 후 선택·스크롤 복원, 1440/430 검수는 조립 후 수행합니다. 이번에 통과한 시험으로 세지 않습니다.

기존 r7의 3페이지+기본 모달은 보존하며 이 원본 화면들을 재현한 완성품이 아닙니다. 대표 W/P/U/S 0/4 유지.
